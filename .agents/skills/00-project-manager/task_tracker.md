# ProjectLoB 현재 작업

기준: 2026-10-04 · `prototype/core-redesign`

## 최신 방향과 제작 환경

- 사용자 확정: 산나비·ARCANE TRIGGER를 참고해 UI까지 전체 도트풍으로 전환한다. 이전 일러스트 혼합 화면은 전환 전 구현이며 아트 완료 상태가 아니다.
- 외부 제작 스킬 총 10개를 사용 가능한 경로에 배치했다. 기존 5개 보존, 신규 5개 추가. LibreSprite·Impeccable 실행 엔진과 Godot MCP를 설치·검증했다.
- PixelLab 인증과 실제 Pixen 생성 8회를 확인했다. 회수자·적 6종·공업 지대 배경을 게임에 적용했으며 생성 후 32회 잔여다. 세부 상태는 [아트·UX 기준](../../../docs/direction/art-and-ux.md), [도구 잠금 파일](../../../tools/art_tooling.lock.json)을 따른다.
- 첫 통합 도트 전투 화면: 같은 바닥·발 기준점, 큰 탄환 실루엣, 짧은 효과 문구, 낮은 발사 순서, 네 적 밀집 판독을 적용했다. 세 비율 렌더와 기능 검증을 완료했다. 상세는 [2026-10-03 기록](../../../docs/history/daily/2026-10-03.md).
- 사용자 최신 아트 확정: 탄환 카드와 새 도트풍 유지, [정비용 헬멧 주인공 v2](../../../docs/art/concepts/2026-10-03-pixel-reference/character-reference-v2-helmet.png)를 시작 외형으로 채택했다. 기존 인게임 배우·배경은 임시 상태이며 이제 채택 시안의 실제 게임 적용을 진행할 수 있다.

## 현재 진행 / 후속 대기

- 사용자 종합 확인: 전체 진행 방향에 긍정 답변을 받았으며 현재 작업의 커밋을 요청했다. 현행 방향을 유지하고 원거리 샘플의 사람 플레이·정식 몬스터 아트·후속 폴리싱을 이어간다.

- 최신 구현: **원거리·요격과 고출력/과열의 결합 샘플**. 실행 `PLAY_RANGED_SAMPLE.cmd`. 두 편성, 준비/발사/도달, 증폭·전이 요격, 재장전 위험, 본체 사망 후 남은 탄, 저장/확률 예측을 연결했다. 새 규칙417/0·실제UI281/0와 기존 회귀 통과. [화면·검증·남은 판단](../../../docs/qa/reports/ranged_2026-10-04.md). 본편 미편성·몬스터 시험용 외형. 다음은 사람 플레이에서 반복 요격 부담과 첫 탄 정형화를 확인하고 정식 몬스터 시안/편성을 진행한다.

- 연출 상태: 보강 후 사용자가 대략적인 느낌을 이해했고 재정비·폴리싱은 향후 진행하기로 했다. **방향 이해 확인 / 세부 폴리싱 후속 대기**. [구현과 검증](../../../docs/qa/reports/ammo_feedback_2026-10-04.md), 실행 `PLAY_AMMO_RISK.cmd`. 해당 연출은 새 원거리 샘플에서도 재사용한다. 연출·밸런스 최종 확정으로 처리하지 않는다.

- 앞선 구현: `PLAY_AMMO_RISK.cmd`의 고출력 증폭/과열 비교 전투 2개, 사전 피해·재장전·접촉 위험 표시, 승리/패배 후 비교 재시작. [구현·화면·검증](../../../docs/qa/reports/ammo_risk_2026-10-04.md). 규칙296/0·UI149/0 및 기존 회귀 통과. 캠페인 공급은 유지한다.

- 앞선 피드백과 현재 기준: 몬스터·요격 진행 방향 채택. 탄환 리스크 부족과 증폭 후 과열/재장전 추가 시간 예시는 [출력과 대가](../../../docs/direction/ammo-risk.md)로 구체화했다. 첫 샘플은 위 최신 구현을 따르며 일반 증폭에 +2턴을 적용한 것으로 해석하지 않는다.

- 몬스터 제작안: [일반 적 8종·보스 후보 2종](../../../docs/direction/monster-roster.md). 플레이어 HP 없는 거리 패배·자동 표적·무기별 시간 비용을 기준으로 요격을 구현했다. 정식 아트는 잔열쥐·철각충·압력두꺼비 시안 비교부터 진행하며 이름/수치의 최종 채택은 별도다.

- 2026-10-04 샘플 크기 피드백: 주인공을 35% 축소(0.65배), 접지와 총구 위치 유지. [갱신된 화면](../../../docs/qa/reports/tower_art_scale_2026-10-04_assets/tower_battle_1280x900.png). 동일 샘플 실행 경로, 4개 비율/실제 입력 검사68/0 재확인.

- 최신 요청 완료: C 복장+B 방한모와 제작한 주거구 배경의 [실행 가능한 전투 샘플](../../../docs/qa/reports/tower_art_sample_2026-10-03.md). `PLAY_TOWER_SAMPLE.cmd`, 대표1280×900 포함 4개 비율, 실제 카드/예측/확정/발사. 샘플68/0·기존 전투 회귀79/0. 적·단일 포즈는 임시이며 기본 캠페인 아트는 아직 교체하지 않았다. 다음은 이 통합 화면 피드백과 같은 스타일의 적/캐릭터 동작 제작이다.

- 최신 구현·검증: 요청한 4번까지(빌드 선택·첫 지역·지도/상점/경제). 720사례 비교 후 예비 급탄기 교환+1, 보유 탄과 파츠 연결, 단계적 적 도입/첫 조합, 시작30Cr·다른 역할의 첫 진열·3→5→7→9Cr 교체 비용·위험 전투 보상+6Cr를 적용했다. [현재 화면과 검사](../../../docs/qa/reports/progression_2026-10-03.md).
- 세계관 채택: 기상탑·탄환 기술자·복구 엔딩의 큰 방향과 ‘위험한 탐험 + 사람 사는 온기 + 은근한 디스토피아’를 유지한다. [세계관 기준](../../../docs/direction/worldbuilding.md) v0.3에 반영했다. 사용자가 아이템·쪽지의 간접 서사를 요청해 [전달 설계와 원고](../../../docs/direction/narrative-delivery.md)에 아이템 6개·기록 20개·상점/환경의 교차 단서를 작성했다. 개별 원고·연출은 제작안이며 게임에는 미적용이다.
- 도트 기준 재정립: 사용자 이미지10개 검토 → 캐릭터·배경 시안 → 헬멧 수정안과 시작 외형 채택을 마쳤다. [제작 방향](../../../docs/direction/pixel-style.md)을 따른다. 컨셉 이미지와 런타임 스프라이트는 구별하며 새 배우·환경은 아직 게임에 미적용이다.
- 후속 기능 등록: 복장/헬멧 인게임 획득·교체. [설계](../../../docs/direction/appearance.md)에 두 독립 슬롯, 영구 수집 제안, 출격/비전투 미리보기·착용, 분리 아트·저장 호환 기준을 기록했다. 능력치 효과는 미정이며 기능 구현은 후속이다.
- 다음 우선순위: 현재 원거리 샘플의 사람 플레이와 새 몬스터 시안 비교. 간접 서사 원고의 기록/상세 연결도 후속 범위로 유지한다. 새 등반의 첫 선택과 반복 빌드 차이는 사람의 추가 플레이 피드백으로 보완한다. 자동 탐색의 완주와 통제 비교는 전체 밸런스/재미의 완료 판정이 아니다.
- 파츠 결과 전달 완료: 장착 아이콘/발동 순서·실제 명중 연결, 쇄도 누적 적중, 교전별 핵심 기록. 산개의 순서 파츠 예측·장착 캐시 누락 수정. [앞선 구현](../../../docs/qa/reports/build_feedback_2026-10-03.md).

- 조작 흐름 구현·검증: 다음 발사 예측/전체 탄창 전환, 고정 손패, 탄창 드래그·버튼 이동과 명시적 회수·상세, 확정 비용, 파츠 손실 비교, 상점 단일 구매, 접힌 출격 설정. [화면과 검사](../../../docs/qa/reports/interaction_flow_2026-10-03.md).
- 구현·검증 완료: 메인 주 행동 재배치, 다섯 무기와 시작 보급 비교, 고정된 상점 비교 영역, 장착·보관·선택 상세를 함께 보여 주는 파츠 작업실. 코어/슬롯 교체, 분해 확인, 전투 잠금, 저장 복원과 터치·키보드 흐름을 검증했다. [화면과 보고서](../../../docs/qa/reports/navigation_ui_2026-10-03.md).
- 배우·환경 제작: 세계관 방향 채택과 사용자 레퍼런스 검토 완료 → 다음은 캐릭터·적·배경 통합 시안 → 실제 아트 교체와 동작 확장. 현행 산업도시·기계형 적 이미지는 임시 자산이다.

## 기존 완료 범위

- 오래된 역할 지침을 보관하고 현재 게임의 기획·아트 기준을 통합했다.
- 회수자·지도·작업실과 다섯 구역의 환경을 실제 Godot 화면에 적용했다.
- 다섯 무기 실루엣·여섯 적 역할, 다섯 파츠 장착 카드, 안정적인 발사 순서와 파츠 발동 표현을 제작했다.
- 메인부터 결과까지 화면·입력 흐름을 정리하고 작은 가로 화면을 실제 렌더와 입력으로 검증했다.
- 상점 구매 전후 장착 안내·현재 수치·비교 이동·압축 충전 접근성을 수정했다. 한글 글꼴을 번들로 고정했다.

실행: `PLAY.cmd`. [돌아와서 확인할 것](../../../RETURN_CHECK.md) · [최신 구현·검증 보고서](../../../docs/qa/reports/progression_2026-10-03.md).

- 실제 갤럭시의 터치·렌더 성능·플레이 피로도와 사람의 첫 선택 이해도.
- 전용 보스 원화, 캐릭터 프레임 애니메이션, 음악·효과음의 제작 범위.
- 여러 시드·난도에서의 빌드 선택 다양성. 자동 탐색의 완주는 실제 승률이 아니다.
