# 재미·UX 검증 루브릭

## 목차

1. 평가 축
2. 증거 규칙
3. 신뢰도

## 1. 평가 축

| 축 | 질문 | 기록할 증거 |
|---|---|---|
| 이해 | 다음 탄의 결과와 실패 이유를 화면만 보고 설명할 수 있는가 | 예상과 실제 결과, 도움말 재확인 |
| 선택 | 실제 이득이 다른 선택지가 둘 이상 존재하는가 | 선택 이유, 포기한 대안 |
| 순서 | 같은 탄 조합도 LIFO 순서가 결과를 바꾸는가 | 재장전 계획과 결산 성공/실패 |
| 압박 | 계산 가능한 위험과 안전 마진이 모두 존재하는가 | 최소 거리, 남은 행동 수 |
| 호흡 | 판단 사이에 의미 없는 반복 입력이 과도하지 않은가 | 리로드, 무효 발사, 반복 장전 |
| 피드백 | 발동 이유와 결과가 한 번의 관찰로 읽히는가 | 배지, 로그, 연출의 일치 여부 |
| 다양성 | 프로필에 따라 탄환·파츠·경로 선택이 달라지는가 | 프로필 간 선택 중복과 미선택 이유 |

## 2. 증거 규칙

- 감상 뒤에 반드시 당시 화면, 상태 단계, 선택, 실제 결과를 붙인다.
- `재미있다/없다`만 기록하지 않는다.
- 많이 선택한 항목이 문제인지, 다른 대안이 읽히지 않은 것인지 구분한다.
- 승패와 재미를 동일시하지 않는다. 패배해도 원인이 이해되고 재계획 욕구가 있으면 긍정 신호다.
- 최적해가 존재하는 것과 선택지가 하나뿐인 것은 다르다. 비용과 상황에 따라 차선이 성립하는지 본다.

## 3. 신뢰도

- `관찰`: 한 프로필의 한 상황
- `반복 신호`: 두 프로필 또는 두 비교 가능한 상황
- `강한 신호`: 세 프로필 이상에서 동일 방향
- `인간 확인`: 촉감, 애니메이션 속도, 장시간 피로처럼 자동 판정 불가
