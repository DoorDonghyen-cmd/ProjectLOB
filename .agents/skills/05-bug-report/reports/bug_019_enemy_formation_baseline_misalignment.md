# 🐛 [버그 리포트] #019. 4체 편성 몬스터의 시각적 바닥선 불일치

## 1. 개요 (Overview)
*   **제보 일시**: 2026-08-15
*   **상태**: `Open`
*   **중요도**: `보통`
*   **관련 컴포넌트**: 전투 UI, 적 트랙 배치, 적 스프라이트 에셋

## 2. 현상 설명 (Description)
*   약 4마리가 등장하는 상층 일반전에서 몬스터들이 같은 바닥선 위에 서 있지 않고 일부가 위로 떠 있는 것처럼 보인다.
*   각 적의 수평 위치는 거리 정보에 따라 달라질 수 있지만, 세로 방향의 발끝 기준선까지 달라져 대열이 불규칙하게 보인다.

## 3. 재현 경로 (Steps to Reproduce)
1. 개발자 메뉴에서 `관리 4체 QA` 또는 `정점 4체 QA` 전투를 시작한다.
2. 전투 트랙에 표시된 네 적의 발끝 또는 스프라이트 불투명 영역 하단을 비교한다.
3. 교란 드론 등 일부 적이 다른 적보다 위에 떠 있는 것처럼 보이는 현상을 확인한다.

## 4. 원인 분석 (Root Cause)
*   `EnemyTrackView`는 모든 적을 같은 80×80 `TextureRect`에 넣고 `STRETCH_KEEP_ASPECT_CENTERED`로 중앙 정렬한다. 따라서 원본 이미지의 캔버스 전체는 같은 기준선에 놓이지만, 실제 불투명 픽셀의 바닥선은 정렬하지 않는다.
*   상층 대표 4체 편성의 원본 스프라이트는 투명 하단 여백이 크게 다르다.
    *   태세 교란 드론: 1024px 중 하단 250px 투명 → 80px 표시 기준 약 19.5px 위에 떠 보임
    *   광학 추적체 03: 하단 123/1024px 투명 → 약 9.6px
    *   경보 순찰 드론: 하단 0/128px 투명 → 0px
    *   상위 신경 통제체: 하단 133/1024px 투명 → 약 10.4px
*   `관리 4체 QA`의 시작 거리는 각각 8m, 12m, 14m, 18m로 서로 달라, 최초 배치에서 `_same_distance_formation_offset()`의 세로 오프셋은 적용되지 않는다. 이 경우 제보된 최초 바닥선 차이의 직접 원인은 이미지 내부 투명 여백이다.
*   전투 중 여러 적의 `current_distance`가 같아지면 `_same_distance_formation_offset()`가 세로 26px 간격의 대각 슬롯을 추가한다. 네 적이 같은 거리라면 -39px, -13px, +13px, +39px이 적용되어 한 줄에서 더 크게 벗어난다.
*   적마다 위상이 다른 비균일 스케일·회전 대기 모션도 시각적 바닥선 흔들림을 보조적으로 키운다.

## 5. 해결 방안 (Resolution)
*   **미적용 / 제안**: 전투 UI에서 원본 캔버스 중심이 아니라 적별 시각적 발끝 기준점이 같은 Y에 오도록 정규화한다.
*   권장 방식은 `EnemyData` 또는 별도 표시 메타데이터에 `visual_ground_offset_y`를 두어 비인간형·부유형을 포함한 의도적 높이를 데이터로 관리하는 것이다. 에셋 파일 자체를 일괄 크롭하면 다른 사용처의 구도에 영향을 줄 수 있다.
*   동거리 적은 Y를 벌리는 대신 X 간격, 겹침 순서, 선택 링/클릭 영역으로 구분하여 거리 트랙의 공통 바닥선을 유지한다.
*   대기 모션은 발끝 피벗 또는 별도 비주얼 자식 노드에 적용해 HP 바·배지와 기준선이 흔들리지 않도록 분리한다.

## 6. 검증 내용 (Verification)
*   수정 후 관리/정점 대표 4체 편성에서 모든 지상형 적의 시각적 발끝이 동일한 기준선에 놓이는지 확인한다.
*   의도적으로 부유하는 드론은 데이터에 정의한 높이만큼만 떠 있고, 같은 종류가 포함된 다른 편성에서도 동일하게 표시되는지 확인한다.
*   전투 진행 중 적 두 마리 이상이 같은 거리에 합류해도 공통 기준선이 유지되고 각 적을 정상적으로 선택할 수 있는지 확인한다.
*   1~4체 UI 스모크 테스트에 시각적 Y 기준선과 동거리 선택 가능성 회귀 검사를 추가한다.
