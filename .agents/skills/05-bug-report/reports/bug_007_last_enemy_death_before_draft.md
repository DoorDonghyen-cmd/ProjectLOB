# 🐛 [버그 리포트] #007. 마지막 적 사망 연출 전에 결과·드래프트 창 표시

## 1. 개요 (Overview)

- **제보 일시**: 2026-07-26
- **상태**: `Closed`
- **중요도**: `보통`
- **관련 컴포넌트**: 전투 종료 연출 / 결과·보상 드래프트 UI

## 2. 현상 설명 (Description)

- 마지막 적을 처치하면 적이 사라지는 모습을 확인하기 전에 결과·보상 드래프트 창이 전투 화면을 덮는다.

## 3. 재현 경로 (Steps to Reproduce)

1. 마지막 생존 적을 탄환으로 처치한다.
2. 마지막 탄환 비행과 적 사망 실루엣을 관찰한다.
3. 사망 연출이 끝나기 전에 결과·드래프트 창이 표시된다.

## 4. 원인 분석 (Root Cause)

- 연출 큐는 발 사이 간격 0.18초까지만 기다렸지만 탄환 비행은 0.28초라 마지막 탄착보다 결과 처리가 빨랐다.
- 명시적인 적 사망 애니메이션과 그 완료 상태가 없어서, 큐가 비는 즉시 보류된 승리 결과를 표시했다.

## 5. 해결 방안 (Resolution)

- 마지막 탄의 남은 비행 시간까지 기다리는 꼬리 대기를 추가했다.
- 탄환 도착 시 사망한 적 실루엣을 0.45초 동안 페이드아웃한다.
- 마지막 적 처치에서는 페이드 완료 후 0.18초의 여운을 추가한 뒤 결과·드래프트를 표시한다.
- 연출 재생 중 적 이동 갱신이 죽은 적을 먼저 숨기지 않도록 차단하고, 큐 종료 후 위치·가시성을 정리한다.

## 6. 검증 내용 (Verification)

- 마지막 처치탄 큐가 실제 사망 대상을 보존함을 확인했다.
- 사망 실루엣 페이드 중 결과·드래프트 창이 숨겨져 있음을 확인했다.
- 처치 페이드와 후속 여운이 합계 0.63초 이상 확보됨을 회귀 테스트로 고정했다.
- 전체 자동 테스트 **2,553 통과 / 0 실패**, 전 스크립트 컴파일 및 4개 씬 로드 성공.
