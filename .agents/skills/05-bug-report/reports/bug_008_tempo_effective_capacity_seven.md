# 🐛 [버그 리포트] #008. Tempo 6발 설계가 약실 중복으로 실제 7발 적재됨

## 1. 개요 (Overview)
*   **제보 일시**: 2026-07-27
*   **상태**: `Closed`
*   **중요도**: `높음`
*   **관련 컴포넌트**: 총기 데이터, 탄창, 연발 화력, 예고창 UI

## 2. 현상 설명 (Description)
*   전술 기관단총 Tempo는 GDD·화력식·예고창 모두 6발 전탄 커밋을 전제로 하지만,
    실제 데이터는 `magazine_capacity=6`, `has_chamber=true`라 최대 7발까지 적재됐다.
*   기본탄 사이클이 의도한 `6 × (3−1) / 4턴 = 3.00`이 아니라
    `7 × (3−1) / 4턴 = 3.50 DMG/턴`이 될 수 있고, 예고창 6칸 밖의 한 발이 생겼다.

## 3. 재현 경로 (Steps to Reproduce)
1. `gun_stats.csv`에서 Tempo의 `magazine_capacity=6`, `has_chamber=true`를 확인한다.
2. `Magazine`이 약실 총기에 `capacity + 1`발을 허용하는 것을 확인한다.
3. Tempo에 7발을 전달하면 실제 잔여 탄수가 7발이 된다.

## 4. 원인 분석 (Root Cause)
*   `magazine_capacity`를 총 실장탄수로 기록하면서 동시에 `has_chamber=true`를 유지했다.
*   문서와 기존 테스트는 6발 배열만 넘겨 “7번째 탄도 들어가는가”를 확인하지 않아 결함을 놓쳤다.

## 5. 해결 방안 (Resolution)
*   Tempo의 내부 탄창을 `5`로 낮추고 약실 `+1`을 유지해 총 실장탄수를 6발로 고정한다.
*   GDD 표에 내부 탄창 5발 + 약실 1발이라는 데이터 의미를 명시한다.
*   7발을 장전해도 6발만 들어가는 회귀 테스트를 추가한다.

## 6. 검증 내용 (Verification)
*   `suite_fire_mode`에서 CSV 내부 탄창 5발, 약실 사용, 총 실장탄수 6발을 확인했다.
*   7발을 전달해도 실제 적재량이 6발로 제한됨을 확인했다.
*   Godot 4.7 전체 자동 검증: **2,639 통과 / 0 실패 / 3 기존 경보**.
