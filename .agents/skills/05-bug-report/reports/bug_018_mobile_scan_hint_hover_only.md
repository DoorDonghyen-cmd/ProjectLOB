# 🐛 [버그 리포트] #018. 모바일에서 미지 노드 스캔 힌트를 확인할 수 없음

## 1. 개요 (Overview)
*   **제보 일시**: 2026-08-05
*   **상태**: `Verified`
*   **중요도**: `높음`
*   **관련 컴포넌트**: 지도 UI, 미지 노드, 모바일 입력

## 2. 현상 설명 (Description)
*   선택 가능한 미지 노드의 전술 스캔 힌트가 마우스 호버 중에만 표시된다.
*   모바일 터치 환경에는 호버 상태가 없고 탭·길게 누르기 등 대체 입력도 연결되어 있지 않아, 모바일 플레이어는 분기 선택 전에 해당 정보를 확인할 수 없다.

## 3. 재현 경로 (Steps to Reproduce)
1. 모바일 또는 터치 입력 환경에서 스캔 힌트가 있는 미지 노드가 선택 가능한 층까지 진행한다.
2. 해당 노드를 탭하거나 길게 누른다.
3. 데스크톱 마우스 호버에서 표시되는 스캔 힌트를 확인할 수 없음을 확인한다.

## 4. 원인 분석 (Root Cause)
*   `map_overlay.gd`가 힌트 표시와 숨김을 각각 `mouse_entered`, `mouse_exited`에만 연결한다.
*   `emulate_mouse_from_touch`는 터치 탭과 드래그를 마우스 입력으로 변환하지만, 터치 장치에 지속적인 포인터 호버 상태를 제공하지는 않는다.

## 5. 해결 방안 (Resolution)
*   미지 노드의 터치 입력을 별도 라우팅해 첫 탭은 스캔과 재탭 안내만 표시하고, 준비된 같은 노드의 두 번째 탭만 이동을 확정하도록 구현했다.
*   다른 미지 노드를 탭하면 확인 대상을 교체하며, 지도 갱신·진입 시 준비 상태를 초기화한다.
*   실제 마우스는 기존 호버 스캔 후 한 번 클릭 진입을 유지하고 터치에서 합성된 마우스 이벤트는 중복 진입하지 않게 차단했다.

## 6. 검증 내용 (Verification)
*   개발자 메뉴에 `스캔·연계 예고 UI` 진입점을 추가했다.
*   `InputEventScreenTouch` 기반 UI 스모크에서 첫 탭 비진입·힌트 표시, 다른 노드 선택 대상 교체, 같은 노드 재탭 진입을 검증했다.
*   2026-08-09 전체 Godot 헤드리스 검증: 2,799 통과 / 0 실패 / 기존 경보 3.
