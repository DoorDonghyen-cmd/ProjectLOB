# 🐛 [버그 리포트] #011. 첫 구역 보스 클리어 후 다음 구역 대신 메인 화면으로 복귀

## 1. 개요 (Overview)
*   **제보 일시**: 2026-07-28
*   **상태**: `Closed`
*   **중요도**: `높음`
*   **관련 컴포넌트**: 연속 런 진행, 구역 해금, 디브리핑, 지도 브리핑

## 2. 현상 설명 (Description)
*   첫 구역인 침전 거주구의 보스를 처치하면 공역으로 이어지지 않고 디브리핑을 거쳐 메인 화면으로 복귀한다.
*   구역 경계에서 덱·파츠·가방·크레딧이 이어지지 않아 한 구역 동안 얻은 탄환 조합을 다음 구역에서 발전시키거나 사용할 수 없다.
*   현행 35층 연속 상승 및 런 내 빌드 성장 목표와 실제 플레이 흐름이 충돌한다.

## 3. 재현 경로 (Steps to Reproduce)
1. 신규 저장 상태에서 침전 거주구 상승을 시작한다.
2. 6층 보스를 처치하고 전투 보상을 확정한다.
3. 공역 전환 연출 대신 디브리핑이 표시되는 것을 확인한다.
4. 디브리핑을 닫으면 메인 화면으로 복귀하며 런 덱이 종료되는 것을 확인한다.

## 4. 원인 분석 (Root Cause)
*   `_advance_floor_or_finish()`가 `get_next_unlocked_section()`만 조회하므로, 아직 잠긴 공역은 다음 구역으로 인정되지 않는다.
*   다음 구역 해금은 디브리핑의 `check_section_unlocks()`에서 뒤늦게 실행된다.
*   과거의 6→13→20→27→35층 온보딩 램프가 코드·UI·테스트에 남아 한 런을 해금 상한마다 의도적으로 종료한다.

## 5. 해결 방안 (Resolution)
*   한 런의 여정을 해금 여부와 무관한 5계층·35층으로 고정한다.
*   구역 보스 처치 시 바로 다음 계층을 해금·저장한 뒤 `enter_section()`으로 연결한다.
*   계층 전환 시 덱·파츠·가방·크레딧 유지 계약을 회귀 테스트로 고정한다.
*   지도·상승 브리핑·GDD에서 과거 런 길이 램프 표현을 제거한다.

## 6. 검증 내용 (Verification)
*   침전 거주구 최종층을 넘기면 `section_b`가 즉시 해금되고 공역 전환 연출로 이어지는 메인 씬 회귀를 추가했다.
*   계층 전환 전후의 덱 크기, 가방 물자, 크레딧이 유지되고 디브리핑이 표시되지 않는 것을 검증했다.
*   지도와 상승 브리핑은 최초 저장에서도 35층·보스 5체의 단일 런을 표시한다.
*   2026-07-28 Godot 4.7 전체 자동 검증 **2,300 통과 / 0 실패 / 기존 경보 3**으로 종결했다.
