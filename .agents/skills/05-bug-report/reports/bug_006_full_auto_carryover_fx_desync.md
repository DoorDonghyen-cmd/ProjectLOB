# 🐛 [버그 리포트] #006. 연발 오버킬 이월 피해와 순차 피격 연출의 시점 불일치

## 1. 개요 (Overview)

- **제보 일시**: 2026-07-26
- **상태**: `Closed`
- **중요도**: `보통`
- **관련 컴포넌트**: 연발 전투 정산 / 탄환 비행 연출 / 적 HP UI

## 2. 현상 설명 (Description)

- 연발 사격으로 앞 적을 처치한 뒤 남은 탄환이 뒤 적에게 적중하지 않는 것처럼 보인다.
- 실제 전투 데이터에서는 뒤 적에게 남은 탄환 피해가 정상 적용되지만, 탄환 도착과 HP 바·피해 숫자의 갱신 시점이 맞지 않는다.

## 3. 재현 경로 (Steps to Reproduce)

1. 대미지 2 탄환 5발을 사용하는 연발 총기로 HP 4인 앞 적과 HP 20인 뒤 적을 배치한다.
2. 연발 사격을 실행한다.
3. 앞 적은 2발로 사망하고 뒤 적은 남은 3발로 HP 20→14가 된다.
4. 화면에서는 전체 전투 정산과 HP 갱신이 즉시 끝난 뒤 탄환 비행만 순차 재생되어, 뒤 적의 피격 반응이 탄환 도착과 동기화되지 않는다.

## 4. 원인 분석 (Root Cause)

- `CombatManager._fire_full_auto()`는 결정론 보존을 위해 한 프레임 안에서 모든 탄을 동기 정산한다.
- 각 탄마다 최근접 생존 적을 다시 조회하므로 오버킬 이월 자체는 정상이다.
- `enemy_damaged` 신호가 정산 즉시 발생해 HP 바와 피해 텍스트를 최종 상태로 먼저 갱신한다.
- 반면 `bullet_fired` 연출은 UI 큐에서 발당 0.18초 간격으로 나중에 재생한다.
- `bullet_fired` 신호에 실제 피격 대상이 포함되지 않아, UI가 신호 수신 시점의 `combat_manager.enemy`를 추측해 표적 스냅샷을 만드는 추가 불일치도 있다. 특히 처치탄은 대상이 이미 사망했으므로 다음 적을 가리킬 수 있다.

## 5. 해결 방안 (Resolution)

- `bullet_fired` 이벤트에 실제 `target`과 정산 직후 잔여 HP/배리어를 포함했다.
- 각 큐 항목이 실제 표적 위치·대상·HP를 보존하고, 탄환 도착 시 HP 바·피해 숫자·피격 파티클을 함께 재생하도록 변경했다.
- 주 사격 대상은 탄착 큐가 표시하고, 과관통·관통 다중타 보조 대상은 기존처럼 즉시 표시하도록 구분해 보조 피해 UI 누락을 막았다.
- 전투 판정은 기존 동기 처리를 유지했다.

## 6. 검증 내용 (Verification)

- `suite_fire_mode`:
  - 발별 대상 `[앞, 앞, 뒤, 뒤, 뒤]`
  - 잔여 HP `[2, 0, 18, 16, 14]`
- `suite_ui_smoke`:
  - 주 대상 HP가 탄환 도착 전에 선갱신되지 않음
  - 과관통·관통 보조 피해는 즉시 갱신
- 전체 자동 테스트 **2,553 통과 / 0 실패**, 전 스크립트 컴파일 및 4개 씬 로드 성공.
