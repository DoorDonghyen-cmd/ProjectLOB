# 🐛 [버그 리포트] #010. 태세 사냥꾼 파훼가 2발 주기 오메가에 발동하지 않음

## 1. 개요 (Overview)
*   **제보 일시**: 2026-07-27
*   **상태**: `Closed`
*   **중요도**: `높음`
*   **관련 컴포넌트**: 총기 시그니처, 태세 전환, 실험체 Ω

## 2. 현상 설명 (Description)
*   태세 사냥꾼은 적이 태세를 바꾸는 격발에 명중·관통 게이트를 우회하는 총기다.
*   현재 구현은 `target.shot_counter == 2`를 고정 조건으로 사용한다.
*   3발 주기 적에게는 발동하지만, `stance_shift_interval=2`인 실험체 Ω는 카운터가 0→1에서 전환하므로 2에 도달하지 않아 파훼가 영원히 발동하지 않는다.

## 3. 재현 경로 (Steps to Reproduce)
1. 태세 사냥꾼으로 실험체 Ω 전투를 시작한다.
2. 오메가의 `stance_shift_interval=2`와 현재 `shot_counter`를 관찰한다.
3. 두 번째 격발에서 태세는 전환되지만 태세 사냥꾼의 게이트 우회가 발동하지 않는 것을 확인한다.

## 4. 원인 분석 (Root Cause)
*   시그니처 조건이 적 데이터의 `stance_shift_interval`을 읽지 않고 3발 주기의 전환 직전 값 `2`를 하드코딩했다.

## 5. 해결 방안 (Resolution)
*   조건을 `target.shot_counter + 1 >= target.stance_shift_interval`로 교체한다.
*   3발 주기 방패병과 2발 주기 오메가 양쪽의 전환 격발에서 파훼가 발동하는 회귀를 추가한다.

## 6. 검증 내용 (Verification)
*   전환 직전 카운터를 적의 실제 `stance_shift_interval`과 비교하도록 수정했다.
*   2발 주기 실험체 Ω와 3발 주기 방패병 모두 전환 격발에서 태세 사냥꾼의 게이트 우회가 발동하는 회귀를 추가했다.
*   2026-07-27 Godot 4.7 전체 자동 검증 **2,288 통과 / 0 실패**로 종결했다.
