# 🐛 [버그 리포트] #003. 리듬 챔버 6발 연발 보너스 +20 폭증

## 1. 개요 (Overview)

- **제보 일시**: 2026-07-24
- **상태**: `Closed`
- **중요도**: `보통`
- **관련 컴포넌트**: Tempo 기관단총, 리듬 챔버, 핵심 전투 로직

## 2. 현상 설명 (Description)

- 리듬 챔버가 Tempo의 기본 내장 파츠인 상태에서 6발 연발 시 연속 보너스가 `+2+3+4+5+6`으로 누적되어 총 +20 피해를 자동 생성했다.
- 탄환 조합과 무관한 기본 파츠 보너스가 연발 총기의 덱빌딩 정체성과 목표 피해량을 압도했다.

## 3. 재현 경로 (Steps to Reproduce)

1. 기본 리듬 챔버가 장착된 Tempo 기관단총을 선택한다.
2. 동일 클래스 탄환 6발을 장전한다.
3. 전탄 연발을 실행하면 리듬 보너스가 총 +20까지 누적된다.

## 4. 원인 분석 (Root Cause)

- 단발 운용을 전제로 만든 연속 클래스 누적 공식이 6발 전탄 연발 계약과 결합되었다.
- 리듬 챔버가 기본 내장이라 플레이어의 선택 비용 없이 매 연발마다 폭증이 발생했다.

## 5. 해결 방안 (Resolution)

- Tempo의 기본 내장 파츠에서 리듬 챔버를 제거하고 파츠 용량을 3으로 조정해 자유 슬롯 3칸을 유지했다.
- 선택 장착한 리듬 챔버는 동일 클래스 2·4·6번째 격발에만 +1을 부여하도록 변경해 6발 총 보너스를 +3으로 제한했다.

## 6. 검증 내용 (Verification)

- `suite_fire_mode`에서 리듬 챔버 미장착 기본 계약과 선택 장착 시 6발 총 +3 상한을 각각 검증했다.
- Godot 전체 자동 검증 결과: **2,436 통과 / 0 실패**.
