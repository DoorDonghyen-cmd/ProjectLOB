# VIS-02: 가까운 적 거리 라벨의 몸체 중첩

2026-09-12 / Verified / 보통 / prototype/core-redesign 범위.

## 재현
개발자 다수전 표적 전환 연습의 A16m/B17m에서 A 아래에 표시한 거리 글자가 B의 몸체와 겹쳤다. 56px 세로 줄 간격에서 거리 기준선이 적 중심+42였고 다음 적 몸체는 중심+34부터 시작했다.

## 수정
거리 글자를 적 옆, 중심+24 높이로 이동했다. 오른쪽 공간이 부족하면 왼쪽에 배치하고 실제 거리/적 위치는 유지한다.

## 검증
집중129/0 및 최종 16m 동일 거리3적/960x600 캡처에서 거리 글자와 몸체의 겹침이 해소됨을 직접 확인했다. 독립 화면 검토 원본과 최종 부록은 docs/qa/reports/multi_target_experience_2026-09-12.md. 최종 캡처 docs/qa/screenshots/multi_target_three_20260912.png, multi_target_small_20260912.png.

수정 전 화면은 개발 중 도구로 열람했고 별도 이미지 파일은 보존하지 않았다. 정지 화면 확인을 시간 연속 연출이나 사람의 이해도 검사로 확대하지 않는다.
