# 🐛 [버그 리포트] #014. 파츠 1개 구매 제한이 리롤 후 초기화됨

## 1. 개요 (Overview)
*   **제보 일시**: 2026-08-05
*   **상태**: `Verified`
*   **중요도**: `높음`
*   **관련 컴포넌트**: 상점, 파츠 경제, 리롤

## 2. 현상 설명 (Description)
*   GDD는 상점당 파츠를 최대 1개만 획득하도록 규정하지만, 파츠 구매 후 주파수를 재요청하면 새 파츠 카드의 구매 제한이 풀린다.
*   2026-08-05 실전 로그에서 첫 상점 한 곳에서 리듬 챔버, 관성 격발, 연동 조준 3개를 연속 구매·장착했다.

## 3. 재현 경로 (Steps to Reproduce)
1. 첫 상점에서 리듬 챔버 또는 인터럽터를 구매한다.
2. 반대 분기가 폐쇄된 것을 확인한다.
3. 주파수 재요청을 실행한다.
4. 새 파츠 두 장이 다시 구매 가능한 상태로 생성되는지 확인한다.
5. 같은 상점에서 두 번째 파츠를 구매한다.

## 4. 원인 분석 (Root Cause)
*   구매 직후 `_mark_shop_offer_sold()`는 현재 `_shop_items`의 배타 그룹만 품절 처리한다.
*   리롤의 `_generate_shop_items()`가 `_shop_items`를 전부 비운 뒤 새 딕셔너리를 생성하므로 구매 완료 상태가 유지되지 않는다.
*   상점 세션 단위의 `part_purchased` 상태가 없다.

## 5. 해결 방안 (Resolution)
*   상점 진입부터 이탈까지 유지되는 `_part_purchased_this_visit` 플래그를 추가했다.
*   파츠 구매 시 방문 플래그를 기록하고, 이후 리롤로 생성된 모든 파츠 카드를 `이번 상점 파츠 구매 완료` 상태로 잠근다. 전술탄 카드는 계속 구매할 수 있다.
*   UI 상태와 무관하게 구매 콜백에서도 방문 플래그를 다시 검사해 직접 호출 우회를 막았다.

## 6. 검증 내용 (Verification)
*   실전 로그에서 첫 상점 구매 3회, 리롤 4회, 파츠 지출 90Cr이 확인됐다.
*   구매 → 리롤 → 새 파츠 두 장 잠금, 전술탄 구매 가능 유지, 잠금 사유 표시를 `suite_part_shop`으로 회귀 고정했다.
*   Godot 4.7 전체 자동 검증 **2,734 통과 / 0 실패 / 기존 경보 3**.
*   81개 스크립트 컴파일 및 4개 씬 로드 성공.
