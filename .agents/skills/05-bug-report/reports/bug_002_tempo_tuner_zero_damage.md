# 🐛 [버그 리포트] #002. Tempo 조율탄 피해 0으로 셋업 효과 미발동

## 1. 개요 (Overview)

- **제보 일시**: 2026-07-24
- **상태**: `Closed`
- **중요도**: `보통`
- **관련 컴포넌트**: Tempo 기관단총, 탄환 데이터, 핵심 전투 로직

## 2. 현상 설명 (Description)

- 조율탄의 원본 피해가 1인 상태에서 Tempo의 피해 −1 패시브가 적용되면 최종 피해가 0이 되었다.
- 셋업 효과는 유효 피해가 발생한 경우에만 적용되므로, 조율탄 다음 과부하탄의 명중 보정이 발동하지 않았다.

## 3. 재현 경로 (Steps to Reproduce)

1. Tempo 기관단총을 장착한다.
2. 조율탄 다음에 과부하탄이 발사되도록 LIFO 스택을 구성한다.
3. 연발 사격을 실행하면 조율탄의 최종 피해가 0이 되고 셋업 버프가 생성되지 않는다.

## 4. 원인 분석 (Root Cause)

- 탄환 원본 수치가 총기의 고정 피해 패시브와 결합된 이후의 유효 피해 조건을 고려하지 않았다.
- 셋업탄이 피해 0이 되면서 `damage > 0` 조건에 묶인 후속 명중 버프도 함께 차단되었다.

## 5. 해결 방안 (Resolution)

- 조율탄 피해를 1에서 2로 상향해 Tempo 적용 후 피해 1을 보장했다.
- 과부하탄 피해를 6에서 5로 낮춰 Tempo 적용 후 피해 4로 조정했다.
- 조율탄·과부하탄 3쌍의 총 피해는 기존 목표와 동일한 15로 유지했다.

## 6. 검증 내용 (Verification)

- `suite_fire_mode`에서 6발 전탄 소비, 조율→과부하 셋업 적용, 총 피해 15, 잔여 버프 0을 검증했다.
- Godot 전체 자동 검증 결과: **2,436 통과 / 0 실패**.
