# 🐛 [버그 리포트] #013. 기본탄만 사용하면 탄약 효율이 무조건 S등급으로 정산됨

## 1. 개요 (Overview)
*   **제보 일시**: 2026-08-05
*   **상태**: `Verified`
*   **중요도**: `높음`
*   **관련 컴포넌트**: 전투 정산, 크레딧 경제, 플레이테스트 로그

## 2. 현상 설명 (Description)
*   기본 보급탄만 사용한 전투는 실제 격발 수와 무관하게 탄약 효율이 100%로 계산되어 S등급 50Cr을 받는다.
*   보상에서 크레딧 카드를 선택하면 선택 보상 50Cr과 기본 정산 50Cr이 함께 지급되어 전투당 100Cr을 얻는다.
*   2026-08-05 실전 로그에서 첫 3전투 후 첫 상점 도착 크레딧이 300Cr로 확인됐다.

## 3. 재현 경로 (Steps to Reproduce)
1. Workhorse로 전투에 진입한다.
2. 전투 중 추가 납탄 없이 기본 보급탄만 격발해 승리한다.
3. 실제로는 3~7발을 사용했어도 탄약 효율 100%, S등급으로 정산되는지 확인한다.
4. 크레딧 카드를 선택하면 총 100Cr이 지급되는지 확인한다.

## 4. 원인 분석 (Root Cause)
*   `CombatOverlayV2._present_encounter_won()`이 실제 격발 수 대신 `battle_stats.lead_bullets_fired`를 분모로 사용한다.
*   `lead_bullets_fired`는 이름과 달리 `request_insert_bullet()`에서만 증가하는 **전투 중 추가 납탄 횟수**다.
*   기본탄만 사용하면 값이 0이라 효율 계산을 건너뛰고 초기값 100을 그대로 사용한다.

## 5. 해결 방안 (Resolution)
*   실제 발사체가 탄창에서 빠지는 시점마다 증가하는 `battle_stats.shots_fired`를 추가했다. 기본 보급탄·전술탄·연발을 같은 기준으로 센다.
*   전투 보상 계산을 `combat_reward_for_stats(total_kills, shots_fired)`로 분리해 UI와 테스트가 동일한 등급 정본을 사용한다.
*   `lead_bullets_fired`는 전투 중 추가 납탄과 Tempo 해금 판정 전용으로 유지해 의미를 분리했다.

## 6. 검증 내용 (Verification)
*   수정 전 실전 로그 기준 첫 3전투는 5/3/7발을 사용했지만 모두 최대 100Cr을 지급해 첫 상점에서 300Cr을 보유했다.
*   기본탄 2발 실제 격발 집계, `2처치/5발=40%·C등급·10Cr`, 0발 S등급 폴백 방지를 `suite_combat_rewards`로 회귀 고정했다.
*   Godot 4.7 전체 자동 검증 **2,734 통과 / 0 실패 / 기존 경보 3**.
*   81개 스크립트 컴파일 및 4개 씬 로드 성공.
