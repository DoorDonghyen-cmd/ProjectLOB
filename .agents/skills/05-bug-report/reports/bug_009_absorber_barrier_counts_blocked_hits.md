# 🐛 [버그 리포트] #009. 흡수체 배리어가 관통 실패 명중에도 감소함

## 1. 개요 (Overview)
*   **제보 일시**: 2026-07-27
*   **상태**: `Closed`
*   **중요도**: `높음`
*   **관련 컴포넌트**: 전투 대미지 적용, 흡수체·세라프·L.O.B 배리어

## 2. 현상 설명 (Description)
*   문서와 테스트 명칭은 스택 스펀지 배리어가 `유효 적중`에만 감소한다고 정의한다.
*   실제 `_apply_damage_to_enemy()`는 전달된 피해가 `0`이어도 배리어 셀을 1 감소시킨다.
*   그 결과 ACC만 통과하고 PEN이 막힌 탄도 흡수체를 3회 만에 처치할 수 있다.
*   v5 LIFO 역사 기준에서도 흡수체가 `총 피해 0`인데 사망하는 결과가 기록되어 있다.

## 3. 재현 경로 (Steps to Reproduce)
1. DEF 4 흡수체에게 ACC는 통과하지만 PEN 3 이하인 탄을 발사한다.
2. `DamageCalculator` 결과가 0임을 확인한다.
3. `EnemyInstance.barrier_cells`가 1 감소하는 것을 확인한다.
4. 같은 조건을 3회 반복하면 총 피해 0으로 흡수체가 사망한다.

## 4. 원인 분석 (Root Cause)
*   `CombatManager._apply_damage_to_enemy()`의 스택 스펀지 분기가 `dmg_amount > 0`을 확인하지 않고 셀을 차감한다.

## 5. 해결 방안 (Resolution)
*   배리어 차감 조건을 `dmg_amount > 0`으로 제한한다.
*   일반 흡수체·세라프·L.O.B 페이즈 1에 대해 도탄 명중과 유효 적중 대조 회귀를 추가한다.
*   v5 역사 기준선은 수정 전 결과로 보존하고, 현행 회귀 비교에서 의도된 계약 변경을 별도 처리한다.

## 6. 검증 내용 (Verification)
*   피해 0인 관통 실패 명중에서는 배리어 셀이 유지되고, 피해가 발생한 유효 적중에서만 1칸 감소하도록 수정했다.
*   일반 흡수체와 보스 배리어의 도탄·유효 적중 대조 회귀를 추가했다.
*   2026-07-27 Godot 4.7 전체 자동 검증 **2,288 통과 / 0 실패**로 종결했다.
