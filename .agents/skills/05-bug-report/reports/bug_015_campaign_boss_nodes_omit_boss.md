# 🐛 [버그 리포트] #015. 캠페인 보스 노드에 실제 보스가 등장하지 않음

## 1. 개요 (Overview)
*   **제보 일시**: 2026-08-05
*   **상태**: `Verified`
*   **중요도**: `높음`
*   **관련 컴포넌트**: 캠페인 라우팅, 보스 전투, 계층 진행

## 2. 현상 설명 (Description)
*   개발자 테스트 숏컷에서는 보스 4종이 정상 편성되지만, 실제 35층 캠페인의 보스 노드에서는 일반 적 호위 편성만 전달되고 보스 리소스가 포함되지 않는다.
*   계층별 최종 노드를 클리어하면 보스 기믹을 경험하지 않은 채 다음 계층으로 진행할 수 있다.
*   현재 계층은 5개지만 보스 리소스는 4종이고, 상승 브리핑은 "보스 5체"로 표시하여 콘텐츠 구조 결정도 함께 필요하다.

## 3. 재현 경로 (Steps to Reproduce)
1. 일반 런을 시작해 계층의 최종 `보스` 노드에 진입한다.
2. 생성된 `enemy_list`를 확인하거나 전투를 플레이한다.
3. 해당 계층의 실제 보스 리소스 없이 일반 적 편성만 등장하는 것을 확인한다.

## 4. 원인 분석 (Root Cause)
*   `combat_scene.gd`의 캠페인 보스 분기는 계층별 호위 `enemy_list`만 구성하고 `_boss_director`, `_boss_seraph`, `_boss_omega`, `_boss_lob_core`를 배열에 추가하지 않는다.
*   기존 테스트는 맵에 보스 노드가 존재하는지와 보스 기믹의 독립 실행만 검사하고, 캠페인 라우팅 결과에 보스 리소스가 포함되는지는 검사하지 않는다.

## 5. 해결 방안 (Resolution)
*   5계층을 **보스 4체 + 관리 계층 정예 관문 1개**로 확정했다.
*   `CampaignContent`에 계층별 관문 편성을 단일 정본으로 만들고 실제 캠페인 진입과 개발자 보스 테스트가 같은 데이터를 사용하도록 연결했다.
*   A/B/C/E 관문에는 각각 디렉터·세라프·오메가·L.O.B 코어를 포함하고, D 관문은 보스가 아닌 흡수체·돌격병·신경술사 정예 편성으로 고정했다.
*   지도·계층 선택·관문 보상 판정도 보스와 정예 관문을 함께 인식하도록 갱신했다.

## 6. 검증 내용 (Verification)
*   `suite_campaign_integrity`에서 A/B/C/E 관문의 실제 보스 포함, 계층당 보스 수, D 정예 편성, 정예 관문 2 TDC 보상을 회귀 고정했다.
*   Godot 4.7 전체 자동 검증 **2,718 통과 / 0 실패 / 기존 경보 3**.
*   80개 스크립트 컴파일 및 4개 씬 로드 성공.
