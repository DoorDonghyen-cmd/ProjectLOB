# 🐛 [버그 리포트] #012. 상점 주파수 재요청 후 가운데 파츠의 이전 설명 잔존

## 1. 개요 (Overview)
*   **제보 일시**: 2026-08-05
*   **상태**: `Verified`
*   **중요도**: `보통`
*   **관련 컴포넌트**: 상점 UI, 주파수 재요청(리롤), 파츠 진열 카드

## 2. 현상 설명 (Description)
*   상점에서 `주파수 재요청`을 실행해 가운데 파츠 후보가 변경되어도 이전 파츠의 설명이 진열대에 남아 보일 수 있다.
*   상품 추첨 데이터와 파츠 리소스 설명문은 정상적으로 변경되며, 결함은 진열 카드 교체 시점에 한정된다.

## 3. 재현 경로 (Steps to Reproduce)
1. 상점 노드에 진입해 가운데 파츠 카드의 설명을 확인한다.
2. `주파수 재요청`을 실행한다.
3. 새 가운데 파츠 카드가 생성된 직후 진열 컨테이너에 구 카드와 새 카드가 함께 존재하고, 이전 설명도 남아 있는 것을 확인한다.

## 4. 원인 분석 (Root Cause)
*   `MaintenanceOverlay._refresh_shop_tab()`이 기존 카드에 `queue_free()`만 호출했다.
*   Godot의 `queue_free()`는 삭제를 프레임 끝으로 예약하므로, 현재 프레임 동안 기존 카드가 `_shop_grid`의 자식으로 유지된 상태에서 새 카드가 추가됐다.
*   그 결과 리롤 직후 구·신 카드가 겹치며 이전 가운데 파츠 설명이 잔존할 수 있었다.

## 5. 해결 방안 (Resolution)
*   기존 카드를 삭제 예약하기 전에 `_shop_grid.remove_child(child)`로 진열 컨테이너에서 즉시 분리했다.
*   이후 `queue_free()`를 사용해 노드 수명은 안전하게 정리한다.
*   UI 스모크 테스트에 리롤 전후의 가운데 파츠 설명을 직접 렌더링해 다음을 고정했다.
    * 진열 카드 수가 현재 상품 수와 즉시 일치한다.
    * 새 설명이 표시된다.
    * 이전 설명이 진열대에 남지 않는다.

## 6. 검증 내용 (Verification)
*   Godot 4.7 헤드리스 전체 회귀 테스트: **2,654 통과 / 0 실패 / 기존 경보 3**.
*   신규 상점 UI 회귀 3건을 포함해 스크립트 컴파일, 씬 로드 및 기존 게임 흐름 검증을 모두 통과했다.
*   실제 모바일 화면에서의 최종 체감 확인 후 `Closed`로 전환한다.
