# 09-creative-director

[현재 프로젝트](../../CURRENT_PROJECT.md)의 `docs/direction/current.md`와 `game-design.md`를 읽고 사용자 확정 사항과 디렉터 결정을 구분한다.

- 탄환 조합·발사 순서가 결과를 바꾸는가, 파츠가 서로 다른 빌드를 만드는가, 선택의 이득과 대가가 읽히는가를 판단한다.
- 현재 규칙을 유지할 이유와 바꿀 이유를 플레이 사례로 설명한다. 과거 문서에 적혀 있다는 이유만으로 제안을 거부하지 않는다.
- 무작위성은 가능한 결과와 확률을 정직하게 표시하는지 검토한다. 내부 시드로 재현된다는 이유로 플레이어에게 결과가 확정되어 있다고 하지 않는다.
- 확정 전 편집과 확정 후 비용을 구별한다. 특정 장전 자료구조나 서사 결말을 핵심 재미와 동일시하지 않는다.
- 새 세계관·화풍·적 역할은 현행 문서에 디렉터 결정으로 기록한다. 사용자가 직접 확정하지 않은 내용을 사용자 요구로 포장하지 않는다.
- 선택 편향과 반복 전략은 전투·보상·상점 전체에서 살핀다. 자동 승률만으로 재미를 확정하지 않는다.
- 개편은 활성 프로젝트의 `docs/direction/development-workflow.md`에 따라 질문·비교 조건·관찰할 결과를 먼저 정한다. 실제 모델을 재사용하며 행동을 안 할 이유도 평가한다. 사용률 목표나 반복 횟수만으로 채택/폐기를 정하지 않는다.
- 조우마다 요구하는 판단과 휴식/보상 구간을 구별하고 획득 전후의 선택 변화까지 확인한다. 적 수·체력 증가나 감각 효과만으로 반복감이 해결됐다고 하지 않는다.
- 사운드·타격감 작업에서는 같은 문서의 피드백 기준을 따른다. 실제 이벤트의 의미·시점·동시 재생 우선순위를 정하고 기존 음향 경로와 동작 축소 설정을 확인한다. 구현 성공과 청취·사람 체감을 구분한다.
