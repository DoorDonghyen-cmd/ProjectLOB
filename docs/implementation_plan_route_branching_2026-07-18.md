# 통로 분기 구조 개편 — 구현 계획

> 날짜: 2026-07-18  
> 범위: 런 맵 그래프, 맵 UI, 전투 시작 거리, GDD/로드맵/목업

## 목표

통로를 별도 선택 상품에서 목적지의 가격표로 바꾸고, 비상계단과 환기구만 남긴다. 환기구 비용은 다음 전투 시작 거리 `-2m`로 확정하며 비전투 노드를 지나도 유지한다.

## 구현 항목

1. `RunManager`에 현재 노드와 미소비 환기 압박 상태를 추가한다.
2. 맵 그래프의 통로 종류를 `stairs`, `air_duct`로 한정하고 층 스킵·확률 패널티 분기를 제거한다.
3. 런 시작 시 무기고별 진입 통로를 가변 배치하되 계단/환기구 최소 1개씩을 보장한다.
4. 맵 UI는 현재 노드에서 연결된 목적지만 활성화하고 노드 카드에 통로 비용을 사전 공개한다.
5. 별도 통로 선택 팝업을 제거하고 목적지 클릭 한 번으로 노드와 통로를 확정한다.
6. 환기 압박은 다음 전투 생성 시 거리 보정에 한 번 적용하고 소비한다.
7. 통로 기반 TDC 보상을 제거하고 관련 GDD, 로드맵, UI 목업을 동기화한다.

## 검증 계획

* 런타임 경로 문자열이 `stairs`, `air_duct` 두 종류뿐인지 검색한다.
* 환기 상태가 비전투 이동에서 소모되지 않고 전투 시작에서만 소비되는지 호출 경로를 확인한다.
* 현재 노드 연결선 외의 같은 층 노드가 비활성화되는지 UI 조건을 확인한다.
* 목업 JavaScript 구문을 Node.js로 검사한다.
* Godot 실행 파일이 있으면 헤드리스 파싱과 씬 스모크 테스트를 수행한다.
