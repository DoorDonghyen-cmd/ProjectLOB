# 고정 전열·탄 순서·파츠 빌드·상점 UX 개편 워크스루

## 바뀐 플레이 경험

적은 교전 동안 네 개 전열 중 자기 레인을 유지한다. 앞의 적을 처치하거나 후속 증원이 들어와도 남아 있는 적이 위아래로 순간 이동하지 않는다. 증원은 비어 있는 레인에만 배치되며 배치된 행동에는 전진하지 않는다.

전장은 HP만 읽는 화면에서 전술 판단 화면으로 바뀌었다. 적 실루엣 옆에 HP와 예상 HP, 장갑, 배리어, 전기 약점, 화상, 충전, 접근 위험을 함께 보여 준다. 전도 선체의 `⚡ +2` 표시는 전격탄의 직접 우위를 전투 중에 확인할 수 있게 한다.

회수탄의 기본 피해는 4에서 2로 낮아졌다. 보행자는 회수탄 +1, 전술탄 +2를 받아 입문 무기로서 모든 전술 조합을 시험하기 좋지만 회수탄만 반복하는 해법은 약해졌다. 장갑에는 철갑, 전기 약점과 다수전에는 전격, 장기 접근에는 소이, 빠른 적에는 충격, 처치선 조절에는 증폭 뒤 연발이 우세하다.

## 파츠와 상점

파츠 풀은 다음 8종이다.

| 파츠 | 핵심 변화 | 주 용도 |
|---|---:|---|
| 가속 총열 | 관통 +2 | 장갑 파훼 |
| 회수 가속기 | 재장전 −1턴 | 긴 재장전 보완 |
| 확장 탄창 | 탄창·회수탄 +1 | 긴 연쇄 |
| 열축전 코일 | 화상 +1 | 소이 빌드 |
| 전이 축전기 | 전이 피해 +1 | 전격 다수전 |
| 충격 가이드 | 밀치기·한도 +1m | 거리 제어 |
| 증폭 시퀀서 | 증폭 피해 +1 | 증폭 후속 조합 |
| 복열 노리쇠 | 연발 타격 +1 | 적중·집중 조합 |

상점은 현재 무기, 장착 파츠, 덱 성향을 상단에 먼저 보여 준다. 파츠 후보는 아이콘, 핵심 수치, 빌드 역할과 교체 결과를 카드로 표시한다. 현재 무기에 효과가 없는 후보는 제외하며, 런에서 아직 보지 못한 후보가 우선 나온다. 모든 후보를 본 뒤에만 반복이 허용된다.

구매한 파츠는 즉시 장착된다. 덱·장비 보관함에서는 보유 파츠를 아이콘 카드로 비교하고 전투 사이에 무료로 교체하거나 분해할 수 있다.

## 확인 경로

- Godot 프로젝트: `새-게임-프로젝트/project.godot`
- 개발자 메뉴의 `다수전`에서 고정 레인, 증원, 약점 표기를 확인한다.
- 개발자 메뉴의 `덱·장비`에서 장착 파츠와 보유 파츠 교체를 확인한다.
- 개발자 메뉴의 `파츠 아이콘`에서 8종 아이콘을 한 번에 비교한다.
- 일반 캠페인의 상점에서 미확인 후보 우선 진열과 구매 즉시 장착을 확인한다.
