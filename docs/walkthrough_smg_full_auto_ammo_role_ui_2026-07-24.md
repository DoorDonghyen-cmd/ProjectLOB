# Phase 12 ④ 워크스루 — 기관단총 연발 전환과 탄환 역할 UI

> 완료일: 2026-07-24

## 결과

전술 기관단총이 6발 시퀀스를 한 턴에 커밋하는 연발 총으로 전환되었다. 도박형은 블라인드 스택 관리 정체성을 위해 단발로 남았고, 더블탭은 코드·UI·개발자 숏컷에서 제거했다.

탄환 27종은 이제 리소스 자체에 역할 메타데이터를 가지며, 드래프트부터 장전·전투·갤러리까지 `[독립]`·`[셋업]`·`[페이로드]`·`[유틸]` 배지를 같은 색과 도움말로 표시한다.

## 핵심 수정

### 전술 기관단총

| 항목 | 이전 | 현재 |
|---|---:|---:|
| 발사 방식 | `single` | `full_auto` |
| 리로드 | 2턴 | 3턴 |
| 예고창 | 2 | 6 |
| 파츠 슬롯 | 4(기본 파츠 1칸 점유) | 3(기본 파츠 없음) |
| 더블탭 | 존재 | 제거 |

기본 6발은 `(3−1)×6 / 4턴 = 3.00 DMG/턴`이다.

### 셋업 체인 정합

기존 조율탄 DMG1은 Tempo의 DMG −1 이후 피해 0이라 `damage > 0` 유효 적중 조건을 통과하지 못했다.

- 조율탄: DMG 1→2, Tempo 적용 후 1피해와 ACC 버프
- 과부하탄: DMG 6→5, Tempo 적용 후 4피해
- `조율→과부하` 3쌍: `(1+4)×3 = 15`, 4턴 기준 3.75 DMG/턴

총 피해는 계획값을 유지하면서 실제 버프 발동 조건을 만족한다.

### 리듬 챔버 폭증 차단

구 공식은 같은 클래스를 6발 연속 발사하면 `+2+3+4+5+6 = +20 DMG`를 자동으로 만들었다. Tempo 기본 내장에서 제거하고, 선택 장착 효과를 2·4·6번째 격발의 +1씩 총 +3으로 제한했다.

### 역할 UI

- `BulletRoleUI`가 역할 표기·색·도움말을 중앙 관리
- 드래프트·교체·가방·스택·실린더·갤러리에서 공통 배지 사용
- 상단 2발이 셋업→페이로드면 `⇢ 연계`
- 적재 화면에 LIFO 안내:
  - “페이로드를 먼저 넣고 셋업을 나중에 넣으면 셋업이 먼저 발사됩니다.”
- 3번째 깊이부터는 기존 정보 은폐 유지
