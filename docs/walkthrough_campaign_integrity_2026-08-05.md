# 캠페인 무결성 — 보스 연결·보상 풀 정상화 워크스루

## 목표

- 실제 35층 캠페인에서 기존 보스 콘텐츠가 계층 관문에 등장하도록 연결한다.
- 스타팅 보너스와 암시장이 정식 아이템 규칙을 우회하지 않도록 획득 후보와 결제 흐름을 고정한다.

## 적용 결과

### 1. 5계층 관문 구조

| 계층 | 관문 유형 | 편성 |
| :--- | :--- | :--- |
| A 침전 거주구 | 보스 | 보안 디렉터 |
| B 공역 | 보스 | 돌격병 + 방패병 + 세라프 |
| C 정비 계층 | 보스 | 오메가 |
| D 관리 계층 | 정예 관문 | 흡수체 + 돌격병 + 신경술사 |
| E 정점 | 보스 | 돌격병 + 회피병 + 방패병 + L.O.B 코어 |

- `CampaignContent`가 캠페인과 개발자 테스트가 함께 사용하는 편성 정본이다.
- D는 새 보스를 억지로 추가하지 않고 관리 계층 정예 관문으로 확정했다.
- 보스와 정예 관문 모두 관문 UI 강조 및 2 TDC 보상 판정을 공유한다.

### 2. 획득 후보 정본

- `ItemCatalog`에 현행 일반 파츠 20종과 공용 전술탄 14종을 명시했다.
- 고유 기본 파츠, 비활성 컨버전 킷, 기본 보급탄, 현재 총기 비호환 탄, 보유 중복 파츠는 해당 획득 경로에서 제외된다.
- 스타팅 파츠 보너스는 1티어 일반 파츠만 사용한다.

### 3. 스타팅 보너스와 암시장 안전성

- 준비 화면의 크레딧/파츠 보너스는 즉시 지급하지 않고 대기시킨 뒤 새 런 초기화 완료 후 한 번만 적용한다.
- 암시장은 가방이 가득 차면 구매를 막고, 예상하지 못한 지급 실패가 발생하면 크레딧을 전액 환불한다.

## 회귀 검증

- 신규 `suite_campaign_integrity`로 계층별 편성, 보스 4체, D 정예 관문, 관문 보상, 파츠·탄환 후보, 스타팅 보너스, 암시장 포화/구매 흐름을 고정했다.
- Godot 4.7 전체 자동 검증: **2,718 통과 / 0 실패 / 기존 경보 3**.
- **80개 스크립트 컴파일**, **4개 씬 로드** 성공.

## 수동 확인 권장

- 모바일 실플레이에서 A~E 관문 표기와 실제 적 대열이 위 표와 일치하는지 한 차례 확인한다.
- 스타팅 보너스 팝업에서 크레딧과 파츠를 각각 선택해 준비 화면 이후 실제 런 가방/잔액에 남는지 확인한다.
