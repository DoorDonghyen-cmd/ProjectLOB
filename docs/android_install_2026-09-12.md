# 갤럭시 설치 안내

파일: `LastOnBoard-test.apk` · 앱 이름: **Last on Board Test**

1. APK 파일을 USB 또는 Quick Share로 갤럭시의 다운로드 폴더에 복사합니다.
2. 휴대폰의 **내 파일 → 다운로드**에서 APK를 눌러 설치합니다.
3. 설치 권한을 요청하면 이번에 APK를 여는 앱(내 파일 등)에 대해 허용한 뒤 설치합니다. 설치 후 이 권한은 다시 꺼도 됩니다.
4. 앱 목록에서 **Last on Board Test**를 실행하고 가로로 플레이합니다.

탄환을 누르면 장전됩니다. 상세 수치는 위쪽 `정보` 버튼에서 확인할 수 있습니다. 적을 누르면 그 적의 정보만 열고 자동 조준은 유지합니다.

다수전 확인: **개발자 테스트 → 다수전 표적 전환 연습**. 연습은 일반 진행을 저장하지 않습니다.

진행은 휴대폰의 앱 내부에 자동 저장합니다. 앱 삭제 시 해당 테스트 진행도도 삭제됩니다. PC 저장과는 별개입니다.

설치가 차단되거나 앱이 실행되지 않으면 표시되는 오류 문구를 알려 주세요. 현재 파일은 개인 플레이테스트용이며 실제 갤럭시 기기에서의 실행·발열·성능은 아직 확인하지 않았습니다.
