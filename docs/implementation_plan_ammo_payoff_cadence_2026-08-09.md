# 조합탄 결산 구조·2탄창 전투 호흡 구현 계획

> 상태: 사용자 승인 후 구현·자동 검증 완료 (2026-08-09)
> 범위: 조합탄 선택 다양성 2단계, 결산탄 인지·예고, 전투 호흡 검증
> 선행 작업: `docs/implementation_plan_mobile_scan_unlock_ammo_guidance_2026-08-09.md`

## 1. 목표

- 플레이어가 적 접근 전에 `연계 → 결산 → 제어` 순서로 탄창을 설계하도록 한다.
- 연쇄탄·교대탄을 단순한 `[공격]` 탄환이 아니라 연계를 피해로 환산하는 **결산탄**으로 읽히게 한다.
- 전투 보상에서 이미 익숙한 관통 조합만 반복 선택되는 현상을 줄이고, 보유한 연계탄과 맞물리는 결산탄을 실제로 접하게 한다.
- 일반 혼합 전투에서 첫 탄창으로 전열을 해체하고, 재장전 뒤 두 번째 탄창으로 정리하는 흐름이 가능한지 자동 검증한다.

## 2. 현재 수치 진단과 이번 범위의 경계

### 2.1 신규 피해 버프탄은 추가하지 않는다

현행 공용 공격탄에 이미 피해 결산 기능이 있다.

| 탄환 | 기본 조건부 피해 | Tempo에서 게이트 개방 크리티컬 시 |
| :--- | ---: | ---: |
| 연쇄탄 | `2 + 3 = 5` | `floor(5 × 1.5) = 7` |
| 교대탄 | `2 + 4 = 6` | `floor(6 × 1.5) = 9` |

Tempo의 기본 6발 시퀀스가 16 피해인 점을 고려하면 별도 `DMG 증가 연계탄`을 더하는 것은 전탄 연발·집중 폭발과 중첩되어 지배 조합을 만들 위험이 크다.

### 2.2 이번 구현에서 바꾸지 않는 것

- 탄환 DMG/PEN/ACC와 조건부 보너스 수치
- 적 HP/DEF/EVA/SPD와 시작 거리
- 총기 장탄수·재장전 턴
- 시작 전술탄 패키지
- 파츠 수치와 상점 가격

이번 단계는 **인지·보상 노출·검증 장치**만 구현한다. 실제 수치 조정은 플레이테스트 JSON에서 결산탄 선택률, 발동률, 과잉 피해를 확인한 뒤 진행한다.

## 3. 결산탄 분류와 표시

### 3.1 분류 규칙

- `연쇄탄(chain)`: `[공격] [결산]`
- `교대탄(crosscal)`: `[공격] [결산]`
- 마무리탄은 탄창 끝 위치 보상이라 `연계 → 결산` 교육 대상에서 제외한다.
- CSV 역할 스키마 `attack/link/control`은 유지하고, `결산`은 UI가 조건을 판독해 붙이는 보조 태그로 처리한다.

### 3.2 카드·가방·탄창 표시 와이어프레임

```text
┌────────────────────────────┐
│ 연쇄탄                     │
│ [공격] [결산]              │
│ DMG 2  PEN 1  ACC 6        │
│ 직전 유효 적중 시 피해 +3  │
└────────────────────────────┘
```

좁은 실린더 행도 역할 배지를 없애지 않고 같은 줄에 축약 표시한다.

```text
2  연쇄탄   [공격][결산]
```

## 4. 적재 화면 결산 예고

기존 `AmmoGuidance`의 명중·관통 전환 예고 아래에 조건부 공격탄의 결과를 같은 계산 순서로 붙인다.

```text
┌────────────────────────────────────┐
│ 발사 1  표식탄  [연계][다음 1발]   │
│     ↓                              │
│ 발사 2  연쇄탄  [공격][결산]        │
├────────────────────────────────────┤
│ 연계 예고                          │
│ 표식탄: 명중 전환 1발              │
│ 연쇄탄: 결산 성공 · 예상 주 피해 7 │
│          기본 2 + 결산 3 × 크리티컬 │
└────────────────────────────────────┘
```

### 4.1 계산 범위

- 현재 LIFO 발사 순서와 현재 최근접 적만 사용한다.
- 다음 1발·대상 지속·잔여 탄창의 누적 ACC/PEN을 앞에서부터 반영한다.
- 연쇄탄은 직전 유효 적중, 교대탄은 직전 역할 변경을 판정한다.
- 바로 앞 연계탄이 명중/관통 게이트를 실제로 열었을 때만 결정형 크리티컬을 표시한다.
- 파츠 조건부 정액, 집중 폭발, 후열 관통/확산, 처치 후 재타깃은 계산하지 않는다.
- 따라서 문구는 `예상 주 피해`로 제한하고 전체 전투 피해나 처치 확정으로 표현하지 않는다.

### 4.2 실패 문구

- `결산 실패 · 직전 유효 적중 필요`
- `결산 실패 · 역할 교대 필요`
- `발동 조건 충족 · 현재 대상 도탄 예상`

## 5. 드래프트 후보 다양성

### 5.1 보유 수량 완화 가중치

- 현재 덱의 동일 탄 보유량을 `n`이라 할 때 기본 가중치를 `max(1, 3 - n)`으로 둔다.
- 컨버전 킷 가중치가 다시 활성화될 경우 곱셈이 아니라 별도 우선순위로 합성해 폭증을 막는다.
- 동일 탄을 금지하지 않아 집중 빌드는 계속 선택할 수 있다.

### 5.2 결산탄 첫 노출 보증

- 조건: 덱에 `[연계]` 탄환이 하나 이상 있고 `chain/crosscal`이 하나도 없다.
- 결과: 탄환 보상 2장 중 1장을 `chain/crosscal`에서 제시한다.
- 결산탄을 한 번 획득한 뒤에는 보증을 해제하고 일반 가중 추첨으로 돌아간다.
- 플레이어는 다른 탄환이나 크레딧을 선택할 수 있으므로 강제 획득은 아니다.

```text
전투 보상
┌ 연쇄탄 ─────────┐  ┌ 다른 운용 탄환 ─┐  ┌ 크레딧 ─────┐
│ [공격][결산]    │  │ [연계]/[제어]    │  │ +20 Cr       │
│ 보유 연계와 호응│  │ 보유량 완화 추첨 │  │              │
└─────────────────┘  └──────────────────┘  └──────────────┘
```

## 6. 전투 호흡 검증

### 6.1 목표 호흡

- 입문 단일 적: 1탄창 안팎
- 일반 혼합 편성: 2탄창
- 엘리트 혼합 편성: 2~3탄창
- 보스: 4탄창 이상

전투를 늘리기 위해 HP만 올리지 않는다. 첫 탄창의 올바른 목표는 최근접 고속 적 처치 또는 제어이며, 그 결과로 재장전과 두 번째 적재 판단 시간이 생겨야 한다.

### 6.2 자동 검증 시나리오

- Tempo + `돌격병/방패병/회피병` 혼합 편성
- 첫 탄창에서 전열 고속 적을 정리한 경우 재장전 뒤 두 번째 적재 단계 진입 가능
- 잘못된 순서로 전열을 남긴 경우 긴급 격퇴 소모 또는 패배 위험 발생
- 결산탄 보너스는 주 대상에만 적용되고 소총 후열·산탄 확산으로 복제되지 않음
- 결산 예고와 실제 발사 피해가 같은 규칙을 사용함

이번 단계에서는 위 결과를 **관측·회귀 고정**하되, 실패한다고 적 수치나 거리를 즉시 변경하지 않는다. 실패 편성은 플레이테스트 목록에 남겨 다음 수치 조정 묶음에서 비교한다.

## 10. 완료 기준

- 연쇄탄·교대탄이 모든 주요 탄환 화면에서 `[결산]`으로 식별된다.
- 현재 LIFO 순서에서 결산 성공 여부와 예상 주 피해가 실제 전투 결과와 일치한다.
- 연계탄 보유·결산탄 미보유 상태의 보상에 결산탄이 최소 1장 등장한다.
- 결산탄 보유 뒤에는 하드 보증 없이 보유량 완화 가중치가 적용된다.
- 기존 공격/연계/제어 역할, LIFO, 전탄 연발, 적 재타깃 규칙이 유지된다.
- 탄환·총기·적 수치는 변경되지 않는다.
- 전체 자동 테스트 실패 0건을 유지한다.

## 11. 구현 결과

- 연쇄탄·교대탄을 주요 탄환 UI에서 `[결산]`으로 표시하고, 툴팁에 발동 조건을 추가했다.
- 현재 LIFO 적재 순서에서 결산 성공·실패 사유와 예상 주 피해를 순차 계산해 표시한다.
- 연계탄은 보유했지만 결산탄이 없는 덱에는 첫 결산탄 후보 1장을 보증하고, 이후에는 동일 탄 보유량에 따라 `3 → 2 → 1` 가중치를 적용한다.
- Tempo의 `돌격병 → 회피병 → 방패병` 혼합 편성에서 첫 탄창으로 전열을 해체하고 재장전 뒤 두 번째 적재 단계가 남는 흐름을 회귀 테스트로 고정했다.
- 개발자 메뉴의 `스캔·연계·결산 QA` 바로가기로 해당 상태를 즉시 재현할 수 있다.
- 탄환·총기·적 수치와 시작 패키지는 변경하지 않았다.
- 전체 자동 검증 결과: **2,827 통과 / 0 실패 / 기존 밸런스 경보 3건 유지**.
