# 조합탄 전투 전문축 분리 구현 계획

> 작성일: 2026-08-15
> 사용자 승인: 2026-08-15
> 목표: 공용 전술탄을 `화력 / 관통 / 명중 / 제어`로 즉시 판독하게 하고, LIFO 조합의 역할 경계를 실제 수치와 판정에 일치시킨다.

## 1. 설계 원칙

- 기존 `attack / link / control`은 보상 풀과 효과 발동 범위를 설명하는 **운용 분류**로 유지한다.
- 신규 `damage / penetration / accuracy / control`은 플레이어가 탄환을 고르는 **전투 전문축**으로 사용한다.
- 리듬 챔버·인터럽터·교대탄의 동일/교대 판정은 전문축을 기준으로 바꾼다. 화력→관통→명중의 실제 조합이 운용 교대로 계산되어야 한다.
- 모든 탄은 정산을 위해 DMG/PEN/ACC를 보유하지만, 전문축 이외 스탯은 게이트 전달에 필요한 최소값으로 제한한다.
- 일반 적은 기본탄 또는 화력탄 단독, 단일 전문 적은 셋업 1종+화력탄, 복합 태세·보스는 2축 이상 조합을 요구하는 계층을 유지한다.
- 제어탄은 거리 0 즉사 규칙을 담당하므로 세 공격 스탯에 흡수하지 않는다.

## 2. 전문축과 목표 밴드

| 화력 | 조건 충족 피해 5~7 | PEN 1, ACC 5~6 | 연쇄·마무리·교대 |
| 관통 | PEN 3~4 | DMG 2, ACC 5~6 | 천공·파쇄·정렬·철갑·관통 |
| 명중 | ACC 8~9 | DMG 2, PEN 1 | 표식·교란·유도 |
| 제어 | KB/Slow 2 | DMG 2, PEN 1 | 선제·충격·점착 |

## 3. UI 와이어프레임

드래프트·가방·실린더·적재 카드의 첫 배지는 전문축으로 통일한다.

```text
┌ 표식탄 ─────────────┐
│ [명중]  [다음 1발]  │
│ DMG 2  PEN 1  ACC 9 │
│ 운용: 연계           │
│ 다음 탄 ACC +3       │
└──────────────────────┘

┌ 연쇄탄 ─────────────┐
│ [화력]  [결산]       │
│ DMG 2  PEN 1  ACC 5 │
│ 운용: 공격           │
│ 성공 시 예상 피해 5 │
└──────────────────────┘
```

- 전문축 색상: 화력=적색, 관통=청색, 명중=황색, 제어=청록.
- 기존 `[결산]`, `[다음 1발]`, `[대상 지속]`, `[잔여 탄창]`은 보조 배지로 유지한다.
- 툴팁 첫 줄은 전문축 설명, 두 번째 줄은 기존 운용 분류를 표시한다.
- 개발자 테스트 메뉴에 네 전문축과 LIFO 교대 판정을 즉시 확인하는 전용 QA 진입점을 둔다.

## 4. 검증 계약

1. CSV와 19개 `.tres`의 `specialty`가 완전히 일치한다.
2. 공용 전술탄 전문축 분포는 화력 3 / 관통 5 / 명중 3 / 제어 3이다.
3. 전문축 판정으로 `명중→관통→화력`은 두 번의 역할 교대로 계산된다.
4. 같은 전문축 반복은 리듬 챔버, 전문축 교대는 인터럽터·교대탄을 발동한다.
5. 9총기×13적 기본/환기구 거리에서 시작 패키지의 첫 탄창 유효 대응 해법이 하나 이상 있어야 한다.
6. Tempo·Suppressor 연발, 결정형 크리티컬, 영구 소실, 후열 관통·확산의 기존 계약을 보존한다.
7. 기존 전체 회귀 테스트 실패 0을 유지한다.

## 5. 중단 조건

- 전문축 분리 때문에 첫 상점 전 특정 총기·일반 적 조합의 해법이 0이 되면 수치를 확정하지 않는다.
- 모든 전투가 명중→관통→화력 3단계로 고정되면 일반 적 게이트 또는 시작 패키지를 재조정한다.
- DMR 범용성은 전술탄 전문축과 별개로 기록하고, 이번 변경에 기본탄·총기 시그니처 너프를 섞지 않는다.

## 6. 구현 결과

- `BulletData.specialty`와 CSV `specialty` 열을 추가하고 19종 리소스를 동기화했다.
- 카드·툴팁·갤러리·가방·실린더·드래프트의 첫 배지를 화력/관통/명중/제어로 통일했다.
- 교대탄·인터럽터·만능 약실·리듬 챔버 판정을 운용 분류가 아닌 전문축 기준으로 전환했다.
- 시작 패키지는 권총 `천공+연쇄`, SMG `표식+천공`, 소총 `천공+연쇄`,
  DMR `천공+연쇄`, 산탄 `파쇄+충격`으로 확정했다.
- 개발자 메뉴에 `탄환 전문축 QA` 진입점을 추가했다.
- 자동 검증: **3,424 통과 / 0 실패 / 기존 경보 3**.
