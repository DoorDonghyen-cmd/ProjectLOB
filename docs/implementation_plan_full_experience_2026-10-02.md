# 전체 플레이 경험 제작

사용자 위임: 앞서 제안한 전체 화면·조합 피드백·아트·검증·지역 확장을 진행한다. 기존 미커밋 작업을 보존하며 실제 Godot 실행 결과로 검토한다.

1. 회수자·작업실·도시 지도·지역 배경 자산을 제작하고 프로젝트에 적용한다.
2. 메인·총기 선택·지도·상점·장비·보상·결과의 시각 위계와 주 행동을 연결한다.
3. 무기·적을 구별되는 기계 형태로 제작하고 탄환·파츠의 실제 발동 근거를 전투 연출에 연결한다.
4. 다섯 무기의 규칙과 캠페인 선택을 검증하고, 화면 캡처와 실제 입력으로 모바일 비율까지 점검한다.
5. 자산·변경·증거를 기록한다. 인간의 재미 평가와 실제 Android 검수는 자동 검사 결과와 구분한다.

범위: 현행 35층·5종 무기·파츠·압축·저장 시스템을 바탕으로 전체 게임 경험을 제작한다. 수치 변경은 선택 다양성의 근거가 있을 때만 적용한다. 배경 원화와 네이티브 UI·벡터 장비/적을 함께 사용하며, 활자와 수치는 이미지에 넣지 않는다.

실행 결과: [전체 경험 적용·검증 보고서](qa/reports/full_experience_2026-10-02.md). 위 1~5의 구현·기록을 적용했다. 실제 Android 및 사람의 이해도 검증, 프레임 캐릭터 애니메이션·음악/효과음은 별도 범위로 남긴다.
