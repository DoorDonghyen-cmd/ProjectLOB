# 전투 밸런스1차 보정 검증

사용자 승인에 따라 리액터·소이의 중첩 효율과 후반 접근 여유를 보정했다. [현재 결정·적용 조건](../../../direction/combat-balance-pass.md). 비교는 실제 Campaign/Model과 기존 획득·거래·정비 경로를 재사용하며 가짜 승리·부품·재화·덱을 지급하지 않는다.

## 범위와 결과

- **5총기 공통 전후:** 시드17·운반용 복장,10개 완주/300전투.
- **추가 조건:** 리액터·스플린터의 시드731042/정찰 복장 전후4완주/112전투, 리벳의 해당 새 조건1완주/28전투, 리액터 열압 유지 새 조건1완주/30전투.
- **전체:**16개 완주/470전투, 명령·획득·거래·저장/재개의37,505개 검사 실패0. [집계](summary.json), [실제 경로/덱·파츠/행동·경제 원본](runs/), [소스 해시](source_manifest.json).

매 전투의 실제 획득 시작 상태에서 ‘탄이 있으면 최대 사격, 비면 재장전, 탄약 소진이면 가능한 비상 보급’ 정책도 별도로 돌렸다. 이 정책은 탄창 순서 편집·짧은 사격·수동 냉각·미래 정보로 결정을 바꾸지 않는다. 이후 표의 통과 수는 **국소 전투 분기**이며 그 단순 정책으로 전체 도전을 진행한 결과가 아니다.

| 시드17/운반용 | 단순 운용 통과 전→후 | 선택 경로의 경과 적 행동 합계 전→후 | 실제 선택 경로 |
|---|---:|---:|---|
| 리벳 | 26/30→24/30 | 340→340 | 전후 완주 |
| 래칫 | 28/30→27/30 | 366→371 | 전후 완주 |
| 스플린터 | 28/30→27/30 | 386→388 | 전후 완주 |
| 리액터·소이/노심 선호 | 28/30→23/30 | 409→517 | 전후 완주·비상 보급0 |
| 스파이크 | 25/30→24/30 | 339→304 | 전후 완주 |

같은 시작 시드·공개 획득 정책을 사용하지만, 전투에서 획득한 성장/필요 탄·후속 선택은 실제 진행에 따라 달라질 수 있다. 순수한 한 발 피해량만 비교한 표가 아니다. 시드731042 정찰 리액터는 단순 운용27/28→23/28, 경과384→471행동, 비상 보급0→2회였다. 새 규칙 정찰 리벳도 완주했고 비상 보급1회였다. 작은 가방의 부담과 전투 길이는 후속 사람 플레이의 관찰 항목이다.

선택 경로 탐색은 미래 드로/난수를 볼 수 있는 유한 탐색이다. 완주 가능성·명령 정합성 증거이며 사람 승률·최적해·미감/긴장감의 확정이 아니다. 스플린터의 무작위 표적은 같은 시드와 전체 무작위 예측 범위로 검사했으며 모든 시드/모든 복장을 검사하지 않았다.

실제 화면에서 기간/성장/코일 설명과 HUD를 검토했다. 최초 UI 비교는 탐색용으로 과거 이력을 잘라낸 복제본과 전체 이력을 비교해 실패했으며, 완전 복제의 실제 Model 명령으로 비교하도록 검사 픽스처를 수정한 뒤 통과했다. 게임 계산 오류로 처리하지 않았다. 문구 수정 중 파싱 오류도 최종 실행 전에 수정했고 최종 로그는 오류 없음이다.

실행 예시: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/run_balance_review.ps1 -Gun heavy -Core inferno -Revision 1 -Label after_heavy17`. `-Revision 0`은 격리된 새 도전 상태에서 보정 표식만 제거해 이전 규칙을 비교한다. 기존 사용자 저장을 변경하지 않는다. 실제 저장은 모두 `qa_runtime/balance_review_20261106/` 아래로 격리했다.

이 단계는 새로운 적 패턴/전장 기믹이나 강화/등급 카드 체계를 구현하지 않는다. Android 지속 성능·실기기 조작·사람의 체감과 모든 파츠/난도/복장 조합의 최종 균형은 별도다.
