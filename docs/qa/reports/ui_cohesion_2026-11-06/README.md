# 지도와 다른 UI의 시각 정합성 검토

2026-11-06. 최신 지도 방향은 최근 비전투 UI와 잘 연결된다. 전체 UI의 통일은 아직 완료되지 않았으며, 가장 큰 잔여 차이는 전투 HUD의 중립 패널·탄환 카드 재질이다. 이번 요청은 검토이므로 게임 화면이나 소스를 수정하지 않았다.

## 비교 결과

[실제 Godot 화면 비교](index.html)는 같은 1280×800 크기의 기존 네이티브 캡처 7개를 모은 검토판이다. 새 UI 목업이 아니다.

| 화면 | 판단 | 유지할 차이 / 보완할 부분 |
| --- | --- | --- |
| 장비 선택 | 지도와 가장 직접적으로 연결된다. 아이보리·황동 색 값, 픽셀 글꼴, 기본 모서리와 선 규격이 같다. | 지도 버튼이 조금 더 평평하다. 장비에만 추가된 위쪽 빛·아래쪽 그림자 마감이 원인이다. 배치를 바꿀 이유는 없다. |
| 정비소 | 따뜻한 작업등·어두운 정보면·황동 선택이 같은 세계로 읽힌다. | 작업장 배경과 탭 중심 구성은 장소의 개성으로 유지한다. |

| 결과 | 같은 픽셀 글꼴과 절제된 정보면으로 연결된다. | 패배의 적갈색·장미빛은 결과 상태의 변주다. 황동으로 통일할 필요가 없다. |

## 권장 범위

1. 지도 방향과 배관도 구성을 유지한다. 지도까지 장소 원화나 단말기 외함으로 바꾸지 않는다.
2. 다음 재질 통일 작업은 전투의 기본 패널·카드 바탕·일반 버튼을 우선 비교한다. 의미가 있는 발열·위험·냉각·사격·효과별 색은 보존한다.
3. 지도와 장비의 공통 버튼은 빛·그림자 마감만 작은 비교안으로 확인한다. 기본 테두리 두께가 다른 것으로 기록하지 않는다. 양쪽의 기본 선은 같고 장비에 추가 장식이 있다.

이는 미감 판단과 후속 제안이며, 사용자의 새 디자인 확정이나 구현 완료가 아니다.

## 검토 근거와 한계

- 주 검토자가 7개 네이티브 캡처를 확인하고, 독립 시각 검토 A와 정적 증거 검토 B를 분리했다. A 완료 후에 B 결과를 합쳤다. A의 전투 보충 검토도 완료한 뒤 종합했다.
- 지도·장비·정비소·상점·전투는 11월6일 캡처, 보상은 11월5일, 결과는 11월4일 캡처다. [소스·캡처 대조](evidence.md)에 해시와 출처를 남겼다. 보상·결과는 전체 테마 의존성의 해시가 없어 최신성 확인 범위에 제한이 있다.
- 도구의 Godot 확장자 지원이 없어 탐지기의 빈 배열을 품질 통과로 해석하지 않는다. 실제 판단은 네이티브 화면과 Godot 테마·스크립트 대조에 근거한다.
- 이번에는 새 실행·입력 회귀검사·모바일 실기기·사람의 이해도 시험을 수행하지 않았다. 기존 기능 검사 통과 수를 시각 품질의 증명으로 사용하지 않았다. APK·커밋·푸시·외부 게시 없음.
