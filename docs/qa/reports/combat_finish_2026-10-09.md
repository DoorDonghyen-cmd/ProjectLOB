# 전투 비주얼 · 장전과 과열 1차 마감

사용자 승인 범위: 출시 목표의 대표 전투 비주얼 제작. 승인 캐릭터/배경/탄환 도트와 고정된 전투 배치를 유지한다. 이번 결과는 본편 공용 화면에 적용한 1차 제작본이며 최종 출시 품질 승인과 구분한다.

## 적용

- UI: 전체 강조 테두리를 짧은 모서리/활성 가장자리로 줄이고, 탁한 강철 면·계단 모서리·얇은 밝은 윗면/어두운 밑면을 사용했다. 탄창은 비어 있는 홈과 장전된 탄의 면을 구별한다. 클릭 영역·최소 크기는 유지한다.
- 발열: 실제 열은 채워진 셀, 예상 최고 열은 빈 윤곽 셀, 한계는 끝의 정지 표시. 냉각 시 빠진 셀에 푸른 잔상이 짧게 남고 실제 숫자는 즉시 갱신한다. 프레임 수와 무관하게 모델 값이 원본이다.
- 전장: 주인공 발 접촉 그림자와 소수의 낮은 대비 공기 입자, 하단 받침면을 추가했다. 승인 원화/배우 크기/거리 배치는 바꾸지 않았다.
- 사격: 기존 조준·반동·증폭·속성 피격 연출을 유지하며 탄피·지면 반사·물리 파편·처치 시 짧은 시각 정지를 더했다. 과열은 총열 부근의 정지 반응, 냉각은 증기와 계기 잔상으로 연결한다. 전역 시간 배율이나 모델 RNG는 사용하지 않는다.
- 진행 표시: 사격 중/과열 중단/재장전 턴/냉각 완료를 실제 사건에 맞춰 표시한다. 냉각 완료 후 과열 경고를 남기지 않는다.

`PLAY.cmd` → 개발 → **전투 비주얼 · 장전과 과열**. 저장을 변경하지 않는 시연이며 쇄도/열5/연타·증폭·냉각 등을 준비했다. 기본탄 → 연타탄 → 증폭탄 순서로 장전 후 확정/발사하면 LIFO 증폭 연쇄·처치·과열·강제 냉각을 한 번에 볼 수 있다. 냉각탄을 조합해 다른 순서도 비교할 수 있다. 본편은 기존 몬스터를 유지하며 이 시연만 기존 생물 시안들을 사용한다.

## 검증

`tools/run_combat_finish_checks.ps1`: **282검사/0실패**. 1008×630 / 1280×900 / 1440×630에서 실제 발사·강화 피격·처치·과열·냉각의 렌더 프레임을 캡처했다. 연출 없는 동일 상태 모델 복사본과 사격 결과/RNG를 비교하고, 모든 관측 프레임에서6개 영역의 위치/높이를 검사했다. 연출 종료 후 적 위치·열·입력 상태 복원과 즉시 연출 설정도 검증했다.

기존 `tools/run_combat_hierarchy_checks.ps1`: **662검사/0실패**. 장전/회수/확정/과열/예측 범위 변경에서 화면 고정과 기존 기능을 재확인한다.

작은 화면의 장전/사격/냉각 캡처를 직접 검토하고, 프레임이 텍스트를 가로지르는 문제와 냉각 후 남는 과열 경고를 수정했다. 생성 PNG 교체 없이 Godot 도형으로 제작했다. [제작 기록](../../art/combat-finish-20261009.json).

Galaxy 실기기 성능·사람의 판독/피로도는 후속이다. 사운드·새 적 동작 원화·새 지역 배경은 이번 범위에 포함하지 않았다. APK/커밋/푸시/외부 게시 없음.
