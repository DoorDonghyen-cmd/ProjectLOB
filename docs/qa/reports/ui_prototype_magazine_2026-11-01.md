# HTML 전투 목업 — 현행 탄창 조작 연결

2026-11-01. 사용자 ‘다음 스텝’ 요청으로 [안정화 후속 1단계](ui_prototype_stabilization_2026-11-01.md#남은-단계와-한계)를 진행했다. 제거한 `이번 사격 / 탄을 눌러 장전하세요` 카드는 다시 넣지 않았다.

## 바뀐 조작

- 시작 시 보유 덱에서 자동 장전. 현재 리벳 기본 구성은 7칸이며, 실제 파츠에 따른 칸 수·발열 상한을 모델에서 받는다. 처음부터 사격할 수 있다.
- 왼쪽부터 최대 2발 사격. 다음 사격 탄만 황동색 테두리·번호로 표시하고, 과열·승리로 중단될 때 버튼에 실제 발수를 표시한다.
- 탄환 선택 → 같은 `1발/2발 빼내기` 버튼으로 즉시 확정. 선택한 탄은 붉은 외곽·`제외` 표시. 사격·냉각·교체를 막고, 제거 후의 다음 탄과 적 피해 예측을 표시한다.
- 같은 탄, 빈칸/패널 여백, 취소, Escape로 선택 취소. `N번 상세`를 닫아도 선택이 유지된다. 빼내기를 모두 쓴 뒤 탄을 누르면 상세가 열린다.
- 빼낸 탄은 이번 전투 소모, 상대 순서 보존, 자동 보충 없음. 사격·냉각으로 빼내기 한도가 회복되지 않으며 전체 교체에만 회복된다.
- 냉각/탄창 교체를 분리했다. 미사용 탄은 교체 시 예비 맨 뒤로 돌아간다. 빈 예비의 불필요한 교체는 표시·실행 모두 거부한다.

규칙 원본은 [탄창 운용](../../direction/weapon-magazine.md), [선택 빼내기](../../direction/magazine-ejection.md)다. 이번 작업으로 새 비용·밸런스를 만들지 않았다.

## 전투 계산 연결과 범위

이전 HTML의 독립 `simulate`/적 행동 계산과 LIFO 조작을 제거했다. 로컬 서버가 기존 `Model.fire`, `cool_magazine`, `reload_magazine`, `emergency_resupply`, `eject_magazine_rounds`와 `Forecast.analyze`를 호출한다. 부분 사격 사이 증폭·파츠 이력, 발열·소모·승패·예측을 같은 코드로 처리한다. 선택 예측은 복사본을 사용한다.

지도·경제·보상은 기존 HTML 목업이며, 그 화면에서 획득한 덱과 장착 파츠를 전투 모델로 전달한다. 일반/관문 적 구성·수치는 직전 목업을 유지하고 정예는 기존 내보내기 데이터를 쓴다. 본편 캠페인/저장과 연결하거나 기존 Godot 화면을 이 디자인으로 교체한 단계는 아니다. 실제 모델을 쓰므로 이전 단순 계산과 피해·파츠 결과는 달라질 수 있다.

서버는 `127.0.0.1`에서만 동작한다. 탭별 전투를 분리하고 명령 revision으로 중복 실행을 막는다. UI는 진행 중 입력과 선택 중 행동을 차단하며, 이전 화면의 늦은 결과·예측을 무시한다. Godot 요청은 `qa_runtime/ui_prototype_model/` 아래 격리 경로만 사용하고 사용자 저장을 열지 않는다.

## 실행

현재 실행 주소: <http://127.0.0.1:8765/index.html#tab=boss>. 기존 탭은 새로고침하면 변경이 적용된다.

서버가 꺼졌으면 저장소 루트의 `OPEN_UI_PROTOTYPE.cmd`를 실행한다. 이 런처는 `python tools/serve_ui_prototype.py`를 실행하며 로컬 Godot 4.7을 사용한다. 단순 정적 파일 서버나 HTML 파일 단독 실행에서는 전투 API가 없으므로 연결 안내와 재시작 버튼을 표시한다. 새로고침/서버 재시작 후 플레이 저장 복구는 아직 제공하지 않는다.

## 다음 단계·미검증

- 작은 화면에서 상세/빼내기 높이 약29px, 냉각/교체 약35px, 사격 약40px. 겹침 확인은 모바일 터치 크기 충족을 뜻하지 않는다. 다음은 보조 버튼·글자·입력 영역의 최소 크기 확보다.
- Android 실기기 터치·길게 누르기, 지속 성능/발열, 사람의 이해도·선택 가치·미감은 미검증이다.
- 로컬 연결은 조작마다 Godot를 실행하는 검토용 경로다. 그 응답 시간은 모바일 전투 성능의 근거가 아니다.
- 이후 검증된 화면 구성을 Godot 실제 UI/저장 흐름에 통합한다. 본편 기본 진입·게임 모델 원본·아트·APK·커밋/외부 게시는 변경하지 않았다.
- 관련 파일 해시는 [manifest](../../../qa_runtime/ui_prototype_magazine_20261101/manifest.json)에 기록했다.
