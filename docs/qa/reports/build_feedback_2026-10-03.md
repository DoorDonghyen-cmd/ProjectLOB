# 파츠·조합의 전투 피드백

2026-10-03 · `prototype/core-redesign` · Godot 4.7 · 시드 731042.

승인된 다음 단계인 **파츠가 전투에서 바꾼 결과를 알아보게 하는 작업**을 구현했다. 기존 탄환 카드와 화면 큰 틀을 유지한다. 배우·배경은 임시 자산이며 새 아트·사운드는 제작하지 않았다.

## 구현

- 전투 상단에 장착 파츠 아이콘을 최대 5개 표시한다. 누르면 효과·조건·대가가 열린다. 아이콘 아래 칸은 **다음 발사**에서 발동할 탄 순서다. 탄창 전체 예측 보기와는 범위를 구별한다.
- 실제 명중 때 해당 파츠와 발사한 탄을 함께 강조한다. 결과 줄은 대표 파츠 하나와 집중/증폭으로 제한한다. 동시에 적용된 다른 파츠도 아이콘이 빛난다. 건너뜀 버튼이 나타나도 아이콘 위치는 유지한다.
- 쇄도 적 명찰에 누적 적중 3칸을 추가했다. 추가 피해가 발생하면 세 칸을 강조한다. 터치 상세/툴팁에서 재장전 후 유지와 보호에 막힌 타격의 규칙을 확인한다.
- 훈련/캠페인 교전 보상에 사용 탄·처치 수와 최대 두 개의 주요 발동 기록을 표시한다. `기록` 버튼으로 전체 결과를 열며 이전 교전과 섞지 않는다.
- 실제 사격 결과에 선택적 `part_effects` 관찰 데이터를 추가했다. 저장 버전·피해 계산·RNG·비용은 바꾸지 않았다. 이전 기록에는 기본값을 사용한다. 발동 횟수는 탄환 기준이며 여러 타격을 따로 세지 않는다.
- 완전히 보호에 막힌 피해 파츠, 최대치에 도달한 화상, 처치 때문에 사용되지 않은 추가 타격/화상을 구별한다. **발동 횟수는 파츠별 추가 HP 피해 총량이 아니다.** 전이·밀기 강조는 해당 강화 효과가 적용된 사격이다. 재장전·보급·압축 기회처럼 유지되는 파츠는 상시 효과로 안내하며 사격 발동으로 표시하지 않는다.

## 함께 수정한 예측 결함

산개의 분기 예측이 선두/후미/삼중 조건을 전달하지 않고 캐시에 다중 장착 파츠를 포함하지 않았다. 실제 발사와 같은 순서 조건을 전달하고 장착 구성과 현재 탄창의 기존 발사 순서를 캐시에 포함했다. 추가 타격 수도 반영한다. 무작위 미래 표적이나 파츠 발동을 확정 표시하지 않는다.

## 같은 전투의 선택 차이

쇄도, HP100·장갑1·거리24 적 하나, 시드731042에서 실제 장전→확정→발사를 실행했다. 아래 직접 피해에는 집중 피해가 포함된다.

| 선택 | 직접 피해 |
| --- | ---: |
| 연발 → 철갑 → 증폭 | 10 |
| 증폭 → 연발 → 철갑 | 16 |
| 점화 약실: 연발 → 철갑 → 소이 | 11 |
| 점화 약실: 소이 → 연발 → 철갑 | 17 |
| 증폭 → 연발 → 철갑 + 연발 강화 파츠 `duplex` | 19 |

순서와 장착 파츠가 결과를 바꾸는 기능 근거다. 검사 상태의 비교이며 일반 런 승률·전체 밸런스·최적 빌드·사람의 재미를 입증하지 않는다.

## 검증

모두 격리된 `qa_runtime` 저장에서 실행했다. 소스와 시나리오를 아는 기능·시각 검사이며 사람의 첫 플레이 관찰이 아니다.

| 검사 | 결과 |
| --- | --- |
| `run_director_ui_checks.ps1 -Mode feedback` | 444개 / 실패0. 발동/예측 일치, RNG 비변경, 저장·이전 기록, 보호/화상 상한/처치, 교전 분리, 순서·파츠 비교, 산개 24개 RNG 상태, 세 비율/큰 글자, 터치·명중·위치 유지·건너뜀·보상 |

전체 캠페인 첫 실행에서는 두 무기가 완주했지만 기존 기준 기록과의 비교 두 건이 실패했다. 새 `part_effects` 필드만 제외하고 모든 피해·명령·턴·RNG 필드를 계속 비교하도록 호환 검사를 수정한 뒤 전체 재실행을 통과했다. 새 관찰 데이터는 별도 테스트로 검증하며, 실제 피해값을 변조하면 기준 비교가 실패하는 것도 확인했다. 표준 오류 스트림의 `FAIL:`도 실행 도구에서 실패로 판정하도록 보완했다.

원본 수치·캡처·코드 해시는 [증거 폴더](build_feedback_2026-10-03_assets/)에 보존한다. 인증서 저장소 경고는 렌더/전투 검사 실패로 이어지지 않았다. 작업 중 테스트 타입 추론 오류를 수정했고, 기록 버튼 한 줄 검사를 실제 글자 폭과 여백으로 보완했다.
