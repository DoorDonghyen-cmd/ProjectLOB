# 전투 도트 UI 통합 수정

## 원인과 변경

사용자 판단: 정비함 PNG 외피가 촌스럽고 도트 인상이 약하며, 발사 카드와 재장전 등 나머지 UI와 어울리지 않는다. 이전 내부 검토에서 4종 리소스 적용만으로 통합을 판단한 것이 부족했다. 해당 외피를 본편에서 철회하고 기존 파일은 제작 이력으로 남긴다.

- 청회색 큰 면과 2px 계단 모서리를 공통 프레임으로 제작. 리벳·긁힘·가죽·법랑 명찰을 제거했다. 배경의 넓은 색면과 기존 탄환 기호를 기준으로 삼았다.
- 장전 카드와 손패, 열계 홈, 실행·재장전·보조 버튼 모두 같은 도형/음영 구조를 사용한다. 실행/냉각/위험은 같은 형상 안에서 밝기·색·아이콘으로 구분한다.
- 재장전을 열린 글자에서 실제 버튼으로 바꾸고 발사 버튼과 같은 220 논리 픽셀 폭에 정렬했다. 접촉 위험도 같은 스킨의 경고 상태이며, 3줄 경고가 폭이나 높이를 밀지 않게 했다.
- 프로젝트에 있던 NeoDunggeunmoPro를 전투 카드·조작부·HP/거리·피해 숫자에 공통 적용. 다른 화면의 일반 본문 글꼴은 유지한다. 카드 폭 검사도 실제 사용 글꼴로 측정하게 했다.
- 카드 hover/focus/누름을 이벤트로 다시 그리며, 압축 드래그 미리보기도 같은 외피다. 입력 영역·전투 규칙·저장은 유지한다.
- 준비된 탄창의 상세 계산은 기본 회색 AcceptDialog에서 게임 내부 상세 화면으로 연결했다. 전투 중 상세 화면은 같은 도트 글꼴/닫기 버튼을 쓴다. 기존 HUD 검사는 이 상세창을 닫지 않고 뒤의 몬스터를 누르고 있었으므로, 실제 닫기 입력 후 검사를 계속하도록 수정했다.

## 검증

- 전투 연출/모델 동일성·5총기/최대10장/3해상도: 784검사, 0실패.
- 정보 위계/장전 전후 고정 배치·냉각·위험 재장전 폭/문구: 677검사, 0실패.
- HP/거리/복합 상태·터치 상세·탄창 상세 닫기/복귀: 2201검사, 0실패.
- 전투 중 탄환 가방 5분류·무소모 열람·닫기/포커스: 618검사, 0실패.
- 실제 1280×900/1008×630/1440×630 캡처를 확인했다. 짧은 화면에서 재장전 접촉 위험은 3줄로 표시하면서 같은 폭/높이를 유지한다.

초기 구현의 GDScript 예약 클래스명 충돌 및 테스트의 정적 글꼴 참조를 수정했다. 추가 HUD 검사의 초기 실패는 열린 탄환 계산창을 닫지 않은 입력 순서였으며, 새 상세 화면을 실제 닫은 후 최종 재실행했다. 변경 전부터 있던 Android build-tools 경고는 PC 검사 실패가 아니며 APK는 생성하지 않았다.

실제 비교: 기존 장식안보다 잔묘사/밝은 크림색 면을 줄였고, 전투 전체의 모서리·글꼴·버튼 형식을 맞췄다. 이는 제작자의 시각 판단이며 새 디자인의 사용자 선호와 Galaxy 가독성 검증은 남아 있다. 기능 통과를 미적 품질/출시 승인으로 취급하지 않는다.
