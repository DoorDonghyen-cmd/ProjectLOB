# 우수 정원 — 높이별 전투 배경

2026-10-23. 사용자가 주조장 배경을 긍정 평가하고 ‘다음 구역도 진행’을 요청했다. 같은 작업 범위로 3구역 전용 전투 배경3종을 제작·연결했다. 이후 사용자 전체 방향 긍정 평가와 상층 식물 보강 요청을 반영했다. 아래 초기 제작 기록 이후의 최신 상태는 마지막 상층v2 절을 참고한다.

## 본편 적용

| 진행 구간 | 환경 | 실제 화면 |
|---|---|---|
| 초반 1~3 | 사육 통로: 깨진 유리 수조, 열린 사육장과 물통, 관리실 작업등 | [1280×800](assets/garden_background_2026-10-23/stage0_1280.png) |
| 중반 4~6 | 방치된 온실: 굵은 뿌리, 재배 수반, 이끼와 관개 수로 | [1280×800](assets/garden_background_2026-10-23/stage1_1280.png) |
| 상층 7~9 | 집수 수로: 거대한 저수 구조물, 수문, 흐르는 물과 낡은 배관 | [1280×800](assets/garden_background_2026-10-23/stage2_1280.png) |

숫자는 내부 진행 위치다. 1F 등 새로운 층수 표기를 추가하지 않았다. 같은 높이의 모든 분기는 같은 그림을 사용하고, 이전 맵도 저장된 길이에 따라3등분한다. 기존/새 저장 모두 배경만 바뀌며 편성·수치·RNG·저장 필드는 변경하지 않았다. 현재 본편 생물4종·공명 처마등·집수 조정기를 그대로 사용한다. 기획의 긴발 숨접이/수로의 어미는 이번에 제작·적용하지 않았다.

`PLAY.cmd` → **개발 → 정원 배경 · 초반 / 중반 / 상층**. 본편에서 3구역에 진입해도 자동 적용된다. 개발 시연은 정상 저장을 덮어쓰지 않는다.

## 제작 출처와 등록

- 내장 `image_gen`을 사용해3장 각1회 생성. 기존 승인 주거 통로와 이번 사용자 긍정 평가를 받은 주조장 중반 원화를 실제 참조 이미지로 전달했다. 전투 발판 구도와 큰 도트 색면을 참조하고, 장소는 우수 정원의 사육·집수 설정에 맞춰 새로 구성했다.
- [전체 프롬프트·참조 원본·해시·파일 위치](../../art/garden-ascent-20261023.json).
- `새-게임-프로젝트/assets/art/garden_ascent_20261023/{lower,middle,upper}_v1.png`, 모두1672×941 RGB. 생성 원본을 그대로 복사했다. 픽셀 편집·블러·재샘플링 없이 표시 영역과 지면만 Godot에서 등록했다.
- 지면 y는663/698/687. 공통 `ascent_background.gd`의 region2에 등록했고 기존 배우 크기/위치·거리 표현은 유지했다.
- 배경은 정지 원화이며 기존 환경 입자만 유지한다. 원화의 물줄기를 새 유체/수면 애니메이션으로 구현한 것은 아니다. 지도·상점·공방의 공통 실내 환경은 이 작업과 구별한다.

## 개발 미리보기의 출처

`tests/fixtures/garden_gate_single.json`은 기존 `foundry/campaign_current_731042/endpoint_single.json`의 복사본이다. 편성6 시점에 실제2구역을 통과한 보행자 덱26장과 획득 파츠를 보존한다. 원래 저장의 관문 보상을 실제 `gate()`로 처리하고,3구역 적을 현재 편성8로 표시한다. 중반/상층 미리보기는 해당 노드로 직접 이동하므로 현재 밸런스의 연속 진행 증거가 아니다. 저장 검사는 실제 선택 가능한 첫 노드에 입장한 상태에서만 수행했다.

## 시각 판단·남은 일

3비율×3단계9장, 정예1008,보스1280,피니시의 대표12장을 직접 열어 확인했다. 좁은 전장 안에서도 수조→뿌리/재배대→수문으로 장소가 구분되고, 배우와 같은 지면에 연결된다. 식물과 물은 작은 고채도 반짝임 대신 묶인 명암으로 두었다. 가로가 긴 화면은 상부 온실/수조를 더 많이 자르지만 하부 수반과 수문이 남는다. 기존 작은 숨접이의 어두운 윤곽은 사용자 기기 밝기에서 추가 확인할 사항이다.

사용자 미감/지역 변화 체감·Galaxy 실기·현재 편성으로3구역 전체 진행/난이도는 미검증이다. 이번 환경 작업으로 접근 압박 재균형이나 새 정예/보스가 완료됐다고 판단하지 않는다. 다음3구역 제작은 기존 기획의 긴발 숨접이·수로의 어미 시안과 상태 동작, 공개된 도약 예고를 실제 전투에 연결하는 단계다.

APK·커밋·푸시·외부 게시·PC종료 미실행.
