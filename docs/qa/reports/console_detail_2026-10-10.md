# 도트 UI 후속 디테일

사용자는 직전 공통 UI 방향을 긍정적으로 채택하고 카드/패널/버튼 3종 참조를 추가했다. [참조 관찰·채택 범위](../../art/style-reference/detail-ui-study.md). 이번 작업은 디자인 세부만 다듬었으며 주요 배치·전투 수치·조작 순서·그림을 변경하지 않았다.

- `tools/build_console_ui.py`와 `assets/ui/console/`: 행동 키의 넓은 계단형 어깨, 아래 받침, 눌림 깊이, 보호 모서리 안의 제한된 반사광. 카드의 비대칭 이음, 장전 판의 안착부. 32px 원본/10px 보호 여백을 유지해 가장자리 묘사가 늘어나지 않는다.
- `ammo_card_view.gd`: 이름 띠 끝의 단차. 이름·발열·수치·효과 위치 그대로.
- `screen.gd`, `combat_surface.gd`: pressed의 위 여백 +2/아래 −2로 글자와 아이콘도 같이 내려간다. 여백 합계가 같아 버튼 최소 크기와 주변 배치에는 영향을 주지 않는다. focus의 투명 모서리 정책을 유지한다.
- 모든 공용 상태에 연결되므로 전투 외 가방·상점·파츠·메인·무기·맵 버튼에도 적용된다. 미감의 최종 사용자 확인은 별도이며 Galaxy 실기기 확인은 후속이다.

## 검증

기존 전투 UI **340검사/0실패**와 공통 화면 **51검사/0실패**를 격리 저장에서 확인했다. 신규 규칙 테스트는 만들지 않았다. 전투검사는 세 비율의 장전·확정·발사·냉각과 고정 배치를, 공통검사는 두 비율의 화면 진입·구매·파츠 교체를 확인했다. 스크립트/런타임 오류 로그 없음. [전투 로그](console_detail_2026-10-10_assets/combat.log) · [공통 화면 로그](console_detail_2026-10-10_assets/console.log).

전투1280 삽입 화면, 발사 대기1008, 상점1008 캡처를 직접 열어 확인했다. 숫자와 버튼 라벨, 선택 모서리가 유지되고 주변 요소가 추가 단면 때문에 밀리지 않는다. 눌림의 시간적 체감과 Galaxy 확인은 후속이다.

이번 변경은 자체 제작 SVG와 Godot 스타일을 사용했으며 첨부 이미지를 잘라 재사용하지 않았다. APK/커밋/푸시는 수행하지 않았다.
