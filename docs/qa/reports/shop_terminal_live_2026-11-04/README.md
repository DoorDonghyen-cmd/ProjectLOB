## 실행과 검증

- 본편은 저장소의 `PLAY.cmd`로 실행한 뒤 지도에서 상점 노드에 들어간다.
- `tools/run_shop_live_checks.ps1`로 165개 검사를 통과했다. 격리 저장에서 본편 지도 진입, 터치 구매, 탄약 교체 취소와 확정, 파츠 구매와 보관·교체·해제, 타이틀 이어하기, 지도 복귀, 다섯 구역의 기록 원문을 검사했다. 이전 지도 버전으로 저장한 뒤 이어하기에서 해당 상점의 전용 서비스가 열리는 것도 확인했다.
- `OPEN_SHOP_CONSOLE_PREVIEW.cmd -Capture`에서 단말·기록 543개 검사와 상점·파츠 1,009개 검사를 통과했다.
- `tools/run_prototype_hud.ps1` 기본 모드는 11,536개 검사를 통과했다. 별도로 실행한 `-Mode flow`는 전투 여정 시안의 공용 HUD가 `Trial` 속성을 읽을 때 중단됐다.
