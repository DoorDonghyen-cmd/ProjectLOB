## 방법과 확인 범위

`tools/run_core_choice.ps1 -Mode probe -Label playtest20261105`는 기존 획득 저장의 규칙을 보존한다. `QA_SPECIALIST=1`을 지정한 `-Label playtest20261105_current`는 같은 획득/성장 상태에 현행 새 도전의 성장 계승 표식만 적용해 비교한다. 이 표식 적용은 격리된 비교 상태에만 수행하며 사용자 저장을 이관하거나 새 보상을 지급하지 않는다. 현재 표식을 적용한 사례의 아이템을 지금의 새 도전 획득 경로에서 다시 모았다는 의미는 아니다.

두 실행은 보유 코어/모듈 유지·교체10쌍씩 총40전투 분기를 비교한다. 각 분기는 관문에서 추가 성장을 건너뛰고 같은 첫 연결 전투에 들어간다. 합법적인 사격량·냉각·재장전·빼내기·보급과 저장/재개를 검사한다. 유한 탐색은 미래 드로와 난수를 볼 수 있으므로 사람의 승률·최적해·실제 선택 이유를 입증하지 않는다.
