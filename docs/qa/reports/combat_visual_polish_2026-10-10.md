# 전투 UI 시각 폴리싱

사용자 요청은 디자인에 남은 AI 제작 같은 인상을 줄이는 것이다. 이번 변경은 공통 프레임의 형태·명암·팔레트에 한정하고 기존 배치/입력/규칙/글자 크기/카드 그림은 유지했다. 사용자가 최종 화풍을 승인한 상태로 간주하지 않는다.

## 판단과 제작

기존 UI는 카드·슬롯·보조 버튼마다 같은 두꺼운 윗선과 두 단계 모서리가 반복됐다. 하나의 형태가 모든 역할에 적용되는 획일성이 문제라고 판단했다. 새 프레임은 코드로 픽셀을 직접 구성했다. 새 생성 이미지, 노이즈/얼룩/리벳, 외부 에셋은 사용하지 않았다.

- 카드: 탁한 회녹색 판형, 얇은 윗선과 한쪽 작은 모서리 절단, 낮은 바닥선. 내부 전체 구분선을 짧은 이름 밑선으로 대체했다.
- 탄창 홈: 어두운 안쪽 면, 깊은 위/좌측 그림자와 가는 아랫선. 카드와 반대 방향의 명암으로 구분한다.
- 주 행동: 밝은 회녹색 눌림면을 유지한다. 보조 버튼은 낮은 대비의 바닥선, 재장전은 청회색 기능색을 사용한다. hover/focus는 모서리로 표시한다.
- 패널: 반복되는 두꺼운 장식 시작점을 없애고 가는 경계선으로 묶었다. 큰 면의 청록 채도를 낮추고 손패를 약간 따뜻한 회색으로 분리했다.
- 발열: 각 셀의 밝은 윗면을 2px에서 1px로 줄이고 빈 셀 명암을 낮췄다. 현재/예상/냉각/위험 구분은 유지한다.
- 장전 카드 이름: 중립 밝기로 통일해 강화/경고에 사용하는 색이 더 잘 구별되게 했다.

제작 파일: `combat_pixel_skin.gd`, `combat_surface.gd`, `ammo_card_view.gd`, `magazine_view.gd`, `heat_gauge.gd`. 프레임은 24×24 RGBA를 코드로 그려 기존 nine-slice 경계 8px 안에서 확장하며 폰트와 입력 영역은 변경하지 않는다.
