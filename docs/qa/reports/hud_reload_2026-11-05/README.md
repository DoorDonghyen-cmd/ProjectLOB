# 빈 탄창 재장전 표시 — 2026-11-05

전투 중 탄창이 비고 실제 재장전이 가능한 상태에서 기존 버튼에 따뜻한 점등과 작은 표시등, ‘재장전 필요’를 표시한다. 적 행동 비용·접촉 위험은 같은 위치에서 계속 표시한다. 장전 완료·행동 연출 중·전투 종료에는 꺼진다. 전투 전체 탄약 소진/비상 보급을 일반 재장전으로 표시하지 않는다.

본편 `campaign_hud/combat.tscn`과 HUD 비교판이 상속하는 `samples/hud/combat_hud.tscn` 및 공용 presenter에 연결했다. 버튼/카드 위치·크기·입력·전투 계산·저장 형식은 유지한다. 점등은 정적 색/작은 ColorRect로 구현하며 별도 반복 애니메이션이나 매 프레임 처리를 추가하지 않았다. 장식은 터치 입력을 받지 않는다.

[1280×800](reload_needed_1280x800.png) · [1008×454](reload_needed_1008x454.png) · [S26비율2340×1080](reload_needed_2340x1080.png).

캡처의 높은 체력/정지 표적은 실제 사격 명령으로 탄창을 소진하기 위한 격리 UI 검사 픽스처다. 게임의 적 체력이나 밸런스 변경을 보여 주는 화면이 아니다.

`powershell -NoProfile -ExecutionPolicy Bypass -File tools/run_prototype_hud.ps1 -Mode ui -Fast`

**11,558개 검사, 실패0.** 기존5총기·여러 창 크기·예측 정합성·빼내기·상세/메뉴·저장/재개 검사에, 실제 사격으로 빈 탄창 만들기→3크기 점등/문구/기존 입력 영역→행동 잠금 시 소등→실제 재장전 후 소등→전투 종료 소등을 추가했다. [검사 결과](ui.json). 초기 검사가 공용 버튼 프레임의 색 초기화를 검출해 점등 색을 `self_modulate`로 분리했고 수정 후 전체 검사를 통과했다.

새 캡처에서 점등·글자·적 행동 비용과 버튼 경계를 시각 확인했다. 모바일 해상도는 PC 렌더이며 Android 실기기와 사용자 체감은 확인 전이다. `Fast`는 검사 중 연출 대기만 줄이며 전투 규칙을 변경하지 않는다.
