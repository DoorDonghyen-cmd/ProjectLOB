# 파츠 장착 화면 본편 적용

지도에서 빌드 작업실을 열거나 상점 단말기에서 `파츠 장착`을 누르면 같은 화면이 열린다. 왼쪽 작업대의 총기와 슬롯 5칸에는 현재 장비가 표시된다. 오른쪽에서 보유 파츠를 고르면 들어갈 파츠와 빠질 파츠의 효과, 달라지는 총기 수치를 확인한 뒤 장착·교체할 수 있다. 슬롯 해제와 보유 파츠 분해는 별도 조작이다. 상점에서 닫기 또는 Esc를 누르면 직전에 선택한 상품으로 돌아간다.

좁은 창에서는 보유 목록과 긴 설명을 각각 스크롤한다. 슬롯과 장착·교체 버튼은 제자리에 남는다.

## 검증

- 빌드 작업실 146건과 상점 318건 통과. 격리 저장에서 실제 장착·교체·해제, 분해 취소·확정 후 잔액과 저장, 상점 상품 선택 복귀를 확인했다.
- 장소 화면 90건과 상호작용 연출 234건 통과. 전투 파츠 배지와 강화 사격 연출 검사도 포함한다.
- PC에서 실행해 화면과 입력을 검증했다. Galaxy S26 실기기에서는 확인하지 못했다.
