## 검증 범위

- 타이틀, 처음 안내, 설정, 신규 등반 덮어쓰기 확인, 이어하기와 자동 저장.
- 5계층 35층 지도, 전투, 보상, 무기고, 보급, 이벤트, 관문, 덱·장비, 기록실, 승리와 패배 정산.
- 다섯 무기와 3~7칸 탄창, 전술 패5장, 다음2장·대기·사용 탄환, 영구 압축과 런 자원형 현장 압축.
- 적6종과 상층 규칙인 충전·배리어·교대 장갑, 복합 관문 편성.
- 1280×800 기본 화면, 1008×630 모바일 최소 화면, 글자110%, 실제 마우스·터치 입력.

## 화면 직접 검토

- 메뉴에서 모드·보급·난도·무기 선택 순서가 위에서 아래로 유지되고, 무기 카드의 이름·핵심 규칙·탄창/재장전 정보가 한 덩어리로 읽힌다.
- 전투는 `탄환 선택 → 순서 확인 → 확정·발사` 단계를 고정 표시하고, 적을 누르면 현재 수치와 행동 규칙을 보여 준다.
- 배리어는 청록 마름모, 충전은 `충n/3`, 태세는 `장4→0`을 색과 함께 표시한다. 배리어와 충전이 함께 있는 경우 서로 다른 앵커를 사용한다.
- 110% 글자와 1008×630에서는 한 화면에 전부 압축하지 않고 세로 스크롤로 모든 버튼에 접근한다. 주요 터치 버튼은 최소 52px 높이를 유지한다.
- 패배 정산은 접촉 원인과 다음 장전 조언을 남기며, 덱과 기록실은 긴 문장 목록 대신 카드·슬롯 구조를 사용한다.

## 남은 제작과 검수

- 임시 도형과 문자 아이콘을 최종 픽셀 아트, 애니메이션, 배경으로 교체한다.
- BGM·SFX를 연결한 뒤 실제 음량 설정과 믹스를 추가한다.
- 아트가 들어간 Galaxy 실기에서 프레임 시간, 발열, 대비, 손가락 드래그 감각을 다시 확인한다.
- 사람 플레이로 무기별 장기 재미와 경제 선호를 계속 조정할 수 있다. 이는 현재 흐름을 막는 기능 결함이 아니다.

현재 APK와 Windows 패키지는 이번 소스보다 오래된 검토본이다. 사용자가 새 테스트 파일을 요청할 때 최신 소스로 다시 내보낸다.
