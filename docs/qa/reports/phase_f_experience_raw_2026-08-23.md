# Phase F 초심자 경험 QA 원본 보고

> 역할: `16-gameplay-experience-tester`, beginner
> 입력: 공개 체크포인트 9개와 sample A/B의 `player_view`만 사용
> 독립성: 소스·오라클·기존 버그·다른 역할 결론 없이 작성, 읽기 전용

## sample A

- 재요청 횟수 `0→1`, 승인 성공, 슬롯 0/1/2의 제목과 설명이 모두 새 제안으로 바뀌었다.
- 관통 증가·재장전 단축·조건부 후속 격발의 거친 역할 구분은 가능하다.
- 수치·비용·현재 덱 상태가 없어 실제 이득 비교는 어렵지만, 행동 승인과 결과는 일치한다.
- 판정: `관찰` 수준 정상 흐름.

## sample B

- 퀵로드 제목에 기존 리듬 챔버의 연속 운용 설명이 붙어 제목과 효과가 충돌한다.
- 카드가 4개이고 슬롯 1이 두 번 나타나 어떤 항목이 실제 구매 대상인지 알 수 없다.
- 리롤 승인과 횟수 증가는 보이지만 무엇이 교체됐는지는 공개 정보로 설명할 수 없다.
- 플레이어 행동: 잘못된 효과를 살 위험 때문에 구매를 보류한다.
- 판정: 원인을 단정하지 않는 `관찰` 신호. 구매 판단을 막는 공개 표현 이상이다.

## 공통 공개 흐름 관찰

- 타이틀→구역 선택→로드아웃→맵→전투→보상→상점 전환은 단계명과 버튼으로 추적 가능하다.
- 로드아웃은 표준형 외 전부 잠겨 있어 초심자의 실질 선택은 없다.
- 전투에서 “약실 비어있음 - 리로드 필요”와 비활성 리로드 버튼이 함께 보이고 가방만 활성이라 다음 입력 설명이 부족하다.
- 상점 재요청은 크레딧 `100→97`, 비용 `3c→6c`, 제안 교체로 결과가 잘 드러나지만 `c`와 `Cr` 표기가 섞인다.
- PNG가 없어 실제 가독성·스크롤·애니메이션·반복 입력 피로는 `인간 확인` 대상이다.

## 독립 결론

정상 샘플은 문제로 오인하지 않았고, 결함 샘플은 사전 답안 없이 플레이어의 선택 포기까지 이어지는 문제로 발견했다.
정지 JSON만으로 촉감과 속도감을 자동 확정하지 않았다.
