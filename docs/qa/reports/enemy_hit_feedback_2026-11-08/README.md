# 전투 피격·경직·감속 검수

본편 전투의 실제 명령과 결과에 반응을 연결했다. 일반 피해는 몸이 사격 방향으로 짧게 밀리며 복귀한다. 차단·감속이 성공하면 몸을 더 낮추고 충돌점 옆에 짧은 도트 섬광을 낸다. 접지점의 보랏빛 표식은 이동 감속이 있는 적을 따라가고 마지막 감속 이동이 끝나면 사라진다. 즉시 연출에서도 상태 표식은 읽을 수 있다.

강한 직접 피해에는 기본 연출에서 50~80ms의 전장 히트스톱을 적용한다. 보통 증폭·연타는 실제 피해가 6 이상일 때, 큰 직접 피해는 18 이상일 때 적용한다. 높은 배율 단계나 복수 처치도 직접 피해가 있을 때 강한 적중으로 처리한다. 한 사격 명령에서 최대 120ms이며, 마지막 적 처치에서는 기존 피니시가 충돌 정지를 맡는다. 방어막에 전부 막힌 사격과 압력탄 요격은 별도 히트스톱에서 제외한다.

## 검증

- `tools/run_surface_fx.ps1 -Mode reactions`에서 시드 17의 본편 전투 사격·냉각 버튼을 실제 터치 이벤트로 실행했다. 1280×800과 1008×454에서 일반·배율·차단탄, 차폐, 즉시 연출, 마지막 적 처치 후 보상 진입을 검사했다. 발밑 표식은 실제 렌더 픽셀을 검사했고, 모든 전투 결과는 동일한 입력을 준 모델과 난수 기록까지 일치했다.
- 같은 실행기의 `rules`와 `ui`도 통과했다. 차폐·장갑·전류·화염 효과와 기존 획득 경로의 5구역 저장·복원까지 검사했다.
- 별도의 구형 `run_finish_feedback_checks.ps1`는 첫 일반 사격에서 재생 기록을 받지 못해 중단됐다. 현재 본편 HUD의 마지막 적 처치와 보상 진입은 `reactions`에서 확인했다.
- 모바일 가로 화면은 PC 창에서 검수했다. Android 실기기의 성능과 여러 전투를 이어 할 때의 체감은 후속이다.
