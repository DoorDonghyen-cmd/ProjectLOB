# 성장 구조 v2 시험판 1 — 특수탄 우선 장전, 코어 정리, 탄종 숙련, 총기 내장 구동

2026-11-10. 사용자 요청: "이대로 진행해 줘"(성장 구조를 처음부터 다시 짠 설계). 도중에 사용자가 "새 성장 구조가 괜찮다면 리벳 자체를 개편하는 게 낫다", "특수탄과 파츠 효과도 지금 구조에 맞게 개편해도 좋다"고 했다. 설계 원본은 [성장·빌드 구조 v2](../../../direction/growth-structure.md)다. APK·커밋·푸시는 하지 않았다.

## 적용한 것 (새 등반, `growth_structure_version=1`)

1. **특수탄 우선 장전**: 전투 시작과 재장전에서 특수탄이 기본탄보다 먼저 장전된다. 기존 구조에서는 같은 래칫 상태의 첫 9발 중 5발이 기본탄이었다.
2. **첫 전투 코어 선택 제거**: 첫 승리 후 바로 주력 탄 묶음. 코어 1개 제한도 없앴다.
3. **탄종 숙련**: 관문 선택지. 주력 계열의 공격탄이 단계마다 타격당 +1(단타 탄 +2), 최대 4단계.
4. **총기 내장 구동**: 리벳·스파이크·데드볼트는 돌파, 래칫·스플린터는 연쇄, 리액터·리와인더는 열압을 장착 칸 없이 가진다. 무기 상세 창에 '내장 돌파(단타 ×2)'처럼 표시된다.

| v2, 코어 없음 | **2구역 실패** | 완주(2구역 전투 2배) | **4구역 실패** |

| **v2 + 내장 구동, 숙련 2회 + 발수 개조** | **완주, 357턴** | **완주, 234턴** | **완주, 468턴** |

- 실패 원인은 첫 전투 코어를 없앤 것이었다(코어 유지 변형은 기존과 비슷). 그래서 코어 역할을 총기에 내장했다.
- 숙련만 고르면 리벳이 발수 개조를 못 받아 최종 보스에서 졌다. 단타 탄 숙련을 +2로 올린 뒤에도 마찬가지였다. **리벳은 발수 개조에 의존한다**(아래 리벳 개편 제안의 근거).
- 남은 크레딧 110~126, 덱 속 기본탄 10~16장은 그대로다. 다음 단계(탄 제거·★강화·이자)가 다룬다.
- 자동 플레이 정책 결과다. 사람의 체감은 확인 전이다.
