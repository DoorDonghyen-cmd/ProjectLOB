# 전투 UI 리소스 개편 — 회수자의 탄약 정비함

**후속 사용자 판단: 미채택.** 재질의 촌스러움·도트 인상 부족·나머지 조작부와 불일치를 지적해 본편에서 철회했다. [현재 수정안](combat_pixel_ui_2026-10-09.md)을 참조한다. 아래는 당시 제작 이력이다.

사용자는 이전 도형/테두리 위주의 1차 마감에 범용 AI UI 같은 인상이 남는다고 지적하고, 전용 리소스를 포함한 집중 개편을 요청했다. 특정 도구 사용 여부를 품질 판정으로 삼지 않고 전체 화면의 형태·정보 위계·세계관 연결을 바꾸었다. 새 디자인의 사용자 선호는 확인 전이다.

## 구현

실제 PNG UI 아틀라스에 급탄 장치/탄환 명찰/탄약함 안감/발사 플레이트4종을 제작했다. 승인 배경을 이미지 참조로 넣고 내장 image_gen으로1회 생성, 투명도와 요소별 영역을 확인했다. 원본은 그대로 보존하고 Godot가 영역별 nearest 축소/캐시·9분할 렌더를 수행한다. 별도 신원·계정·외부 업로드 없음.

- **탄창:** 큰 박스로 결과 전체를 둘러싸지 않는다. 급탄 장치 리소스는 탄창 주위에만 사용하고 구리 걸쇠·빈 홈·장전 탄을 읽게 한다. 내부를 수직 중앙 정렬해 테두리와 정보를 분리했다.
- **발열/결과:** 탄창 바깥의 열린 공간에 유지한다. 과열 경고와 발사 버튼도 급탄 프레임 밖에 두어 마지막 줄이 테두리에 걸리지 않게 했다.
- **손패:** 어두운 탄약함 안감 위에 법랑 명찰 카드. 이름/발열은 밝은 면의 어두운 글자, 피해/관통/효과는 어두운 본체에 배치한다. 승인 탄환 도트·게임 수치는 그대로이며 압축/등급/선택 표시는 동적이다.
- **조작:** 실행 버튼만 황토색 전용 플레이트. 보조 편집/메뉴 버튼은 평상시 박스를 제거하고 hover/focus로 조작 가능 상태를 구분한다. 상단의 불필요한 청록 강조도 줄였다.

장전 전후 고정 공간·클릭 영역·탄환 드래그/페이지·발열/재장전 규칙은 보존한다. 카드 외피는 전투에 한정하고 상점·가방의 기존 상세 카드는 무작정 교체하지 않았다. 본편 전투와 저장 분리 시연에 모두 연결했다.

## 검증과 제작 기록

Godot MCP `get_project_info`로 활성4.7 프로젝트를 확인하고 기존 로컬 Godot import/격리 실행 경로를 사용했다. 프로젝트 지침에 따라 현행 docs/direction을 원본으로 사용하며 Impeccable의 PRODUCT.md 부재를 새 기획 원본 생성이나 재승인 요구로 해석하지 않았다. 기존 primary scene은 유지하고 리소스 원본을 직접 열어 보는 `fieldkit_resource_preview.tscn`을 추가했다.

- 실제 UI/연출: 756검사/0실패. 3해상도 대표 전투와 추가1008×630/1440×630의5무기×10장 가방, 카드 제목/효과 폭, 리소스 적용, 사격 모델/RNG 동일성, 즉시 연출을 검사.
- 고정 배치/발열·냉각 회귀: 662검사/0실패.
- 기존 탄환 순환 UI:341검사/0실패. 개별 카드·교환·사격·재장전·10장 페이지.

한 차례 통합 캡처 후 큰 외곽을 탄창에 한정하고, 카드 명찰과 피해 라벨 간격·오른쪽 절삭 모서리의 발열 여백을 수정했다. 원본 이미지를 UI 전체에 통째로 늘리지 않으며 텍스트를 그림에 굽지 않았다.
