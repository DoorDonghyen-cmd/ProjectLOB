# 장비 선택 — 모바일 시작 버튼 노출 진단

2026-11-06. 사용자가 모바일에서 ‘등반 시작’을 누르기 위해 화면 전체를 내려야 한다고 보고했다. 기존 복장 목록 스크롤과 별개인 행동 접근성 문제다. 이번 요청은 확인이며 **본편 씬/스크립트/APK는 바꾸지 않았다**.

## 재현과 원인

Godot MCP로 활성 프로젝트/4.7을 확인하고, 격리 저장의 실제 `redesign/main.tscn` 장비 선택을 네이티브 PC 창에서 실행했다. PC Compatibility/RTX4060Ti 캡처이며 Android 실기기 검증은 아니다. [측정 원본](inspection.json), [출력](stdout.log), [실행 오류 로그](stderr.log).

| 실제 창 | UI 정수 배율 | 논리 높이 | 장비 화면 최소 높이 | 첫 화면의 시작 버튼 |
|---|---:|---:|---:|---|
| 1280×800 | 1 | 800 | 800 | 보임 |
| 1170×540 | 1 | 540 | 617 | y545~599, 화면 밖 |
| 2340×1080 | 2 | 540 | 617 | y545~599, 화면 밖 |
| 2340×960 | 2 | 480 | 617 | y545~599, 화면 밖 |

2340×1080은 기존 S26 비율 검증 크기를 재사용한 것이다. 기기의 실제 가용 화면/설정값을 조회한 수치가 아니다. 2340×960은 높이가 줄어드는 조건 검증이며 특정 시스템 바 크기로 단정하지 않는다.

원인은 전역 배율 오류가 아니라 `equipment_screen.gd::_fit_layout`의 콘텐츠 최소 높이와 하단 행동 줄이 전체 페이지 스크롤 내부에 있는 구조다. 기본 글씨에서 상단48 + 장면336 + 무기 목록113 + 행동54 + 그룹 간격30 + 상하 여백36 = **617**이다. `_loadout_screen()`의 초기620 제한은 후속 `_fit_layout`에서 덮어써지므로 단독 원인으로 지목하지 않는다. 실제 정수 배율은 기존 정책대로1/2로 적용됐다.

[기존1170×540](1170x540_before.png) · [기존2340×1080](2340x1080_before.png). 이전 외형 시안의41검사는 전후 배치 동일성/착장 연동을 검사했으며, 시작 버튼의 최초 노출을 통과 조건에 넣지 않았다. 당시 ‘정상 스크롤 유지’ 설명을 이 문제의 통과 근거로 사용하지 않는다.

## 수정 방향 검토 — 아직 본편 적용 아님

장비/복장 그림과 버튼·폰트 크기를 유지하고 하단 행동 줄만 스크롤과 분리하는 QA 구도를 만들었다. [최초 화면](1170x540_proposal.png) · [아래로 내린 화면](1170x540_scrolled.png) · [PC1280×800 유지](1280x800_proposal.png). 같은 철제/황동 외형 시안을 사용했다.

검토 결과 시작 버튼은 모바일 크기에서 항상 보이고 본문을 내려도 제자리에 남는다. 모든 기존 버튼 크기, PC의 기존 행동 줄 위치, 스크롤 끝에서 무기 목록을 모두 드러낼 수 있는지 등 **81항목 실패0**. [검사 원본](preview.json), [출력](preview_stdout.log), [실행 오류 로그](preview_stderr.log).

다만 하단 고정만 추가하면 첫 화면에서 무기 목록 대부분이 잘린다. 따라서 이 구도를 최종안/본편 수정 완료로 채택하지 않는다. 후속 구현에서는 불필요한 최소 높이와 여백부터 조정하고, 행동 줄을 스크롤 밖에 두면서 총기 목록/장면이 얼마나 보이는지도 함께 확인한다. 전체 Canvas/글꼴을 축소해 맞추는 방식은 제안하지 않는다. 사용자 실시간 착장/복장 목록 스크롤 선호도 유지한다.

`preview.gd`의 CanvasLayer는 구도 검토용 우회이며 정식 구조가 아니다. 정식 구현은 씬에 행동 줄과 본문 스크롤을 분리해 저장하고 포커스/안전 영역/터치/시작·취소/선택 보존/저장을 검증해야 한다. 이번 진단에서 해당 조작과 실기기 통과를 주장하지 않는다. [본편 소스 해시/범위](manifest.json), [진단 재현](inspect.gd), [구도 검토 재현](preview.gd). 외형 도우미는 [이전 시안](../equipment_visual_2026-11-06/material.gd)을 사용했다.
