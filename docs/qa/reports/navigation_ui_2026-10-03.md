# 비전투 UI와 조작 흐름 — 2026-10-03

활성 프로젝트: `worktrees/core-redesign/새-게임-프로젝트` · `prototype/core-redesign` · Godot 4.7.

## 범위와 결정

사용자가 만족한 탄환 카드 디자인을 유지하고 메인·무기 선택·상점·파츠 화면과 조작을 개편했다. 캐릭터·적·배경은 임시 자산을 유지한다. 후속 작업은 **세계관 핵심 정리 → 요소별 레퍼런스 비교 → 통합 시안 → 배우·환경 아트 재작업**으로 등록했다. 산업도시·기계형 적을 사용자 확정 세계관으로 취급하지 않는다.

## 적용 결과

- **메인**: 이름/탄환 조합과 출격 행동을 두 영역으로 나눴다. 저장이 있으면 이어하기가 주 행동이며 기록·설정·규칙은 보조 영역에 둔다. 개발자 연습에서 돌아온 뒤에도 새 등반으로 기존 저장을 교체할 때 확인한다.
- **무기 선택**: 다섯 카드 전체를 터치해 선택한다. 고유 규칙·발사 방식·탄창·재장전과 시작 탄환 그림/수량이 출격 버튼과 같은 화면에 있다. 미리보기는 무기별 실제 덱 및 해금 보급과 일치한다. 난도 조작을 노출하고 시드는 선택 변경 뒤에도 유지한다.
- **상점**: 세 상품과 고정 비교 영역을 나란히 둔다. 선택 시 화면 높이가 늘거나 스크롤이 이동하지 않는다. 파츠의 대가를 상품 카드에도 표시한다. 구매 후 실제 장착/보관 위치와 결과를 같은 화면에서 확인한다. 중복 장비 편집 영역을 제거했다.
- **파츠**: 장착 5칸·보관함·선택 상세를 함께 보여 준다. 코어는 하나라는 제한을 표시한다. 실제 모델로 장착 전후 탄창·재장전 변화를 계산한다. 교체 후보는 유효한 구성만 노출하며 기존 파츠를 보관한 채 한 번에 교체한다. 보관함 자체가 스크롤하므로 모든 파츠에 접근할 수 있다.
- **입력**: 전투 중 장비는 열람만 가능하다. 분해는 게임 안에서 확정/취소한다. 작업실에서 Tab 초점이 순환하고 닫기/Escape 시 이전 행동으로 돌아온다.
- **표현**: 파츠별 픽셀 부품 실루엣과 각진 카드 프레임을 적용했다. 탄환 카드 원본·전투 계산·RNG·저장 버전은 변경하지 않았다.
