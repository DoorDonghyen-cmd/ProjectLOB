# 고열탄·소이탄 통합 — 2026-10-20

기준 `prototype/core-redesign`, HEAD `197c694`. 이전 피드백 검토의 미커밋 문서/열 게이지 변경을 보존하고 이어서 작업했다. 사용자는 높은 발열의 지속 피해탄 방향에 이어 두 계열의 통합을 승인했다. 명칭과 수치는 디렉터 1차 적용값이다.

## 적용 결과

- 고열탄의 열 절반 조건 추가 피해를 폐기하고 **소이탄**으로 통합. 일반은 기본 직접1·화상2×3턴·발열4, 압축은 직접1·화상2×6턴·발열7·1칸이다.
- 압쇄/증강의 화상 피해는 기본의2배인4/턴. 코일/노심은 지속 기간을 늘리며 파츠 문구에도 `턴`을 명시한다. 현재 화상 최대6턴과 기폭·불씨 연계는 유지한다.
- 보호막은 직접 타격을 막지만 화상 부여와 지속 HP 피해를 막지 않는다. 화상은 적 행동 직전이며 재장전 중에도 처리한다. 재충전 보호막 몬스터는 이번 범위에 포함하지 않았다.
- 일반/압축/현장 압축 고열탄의 저장 ID를 대응 소이탄으로 변환한다. 소유 사본 수, 발사/장전 순서, 예약, 압축 취소/사용 시 원본 반환을 보존한다. 별도의 신규 고열탄 획득을 제거한다.
- 오래된 고열 압축은1칸이었다. 통합 압축도1칸으로 두고 발열7을 비용으로 삼아, 가득 찬 기존 장전 저장을 강제로 비우거나 탄을 버리지 않는다. 기존 소이 압축의2칸 제약은 바뀐다.
- 기존 역사 기록의 ID 조회를 위한 별칭은 남기지만 현재 선택/획득은 정식 소이 ID를 사용한다. 캠페인의 `thermal` 보급 해금 ID는 탄 ID와 다르므로 바꾸지 않는다.

## 표시 개선과 발견한 결함

- 손패의 주요 수치를 작은 직접 피해 대신 `화상 / 턴 2`, 보조 수치를 `3턴 지속`, 발열 비용을 별도로 표시한다. 발사 레일도 같은 정보를 우선한다. 산개는 표적을 확정하지 않고 `무작위`와 생존 조건을 남긴다.
- 보호막에 막힌 직접 피해가0이어도 화상이 붙으면 `화상` 팝업과 턴당 피해/기간을 표시한다. 적의 불꽃 옆 숫자에 `턴`을 붙인다.
- 실제 렌더 검수에서 발사 합계가 화상을 누락해 `피해 0`으로 보이는 문제를 확인했다. 실제 예측 사건의 화상 피해를 합산해 `피해 2(화상 2)`로 표시한다. 한 입력에 포함된 강제 재장전의 화상 사건도 수집한다. 선택적 재장전이나 아직 지나지 않은 나머지 지속 턴을 미리 합산하지 않는다.
- 장전된 탄의 상세가 `보유 없음`으로 읽히던 표현을 `이번 발사에 장전됨`으로 구분했다. 상세의 주요 문장에서도 화상과 관통 수치가 뒤섞이지 않게 했다.
