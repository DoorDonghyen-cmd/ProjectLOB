# 물자 거래 단말 2차 시안

이 문서는 외형 변경 전 캡처다. 실행 파일은 [카세트 단말 시안](../shop_terminal_cassette_2026-11-04/README.md)을 연다.

[재고와 현장 기록 나란히 보기](terminal_compare_1280x800.png) · [S26 가로 재고](stocked_2340x1080.png) · [S26 안전 영역 크기의 우수 정원 기록](garden_record_2160x1032.png) · [1차 시안 캡처](../shop_terminal_review_2026-11-04/terminal_compare_1280x800.png)

저장소 루트의 `OPEN_SHOP_TERMINAL_PREVIEW.cmd`를 실행한다. 기본은 축열 주조장이며 F1~F6으로 [각 시안 상태](../shop_terminal_review_2026-11-04/README.md#실행)를 연다. `지도로`를 누르면 지도 단계로 이동하고, `단말 시안 다시 열기`는 처음 거래 상태를 복원한다.

- 상점 화면에서 배관도를 빼고 구역과 장소를 상단에 적는다. 1280×800 기준 단말 폭은 724px에서 1,040px로 늘었다. 기존 탄환·파츠 그림을 재사용하며 목록에서는 작게, 선택 상세에서 크게 보여 준다.
- 《Lethal Company》의 재고와 기록을 한 장치에서 전환하는 구조, 《Alien: Isolation》의 기록 제목과 본문 구분을 참고했다. 각 구역의 기존 원고에 내용에서 가져온 제목을 시안용으로 붙였다. 다섯 구역의 원문은 그대로 표시한다. [선택한 레퍼런스 화면](../../../art/references/2026-11-04-ui/shop-terminal-games.jpg)
- 시안은 별도 Godot 씬이다. 기존 상점 스냅샷으로 재고와 이야기를 구성하고, 거래는 실제 Campaign 기능을 사용한다. 별도의 격리 경로에서 실행한다.

## 검증

`OPEN_SHOP_TERMINAL_PREVIEW.cmd -Capture`로 **673개 검사, 실패 0건**. 1008×454, 1280×800, 2340×1080, 2160×1032에서 배관도 숨김과 단말 폭, 탭 전환 중 구매 선택·잔액 유지, 지도 복귀, 같은 위치의 복귀 버튼을 확인했다. 다섯 구역 원문과 새 제목을 확인했다. 뒤의 세 크기에서는 구매, 품절, 새 진열, 파츠 장착·보관, 탄 교체와 취소, 격리 저장 미생성도 검사했다. S26 크기는 PC GPU 렌더이며 실기기 조작은 확인 전이다.
