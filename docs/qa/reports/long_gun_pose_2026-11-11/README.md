# 양손 총기 조준과 데드볼트 개머리판

양손 총기 6종의 조준·발사 각도를 낮췄다. 조준 때 실측한 두 손의 중간에 총을 배치하고, 반동 중에는 그 손 간격을 유지하며 기존의 뒤로 밀리는 움직임과 작은 총열 들림을 쓴다. 데드볼트 개머리판과 캐릭터가 겹치는 구간은 소매와 어깨가 앞에 오도록 합성했다.

운반복의 같은 전투에서 양손 총기 6종의 조준 각도가 약 16~21°에서 4~5°로, 최대 반동 각도는 약 22~29°에서 6~8°로 낮아졌다. 전투 화면의 총구 섬광과 탄환은 새 총구 위치를 따라간다.
