# 원거리·요격 비교 샘플

2026-10-04 · `prototype/core-redesign` · Godot 4.7.stable. 기존 작업을 보존하고 격리 저장으로 검증했다.

## 실행과 적용 범위

[PLAY_RANGED_SAMPLE.cmd](../../../PLAY_RANGED_SAMPLE.cmd)를 실행한다. `01 공격 예고`는 준비 중인 본체와 근접 전열, `02 탄 요격`은 이미 날아오는 압력탄으로 시작한다. 상단 `일반 +2` / `고출력 +4`는 첫 증폭을 바꿔 같은 편성을 처음부터 비교하는 버튼이다. 나머지 손패와 순서는 자유롭게 수정할 수 있다. `R`로 재시작하고 종료 버튼/Esc로 닫는다.

[ranged_sample.tscn](../../../새-게임-프로젝트/redesign/samples/ranged_sample.tscn)은 보행자로 플레이하는 별도 샘플이다. `save_enabled=false`·`debug_session=true`이며 `qa_runtime/ranged/sample` 아래 APPDATA/LOCALAPPDATA를 사용한다. 캠페인 편성·상점·보상 공급은 유지한다. 새 압력두꺼비는 엔진으로 그린 단순한 시험용 도트 실루엣이며 최종 몬스터 아트가 아니다. 승인된 주인공·배경·탄환 카드를 재사용했다.

## 실제 규칙과 전달

- 본체는 제자리에서 2턴 준비하고 실제 거리에서 압력탄을 발사한다. 샘플 시작 거리는 24m다. 압력탄은 생성 턴에 이동하지 않고 다음 시간 틱부터 6m씩 접근한다. 동시에 본체 한 종·탄 한 개를 다룬다.
- 압력탄은 HP 1·장갑 0. 가장 가까운 위협일 때 다음 탄이 자동 요격하며 동거리에서는 압력탄이 우선이다. 산개도 이 요격은 확정이고, 적이 더 가까우면 기존 적 무작위 표적을 사용한다. 상세 클릭은 조준 변경이 아니다.
- 증폭탄 요격은 다음 두 발을 강화하고 고출력의 과열도 발생한다. 전격 요격은 다른 위협으로 전이한다. 적이 앞에 있어도 전이의 다음 표적이 압력탄이면 요격할 수 있다. 연발의 남는 타격은 다음 적으로 넘기지 않는다.
- 본체를 발사 전에 처치하면 발사를 막지만, 발사 후 처치해도 탄은 남는다. 적·증원·탄이 모두 없어야 승리한다. 본체는 탄이 사라진 뒤 회복 1턴을 소비하고 준비 2턴을 다시 시작한다.
- 압력탄 0m 도달은 이번 실험에서 패배다. 플레이어 HP 피해를 새로 만든 것은 아니다. 무기·파츠·과열을 합한 재장전 시간 동안 실제 이동·발사가 진행하고, 중간에 패배하면 후속 틱을 중단한다.

탄에는 도달 턴을 붙이며 실제 다음 표적이 됐을 때만 `요격`으로 바뀐다. 탄창 예측은 요격과 적 피해를 구별하고, 재장전 후 위협에는 미래 압력탄/발사 카운트를 표시한다. 재장전 실행 중에는 현재 탄의 거리를 보여 준다. 이미 예측되는 피격은 실행 버튼에도 표시한다. 압력탄을 누르면 속도·도달·요격·패배 조건을 열람하고 닫을 수 있다.

기존 모델을 확장했으며 UI 전용 가짜 피해 계산은 없다. 별도 투사체 목록과 증가하는 UID로 적 슬롯·처치 수·증원 인원과 분리한다. 산개 예측은 실제 분기별 표적·상태를 계산하고 투사체와 발사 카운터를 캐시에 포함한다. v8 저장의 새 필드 누락은 빈 상태로 읽고 잘못된 상태는 라이브 저장을 바꾸지 않고 거부한다.

새 규칙 검사는 다섯 총기, 화상으로 본체 사망, 탄만 남음, 준비 중 처치, 전이의 주/보조 요격, 증강 연속 사격, 쇄도 적중 분리, 압축 첫/끝 제약, 선두·후미 파츠, 긴 재장전, 밀린 본체의 발사 거리, 증원 중 안정 ID와 다음 발사 UID, 산개 48시드의 실제 결과/예측 범위, 실제 파일 저장·복원을 포함한다.

UI는 1280×900·1280×800·1008×630·1440×630에서 검사했다. 네 적+압력탄, 상세 열기/닫기, 본체 사망 후 남은 탄 요격, 사전 경고와 실제 피격, 재시작, 정상 속도의 발사/요격 프레임을 확인했다. 실제 카드 버튼과 발사/재장전으로 두 전투 모두 완주했다.

첫 전투는 기본 조합 사격과 재장전 뒤 `전격 → 고출력 증폭 → 연발 → 소이`로 완료했다. 두 번째는 고출력 시작 조합·재장전 뒤 `일반 증폭 → 연발 → 연발`로 두 번째 탄까지 요격하며 완료했다. 후속 경로는 실제 모델 탐색으로 찾은 뒤 공개 UI 입력으로 재생했다. 탐색은 미래 패를 아는 통제 검사이며 사람의 첫 플레이 승률이 아니다. [후속 경로 JSON](ranged_2026-10-04_assets/ranged_ui_paths.json).

격리 환경의 Windows 인증서 저장소 메시지(`Failed to read the root certificate store`)는 별도로 남았으며 최종 실행의 스크립트/파싱 오류와 검사 실패는 0이다. [규칙 로그](ranged_2026-10-04_assets/ranged_rules_runner.stdout.log), [UI 로그](ranged_2026-10-04_assets/ranged_ui_runner.stdout.log), [실행 환경 stderr](ranged_2026-10-04_assets/ranged_ui_runner.stderr.log).

재현 명령은 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/ranged_sample.ps1 -Rules`와 `-Capture`다. 같은 도구를 인수 없이 실행하면 플레이 창을 연다.

캡처를 직접 확인해 준비·비행·요격·도달을 구별하고 고정된 적 정보/카드와 겹치지 않는지 점검했다. 시험용 본체의 작은 도형 실루엣과 상세창의 기존 기본 스타일은 정식 아트 품질로 판정하지 않는다. 연출의 추가 폴리싱은 사용자 지시대로 후속이다.

남은 핵심은 요격이 매번 같은 첫 탄을 넣는 부담으로 굳는지, 일반/고출력과 전이 중 선택이 읽히는지의 사람 플레이다. 결과에 따라 공격 간격·도달 속도·편성 빈도를 조정한 뒤 캠페인과 정식 몬스터 아트를 연결한다. 실제 Galaxy 입력·성능, 다른 무기의 원거리 플레이 화면, 장기 밸런스는 이번 검사로 완료를 주장하지 않는다. APK·커밋·푸시는 수행하지 않았다.
