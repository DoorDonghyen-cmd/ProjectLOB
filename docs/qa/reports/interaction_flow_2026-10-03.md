# 조합 편집과 선택 결과 전달 개선

2026-10-03 · `prototype/core-redesign` · 실제 Godot 4.7 OpenGL UI.

[앞선 화면 검토](interaction_flow_review_2026-10-03.md)의 우선 문제를 구현했다. 사용자 제안의 세로 순서·30% 확대·민트색을 고정 규칙으로 적용하지 않았다. 전장·발사 순서·손패의 동시 노출과 승인된 탄환 카드 형태를 유지한다.

## 변경

- **이번 발사와 전체 탄창:** 전장의 기본 HP 예측·요약은 다음 발사 한 번을 기준으로 한다. 증강의 발사 버튼도 실제 다음 발사에서 나갈 수량을 표시한다. 여러 번 발사해야 하는 탄창은 `전체 N턴 보기`로 별도 비교하며, 레일의 후속 탄에 몇 번째 발사인지 표시한다. 산개는 기존의 확률·범위 예측을 유지한다. 증강의 처치 연쇄 조건을 무기·도움말·전투에 맞춰 설명했다.
- **고정 손패:** 장전한 탄환은 원래 자리에 어둡게 남는다. 두 사본 중 실제 누른 카드가 사용 상태가 되며, 다른 카드가 당겨지지 않는다. 압축과 확정 전 취소도 손패 위치를 유지한다. 새 교전·재장전·패 교환은 새로운 손패 구성 시점이다.
- **탄창 편집:** 슬롯 탭은 선택이다. `앞으로/뒤로`, `선택 회수`, `끝 탄 회수`, `탄 상세`를 분리했다. 터치 드래그로도 순서를 옮긴다. 앞/뒤 고정 압축탄의 조건은 이동 검증에 포함한다. `끝 탄 회수`는 순서를 옮긴 뒤에도 오른쪽 마지막 탄을 회수한다.
- **상세와 확정:** 계산은 별도 창으로 열려 전투 화면의 높이를 밀지 않는다. 확정 후에도 같은 상세 버튼을 사용할 수 있다. 확정은 기존처럼 0턴이며, 이후 변경에는 남은 탄을 버리고 재장전 비용을 지불한다. 비용을 확정 버튼 곁에 표시했다.
- **파츠:** 교체 영역에 얻는 효과·새 대가·잃는 효과·해제되는 대가와 최종 탄창/재장전 변화를 함께 표시한다. 교체 예정 장착 파츠의 테두리를 연결한다. 기존 파츠가 보관되는 원자적 교체와 분해 확인은 유지한다.
- **상점:** 상품의 하단 구매 버튼을 가격/구매 상태로 바꾸고, 고정 비교 영역의 구매 버튼으로 동선을 모았다. 맵 이동을 보조 강조로 바꿨다. 구매 후 잔액·자동 장착·보관·판매 완료 처리는 유지한다.
- **출격 준비:** 무기·시작 보급·출격을 기본 화면으로 둔다. 시드와 난도 입력은 `등반 설정`에 접으며 설정한 난도는 닫아도 표시한다. 시작 탄환은 카드 전체를 눌러 효과를 확인한다.

전투 피해 규칙, RNG, 탄환 자원, 재장전 비용, 저장 형식은 유지했다. 모델에는 유효한 계획 순서 이동 명령을 추가했으며 실제 예측은 복사 모델의 발사 명령으로 계산한다. 배우·배경 이미지와 세계관은 이번 작업에서 재제작하지 않았다.

작업 중 작은 화면 세로 넘침과 초기 드래그 입력 실패를 확인했다. 조작부 여백/높이를 조정하고 레일 내부 드래그를 포인터 입력으로 처리한 뒤 다시 통과했다. 최종 마감의 시작 탄환 전체 터치·난도 상태 갱신·끝 탄 회수는 interaction/navigation/frontend로 재확인했다. 실행 환경의 루트 인증서 저장소 경고는 남지만 스크립트 오류나 검사 실패는 없다.

실행 로그와 최종 소스 해시는 자산 폴더에 보존했다. 자동 성공 횟수는 가독성·재미 점수가 아니다. 실제 Galaxy의 손가락 조작·프레임 성능, 처음 플레이하는 사람의 다음 행동 이해도는 추가 확인이 필요하다.
