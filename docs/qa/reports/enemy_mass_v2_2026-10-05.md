## 유지한 판독 요소

- 돌진체의 네 다리/긴 몸, 장갑체의 넓은 흉부, 기동체의 긴 목/다리.
- 충전체의 마름모/주황 센서, 흡수체의 원형 몸/청록 중심, 태세체의 낮고 넓은 쐐기.
- 압력두꺼비의 낮은 유기체 실루엣과 준비 상태에 따라 커지는 황토색 목주머니.

색뿐 아니라 외형으로 역할을 구별한다. 작은 화면에서 가는 선의 강조가 줄고 주인공과 같은 명암 범위로 보이는 것을 직접 확인했다. 새 세계관 목록의 종별 디자인/이름을 구현한 작업은 아니며, 적 v2에 대한 별도 사용자 시각 확인은 아직이다.

## 자산과 배치

내장 `image_gen.imagegen`으로 각 적 v1을 편집하고 주인공 v2와 주거구 배경을 참조했다. [자산 폴더 설명](../../../새-게임-프로젝트/assets/art/actor_cohesion_20261005/README.md), [전체 프롬프트 경로·생성 출처·해시](../../../새-게임-프로젝트/assets/art/actor_cohesion_20261005/provenance.json).

새 PNG 7개는 원본과 바이트/SHA-256이 같다. 6종은 1254×1254 RGBA, 개구리 아틀라스는 1774×887 RGBA다. 원본/v1/확정 주인공을 보존했다. PNG 픽셀의 별도 후처리 없이 Godot 영역과 표시 크기로 통합한다. 생성 결과의 정확한 논리 해상도·고정 팔레트 준수를 단정하지 않는다.

`actors.tres`와 `ranged_battle_view.gd`에서 새 자산을 참조한다. 다른 적의 표시 높이, 기존 발/부유 앵커, 피격/이동 오프셋을 유지했고 가로 폭은 원본 비율에 맞췄다. 모든 증원 아이콘도 같은 자산을 사용한다.

개구리의 두 생성 프레임에는 약40 원본 픽셀의 가로 배치 차이가 있었다. PNG를 수정하지 않고 팽창 프레임의 소스 원점을 보정했다. 수축 영역 `(131,301,729,485)`, 팽창 영역 `(978,301,729,485)`, 표시 크기98×67이다. 두 프레임의 발 바닥은 원본 y784로 같으며, 비교 캡처에서 목 팽창 시 몸이 옆으로 밀리는 현상을 방지했다. 준비/차단/발사 상태는 기존 모델을 그대로 따른다.

## 검증과 범위

- 격리 APPDATA/LOCALAPPDATA, 저장 비활성 본편으로 실제1280×900·1008×630·1440×630 검사: **350검사/0실패**. [stdout](enemy_mass_v2_2026-10-05_assets/stdout.log), [stderr](enemy_mass_v2_2026-10-05_assets/stderr.log).
- 화면 경계/스크롤, 전체7종의 명찰 간섭·중심 선택·발 기준, 증원 아이콘, 공개 버튼의 장전→준비→발사→요격 및 차단 정지를 확인했다. 표시 적/공격체와 실제 모델 상태가 일치한다.
- Godot import/실행에서 스크립트 오류 없음. 기존 환경의 Windows 인증서 저장소 경고만 동일하다. 기능 통과와 사람의 시각 선호는 구분한다.
- 이번 변경은 자산과 영역 배치다. 규칙·전투 수치·사용자 저장은 변경하지 않았다. 신규 프레임 애니메이션, APK, 커밋, 푸시는 수행하지 않았다.

실행: [PLAY.cmd](../../../PLAY.cmd). 검증 재실행: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/run_actor_cohesion_checks.ps1`.
