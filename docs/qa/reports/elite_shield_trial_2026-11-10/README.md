# 수석 시종 차폐 비교

## 본편 적용

사용자가 선택한 B안을 귀족 거주구의 수석 시종 전투에 연결했다. 닫힌 차폐 3칸은 철갑 계열로 타격당 2칸씩 줄일 수 있다. 닫힌 상태에서 적이 두 번 행동하면 남은 차폐가 열리고, 적 행동 3회 뒤에 차폐가 복구된다. 새로 진입한 수석 시종 전투에서 이 규칙을 사용한다. 이미 시작한 교전은 당시의 차폐 규칙과 상태를 이어간다.

본편의 실제 6기 편성에서 [개방까지 1행동](campaign_guard_1008.png)과 [본체 노출·재차폐 3턴](campaign_open_1008.png)을 수석 시종 HP 카드 위에 표시한다. 개발 메뉴의 ‘귀족 거주구 · 수석 시종’에서도 들어갈 수 있다.

격리 저장에서 전용 규칙 165개와 화면·조작 126개를 통과했다. 이미 시작한 교전의 이전 저장과 개방까지 1행동이 남은 새 저장을 각각 복원했다. 실제 편성에서 사격과 냉각으로 개방을 확인했고, 1280×800과 1008×454에서 차폐 표시가 수석 시종 HP 카드 위에 오는지 확인했다. 기존 귀족 거주구 947개, 표면 효과 322개, 적 위협 2,045개 검사도 통과했다.

시드 `731042`의 전체 등반 검사에서 수석 시종에게 도달한 네 무기가 4구역 2층과 6층 정예전을 각각 클리어했다. 여덟 교전 모두 실제로 획득한 철갑탄 없는 덱을 썼다. 리벳 경로는 그보다 앞선 2구역에서 전투 저장 복원 검사에 실패했다. 전체 등반 검사 로그는 `qa_runtime/playtest_rework_20261103/climb_elite_shield_live/stdout.log`에 있다.

## 적용 전 A/B 비교

[PLAY_ELITE_SHIELD_TRIAL.cmd](../../../../PLAY_ELITE_SHIELD_TRIAL.cmd)를 열고 A 또는 B를 선택하면 귀족 거주구의 수석 시종 전투가 시작된다. 두 안 모두 리벳, 같은 배경과 적 배치, 기본탄–기본탄–철갑탄–연타탄–철갑탄–기본탄 순서로 시작한다. 비교 전투는 별도 저장 경로를 쓰며 다시 실행할 때 첫 상태에서 시작한다.

| 안 | 차폐 3칸을 여는 방법 | 비교할 선택 |
|---|---|---|
| A · 철갑 약점 | 일반 타격은 1칸, 철갑은 2칸을 깎는다. | 철갑을 앞당겨 노출시키거나, 기본탄·연타탄으로 열고 철갑을 본체에 쓴다. |
| B · 철갑 전용 | 철갑 타격만 2칸을 깎는다. 차폐가 유지되면 두 번째 적 행동 끝에 스스로 열린다. | 철갑으로 일찍 열거나, 냉각·탄창 교체로 노출을 기다린다. |

두 안 모두 노출이 시작되면 적 행동 3회 동안 열리고, 이후 차폐가 돌아온다. 사격으로 열면 그 사격 뒤의 적 행동도 노출 시간에 포함된다. A를 우선 후보로 둔다. 철갑에 빠른 파훼 역할을 주면서도 탄창 구성에 따라 기본탄·연타탄을 쓰는 선택이 남는다. 수석 시종 한 전투에서 두 안을 비교한 뒤 적용 범위를 판단한다.

## 실제 전투 화면

같은 첫 기본탄 사격 뒤 [A는 차폐 2칸](guard_weak_1008.png), [B는 차폐 3칸과 노출까지 1행동](guard_strict_1008.png)을 표시한다. B에서 이어서 냉각하면 [차폐가 열리고 재차폐까지 남은 시간이 표시된다](open_strict_1008.png).

## 검증

- 전용 규칙 검사 145개와 실제 화면·조작 검사 86개가 통과했다. 1280×800과 1008×454의 PC 창에서 사격·냉각과 상태 표시를 확인했다.
- 철갑 없이 기본탄만 든 덱으로 B 전투에서 승리했다. 차폐 예측과 실제 결과, 노출 직전 상태의 저장·복원, 재차폐도 확인했다.
- 기존 귀족 거주구 규칙 947개, 표면 효과 322개, 적 위협 2,045개, 잔해 규칙 184개가 통과했다. 체감 난이도와 모바일 실기기는 후속 확인 범위다.
