- 밝은 갈색/베이지 몸체를 어두운 회녹색 금속(`#2c3530`·`#626b60`)으로 낮추고, 표시에는 아이보리(`#dfd8ba`), 선택/구매에는 절제한 황동을 사용했다. 정비소의 어두운 금속·조명과 전장의 저채도 산업 배경을 기준으로 조정했다. 지역별 상품 그림·서사는 그대로 동작한다.
- 보유금은 별도 단말기 계기에 밝은 아이보리32px로 유지하고, 결제 후 잔액/부족 금액도32px로 강조했다. 공통 픽셀 글꼴 규격의24px 요청은16px로 정규화되어 시각 차이가 없었으므로32px 단계를 사용했다. 재화 부족에는 위험색과 부족 금액을 함께 표시한다.
