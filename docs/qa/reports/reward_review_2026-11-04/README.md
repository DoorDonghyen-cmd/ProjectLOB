# 전투 보상 Godot 시안

전투가 끝난 장소와 캐릭터를 화면에 남기고, 하단에 실제 전리품을 펼친다. 후보를 고르면 옆에서 효과·대가·현재 주력 탄과의 관계를 읽고 회수한다. 전리품은 처음 등장할 때 약 0.26초 동안 밝아진다. 확정 화면은 아직 시안 단계다.

## 실행

`OPEN_REWARD_REVIEW.cmd`를 실행한다. 후보 확인과 회수는 클릭 또는 터치로 조작한다.

- **F1 정예 격파.** 제3 격발기와 확장 탄창 중 하나를 비교한다. 제3 격발기의 세 번째 발 직접 피해 배율과 현재 주력인 연타탄 보유 수를 함께 보여 준다. 크레딧이나 보류도 선택할 수 있다.
- **F2 탄약 가방 32/32.** 받을 탄을 고르고 내보낼 탄을 선택한다. 후보는 한 페이지에 세 장씩 보이고, 오른쪽 두 줄에서 받을 탄과 내보낼 탄의 피해·발열·보유량 변화를 같은 위치에서 비교한다. `Esc`와 `후보로 돌아가기`는 교체를 취소한다.
- **F3 성장 코어.** 첫 전투에서 코어를 고른 뒤 주력 탄 2장과 지원 탄 1장 묶음을 선택한다. 실제 적용되는 효과와 대가를 표시한다.

## 레퍼런스에서 가져온 점

- 《Darkest Dungeon》의 전리품 화면처럼 전투 장소와 캐릭터를 남겨 승리에서 획득까지 같은 장면으로 느끼게 했다. [전투 전리품 캡처](https://www.gamegrin.com/assets/games/darkest-dungeon/screenshots/_resampled/croppedimage1201631-darkest-dungeon-screenshot-11.jpg)
- 《Shogun Showdown》 개발 기록의 효과 설명과 보상 보류를 참고해, 물건을 먼저 고른 뒤 결과를 확인하도록 했다. [Roboatino 개발 기록](https://roboatino.itch.io/shogunshowdown/devlog/404183/shogun-showdown-alpha-v02-map-challenges-and-more-wishlist-on-steam)
- 《Hades》의 효과·대가 읽는 위치와 《Slay the Spire》의 후보 선택 흐름을 참고했다. 시안의 배경, 캐릭터, 탄환, 파츠는 프로젝트 아트를 사용한다. [기존 비교 보드](../../../art/references/2026-11-04-ui/index.html)

## 검증 범위

`OPEN_REWARD_REVIEW.cmd -Capture`로 Godot 4.7에서 140개 검사를 통과했다. 세 크기에서 장면과 패널의 경계, 키 전환, 터치 회수, 보류·크레딧, 후보 페이지 이동, 교체 취소와 1대1 교체, 첫 코어→주력 탄 묶음을 확인했다. 2026-11-05 F2 수정 전후 F1·F3의 화면 여섯 장은 이미지 해시가 일치했다.

시안은 실제 전투 노드에서 승리 상태를 재현하고 Campaign의 보상 후보·획득 규칙을 실행한다. 데이터는 시안 세션에만 있다. 본편 진입, 실전에서 보상으로 넘어가는 연출, 보스 보상, Android 실기기는 본편 연결 단계의 검증 범위다.
