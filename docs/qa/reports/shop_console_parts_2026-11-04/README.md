# 상점 CRT 단말의 파츠 장착 시안

[교체 비교와 장착 완료 나란히 보기](mount_compare_board_1280x800.png) · [교체 비교](mount_compare_1280x800.png) · [작은 가로 화면](mount_compare_1008x454.png) · [S26 안전 영역 크기](mount_compare_2160x1032.png)

`OPEN_SHOP_CONSOLE_PREVIEW.cmd`를 열고 `F4`로 장착대가 찬 예시를 선택한다. 가속 총열을 구매하고 화면 하단의 `파츠 장착`을 누른다. 보관함에서 가속 총열이 선택되어 있다. 장착대 2번의 열축전 코일을 누르면 교체할 대상과 얻고 잃는 효과를 확인할 수 있다. `교체 장착`을 눌러 적용하거나 오른쪽 `재고` 키로 돌아간다.

왼쪽에는 장착 슬롯 5개와 보관함을 둔다. 오른쪽에서 선택한 파츠의 효과와 장착 결과를 보여 준다. 빈 슬롯에 장착할 수 있을 때는 장착, 이미 장착한 파츠는 해제, 교체가 필요할 때는 기존 규칙에 맞는 슬롯만 선택할 수 있다. 교체 대상을 고르기 전에는 확정 버튼이 잠긴다. 교체 시 기존 파츠는 보관함으로 돌아간다.

실제 `Campaign.buy`, `equip`, `replace_part`와 효과 계산을 사용한다. 시안에서는 격리된 등반 기록을 메모리에서 사용한다. 확정된 것은 옆 조작기와 CRT 외형 방향이며, 파츠 배치와 조작은 이번 검토용 씬에 연결했다. 본편 상점 진입과 저장 연결은 후속 통합 범위다.

`OPEN_SHOP_CONSOLE_PREVIEW.cmd -Capture`에서 **1,009개 검사, 실패 0건**. 1008×454, 1280×800, 2160×1032에서 구매 후 보관, 보관 파츠 사전 선택, 코어 교체 제한, 슬롯 선택 전 확정 잠금, 취소, 실제 교체, 잔액 유지, 해제 후 재장착을 터치 이벤트로 확인했다. 상점의 기존 화면·거래·CRT 회귀 검사도 포함된다. S26 가로 크기는 PC GPU 캡처다.
