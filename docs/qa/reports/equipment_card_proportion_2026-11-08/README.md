# 장비 선택 카드 비율과 버튼 상태

사용자 플레이 후기의 무기·복장 비율과 버튼 통일감을 장비 선택 화면부터 반영했다. 기존 철제·황동 장비실에서 카드 안의 그림과 상태 표현을 조정했다.

| 화면 | 수정 전 | 수정 후 |
|---|---|---|
| PC 1280×800 | [캡처](before_1280x800.png) | [캡처](after_1280x800.png) |
| 모바일 가로 비율 1170×540 | [캡처](before_1170x540.png) | [캡처](after_1170x540.png) |
| 짧은 가로 창 844×390 | | [고정 출발과 선택 영역](after_844x390.png) |

- 아래 총기 그림은 공용 150×40 상한, 왼쪽 큰 그림은 298×106 상한 안에서 원화 비율로 중앙에 맞춘다. 폭이 좁아지면 그림이 받침 안에서 자연스럽게 작아진다.
- 복장 아이콘은 G안의 상반신 32×26을 정확히 두 배로 표시한다. 좁은 카드에서는 긴 이름을 최대 두 줄로 읽을 수 있다.
- 주 행동은 황동, 보조 행동은 철제 면이다. 선택은 황동 모서리, 일반 호버는 중립 테두리, 훈련 잠금은 잠금 기호와 어두운 그림을 쓴다.
- 같은 세 총기와 여섯 창 크기로 수집한 18개 상태에서 카드·중앙 착장·행동 줄의 외부 기하와 가운데 스크롤 범위의 기록이 동일했다. 모바일 비율은 PC에서 렌더링했다.
- 장비 검사 6,142개와 총기 UI 검사 151개를 통과했다. 7×7 실제 선택·출발·저장 복원, 6크기·3글자 설정, 짧은 창 이름 줄바꿈과 고정 출발, 훈련 잠금을 확인했다. [훈련 잠금 캡처](training_locks.png)
