# 전투 파츠·탄환 발동 연출

전장 왼쪽의 사격 결과 칸에서 실제로 작동한 파츠와 해당 탄환의 아이콘이 잠깐 커졌다 제자리로 돌아온다. 강화가 적용된 타격은 같은 타이밍에 피해 숫자도 한 번 더 커진다. 여러 효과가 겹치면 최대 세 아이콘을 표시하고 나머지는 숫자로 표시한다. 증폭을 준비한 지원탄과 증폭을 받아 적중한 탄은 각각 표시된다. 연출을 줄인 상태에서도 아이콘과 문구는 같은 위치에 고정된다.

세 번째 발의 복수 파츠·증폭 적용, 같은 연발의 증폭 준비와 적용, 기본탄, 차폐에 전부 막힌 첫 발, 뒤쪽 적이 없는 전격탄을 확인했다. 본편 전투 버튼으로 실행한 결과를 같은 입력을 받은 전투 모델과 비교했다. 1280×800과 1008×454는 PC에서 렌더링했으며 모바일 실기기와 플레이 체감 검증은 별도다.

- [세 번째 발의 복수 발동](stacked.png) · [증폭 준비](boost_ready.png) · [같은 연발의 증폭 적용](boost_applied.png)
- 발동·적중 규칙 241개, 실제 화면 480개, 전이·표면 연출 규칙 322개, 빌드 규칙 643개 통과. 실제 화면에서 아이콘 확대·복귀, 연출 축소 시 고정, 짧은 화면에서 HP 카드와 피해 숫자 분리를 확인했다.
- 별도 캠페인 장기 검사는 해당 실행에 필요한 등반 경로 결과 파일이 없어 중단됐다.
