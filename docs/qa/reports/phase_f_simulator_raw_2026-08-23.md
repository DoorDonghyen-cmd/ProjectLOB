# Phase F 전투 시뮬레이터 원본 보고

> 역할: `12-combat-simulator`
> 입력: 현 전투 코드·전투 회귀·최근 인간 플레이 로그
> 독립성: 기능·경험 QA 결론 없이 읽기 전용으로 작성

## 판정

| 항목 | 판정 | 근거 |
|---|---|---|
| `ACC >= EVA` | PASS | 인간 로그 16발 대조, 불일치 0 |
| 이진 관통 `PEN < DEF ? 0 : DMG` | PASS | 관통 로그 15건 대조, 불일치 0 |
| LIFO 탄창 | PASS | 단위 테스트 C→B→A, 실제 CombatManager 고정 전투 |
| 고정 전투 왕복 | PASS | 2발 전투 승리와 단계 계약 통과 |
| 최소 거리 | PASS | 3전 모두 요약 8m, 전진 로그와 일치 |
| 리로드 | PASS | 3전째 1회/1턴, `14 - 1×1 = 13m`와 실제 13m 일치 |
| 인간 로그 과잉 피해 재산출 | PASS | 2+1+1 = 4 피해 |
| 일반 과잉 피해 자동 계측 | 계측 결손 | 생산 로그에 `overkill_damage` 생성자가 없고 합성 테스트에만 존재 |
| 실데이터 넉백 무한 락 | 근거 부족 | 탐지 스모크는 통과하나 sim harness가 리로드를 모델링하지 않음 |

전체 회귀는 `3,562 통과 / 0 실패 / 기존 경보 3`, 종료 코드 0이다.

## 경계와 결론

- UI sample A/B는 전투 버그 판정에서 제외했다.
- 초과 PEN 무보너스, 도탄 0피해, 발사·리로드 중 적 전진, 집중 3회 보너스, 빗나간 탄 소멸은 정상 규칙이다.
- 인간 로그만으로 LIFO를 증명할 수 없어 단위 테스트와 고정 전투를 근거로 사용했다.
- 현재 전투 정산의 확정 버그는 0건이다. 과잉 피해 필드와 넉백 락 실데이터 판정은 기능 결함이 아니라 후속 계측 개선 후보이다.
