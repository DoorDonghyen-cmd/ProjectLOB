# 파츠 장착과 강화 사격 연출

파츠 장착과 교체가 성공하면 선택한 부품의 아이콘이 실제로 바뀐 슬롯으로 이동하고, 도착할 때 슬롯 테두리와 짧은 불빛이 반응한다. 상점에서 구매와 함께 빈 슬롯에 자동 장착되면 단말기의 파츠 장착 키에 확인을 표시한다. 해제한 부품은 보관함에서 표시한다. ‘즉시’에서는 테두리를 고정해서 표시한다.

[장착 중](install_travel.png) · [슬롯에 들어간 순간](install_seated.png)

발동한 파츠의 배지가 짧게 커지고 테두리에 불빛이 들어온 뒤 원래 크기로 돌아온다. 총기 내장 구동은 장착 파츠 배지에서 제외한다. 강화 사격은 실제로 적용된 가산·배율·연타에 따라 총구, 궤적, 적중을 구분한다. 태그 배율도 해당 탄의 연출에 반영하고, 차폐에 전부 막힌 탄과 요격에는 강화 적중을 표시하지 않는다.

[태그 배율 적용 탄 궤적](tag_multiplier_flight.png) · [단타 배율기와 복제 기판 발동](tag_multiplier_contact.png) · [짧은 화면의 복수 발동](stacked_contact_1008x454.png)

격리 저장에서 상점 조작 234개, 빌드 작업실 105개, 전투 화면 544개, 발동·탄 궤적 규칙 254개와 777개를 통과했다. 장착·교체·자동 장착을 실제 입력으로 검증했다. 전투 결과는 같은 입력의 전투 모델 및 난수 상태와 일치했다. 비교 시나리오에는 기존 등반의 단일 강화와 현행 등반의 태그 파츠를 각각 사용했다. 화면은 PC Godot에서 렌더링했다. 모바일 실기기와 플레이 체감은 미확인이다.
