# 전투 보상 본편 적용

`PLAY.cmd`에서 도전을 시작하거나 현행 지도 저장을 이어가고 전투에서 승리하면 새 보상 화면이 열린다. 시안과 본편은 `redesign/rewards/screen.tscn`을 함께 사용한다.

- 첫 전투는 성장 코어와 주력 탄 묶음의 두 단계를 표시한다. 정예 파츠는 획득 시 장착되는지 보관되는지 미리 보여 준다.
- 보유 탄과의 교체는 선택과 확정을 나눈다. 가방에 여유가 있으면 바로 추가하거나 보유 탄과 교체할 수 있다.
- 보스가 지급한 크레딧은 수령 내역으로 표시한다. 보스 전리품을 선택하거나 보류하면 다음 관문으로 이동하고, 최종 보스에서는 정상 복구로 넘어간다.
- 교전 기록과 상세, 빌드·기록실·설정·타이틀은 보상 화면에서 연다.

## 검증

- `tools/run_reward_live_checks.ps1` 104개 통과. 실제 전투 노드에 진입한 뒤 종료 상태를 재현해 정예, 일반, 보스를 검사했다. 파츠 선택과 회수, 교체 취소와 1대1 교체, 창 크기 변경 후 선택 유지, 저장 복원, 구버전 지도 보상 진입, 관문 및 최종 정상 복구를 확인했다.
- `tools/run_focus_build.ps1 -Mode ui -Label reward_live` 80개 통과. 본편 첫 전투를 실제 입력으로 클리어하고 코어와 주력 탄 묶음을 회수했다. 보상 이후 탄 목록과 난수 상태가 저장에서 일치했다.
- `OPEN_REWARD_REVIEW.cmd -Capture` 140개 통과. `tools/run_prototype_hud.ps1` 기본 모드 11,536개 통과.
- Godot MCP로 활성 프로젝트와 엔진을 확인했고, 실제 실행과 캡처에는 Godot 4.7을 사용했다. Galaxy S26 크기 검사는 PC에서 실행했다. 실제 기기의 터치 및 안전 영역은 미확인이다.
