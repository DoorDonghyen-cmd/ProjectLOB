# 초반 편성별 선택과 행동 압박 — 2026-10-14

## 결정과 적용

사용자가 선택의 재미와 선택을 재촉하는 접근을 논의하고 실행을 승인했다. 디렉터 적용안은 실시간 제한 없이 **행동을 소비했을 때 변하는 위협**을 읽게 하는 것이다. 새로운 자원이나 매 전투 추가 제한 시간을 넣지 않았다. 아래 수치는 검증용 현행 구현이며 최종 밸런스/사용자 체감 확정은 아니다.

- 첫 지역 첫 전투와 조합 안내는 유지한다.
- 진행 깊이2: 장갑3/HP7의 처마등 + HP5 숨접이. 증폭·철갑으로 빨리 뚫거나 소이·충격으로 시간을 쓰는 대응을 구분한다.
- 깊이3의 전투: HP4 숨접이 + HP6 압력두꺼비. 기존2행동 준비 규칙을 초반에 노출. 발사 전 본체 처치와 발사 후 기본탄 요격 모두 가능하다. 같은 줄의 비전투 분기는 유지하므로 반드시 만나는 전투는 아니다.
- 깊이4/5 중 전투가 배치된 줄: 전열4 + 증원2. 서비스 줄은 시드별4 또는5이므로 두 깊이에 같은 편성을 적용한다. 열이 남은 다음 탄창과 냉각 순서가 의미를 갖도록 길이를 늘린다. 깊이6 이후·관문·상위 지역은 유지한다.
- 깊이2 보상 후보에 파쇄·차단·우회, 깊이3/4 후보에 냉각·차단·우회를 일찍 포함한다. 해당 탄의 획득을 강제하거나 확정 보상으로 지급하지 않는다.
- 두꺼비의 준비 표시는 조준 아이콘 옆 `2턴/1턴`. 재장전 버튼은 실제 재장전 결과에 따라 `적 발사`, `압력탄 임박`, `피격 위험/접촉 위험`을 표시한다. 경고가 없을 때는 냉각량. 열 전후 수치와 적 행동 턴은 항상 두 번째 줄에 남긴다.
- 경고는 문자열 유추 대신 실제 복제 모델의 재장전을 실행해 계산한다. 화상 사망·차단·쇄도2턴·기존 압력탄 이동을 포함한다. 예측은 원본 상태/RNG를 변경하지 않는다. 두 줄 높이 유지, 경고색이 최종 픽셀 스킨에서도 유지되도록 의미 메타데이터를 연결했다.
- roster_version2 유지. 저장된 진행 중 전투는 복원 그대로이며, 이후 새로 생성되는 첫 지역 편성에 적용한다. 마커 없는 이전 저장과 roster_version1, 상위 지역은 기존 편성이다.

## 기능 검증

모든 실행은 qa_runtime 아래 격리 APPDATA/LOCALAPPDATA, UI 저장 비활성으로 진행했다.

| 검사 | 결과 |
|---|---|
| `tools/run_residential_checks.ps1 -Mode rules` | 4,461 검사, 실패0 |
| 같은 명령 `-Mode ui` | 592 검사, 실패0 |
| `tools/run_heat_checks.ps1 -Mode rules` | 783 검사, 실패0 |
| `AUDIT_ENCOUNTERS=decision` + `tools/run_early_ammo_checks.ps1 -Mode audit -AuditTag decision_final` | 실제 시작 덱/정찰복4장, 6시드×3편성×5총기, 정책162회, 실패0 |

집중 시나리오는 일반 증폭→철갑→기본으로 장갑 표적을1턴에 제거하는 경로와 소이→충격→기본→기본 후 두 번의 재장전으로3턴에 제거하는 경로를 확인했다. 두 경로는 카드 수와 열/시간 비용이 다르다. 원거리 편성은 일반 시작 탄 조합으로 발사 전에 처치할 수 있고, 실제 발사 후에는 특수탄 없이 기본탄으로 요격 가능했다.

증원 편성에서 열2로 시작한 동일4장 비교: 증폭→연타→철갑→냉각은3발 후 과열되어3턴, 증폭→연타→냉각→철갑은4발/1턴/잔열9. 시작 열은 재현용 fixture이며 전체 등반 통계와 구분한다. 기존 발열 검사가 재장전 잔열과 강제 냉각을 별도로 검증한다.

## 자동 정책 비교와 한계

각 편성은 성장 없이 독립 시작한다. 무작위 정책은 실제 패에서 순서를 무작위로 고르고 용량만큼 채운다. 비교 정책은 합법적인 부분/전체 순서를 열거해 현재 결과를 평가하며 최적 전략이나 사람 플레이를 대표하지 않는다. 산개는 무작위 정책만 검사했다. 모든162회가 생존했다.

증원 편성 평균 소모 턴(각6시드):

| 총기 | 무작위 장전 | 결과를 평가한 선택 |
|---|---:|---:|
| 보행자 | 7.50 | 5.00 |
| 쇄도 | 10.00 | 7.50 |
| 압쇄 | 6.00 | 5.17 |
| 증강 | 9.33 | 6.00 |
| 산개 | 8.00 | 비교하지 않음 |

시간 효율 차이는 확인했으나 무작위 장전도 전승하므로 **선택의 재미·난도 문제가 해결됐다고 결론내리지 않는다**. 특히 압쇄는 장갑/원거리 편성에서 두 정책의 소모 턴이 같았다. 후속 사람 테스트는 특정 탄을 기다려야 한다는 강요가 없는지, 재장전/짧은 장전이 실제 고민이 되는지, 압쇄가 선택을 건너뛰는지에 초점을 둔다. 초기 전투를 일부러 패배시키려고 거리나 HP를 일괄 조이지 않았다.
