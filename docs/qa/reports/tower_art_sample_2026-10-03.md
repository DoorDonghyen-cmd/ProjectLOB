## 제작 범위

사용자 선택 캐릭터 PNG 1254×1254와 배경 PNG 1672×941를 `assets/art/tower_sample_20261003/`로 바이트 그대로 복사했다. 이미지 재생성/편집은 하지 않았다. 원본 비율과 nearest 필터를 유지하며, 배경을 화면 폭에 맞춘 뒤 발판을 기준으로 세로 카메라 영역을 정한다. 캐릭터의 발 앵커와 적의 발 위치가 같은 발판에 놓인다. 좁은 세로 공간에서는 전장 높이와 인물 크기를 조정해 손패 6장과 발사 버튼을 화면 안에 남겼다.

신규 `redesign/samples/tower_battle.tscn`/`.gd`는 기존 screen.gd의 전투 입력과 레이아웃을 재사용한다. `tower_battle_view.tscn`/`.gd`는 텍스처와 배경 기준점, 캐릭터 표시를 소유하는 재사용 전장 씬이며 @tool 미리보기 데이터를 포함한다. 기본 전투에는 화면 생성과 배경/캐릭터 그리기용 작은 오버라이드 지점만 추가했다. 이 샘플에서 별도의 전체 UI 재설계나 모든 기존 런타임 레이아웃의 씬 직렬화를 수행한 것은 아니다.

샘플 런처의 APPDATA/LOCALAPPDATA는 `qa_runtime/art_sample/tower/`로 격리한다. save_enabled=false·debug_session=true로 캠페인 저장도 차단한다. 캡처 도구는 별도 숨김 창으로 실행하고 종료 후 결과를 확인한다. Godot MCP로 4.7 버전/프로젝트 확인과 샘플 씬 생성에 성공했다. 격리 저장·실제 렌더 캡처는 기존 로컬 CLI 방식으로 수행했다.
