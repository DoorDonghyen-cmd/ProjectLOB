# 리와인더·데드볼트 도트 보강

리와인더는 카세트 릴의 살과 테두리, 철제 덮개의 이음매와 고정점을 보강했다. 데드볼트는 중절식 약실의 단차와 경첩 축, 목재 결을 더했다. 두 총기의 기존 실루엣과 배색을 기준으로 리액터의 금속 명암과 부품 묘사 밀도를 참고했다.

장비 선택·빌드 작업실·전투가 새 원화를 공유한다. 파지점과 장전 동작을 유지하고 새 원화의 투명 경계와 총열 끝에 맞춰 장비 그림 영역과 장전 부품 범위, 데드볼트 총구 위치를 조정했다. [원화·제작 입력·해시](../../../../새-게임-프로젝트/assets/art/weapon_expansion_20261106/provenance.json)
