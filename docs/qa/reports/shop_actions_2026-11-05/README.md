# 상점 주요 행동 우선순위 — 2026-11-05

사용자는 재고·현장 기록이 구매보다 두드러져 보이며, 기존 재고 위치에 구매가 와야 한다고 지적했다. 직전 결제 행의 우측 정렬만으로 이 요구가 해결되지 않았으므로 실제 구매 버튼을 단말기 오른쪽 물리 키로 옮겼다.

## 현재 구성

- 보유금 바로 아래 첫 물리 키는 **구매**, 두 번째 키는 **파츠 장착**이다. 구매는 밝은 황동색과 물리 키 깊이를 사용하고, 두 버튼은 기존48px 높이의 고정 조작부를 공유한다.
- 현장 기록은 하단 보조 행동으로 옮겼다. 판매 중에는 재고/판매 물품 탭을 표시하지 않는다. 기록·장착 화면에서만 하단에 ‘판매 물품’ 복귀 버튼이 나타난다.
- 구매 버튼은 기존 인스턴스를 옮겼으며 결제 영역에 중복 구매 버튼을 남기지 않았다. 상품 상세·선택/교체·구매 후 잔액은 CRT에 남는다.
- 기록·장착 화면에서는 구매를 비활성화한다. 판매 물품으로 돌아오면 실제 상품/보유금/품절/가방 조건에 따라 복원한다. 파츠 장착 중에는 해당 물리 키도 비활성 상태로 자리를 유지한다.
- 기록 열람/복귀와 파츠 화면 이동은 결제하지 않는다. 가격·상품·저장 형식·게임 규칙과 직전 승인 방향의 몸체/색/주사선은 유지했다.
