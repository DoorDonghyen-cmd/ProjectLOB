# 조작대와 출발을 나눈 관문 시안

작업 중에는 운반 복장의 기존 정비 포즈와 조작대 표시등을 사용한다. 정비를 확정하면 표시등이 짧게 밝아진다. 다음 구역 이름, 문 상태, 출발 버튼은 문 위 표찰에 모았다.

출발하면 작업 후보와 비교창이 사라진다. 표찰 양쪽의 주황 경보등이 한 번 밝아지고 ‘차단문 개방 신호’가 표시된다. 닫힌 문과 캐릭터 자세를 유지한 채 암전하고, 화면이 완전히 어두워진 뒤 다음 구역 이동을 확정한다. 시안에서는 암전 뒤 다시 보기 버튼이 열린다.

## 실행

- `OPEN_GATE_REVIEW.cmd`는 이 시안을 연다. F1은 개조부터, F2는 재정비부터 시작한다.
- `OPEN_GATE_REVIEW.cmd -Workstation`은 출발을 작업 패널에 둔 [직전 관문 시안](../gate_workstation_2026-11-05/README.md)을 연다.
- `OPEN_GATE_REVIEW.cmd -Classic`은 [첫 분할 화면](../gate_review_2026-11-05/README.md)을 연다.

## 검증

Godot 4.7 격리 실행에서 새 시안 129개, 직전 시안 112개, 첫 시안 102개를 통과했다. 표찰 안의 출발 버튼, 경보 시 문과 캐릭터 자세 유지, 완전 암전 후 구역 변경, 다시 보기, 기존 개조·정비·탄약 생산을 확인했다. 세 해상도는 PC에서 실행했다.

본편 진입 및 저장 연결은 후속 작업이다.
