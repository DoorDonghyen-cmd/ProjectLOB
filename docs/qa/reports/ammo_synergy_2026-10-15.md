# 탄환 연계 발견과 선택 폭 — 2026-10-15

## 결정과 적용 범위

사용자는 탄환마다 잘 맞는 상대를 두는 방향(증폭→연타 등)을 제안하고 실행을 승인했다. 구현에서는 탄 이름에 따른 추가 보너스 대신 기존 효과의 상호작용을 실제 전투 계산으로 확인하고 보여준다. 이번 작업은 피해·발열·적 수치를 바꾸지 않았다. 기존 구조에서 여러 선택의 차이가 확인되어 발견과 순서 이해를 먼저 보강한 디렉터 결정이다.

새 등반 메뉴의 기본 선택을 운반용 외투(carrier, 패6장/교환0회)로 변경했다. 이전 정찰복4장 기본 선택을 이번 비교 적용에서 대체한다. 복장별 수치·탄창 크기·기존 저장·훈련 기본은 그대로다. 시작 탄창은 무기별 기존3~5칸이며 모든 후보를 동시에 쏠 수 있는 것은 아니다. 정식 기본 복장과 재미는 사용자 플레이로 재평가한다.

탄환 회수 금지, 버려서 냉각, 숨겨진 발열 수치, 실시간 선택 제한은 이번에 도입하지 않았다.

## 플레이 흐름

- 손패의 금색 연결 표시는 현재 장전과 맞물리는 후보. 실선은 지금 삽입해 연결, 점선은 삽입 후 레일 맨 뒤로 명시적으로 옮겨야 연결된다.
- 마지막 장전이 먼저 발사되는 규칙을 유지한다. 자동으로 순서를 바꾸지 않는다.
- ‘연계’ 버튼은 빈 탄창일 때 현재 패의 연결 쌍, 장전 중에는 현재 장전 양끝에 이어지는 후보를 보여준다. 발사 순서와 반대인 장전 순서를 따로 안내한다.
- 상세에서 실제 후속 피해·과열/패배 위험·증강의 다음 사격 필요 여부를 표시한다. 카드의 기존 효과·발열·조건 설명은 가리지 않는다.
- 산개는 표적에 따라 달라지는 조건부 후보이며 확정 피해를 표시하지 않는다. 기존 레일의 비동기 무작위 예측과 분리했다.

연계 종류는 증폭→다회 타격/관통/조건부 마무리, 파쇄→장갑 피해, 소이→기폭/불씨/충격/차단, 처치→추격, 예약→다음 패, 냉각→고발열, 발열→잔열/배기, 다른 탄종→결산이다. 각 전술 탄종19개가 적어도 두 다른 탄종과 실제 연결되는 조건을 검사했다. 이것은 모든 패나 모든 전장에서 항상 둘 이상이 유효하다는 뜻이 아니다.

## 비교 결과

격리한 보행자 조건에서 발사 순서별 실제 피해:

| 적 장갑 | 증폭→연타 | 증폭→철갑 |
| --- | ---: | ---: |
|0|12|6|
|6|2|3|

다회 타격이 유리한 표적과 관통이 유리한 표적이 갈린다. 압쇄/HP6·속도2·거리2 조건에서는 소이→충격이 접근을 지연하고 다음 재장전 화상으로 처치하지만 소이→기본은 접촉 패배한다. 피해 수치 외에 시간 확보의 연계도 확인했다.

## 검증과 증거

모든 테스트는 qa_runtime 격리 저장에서 실행했고 실제 UI는 저장을 비활성화했다.

| 검사 | 결과 |

|실제 UI 1008×630·1280×900·1440×630|314검사 / 실패0|
|기존 지원탄/강화 규칙 회귀|953검사 / 실패0|

자동 교전은5총기·6시드·초반3편성으로 구성하며 산개는 무작위 정책만 검사한다. 선택 정책은 전역 최적 해법이 아니며 패 교환을 사용하지 않는다. 패배1회는 증강/무작위 정책/시드913/깊이4/16턴. 전승이나 전체 캠페인 밸런스 검증으로 해석하지 않는다.

연타/철갑 선택 전환, 화상 지연, 발사 전 과열 차단, 장갑 없는 적, 잔열 조건 미달, 예약·추격·압축 위치 제한을 검증했다. 상세 창 열기와 후보 탐색은 실제 전투 상태와 RNG를 변경하지 않는다. 기본 메뉴에서 실제 등반을 시작해6장/교환0회도 확인했다.

## 한계와 다음 확인

이 기능은 인접한 두 탄의 연결을 발견하는 도우미이며 최적 수를 추천하는 시스템이 아니다. 여러 지원탄을 사이에 둔 복잡한 연결은 실제로 작동해도 후보 표시에서 빠질 수 있다. 산개 표시는 일반적인 가능성이므로 실제 성공을 보장하지 않는다. 6장 안내 계산은 이 PC 단일 측정 약905μs였고 Galaxy 성능은 미측정이다.

화면에서 카드와 버튼이 잘리지 않는 것은 확인했지만, 금색 실선/점선의 의미를 사용자가 바로 이해하는지와 조합을 찾는 재미는 미검증이다. 다음 사람 테스트에서는 고정 증폭→연타만 고르는지, 장갑에 따라 수신 탄을 바꾸는지, 화상·밀치기·냉각 경로를 선택하는지 확인한다. APK는 생성하지 않았다.
