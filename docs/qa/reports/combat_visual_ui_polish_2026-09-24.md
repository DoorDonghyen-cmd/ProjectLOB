# 전투 시각 UI 보강 QA

## 수정한 문제

압축 코어 아이콘과 패 교환 버튼이 좁은 헤더에 함께 배치되어 세로로 늘어났고, 이전 선택 흐름 개편도 색과 형태의 변화가 작아 체감이 약했다.

## 결과

- 압축 코어 표시를 후보 제목에서 분리해 58×44px 도구 행에 고정했다.
- 합치기 버튼은 두 탄환, 결합 화살표, 코어 마름모를 직접 그리는 48px 높이 그래픽 버튼으로 교체했다.
- 단계, 활성 패널, 후보 카드, 후보 결과, 발사 결과에 서로 다른 채움과 테두리를 적용했다.
- 작은 후보 카드에서 잘리던 `추가하면` 반복 문구를 제거하고 결과만 남겼다.

## 검증

| 검증 | 결과 |
|---|---:|
| 전체 Godot 자동 테스트 | 3,730 / 0 실패 |
| 실제 OpenGL UI | 3,677 / 0 실패 |
| 자동 버튼 입력 | 1,179회 |
| 압축 코어 표시 높이 | 48px 이하 |
| 그래픽 합치기 버튼 높이 | 52px 이하 |

1280×800과 1008×630 캡처에서 압축 도구 행, 3열 후보 카드, 발사 순서가 겹치지 않았다. 원본은 `qa_runtime/city/ui_combat_visual_v2_verified`에 있다.
