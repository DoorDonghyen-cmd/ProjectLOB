# 주인공 동작과 적 반응 1차 — 2026-10-05

**후속 사용자 확인:** 사용자가 이번 주인공 동작 이미지에 대해 “딱 원한 그림”이라고 평가했다. 그림체와 디자인은 확정 기준으로 채택한다. 재생 속도·연결감·모바일 체감의 검증과 구분한다.

본편 전투에 주인공의 조준·사격 반동·재장전 자세를 연결하고, 적의 대기·접근·피격·처치 반응을 추가했다. 확정 주인공 v2의 복장·모자·큰 색면과 기존 표시 크기를 유지한다. 구현/자동 기능 검사/실제 캡처 검수 완료이며, 새로운 움직임의 사용자 체감 확인은 후속이다.

## 플레이에서 달라진 점

- 장전 확정 전에는 기존 총을 내린 대기 자세, 확정 후에는 총을 어깨에 올리는 조준 자세를 사용한다. 발사 때 반동 자세를 보여 주고 총구 이펙트도 해당 자세의 총구에 맞춘다.
- 재장전은 탄창을 꺼내는 자세 → 끼우는 자세 → 조준 복귀로 이어진다. 실제 재장전이2턴이면 그2턴에 걸쳐 한 동작을 진행한다. 과열로 추가 냉각하는 턴에는 총을 열어 둔 자세와 기존 냉각 이펙트를 유지한다.
- 적은 작은 대기 호흡/부유와 접근 시 몸의 눌림을 사용한다. 지상 적의 발을 통째로 들지 않고 지면에 고정한다. 실제 이동 이벤트가 없는 적은 접근 동작을 하지 않는다.
- 일반 피해에도 짧은 움찔과 밝기 반응이 생긴다. 처치된 본체는 기존 위치에서 짧게 가라앉고 사라진다. 죽은 적을 다시 전투/선택 대상으로 등록하지 않는다.
- 감소된 연출에서는 대기 변형·반동을 멈춘다. 건너뛰기/동기화 후 자세·피격 상태를 초기화한다.
