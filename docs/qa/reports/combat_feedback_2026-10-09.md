# 도트 UI 반응과 피해 숫자

사용자는 도트 UI가 이전보다 훨씬 좋아졌다고 평가하고, 이를 기반으로 UI 연출/피해 플로팅을 게임답게 발전시켜 달라고 요청했다. 채택 UI 배치·아트와 계산 규칙은 유지하고 실제 행동 이벤트에 표현을 더했다.

## 구현

- 숫자와 효과를 분리했다. 일반 피해 36px, 강화44px 중심에 최대4px 진입 변화·4px 상승·끝 페이드. 공간이 좁으면 실제 글자 높이/폭에 맞춰2px씩 줄이며 최소24px를 유지한다. 글자는 기존 도트 글꼴, 어두운 외곽으로 보호한다.
- 실제 합계 피해와 실제 hits만 표시. 집중/증폭/기폭/추격·연타·화상·전이·막힘·처치 구분. 실제1타에 처치했다면 연타탄이어도2연타라고 쓰지 않는다. 피해 없는 냉각/예약은 해당 동작으로 표시한다.
- 전이/확산은 피해를 받은 적마다 별도 숫자. 처치 전 HUD 열 위치를 보존해 죽은 적의 숫자가 화면 왼쪽으로 점프하지 않는다. 살아 있는 HP/거리와 숫자끼리의 충돌을 프레임 단위로 검사한다.
- 실제 타격 시 HP 손실 구간에 짧은 황금색 잔상. 장전 도착, 탄창 발사/명중, 버튼 누름/연쇄 발사/재장전 각 턴/냉각 완료에 짧은 도트 반응. 컨테이너 위치·크기/클릭 영역은 유지한다.
- 정상 타격 읽기 구간0.27→0.36초, 화상0.24→0.32초. 기존 속도/건너뜀 경로를 따른다. 즉시 연출에서는 숫자 변화/상승/끝 페이드와 버튼·탄창 pulse를 생략한다. 전역 시간 배율/RNG/모델은 변경하지 않는다.

## 검증

- 새 피드백 전용 실제 UI 검사: 489검사/0실패. 3해상도×7전투(일반·강화 연타·전이·화상·막힘·처치·동시 처치), 실제 중간 프레임의 HUD/거리/숫자끼리 겹침·고정 배치·효과 문구 폭, 모델/RNG 동일성, 실제 버튼/탄창 반응 및 즉시 설정.
- 기존 전투 연출 회귀: 784검사/0실패. 실제 강화 처치·과열/강제 재장전·냉각·원위치 복귀, 5총기×10장 손패 및 즉시 연출.
- 최종 큰 숫자 크기 수정 후 피드백489검사 재실행. 1280×900 강화 연타와 1008×630 다중 처치·화상 캡처를 직접 확인했다. 정상 피해/강화 숫자와 각 대상의 위치가 구별되며 현재 HP와 거리를 가리지 않는다.
- 기존 장전 전후 고정 영역은 동일하며 새 연출이 동작하는 관찰 프레임에서도 유지한다. 원본 PNG/세계관/규칙 데이터 변경 없음.
