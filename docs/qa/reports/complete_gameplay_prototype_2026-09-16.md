# 완성형 체험판 QA 보고서

## 판정

**기능 검토 빌드로 사용 가능하다.** 일곱 교전의 전투·보상·저장·재개·완주 흐름과 두 총기, 네 유효 파츠 축에 결정론적 완주 경로가 확인됐다. 기본탄만 반복하는 정책은 모든 조건에서 패배해 탄환 조합을 건너뛸 수 없었다.

사람의 재미, 타격감, 장시간 피로는 자동 검사로 확정하지 않는다. APK 및 갤럭시 실기 검증은 이번 범위에서 제외했다.

## 기능 검증

- 규칙·계산 계약: **11,877 통과 / 0 실패**
- 실제 캠페인 탐색: 학습/일반 × 보행자/쇄도 **4개 완주**, 무결성 **3,589 / 0 실패**
- 실제 렌더 UI 재생: **1,610 통과 / 0 실패**, **485개 버튼 입력**, 4개 캠페인 완주
- 1280×800 및 1920×864 시각·터치·저장 보존: **174 통과 / 0 실패**
- 보상 화면은 실제 전투 기록, 다음 편성, 후보 효과만 사용하며 상태를 변경하지 않는다.
- 완주 화면의 직접 피해·증폭 타격·화상·전이·처치 합계는 저장된 전투 히스토리에서 계산한다.
- 기존 프로젝트 전체 회귀: **3,730 통과 / 0 실패 / 기존 경보 3**

## 밸런스 매트릭스

시드 `731042`, `17`, `90210`에서 보행자/쇄도를 실행했다. 빠른 탐색이 놓친 경로는 빔 폭 5·12·50으로 다시 검사했다. 탐색 실패는 불가능 증명이 아니며, 한 폭에서 찾은 실제 명령 경로를 다른 폭의 실패보다 우선했다.

| 정책 | 최종 판정 |
|---|---|
| 확장 탄창 우선 | 두 총기·3시드 모두 완주 경로 확인 |
| 가속 총열 우선 | 두 총기·3시드 모두 완주 경로 확인 |
| 열축전 코일 우선 | 두 총기·3시드 모두 완주 경로 확인 |
| 회수 가속기 우선 | 쇄도에서 완주 경로 확인. 보행자는 장착 불가라 다른 파츠로 진행 |
| 덱 제거 우선 | 두 총기·3시드 모두 완주 경로 확인 |
| 보상 전부 건너뛰기 | 5/6 완주 경로 확인. 쇄도·시드17은 6교전에서 제한 내 경로 미발견 |
| 기본탄만 반복 | 0/6 완주. F2·F5·F7에서 패배 |
| 차근차근 배우기 | 두 총기·3시드 6/6 빠른 탐색 완주 |

빠른 탐색에서 완주한 31개 일반/학습·보상 경로의 사용량은 회수탄 716, 증폭탄 275, 소이탄 148, 연발탄 136, 철갑탄 131, 전격탄 71, 충격탄 14였다. 충격탄은 사용 빈도가 낮지만 가까운 고속 적에서만 필요한 거리 제어 역할이고, 교육 교전과 실제 완주 경로에서 사용되므로 이번에는 수치를 올리지 않았다.

## 발견과 처리

- 빠른 빔 탐색의 폭을 늘리면 일부 경로가 오히려 사라지는 비단조 현상을 확인했다. 이는 게임 규칙 문제가 아니라 휴리스틱 가지치기 특성이다.
- `QA_BEAM_WIDTH`, `QA_SEARCH_DEPTH`, `QA_GUN`, `QA_REQUIRE_SITUATIONAL`을 실행기에 추가하고, 매트릭스가 실패 사례를 빔 폭 5·12·50으로 재검증하게 했다.
- 파츠 성향 정책은 목표 파츠를 얻은 뒤 후속 파츠 보상에서 그대로 유지하도록 수정했다. 이를 통해 서로 다른 최종 빌드 비교가 가능해졌다.
- 게임 수치 변경이 필요한 막힘은 발견되지 않았다.
