# 탄환 등급·압축 개편 검증

2026-10-09 · Godot4.7 · 활성 core-redesign 본편. [현행 설계](../../direction/ammo-grades.md).

## 구현

같은 일반탄2장→고급1장, 계열명 유지. 기존6계열에11계열의 영구/임시 압축형을 더했다. 신규 기본 탄종 없이17계열을 지원한다. 고급 재압축/희귀는 이번 범위에서 활성화하지 않았다.

상점18Cr·방문당1회 영구 압축, 기존 관문/정비 성장, 전투 코어를 쓰는 임시 압축을 연결했다. 두 번째 지역부터 일부 후보를 고급으로 발견할 수 있고 새 상점 고급 가격은24Cr다. 기존 저장/진열 가격은 호환한다. 강화된 효과와 열/점유/발사 위치 비용을 확정 전에 비교한다.

등급은 카드·탄창·압축 미리보기의 짧은 막대로 표시한다. 임시는 금색 점. 손패 공간을 늘리지 않고 압축 후보가2종을 넘으면 추가 선택창을 사용한다. 직접 드래그 압축 경로는 유지한다.

새 규칙 검사는17계열×5총기의 예측/실제 발사, 임시 압축의 취소·환급·저장·발사 후 원본 복원, 영구 압축의 가격/횟수/최소 덱/재진열 잠금, 기존 저장 고출력12Cr 진열, 신규 효과 조건을 확인했다. 화상 없는 기폭/장갑 최소 피해, 실제 처치 뒤 추격, 예약2장 재장전, 실제 잔열6의 방출, 차단2턴과 첫/끝 발·2칸 제약을 다뤘다.

200개 후반 상점 표본은 일반159/고급41이었다. 고급41에는 기존 고출력형이 포함된다.15%는 압축 가능한 일반 후보의 승급 추첨이며 모든 탄환을 합친 고급 출현률이 아니다.

초기 규칙 테스트에서 기존 장갑 최소 피해1을0으로 기대하거나2칸 탄이 들어갈 공간을 남긴 채 실패를 기대한 테스트 조건을 바로잡았다. 게임 규칙을 테스트에 맞춰 변경하지 않았다. 최종 격리 import와 실행에서 스크립트 오류 없음. git diff --check 통과(줄 끝 정규화 안내 제외).

전체 등반 회귀는 시드731042·난도0에서5총기 각각45개 장소를 통과했다. 쇄도/압쇄는 혼합 경로, 나머지는 안전 경로다. 공개 행동 기반 탐색기(candidate_limit800)의 결과이며 사람 승률이나 신규 고급탄 전체의 장기 밸런스 검증은 아니다. 이 탐색기는 새 상점 영구 압축을 선택하지 않으며 최종5개 덱에도 고급탄이 없었다. 따라서 등반 결과는 기존 일반탄 경로의 회귀 근거로 한정하고, 고급탄의 실제 계산/임시 복원/영구 획득은 위의 전용 검사 근거를 사용한다. ## 남은 확인

일반2장을 유지할지 고급1장으로 압축할지의 실제 선택 빈도, 고급 냉각의 첫 발 제약과 잔열 빌드,2칸 탄의 파츠/총기별 선호는 사람 플레이로 확인해야 한다. 최종 밸런스 확정이나 Galaxy 실기기 검증은 아니다. 새 아트 제작/APK/커밋/푸시/외부 업로드는 수행하지 않았다.
