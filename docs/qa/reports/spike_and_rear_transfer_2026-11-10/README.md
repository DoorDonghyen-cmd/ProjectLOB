# 스파이크 복장과 전이 방향 검수

## 스파이크 복장

게임에서 사용하는 캐릭터 장면으로 복장 7종을 스파이크(위)와 리벳(아래)에 입혀 대기·조준·반동·재장전 열기·재장전 닫기·냉각을 비교했다. 캡처 84개 모두 해당 복장과 총기 계열의 아틀라스 행을 참조했다. 전투 화면에서도 스파이크의 사격·재장전·냉각과 이어하기 검사 196개가 통과했다.

운반복은 권총 자세에서 부츠의 주황색 면이 길게 드러나고, 작업복은 무릎과 종아리의 밝은 면이 리벳 자세와 다르게 이어진다. 자세별 아틀라스 그림에서 보이는 차이다. 플레이 피드백에서 본 정확한 자세와 복장은 특정되지 않았다. [운반복 비교](outfit_carrier.png) · [작업복 비교](outfit_work.png)

## 전격탄과 불씨탄

- 전격탄은 주 표적보다 뒤의 생존 적 중 가까운 순으로 전이한다. 압축과 임시 압축 전격탄은 뒤쪽의 모든 생존 적을 대상으로 한다.
- 불씨탄은 뒤쪽에서 가장 가까운 생존 적에게 화상을 옮긴다. 뒤쪽 적이 없으면 이 탄환으로 화상을 차감하지 않는다. 턴 진행에 따른 화상 피해와 기간 감소는 적용된다.
- 같은 거리의 적과 압력탄은 전이 대상에서 제외한다. 전격탄이 압력탄을 직접 요격하면 요격 지점 뒤의 적에게 전이할 수 있다.

전투 규칙·이펙트 검사 322개, Godot 전투 화면 검사 552개, 빌드 회귀 검사 643개가 통과했다. 기본·압축·임시 압축, 앞·동거리·후방, 처치된 적, 산개총의 표적 확률과 실제 사격, 압력탄 직접 요격을 포함한다. Godot 화면은 1280×800과 1008×454에서 확인했다. 기존 압력탄·소이탄 단독 검사 두 개는 각각 해당 검사 데이터에 없는 `reload_heat`와 `heat_peak`를 읽다 중단됐다. 압력탄과 불씨 전이는 현행 전투 규칙 검사에서 별도로 검증했다.
