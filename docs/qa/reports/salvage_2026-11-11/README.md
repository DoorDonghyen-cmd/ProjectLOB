# 탄환 회수 시험판 — 검증

2026-11-11. 설계: [탄환 회수](../../../direction/salvage.md).

## 기능 확인 (`tests/salvage_ui.gd` 40 통과)

- 적 종류마다 회수 탄(운반 사족체는 없음), 새 등반 플래그, 저장 검증.
- 실제 2구역 전투 3개를 해법기로 이겨 확인: 마지막으로 쓰러뜨린 적(회수 탄 있는 종류)이 카드를 정함, 보상 3장 안에 들어감, 처치 숫자 아래 '회수 철갑탄', 받으면 덱에 추가.
- 정예(3구역): 압력두꺼비 → 압축 소이탄을 파츠 2택 옆에 한 장 더.
- 이전 저장에는 회수 카드 없음. 보상 화면(1280×800·1008×454)에 '회수 · 금형공' 카드([캡처](salvage_reward_1008x454.png)).

## 자동 등반 (시드 17·23, 섞인 보상·교차 사격·과열 대가 포함)

**첫 시험(운반 사족체 포함)**: 회수 137번 중 운반 사족체 81번(59%) → 충격탄만 쌓였다. 래칫이 다른 탄을 고르면 교차 사격만 있을 때보다 13~39% 느려졌다. → 운반 사족체를 회수 대상에서 뺐고, 회수 카드가 주력·강화 칸 대신 늘 '다른 공격탄' 칸을 쓰게 바꿨다.

**고친 뒤**

- 회수 분포(125번): 장갑벽 54(43%) · 전도 선체 34(27%) · 압력두꺼비 24(19%) · 흡수 구체 13(10%). 보상 화면 296곳 중 125곳(42%)에 회수 카드가 있었다(첫 보상·보스·졸개만 남은 전투는 없음).
- 완주 11/12. 진 1번(리액터, 시드 23, 5구역 정예)은 넓힌 탐색으로도 이길 길이 없다. 같은 전투가 과열 대가 실험(+2)에서도 못 이긴 곳이라, 덱이 조금만 달라져도 걸리는 빠듯한 자리다. 지켜볼 곳으로 남긴다.

| 총기 | 주력만 고름(회수 전 → 후) | 다른 탄도 고름(회수 전 → 후) |
| --- | --- | --- |
| 리벳 | 421 → 421 / L → 353 | 305 → 298 / 240 → 274 |
| 래칫 | 351 → 351 / 288 → 308 | 381 → 513 / 318 → 406 |
| 리액터 | L → 571 / 470 → L | 439 → 469 / 331 → 328 |

- 자동 선택은 '다른 공격탄이 나오면 무조건' 고르므로, 회수 카드가 늘 그 자리를 차지하면 래칫은 철갑탄·전격탄으로 덱이 퍼져 느려진다. 사람은 필요한 회수 탄만 고를 것이다.
- 해법기는 회수를 생각하지 않고 적을 잡는다. '원하는 탄을 위해 마지막 적을 고르는' 결정은 사람 플레이로 봐야 한다.
