# 교차 사격 — 섞을 이유 (B) 검증

2026-11-11. 사용자 "다음 단계 진행해 줘"(섞인 탄 보상 A 다음, 섞을 이유 B). 설계: [보상·경제 개편 · 교차 사격](../../../direction/reward-economy.md#교차-사격-1111-b).

## 규칙 (새 등반, `mix_combo.gd`)

- 탄창 안에서 직전 공격탄과 **다른 계열**의 공격탄을 쏘면 타격당 **+1**. 연달아 바꿀 때마다 +1 더, 최대 **+3**.
- 같은 계열을 다시 쏘면 0으로 돌아간다. 기본탄·지원탄은 세지도 끊지도 않는다. 탄창을 새로 장전하면 처음부터.
- 주력 한 계열만 쏘면 아무 변화가 없다.
- 피해 숫자 아래 `교차+N`, 계산 줄의 가산에 포함. 전투 도움말에 한 줄.

## 기능 확인

- `tests/mix_combo_ui.gd` 4 통과: 실제 래칫 전투에서 피해 숫자 아래 `교차+1`([캡처](cross_float_1008x454.png)).

## 자동 등반 (시드 17·23, 섞인 탄 보상 + 과열 대가 포함)

전체 턴(L = 미완주, 원래 빠듯한 보스에서 기본 탐색 실패).

| 총기 | 주력만 고름 | 다른 탄도 고름(교차 전) | 다른 탄도 고름(교차 후) |
| --- | --- | --- | --- |
| 리벳 | 421 / L | 371 / 304 | **305 / 240** |
| 래칫 | 351 / 288 | 466 / 356 | 381 / 318 |
| 리액터 | L / 470 | 543 / 391 | **439 / 331** |

- 섞으면 교차 전보다 11~21% 빨라졌다. 리벳·리액터는 이제 섞는 쪽이 주력만 쓰는 쪽보다 확실히 빠르다.
- 래칫은 섞는 쪽이 아직 9~10% 느리다. 연타탄에 붙는 공명기(n번째 타격 ×n)·구동이 커서, 다른 탄이 섞이면 그 몫이 준다.
- 주력만 쓰는 결과는 교차 전과 같다(한 계열은 보너스 없음).
- 무판단 사격은 주력만이든 섞든 1~2구역에서 진다. 쉬워지지 않았다.

## 사람 확인

아직. `교차+N`이 커지는 맛이 느껴지는지, 탄 순서(빼내기)를 교차에 맞춰 바꾸게 되는지 볼 것.
