# 탄환 발견·연계·과열의 캠페인 통합

2026-10-04 · `prototype/core-redesign` · Godot 4.7.stable · 기준 커밋 `7037ee4` 이후 작업 트리. 모든 게임플레이 검증은 `qa_runtime`의 격리 저장을 사용했다.

## 실제 적용

[PLAY.cmd](../../../PLAY.cmd)에서 최신 본편을 실행한다. 신규 시작 덱은 새 등반에 적용하며 기존 저장 덱을 강제로 교체하지 않는다. [현재 결정](../../direction/ammo-combinations.md).

- 기존 여섯 역할에 파쇄·기폭·추격·우회·냉각, 고출력 증폭의 정식 보급을 더했다. 전술 선택 12종이며 압축 변형/회수탄을 부풀려 센 숫자가 아니다.
- 시작 덱은 무기별 3~4종, 보급 후보는 층에 따라 확장한다. 보상은 연계 후보와 미보유 탄을 병렬 제안하고 상점은 미진열 탄을 우선한다. 일반 증폭만 있다고 냉각을 연계 추천하지 않는다.
- 신규 탄은 별도 픽셀 실루엣·피해/관통·한 줄 효과로 표시한다. 발사 레일에 장갑 감소·기폭·추격·냉각 결과를 표시하고 고출력의 사격 후 재장전 비용은 확정 후에도 보인다.
- 장갑 전열·배리어 전열·장갑 뒤 원거리 편성을 본편에 넣고 과열·압력탄 표시를 연결했다. 승인된 주인공 크기/주거구 배경을 재사용한다. 적 최종 아트와 지역 배경 세트는 이 작업의 완료 범위가 아니다.
- 현재 다섯 파츠 슬롯·압축 자원 경제를 유지한다. 화상 강화 파츠는 기폭할 총 피해에도 영향을 주며 순서/관통/처치 파츠는 새 탄환에도 기존 규칙으로 적용된다.

## 실제 계산 비교

| 조건 | 먼저 실행할 조합 | 순서를 바꾼 결과 |
|---|---|---|
| 보행자·장갑4·HP40 | 파쇄→연발: 직접 피해 1+6 | 연발→파쇄: 2+1. 파쇄 자체에는 감소 전 장갑 적용 |
| 압쇄·배리어2·장갑4 | 소이→기폭: 타격 둘이 막혀도 남은 화상 6 즉시 지급 | 기폭을 먼저 쓰면 쓸 화상이 없음. 남겨둔 화상과 즉시 피해를 이중 계산하지 않음 |
| 앞 적 HP5·뒤 적 HP20 | 철갑 처치→추격: 뒤 적 피해8 | 직전 탄이 처치하지 못하면 추격 추가 피해0. 요격도 조건 미충족 |
| 고출력과 냉각 | 고출력→냉각: 과열0 | 냉각→고출력: 과열1. 기본 재장전 시간은 줄일 수 없음 |
| 앞 장갑 적·뒤 원거리 | 우회는 뒤 적 공격 | 앞 적 접근은 계속됨. 최근접 압력탄은 요격 우선 |

위 비교는 통제된 실제 모델 검사다. 자연스럽게 얻은 덱의 평균 승률, 신규 탄환의 동등한 선택률을 뜻하지 않는다.

## 검증과 발견한 문제

- 신규 탄·순서·무기/파츠·보급·저장 검사: 45,841 / 실패0. 많은 항목은 30시드×무기×노드의 보상 규칙 반복 검사다. 서로 다른 밸런스 상황 45,841개라는 뜻이 아니다.
- 실제 UI: 176 / 실패0. 1280×900, 1008×630, 1440×630. 지도 진입, 카드 장전/확정/발사/재장전, 냉각 전후 비용, 압력탄 생성, 신규 상점 진열·구매, 보상 획득. 전투는 재현용 fixture를 사용하고 조작은 공개 버튼 입력을 사용했다.
- 기존 무기 규칙 3,245 / 실패0, 첫 지역·경제 규칙 4,229 / 실패0, 무기 UI 390 / 실패0, 첫 지역·상점 UI 86 / 실패0, 원거리 규칙417 / UI281, 출력 규칙296 모두 실패0.
- 낮은 화면에서 본편의 높이가 조금 넘치던 문제를 재현하고 전장 최소 높이를 조정했다. 캡처에서 카드·열 표시·피해·순서·재장전·압력탄이 잘리지 않는지 별도로 확인했다.
- 압축 검사의 기본 덱 의존 기대를 현재 보행자의 중복 충격탄으로 교체했다. 저장 동일성 검사는 기존 정규화 필드의 `0`과 JSON 파싱의 `0.0`을 양쪽 동일하게 정규화한 뒤 전체 상태를 비교한다. 상태 검증을 생략하지 않았다.
- 냉각 추천 수정 전 입력 기록에서 일부 보상 선택이 무효화되는 것을 재생 검사가 검출했다. 해당 구 기록을 최종 증거로 사용하지 않고 새 규칙으로 전체 경로를 다시 탐색했다.
- 산개는 같은 실제 resolver를 사용하면서 분기 병합 키를 숫자 상태로 줄이고, 타격마다 불변인 무기/파츠 값과 설명 생성 비용을 분리했다. 모든 전술 탄×다섯 무기×네 파츠 구성에서 일반 실행과 최적화 분기의 피해·전체 상태 일치를 확인했다.

최종 보상 규칙의 전체 캠페인: **29,973검사 / 실패0**, 다섯 무기×두 경로×35층 완주, 실제 명령 **4,877회**마다 저장/복원. 시드731042·난도0·미래 패/RNG를 읽는 제한 탐색이다. [경로별 요약](ammo_expansion_2026-10-04_assets/campaign_summary.json), [완주 로그](ammo_expansion_2026-10-04_assets/campaign.stdout.log). 원본 입력/상태 기록은 격리 실행 폴더의 `city_campaign_report.json`이며 요약에 SHA-256을 기록했다.

## 성능과 미검증 범위

전용 PC 측정의 최종 보스 편성에서 산개 5발 예측 약165ms, 8발 약1.89초였다. 생존 HP40의 인위적 네 적 조건에서는 8발 약1.75초였다. 결과 분기를 생략하지 않았으며 8칸 확장 산개의 예측 지연은 아직 후속 최적화 대상이다. 이 숫자는 Galaxy 성능 측정이 아니다. 원본 상세 수치는 `forecast_performance.json`에 보존한다.

자동 완주는 미래 패/RNG를 읽는 제한 탐색이다. 사람의 이해도, 난도·여러 시드의 실제 승률, 냉각·고출력의 선택률, 모바일 렌더/입력 성능은 미검증이다. 몬스터 외형·동작·사운드·연출 폴리싱과 신규 탄의 압축 변형은 별도 후속이다. APK·커밋·푸시는 이번 작업에서 하지 않았다.

격리 실행의 Windows 인증서 저장소 메시지는 기존 환경 메시지이며 스크립트 파싱/기능 오류와 구분했다.
