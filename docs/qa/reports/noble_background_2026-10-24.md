# 귀족 거주구 — 높이별 전투 배경

2026-10-24. 우수 정원 상층 수정에 대한 사용자 긍정 평가와 ‘다음 구역 진행’ 요청으로, 4구역 기계화 귀족 도시의 배경3종을 제작해 본편에 연결했다. 전용 승강장 진입로→저택 거리→가문 접견관 구성은 디렉터 제작안이다. 현재 미감에 대한 사용자 확인은 후속이다.

`PLAY.cmd → 개발 → 귀족 배경 · 초반 / 중반 / 상층`. 본편4구역 진입에도 자동 적용된다. 내부 순서는 물리적인 층수 표기가 아니며 기존/새 저장의 지도 길이를 같은 규칙으로3등분한다. 개발 미리보기는 정상 저장을 사용하지 않는다.

4구역 화면 표시명을 ‘송전 회랑’에서 **‘귀족 거주구’**로 변경했다. 정식 세계관 고유명 확정이 아닌 설명형 작업 명칭이다. 기존 송전 설비·장소명은 도시 내부 시설로 유지했다. 차폐 귀족·겹문 시종·수석 시종·백동 후작은 기획에만 있으며 이번에 제작하지 않았다. 실제 화면의 일반·정예·보스는 기존 공통 편성과 그림이다. 전투·경제·RNG·저장 필드는 변경하지 않았다.

## 제작과 화풍

- 내장 `image_gen`으로 각1회, 총3장 생성. 승인 주거 통로, 사용자 긍정 평가를 받은 정원 상층v2, 현재 전투 화면을 실제 이미지 입력으로 전달했다. 첫 두 장은 큰 도트 색면과 공간 깊이, 마지막은 표시 영역을 위한 참조이며 기존 UI·생물·식물을 새 배경에 복제하지 않도록 구분했다.
- 청회색 탑의 깊이 안에 탁한 상아색 외장·황동·작은 와인색 천을 배치했다. 밝은 실내 창과 넓고 정돈된 건축을 통해 하층과 다른 공급·계급을 표현한다. 5구역의 통일된 군사/중앙 권위와 달리 개인 저택과 취향이 보이는 도시다.
- 원본: `새-게임-프로젝트/assets/art/noble_ascent_20261024/{lower,middle,upper}_v1.png`,1672×941 RGB. 생성 PNG를 그대로 복사. 블러·재샘플링·픽셀 덧칠 없음. 프롬프트 요청 지면720과 실제 생성 지면이 달라 **실제 원화의686/686/687**을 등록했다.

## 미리보기와 저장 검증의 한계

`noble_preview.gd`는 기존 `garden_gate_single.json`의 실제2구역 통과 덱26장·획득 파츠를 사용한다. 3구역은 연결된 지도 경로만 합성하고 전투·보상 없이4구역 입구로 이동한다. 즉 **4구역까지 실제로 성장한 덱이나 난이도 검증이 아니다**. 상층/정예/보스도 직접 이동하는 시각 시연이다. 저장 검사는 합성된 이전 경로에서 실제 선택 가능한4구역 첫 노드를 `enter()`한 뒤 격리 저장/복원을 비교한다. 이 출처를 본편 플레이 기록과 혼동하지 않는다.
