# 플레이 피드백 검토 — 2026-10-20

기준 커밋 `197c694`. 작업 시작 시 활성 브랜치 `prototype/core-redesign`의 작업 트리는 깨끗했다. 사용자 플레이 피드백, 현재 코드 확인, 격리 계산 재현, 기존 실제 화면 검토를 구분한다. 아래 규칙안은 비교할 디렉터 제안이며 아직 본편 규칙을 바꾼 것이 아니다.

## 사용자 관찰과 확정 사항

- 전투는 이전보다 재미있어졌다. 낮은 기본탄을 교체하는 선택은 너무 당연하며, 자유로운 회수 때문에 신중하게 고를 리스크가 적다.
- 최초 ‘발열탄 효과가 없는 것 같다’는 표현은 후속 답변에서 **‘발열이라는 효과 자체가 체감되지 않는다’**로 명확해졌다. 특정 탄종 오작동 신고로 단정하지 않는다.
- 사용한 탄을 같은 전투에서 다시 쓰지 않는 방식과 기본탄 풀 확대, 단발의 맛과 파츠를 통한 반자동/자동화는 검토 아이디어다. 도입 확정 아님.
- 정예·보스의 패턴 효과가 잘 전달되지 않는다. 기능 검증 통과를 사람의 이해도 통과로 간주하지 않는다.
- 장비 선택에서 복장의 화풍·자세를 통일해야 한다. **마지막에 추가된 7~10장 신규 4종의 도트 표현을 기준으로 삼는다.** 신규 4종의 모든 포즈·초상화 품질까지 승인받았다는 뜻은 아니다.

## 디렉터 제안 — 비교 전, 본편 미적용

1. **먼저 발열과 패턴의 원인→결과를 보이게 한다.** 효과가 실제 붙은 탄의 강화량, 고열 진입, 과열로 못 쏜 탄, 추가 적 행동을 연결한다. 과열 상태를 조작부에서 잠시 유지하고 강제 냉각/재장전과 구분한다. 모든 탄을 고열만으로 강화하거나 비용을 일괄 강화하는 것은 이번 결론이 아니다. 정예 공명은 본체→호위→추가 이동, 보스는 문판 개방→장갑 상실→발사 예고→압력탄으로 전달한다. 강제 무적·피해 상한으로 패턴을 억지로 보장하지 않는다.
2. **소규모 비교의 첫 규칙은 전투 내 사용 탄 재순환 금지다.** 발사/교환한 탄은 해당 전투의 사용함으로 이동, 다음 전투에서 복구한다. 영구 소멸이 아니다. 보유 탄약량은 손패4~10장 및 탄창과 분리해 늘리고, 재장전 때 쓰지 않은 손패를 보존하고 빈 자리만 보충하는 안을 같이 비교한다. 현재 덱10장/최대14장을 그대로 두고 재순환만 끄지 않는다. 증원·정예/보스·지원탄 편중·탄약 고갈·압축 원본·저장 보존을 검증해야 한다. 구체적인 보유 매수/고갈 처리는 미결정이다.
3. **회수 페널티는 위 비교 뒤에 결정한다.** 미확정 선택 취소와 자원을 소비하는 실질적인 탄환 교환을 구분한다. 발라트로에서도 카드 선택 취소 자체는 소비가 아니므로, 클릭 실수에 벌점을 주는 구조를 그대로 채택할 이유는 없다. 반복 재사용을 없애도 긴장감이 부족하면 ‘장전 확정 이후 배출한 탄은 사용함으로, 대체 탄 즉시 지급 없음’을 비교한다. 회수=무작위 새 탄 지급은 무료 리롤 통로가 되므로 추천하지 않는다. 횟수 제한과 소모 제한을 동시에 추가하지 않는다.
4. **획득 고민은 무엇을 교체하느냐보다 무엇을 얻고 남기느냐에 둔다.** 초반 약한 기본탄을 바꾸는 성장 자체는 허용한다. 저위력·저발열을 남길 이유는 실제 열 제약과 장기 탄약 분배로 만들고, 새로운 특수탄 확보/한 장 개조/코어 성장의 기회비용을 비교한다. 일반탄 이름이나 낮은 위력 변형만 늘리지 않는다. 재순환 규칙을 결정한 뒤 무료 교체 범위와 확보 정책을 맞춘다.
5. **단발의 손맛과 행동 경제를 분리한다.** 한 탄창을1턴에 쏘는 무기와 한 발마다1턴을 쓰는 무기는 같은 대가로 비교할 수 없다. 무기5종의 고유 특성을 보존하고, 발사기구 파츠는 발수와 함께 발열·재장전·강화 보상을 설계할 후순위 후보로 둔다. 자동 파츠가 모든 무기의 필수 정답이 되는 변경은 피한다. 먼저 단발의 적중·반동·탄 사이 리듬을 검토한다.
6. **복장은 독립 작업으로 바로 제작 가능하다.** 신규4종의 무광 색면/도트 밀도를 기준으로 선택 화면 전용 공통 대기 자세, 같은 방향·발 기준·표시 신장·광원을 설정한다. 기존3종을 먼저 그 기준으로 다시 만들고 신규4종도 같은 초상화 자세로 정리한다. 복장 고유 실루엣은 유지한다. 전투 아틀라스 임의 잘라내기나 해상도 필터만으로 통일됐다고 보고하지 않는다. 전투·실내 원본을 무조건 함께 교체하지 않는다.

권장 순서: 전달 결함/복장 정리 → 탄약 재순환 단일 비교 → 교체·회수 비용 확정 → 발사기구 파츠. 재순환 비교 전에는 새로운 탄종 대량 추가를 하지 않는다.

발라트로 참고는 ‘큰 수의 성장’과 ‘라운드 안의 제한된 사용/버리기’를 구별했다. [개발사 공식 소개](https://www.playstack.com/games/balatro/?from=home)는 선택·버리기·조커의 역할을 설명한다. 같은 라운드 재순환 부재와 다음 라운드 복귀 세부는 [플레이어 확인1](https://www.reddit.com/r/balatro/comments/1gz1rkk), [확인2](https://www.reddit.com/r/balatro/comments/1ivxw9p)를 보조 확인했다. 공식 소스 코드/실행 중인 발라트로를 직접 검증한 것은 아니며 우리 게임의 규칙 채택 근거는 현재 전투 비교로 별도 검증해야 한다.

## 고열탄 후속 논의 — 지속 피해와 보호막

- **사용자 제안:** 고열탄은 높은 무기 발열을 대가로 적에게 턴당 지속 피해를 주고, 보호막을 채우는 적에게 효과적이면 좋겠다. 기존 발사 직전 열 절반 조건의 가산 피해는 직관적이지 않다는 피드백에 따른 방향이다. 앞서 대화에서 제안한 저장 열에 따른 점진적 직접 피해 증가는 채택하지 않았다.
- **현재 코드에서 확인:** 소이탄은 직접 피해1·발열2·화상3이다. 보호막이 직접 타격을 막아도 살아 있는 적에게 화상을 부여한다. 화상은 적의 전진 직전에 HP에 직접 피해를 주며 보호막/장갑 계산을 거치지 않는다. 한 번의 연쇄 발사 안에서 탄마다 발동하는 것이 아니라 경과한 적 행동 턴마다 발동한다. 재장전2턴이면 화상도 최대2회 처리한다. 현재 보호막은 막은 타격에 따라 소모되며 재충전되지 않는다. 보스의 문판 장갑 변화와 보호막 재충전을 혼동하지 않는다.
- **디렉터 제안 — 미구현:** 기존 소이탄과 개편 고열탄을 하나의 화상 계열로 통합한다. 직접 피해는 낮게, 지속 피해와 발열 비용을 주효과로 두고, 보호막이 남아 있어도 화상을 부여하고 지속 피해는 HP로 전달한다. 별도의 보호막 회복 금지 효과까지 겹치지 않는다. 최종 이름과 일반/압축 수치는 미정이다.
- **선택 가치 가설:** 먼 적·보호막을 반복 보충하는 적에게는 기다리는 동안 피해가 누적되고, 곧 닿는 적에게는 즉시 처치 탄보다 불리해야 한다. 과열 재장전 중 화상도 진행되지만 적 접근도 진행되므로 고발열이 일방적인 이득이 되지 않는지 비교해야 한다. 기폭탄의 남은 화상 전환과 기존 화상 파츠/압쇄 무기 상호작용도 통합 시 검증 대상이다.
- **후속 범위:** 보호막 재충전 적의 주기·예고·대응 경로를 별도로 설계한다. 화면에서는 무기의 `발열`과 적의 `화상`을 구분하고 턴당 피해/남은 턴을 연결한다. 이번 후속은 코드 열람과 설계 기록이며 새 전투 규칙 적용이나 실행 검증은 하지 않았다.
