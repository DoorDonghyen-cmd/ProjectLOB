# 탄환 궤적과 적중 시안

[사용자 방향을 반영한 본편 적용 결과](../shot_fx_live_2026-11-08/README.md)

1구역 승강장·주거 통로에서 운반복과 리벳으로 기본탄을 한 발 쐈다. 일반 3 피해와 선두 격발기 첫 발 ×2의 6 피해를 각각 동일한 전투 상태에서 비교했다. 재생 영상은 1008×454 본편 화면의 전투 영역을 잘라 반속도로 보여 준다. 영상은 왼쪽 위부터 현재·A·B·C 순서이며, 정지 비교는 왼쪽이 비행, 오른쪽이 적중이다.

| 시안 | 비행 | 적중 |
|---|---|---|
| A 예광선 | 짧고 가는 실선이 탄두를 따라간다. | 접점에서 작은 섬광과 짧은 스파크가 튄다. |
| B 불씨와 파편 | 탄두 뒤로 불씨가 끊어지고, 뒤로 갈수록 어두워진다. | 크기가 다른 파편이 진행 방향으로 퍼지며 사라진다. |
| C 겹잔광 | 중심 궤적과 위아래 잔광이 겹쳐 보인다. | 끊어진 도트 충격파가 좌우로 벌어진다. |

B는 탄두와 파편의 움직임이 잘 읽히면서 적의 형태와 피해 숫자가 선명하다. A는 효과가 자주 반복돼도 부담이 적다. C는 한 발의 인상이 가장 강해서 연발에서 어떻게 보일지 확인할 가치가 있다. 이번 비교는 동일한 일반 전투의 단발 시안이다.

격리 실행 `tools/run_firing_fx.ps1 -Mode concepts -Label trail_impact_concepts_20261108`에서 본편 사격 버튼으로 네 가지를 재생했다. 시안은 별도 검수 장면의 그리기 계층에 있으며, 모든 전투 결과는 같은 입력을 적용한 모델과 난수 기록까지 일치했다. PC의 모바일 가로 비율을 사용했다.
