# 판단 없이 쏴도 깨지는가 — 무판단 사격 측정

2026-11-11. 사용자 플레이 피드백: "아무탄이나 막 발사해도 클리어 되는 문제가 있었어".

## 방법

- `tests/growth_v2_climb.gd`에 `QA_NAIVE=fire`를 추가했다. 전투마다 매 턴 최대 발수로 쏘고, 탄창이 비면 재장전, 비상 보급이 뜨면 사용한다. 빼내기·선택 냉각·발수 조절은 하지 않는다. 상점·관문·보상 선택은 기존 자동 등반과 같다.
- 3총기 × (v2 이전 / v2 현재 구성 / v2 태그 시험판) × 시드 17·23. 같은 시드의 해법기(최선의 수) 등반과 같은 전투를 비교했다.
- '여유'는 전투가 끝났을 때 가장 가까운 적의 거리(m)다. 0이면 접촉 패배다.

## 결과

| | v2 이전 | v2 현재 구성 | v2 태그 |
| --- | --- | --- | --- |
| 리벳 | 4구역까지(2/2) | 4구역 1전 / 2구역 보스 | 3구역 / 2구역 보스 |
| 래칫 | 1구역 보스에서 패배(2/2) | 2구역 보스 / **완주**(시드 23) | 2구역 보스 / 3구역 보스 |
| 리액터 | 1구역 보스에서 패배(2/2) | 2구역 보스(2/2) | 2구역 보스(2/2) |

- **일반 전투는 판단 없이 거의 다 이긴다.** 진 곳은 대부분 구역 보스(1구역 8층, 2구역 9층)다. 이긴 일반 전투의 여유는 평균 15~30m.
- **1구역은 판단이 결과를 바꾸지 않는다.** 무판단 사격과 해법기가 1구역 모든 전투(보스 포함)에서 턴·여유까지 같았다. 전부 쏘기가 최선이다.
- 2구역부터 일반 전투는 무판단이 몇 턴 더 걸리지만 여유가 18~30m로 위험하지 않다. 판단이 결과를 바꾸는 곳은 보스뿐이다.
- **v2가 초반을 쉽게 만들었다.** v2 이전에는 래칫·리액터가 무판단으로 1구역 보스를 못 넘었는데, v2(특수탄 우선 장전 + 총기 내장 구동)에서는 넘는다.
- **해법기도 고르는 수단을 거의 쓰지 않는다.** 30전투 동안 래칫은 냉각·빼내기·발수 조절 0회, 리벳 냉각 8회, 리액터 냉각 3회. 차이를 만드는 것은 재장전 시점 정도다. 과열 강제 냉각은 등반당 120~240턴 일어나지만 대가로 작동하지 않는다.
- 해법기 기준으로도 래칫 5구역 여유는 평균 29m(최소 24m)로 적이 거의 다가오지 못한다.

## 뜻

전투의 결정(몇 발 쏠지, 빼낼지, 언제 식힐지)이 일반 전투에서 결과를 바꾸지 못한다. 수치만 올리면 '재장전 시점'만 중요한 게임이 되므로, 결정이 생기는 규칙과 수치를 함께 손봐야 한다. 앞으로 '무판단 사격은 지고, 해법기는 여유 있게 이긴다'를 균형 기준으로 쓴다.
