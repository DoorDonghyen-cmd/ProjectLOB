## 규칙 (새 등반만, `reward_trim.gd`)

- 일반 전투 보상: **탄 1장 빼기 카드(맨 앞)** / 새 탄 후보 3장 / 대신 N Cr / 보류. 기본 선택은 첫 새 탄이다.
- 빼기 목록은 보유한 탄 종류별 한 칸, 기본탄 먼저, 그다음 많이 가진 순.
- 덱 최소 장수 아래로는 뺄 수 없다(카드가 사라진다).
- 정예·보스·첫 보상(주력 탄 묶음)은 그대로다. 이전 저장은 바뀌지 않는다.

## 배치를 바꾼 이유

- 처음에는 '대신 N Cr' 옆 버튼으로 넣었다. 새 등반으로 740×454를 보는 기존 보상 검사에서 버튼 줄이 넓어져 보상 판이 화면 밖으로 나갔다. 좁은 화면에서도 맞도록 카드 줄(옆으로 넘김)로 옮겼다.
- 네 번째 카드로 두니 휴대폰 폭(1008)에서 넘겨야 보였다. 사용자가 보상 선택지를 놓친 일이 있어 맨 앞에 두었다.

## 발견한 기존 문제

- 844×390에서는 보상 화면 아래 버튼 줄이 화면 밖으로 잘린다. 새 버튼이 없는 이전 상태에서도 똑같이 잘린다([캡처](reward_old_844x390.png)). 보상 화면 기존 검사는 1008×454·2340×1080만 본다. 화면 높이가 390 정도인 기기에서는 따로 고쳐야 한다.
