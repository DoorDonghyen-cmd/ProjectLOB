# 본편 버튼 틀과 색상

사용자가 좋다고 한 전투의 냉각·탄창 교체 버튼에서 금속 테두리의 모양을 가져왔다. 본편 주요 화면의 행동 버튼과 확인창은 모서리와 테두리를 같은 리소스에서 받는다. 눌림은 기존 공통 반응을 사용하고 키보드 포커스는 2픽셀 테두리로 표시한다. 배치에는 각 화면에 지정된 높이와 글자 여백을 사용한다.

타이틀의 ‘새 등반’과 결과의 ‘새 도전’은 황동색 `#BEA36B`로 맞췄다. 상점은 기존 황동 구매 키와 회녹색 보조 키를 사용하며, 키의 하단 테두리를 공통 틀에 맞췄다. 일반 확인창의 확정 버튼에도 황동색을 적용했다.

## 검증

격리 저장으로 타이틀·장비·지도·정비소·상점·보상·결과·관문·보급소·조우·이야기 장면·빌드·공통 창과 모달을 확인했다. 6개 테마에서 주 버튼의 일반·호버·누름·비활성·포커스 틀을 검사했고, 타이틀과 결과의 주 버튼 색상도 비교했다. 상점 구매, 결과에서 새 도전, 모달 터치와 키보드 포커스를 포함한 UI 검사 16종과 전투 HUD 검사 126개가 통과했다. 화면은 PC와 휴대폰 가로 비율의 PC 창에서 확인했다.

## 황동 표면 후속

황동 행동 버튼의 윗면과 왼쪽에 빛을, 오른쪽과 아래에 그림자를 픽셀 단으로 넣었다. 글자 뒤의 면에는 기존 색을 쓴다. 버튼을 누르면 윗면 반사광이 어두워지고, 비활성 상태에서는 기존 어두운 면으로 돌아간다. 결과 화면의 같은 버튼에서 가운데 `#BEA36B`, 윗면 `#D8C8A6`, 아랫면 `#726240`을 실제 캡처에서 확인했다.

## 타이틀 시안 적용

사용자가 고른 어두운 철제 면과 얇은 황동 테두리를 타이틀에 적용했다. ‘등반 계속’과 새 저장 상태의 ‘새 등반’에 이 틀을 쓴다. 같은 상점 저장으로 844×390과 1280×800에서 시안과 본편을 비교했다. 차이는 공통 코드가 계산한 버튼 안쪽 반사광과 그림자에만 있었으며 RGB 채널당 최대 4였다. 타이틀·공통 창·초기 동선·결과·장비 팝업 검사 5종이 통과했다.

## 시작·이동·확정 버튼 적용

타이틀의 어두운 철제와 황동 테두리 테마를 장비 선택의 ‘등반 시작’, 결과의 ‘새 도전’, 지도의 ‘이동’과 ‘전투 건너뛰기’, 보상의 ‘이 탄으로 교체’, 정비소의 작업 실행과 ‘강화 확정’에 연결했다. 보상 교체는 내보낼 탄을 고른 뒤 활성화되고, 후보 화면으로 돌아가면 회수 버튼 스타일이 복구된다.

- [장비 선택](equipment_dark_primary_844x390.png) · [결과](results_dark_primary_1280x800.png) · [지도](map_dark_primary_1008x630.png)
- [보상 교체](reward_dark_primary_1008x454.png) · [정비 강화](workbench_dark_primary_844x390.png)

장비 선택, 결과, 지도, 보상 교체의 동일한 전후 캡처에서 픽셀 차이는 각 버튼 영역에만 있었다. 지도에서 잠긴 장소의 미리보기와 이동 가능한 장소의 진입을 확인했다. 보상 교체·취소와 정비 실행·저장 재개를 포함해 화면 검사 8종과 정비 강화 검사 2,011개가 통과했다. PC 창과 휴대폰 가로 비율의 PC 창에서 확인했다.
