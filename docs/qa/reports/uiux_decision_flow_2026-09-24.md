# UI·UX 선택 흐름 QA

## 판정

자동 회귀 기준 PASS. 전투·지도·상점·덱 장비의 새 입력 경로가 실제 OpenGL 렌더링과 보행자·쇄도 35층 재생에서 중단 없이 동작했다.

## 확인 항목

- 지도 노드 선택만으로 진입하지 않고, 선택 결과와 활성화된 이동 버튼을 거쳐 전투로 진입한다.
- 상점 파츠 선택 시 비교 패널에 이득 `▲`, 대가 `▼`, 현재 빌드 변화가 나타난다.
- 상점 탄환은 보유량 전후와 실제 피해·관통·속성을 표시한다.
- 덱·장비 세 탭이 각각 현재 장착, 보관 파츠, 탄환 구성만 표시한다.
- 전투에 단계 안내, 후보 결과, 명시적 압축 버튼이 나타난다.
- 명시적 압축 버튼과 드래그 압축 모두 코어를 사용하며 되돌리기로 탄환 두 발과 코어를 복구한다.
- 1008×630 모바일 가로 화면과 840px 접힘에서 전투 조작이 화면 밖으로 이탈하지 않는다.
