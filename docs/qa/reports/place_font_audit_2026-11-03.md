# 장소 글꼴 — PC 창 모드 재현 점검

> 후속: 사용자 승인 후 [공통 가독성 수정·Galaxy S26 크기 검수](ui_readability_2026-11-03.md)를 완료했다. 아래 내용은 수정 전 원인/증거 기록이다.

2026-11-03. 사용자: 상점에서 일부 글자가 깨지거나 작게 보임. 환경은 **PC 창 모드**로 확인. 상태: **재현 확인 / 수정 전**. 이번 점검에서는 제품 코드·에셋·사용자 저장을 변경하지 않았다.

## 확인 결과

상점은 `shop_screen.gd::_fit_canvas()`에서1600×900 전체 Canvas를 축소한다. 프로젝트의1280×800 기준 viewport 배율도 더해져 실제 글자 크기가 아래로 떨어진다. 기본16px 보조 설명과24px 가격/본문이 특히 영향을 받는다.

| 실제 창 크기 | 보조 글자(설정16) | 가격·본문(설정24) | 상품명(설정32) |
| --- | ---: | ---: | ---: |
| 1600×900 | 약16px | 약24px | 약32px |
| 1280×800 | 12.8px | 19.2px | 25.6px |
| 1008×630 | 10.08px | 15.12px | 20.16px |
| 1008×454 | 8.07px | 12.11px | 16.14px |
| 844×390 | 6.93px | 10.4px | 13.87px |

- 실제 렌더에서1280×800에서도 보조 글자의 획 두께가 불규칙하고,1008×630에서 더 작은 문구가 끊겨 보이는 현상을 확인했다. 카드 종류·등급·설명·잔액·파츠/총기 정보·설정 버튼이 영향을 받는다. 상점 상세 창도 동일한 Canvas 아래에 있다.
- `NeoDunggeunmoPro`는16단위 격자의 도트 원형이다.24px 설정 자체가1.5배이며, 부모의 비정수 배율이 다시 적용된다. 글자 크기만 일괄 증가하면 이 비정수 배율과 잘림 문제를 해결하지 못한다.
- 기본 글꼴에는 완성형 한글11,172자가 모두 있다. 이번 화면의 한글 글리프 누락은 확인하지 않았다. 다만 상점의 `→`, 공방의 `↔`, `−`, `→`, 장소 상단 `⌁`는 이 글꼴에 없어 시스템 대체 글꼴에 의존한다. 화면/OS에 따라 기호의 모양·두께가 달라질 수 있다. 실제 누락 여부와 글리프 지원 여부를 구분한다.
- 공방·보급소에는 상점 전용 Canvas 축소가 없지만 프로젝트 viewport의 축소가 적용돼1008×630에서16px 문구가12.6px로 내려간다. 같은 계열 결함이다.

## 수정 우선순위

1. 상점 텍스트를 실제 화면 픽셀 기준으로 렌더하고 전체 축소를 없앤다. 글자는 우선16/32px의 온전한 도트 단계로 정리한다. 카드 폭·줄바꿈·여백을 창 크기에 맞추고 낮은 창은 스크롤로 수용한다. 할인 가격·구매 효과·보유/잔액을 가독성 우선으로 검수한다.
2. 상세/가방과 공방·보급소에 같은 최소 글자 크기·배율 원칙을 적용한다. 전투/지도 등 다른 화면으로 이동할 때 기존 배율이 복구되는지도 확인한다. 게임 전체의 stretch 설정을 일괄 변경하지 않는다.
3. 미지원 기호는 뜻을 보존한 문구·이미지 또는 명시적인 동봉 글리프로 통일한다. 시스템 글꼴 대체에 맡기지 않는다.
4. 창 크기 변경·큰 글씨 설정·상품/기호/긴 설명·실제 구매/자동 저장을 함께 재검증한다. 기존 화면 안 배치 검사만 통과했다고 판독성 해결로 기록하지 않는다.

위는 수정 제안이며 이번 사용자 요청의 점검 결과다. 사용자 기존 라인+도트 미감은 유지한다.

## 추가 확인 — 상점 이외 구간

사용자의 후속 질문에 따라 지도·빌드 작업실·사건·메뉴/설정·등반 장비·전투·보상/관문을 PC1280×800 및1008×630에서 추가 점검했다. **상점에 국한된 문제가 아니다.** 제품 소스/폰트 변경은 하지 않았다.

| 구간 | 추가 확인 결과 | 수정 범위 |
| --- | --- | --- |
| 지도·장소 상세 | 1008×630에서12px 보조 글자는9.45px,16px 글자는12.6px. 층/구역 이름과 상태·선택 정보의 획이 작고 불규칙함 | 화면 공통 배율과 지도 보조 글자 최소 크기 |
| 사건(조우) | 설명·행동 버튼16px→12.6px, 장소 상단 기호⌁ 미지원 | 공방/보급소와 공통으로 정리 |
| 빌드 작업실·탄환 덱 | 설명16px→12.6px.17·18·20·22px 등 이전 글자 크기도 남아있음. 파츠 비교의→·−는 기본 폰트 미지원 | 장비/카드/상세 타이포와 실제 렌더 배율 |
| 시작 화면·등반 장비 선택·설정 | 기본 viewport 축소가 적용됨. 장비의 보조 설명·설정 항목16px→12.6px, 선택 화면‹·› 미지원 | 비전투 화면 공통 처리에 포함 |

따라서 **상점 단독 수정이 아니라 비전투 화면의 공통 배율/글자 기준을 먼저 정리하고, 상점의 추가 Canvas 축소 및 장비 상세의 남은 개별 글자 크기를 함께 손보는 범위**가 맞다. 전투·개편 보상/관문은 기존 읽기 크기를 유지하면서 기호와 세부 타이포를 별도로 보완한다.
