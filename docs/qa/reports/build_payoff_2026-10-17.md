# 빌드별 다수 처치 — 적용과 검증

2026-10-17 · `prototype/core-redesign` · Godot4.7 Windows

## 적용 결과

사용자는 성장 파츠와 여러 적이 동시에 죽는 쾌감을 긍정적으로 평가했다. 이번에는 승인된 세 방향을 [현행 화력 성장 규칙](../../direction/damage-growth.md)에 연결했다. 구체적인 충격파 수치·편성·연출 강도는 디렉터 구현안이다.

- 연쇄: 기존 남은 타격 전달을 유지하며 타격 수를 늘리는 모듈/탄환을 발견하기 쉽게 한다.
- 열압: 기존 고열 배율에 **고열 직접 공격이 한계에 도달할 때 다른 활성 표적에 충격파**를 추가했다. 장갑 차감 전1회 타격 피해의 절반, 각 적 장갑 재차감, 배리어 차단. 처치 냉각은 이후 적용하므로 충분히 식히면 강제 재장전을 피한다.
- 돌파: 기존 단타 배율/초과 피해 전달을 유지하며 관통·강한 단타를 모으는 방향을 지원한다.
- 새 등반은 전열 최대4기와 단계별 증원으로 확대한다. 첫 안내는 유지, 깊이2는4기/3은6기/이후8기. 상위 구역은 기존 특수 역할과 핵심 적을 남기고 보조 적을 추가한다. 플레이어 성장에 맞춰 HP나 거리/개체 수를 자동 조절하지 않는다.
- 새 등반의 탄환 보상/상점 모듈 한 후보에 장착 코어 적합성을 반영한다. 미발견·등장 단계·소유 제한과 다른 선택지는 유지한다. 정예 파츠 보상은 기존 규칙이다.
- 실제 사격의 피해 합계/처치 수, 다수 처치의 짧은 정지감·파편·후속 궤적·기존 저음 효과를 연결했다. 전역 시간 배율은 바꾸지 않는다. 같은 대상 후속 피해는 합쳐 표시하고 밝은 충돌 효과선이 피해 글자를 침범하지 않게 했다.

v1/v2 캠페인의 편성과 발견 규칙을 유지한다. 열압 충격파는 현행 파츠 효과이므로 기존 등반에도 적용된다. 새 편성 버전3의 첫 지역이 기계 대체 그림으로 잘못 연결되는 분기를 발견해 주거 생물 아트로 교정했다. 신규 탄환·파츠·원화·음원은 추가하지 않았다.

실제 Model.fire와 Forecast를 비교하고 예측이 live state/RNG를 바꾸지 않는지 확인했다. 산개12시드에서 충격파 결과가 예측 범위에 포함됐다. 직접 타격이 막힘/저열/지원탄/한계 미도달이면 충격파가 없고, 충격파는 장갑을 뚫는 최소1피해를 만들지 않는다. 압력탄 요격은 실제 보조 표적으로 처리하면서 적 처치 수에는 넣지 않는다. 적이 도착한 턴에 이동하지 않고 다음 결정 기회를 남기는 것도 확인했다.

열압 성장2, 시작 열5, 증폭→연타, HP6/6/6/30(마지막 장갑3) 표본에서 원 표적6 + 충격파6/6/3 = 실제21피해,3기 처치다. 생존 표적 때문에 강제 재장전까지 진행했다. 처치 냉각 표본에서는 충격파 뒤 열8로 내려가 강제 재장전을 피했다.

[탄 선택 비교](build_payoff_2026-10-17/comparisons.json)는 각 빌드가 다른 탄을 선호하는 기능 표본이다. 연쇄에는 복층 급탄기, 열압에는 시작 고열을 주었으므로 동일 조건의 코어 우열/밸런스 비교로 사용하지 않는다.

## 캠페인 탐색의 의미와 한계

시드731042/17, 낮은 난도, 작업복5장, safe 경로 선호, 각 명령 뒤 저장·복원으로 총2401명령을 재생했다. 메뉴 기본 선택은 운반용 외투6장이며 이30경로는 그보다 작은 작업복5장 표본이다. 공개 기본6장 새 등반은 별도 UI 검사에 포함했다.

첫 탐색은29/30경로를 통과했다. 쇄도+열압/시드731042/노드401에서 제한된 탐색이 경로를 못 찾았다. 후보6000·탐색폭32·깊이16으로 넓혀24명령 경로를 찾았고, 최종 캠페인 재생에서는 같은 조합의 관문 전투802도26명령 경로를 찾아 완주했다. 적 수치를 낮추거나 저장 검증을 완화해 통과시키지 않았다. 두 구간은 사람 난도 관찰 대상으로 남긴다.

기능 탐색기는 미래 RNG 상태를 사용할 수 있다.30경로의 성공을 사람 승률, 쉬운 난도, 최적 전략 또는 공정한 빌드 비교로 해석하지 않는다. 첫 지역 종료 성장 단계는 연쇄/열압3~4, 돌파1~4였으며 압쇄+돌파는 두 시드 모두1에 머물렀다. 조합별 성장 편차를 후속 관찰해야 한다. 상위 지역은 대표 편성·기존 핵심 적/역할 보존·발사/예측/저장을 검사했으며 전체 등반 완주는 검사하지 않았다.

코어별 타격 화면은 준비된 HP/열/성장 상태의 기능 표본이다. 주거 무리 화면도 실제 encounter_pack으로 만든 깊이4 배치 표본이며 첫 전투를 그8기 편성으로 바꿨다는 뜻이 아니다. 새 등반 캡처만 실제 첫 노드 진입이다.

초기 타격 캡처에서 글자 뒤에 밝은 효과선이 겹쳤다. 이전 증폭 표시가 남았다고 잠정 추정했지만 코드상 이전 팝업은 정리되고 있었다. 실제 원인은 주 표적 충돌의 흰색 선이었고, 피해 표시 영역을 피하도록 수정했다. 짧은 효과 꼬리표/좁은 너비의 글자 크기도 조정했다.

이번 확인은 기능과 렌더 판독 검사다. 새 연출의 사람 선호·반복 피로도·청감·Galaxy 성능과 장기 균형은 미확인이다.
