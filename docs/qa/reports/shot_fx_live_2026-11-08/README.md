# 강화 사격 궤적과 적중 본편 검수

일반 사격에는 기존의 짧은 꼬리와 적중 연출을 쓴다. 강화 사격은 실제 피해 결과에 따라 아래 단계로 구분한다.

| 단계 | 발동 예 | 비행과 적중 |
|---|---|---|
| A | 증폭탄이 다음 탄에 피해를 더했을 때 | 가는 예광선과 짧은 스파크 |
| B | 선두 격발기 첫 발 ×2, 단일 코어 배율 | 끊어진 불씨와 퍼지는 도트 파편 |
| C | 제3 격발기 ×3, 데드볼트 봉인탄 ×3, 배율 중첩 | 세 줄의 잔광과 양옆으로 퍼지는 충격파 |

궤적은 탄두 뒤에서 총구까지 지나온 거리 안에 그린다. 타격 효과는 고정된 적중점에 놓고 피해 숫자 뒤에 그린다. C의 충격파는 큰 피해 숫자 옆에서 보이도록 시작 폭을 넓혔다. 방어막이 공격을 모두 받아내면 차폐 효과를, 압력탄을 요격하면 요격 효과를 보여 준다. 즉시 연출에서는 강화색을 읽을 수 있다.

## 검증

`tools/run_impact_parts.ps1 -Mode rules`로 실제 가산, 선두 격발기, 제3 격발기, 데드볼트, 배율 중첩과 차폐·요격 구분을 확인했다. `-Mode ui`는 PC의 1280×800과 1008×454에서 본편 사격 버튼을 사용해 궤적과 적중 단계, 즉시 설정, 이전 획득 경로 저장·복원을 확인했다. 재생한 전투 상태와 난수 기록은 같은 명령을 수행한 모델과 일치했다. Android 실기기 확인은 후속이다.
