# 정비소 작업 장면·탭 UI 시안 — 2026-11-04

**본편 연결 후속(2026-11-04):** 사용자 긍정 평가와 실행 지시 후 [실제 정비 기능·저장 연결](workbench_live_2026-11-04.md)을 완료했다. 아래는 연결 전 시안의 범위/근거다.

**사용자 미감 확인:** 전달한 통합 시안에 “와 훨씬 좋아졌어 지금까지 본 결과 중 가장 좋은 거 같아”라고 평가했다. 작업 장면 중심 구도·작업 탭·먹색/아이보리/황동을 정비소의 후속 시각 기준으로 이어간다. 이 평가는 실제 정비 기능/저장·모바일 실기기 검증 완료를 뜻하지 않는다.

사용자는 이전보다 깔끔해진 점을 긍정했지만 청록색 중심 표현과 장소에 맞지 않는 기능 목록 구성을 지적했다. 첨부한 게임 작업대 이미지처럼 물건/작업 장면이 중심이 되고 ‘탄종 교체 / 탄환 압축 / 탄환 개조’가 탭으로 나뉘는 방향을 요청했다. 최신 요청을 정비소의 기존2열 유지보다 우선하여 **별도 통합 시안**을 만들었다. 본편 연결 파일은 바꾸지 않았다.

## 시안의 결정

- 정비소 원화를 화면 전체에 사용하고 배우·작업대·압축기를 함께 보인다. 기존 작은 장소 삽화 아래의 기능 카드 목록을 상단 작업 탭과 한 작업의 정보 영역으로 바꿨다.
- 탭은 탄종 교체·탄환 압축·탄환 개조·덱 정리·가방 확장. 기존 작업을 누락하지 않았다. 탭 전환/하단 탄 선택은 미리보기 상태만 바꾸고 정비 기회를 소비하지 않는다.
- UI는 먹색·아이보리·황동색이며 선택 탭은 낮은 강도의 면과 밑줄로 구분한다. 청록 발광 틀/카드 테두리를 반복하지 않는다. 기존 그림에는 시안 전용 중성/따뜻한 색 변환 재질을 사용했고 원본 비트맵은 보존했다.
- 선택 탄환은 실제 탄환 원화를 작업대 위와 하단 작은 목록에 표시한다. 우측은 작업 대상·소모/획득·성능/수량 변화·실행 버튼으로 제한한다. 무관한 탄환명이 가방 탭에 남거나 무료/정비 횟수가 반복되지 않게 정리했다.
- 글자와 숫자·버튼·탭은 Godot 노드다. 원화에 UI를 구워 넣지 않았다. 기존 픽셀 글꼴16/32를 사용한다.

## 현재 한계와 범위

- **팔레트/구성 확인용 시안**이다. Apply 버튼의 정비 확정/실제 보유 덱 변경·저장은 연결하지 않았다. 탭·보유 탄환 선택과 우측 표시가 동작한다.
- 보유20발/상한32와 다섯 탄종 수량은 표시 예시다. 피해·발열/압축·화력 개조 대상은 실제 Content 함수에서 읽지만 현재 사용자의 등반 저장이나 실제 상점 후보를 불러온 결과는 아니다. 교체 후보와 가방 증가량도 표현 예시이며 밸런스 변경을 뜻하지 않는다. 현재 개조 시안은 화력 개조만 표시한다.
- 첨부 레퍼런스의 원리를 적용했으며 그 게임의 UI/총기/손/텍스트/로고를 복제하지 않았다. 기존 도트 게임의 화풍을 유지한다.
- 새 작업대 근접 배경 생성을 built-in image_gen에 요청했으나 도구가 violence 안전 필터로 거절했다. 재시도/CLI 전환 없이 기존 승인 원화·배우·탄환을 재사용했다. 따라서 실제 손/작업물의 근접 시점, 새 원화, 압축/교체 애니메이션은 미구현이다. 이번 시안은 기존 방 그림을 크게 프레이밍한 구성이다.
- 본편 정비소·공통 규격 v1·상점/결과창·게임 계산/저장은 유지했다. 새 배색을 모든 화면의 확정 팔레트로 선언하지 않았다. 향후 본편 연결 때 실제 후보·대가·저장·확정/취소 및 모든 기존 기능을 검증해야 한다.
