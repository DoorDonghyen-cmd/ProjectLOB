# 옆 조작기 시안의 CRT 화면

[움직이는 밝은 띠](idle_scan_1280x800.webp) · [같은 재고에서 CRT 전후 비교](compare_1280x800.png) · [재고](crt_stock_1280x800.png) · [현장 기록](record_1280x800.png) · [S26 가로 재고](stocked_2340x1080.png) · [S26 안전 영역 크기의 우수 정원 기록](garden_record_2160x1032.png)

`OPEN_SHOP_CONSOLE_PREVIEW.cmd`에서 실행한다. 왼쪽 모니터 유리에 낮은 대비의 주사선, 모서리 음영과 따뜻한 형광 빛을 적용했다. `재고`와 `현장 기록`을 실제로 전환할 때 약 0.19초 동안 밝은 띠가 지나간다. 글자와 버튼의 위치는 유리 효과 아래에서 그대로 읽고 조작한다.

모니터가 열려 있을 때 2.4초 쉬고 3.6초 동안 희미한 띠가 아래로 내려간다. 탭을 바꾸면 주기를 다시 시작하고 모니터를 닫으면 멈춘다. 가는 주사선은 고정되어 있다. 단일 Godot CanvasItem 셰이더에서 화면을 복사하지 않고 합성한다. 1280×800에서 실제 이동 프레임 15장을 촬영했다. 밝기가 달라진 픽셀은 모니터 유리 안에 있었고 띠의 중심은 위에서 아래로 이동했다.

`OPEN_SHOP_CONSOLE_PREVIEW.cmd -Capture`에서 **803개 검사, 실패 0건**. 가로 크기 4종에서 표시부 범위와 터치 통과, 기록 전환, 보유금 연동과 지도 복귀를 확인했다. 뒤의 세 크기에서 기존 구매·재고 변경·탄 교체 회귀 검사를 실행했다. S26 크기는 PC GPU 확인이며 실기기 성능과 조작감은 확인 전이다.
