# UI·UX 도구 및 자료 점검

2026-10-17. 사용자 요청: 플레이 체감 피드백 이전의 UI·UX 보강을 위해 현재 스킬·플러그인과 추가 자료 필요성을 확인한다. 이번 작업은 준비 현황 및 화면 자료 검토이며 게임 코드·아트·밸런스·저장·APK를 변경하지 않았다.

## 판단

현재 구성으로 Godot UI 보강을 시작할 수 있다. 신규 플러그인이나 외부 UI 팩 구매는 필수가 아니다. 승인된 도트 UI와 기존 공통 스킨을 유지하고, 최근 추가된 코어·위력·개조·탄환 획득의 선택 흐름을 먼저 정리한다. 설치된 도구 수나 기능 테스트 성공을 직관성의 증거로 취급하지 않는다.

## 도구 확인

- Godot MCP: 실제 버전 조회 성공, `4.7.stable.official.5b4e0cb0f`.
- Impeccable: 로컬 engine-probe 성공, 엔진0.1.11. 설치 스킬4.5.0. 이번에는 웹 검사나 화면 수정 명령을 실행하지 않았다.
- Figma: 플러그인 디렉터리에서 installed=true/ENABLED. 계정 조회는 인증 재시도 안내가 두 차례 반환되어 계정 접근 확인은 미완료. 파일을 만들거나 게시하지 않았다. Godot 작업의 선행 조건으로 삼지 않는다.
- PixelLab: 같은 대화의 계정 조회에서 연결 확인. 필요 시 아트 보조로 사용하며 UI 구조 검토에 필수 아님. 이번 점검에서 생성하지 않았다.
- Product Design·MagicPath: 디렉터리 검색에서 미설치 후보 확인. 웹/앱 시안 제작 중심이며 현재 Godot 구현·검증 경로에 추가할 근거가 약해 설치하지 않았다.
- Superdesign: 스킬은 세션 목록에 있으나 이번 이름 검색 결과는 없었다. 서비스 연결을 확인했다고 보고하지 않는다.

## 화면에서 관찰한 보강 후보

최근 [첫 특수탄 선택과 교체 화면](earned_ammo_2026-10-17.md)을 열어 확인했다. 해당 보고서의 핵심9개 소스 해시가 현재 파일과 일치한다. 전체 프로젝트의 동일성을 증명하는 해시는 아니다. [열압 처치 캡처](build_payoff_2026-10-17/thermal_drive_impact_1008.png)는 이전 검증의 발사 중 상태로 참고했으며 새 본편 시작 덱을 보여주는 화면으로 간주하지 않는다.

1. **보상·탄환 교체:** 카드 효과와 아래 '영향'이 겹쳐 설명된다. 교체 창은 들어올 카드와 나갈 카드의 차이를 텍스트 수치로 읽어야 한다. 중복 설명을 줄이고 교체 전후·덱 장수·다음 전투 적용을 비교하기 쉽게 만드는 것이 우선이다.
2. **코어·파츠·탄환 관계:** 획득 화면과 전투에서 어떤 성장 효과가 실제로 적용됐는지 연결해 보여주는 방식 검토. 고정된 정답 탄환을 강요하거나 새로운 복잡한 상시 설명을 추가하지 않는다.
3. **전투 행동과 위험:** 장전 가능/확정/발사 중/과열/강제 냉각 상태에서 주 행동과 다음 상태가 읽히는지 점검한다. 이전 발사 중 캡처만으로 비활성 버튼의 가독성 결함을 단정하지 않는다.
4. **상점·파츠:** 현재 장착과 교체 후보의 이득·패널티·가격·여유 칸 비교를 같은 방식으로 통일하는지 확인한다.
5. **공통 조작:** 뒤로 가기·취소·선택 상태·스크롤 후 오선택·큰 글씨·긴 한국어·손패10장/덱14장 같은 최대 상태를 확인한다.

위 항목은 보강 우선순위이며 새 UI 구현 완료를 의미하지 않는다. 전투 계산과 밸런스를 유지한 상태에서 전후 비교가 가능하도록 작업 범위를 나누는 것이 적합하다.

## 추가 자료 필요성

사용자가 지금 추가로 제공해야 하는 필수 자료는 없다. 새로운 미술 방향이나 UI 팩도 필요하지 않다. 제작 쪽에서 현재 빌드의 전체 화면 흐름 캡처와 버튼·카드의 일반/선택/비활성/포커스 상태 비교판을 보완하면 된다. 기존 기준을 docs/direction/ 아래 연결하며 별도 PRODUCT.md/DESIGN.md를 기획 원본으로 만들지 않는다.

Galaxy 기종·표시 설정과 선택/스크롤 시 망설이거나 오입력한 짧은 영상은 후속 실기 판독·터치 확인에 유용하지만 작업 시작 조건은 아니다. 이번에는 실제 기기 테스트나 새로운 전체 UI 테스트를 실행하지 않았다.
