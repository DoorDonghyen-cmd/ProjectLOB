현재 화면 직접 시각 검토(자동 detector 결과를 읽기 전):
- 선택: 전체 배경, 중앙 인물, 좌측 총, 우측 복장, 하단 무기가 같은 공간에서 구성되어 있다. 공통 청록 카드가 있어도 주인공/배경이 시선을 먼저 받는다. UI 전체가 완벽한 것은 아니며 오른쪽 반복 카드, 작은 보조 설명은 남는다.
- 상점: 따뜻한 장소 그림은 작은 헤더 삽화이며 대부분이 짙은 단색 배경 위 큰 상품/상세 카드다. 같은 디더/깎인 모서리가 상품, 수치, 상세, 슬롯까지 반복된다. 상품 그림은 카드 면적에 비해 작고 카드 안 빈 공간은 커서 서식 틀이 먼저 보인다. 가격/품절/선택 표시는 기능적으로 좋다.
- 정비소: 장소 그림은 분명 존재하고 장면 자체는 어울린다. 작업 선택은 같은 크기의 제목+설명+버튼 카드 다섯 개라 기능 메뉴의 존재감이 강하다. 같은 무늬의 내부 버튼을 다시 넣어 테두리가 중첩된다. 주제는 공방인데 카드의 형태/아이콘은 작업별 구체성을 거의 주지 않는다. 작업별 별도 그림/수공예 소품을 무조건 추가하자는 결론은 아니다.
- 등반 최종 성공: 가로 배너, 같은 크기 통계 다섯 개, 교전/열 기록, 다른 재질 파츠 띠, 최종덱과 동일 비중 버튼 세 개가 순서대로 쌓인다. 성취의 주인공이 될 대표 결과/빌드가 없고 기록 항목이 평준화된다. 실패와 같은 구조라 감정의 차이가 제목과 색/문구에 의존한다.
- 보상: 주황 선택 버튼이 세 카드에 함께 있고 재질이 다른 파츠 안쪽 프레임과 청록 외곽이 중첩된다. 라인테마 공통색 자체가 원인은 아님(선택 화면도 동일 사용). 과거 강철/천 소재로 회귀하자는 결론도 아님.
- 객관성 한계: 관측 가능한 배치/색/크기/반복과 그것이 주는 상투적 인상이라는 디자이너 해석을 구분. AI가 만들었다는 판정이나 다른 모든 플레이어의 반응으로 일반화하지 않음. 기능 자동검사 수치로 미감을 입증하지 않음.
