## 확인한 동작

- `deck_loadout.tscn`이 요약, 현재 빌드, 보관함, 전술 덱 구역을 제공한다.
- 덱·장비에서 파츠 하나를 해제해도 나머지 장착 조합이 유지된다.
- `combat_workbench.tscn`이 전장, 단계, 탄환 후보, 발사 순서, 예측, 행동 영역을 제공한다.
- 영구 압축탄의 앞 고정·2칸 점유·뒤 고정 표시와 발사 결과가 유지된다.
- 같은 탄환을 터치 드래그하면 압축 코어만 소모하고 패 교환 횟수는 보존된다.
- 짧은 터치는 일반 장전으로 처리되고 끝 탄 회수 시 탄환과 코어가 정확히 복구된다.
- 1008×630 모바일 가로 화면에서는 탄환과 발사 순서를 한 화면에 유지한다.
- 840px 미만에서는 두 전투 구역이 한 열, 탄환 카드가 2열로 전환된다.

## 시각 검토

1280×800과 1008×630 모두 `전장 → 현재 단계 → 후보와 발사 순서 → 확정` 순서가 유지된다. 모바일 가로 화면에서 발사 순서를 접힘 아래로 보내지 않도록 900px 접힘 기준을 사용했다. 덱·장비는 5칸 현재 빌드를 먼저 보여 주고, 보관함 카드에는 장착 상태와 행동이 붙는다.

대표 화면은 `loadout_combat_ui_2026-09-24_assets/`에 보관한다.

- `combat_workbench_1280.png`: 1280×800 전투 작업대
- `combat_workbench_1008.png`: 1008×630 모바일 가로 전투
- `combat_compression_ready.png`: 전투 중 임시 압축 준비 상태
- `deck_loadout_1280.png`: 5칸 파츠와 보관함을 포함한 덱·장비

## 실행 환경과 범위

실제 사용자 저장과 분리된 `qa_runtime/city/ui_loadout_combat_final4` 프로필을 사용했다. 35층 입력 기준은 2026-09-21 최신 캠페인 검증 기록을 명시했다. 최종 아트가 아직 없으므로 픽셀 단위 레퍼런스 비교와 Galaxy 실기 촉감은 후속 아트·기기 검수 대상이다.
