# 탄환 역할 분리와 누적 강화 — 2026-10-14

## 결정 상태

사용자 승인: 모든 탄의 자체 피해가 좋은 구조를 벗어나, 준비·지원 탄을 연결해 공격탄의 숫자를 크게 만드는 방향. 단순 제한시간 추가나 개별 성능 상향보다 조합 보상을 중심으로 한다.

디렉터 구현: 기존18종을 유지하며 고출력 증폭탄을 **배율탄**으로 재정의했다. 내부 ID charge_hot는 기존 덱을 복원하기 위해 유지하되 독립 탄종으로 분류한다. 이하 수치/배율은 이번 적용안으로, 사용자 최종 밸런스 채택과는 구분한다.

## 현행 규칙

- 순수 지원: 증폭·배율·파쇄·냉각·예약·차단·불씨. 일반/압축/현장 압축 모두 직접 피해0, 직접 타격0. 무기·약점·파츠·강화 버프로 숨은 피해가 생기지 않는다. 배리어를 깎거나 쇄도 적중 횟수를 올리지 않는다. 파쇄 자체는 배리어를 소모하지 않고 장갑을 낮춘다.
- 공격: 기본·철갑·연타·전격·우회. 준비형 공격: 소이·충격. 마무리 공격: 기폭·추격·고열·열방출·연계. 준비형 공격은 여전히 공격이므로 강화 효과를 소비한다. 카드의 ‘다음 공격’은 순수 지원을 건너뛴다는 뜻이다.
- 일반 증폭: 직접 피해0 / 다음 **공격탄**1발 타격당+3 / 열3. 여러 증폭은 더해진다.
- 배율탄: 직접 피해0 / 다음 공격탄1발 ×2 / 열5. 증강은 효과 증가분을 두 배로 하여 ×3. 배율끼리는 곱한다. 증폭 시퀀서의 +1은 가산 증폭에만 적용한다.
- 압축 증폭: 직접 피해0 / 공격탄2발 +4 / 열5 / 마지막 발사 고정. 각 효과는 한 번의 재장전만 이월한다. 일반 증폭/배율을 압축 효과와 함께 쏘더라도 일반 효과까지 이월되지 않는다.
- 적용 순서: 공격탄 피해 + 증폭 + 약점/파츠/조건부 가산 → 배율 → 장갑 차감 → 타격별 판정. 연타는 같은 강화 수치를 각 타격에 쓴다. 화상/전이의 고정 효과 피해에는 공격 배율을 소급 적용하지 않는다.
- 층별로 적용 발수를 따로 보관한다. +3/1발과 +4/2발을 쌓으면 첫 공격+7, 다음 공격+4. 지원탄을 끼우거나 중간에 증강이 멈춰도 공격 전까지 보존. 공격이 배리어에 막혀도 강화는 소비한다.
- 일반 재장전은 미사용 일반 효과를 지운다. 과열로 강제 재장전하면 같은 재장전 규칙이 작동하므로 늦게 둔 공격이 나가지 못할 수 있다.
- 개별 직접 피해 조정(무기 보정 전): 충격3→1/압축5→2, 소이2→1/압축3→1, 전격3→2, 우회3→2, 추격2→1, 고열2→1, 기폭 계열2→0. 지속 피해·넉백·관통·조건 보상·열 수치는 유지. 기본/철갑/연타의 기본 피해는 이번에 더 낮추지 않았다.

공격탄 기본피해0인 기폭은 무기 공격 보정을 받을 수 있다. 위의 ‘순수 지원0’과 구분한다. 효과 설명과 실제 분류는 content.gd의 is_attack/ammo_role/primary_stat이 담당한다.

## UX 및 보상 연결

지원 카드의 가장 큰 숫자를 `피해0` 대신 다음 공격+3/×2, 장갑−3, 냉각−3, 예약 장수 등으로 바꿨다. 배율탄은 기존 도트 문법의 × 표식, 다른 이름과 효과를 사용한다. 발사 레일도 지원 효과를 보여 주며 지원탄에 강화가 소비되는 것처럼 표시하지 않는다. 실제 발사 중 다음 공격 슬롯에 남은 가산/배율을 보여 주고 효과별 남은 발수를 반영한다. 배율 피해는 강조 플로트와 계산식에 연결했다. 표기 피해는 실제 제거 HP이며 큰 숫자를 위해 허위 피해를 표시하지 않는다.

기존 보상/상점 공급 단계 유지, 증폭→배율 및 배율→증폭/연타/냉각의 빌드 보상 연결 추가. 배율탄은 기존 고출력 탄의 공급 단계부터 나온다. 압축 결과는 여전히 이월형 고급 증폭이며 배율탄으로 바뀌지 않는다.

## 검증

- 지원/조합 규칙 **624검사 실패0**: 5총기×순수 지원, 파츠/약점에 의한 피해 부활 방지, 배리어/쇄도 적중, 가산·배율 중첩, 서로 다른 지속 발수, 증강 단발 중단/재개, 이월/소멸, 압축·인벤토리 보존, 잘못된 저장 거부, 20시드 산개 실제 결과와 예측 범위, 미리보기 RNG 불변.
- UI **280검사 실패0**: 1008×630/1280×900/1440×630, 실제 터치 장전→확정→발사→재장전, 지원만 있는 손패의 유료 순환, 레이아웃 높이 불변. 기존 작업복5장 QA fixture로 카드와 전투를 검사했다.
- 기존 발열 **783검사 실패0**, 첫 지역 규칙 **4,461검사 실패0**. 저장 포맷 변경 후 v12→v13 보존과 v13 왕복은 집중 규칙에서 재검증했다.
- 실제 시작 덱·정찰복4장·6시드·5총기, 초반3편성 정책162회 + 장갑/원거리/증원 편성 정책162회. 모두 생존. 두 집합은 일부 편성이 겹치며 324개의 서로 다른 전투를 뜻하지 않는다. 성장/보상 없는 독립 전투이므로 새 배율 빌드 평가는 집중 검사로 분리한다.

**동일 패 비교:** 보행자/무장갑/충분한 적HP, 발사 순서 `증폭→배율→냉각→연타`는24피해, `배율→냉각→연타→증폭`은12피해. 첫 경우 (연타 기본2+보행자1+증폭3)×배율2×2타=24. 후자는 연타 뒤의 증폭이 공격을 강화하지 못한다. 이는 재현 가능한 조합 보상의 예이며 모든 적·무기에서 같은 피해를 보장하지 않는다.

가산 증폭2장→연타는18피해. 배율2장 사이 냉각 후 기본 공격은 ×4, 증강의 확장 탄창에서는 ×9를 확인했다. 후자는 기본 탄창3칸이 아닌 정식 용량+1 fixture이다. 대가인 카드/칸/열/행동은 실제로 소비한다.

## 저장과 검증 한계

전투 저장 버전13. v12까지의 이미 부여된 피해/잔여 공격 발수/이월/탄창 배열을 보존한다. 새 발사부터 지원을 건너뛰고, 새 고출력 ID는 배율 효과를 부여한다. 사용자 실저장은 열거나 덮어쓰지 않았다. 모든 QA는 격리 APPDATA/LOCALAPPDATA와 UI save_enabled=false.

초기 점검에서 Script.reload와 함수명이 충돌해 after_reload로 고쳤다. 저장 비교의 JSON 숫자형 차이, 증강 기본 탄창3칸을 넘긴 테스트 fixture와 다음 한 발/전체 탄창 예측 선택 오류를 수정했다. 마지막 실행은 모두 통과했다. 지원탄이 압력탄을 겨눴을 때 요격으로 잘못 표시되던 경로도 실제 제거 여부로 수정했다.

전체 캠페인 완주/모든 파츠 조합/모든 압축 변형/모바일 실기/사람의 재미 체감은 미검증이다. 초기 무작위 정책도 여전히 생존하므로 난도와 재미를 완성했다고 판단하지 않는다. 초과 피해 전이와 모든 파츠의 배율 개편은 이번에 추가하지 않았다. APK/커밋/푸시 없음.
