# UI·UX 직관성 블랙박스 검토

검토일: 2026-09-24  
대상: `prototype/core-redesign` 최신 UI  
기준: 처음 보는 플레이어에게 공개된 화면과 규칙 설명만 사용  
화면: 1280×800, 1008×630 모바일 가로

## 결론

현재 UI는 기능 접근성과 상태 정합은 높지만 직관성은 부족하다. 버튼을 찾아 진행할 수는 있어도, 핵심 재미인 `탄환 선택 → 순서 조합 → 결과 증폭`의 이유를 화면만 보고 빠르게 학습하기 어렵다. 아트 교체만으로 해결될 문제가 아니며, 정보 우선순위와 행동 흐름을 한 번 더 줄여야 한다.

## 핵심 문제

### 1. 전투가 결정을 설명하지 않는다

후보 탄환, 적 정보, 발사 큐, 예상 결과가 각각 존재하지만 시선으로 이어지지 않는다. 플레이어는 왼쪽 카드의 기호를 읽고, 위쪽 적의 작은 수치를 해석하고, 오른쪽 큐의 결과를 비교해야 한다. 탄을 추가했을 때 어느 적의 어떤 수치가 왜 변했는지 즉시 드러나지 않는다.

### 2. 모든 정보의 시각 무게가 비슷하다

상태바, 패널 제목, 카드, 보조 버튼, 주 행동 버튼이 비슷한 어두운 면과 외곽선을 쓴다. 화면에 정보는 정돈되어 있지만 먼저 봐야 할 한 곳이 약하다. `장전 확정`, `발사`, `이동`, `구매` 같은 주 행동은 채운 강조 버튼으로 분리할 필요가 있다.

### 3. 기호가 설명을 대신한다

탄환 카드의 피해·장갑·속성·압축 가능 표시와 적의 HP·장갑·행동 표기가 한꺼번에 등장한다. 각 기호는 일관되지만 처음 보는 사람에게는 아직 언어가 아니다. 특히 압축 가능 외곽선과 드래그 동작은 사전 지식 없이는 발견하기 어렵다.

### 4. 메타 화면은 비교보다 목록에 가깝다

상점은 구매 가능 여부는 분명하지만 새 파츠가 현재 빌드를 어떻게 바꾸는지 바로 비교하기 어렵다. 덱·장비는 현재 빌드, 보관함, 탄환 덱이 한 긴 모달에 들어가며 목적이 다른 세 작업이 경쟁한다.

### 5. 지도 선택이 행동으로 이어지는 과정이 약하다

이동 가능한 노드, 선택된 노드, 실제 이동 확정의 차이가 외곽선과 하단 카드에 의존한다. 첫 탭 뒤 무엇이 달라졌고 어디를 눌러 확정해야 하는지 더 직접적으로 보여 줘야 한다.

### 6. 초반부터 시스템 전체가 노출된다

크레딧, 압축 코어, 무기, 덱, 난도, 파츠 5칸, 적 규칙, 속성, 압축을 빠르게 만난다. 기능은 단계적으로 해금되더라도 화면 언어가 이미 전체 시스템을 전제로 한다.

## 우선 개편안

### P0 · 전투 결정 흐름

1. 후보 탄환 카드는 `이름 + 핵심 수치 하나 + 이번 상황의 결과`를 1차 정보로 보여 준다.
   - 예: `철갑탄 · 장갑 관통 · A에게 4 피해`
   - 나머지 수치와 규칙은 탭 상세로 보낸다.
2. 탄환을 장전하면 후보 카드에서 발사 큐로 이동하는 선이나 짧은 모션을 보여 준다.
3. 새 탄이 바꾼 결과만 강조한다.
   - `A HP 4 → 처치`, `B 장갑 관통`, `접촉 위험 해제`
4. 단계마다 주 행동 하나만 채운 색으로 강조한다.
   - 탄 선택 단계: `장전 확정`
   - 발사 단계: `발사`
5. 압축은 드래그 외에 `첫 탄 선택 → 같은 탄 강조 → 두 번째 탭으로 압축` 대체 입력을 제공한다.
6. 적 위 수치는 HP 바, 장갑 판, 행동 아이콘 세 가지까지만 상시 노출하고 나머지는 탭 상세로 이동한다.

### P1 · 지도와 상점

1. 지도 첫 탭은 하단에 선택 결과와 단일 `이 경로로 이동` 버튼을 연다. 같은 노드 재탭을 확정 규칙으로 사용하지 않는다.
2. 이동 가능 노드는 밝기와 형태로 분리하고, 전투·상점·보급·사건 아이콘을 크게 만든다.
3. 상점에서 상품을 선택하면 `현재 → 구매 후` 비교 영역을 하나 보여 준다.
4. 파츠 카드는 이득과 대가를 두 줄로 고정하고 상세 규칙은 선택 뒤 펼친다.

### P1 · 덱·장비

한 긴 모달을 세 목적에 따라 나눈다.

- `장착 파츠`: 5칸 구성과 선택 파츠 비교
- `보관함`: 파츠 목록과 장착·해제
- `탄환 덱`: 탄환 수량과 조합 분포

파츠를 고르면 현재 장착 파츠 하나와 나란히 비교하고, 변화한 수치만 색과 화살표로 표시한다.

### P2 · 학습과 공통 문법

1. 시작 전 큰 설명창보다 실제 첫 장전, 첫 경로 선택, 첫 파츠 구매 순간에 한 문장 안내를 붙인다.
2. 아이콘은 첫 3회까지 이름을 함께 표시하고 이후 설정에서 축약할 수 있게 한다.
3. 색 역할을 고정한다.
   - 민트: 선택·진행
   - 노랑: 보상·성장
   - 주황: 위험·대가
   - 시안: 전기·압축
4. 상단 공통 상태바는 현재 결정에 필요한 항목만 남긴다. 난도와 덱 장수처럼 매 순간 필요하지 않은 값은 메뉴나 덱 화면으로 이동한다.

## 권장 작업 순서

1. 전투 카드와 결과 연결, 주 행동 강조, 압축 대체 입력
2. 지도 선택·확정 분리
3. 상점 구매 전후 비교
4. 덱·장비 3탭 분리
5. 맥락형 초반 안내와 아이콘 학습
6. 위 구조가 검증된 뒤 최종 아트와 사운드 적용

## 검증 방법

- 규칙 설명을 읽지 않은 신규 플레이어가 첫 전투에서 `탄 선택 → 순서 확인 → 확정 → 발사`를 도움 없이 완료하는지 본다.
- 각 선택 전 플레이어에게 “왜 이 탄/경로/파츠를 골랐는가”를 묻고 화면에 근거가 있었는지 기록한다.
- 서로 다른 세 플레이 성향에서 압축 발견, 순서 변경, 상점 비교, 지도 확정을 반복 관찰한다.
- 자동 입력 성공률과 별도로 첫 행동 시간, 잘못 누른 횟수, 상세창을 연 횟수를 기록한다.

현재 자동 테스트의 성공은 기능 접근성과 상태 정합을 증명한다. 이 보고서의 직관성 평가는 실제 플레이어가 선택 이유를 이해하는지에 대한 별도 판단이다.
