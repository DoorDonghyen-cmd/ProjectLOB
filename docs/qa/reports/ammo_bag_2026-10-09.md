# 전투 탄환 가방 UI

2026-10-09 · 활성 Godot4.7 작업 트리. 사용자 요청: 버튼으로 보유 탄·사용한 탄 등 순환 상태 열람.

## 적용

전투 탄환 선택 영역 오른쪽 `탄환 가방` → 전체 화면 열람. 전체 보유 / 손패 / 장전 / 뽑을 탄 / 버린 탄 탭과 수량, 공통 탄환 카드와 상세 설명. 같은 탄은 묶어서 수량 표시하되 장전 탭은 실제 발사 순서대로 개별 표시한다. 뽑을 더미는 탄종 기준 정렬이며 숨은 추첨 순서를 추가로 공개하지 않는다.

편집 중 장전한 카드는 손패에서 제외하여 중복 집계를 막는다. 임시 압축 원본2장/장전1장의 차이는 별도 안내한다. 버린 탄에는 사격·교환·재장전 시 남긴 패가 포함되고 덱이 비면 다시 섞인다고 안내한다. 구 저장의 별도 기본탄은 덱 보유 수에 포함하지 않는다.

닫기/뒤로 가기로 전투 복귀·버튼 포커스 복원. 상태 복사본만 읽으므로 열람으로 턴·패·발사 순서·RNG가 변경되지 않는다. 탭·닫기·선택 탄의 설명은 목록 스크롤 중에도 고정한다.
