# 전투 화면 총기 크기

본편 등반과 입문 전투에서 플레이어가 든 총기 7종을 15% 확대했다. 캐릭터 몸, 발 위치, 장비 선택과 작업실 표시에는 기존 배율을 쓴다. 양손으로 잡는 자세에서는 두 파지점의 중간을 기준으로 확대하고, 한 손으로 잡거나 장전 중 앞손이 떨어지는 자세는 주 손을 기준으로 잡는다. 총구와 탄환 시작점은 총기와 같은 좌표 변환을 사용한다.

동일한 시드 17, 운반복, 첫 전투의 조준 자세에서 기존 배율과 새 배율을 비교했다. 비교 그림에서 캐릭터 부분을 2배로 확대했다. 갤럭시 화면 비율은 PC에서 재현했다.

## 검증

- 총기 7종과 두 화면 크기에서 본편과 입문 전투의 확대, 장비 선택의 기존 배율, 파지 위치와 총구 좌표 100건 통과.
- 총구 섬광과 투사체 3,217건, 스파이크의 7복장 반동·재장전·냉각 196건, 신규 총기 장비 선택·사격·저장 151건 통과.
