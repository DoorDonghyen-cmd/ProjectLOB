# 주인공·적 도트 표현 통합 — 2026-10-05

후속: 사용자가 더 뭉개진 표현을 요청해 [주인공 v2](hero_mass_v2_2026-10-05.md)를 적용했다. 아래 화면·8개 자산 기록은 1차 수정 당시 증거로 보존한다.

사용자가 배경까지 고려해 주인공 표현을 더 뭉개자는 방향으로 제작을 승인했다. 선택한 C 복장+B 방한모, 자세·총 방향·0.65 표시 배율을 유지하고 내부 선과 반사광을 큰 청회색 면으로 정리했다. 압력두꺼비와 기존 적 6종에도 같은 표현을 적용했다. 본편 `PLAY.cmd`와 전투 샘플에서 사용하며 원본은 보존한다. 새 시각 결과에 대한 사용자 확인은 아직 받지 않았다.

| 배치 | 적 리소스별 영역·화면 크기를 지정하고 발/기존 부유 높이에 고정. 증원 아이콘도 같은 그림 사용 | 이동·피격 오프셋 유지. 큰 적은 명찰 아래에 들어오도록 높이를 조정 |

배경 PNG, 탄환 카드, 전투 수치, 저장 모델은 이번 작업에서 바꾸지 않았다. 기존 `pixel_art.gd`의 탄환 변경분을 보존하고 자산 선택과 스프라이트 영역만 추가했다.

## 제작 파일·방법

[자산 폴더 설명](../../../새-게임-프로젝트/assets/art/actor_cohesion_20261005/README.md), [출처·크기·해시·프롬프트 파일 목록](../../../새-게임-프로젝트/assets/art/actor_cohesion_20261005/provenance.json).

내장 `image_gen.imagegen`으로 제작했다. 주인공·기존 6종은 각 1254×1254 RGBA, 개구리 아틀라스는 1774×887 RGBA다. 8개 PNG 모두 생성 원본과 SHA-256이 같다. PNG 자체의 후처리 없이 Godot `AtlasTexture`/영역 렌더와 nearest 표시를 사용한다. `actors.tres`에 적별 영역과 표시 크기가 있다.

화풍 지시는 큰 도트 군집과 제한된 명암이지만, 생성 결과를 엄격한 고정 팔레트/완벽한 픽셀 격자로 검수했다고 주장하지 않는다. 미약한 알파 픽셀이 남아 있어 알파 128 이상 외곽을 분석해 영역을 정했으며 실제 배경에서 투명 여백·테두리·작은 크기를 확인했다. 최종 수작업 스프라이트와 애니메이션 제작 때 정규화할 여지는 남아 있다.

## 검증

- 교체 전 기준 화면: 125검사/실패0. 교체 후 확장 검사: **350검사/실패0**. 검사 범위가 늘었으므로 두 수를 품질 개선 비율로 비교하지 않는다.
- 1280×900, 1008×630, 1440×630 실제 본편. 화면 스크롤/컨트롤 경계, 동일 지면, 적 명찰 가림, 네 적 편성, 전체 7종의 중심 클릭 판독, 증원 아이콘을 확인했다.
- 공개 버튼으로 장전→발사→준비 1턴→재장전/공격체 발사→요격, 차단탄의 준비 정지를 실행했다. 표시 적/공격체와 모델 상태가 일치한다. 요격 후 제거된 공격체 기록이 배열에 남는 모델에 맞춰 활성 위협의 소멸을 검사한다.
- [최종 실행 로그](actor_cohesion_2026-10-05_assets/after_stdout.log), [stderr](actor_cohesion_2026-10-05_assets/after_stderr.log). import와 최종 UI 검사에 스크립트 오류 없음. 환경의 기존 Windows 인증서 저장소 경고는 남는다.
- 별도로 실행한 예전 `ranged_ui_runner.gd`는 폐기된 `reload_heat` 필드를 참조해 중단됐다. [로그](actor_cohesion_2026-10-05_assets/legacy_ranged_attempt.stderr.log). 해당 오래된 열/재장전 가정의 전체 테스트를 이번에 통과했다고 집계하지 않는다. 현행 본편의 준비·발사·요격·차단은 위 새 검사로 확인했다. 이 과거 검사 이관은 후속이다.
- APPDATA/LOCALAPPDATA를 `qa_runtime/actor_cohesion/` 아래로 격리했고 본편 저장을 비활성화했다. 기존 사용자 저장은 사용하지 않았다.

재실행: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/run_actor_cohesion_checks.ps1`
