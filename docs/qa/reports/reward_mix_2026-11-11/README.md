## 규칙 (새 등반, `reward_mix.gd`)

일반 전투·탄약고 3장 = 주력 1장(강화가 있으면 강화) / 다른 공격탄 1장(덱에 가장 적게 가진 계열) / 주력 지원탄 1장. 이전은 [주력 복사, 지원탄, 주력 강화]. 예: 래칫 2구역 [연타탄, 배율탄, 증폭탄] → [연타탄, **우회탄**, 배율탄].

- 다른 공격탄을 고르면 끝 덱의 공격탄이 10종까지 퍼지고 기본탄이 줄었다. 리벳·리액터는 빨라지고 래칫은 느려졌다(+19~33%).
- 자동 선택은 다른 공격탄이 나오면 무조건 고른다. 사람은 고를 때만 고르므로 실제 덱은 그 사이일 것이다.
