# ORVASK — 무기 적용과 도트 화풍 통합

2026-10-24. 사용자 요청에 따라 다섯 무기 본편 적용 → 배경 기준 화풍 조정 → 화면/동작 검증을 수행했다. 그림을 포함한 PDF는 Google Drive의 `ORVASK - Reports`에 전달한다. 업로드 확인 후 PC 종료 요청을 이행한다.

## 적용한 결과

- 리벳 / 래칫 / 스플린터 / 리액터 / 스파이크를 장비 선택·전투·빌드·도움말에 연결했다. 내부 ID는 유지했다.
- 스플린터는 승인한 원통형을 유지하고 황토색 몸체를 바랜 회녹색으로 바꾼 v4를 새로 제작했다. 기존 원본·전체 프롬프트·해시를 보존했다.
- 다섯 총기의 손잡이, 보조 손, 총구, 재장전 부품, 발열 면을 한 등록표로 관리한다. 리벳/스파이크 한손, 나머지 양손을 유지했다. 리벳의 작아진 크기를 유지했다.
- 전투의 저해상도 총기 표시를 래칫 전용에서 다섯 총기 공통으로 바꿨다. 장비 선택의 큰 총기는 128열 기준 표시로 작은 부품선이 인물보다 과하게 선명하지 않게 했다. 생성 원본을 파괴적으로 축소하지 않았다.
- 인간형·주조장 기계·정원 생물·기존 정예/보스의 표시에서 잔묘사를 화면 기준 약1.5px 덩어리로 묶고 가장 어두운 경계만 청회색 그림자 계열로 완화했다. 블러·외곽선 팽창은 사용하지 않았다. 25% 피니시 줌에서도 같은 소스 격자가 확대된다.
- 무기 미리보기 `WEAPON_CONCEPTS.cmd`를 본편 5종과 원본/전투 밀도 비교로 갱신했다. 기존/신규로 잘못 표기되던 두 종 비교는 해제했다.

## 리액터 규칙

새 등반은 탄창6 / 열 한계14 / 냉각8 / 기본 재장전2턴이다. 열 한계에 닿으면 다음 탄 카드1장만 강행한다. 연타는 카드의 두 타격을, 지원탄은 그 지원 효과를 그대로 처리한다.

| 상황 | 처리 |
|---|---|
| 과열 없음 | 전탄 연쇄, 일반 재장전2턴 |
| 한계 도달, 강행할 탄 없음 | 사격 종료 후 강제 재장전3턴 |
| 강행 후에도 과열 | 사격 종료 후 강제 재장전4턴 |
| 강행 냉각/처치 냉각으로 한계 미만 | 강제 재장전 없이 입력 종료, 남은 탄 보존 |
| 마지막 위협 제거 | 불필요한 강제 재장전 없음 |
| 후속 증원 남음 | 종료로 간주하지 않고 실제 적 행동/냉각 비용 적용 |

사격 자체1턴은 재장전 비용과 별도다. 파츠 보정은 실제 예측에 반영한다. 발열 안내와 발사 애니메이션에 강행1발·강제 재장전 비용을 표시했다. `weapon_version=1`을 새 등반에 저장하며 기존 저장은4칸/13한계/6냉각/1턴과 화상4·전이3의 이전 능력을 유지한다.

## 화풍 검토 판정

| 자산군 | 이번 판정과 처리 |
|---|---|
| 주인공·복장 | 승인된 큰 색면과 파지 재사용. 새 무기와35개 조합의6자세를 렌더 검수. 기존 기본3복장은 같은 전투 몸체 계열을 공유하며, 새 독립 의상 애니메이션을 제작한 것은 아님. |
| 무기 | 다섯 신규 아트와 공통 표시 밀도, 소품 밖 발열 잔상 방지. |
| 일반·정예·보스 | 기계의 작은 검은 선과 생물의 큰 면 차이를 줄이되 금속/생물 재질 차이는 유지. |
| 배경 | 현재1~5구역 배경을 비교 기준으로 보존. 서로 다른 구역의 조명/색을 하나로 덮지 않음. |
| 상점·정비·보급 | 기존 공통 실내와 분리된 인물 레이어를 실제 화면에서 확인. 이번에는 원화를 다시 생성하지 않음. |
| 탄환·파츠·UI | 이미 승인된 큰 아이콘, 금속 패널과 서체 대비를 유지. 글자와 적 행동 예고에는 배우용 격자 처리를 적용하지 않음. |
| 지도·타이틀 | 현재 구도와 기호의 역할 유지. 신규 무기명 연결과 화면 조화를 확인. |

실제 동작2977프레임 관찰에서 거리 순서/접지 오류0. PC Godot4.7 Compatibility에서1280×900,1008×630,1440×630 화면을 확인했다. 전투는 프로젝트의1280×800 논리 화면/확장 스케일을 사용한다. 장비 검사에는1008×630 논리 화면과 확대 글자도 포함된다.

기존 장비 검사에는 현재 기본탄20장 출발 이전의10장/특수탄 출발 기대값이 남아 있었다. 실제 캠페인 생성 결과를 기준으로 수정했다. 첫 통합 검사의 화면 넘침은 검수기가 실제 전투와 다른 논리 해상도를 강제한 원인이었으며, 실제 프로젝트 설정으로 재검증했다. 중간 실패를 최종 통과 수에 중복 합산하지 않았다.

전투 탐색은5무기×정예/보스×2시드의20조건 중19조건에서 제한 탐색으로 승리 경로를 찾았다. 리액터 보스731042는 탐색 폭을 넓힌 뒤13턴/22장 사용/4장 잔여로 성공했다. **이는 사람의 승률이나 균형 확정이 아니다.** 같은 통제 조건에서 리액터가 다른 무기보다 탄약을 많이 사용하는 경향이 있어 플레이 테스트의 우선 관찰 항목으로 남긴다.
