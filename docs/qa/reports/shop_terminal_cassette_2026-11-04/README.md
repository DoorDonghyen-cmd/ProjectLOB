# 카세트 단말 시안

이 문서는 오른쪽 카세트 모듈을 사용한 외형의 기록이다. 실행 파일은 [최신 하단 조작부 시안](../shop_terminal_data_deck_2026-11-04/README.md)을 연다.

[같은 크기에서 이전 외형과 비교](before_after_1280x800.png) · [재고](stocked_1280x800.png) · [현장 기록](record_1280x800.png) · [S26 가로 재고](stocked_2340x1080.png) · [S26 안전 영역 크기의 우수 정원 기록](garden_record_2160x1032.png)

`OPEN_SHOP_TERMINAL_PREVIEW.cmd`를 열면 이 시안이 실행된다. 축열 주조장이 기본이며, `현장 기록`을 열면 오른쪽 카세트 릴과 표시등의 색이 바뀐다.

바랜 회갈색 사출 케이스 안에 검은 화면을 한 단 넣었다. 오른쪽에는 두 릴이 보이는 테이프 모듈, 상태등 두 개, 통풍구를 배치했다. 카세트 모듈은 기록 탭 상태를 시각화하며 텍스트와 탭은 기존 Godot 조작을 사용한다. 1280×800에서 모듈 폭을 확보하도록 단말 외곽을 1,104px로 조정했다. 본편 반영 전 시안이다.

`OPEN_SHOP_TERMINAL_PREVIEW.cmd -Capture`에서 **685개 검사, 실패 0건**. PC GPU에서 1008×454, 1280×800, 2340×1080, 2160×1032의 화면과 탭 전환에 따른 표시등 상태를 확인했다. 거래 회귀 검사는 뒤의 세 크기에서 실행했다. S26 실기기 조작은 확인 전이다.
