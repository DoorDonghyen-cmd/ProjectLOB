# 첫 관문 여정의 모바일 전달 준비 — 2026-11-01

## 완료 범위

사용자의 다음 스텝 요청에 따라 기존 모바일 빌드 도구에 **`magazine-journey` 모드**를 연결했다. 최신 라인 + 도트 HUD, 5연속 전투, 실제 코어/탄 보상, 무료 정비2곳을 시작 화면으로 선택할 수 있다. 기본 `campaign`과 기존 `weapon-magazine` 모드는 유지한다.

이번에는 **Android용 리소스 묶음의 생성·실행 검사까지** 진행했다. APK 생성·서명·설치·업로드를 수행하지 않았고 기존 `builds/mobile/latest.json`은 그대로다. 실제 휴대폰의 터치·복귀·지속 FPS·발열은 미측정이다.

## 연결한 내용

- `tools/mobile_play_modes.json`에서 모드별 시작 씬·컨트롤러·설치 안내·설명을 함께 관리한다. 빌드와 검증이 같은 시작 씬을 확인한다.
- `build_mobile_release.ps1`과 `export_city_android.ps1`에 새 모드를 추가했다. 기존처럼 빌드 중에만 시작 씬을 바꾸고 원본 설정 바이트를 복구한다. 현재 기본 진입을 여정으로 바꾸지 않았다.
- 여정의 실제 씬 참조·동적 라인 틀·폰트와 공통 `class_name` 의존성을 포함한다. 정해진 비교 전투 JSON을 여정 덱/적 상태로 주입하지 않는다.
- APK 검사에서 여정/HUD/보상/경로 리소스와 실제 시작 씬을 확인한다. 검증 뒤 모드가 달라진 manifest는 포장하지 않는다. 전달 요청에도 플레이 모드와 시작 씬을 기록한다.
- [여정 설치 안내](../../mobile_journey_install.md)를 준비했다. 두 단계 빼내기, 실제 보상 확정, 재도전/새 출발, 별도 여정 저장과 첫 관문 종료를 설명한다.
- `tools/check_mobile_journey.py`는 원본을 변경하지 않고 격리 복사본에서 Android 리소스 ZIP을 컴파일한다. 실제 APK 검증과 동일한 리소스 검사·실행 probe를 재사용한다.

## 독립 리소스 검사에서 발견한 문제

첫 복사본 검사에서 `map_generator.gd`의 `RunManager` 참조가 누락되어 컴파일되지 않았다. 기존 리소스 선택기는 `res://` 문자열만 추적했기 때문이다. 전역 `class_name` 참조까지 추적하도록 수정했다. 기존 독립 비교 목록174개는 전부 유지되며13개 공통 의존성이 추가됐다.

검사 환경의 기본 임시 폴더에 Godot의 `tmpproject.binary`를 만들지 못하는 문제도 재현했다. `TEMP`/`TMP`를 검사/빌드의 격리 폴더로 지정하고 빌드 후 기존 환경 값을 복원하게 했다. 단위 검사의 동일한 임시 폴더 권한 실패도 경로를 바꿔 재검증했다.

한 차례 초기 import는 완료 로그 뒤 비정상 종료했으나 동일 복사본의 재실행은0으로 종료했다. 검사기는 오류 메시지 없는 import의 비정상 종료에만 한 번 재시도하며, 재시도 역시 정상 종료해야 통과한다. 최종 실행은 import와 export 모두 첫 실행 종료0, 진단 오류0이었다. 실패 자료는 `qa_runtime/mobile_journey_20261101/20261101-094900-683301`, `20261101-095005-395763`, `20261101-095055-209786`에 보존했다.

## 다음 전달과 미검증 범위

APK 요청 시 기존 빌드 명령에 `-PlayMode magazine-journey -Architecture arm64`와 해당 버전 변경 내역을 지정한다. APK 서명·정렬·포함 리소스·최종 용량을 확인하고 기존 절차대로 ZIP/Drive 전달한다. 리소스 ZIP의 크기로 실제 APK 용량이나 업로드 가능 여부를 단정하지 않는다.

휴대폰에서는 [지속 플레이 절차](../protocols/mobile-sustained.md)에 따라 초기와 관문/반복 플레이 후반의 프레임, 기기 열 상태, 앱 전환·재실행을 확인해야 한다. 이번 PC 리소스 실행은 Android 설치/터치/안전 영역/성능 통과의 대체 근거가 아니다. 새 탄창 전투의 본편 기본 캠페인 전환은 여전히 별도다.
