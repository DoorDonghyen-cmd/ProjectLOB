# 모니터와 옆 조작기 상점 시안

이 문서는 CRT 효과 적용 전 캡처다. 같은 실행 파일에서 [최신 CRT 시안](../shop_console_crt_2026-11-04/README.md)을 볼 수 있다.

[HP 2644A 안과 같은 크기로 비교](compare_1280x800.png) · [재고](stocked_1280x800.png) · [현장 기록](record_1280x800.png) · [구매 뒤 보유금](purchased_1280x800.png) · [S26 가로 재고](stocked_2340x1080.png) · [S26 안전 영역 크기의 우수 정원 기록](garden_record_2160x1032.png)

저장소의 `OPEN_SHOP_CONSOLE_PREVIEW.cmd`로 연다. 오른쪽 조작기의 `재고`와 `현장 기록` 키가 왼쪽 모니터를 바꾼다. 구매와 새 진열에 따라 오른쪽 보유금 표시가 바뀌고, 기록을 열면 기록 키 아래 슬롯의 표시등이 켜진다.

《Stories Untold》의 독립 모니터와 별도 장비, 《Nauticrawl》의 조작과 반응을 가까이 배치하는 방식을 참고했다. 큰 화면에는 현재 구역과 상품 또는 기록을 배치하고, 옆 장비에 보유금과 조작을 모았다. [레퍼런스 비교](../../../art/references/2026-11-04-ui/cassette-futurism-study.md)

별도 시안 씬이 기존 거래 시안을 상속한다. 두 시안은 상점 데이터와 조작을 공유하고 실행 파일이 각각 있다. 기존 하단 조작부 시안은 `OPEN_SHOP_TERMINAL_PREVIEW.cmd`에서 비교한다.

`OPEN_SHOP_CONSOLE_PREVIEW.cmd -Capture`에서 **731개 검사, 실패 0건**. 1008×454, 1280×800, 2340×1080, 2160×1032에서 버튼과 화면의 분리, 보유금 연동, 기록 표시등, 탭 전환 중 선택 유지, 지도 복귀를 확인했다. 뒤의 세 크기에서 구매·품절·새 진열·보관·탄 교체 회귀 검사도 실행했다. 기존 하단 조작부 시안은 **697개 검사, 실패 0건**. 둘 다 본편 적용 전 시안이며 S26 크기는 PC GPU 캡처다.
