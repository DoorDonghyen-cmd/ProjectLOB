# 전술 작업대 UI 독립 화면 검토 — 2026-09-11

**판정: 정지 화면에서 정보 비교와 장전 규칙 안내의 개선을 확인했다. 실제 장전 순서·버튼 동작·사용자 이해도는 미검증이다.**

신규 플레이나 실제 사람의 체감 측정을 수행한 보고가 아니다. 변경 전후의 화면 원본만 비교했다. 명백하게 보이는 배치·표시 상태와 플레이 중 확인해야 하는 해석 가설을 구분한다. 기능 통과 또는 재미 통과 판정으로 사용하지 않는다.

## 검토 범위

경험 QA 스킬과 재미·UX 루브릭의 공개 정보 원칙을 적용했다. 이번 검토에서는 소스 코드, GDD, 기존 QA 결론, 다른 검토자의 결론을 읽지 않았으며 다른 에이전트를 생성하지 않았다. 이 보고서만 작성했다.

변경 전 원본 위치는 `qa_runtime/preart_20260911/visual/final/artifacts/`, 변경 후는 `qa_runtime/preart_20260911/visual/workbench4/artifacts/`다. 변경 후 생성 완료 통지를 받은 뒤 아래 원본을 직접 열람했다.

| 화면 | 변경 전 | 변경 후 | 검토 범위 |
|---|---|---|---|
| `title.png` | 있음 | 있음 | 안내 진입과 첫 화면 문구 |
| `loading_guide.png` | 있음 | 있음 | 역순 장전·피해 조건·행동 예산 설명 |
| `management_roster.png` | 있음 | 있음 | 기본 전장의 적 배지, 다음 탄 정보, 버튼 |

총 10장이다. 전후 `ammo_hand.png`는 각각 전장과 열린 작업대를 보여주므로 같은 UI 상태의 일대일 비교로 취급하지 않았다. `workbench_four_enemies`와 `workbench_wide`는 변경 전 대응 파일이 없어 새 화면 자체를 검토했다. 다른 화면은 960×540이다. 좌표는 원본의 대략적인 위치다.

## 확인된 개선과 현재 표시 상태

### 적 정보와 후보를 함께 읽을 수 있음

변경 전 `management_roster`의 전장 중앙에는 네 적의 HP 막대와 작은 상태 배지가 근접해 있다. 변경 후 기본 전장에도 해당 밀집 배치는 남아 있다. 새 `workbench_four_enemies`에서는 상단 y64–127에 네 적의 이름·HP·장갑·회피·거리·속도·태세 정보가 별도 사각 영역으로 나뉜다. 이 요약 영역에서는 서로의 텍스트가 가리거나 이름이 잘리는 현상을 확인하지 못했다.

첫 대상은 “첫 표적”으로, 나머지는 2·3·4번으로 구분된다. 후보 카드와 같은 화면에 적 조건이 있어 화면에 표시된 장갑·회피와 카드 조건을 대조할 수 있다. `ammo_hand`와 `workbench_wide`의 세 적 요약도 독립된 영역에서 읽을 수 있다. 실제 대상 선정·전환 때 번호가 어떻게 갱신되는지는 정지 화면으로 확인하지 않았다.

후보에는 경량탄·교란탄·천공탄 등의 이름과 “회피 8까지 명중”, “방어 4까지 관통”, 효과 설명, 현재 적에 대한 명중·관통 판정이 표시된다. 색 외에도 명중·관통·화력·제어라는 역할 이름과 기호를 사용한다. 이는 역할 구분의 근거가 되지만 역할명만으로 모든 효과나 유효성이 보장된다는 뜻은 아니다.

### 장전과 발사의 구분이 명확해짐

`loading_guide` 제목이 변경 전 “장전 순서가 사격 순서가 된다”에서 변경 후 “마지막에 넣은 탄이 먼저 발사된다”로 바뀌었다. 본문의 역순 예시와 제목이 같은 의미를 전달한다.

작업대 상단에는 “순서 설계 · 장전 중 턴 진행 없음”, 적 요약 아래에는 “마지막 장전 → 첫 발사”, 왼쪽 슬롯 위에는 “발사 순서 · 위부터 ↓”가 보인다. 하단은 “최근 장전 취소 · 비용 없음”과 “0발 장전 확정 · 발사는 별도”로 나뉜다. 장전 계획을 고치는 것과 실제 발사가 서로 다른 행동임을 화면 자체에서 설명한다.

다만 세 작업대 원본 모두 슬롯이 0/5이며 하단 버튼이 회색이다. 실제로 탄을 채웠을 때 새 탄의 삽입 위치, 첫 발사 표시, 이름·효과의 잘림, 취소 결과, 확정 버튼 활성화 및 확정 후 전환은 검증하지 못했다. 회색 버튼의 실제 비활성 여부도 클릭으로 확인하지 않았다.

### 후보와 발사 슬롯은 별도의 스크롤 영역

960 화면의 후보 첫 줄은 카드 전체가 보이며 다음 줄은 일부만 보인다. 후보 오른쪽 스크롤바가 있어 화면 아래에 추가 후보가 있음을 나타낸다. 공개 패 화면에서는 후보 위에 “다음 보충 2”와 충격탄·파쇄탄의 별도 작은 카드가 보인다. 이 두 카드는 바로 아래 장전 후보와 다른 영역에 있으나 초보자가 보충 예고와 즉시 선택 가능 대상을 구별하는지는 확인하지 않았다.

왼쪽 발사 슬롯은 0/5라고 표시하지만 960 화면에서 네 칸만 전체가 보이고 다섯 번째는 y451 이후 일부만 보인다. 1280×720에서도 네 칸 전체와 다섯 번째 윗부분만 보인다. 왼쪽 슬롯 전용 스크롤바가 있으므로 마지막 칸이 영구히 가려졌다는 결함은 아니다. 그러나 현재 화면만으로는 다섯 칸의 전체 순서를 동시에 확인할 수 없다.

### 기본 전장과 도움말의 남은 제한

변경 후 `management_roster`는 다음 탄 설명을 왼쪽 아래로 옮겼다. 하단 버튼은 “빼내기 · 탄 소멸”, “리로드 · 1턴”, “가방”, “발사”다. 리로드에는 시간 비용을, 빼내기에는 자원 소모를 표시하므로 비교하는 비용 축이 서로 다르다. 발사에는 비용 문구가 없다. 이 화면만으로 발사·빼내기의 적 접근 비용까지 완전히 설명할 수 없다. 실제 비용이 몇 턴인지는 추정하지 않았다.

`loading_guide`의 4번 “거리가 행동 예산이다”는 처음 펼친 화면 하단 y411–427에서 문장이 중간에 끝난다. 스크롤바가 보이므로 정보가 없거나 스크롤로도 읽을 수 없다는 결함은 아니다. 다만 처음 보이는 화면에는 장전 취소와 교전 행동 비용의 설명이 끝까지 나오지 않는다.

`title`에는 눈에 띄는 변경이 없으며 장전 안내와 런 시작 버튼이 구분되어 있다. 안내를 실제로 찾고 읽는지는 이 캡처로 판단하지 않았다.

## 문구와 역할 해석에서 확정하지 않은 사항

- “명중”, “관통”, “화력”, “제어”는 새 작업대 카드의 역할 표제다. 관통 카드라도 첫 표적의 회피 조건을 통과하지 못하는 판정이 함께 보인다. 화면은 명중과 관통을 분리해 제공하므로 “관통 역할이면 항상 적중한다”는 잘못된 규칙을 직접 주장한다고 판정하지 않았다.
- 카드 판정 위의 “조건부 파츠 제외”는 계산 범위를 제한하는 문구다. 어떤 조건부 보정이 빠졌는지 이 화면만으로 설명되지 않지만 실제 파츠 상태나 틀린 판정 여부를 추정하지 않았다. 조합을 갖춘 상태에서 판정과 발사 결과의 관계를 별도로 확인해야 한다.
- 기본 전장에 “약실 비어있음”과 “다음 발 · 기본 탄도”가 함께 보인다. 아래에는 가방에서 장전하라는 설명이 있어 즉시 발사 가능하다고 명시한 것은 아니다. 다만 “다음 발” 제목을 현재 탄이 있다는 의미로 받아들이는지는 사용자 확인 항목이다.
- 보충 예고, 후보 선택, 슬롯 삽입, 전장 보기의 실제 클릭 결과는 원본에 없다. 이 보고서에서는 작동하거나 작동하지 않는다고 평가하지 않는다.

다음 검증에는 실제 1발·혼합 5발 장전 화면, 취소와 확정 직후 화면, 교전 중 행동 비용이 드러나는 전후 화면이 필요하다. 초보자가 역할과 현재 표적 판정을 설명할 수 있는지, 전체 순서를 확인하는 데 스크롤이 방해되는지, 읽기 피로가 줄었는지는 **인간 확인 필요**다.
