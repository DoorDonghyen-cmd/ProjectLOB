# 파츠 효과 검토 — 지금 탄환·전투에 맞는가

2026-11-11. 사용자: "파츠 효과가 지금 탄환과 전투에 적합한지 검토해 줘". 기준 규칙: 성장 v2, 과열 대가, 섞인 탄 보상, 교차 사격, 탄환 회수, 현재 구성(태그 시험판 제외).

## 방법

- `tests/part_value_bench.gd`: 최신 자동 등반(시드 17, 다른 탄도 고르는 선택)의 4·5구역 실제 전투 4개를 총기마다 골라, **파츠를 하나씩만** 장착하고(총기 내장 구동은 유지) 해법기로 이긴다. 적 턴 합계를 '파츠 없음'과 비교한다. 발동률 = 그 파츠가 효과를 남긴 발사 비율.
- 기준(파츠 없음): 리벳 61턴, 래칫 100턴, 리액터 86턴. 1턴 ≈ 1~1.6%라 ±3%는 차이 없음으로 본다.
- 한계: 시드 하나, 전투 4개. 해법기는 빼내기·회수를 노리지 않는다. 섞인 덱에서 쟀으므로 주력만 쓰는 덱과는 다를 수 있다. 원자료: [표](bench_table.txt), `part_value_*.json`.

## 읽을 점

1. **고장 난 파츠가 있다**: 야전 압축기는 지금 전투에서 아무 일도 하지 않으면서 탄창 2칸을 빼앗는다. 냉각 약실·예약 급탄기도 손패 시절 규칙에 묶여 있다.
2. **과열 대가가 파츠 판도를 바꿨다**: 열을 다루는 파츠(방열판·가속기·순환펌프)가 가장 강해졌고, '재장전 +1턴'·'열 한계 −2'·'열 +1'을 대가로 가진 파츠는 손해가 됐다. 특히 재장전 대가가 강제 냉각에도 붙는 것은 의도하지 않은 이중 대가다.
3. **섞는 방향은 파츠도 받쳐 준다**: 삼중 시퀀서·교차 급탄기가 강하다. 단, 규칙 '교차 사격'과 파츠 '교차 급탄기'의 이름이 겹친다.
4. **숫자가 작은 파츠는 체감이 없다**: +1·+2·HP 5 이하 같은 조건은 지금 적 체력(15~80)과 피해 크기에서 결과를 바꾸지 못한다.

## 고친 것 (11-11, 사용자 "1,2 진행해 줘")

새 등반(과열 대가 적용)만. 이전 저장은 그대로. 구현: `redesign/part_tuning.gd`, 검사 `tests/part_tuning_rules.gd` 20 통과.

1. **고장 난 파츠**
   - 야전 압축기: 새 등반 보상·상점에서 뺐다(탄창 전투에 현장 압축이 없다). 이미 가진 저장은 그대로.
   - 냉각 약실: '수동 냉각 직후 사격의 첫 공격탄 타격당 +3'을 더했다(재장전 냉각 +4, 탄창 −1칸 유지). 미리 식히는 판단을 보상한다.
   - 예약 급탄기: 이미 제시 중단 상태 그대로.
2. **이중 대가**
   - 과열 강제 냉각은 파츠의 '재장전 +1턴' 대가(후미 점화기·열폭주 노심)를 더하지 않는다. 회수 가속기의 −1은 그대로 준다 — 탄창 전투의 교체는 최소 2턴이라, 회수 가속기는 사실상 과열 냉각에서 작동한다(처음에 이것까지 빼서 래칫에서 효과가 0이 되는 것을 검사로 찾고 되돌렸다).
   - 잔열 노심 열 한계 −2 → −1, 연타 공명기 열 +1 삭제.
   - 파츠 설명·전투 도움말의 강제 냉각 행동 수도 같은 규칙을 쓴다.

**같은 전투로 다시 잰 결과**(음수 = 이득)

| 파츠 | 리벳 | 래칫 | 리액터 |
| --- | --- | --- | --- |
| 열폭주 노심 | +16% → **−8%** | +2% → −4% | −13% → **−21%** |
| 연타 공명기 | +8% → **−8%** | +6% → −1% | −6% → −6% |
| 후미 점화기 | 0 → −2% | +13% → +6% | +23% → +14% |
| 잔열 노심 | +15% → +8% | +10% → +5% | −13% → −6% |
| 냉각 약실 | +7% → −2% | +5% → +5% | −4% → −4% |

- 열폭주 노심·연타 공명기는 손해에서 이득으로 돌아섰다.
- 후미 점화기는 아직 손해다. 교체 +1턴 대가가 남아 있고, 마지막 발은 대개 기본탄이라 +3이 약하다. 잔열 노심도 리벳·래칫에서 약간 손해다.
- 냉각 약실은 해법기가 보너스를 노리고 식히지 않아 발동이 0~2%다. 사람 플레이로 봐야 한다.
- 남은 것: 3(약한 파츠 숫자 키우기), 4(교차 급탄기 이름), 후미 점화기·잔열 노심 추가 조정.
