# 중앙 통제구 — 높이별 전투 배경

2026-10-24. 사용자 ‘다음 스텝 진행’ 요청으로 마지막 5구역 전투 배경 3종을 제작하고 본편에 연결했다. ‘지배자와 친위대의 중추’는 사용자 채택 방향이며, 검문 회랑→공급 통제실→중앙 제어핵의 구체 공간과 설명형 표시명 ‘중앙 통제구’는 디렉터 제작안이다. 정식 고유명과 신규 원화의 사용자 미감은 아직 확정하지 않았다.

## 적용과 확인 경로

|---|---|---|

| 중반 5~7 | 공급 통제실: 쌍 제어 기둥, 공급 연결부와 조절 장치 | [1280×800](assets/central_background_2026-10-24/stage1_1280.png) |
| 상층 8~10 | 중앙 제어핵: 거대한 원형 잠금 장치, 탑으로 뻗는 공급관 | [1280×800](assets/central_background_2026-10-24/stage2_1280.png) |

`PLAY.cmd → 개발 → 중추 배경 · 초반 / 중반 / 상층`. 본편 5구역에서도 진행 위치에 따라 자동 적용된다. 물리적인 층수나 새로운 게임 규칙이 아니며, 현재 10단계 경로를 기존 공통 규칙으로 3등분한다. 다른 길이의 구 저장에도 같은 비율 규칙을 쓴다.

이로써 1~5구역 모두 전용 3단계 전투 배경을 사용한다. 지도 배경과 상점·공방의 공통 실내는 별도다. 5구역의 기존 공통 기계 일반/정예/보스와 수치는 유지했다. 친위대 전용 몬스터, 지배자 외형·최종 패턴, 엔딩 전용 원화는 이번 범위가 아니다.

## 미리보기 출처와 수정

`central_preview.gd`는 기존 `garden_gate_single.json`의 실제 2구역 통과 덱 26장·파츠를 사용하고, 3~4구역의 연결 경로만 합성한다. 전투·보상 없이 5구역으로 이동하므로 **실제로 성장한 5구역 덱이나 난이도 검증이 아니다**. 이 기록은 관문 개조 이전 버전(gate_version=0)이다. 정원/귀족 미리보기와 공유하는 경로·단계 선택을 `ascent_preview.gd`로 분리했다.

첫 중앙 검사에서 최종 보상 이후 5개 검사가 실패했다. 직접 전투로 이동하는 미리보기가 이전 관문의 `resolved=true`를 남겨 `reward()`가 거부한 것이 원인이었다. 정상 본편의 `enter()`는 이미 이 값을 초기화한다. 미리보기 단계 진입에도 미해결 상태, 보스 보상 지급 여부, 조우/보급 임시 상태를 초기화하도록 수정했고 정원·귀족에도 공통 적용했다. 정상 전투/경제 규칙을 바꾼 수정은 아니다. [첫 출력](assets/central_background_2026-10-24/first_pass.log)과 [막힌 보상 화면](assets/central_background_2026-10-24/first_reward_stuck.png)을 보존했다.

저장 검사는 합성된 이전 경로에서 실제 선택 가능한 첫 노드로 진입한 뒤 격리 저장/복원을 비교한다. 개발 미리보기와 검사는 정상 사용자 저장을 쓰지 않는다.
