## 5. 전투 시뮬레이터 대조

### 로그가 지지하는 결론

- `ACC >= EVA` 명중 규칙과 이진 관통 공식은 기록된 모든 대조 표본에서 실제 결과와 일치한다.
- 완료된 3전에서 전투 진행 불가, 잘못된 피해 정산, 리로드로 인한 거리 계산 오류는 발견되지 않았다.
- 3전째 리로드 1회/1턴은 `14 - 1×1 = 13m`와 실제 상태가 일치했다.
- 16발 중 15명중·14유효 적중, 총 피해 44, 과잉 피해 4라는 재산출은 전투 로그 내부 합계와 일치한다.

### 로그가 지지하지 않는 결론

- 인간 로그는 `in_progress`이고 `run_end={}`이므로 완주 난이도, 최종 정산, 35층 지속성은 판정할 수 없다.
- 화면·선택 전 예상·선택 이유가 없어 빈 약실 안내의 이해도, 통화 표기 인지, 상점 구매 판단을 지지하거나 반박하지 않는다.
- 탄창의 전체 적재·발사 순서가 충분하지 않아 인간 로그만으로 LIFO 재미나 순서 최적화를 증명하지 않는다.
- PNG와 입력 시간 자료가 없어 전투 촉감, 애니메이션 속도, 피로도를 판단하지 않는다.

### 확정 버그가 아닌 후속 신호

- 생산 텔레메트리에는 `overkill_damage` 직접 필드가 없어 현재는 원시 피해와 HP로 재산출해야 한다. 이번 재산출은 성공했으므로 게임 정산 버그가 아니라 관측성 개선 후보이다.
- `sim_harness`가 리로드를 모델링하지 않아 실데이터 넉백 무한 락 부재를 수학적으로 확정할 근거가 부족하다. 탐지 스모크 통과만으로 전체 부재를 선언하지 않으며 QA 도구 커버리지 개선 후보로 남긴다.
