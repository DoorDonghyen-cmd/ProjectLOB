# 물자 거래 단말 시안

이 문서는 배관도를 함께 보여 준 1차 시안 기록이다. 실행 파일은 [최신 2차 시안](../shop_terminal_v2_2026-11-04/README.md)을 연다.

## 실행

저장소 루트의 `OPEN_SHOP_TERMINAL_PREVIEW.cmd`를 연다. 기본 진입은 축열 주조장이다. `현장 기록`에서 기존 인사·장면 묘사·대화를 읽고, `재고`로 돌아와 같은 상품을 확인할 수 있다.

| 키 | 예시 |
|---|---|
| F1 | 주거 통로, 첫 할인과 잔액 부족 |
| F2 | 축열 주조장, 상품 세 개 |
| F3 | 축열 주조장, 가방 한도와 교체 |
| F4 | 귀족 거주구, 장착 슬롯이 찬 상태 |
| F5 | 우수 정원 |
| F6 | 중앙 통제구 |

## 시안에서 정한 것

- [후속 레퍼런스](../../../art/references/2026-11-04-ui/shop-device-followup.md)의 지도와 단말 구도를 사용한다. 실제 배관도에서 현재 구역의 경로와 상점 노드를 가져온다. 판매품 이름·가격은 짧은 세 줄로, 선택 상품의 효과·결제 후 잔액·장착/보관/교체는 옆에 둔다. 무광 철판 프레임은 `chassis.gd`의 도트형 면과 선으로 그렸으며 기존 탄환·파츠·지도 아이콘을 재사용한다.
- 진입 시 재고를 표시한다. 별도 현장 기록 탭은 `city_story.gd`의 다섯 구역 원문을 불러온다. 각 구역의 인사말과 전문을 그대로 보여 주며 읽은 뒤에도 상품 선택과 잔액을 유지한다. 이야기 탭 노출 방식은 시안의 결정이다.
- 시안은 기존 카운터 샘플의 실제 Campaign 거래와 `qa_runtime/core_choice_20261103/climb_fresh17/`의 다섯 상점 스냅샷을 재사용한다. `지도로`는 현재 시안에서 실제 지도 단계로 이동하고 `단말 시안 다시 열기`는 원래 예시를 다시 불러온다. 본편 진입점 연결은 시안 검토 이후다.

## 검증

`OPEN_SHOP_TERMINAL_PREVIEW.cmd -Capture`로 Godot 4.7 호환성 렌더러에서 **1,771개 검사, 실패 0건**을 확인했다. 1008×454, 1280×800, 2340×1080, 2160×1032에서 현장 기록 전환, 현재 위치 표시, 지도 복귀, 고른 상품·잔액 유지, 같은 위치에 있는 지도 복귀 버튼을 검사했다. 거래는 뒤의 세 크기에서 실제 터치 이벤트로 가격 할인·잔액 부족·구매·장착/보관·새 진열·교체와 취소를 확인했다. 다섯 구역의 원문 일치와 격리 저장 파일 미생성도 검사했다.

Godot MCP에서 프로젝트와 엔진 버전을 확인했고 실행·캡처는 로컬 Godot으로 진행했다. 위 S26 화면은 같은 가로 크기의 PC GPU 렌더다. Galaxy S26 실기기 조작과 사람의 이야기 발견성 평가는 별도다.
