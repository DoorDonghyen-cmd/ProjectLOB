# 하단 조작부 단말 시안

[1280×800 이전 외형 비교](before_after_1280x800.png) · [재고](stocked_1280x800.png) · [현장 기록](record_1280x800.png) · [S26 가로 재고](stocked_2340x1080.png) · [S26 안전 영역 크기의 우수 정원 기록](garden_record_2160x1032.png)

저장소의 `OPEN_SHOP_TERMINAL_PREVIEW.cmd`로 연다. 화면 아래의 `재고`와 `현장 기록` 키가 실제 전환 버튼이다. 기록 모드에서는 해당 키가 눌린 상태로 남고 바로 옆 데이터 테이프 슬롯의 표시등이 켜진다.

HP 2644A를 중심으로 한 [실물 조사](../../../art/references/2026-11-04-ui/cassette-futurism-study.md)를 적용했다. 검은 화면을 회갈색 케이스에 매립하고, 조작 키와 좁은 테이프 슬롯을 하단에 묶었다. 오른쪽 모듈이 차지하던 폭은 표시부에 돌려줬다. 키와 슬롯은 현재 화면에 맞춰 재구성한 시안이며, 현장 기록은 기존 원고를 사용한다.

`OPEN_SHOP_TERMINAL_PREVIEW.cmd -Capture`에서 **697개 검사, 실패 0건**. Godot 4.7에서 가로 크기 4종(1008×454, 1280×800, 2340×1080, 2160×1032)의 표시부와 하단 키 위치, 두 키의 터치 전환·눌림 상태, 기록 표시등, 복귀 버튼 위치, 상품 선택 유지와 다섯 구역 원문을 확인했다. 뒤의 세 크기에서 구매·재고 변경·탄 교체 회귀 검사도 실행했다. 본편 적용 전 시안이며 S26 크기는 PC GPU 캡처다.
