# 아이콘 중심 파츠·성장 선택 UI 워크스루

## 결과

무기고에서 가장 읽기 어려웠던 파츠 문장 목록을 그림 중심 카드로 교체했다. 파츠는 이름을 읽기 전에 서로 다른 실루엣과 색으로 구분되며, 카드에는 실제 선택에 필요한 변화량만 크게 표시한다.

| 파츠 | 시각 표식 | 카드 전면 정보 |
|---|---|---|
| 가속 총열 | 긴 총열과 원형 렌즈 | 관통 `+1` |
| 회수 가속기 | 양방향 순환 링 | 재장전 `−1턴` |
| 확장 탄창 | 세로 탄창 셀과 추가 표시 | 탄창·회수탄 `+1 · +1` |
| 열축전 코일 | 코일과 불꽃 | 화상 `+1` |

무기고 후보 카드는 상세 버튼으로 동작한다. 한 번 누르면 기존의 전체 효과 문장과 현재 빌드에서의 실제 영향을 확인할 수 있다. 구매 영역은 가격과 `장착` 행동만 남겼다. 장비 보관과 덱·장비 창도 같은 카드를 재사용하며 현재 장착 파츠는 외곽선과 `장착` 표식으로 구분한다.

압축 코어는 두 탄환이 코어로 합쳐지는 그림과 현재 충전량을 보여 준다. 계층 관문의 세 선택은 탄창 셀 증가, 두 발의 결합, 크레딧 묶음이라는 서로 다른 도형과 `4→5칸`, `2발→1발`, `+24Cr` 변화량을 전면에 둔다.

## 확인 경로

1. Godot에서 `새-게임-프로젝트/project.godot`을 연다.
2. F6이 아닌 F5로 메인 씬을 실행한다.
3. `개발자 테스트 → 크레딧 무기고`에서 상점과 장비 보관을 확인한다.
4. `개발자 테스트 → 파츠 아이콘`에서 파츠 4종을 한 화면으로 비교한다.
5. `개발자 테스트 → 계층 관문`에서 성장 선택 카드 3종을 확인한다.
