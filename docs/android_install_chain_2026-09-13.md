# 갤럭시 연계 개편판 설치

`LastOnBoard-chain.apk`를 휴대폰으로 옮겨 실행하고 기존 Last on Board Test 앱을 업데이트합니다. Android 7 이상 ARM64/ARMv7용 테스트 서명 빌드입니다. 필요하면 APK를 연 파일 앱에만 '출처를 알 수 없는 앱 설치'를 허용한 뒤 설치 후 끕니다.

기존 테스트 앱을 삭제할 필요는 없습니다. 새 규칙은 별도 자동 저장을 사용하므로 새 런으로 시작합니다. 이전 규칙의 저장을 잘못된 순서로 불러오지 않습니다. 기존 APK는 `builds/android-test/LastOnBoard-test.apk`에 비교용으로 남습니다.

- 탄환을 누른 순서대로 왼쪽부터 발사합니다. 확정 전 칸을 터치하면 그 탄을 회수합니다.
- 균열 → 연속/도약으로 활용하거나 균열 → 파쇄로 소비할 수 있습니다. 축전은 다음 2발을 강화합니다.
- '패 교환'은 장전마다 1회입니다. 기본탄은 항상 보급됩니다.
- '확장 탄창' 파츠로 5칸을 사용할 수 있습니다.
- 적과 보상이 시드마다 달라집니다. 시드를 고정하면 다시 같은 조건으로 플레이할 수 있습니다.

가로 모드입니다. 규칙과 수치는 상단 '규칙'/'정보'에서, 적별 상태는 해당 적을 터치해 볼 수 있습니다. 이 빌드의 Android 패키지 서명/정렬은 검사하지만 실제 기기 성능·발열·손가락 조작감은 별도 확인 대상입니다.
