# 무기 4종 — 런의 플레이 방식

## 결과

사용자의 “무기는 캐릭터 같은 역할이며 4~5종이 적당하다”는 방향을 반영해 보행자·쇄도·산개·압쇄 네 무기를 구현했다. 등반 시작에 선택하고 끝까지 유지한다. 동일한 공통 탄환을 조합하되, 사격 속도·적 군집·관통에 따라 좋은 장전과 획득 판단이 달라진다.

| 무기 | 플레이 방식 | 비용 |
|---|---|---|
| 보행자 | 한 발씩 피해 +1, 화상/밀치기 타이밍 조절 | 일제 사격 불가 |
| 쇄도 | 한 탄창을 1턴에 몰아쳐 증폭→연발 실행 | 재장전 3턴 |
| 산개 | 거리 차 3m 이내 다른 적에 절반 피해 확산 | 재장전 2턴, 확산에 각 적 장갑 적용 |
| 압쇄 | 관통 +2, 장갑보다 높은 관통이면 타격당 피해 +1 | 기본 3칸, 재장전 2턴 |

산개는 연발/전격 비중이, 압쇄는 철갑 비중이 높은 기본 덱 10장으로 시작한다. 기존 두 무기의 기본 덱과 저장은 유지한다. 해금된 보급 사이드그레이드는 모든 무기에 적용된다.

무기 선택 화면은 두 열의 네 카드, 임시 벡터 실루엣, 고유 규칙, 비용, 추천 조합, 시작/특징·보급 버튼으로 구성한다. 전투의 무기 표시와 실제 정산 기반 탄창 예측·상세 계산·연출·정산을 연결했다. 확산은 화상이나 밀치기를 복제하지 않으며, 전이와 따로 기록한다.

용량은 산개 4→5→6칸, 압쇄 3→4→5칸이며 파츠와 독립적으로 성장한다. 회수탄 공급, 맵/덱/관문 용량, 상점의 회수 가속기 적합성과 저장 검증도 무기 데이터에 맞춰 동작한다.

개발자 메뉴에는 동일 대열에서 네 무기를 비교하는 실제 조합 버튼과 선택 화면 바로가기를 제공한다. 실제 등반과 훈련 저장은 보존한다.

## 검증과 조정

- 압쇄의 초과 관통 추가 피해는 초기 최대 +2에서 +1로 낮췄다. 실제 기본탄 한 탄창+재장전 주기를 비교해, 회수 가속기까지 장착해도 무장갑에서는 보행자의 템포가 유리하고 장갑에서는 압쇄가 유리한 경계를 확인했다.
- 거리 차 3m 경계, 적별 장갑, 증폭/연발, 확산 처치 후 전격 표적 재선택, HP 한도, 화상/밀치기 복제 방지, 전투 종료 전진 중단과 예측/실제 결과 일치를 검증했다.
- 최종 검증 수치와 실제 명령/화면 증거는 [QA 보고서](qa/reports/weapon_archetypes_2026-09-16.md)를 따른다.
- 메뉴 설정 제목 줄바꿈 WPN-01을 수정했다. 확장된 개발자 목록을 터치하는 QA 드라이버는 실제 스크롤로 버튼을 화면에 올린 뒤 입력하도록 수정했다. 상대 경로 재생 입력도 절대 경로로 해석하고 잘못된 보고서는 즉시 실패 처리한다.

네 무기 모두 공통 탄환의 핵심 이해도를 유지하는 첫 로스터다. 무기별 전용 탄환 풀/추가 고유 자원은 구현하지 않았다. 최종 체감 밸런스와 반복 플레이의 빌드 다양성은 사람이 비교한다. 다섯 번째는 이 네 가지와 구별되는 판단을 제공할 때 추가한다.
