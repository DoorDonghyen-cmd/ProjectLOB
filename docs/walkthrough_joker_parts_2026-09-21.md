# 5칸 파츠 빌드와 코어 패널티 개편 워크스루

## 바뀐 플레이 경험

파츠는 이제 하나를 골라 교체하는 부속품이 아니라 최대 5개 효과를 쌓는 런 빌드다. 일반 모듈은 관통, 화상, 전이, 밀치기, 증폭, 연발, 선두·후미 탄처럼 기존 탄환의 역할을 강화한다. 강한 코어 파츠는 한 개만 장착할 수 있고 탄창 축소, 재장전 증가, 직접 피해 감소 같은 대가를 가진다.

이에 따라 같은 총기에서도 빌드가 달라진다. `과구경 총열 + 선두 격발기 + 증폭 시퀀서`는 짧고 강한 발사 순서를 만들고, `충격 피스톤 + 충격 가이드`는 피해를 내주는 대신 거리를 통제한다. `야전 압축기 + 소이 계열`은 작은 탄창으로 압축탄과 화상을 설계한다. `삼중 시퀀서`는 서로 다른 탄 세 번째를 결산탄으로 만든다.

## 상점과 장비 흐름

- 상점 상단의 5개 소형 슬롯에서 현재 빌드를 먼저 확인한다.
- 금색 이중 테두리와 `CORE` 표식으로 코어를 즉시 구분한다.
- 파츠 카드에는 큰 효과 수치, 이점 `▲`, 대가 `▼`를 표시한다.
- 크레딧이 충분하면 한 상점에서 여러 파츠를 구매할 수 있다.
- 빈 슬롯과 코어 조건이 맞으면 자동 장착하고, 맞지 않으면 보관함에 둔다.
- 덱·장비 창에서는 가로 스크롤 없이 2열 보유 카드의 장착 버튼으로 5칸을 교체한다.

## 파츠 구성

일반 모듈 14종과 코어 6종, 총 20종이다. 전체 목록과 정산 순서는 [GDD 29](gdd/29_joker_parts_build.md)에 정리했다. 단발 무기에서 효과가 없는 회수 가속기는 상점 후보에서 제외하며, 나머지 19종은 등장할 수 있다. 상점은 런에서 아직 보지 못한 파츠를 반복 파츠보다 먼저 진열한다.

## 저장 호환

전투 저장은 v8, 캠페인 저장은 v4로 올라갔다. 이전의 단일 파츠는 다중 장착 배열의 첫 항목으로 변환한다. 복원 시 최대 5개, 중복, 코어 1개, 보유 목록 포함 여부를 검증하며 조작된 두 코어 저장은 거부한다.

- 메인 메뉴 → `개발자 테스트` → `파츠 아이콘`: 20종 카드 비교
- 메인 메뉴 → `개발자 테스트` → `도시 · 덱·장비`: 5칸 장착과 코어 교체
- 메인 메뉴 → `개발자 테스트` → `도시 · 상점`: 다중 구매와 자동 장착·보관
- 일반 도시 등반: 상점에서 실제 런 빌드 구성

## 검증

| 범위 | 결과 |
|---|---:|
| 무기·파츠 규칙 | 3,245 / 0 실패 |
| 다수전·증원 | 144 / 0 실패 |
| 가독성·정산 | 30,068 / 0 실패 |
| 35층 캠페인 8회 | 22,631 / 0 실패, 8/8 완주 |
| 실제 UI·입력 | 3,426 / 0 실패, 1,103 입력 |

전체 캠페인에서 과구경 화력, 충격 제어, 야전 압축·소이, 전이·연발 등 서로 다른 최종 장착 조합이 만들어졌다. 자동 검증은 규칙과 도달성의 근거이며, 파츠 선택의 만족감과 특정 조합의 장기 지배 여부는 실제 플레이에서 계속 관찰한다.

구버전 필드로 장착 한도를 우회하는 저장과 전투 중 장비 교체를 추가 차단한 뒤, 단일 시드 35층 2경로 4,743/0과 실제 UI 1,613/0·507입력을 최종 재검증했다.

검증 화면과 실행 결과는 `docs/qa/reports/joker_parts_2026-09-21.md`에 정리했다. APK와 Windows 패키지는 만들지 않았고 커밋·푸시도 수행하지 않았다.
