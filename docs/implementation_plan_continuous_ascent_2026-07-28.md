# 첫 구역 이후 35층 연속 상승 복구 계획

> 세션: `codex0728-continuous-ascent`
> 날짜: 2026-07-28

## 문제

첫 침전 거주구 클리어 시 다음 계층 해금보다 디브리핑이 먼저 실행되어 메인 화면으로 복귀한다. 과거의 `6→13→20→27→35층` 런 길이 램프가 남아 현행 35층 연속 상승과 런 내 빌드 성장 목표를 끊고 있다.

## 구현

1. 런 여정을 해금 여부와 무관한 `section_a`~`section_e` 35층으로 고정한다.
2. 구역 경계에서는 바로 위 계층을 조회하고 `check_section_unlocks(true)`로 즉시 해금·저장한다.
3. `enter_section()`으로 덱·파츠·가방·크레딧을 유지한 채 다음 계층에 진입한다.
4. 디브리핑은 사망 또는 정점 돌파에만 표시한다.
5. 지도·상승 브리핑·GDD·회귀 테스트에서 조기 종료 상한과 런 길이 램프를 제거한다.

## 검증 기준

- 침전 보스 뒤 현재 계층이 `section_b`다.
- `section_b`가 영구 해금 목록에 즉시 들어간다.
- 덱·가방·크레딧이 전환 전후 동일하다.
- 디브리핑과 메인 화면 복귀가 발생하지 않는다.
- 최초 저장에서도 런 길이 35층과 5계층 맵이 고정된다.
