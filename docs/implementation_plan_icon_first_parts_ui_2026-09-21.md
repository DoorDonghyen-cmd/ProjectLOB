# 파츠 중심 아이콘 UI 개편 계획

상태: 구현 및 실제 렌더 검증 완료  
대상: 개편판 무기고, 장비 보관, 덱·장비, 기초 훈련 파츠 보상  
목표: 파츠를 긴 설명문이 아니라 `형태 + 변화하는 수치 + 장착 상태`로 먼저 판단하게 한다.

## 문제

- 무기고의 탄환은 탄두·속성·피해·관통 아이콘이 있지만 파츠는 이름과 설명 두 줄뿐이라 서로 다른 종류로 보이지 않는다.
- `관통 +1`, `재장전 −1턴`, `탄창/회수 +1`, `화상 +1`처럼 단순한 효과가 문장 속에 묻힌다.
- 장착/보관 영역도 버튼 문장만 반복되어 현재 장착 파츠와 교체 후보를 빠르게 비교하기 어렵다.

## 시각 언어

| 파츠 | 큰 실루엣 | 전면 수치 | 색 |
|---|---|---|---|
| 가속 총열 | 긴 총열과 관통 렌즈 | 방패 관통 `+1` | 청색 |
| 회수 가속기 | 순환 화살표와 회전축 | 재장전 `−1턴` | 녹색 |
| 확장 탄창 | 세로 탄창 셀과 추가 칸 | 탄창 `+1`, 회수탄 `+1` | 금색 |
| 열축전 코일 | 코일과 불꽃 | 화상 `+1` | 주황 |
| 파츠 없음 | 점선 빈 장착 슬롯 | 빈 슬롯 | 회색 |

색만으로 구분하지 않는다. 모든 파츠는 서로 다른 외곽 형태와 기능 아이콘을 가진다.

## 무기고 와이어프레임

```text
┌ 탄환 카드 ┐  ┌ 파츠 카드 전체가 상세 버튼 ──────────┐
│ 기존 아이콘│  │ [큰 파츠 실루엣]  가속 총열           │
│ 피해/관통 │  │                    [방패 관통]  +1     │
│ [12Cr]    │  │                    장갑 대응           │
└───────────┘  │ [30Cr · 장착]                          │
               └────────────────────────────────────────┘

┌ 압축 코어 충전 ┐
├ 현재 장착 ────────────────────────────────────────────┤
│ [파츠 그림 + 핵심 수치] [장착 중]                     │
├ 보관 파츠 ────────────────────────────────────────────┤
│ [파츠 그림 + 핵심 수치] [장착] [+10Cr]                │
└────────────────────────────────────────────────────────┘
```

## 상호작용

- 상점의 파츠 그림 영역을 누르면 큰 아이콘과 전체 설명이 있는 상세 창을 연다.
- 구매 버튼은 가격과 결과만 표시한다. 이미 구매했거나 방문 한도를 썼으면 비활성 상태를 유지한다.
- 보관 파츠는 그림 아래에 `장착`, `+10Cr` 두 행동만 둔다.
- 현재 장착 파츠는 밝은 외곽선과 `장착` 표시로 구분한다.
- 툴팁과 상세 창에는 기존 전체 문장을 유지해 정보 손실을 막는다.

## 적용 범위와 완료 조건

1. 무기고의 모든 파츠 후보가 아이콘 카드로 보인다.
2. 현재 장착 및 보관 파츠도 같은 아이콘 언어를 사용한다.
3. 덱·장비 창과 7교전 보상의 파츠 표시도 같은 컴포넌트를 재사용한다.
4. 기존 구매·장착·분해 버튼 이름과 저장 규칙을 유지한다.
5. 1280×800, 1008×630 실제 렌더에서 카드 잘림 없이 터치된다.
6. 개발자 테스트의 `크레딧 무기고` 바로가기로 즉시 검수한다.

인접한 단순 선택인 압축 코어 충전과 관문 3택도 같은 패스에서 도형 카드로 전환한다. 긴 설명을 추가하지 않고 탄창 칸 증가, 두 발 압축, 크레딧 획득을 그림과 변화량으로 표시한다.

## 완료 결과

- `PartCardView` 하나로 무기고 후보, 현재 장착, 보관함, 덱·장비, 기초 훈련 보상을 통일했다.
- `UpgradeChoiceView`로 압축 코어와 관문 `탄창 확장/탄환 압축/크레딧`을 도형과 변화량 중심 카드로 바꿨다.
- 상점의 파츠 카드를 누르면 전체 설명을 별도 상세창에서 볼 수 있어 기본 화면에는 판단에 필요한 정보만 남는다.
- 개발자 테스트에 `파츠 아이콘` 바로가기를 추가해 4종의 실루엣·색·수치를 한 화면에서 검수할 수 있다.
- 실제 OpenGL UI 자동 검사에서 1,659개 조건, 528개 입력, 실패 0을 확인했다. 1280×800과 1008×630 상점 화면에서 주요 행동이 잘리지 않는다.
