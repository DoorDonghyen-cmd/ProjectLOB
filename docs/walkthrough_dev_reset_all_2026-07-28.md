# 개발자 테스트 전체 데이터 초기화 워크스루

## 결과

메인 화면의 `🛠️ 개발자 테스트` 패널에 `🧹 전부 초기화`를 추가했다. 확인 후 현재 런, 모든 영구 진행, 실제 메타 세이브를 첫 실행 상태로 복원하고 메인 화면으로 돌아간다.

## 사용 방법

1. 메인 화면에서 `🛠️ 개발자 테스트`를 연다.
2. `🧹 전부 초기화`를 누른다.
3. 삭제 범위를 확인한 뒤 `전부 초기화`를 선택한다.
4. 완료 안내가 표시되면 새 게임을 시작한다.

## 초기화 범위

- 현재 런: 총기·파츠·가방·덱·크레딧·층·계층·노드·맵·런 통계
- 영구 진행: 메타 크레딧·업그레이드·TDC·금고·무기/계층 해금·로어·승천·침투 위험도
- 영속 파일: `user://meta_save.cfg`

초기값은 100 Cr, 기본 무기 `workhorse`, 첫 계층 `section_a`, 승천 0, 침투 위험도 1이다.

## 검증

- `suite_save_load.gd`: 오염된 메타·런 상태와 테스트 세이브를 만든 뒤 전체 초기화하여 모든 기본값과 파일 삭제를 검사
- `suite_ui_smoke.gd`: 개발자 메뉴의 버튼 존재와 확인 대화상자 표시를 검사
- Godot 4.7 전체 자동 검증: **2,435 통과 / 0 실패 / 기존 경보 3**
- 스크립트 컴파일 73개, 씬 로드 4개 성공
