# 다섯 무기 규칙 개편 — 2026-09-16

현재 개편판을 사용자 방향의 기본형+특화4종으로 재구성했다. 탄환 순서·조합으로 피해를 높여 처치하는 핵심과 전체 도시 맵·상점·이벤트·성장 흐름을 유지한다. UI 와이어프레임은 코드 편집 전에 [구현 계획](implementation_plan_weapon_rules_2026-09-16.md)에 작성했다.

| 무기 | 현재 플레이 |
|---|---|
| 보행자 | 전탄 연쇄, 모든 탄환 기본 주 피해+1 |
| 쇄도 | 전탄 연쇄, 같은 적 실제 주 타격3회마다 고정 추가 피해4 |
| 산개 | 전탄 연쇄, 탄환마다 생존 적 균등 무작위, 기본5칸 |
| 압쇄 | 전탄 연쇄, 화상 턴당2피해·전격 전이3 |
| 증강 | 단발, 기본 피해·관통·효과 강도2배 |

연쇄4종은 전체 탄창 실행 후 생존 적이 한 번 행동한다. 증강은 한 발마다 생존 적이 행동하며 연발 타격 수/화상 기간/증폭 적용 탄환 수는 유지한다. 강도만 강화하므로 중복4배가 발생하지 않는다. 쇄도 진도는 적마다 재장전·표적 변경을 거쳐 유지하며 화상·전이를 세지 않는다.

카드/설명/계산/규칙/무기 상세/임시 실루엣/정산/교육 수치를 현재 무기에 맞췄다. 산개는 미래 RNG 표적을 노출하지 않고 가능한 표적 분기로 주 피해·최종HP 범위·처치/접촉 확률을 공개한다. 최근접4종은 실제 명령 복제 예측을 유지한다. 무기5종의 같은 대열 개발자 바로가기와 실제 저장 보존을 확인했다. 작은 화면의 HP19가 잘리는 고정 출력 폭도 수정했다.

전투 저장은v4이며v2/v3를 이관한다. 별도 표적 RNG가 있어 저장 재개 시 산개 결과가 동일하고 카드 미리보기는 draw/target RNG를 소비하지 않는다. 기존 압쇄의 회수 가속기는 복원 가능하나 새 재장전 하한 때문에 추가 비용 감소가 없다.

[QA 보고서](qa/reports/weapon_rules_2026-09-16.md)에 원본과 독립 검토 범위를 기록했다. 규칙3,120/0, 탄환·예측28,014/0, 실제 무기UI271/0, 도시10완주22,040/0, 실제 도시UI6,616/0·5완주·2,160입력, 최종 용량UI760/0, 기존 회귀3,730/0/경보3을 확인했다. 자동 경로 탐색기는 미래 패/RNG에 접근하므로 사람의 재미·실제 승률·최종 균형은 별도 비교한다.

플레이 파일: `builds/city-windows/Play-City.cmd`. 같은 폴더의 독립qa-profile에 저장한다. 최신5종을 선택하고 맵·상점 포함35층 도시를 시작하거나 탄환 기초 훈련을 선택할 수 있다. 재생성은 `tools/export_windows_readability.ps1 -BuildKind city`다. 빌드의 소스 커밋/해시는 내보내기 후 이 문서에 기록한다. APK/원격 푸시는 수행하지 않았다.

다음 사람 확인: 증강 한 발 효율과 추가 접근 비용, 쇄도 보너스와 재장전2턴, 산개 분산 위험과5→7칸 보상, 압쇄 지속·전이 빌드 체감. 공통 패/같은 시드 비교로 출발 수치를 조율한다.
