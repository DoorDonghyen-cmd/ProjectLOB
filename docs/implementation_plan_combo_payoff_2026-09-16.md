# 탄환 조합 보상감 및 전투 가독성 개편 계획

## 목표

탄환을 좋은 순서로 장전했을 때 단순히 수치가 올라가는 데서 끝나지 않고, 플레이어가 **어떤 연결이 생겼고 그 결과 적이 얼마나 남거나 언제 죽는지** 발사 전에 이해하도록 만든다. 기존 7종 탄환, 좌→우 발사 순서, 피해·관통·물리·화염·전기의 간결한 규칙은 유지한다.

## 핵심 조합

- `증폭탄 → 연발탄`: 다음 타격 강화가 2회 모두 적용되는 단일 대상 폭딜.
- `증폭탄 → 철갑탄`: 장갑을 통과하는 안정적인 마무리.
- `소이탄 → 충격탄`: 화상 대상을 밀어 추가 전진 정산 시간을 확보.
- `증폭탄 → 전격탄`: 주 대상 피해를 강화하면서 다른 적도 전이 피해로 정리.
- `회수탄`: 손패가 맞지 않을 때 빈 순서를 메우는 안정적인 기본탄.

새로운 속성 상성이나 별도의 상태이상은 추가하지 않는다. 먼저 현재 규칙의 조합이 전투에서 실제로 쓰이게 만든다.

## UI 요청 명세

### 탄창 영역

- 현재 탄창의 좌→우 발사 방향을 슬롯 사이 화살표로 항상 표시한다.
- 증폭을 받는 탄환으로 이어지는 화살표와 해당 슬롯을 청록색으로 강조한다.
- 각 슬롯 결과는 `A −7 · HP 2`, `A 처치`, `B 전이 −2`처럼 표적과 결과를 짧게 표시한다.
- 두 번째 줄은 `증폭 적용`, `증폭 · 2타`, `화상 2회 예상`, `거리 +2m`처럼 이 탄을 해당 위치에 둔 이유를 한 문장으로 표시한다.
- 화상 예상 횟수는 별도 공식을 만들지 않고 실제 전투 복제 예측에서 발생한 화상 정산 이벤트만 센다.
- 탄창 전체 결과를 `A 처치 · B HP 4 · 안전 3m` 형태의 한 줄 요약으로 표시한다.

### 상세 설명

- 슬롯을 선택하면 현재의 실제 피해 계산과 함께 후속 화상 횟수, 전이 표적, 밀쳐낸 거리, 최종 남은 HP를 보여 준다.
- 기존 `계산 보기`와 슬롯 회수 방식은 유지한다.
- 화면 폭 1280×800 및 1920×864에서 가로 넘침이 없어야 하고, 기존 터치 영역을 줄이지 않는다.

### 개발자 바로가기

- `조합 결과 연습`을 추가해 증폭·연발, 소이·충격, 증폭·전격의 예상 표시를 한 화면에서 즉시 검증한다.
- 개발자 연습은 기존 실제 저장 파일을 변경하지 않는다.

## 밸런스 및 교전 재배치

- 충격탄 피해를 2에서 3으로 조정해 회수탄 대비 피해 손실을 1로 줄인다. 거리 제어를 선택해도 공격 템포가 과도하게 손해 보지 않게 한다.
- 5교전은 가까운 고속 적과 후열 적을 함께 배치해 `소이탄 → 충격탄`이 화상 정산 시간을 확보하게 한다.
- 6교전은 3개체 편성으로 바꿔 전격탄의 총 피해와 표적 전환 가치가 분명해지게 한다.
- 일반 런 중후반 편성에도 고속 2개체 및 3개체 변형을 늘려 충격탄과 전격탄이 특정 교전에서 최선이 되도록 한다.
- 단일 카드 반복보다 올바른 2~3장 순서가 적을 깔끔하게 정리하는 HP·장갑 구간을 우선한다.

## 검증 기준

- Forecast는 라이브 상태를 변경하지 않고 같은 입력에 같은 결과를 낸다.
- 예측된 피해, 처치, 화상 정산, 이동, 전이 결과가 실제 명령 재생 기록과 일치한다.
- 교육/일반 × 단발/일제 4개 캠페인이 실제 명령만으로 완주된다.
- 자동 탐색 캠페인 전체에서 충격탄과 전격탄이 각각 1회 이상 실제 발사된다.
- 회수탄만 사용하는 단순 정책은 중후반 교전에서 안전한 지배 전략이 되지 않는다.
- 렌더 UI, 저장/복원, 1280×800 및 1920×864 터치 검증을 통과한다.
- Windows 플레이 빌드와 헤드리스 시작 검증을 갱신한다. APK는 생성하지 않는다.
