# 다수 적 표적 예고와 개별 정보

사용자가 승인한 다수전 표시 방향을 현재 간결한 Godot UI에 적용한다. 거리·자동 표적·탄환별 재표적·단발/일제의 전진 규칙은 유지한다.

## 화면 설계

```text
전장: 적을 A/B/C로 식별, 실제 거리 축과 기존 세로 줄 유지
     현재 표적 조준선 + 첫 발 예상 피해
     각 적 이름/HP/장갑/회피/접근은 상시 표시
     적 또는 정보 줄 호버/클릭 → 해당 적 상세 (조준 변경 없음)
탄창: [1 탄환 →A −3] [2 탄환 →B 도탄] [3 …] [4 …]
     준비탄 연결 화살표 유지
     연속 사격 예상 · 단발은 매 발 전진 / 일제는 전탄 후 전진
     종료로 미발사 탄은 ‘보존’, 손실로 미발사 탄은 ‘중단’ 표시
```

미리보기는 모델을 깊은 복제하여 실제 confirm/fire 명령으로 계산한다. 원본 상태·RNG·저장·장전 계획을 변경하지 않는다. 단발은 매 사격 사이 전진/둔화 소모를 적용하고, 일제는 탄마다 재표적한 뒤 한 번 전진한다. 계획 취소/확정/장전/발사 후 자동 갱신한다. 예고는 현재 탄창을 연속 발사한다는 조건이며 중간 재장전은 포함하지 않는다.

탄창 예고는 다수전에 표시하고 단일 적 화면은 현재 간결함을 유지한다. 첫 발 피해는 현재 표적을 강조하며, 모든 적의 세부 정보는 정보 버튼과 개별 적 버튼으로 접근할 수 있다. 재생 중 예고를 지우고 실제 피격 결과를 재생한다.

## 검증

표적 이동, 같은 거리, 처치, 준비탄, 장갑/회피, 둔화, 단발 전진, 일제 한 번 전진, 조기 종료와 잔탄, 원본 상태/RNG 불변을 실제 명령 결과와 대조한다. 실제 입력으로 개별 정보 확인과 조준 불변 검증. 개발자 다수전 예고 연습 추가. 기존 화면/연출/두 총기 캠페인을 확인하고 새 Windows 빌드로 제공한다.
