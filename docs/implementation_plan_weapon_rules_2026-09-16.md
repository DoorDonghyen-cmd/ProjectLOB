# 다섯 무기 규칙 구현 계획

사용자가 기본 피해+1 보행자와 탄환 효과2배 단발 방향을 받아들였다. 이전 전체 개발/UI 변경 위임 안에서 구현한다. 단발은 추천했던 피해/관통 포함으로 시작하고 연발 타격 수와 지속 기간을 다시 곱하지 않는다. APK/원격 푸시는 이번 범위에 포함하지 않는다.

## 출발 수치

| ID / 이름 | 발사 | 기본 용량 / 재장전 | 고유 규칙 |
|---|---|---|---|
| single / 보행자 | 전탄 | 4 / 1턴 | 기본 주 피해+1 |
| burst / 쇄도 | 전탄 | 4 / 2턴 | 같은 적3회 실제 주 타격마다 고정 추가 피해4 |
| scatter / 산개 | 전탄 | 5 / 2턴 | 매 탄환 생존 표적 균등 무작위 |
| heavy / 압쇄 | 전탄 | 4 / 1턴 | 화상 틱2, 전이 피해3 |
| amplifier / 증강 | 단발 | 3 / 1턴 | 탄환 기본 피해/관통/증폭/넉백/화상 틱/전이2배 |

모두 관문 용량 성장+2. 출발 값은 실제 명령 비교 후 필요하면 수정한다. 증강의 연발은2타를 유지하고 타격 피해만2배, 증폭은 부여량2배/뒤2발 유지, 화상은 틱2/기간 유지, 넉백 예산4m이다. 처치 시 전진 생략이나 수동 조준은 추가하지 않는다.

## 모델과 예측

- Model v4, 기존v2/v3 상태 마이그레이션. 적중 진도0..2와 별도 표적 RNG를 저장/검증한다. 실제 사용자 저장은 QA에서 사용하지 않는다.
- 연쇄는 전체 실행 후 생존 적1회 행동. 적중/처치/전이/화상은 실제 HP 한도로 정산하며 연발 도중 죽은 적에 허위 적중을 세지 않는다.
- 공통 Content 함수가 기본 피해/관통/효과 값의 표시와 정산에 사용된다.
- 산개 공개 예측은 실제 표적 RNG를 소비하거나 미래 표적을 노출하지 않는다. 생존 표적 분기를 같은 정산기로 열거하고 확률·피해/잔여HP 범위·접촉 가능성을 표시한다. 동일 상태 캐시와 분기 상태 합치기로 비용을 관리한다.

## UI 와이어프레임 — 소스 편집 전

```text
메뉴 2열 / 스크롤
[보행자: 기본 피해+1] [쇄도: 같은 적3타 보너스]
[산개: 무작위/5칸]   [압쇄: 화상2/전이3]
[증강: 단발/성능2배]

전투
무기 이름 · 핵심 규칙 · 경과 턴
┌복도: 적A/B/C, HP/거리, 쇄도 진도○○○┐
├보유 탄환 아이콘/수치┬장전 순서 최대7칸┤
│갱신된 피해·관통·효과│산개: 무작위/피해 범위│
│한 탄환 설명         │적별 HP 범위/처치 확률│
└─────────────────┴확정/전탄 또는단발/재장전┘
```

- 같은 대열 개발자 비교5종을 제공하고 실제 저장을 보존한다.
- 산개에 확정 조준선/확정 처치 문구를 표시하지 않는다. 나머지는 실제 명령 복제 예측을 유지한다.
- 좁은 가로 화면의5~7칸 수치·설명 폭과 메뉴5번째 카드를 실제 UI로 확인한다.
- 검토에서 확인한 이전 전투 전용 확장 파츠의 산개8칸도 별도 검사한다. 전체 도시 상점은 이 파츠를 제공하지 않아 도시 최대는7칸이다.
- 보상/계산/규칙/무기 상세/임시 실루엣/정산도 최신 효과를 반영한다.

## 검증과 납품

실제 장전/발사/재장전/저장으로5종 경계 규칙, 정확한 배율, 적중 진도, 무작위 분포/예측 범위/캐시 비용을 검증한다. 도시 런의 무기별 완주 경로와 실제 버튼 UI를 확인한다. 자동 경로 QA는 미래 패/RNG 접근이 있으므로 사람 재미·승률 검증과 구분한다. 필요한 회귀와 Windows 내보내기/격리 기동 후 중앙 트래커/로그/히스토리와 로컬 커밋을 완료한다.
