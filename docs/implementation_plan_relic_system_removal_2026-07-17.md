# 렐릭 시스템 제거 구현 계획

## 목표

프로젝트에 분산된 문자열 기반 렐릭 상태와 UI, 전투 효과, 맵 조건, 정산 공식을 제거하고 현행 기획 문서를 실제 런타임 구조와 일치시킨다.

## 구현 범위

1. `RunManager`와 `CombatManager`의 `active_relics` 상태 및 렐릭 전용 효과 제거.
2. `start_encounter()`의 렐릭 인자를 삭제하고 모든 호출부 동기화.
3. 로드아웃 렐릭 카드·토글·스탯 미리보기와 디브리핑 보너스 제거.
4. 가스 밸브 조건부 맵 노드는 연결 구조를 유지한 일반 공개 우회로로 전환.
5. 현행 GDD, 로드맵, HTML 목업, 프로젝트 전용 기획/밸런스 스킬에서 렐릭 계획 제거.
6. 포인트블랭크는 `PartData` 기반 총기 고유 파츠이므로 유지하고 잘못된 명칭만 수정.

## 검증 계획

- 런타임과 현행 문서에서 렐릭 키워드 및 문자열 ID 잔존 검색.
- `start_encounter()` 선언과 호출부 인자 수 교차 확인.
- 변경 파일 대상 `git diff --check` 실행.
- 전술 로드아웃 HTML의 JavaScript 구문 검사.
- Godot 실행 파일이 제공될 경우 헤드리스 프로젝트 파싱 및 씬 실행.
