# 맵·상점 포함 전체 도시 등반 개편

이전 일곱 교전 체험판은 전투와 보상만 제공했다. 개편판은 기존 제작본의 침전 거주구→공역→정비 계층→관리 계층→정점, 6/7/7/7/8층을 하나의 35층 런으로 연결한다. 기본 시작은 도시 등반이며 기초 훈련은 메뉴에서 별도로 선택한다.

## 플레이 흐름

1. 총기와 시작 덱 성향, 해금된 난도를 선택한다.
2. 건물 단면 맵에서 연결된 다음 목적지를 누른다. 다른 방을 누르면 위험과 통로를 미리 확인한다.
3. 전투는 피해·관통·물리/화염/전기와 좌→우 발사 규칙을 유지한다. 승리 보상은 탄환·크레딧·정제·유지 중 하나다.
4. 무기고에서는 탄환12Cr, 파츠30Cr, 진열 갱신3Cr, 덱 정제12Cr을 사용한다. 구매한 파츠를 보관·교체·분해할 수 있다.
5. 보급은 탄환 또는 무료 정제, 미지 단말은 예고된 크레딧/거리·자료/탄환·탄환/크레딧 교환이다. 우회는 전투 없이 기록을 발견한다.
6. 관문을 넘으면 탄창을4→5→6칸으로 늘리거나24Cr을 받는다. 성장한 칸수는 장착 파츠와 별개다.
7. 최종 코어에서 완주를 정산한다. 기록실은 전술 데이터,20기록,시작 덱 성향4개,난도0~10을 보관한다.

환기구의 −2m 비용은 비전투 방을 지나도 유지되고 다음 전투에서 한 번만 적용된다. 같은 목적지에 무료/유료 경로를 동시에 제공하지 않으며 오른쪽 분기는 합류 전까지 오른쪽 경로를 따른다.

## 저장과 연습

`user://city_campaign_v1.json` 하나에 경로·지갑·상점 한도·전투 손패/RNG·영구 프로필을 원자적으로 저장한다. 전투 결과를 화면에 반영하기 전에도 저장한다. 정산과 구매는 상태 검증으로 이중 지급을 방지한다.

기존 제작본의`meta_save.cfg`, 개편판의`chain_run_v2.json`은 별도로 보존한다. 도시 등반과 훈련 이어 하기를 구분한다. 개발자 테스트의 맵·무기고·보급·이벤트·승강기·보상·정산은 실제 도시 저장을 변경하지 않는다.

## 구조와 범위

- `campaign.gd`: 경로,재화,노드 거래,관문,프로필과 저장.
- `campaign_content.gd`: 기존 MapGenerator의 구역명·고도·방 이름을 사용하며 생성 RNG를 노드 시드로 분리.
- `city_map_view.gd`: 실제 Godot 버튼, 목적지 아이콘, 건물 단면과 연결선.
- `campaign_ui.gd`: 맵·상점·보상·서비스·승강기·기록실·정산 화면.
- 기존 Model: 전투·학습 책임 유지. 탄창 영구 성장 보정과 메모리 상태 복원 API 추가.

기존 명중/회피·구경·27탄종·영구 HP 업그레이드는 현재 단순한7탄종/2총기/4시작 덱으로 대체했다. 5관문은 간결한 스탯과 호위 편성으로 구현되어 있다. 최종 보스 아트·사운드와 사람의 재미 승인까지 완료했다는 의미는 아니다.

검증 수치와 화면 증거는 [QA 리포트](qa/reports/full_city_campaign_2026-09-16.md)에 기록한다. 최신 Windows 실행 파일은`builds/city-windows/Play-City.cmd`다. APK와 원격 푸시는 요청 전까지 진행하지 않는다.
