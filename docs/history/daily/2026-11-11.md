- 회귀: 현재 UI 검사 30종 통과. `build_roles_rules`의 11-03 계산기 비교 6건이 새 등반의 교차 사격 플래그로 어긋나, 검사 빌더에서 11-11 규칙 플래그(교차·과열)를 지우게 했다(3048/0). 나머지 규칙 회귀 통과(magazine_build 기존 1건).

## 파츠 고장·이중 대가 수정

- 사용자: "1,2 진행해 줘". 야전 압축기 새 등반 제시 중단, 냉각 약실 '수동 냉각 직후 첫 공격탄 +3', 과열 강제 냉각에서 파츠의 재장전 +1 대가 제외, 잔열 노심 열 한계 −1, 연타 공명기 열 대가 삭제. → [검토 · 고친 것](../../qa/reports/part_review_2026-11-11/README.md#고친-것-1111-사용자-12-진행해-줘).
- 실수와 정정: 처음엔 강제 냉각을 '총 기본 재장전'으로만 세서 회수 가속기의 −1까지 뺐다. 탄창 교체는 최소 2턴이라 래칫에서 회수 가속기가 아무 일도 하지 않게 되는 것을 검사로 찾고, 대가(+)만 빼도록 고쳤다.
- 재측정: 열폭주 노심 리벳 +16% → −8%, 연타 공명기 리벳 +8% → −8%. 후미 점화기는 아직 손해(래칫 +6%, 리액터 +14%).
- 회귀: 현재 UI 검사 33종 통과, 규칙 회귀 통과(magazine_build 기존 1건).
