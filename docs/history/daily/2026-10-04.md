# 2026-10-04 작업 기록

## 전체 방향 확인과 개발 기준점 커밋

사용자는 현재까지의 전체 진행 방향에 긍정 답변하고 작업 내용 커밋을 요청했다. 활성 브랜치 `prototype/core-redesign`의 미커밋 작업 전체를 범위로 잡았다. UI·UX 개편, 성장/빌드 흐름, 세계관·도트 기준/자산, 개발 지침/도구, 고출력·과열·원거리 요격 샘플과 검증 기록을 함께 보존한다. 사용자 방향 확인은 개별 수치·임시 아트의 최종 확정과 구별해 현행 방향 문서에도 기록했다.

커밋 준비에서 변경 파일 654개를 확인했다. 빌드·임시 QA·도구 바이너리·로컬 MCP 설정은 기존 제외 규칙을 따르고, 텍스트 파일 470개의 인증 정보 패턴 검사는 후보 0건이었다. 변경 코드와 에셋은 직전 검증 이후 수정하지 않았으며 기존 통과 기록을 유지했다. 이번 요청 범위는 로컬 커밋이며 원격 푸시는 포함하지 않는다. 루트 `main` 체크아웃의 별도 변경은 그대로 보존한다.

## 원거리·요격과 고출력 결합

사용자 진행 요청에 따라 `PLAY_RANGED_SAMPLE.cmd`에 압력두꺼비 한 종과 두 비교 편성을 구현했다. 준비 2턴·발사 턴 이동 없음·압력탄 6m/턴·HP 1·본체 사망 후 탄 유지, 가장 가까운 탄의 확정 요격(산개 포함), 증폭/전이 유지, 적·증원과 분리된 안정 ID를 실제 모델과 예측/저장에 연결했다. 기존 파츠·압축·과열 비용이 늘리는 실제 재장전 시간에 압력탄도 진행한다.

새 UI는 도달 턴, 실제 다음 표적일 때만 요격 표식, 적 피해와 요격 구분, 재장전 피격 경고, 눌러 보는 상세와 전용 패배 이유를 제공한다. 정상 속도 캡처 중 발사 순간에 남아 있던 준비 문구를 현재 압력탄 표시로 동기화했다. 입력 검사의 중복 카드 선택·창 크기 변경·상세창 좌표 문제도 수정하고 실제 카드 입력으로 두 전투를 완주했다.

[보고서와 13개 캡처](../../qa/reports/ranged_2026-10-04.md). 원거리규칙417/0·UI281/0, 기존 무기3245/0·성장4229/0·적27/0·증원144/0·출력규칙296/0·출력UI149/0·발사과열165/0·기상탑68/0. 최종 스크립트/파싱 오류 없음. 기존 격리 Windows 인증서 메시지는 환경 한계로 구분한다. 외형은 시험용 도트 실루엣이며 정식 아트·사운드·추가 연출 폴리싱·캠페인 편성은 후속이다. 사람의 요격 부담/반복 선택과 Galaxy 성능은 검증하지 않았다. APK·커밋·푸시는 하지 않았다.

## 연출 방향 이해 확인 · 폴리싱 후속 전환

화면 반응 보강 후 사용자가 대략적인 느낌을 이해했고 향후 재정비·폴리싱하면 되겠다고 답했다. [현재 방향](../../direction/current.md)과 [출력/과열 설계](../../direction/ammo-risk.md), 진행표를 ‘방향 이해 확인 / 세부 폴리싱 후속 대기’로 갱신했다. 최종 품질·수치·재미 확정으로 확대 해석하지 않는다. 다음 우선순위는 기존 원거리 한 종·요격 결합이다. 이번에는 결정 상태만 기록했고 코드·아트 변경이나 기능 검사 재실행은 하지 않았다.

## 고출력 발사·과열의 시각 피드백 보강

사용자의 모호했던 피드백을 확인했고 ‘강한 발사와 과열을 표현하는 화면 반응이 약함’이라는 답을 받았다. `game-feel` 기준으로 고출력의 짧은 총구 집중, 강화된 두 탄의 레일/타격 강조, 총열 잔열과 증기, 기본 재장전과 추가 냉각의 턴별 접근을 비교 샘플에 적용했다. 실제 이벤트를 재생하며 수치·모델·예측·공급은 유지했다. 연출 줄임과 건너뜀을 확인했다.

[구현·화면·검증 보고서](../../qa/reports/ammo_feedback_2026-10-04.md). 신규 연출165/0, 기존 UI149/0·규칙296/0·기상탑68/0. 중간의 창 크기 변경/클릭 경쟁은 테스트 대기 순서로 해결했고, 실제 작은 화면의 확대 피해 숫자/정보판 겹침은 표시 위치를 수정했다. 최종 스크립트 오류 없음, 기존 격리 Windows 인증서 메시지는 구분해 기록했다. 자동 통과를 사람의 체감 개선 확정으로 취급하지 않는다. 실행 `PLAY_AMMO_RISK.cmd`, 새 사운드·캐릭터 프레임·원거리 요격은 후속이며 APK·커밋·푸시는 하지 않았다.

## 주인공 표시 크기 35% 축소

사용자의 30~40% 축소 요청을 반영해 샘플 씬의 character_size_multiplier를 0.65로 지정했다. 공통 character_scale을 통해 주인공 표시와 총구 위치에 적용하며 발 위치를 유지했다. 적·배경·UI의 크기는 바꾸지 않았다. 기존 캡처를 보존하고 `tower_art_scale_2026-10-04_assets/`에 새 화면을 저장했다. 대표1280×900과 작은1008×630을 직접 열어 확인했고 기존 샘플 검사68/0을 통과했다.

## 몬스터 컨셉과 원거리 규칙 검토

사용자가 현재 주인공 크기를 긍정 확인하고 몬스터 컨셉·목록 및 원거리 공격 방식을 요청했다. [몬스터 제작 초안](../../direction/monster-roster.md)에 일반 8종과 보스 후보 2종을 정리했다. 기존 6종 역할에 생물/정비 장치의 과거 용도와 실루엣을 연결하고 신규 원거리 2종을 제안했다. 첫 시안 제작 후보는 잔열쥐·철각충·압력두꺼비다.

실제 모델·콘텐츠·캠페인·예측 코드를 확인해 플레이어 HP 부재, 0m 패배, 가까운 적 자동 표적, 관통은 장갑 차감, 사격 전체 1턴 및 무기/파츠별 재장전 비용을 설계 근거로 삼았다. 느린 공격체의 요격을 첫 실험으로 권고하며 증폭탄 요격·전격 전이, 산개의 확정 요격 예외, 발사 후 본체 사망·공격체만 남는 경우·재장전 중 도달을 명시했다. 규칙과 수치는 디렉터 초안이고 사용자 확정/플레이 검증 결과가 아니다.

현재 방향·도트 기준·세계관·게임 설계·작업 추적에 연결했다. 이번 변경은 문서이며 새 적/HP/투사체 구현, 이미지 생성, APK 제작은 하지 않았다. 기능 검사를 재실행하지 않았으며 문서의 상태 구분과 신규 링크를 확인했다.

## 탄환 출력의 위험·대가 검토

사용자가 몬스터·요격 진행 방향에 동의하고, 증폭 효과를 받은 뒤 과열로 재장전 시 적에게 추가 2턴을 주는 예시를 제시했다. 실제 발사/재장전/화상/충전 처리와 무기·파츠의 비용을 읽고 [검토 초안](../../direction/ammo-risk.md)을 작성했다. 일반 증폭의 기존 탄창·순서 비용, 추가 2턴의 큰 생존 영향, 전투 종료 시 재장전 대가가 사라지는 한계를 명시했다.

일반 조합은 유지하면서 일부 고출력 변형에 발사 시 다음 재장전 +1턴을 부과하는 안을 우선 비교하도록 제안했다. 후속 두 발의 실제 피해를 보고 비용을 사후 판정하는 복잡도를 줄이고, 장전 중 최종 재장전 시간과 적 위험을 함께 예측하는 UI를 정의했다. +4 증폭/+1턴은 디렉터 비교 수치이고 사용자 확정이 아니다. 파츠 없는 보행자·장갑 없는 충분한 HP의 단일 적 조건에서 24/32/40 피해의 산술 비교를 남겼으며 실제 전투 시뮬레이션 통과로 표현하지 않았다.

변경은 설계 문서와 진행 상태뿐이다. 기존 플레이 규칙을 수정하거나 기능 검사를 재실행하지 않았다. 승인된 몬스터·요격 제작은 후속으로 유지하며 과열 제안을 이미 적용했다고 안내하지 않는다.

## 고출력 탄환 비교 샘플 구현

사용자가 첫 단계 진행을 요청해 `PLAY_AMMO_RISK.cmd`와 비교 전투 2개를 만들었다. `charge_hot`은 +4 증폭과 발사당 다음 재장전 +1턴을 갖고 일반 증폭·압축의 기존 규칙은 유지한다. 과열 누적/해소·기존 저장 호환, 실제 모델로 계산하는 사격 후 재장전 예측과 산개 범위, 카드의 열 표시·+1, 위험 스트립과 비교/재시작/종료 동선을 구현했다. 캠페인 시작 덱·보상·상점에는 새 변형을 넣지 않았다.

긴급 제압은 고출력으로 가까운 두 적을 처리해야 하고, 보호막 전열은 일반 출력으로 재장전 시간을 남기는 구성을 비교했다. 두 전투를 실제 UI 카드 입력으로 끝까지 승리했고 예측된 접촉 패배·재시작도 확인했다. 보호막 전열에서는 안정적인 첫 사격 후 고출력 마무리도 가능하다. 판정 차이를 보이는 실험 편성으로, 전체 밸런스/재미 완료라는 뜻은 아니다.
