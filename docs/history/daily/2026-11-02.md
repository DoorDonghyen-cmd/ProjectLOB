- 재장전 복장 혼합, 모바일 확대/비율 깨짐, 사격 입력3안, 발사 대상 표시와 발사별 카드 소모, 연속 발열/총기 성능, 교체/냉각 역할, 행동 연출, 작은 글자, 지도 상시 범례/경로 가독성을 기록했다.
- 소스 대조: 교체/냉각 모두 열 감소·누적 초기화, 기존 연속 공격 추가 열0/1/2, 연출 종료 뒤 카드 갱신, 창 전체 배율 변경/복원, 버튼으로 여는 지도 범례 확인. 복장 혼합/모바일 확대의 로컬 원인은 아직 재현하지 않았다. 실행 형태·기종·발생 시점과 복장/총기를 비동기 질문했다.
- 후속: 오류→가독성/연출→사격·열 비교→지도 밀도/전체 등반 균형. 최근 적 HP·총기별 시작 덱 변경과 앞선 지도1~2전투 문제를 보존했다. 새 입력·열 성능 수치는 채택하지 않았다.
- [전체 검토](../design/playtest-review-2026-11-02.md), [현행 우선순위](../../direction/playtest-priorities.md). 문서만 변경, 신규 런타임 검사/실기기 검증·APK/커밋/외부 게시 없음.

- 본편 전투→메뉴에서 배율2가 남는 오류를2016×908에서 재현했다. HUD 이탈 전에 크기 콜백을 끊어 원래 설정을 복원한다. 저장 복원 후 float 방문 ID와 정수 간선 ID가 맞지 않아 경로가 흐려지는 오류도 재현/수정했다.

- Godot4.7 격리 저장: 배율/35복장·총기2,986, 확대/축소 전환54, 카드/모델 일치1,752, 지도/현행 규칙 재생19,115, 기존 HUD11,536, 피드백169검사 실패0. HUD probe/import 통과. 실제3~4크기 화면 확인.

## 후속 — 사격 범위와 교체·냉각 비교

- 사용자 진행 지시에 따라 실제 획득 상태15개(5총기×첫 교전/장갑 진지/관문)로 [비교판](../../direction/fire-heat-comparison.md)을 연결했다. 기존 `OPEN_MAGAZINE_COMPARISON.cmd`를 사용하고 본편 기본 진입/저장은 유지한다.
- 앞줄 연속 드래그→사격 확정, 짧은 탭→기존 빼내기, 취소/가장자리 스크롤/메뉴 발수 조절을 구현했다. 기존 발수·강행·처치 연속 조건과 적 행동 비용을 존중한다.
- 교체 냉각 기존/0/2 및 고열 위력80%를 독립 옵션으로 비교한다. 교체0/2는 연속 누적을 유지하고 냉각 약실+4를 보존한다. 기본은 범위 선택+열 유지+위력 유지. 디렉터 실험값이며 본편 채택/사람 재미 확인을 뜻하지 않는다.
- 같은 열 상태에서 짧은 사격은 추가 피해를 포기해 강제 냉각 비용을 피하며, 교체와 냉각의 역할 차이가 확인됐다.75조건 승리 경로를 실제 명령으로 재생했으나 제한 탐색이므로 최적 턴/사람 승률로 해석하지 않는다.
- 규칙5,805·조작105·경로658·기존 총기7,101/HUD11,536검사 실패0, 전체 임포트 통과.3크기 캡처 확인. 재장전 중 패배의 누적 초기화/저장도 검사했다. [상세 근거·화면·변경분](../../qa/reports/fire_heat_comparison_2026-11-02.md).
