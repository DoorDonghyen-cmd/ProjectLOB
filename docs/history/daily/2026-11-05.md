## PixelOE · pixelfx 추가

- 사용자 요청으로 [PixelOE](https://github.com/KohakuBlueleaf/PixelOE)와 [pixelfx](https://github.com/patch-gg/pixelfx)를 로컬 제작 도구로 설치했다. [사용법·범위](../../art/pixel-tools.md), [버전 잠금](../../../tools/art_tooling.lock.json).
- 원본은 `D:/ProjectLoB/.tools/`에 분리하고 커밋을 고정했다. PixelOE 전용 Python 환경·의존성 잠금, 세 실행 CMD, 재설치와 검사 명령을 추가했다. 기존 소스 수정이나 다른 버전이 있는 재설치는 중단하도록 했다.
- `python tools/check_pixel_tools.py` 통과. 실제 PixelOE 64×48 RGB 변환 및 입력 보존, pixelfx 탄착43·불꽃60 프레임의 투명 시트·좌표·재생 시간과 원본 자체 검사2개 실패0/경고0을 확인했다. `pip check` 통과. 원본은 두 저장소 모두 수정 없음.
- 재설치 명령을 기존 설치에서 실행해 같은 고정 버전으로 복구 후 검사를 다시 통과했다. 갤러리 등록 모듈에서244종 효과 가져오기도 확인했다.
- 로컬 갤러리 실행기와 HTML·효과 등록 모듈의 HTTP200을 확인했다. 기본 포트8766, 기존 UI 목업8765와 분리했다. 제한된 실행 환경의 로컬 접속 차단 때문에 갤러리 연결 확인은 일반 Windows 실행으로 수행했다.
- Apache-2.0·MIT 원문 및 pixelfx 파생 코드·별도 글꼴 고지를 보존했다. 게임에는 글꼴이나 효과를 통합하지 않았다.
- CPU 변환 경로가 확인된 범위다. GPU 경로는 미검증이고 Slang 가져오기는 C:/D: 드라이브 차이로 D3D12 경고가 있다. 도구 설치가 현재 아트의 화풍 적합성이나 Godot 통합을 입증하지 않는다. 다음 자산 작업에서 선택적으로 비교한다.
