# 2026-10-30 작업 기록

## 전체 성장·탄약 경제 통합 감사

- 사용자 후속 실행 요청으로 우선순위6번을 진행했다. B1 적용 빌드에서 새 등반31조건과 막힌 전투의 준비/재탐색을 실행했다. 재현 가능한 QA 도구·전투/획득 지표·근거 묶음을 추가했고 본편 전투 수치는 유지했다.
- 선택21실행 125,231검사 실패0. 기본 정책25조건, 합법 준비/재탐색 포함29조건에서 엔딩 경로를 확인했다. 통합 성공846전투이며 반복 재생한 앞 구간은 중복 합산하지 않았다. 탐색 실패는 기능 실패나 불가능성 증명과 구분한다.
- 운반5무기×2시드는 모두 엔딩 경로 확인. 후미 점화기 해제의 재장전 비용 차이, 정찰 패 교환, 가방/공방 압축/보급 경로의 기회비용을 기록했다. 비상 보급4사례에서 지급 기본탄 실제 발사와 승리를 확인했다.
- 운반10경로 모두 코어8 상한에2구역에서 도달했다. 다음7번은 후반 성장 기회 배분을 먼저 비교한다. 정찰 리액터·압축 우선 리액터의 최종전은 현재/이전 발열과 준비 탐색에서도 미해결로 남겨 함께 비교한다.
- 기능/저장 검증과 화면·사람 체감·모바일 지속 성능을 구분했다. 이번 단계의 화면 변경/새 렌더 검수는 없으며 모바일 발열·사람 난도/재미·나머지 복장 균형은 미확인이다.
- QA 초기의 이중 코어 대체안과 교환 경로 검사기 오류를 수정했다. 초기 잘못된 실행은 최종 수에서 제외했다. 과거 원자료의 공통 note 오류는 보고서에서 명시하고 후속 도구 문구를 수정했다.
- 작업 시작 시 기존 변경을 보존했고 본편 GDScript 해시 동일성을 확인했다. APK·커밋·푸시·외부 게시 없음.

## 후속 — 후반 관문 성장 확장 본편 적용

- 사용자의 다음 실행 요청으로7번을 진행했다. 기존8단계 성장 지연/무상 상한 추가와 비교해, 후반 관문 개조 하나 대신 상한+2를 선택하는 안을 채택했다. 새 등반2~4구역 보스 이후 최대14, 이후 기존 조건·승리로 성장한다. 기존 저장/초반/발열/적 수치는 보존했다.
- 상한·승리 정산·규칙 표식·저장 검증·예측을 연결했다. 카드에 성장 완료 후 실제 효과와 즉시 피해 증가가 없음을 표시하고, 네 후보2열·내용 기반 높이·초기 포커스를 적용했다.
- 최종15실행51,292검사 실패0. 새 등반10조건275전투, 기본7/정비 포함9조건 엔딩 경로 확인. 초반112전투는 이전 경로/턴/탄약/성장 결과 동일. 각 후반 구역2단계에서10/12/14 도달을 확인했다.
- 압축 중심 리액터 최종전은 새 경로를 찾았지만 잔탄1. 정찰 리액터는 교환 후속으로 최종전까지 진입했으나 여전히 탐색 미해결이다. 스플린터 강제 냉각 부담도 유지되므로 전면적인 난도 해결로 표현하지 않는다.
- 세 화면 비율·큰 글자 실제 렌더/터치 검사, 최종 대표3캡처 직접 검수. 초기4열 카드 글자 넘침을2열/자동 높이로 수정했다. 초기 형식 추론/명령 인자 오류는 최종 집계에서 제외했다.
- 사람의 관문 선택 가치·각 구역 초반 두 전투에 몰리는 성장·모바일 지속 성능/발열은 후속이다. 다음 독립 작업은8번 관문 통과 연출 검토. 추가 슬롯/소모 특수탄/복장 해금/발사기구 파츠는 체감 확인 전까지 보류한다.
- 기존 큰 작업 트리를 보존했다. APK·커밋·푸시·외부 게시 없음.

## 최신 후기 — 전투 반복감과 우선순위 변경

- 사용자는 플레이 중 “톡톡 터지는 도파민이 부족하게 느껴져서 흥미가 길게 가지” 않는다고 했고, 후속 질문에 “전투가 반복돼 매번 비슷하게 느껴진다”고 답했다. 이번 후기의 정확한 빌드는 확인되지 않았다.
- 디렉터 판단으로 관문 통과 연출보다 전투별 판단과 길이의 대비를 우선 검토한다. 기존 적 패턴·성장 장치가 실제 장전/사격 선택을 충분히 바꾸지 못한다는 설명은 가설로 구분했다.
- 초반 연속 3~5전투에서 짧은 돌파, 준비 변화, 실제 획득 직후 처치 변화를 비교하는 범위와 사람 플레이 판단 기준을 정리했다. 현재 방향·통합 우선순위·작업 현황을 연결했다.
- 이번 변경은 문서만이다. 비교안 구현·실제 화면/사람 체감·모바일 지속 성능은 미수행이며 기존 자동 검사 결과를 재미 검증으로 전용하지 않는다.

## 후속 실행 — 초반 전투 호흡 1차 개편

- 사용자 “좋아 진행해 줘” 승인으로 첫 구역 일반전의 길이와 판단 차이를 구현했다. 새 편성 12에 무리전·사수 매복·교대 방패 진지를 적용하고 일반전의 반복 증원을 줄였다. 두 번째 승리에서 실제 첫 특수탄과 함께 쓸 보상 후보를 제공한다. 현재 방어/개방 표시와 지도 설명을 연결했다.
- 첫 단축안에서 일반전이 모두 같은 한 사격으로 끝나는 경로를 확인해 기존 태세 교대 규칙을 활용했다. 실제 획득 리벳에서 즉시 경로 5턴/8발과 먼저 개방한 경로 2턴/3발을 비교했다. 최적성·사람 재미의 증거와 구별한다.
- 초기 소이 보상에서 충격을 앞에 둔 경로가 3구역 보스 탐색에 막혀, 기존 맞춤 후보를 우선 유지하고 충격을 대안으로 남겼다. 수정 뒤 같은 보스를 통과했다. 초기안과 이전 편성 대조 기록도 보존했다.
- 최종 초반 17조건(새 등반 12·이전 편성 5) 85전투와 첫 관문 출발 확인. 같은 장비 준비 비교·세 화면 비율·터치/자동 저장 확인. 출시 캔버스 설정을 바꿨던 초기 UI 검사 설정은 수정 후 재실행했다.
- 최종 7실행 18,375검사 중 18,373통과, 리액터 최종전 한 조건의 승리/엔딩 경로 확인 2개 미충족. 후반 45전투 완료와 초반을 합쳐 실제 130전투 완료. 리벳은 엔딩, 리액터 최종전은 신구 편성의 전투 입력이 동일한 상태에서 탐색 미해결로 남겼다. 일반 기능 오류와 공략 불가능성으로 표현하지 않는다.
- 구현 상태·현행 규칙·후속 우선순위를 갱신하고 근거 압축/해시/화면을 보존했다. 본편 변경은 예상한 7개 스크립트뿐이며 기존 작업 트리를 보존했다. 사람의 반복감 개선, 정찰 리액터 장기전과 모바일 지속 성능/기기 발열은 후속이다. APK·커밋·푸시·외부 게시 없음.
