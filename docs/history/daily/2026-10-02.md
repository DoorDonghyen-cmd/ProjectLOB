# 2026-10-02 — 디렉터 기준 재정립과 첫 적용

사용자가 기획·아트 전면 재검토와 개편을 위임했다. 오래된 creative-director 등 역할 지침이 현재 게임의 방향과 충돌하는 문제를 정리했다.

- 역할 스킬 12개·AGENTS·작업 흐름·진행 경로를 두 위치에서 갱신하고 원문을 보존했다. 경험 평가 보조 문서의 LIFO·명중 가정도 제거했다.
- [현행 기획](../../direction/current.md), 전체 화면의 역할, 산업 그래픽 아트 기준과 자산 이력을 작성했다.
- 도시 배경을 생성·적용하고 공통 글꼴과 전투 화면의 전장/발사 레일/손패 구도를 교체했다.
- 물리/논리 화면 크기 혼용, 압축 도구와 버튼의 줄바꿈 팽창, 카드 문구 반복, 적 장갑 표현, 포커스 대비를 수정했다.
- 현행 규칙 3245/0, 무기 UI 390/0, 캠페인 UI 3698/0, 메인 준비 33/0, 최종 배치 검사 실패 0. 과거 `run_all` 시간 초과는 미완료로 기록했다.

[검증 보고서와 캡처](../../qa/reports/director_rebuild_2026-10-02.md)에 실제 적용 범위와 미검증 항목을 남겼다. 다음 제작은 지역·캐릭터 자산과 파츠/연쇄의 시각 피드백 확장, 실제 기기에서의 이해도 검증이다. 이번 작업 이전의 미커밋 변경은 유지했다.


## 전체 플레이 경험 제작

- 회수자·작업실·도시·네 지역 원화 7개를 제작하고 기존 첫 구역과 합쳐 전 지역에 적용했다. 총기 5종과 적 6역할의 네이티브 표현을 새로 만들었다.
- 타이틀·총기 선택·지도·상점·다섯 파츠 장착·보상·결과를 연결했다. 상점 상품 세 개와 충전·장착 상태를 한 화면에 배치하고 구매 전후 안내 오류를 수정했다.
- 발사 슬롯 위치를 유지하고 실제 피해·파츠 발동과 속성 타격을 표시했다. Noto Sans KR과 라이선스를 번들로 포함했다.
- 규칙3245/0, 무기UI390/0, 캠페인UI3698/0, 메인준비33/0, 새 경험64/0, 세 비율 배치 실패0. 압쇄·증강 캠페인10668/0. 현행 시드731042에서 다섯 총기 두 경로씩 35층 완주, 4596명령을 확인했다.
- 예전 고난도 재생5건은 종료 시점 불일치로 실패하여 근거에서 제외했다. 추가20경로 탐색은 필요한10경로 확인 후 중단했으며 미완료를 통과로 집계하지 않았다.
- [최종 보고서와 실제 화면](../../qa/reports/full_experience_2026-10-02.md), 실행 `PLAY.cmd`. 실제 기기·사람의 이해도, 프레임 캐릭터 애니메이션·음악/효과음은 별도다. APK·커밋·푸시는 수행하지 않았다.

## 전체 도트풍 확정과 제작 도구 설치

- 사용자가 산나비·ARCANE TRIGGER처럼 게임 전체와 UI까지 도트풍을 요청했다. [현행 아트 기준](../../direction/art-and-ux.md)에 확정 사항과 미구현 상태를 구별해 반영했다.
- 기존 외부 스킬 5개가 활성 작업 폴더에만 있음을 확인했다. 파일을 보존하고 신규 자산 제작·장면·타일·셰이더·Impeccable 스킬 5개를 추가했다. 대화 루트에도 10개를 배치하고 SKILL.md 해시 일치를 확인했다.
- LibreSprite 1.3 공식 Windows ZIP의 SHA256을 검증하고 `.tools`에 설치했다. 설정 경로를 작업 폴더로 분리했다. 제한 셸에서는 버전 출력 후 1로 종료하고 실제 변환이 수행되지 않아 승인된 일반 Windows 환경에서 변환을 검증했다.
- PNG → ASE → 시트 PNG/JSON 내보내기, RGBA 픽셀 동일성, 크기·팔레트·투명도, 미리보기, 기준 화면 비교 스크립트를 확인했다. 도구 동작 검사이며 게임 아트 품질 검증은 아니다.
- Impeccable 스킬 4.5.0과 엔진 0.1.11을 설치하고 `engine-probe`를 확인했다. 자동 브라우저 훅은 설치하지 않았다.
- Godot MCP 원본 커밋을 고정해 빌드했다. npm audit에서 확인한 구형 의존성을 SDK 1.31.0 등으로 수정하고 재검사 0건. MCP 초기화·14개 도구 목록·4.7 엔진 버전·현재 프로젝트 정보 조회를 통과했다. Git worktree에서는 상위 설정을 읽지 않아 두 위치에 프로젝트별 설정을 등록했다.
- PixelLab 계정이 없다는 사용자 답변에 따라 비활성 연결 설정과 로컬 키 입력 도구를 준비했다. 계정 생성·인증·유료 호출은 수행하지 않았다.
- 실행: `PIXEL_EDITOR.cmd`, 계정 준비 후 `CONNECT_PIXELLAB.cmd`. 출처·버전·해시는 `tools/art_tooling.lock.json`, 검증 결과는 `qa_runtime/art_tooling`에 기록했다. 게임 규칙·화면·플레이어 저장·APK·커밋·푸시는 이번 설치에서 변경하지 않았다.
