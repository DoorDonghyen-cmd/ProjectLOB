# 2026-10-26 플레이 피드백 검토

사용자의 플레이 메모를 현재 소스/현행 방향과 대조해 관찰, 기능 확인, 디렉터 제안, 미확정 항목으로 나눴다. 격리 Godot 모델 비교로 위력3 기본/철갑의 장갑0/3/5 피해와 래칫 한계 도달 시 적 생존/전멸의 턴 비용, 탄약 소진 패배 처리를 확인했다. 실패0. 사용자 세이브 재현과 GPU 프로파일링은 수행하지 않았다.

파츠 선택 차이를 만들기 전 슬롯부터 늘리지 않기, 핵심 특수탄은 전투별 비축 유지, 무한 리필/무한 증원 보류, 적 몸체 부분 겹침과 선택적 거리 표시는 디렉터 제안이다. 발열·관통이 구현돼 있다는 사실을 충분한 체감으로 오인하지 않는다. 후반 성능은 누적 기록 직렬화/복사·예측·화면/연출을 측정 대상으로 기록했고 발생 시점 질문은 응답 대기다.

전투 코드·수치·원화·사용자 저장 변경 없음. APK/커밋/푸시/외부 게시 없음. [전체 검토](../design/playtest-review-2026-10-26.md).
