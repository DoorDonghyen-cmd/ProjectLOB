## 관문 본편 연결

사용자 요청("본편에 연결해주고")으로 2026-11-05 승인 관문 시안(문 위 표찰 출발)을 본편에 연결했다.

- `campaign_ui.gd::modern_gate()`가 `samples/gate_review/threshold_preview.tscn`을 열고 `configure(ui, presenter)`로 실제 등반을 넘긴다. 관문 명령은 `_campaign_action`(자동 저장)으로 처리, 출발만 화면을 다시 그려 지도로 넘어간다.
- 추가: 복장별 작업 자세, 정비소와 같은 `메뉴`, 유료 정비가 없는 이전 저장 처리, 높이 440 미만에서 비교창을 올리는 배치.
- 실수와 정정: 시안 고정물(임의 구역·승리 수)이 저장 검증을 통과하지 못해 자동 저장 검사가 실패 → 실제 자동 등반의 관문 상태 파일로 교체. 처음에는 출발에도 '다시 그리지 않음'을 넘겨 암전 화면에 머묾 → 출발만 다시 그리도록 수정. 844×390에서 실행 버튼이 선반에 가림 → 배치 보정.
- 검증: 본편 관문 123검사, 시안 3종 129/112/102 통과. 이전 관문 화면을 누르던 오래된 검사 7개와 11월2일 기록 재생 검사는 갱신 필요. [보고서](../../qa/reports/gate_live_2026-11-07/README.md).
