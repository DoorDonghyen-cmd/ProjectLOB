- [별도 Godot 시안](../../qa/reports/workbench_theme_2026-11-04.md): 전체 장소/배우, 5작업 탭, 먹색·아이보리·황동, 보유 탄 선택과 간결한 우측 변화 정보. 글자/수치는 실제 엔진 노드.25확인 실패0, PC1280/S26비율 렌더 확인.
- 새 근접 배경 생성은 이미지 도구의 안전 필터 거절로 사용하지 않았다. 기존 원화/배우/탄환 재사용과 시안 재질로 구성했다. 실제 손/작업물의 근접 원화·애니메이션 미구현. 시안은 표시 예시이며 정비 확정/저장 미연결, 본편 파일 유지.

## 정비소 이후 UI 개편 대상 목록

- 사용자가 같은 과정을 다른 UI로 이어가되 레퍼런스를 먼저 수집하고 대상부터 목록화하도록 요청했다. 기존 캡처/실제 진입 코드/현재 규격을 대조해 [개편 대상·우선순위·레퍼런스 수집 범위](../../direction/ui-rework-scope.md)를 작성했다.
- 결과/상점/보상/관문 우선, 보급/사건/빌드 다음, 공통 상세/메뉴/설정 연계, 서사/기록 후순위 검토를 제안했다. 지도/전투/캐릭터 선택/타이틀은 현재 구조와 읽기 문제를 구분해 부분 점검 대상으로 남겼다. 정비소의 작업대·색·탭을 모든 화면에 복제하지 않는다.
- 이번은 목록/계획만으로 제품/아트 수정·새 실행 검사·외부 레퍼런스 수집 없음. 다음은 상위4화면의 출처 있는 실제 게임 레퍼런스 비교다.


## 결과/상점/보상/관문 UI 레퍼런스 수집

- 사용자 실행 지시로 공개 UI 아카이브/리뷰/플레이어 캡처를 검색해5개 게임16개 화면, 각 영역4개를 선정했다. [이미지 비교 보드](../../art/references/2026-11-04-ui/index.html) · [출처/관찰/참고/제외/자산·모바일 조건](../../art/references/2026-11-04-ui/README.md).
- 결과는 Hades 대표 빌드와 Balatro 결과 선언/다음 행동, 상점은 Dead Cells 장면과 Slay the Spire 진열/가격, 보상은 Hades 효과 비교와 Slay the Spire 선택, 관문은 Moonlighter 장소/비용과 Slay the Spire 전후 비교를 중심으로 제안했다. 다른 게임의 규칙/장식/팔레트를 그대로 가져오지 않는다.
- 원본16개 시각 확인·해시 일치·HTML 로컬 파일 연결/JS 문법 검사 통과. Balatro 공식 팩 아틀라스와 Inscryption 전투 보드를 보상 UI 후보에서 제외/교체하고 이유를 기록했다. 구버전 캡처와 정지 화면 관찰/미검증 입력·애니메이션을 구분했다.
- Work 설정에서 로컬 브라우저 사용 비활성 반환. 실제 보드 렌더/분류·확대 클릭 검증은 미완료이며 HTTP 서버 지속 실행도 확인하지 못했다. HTML 직접 열기와 원본/접촉표/문서를 제공한다. 이 제한으로 제품 작업 승인을 다시 요구하지 않았다.
- 조사 단계로 게임/에셋 임포트/저장 변경·Godot 회귀·외부 게시 없음. 다음은 결과창의 실제 장면·데이터를 넣은 통합 시안이다.


## 등반 결과창 Godot 시안

- 기존 배경과 복장 위에 승패·원인·대표 전투 수·장착 코어·기록 내 최고 단발을 배치했다. 상세는 접을 수 있다. 기존 승리를 복원하고 전투 스냅샷에서 실제 탄창 교체로 패배를 재현했다.
- 격리 실행에서 1280×800/S26 두 가로 크기, 터치·글리프·버튼 크기·상태 보존 279검사 통과. [시안 실행과 전후 캡처](../../qa/reports/results_review_2026-11-04/README.md). 사용자 미감과 Android 실기기·본편 이동 경로는 후속이다.

- 후속 피드백으로 패배 시안의 운반용 외투 쓰러짐 포즈를 제작했다. PC/S26 가로 캡처와 기존 279개 검사를 다시 확인했다. [수정된 패배 화면](../../qa/reports/results_review_2026-11-04/lost_1280x800.png).

- 쓰러진 자세가 어색하다는 피드백을 반영해 패배 시안에 사용한 총기만 남겼다. PC/S26 가로 캡처와 279개 검사를 확인했다. [같은 기록에서 두 연출 비교](../../qa/reports/results_review_2026-11-04/compare_lost_staging_1280x800.png).

- 총기 자세에 대한 후속 피드백으로 패배 시안을 빈 전장으로 전환했다. 결과 정보와 별개로 배경 색만 0.85초 동안 어두워진다. 285개 검사 통과. [패배 시안](../../qa/reports/results_review_2026-11-04/lost_1280x800.png).

- 결과 시안에서 같은 경로 재시작을 제거하고 ‘새 도전’, ‘탑 돌파/돌파 실패’ 문구를 적용했다. 기록실은 보조 행동으로 유지했다. [수정 시안과 261개 검사](../../qa/reports/results_review_2026-11-04/README.md).

## 도전 결과창 본편 적용

- 승인 시안을 본편 결과와 공유하고 승리 귀환/패배 전장·상세·새 도전·기록실을 연결했다. 새 도전은 준비 화면을 열며 시작 확정 전 저장은 보존한다.
- 본편 1,211개 통과. PC 승리/패배는 시안과 픽셀 일치, S26 가로 크기와 인셋 제외 크기는 스크롤 없이 확인했다. 구형 서사 검사 실패와 Android 실기기 미검증을 [검증 보고서](../../qa/reports/results_live_2026-11-04/README.md)에 기록했다.

## 카운터 상점 시안

- 추가 상점 레퍼런스를 바탕으로 기존 카운터 위 실제 상품·가격표, 선택 효과와 결제 결과를 배치했다. 상인 그림은 별도 시안 자산이다.
- PC/S26 가로 크기에서 실제 Campaign 거래를 사용한 358개 검사 통과. [실행·전후 비교·검증](../../qa/reports/shop_counter_review_2026-11-04/README.md). 본편 연결과 실기기 확인은 후속이다.
