# 2026-10-05 작업 기록

## 최신 플레이 피드백과 후속 탄환 확장 후보

- 사용자: 이전보다 긴장감과 선택의 재미가 확실히 좋아졌으며, 탄종이 다양해지면 패 선택 재미가 더 강해질 것으로 기대.
- 반영: [현재 방향](../../direction/current.md)과 tracker에 개편 후 긍정적 체감 기록. LIFO 수정 당시의 부정적 평가와 패/순환/잔열 개편 후 평가를 구분했다.
- 검토: 기존 탄환 역할을 확인하고 [다음 패 준비·적 행동 대응·기존 연계 분기](../../direction/decision-value.md#후속-탄환-확장-검토)를 후속 후보로 기록했다. 신규4~6종은 디렉터 제안이며 이름/효과/수치 미확정, 미구현.
- 범위: 문서만 변경. 게임 규칙·APK·실제 저장·커밋·푸시 변경 없음. 사용자 체감을 전 무기 밸런스/장기 다양성/기기 성능 검증으로 확대하지 않았다.

## 탄창·파츠·총기 연동 구현

- 사용자: 소규모 탄종 확장을 승인하고 탄창 크기·파츠·총기의 연결을 강조했다.
- 기획/구현: [빌드 연결](../../direction/build-synergy.md). 예약·차단·확산·연계4탄과 냉각 약실·연쇄 방열기·예약 급탄기3파츠를 추가했다. 현재 전술 보급18종, 수집 파츠26종. 시작 덱/기존 총기 기본값/패 순환/잔열/LIFO를 보존한다.
- 전투: 소유 탄 이동에 의한 다음 패 예약, 적마다 한 번의 특수 행동 정지, 기존 화상의 이동, 앞선 서로 다른 탄종의 결산. 작은 탄창의 재장전 냉각 강화와 세 번째 탄의 냉각을 실제 슬롯·열·시간 비용으로 연결했다.
- 화면: 도트 카드/파츠 실루엣, 실제 무기·파츠 수치 설명, 발사 예측/결과, 예약 이름 유지, 상점/장비의 탄창·손패·재장전 냉각 비교. 캡처 검토에서 숨겨진 예약 문구를 발견해 실제 선택란으로 옮기고 가시성 검사도 추가했다.
- 저장: v12. v11 이하 배열/RNG/열 보존, 예약 소유권/장수와 적 차단 타이머 검증. 영구 압축 예약을 유지하고 현장 압축/회수탄의 예약을 제외한다.
- 검증: 신규 규칙6,562/0, UI399/0, 2,520통제 사례19,216/0. 기존 탄환45,961/0·패/잔열827/0·열 빌드3,020/0·열 결과263/0·성장4,949/0·무기3,665/0. 새 전체35층 등반27,075/0, 5총기×2경로·4,394명령 저장/복원. 최종 소스의 동일 명령 재생30,779/0으로10경로 상태·전투 이력 일치. [검증과 실제 화면](../../qa/reports/build_synergy_2026-10-05.md).
- 한계: 통제 장전은 사람의 승률·장기 선택 다양성이 아니다. 예약 반복, 작은 탄창의 가치, 다섯 파츠 편중과 실제 Galaxy 검증은 후속이다. 기존 사용자 작업과 저장을 보존했고 APK/커밋/푸시는 수행하지 않았다.

## 주인공·압력두꺼비 도트 이질감 검토

- 사용자: 주인공의 진하고 선명한 도트가 특히 개구리 몬스터와 이질감이 크다고 피드백했다.
- 확인: 직전 실제 본편 캡처 `qa_runtime/build_synergy/ui/interrupted_1008.png`와 현재 렌더 코드를 대조했다. 주인공은 선택된 C+B 이미지, 압력두꺼비는 `redesign/samples/ranged_battle_view.gd`의 시험용 사각형 도형이다. 공통 nearest 필터만으로 묘사 밀도와 명암 차이가 해소되지는 않는다.
- 판단: 주인공 디자인/크기를 기준으로 개구리의 픽셀 덩어리·선택적 외곽선·명암을 맞추는 것이 우선이다. 낮은 몸·넓은 발·부푸는 목주머니와 공격 예고의 판독성을 유지한다. 다른 임시 적도 이후 같은 통합 화면에서 비교해야 한다.
- 범위: 검토와 기록만 수행. 새 이미지 생성/적용, 게임 코드·저장 변경, APK 생성은 하지 않았다.

## 배경을 포함한 주인공 도트 기준 재검토

- 사용자: 배경 도트 분위기를 함께 보면 주인공도 조금 더 뭉개져야 한다고 제안했다.
- 확인: 주인공/배경 원본과 실제1008×630 본편 캡처, 캐릭터 표시 배율을 다시 비교했다. 배경의 넓은 면에 비해 작은 크기의 주인공은 내부 경계와 명암 대비가 촘촘하게 보인다.
- 판단 수정: 현재 주인공 묘사를 고정해 몬스터만 맞추는 순서에서, 주인공+배경의 공통 표현을 먼저 비교하는 순서로 전환한다. 디자인/표시 크기는 유지하며 큰 색면, 줄인 잔디테일, 절제된 외곽 대비를 제안한다. 실루엣과 무기/모자 구분은 유지한다.
- 범위: 기획/진행 기록만 갱신했다. 새 이미지 생성이나 실제 화면 교체는 하지 않았으며 문서 수정만 검증한다.


## 주인공·적 도트 표현 통합 적용

- 사용자: 위 방향으로 실제 작업을 승인했다. 선택한 캐릭터 디자인/크기를 유지하며 주인공 묘사를 배경에 맞게 정리했다.
- 제작: 내장 image_gen으로 주인공·두꺼비 2상태·기존 적 6종 PNG를 제작했다. 생성 원본 SHA-256과 복사본8개를 대조했고 전체 프롬프트와 출처를 자산 폴더에 보존했다. Python으로 PNG를 편집하지 않았다.
- 통합: 주인공은 기존 자세·발/총구 앵커·0.65 배율 유지. 두꺼비는 실제 준비 카운트와 목 팽창을 연결했다. 기존 적은 개별 AtlasTexture 영역과 표시 크기, 기존 발/부유 높이·피격 이동을 사용한다. 증원 아이콘도 같은 그림이다. 전투/저장 수치는 변경하지 않았다.
- 검증: 교체 전 실제 캡처125/0, 최종 본편3해상도·전체7종·준비/발사/요격/차단350/0. 화면/명찰/적 중심 선택과 상태 정합성을 확인했다. 기존 ranged_ui_runner는 폐기된 reload_heat 참조로 중단됐으며 이번 통과 수에 넣지 않는다. 현행 본편의 원거리 흐름은 새 검사로 확인했다.
- 증거: [변경 전후·실제 화면·로그·한계](../../qa/reports/actor_cohesion_2026-10-05.md). 새로운 스타일의 사람 확인, 프레임 애니메이션, 세계관 생물 재설계, 지역별 배경과 Android 성능은 후속이다. 사용자 저장/기존 미커밋 작업을 보존했고 APK/커밋/푸시는 하지 않았다.

- 변경: 방향·진행·제작/검증 문서의 확인 상태를 갱신했다. 게임 코드와 PNG는 유지했고 게임 검사는 재실행하지 않았다. JSON 파싱 및 diff 검사를 수행했다.


## 세계관에 맞춘 몬스터 컨셉/설정 재정비

- 사용자: 동작 확대 전에 현재 세계관에 맞는 몬스터 컨셉과 설정 재검토를 요청했다.
- 진단: 기존6기계형+압력두꺼비의 정체/이름과 기상탑 생물 설정 사이에 간극이 있었다. 기존 몬스터 문서에는 이미 생물 후보가 있었지만 원거리 격리 실험 시점의 상태와 실제 구현 설명이 섞여 있었다.
- 정비: 자생·사육·관리 장치의 관계를 기준으로 기본7종을 정리했다. 배관쥐/철각충/집수도롱뇽/압력두꺼비와 호출 정비기/차폐 운반기/개폐 준설기 각각에 과거 역할·폭주 후 행동·상태 실루엣·전투 선택·사람의 흔적을 연결했다. 개별 내용은 디렉터 제작안이다. [현행 설정](../../direction/monster-roster.md).
- 우선순위: 아직 기계형인3생물의 정지 컨셉 →3관리 장치의 실루엣/접지 →자산·표시명·구 저장 이름 검토/통합 →종별 동작. 승인된 주인공 그림체는 유지한다. 중앙 격리 관리자 보스 후보는 복구 목표와 충돌하지 않도록 정리했고 기존 관문 패턴과 별도로 명시했다.
- 문서: 세계관의 짧은 작업복/전체 미적용 문구를 현재 승인/구현 상태로 바로잡고 방향·아트·간접 서사·tracker를 연결했다. [이전 v0.2 목록](../design/monster-roster-v0.2-2026-10-05.md)은 원문과 원본 해시를 남기고 상대 링크만 다시 맞췄다.
- 검증:7역할 매핑과 실제 ENEMY_NAMES 키 일치, 수정 문서의 로컬 링크 검사 및 diff 검사 통과. 문서 작업이므로 게임 검사를 재실행하지 않았다. 코드/PNG/인게임 이름/저장/편성/밸런스와 APK/커밋/푸시는 변경하지 않았다.

## 최신 Galaxy 테스트 빌드 전달

- 사용자 요청으로 현재 v12 작업 트리의 APK를 빌드하고 기존 Drive 폴더에 ZIP을 업로드했다. 배우 v2·주인공4키포즈·거리 배치 수정과 탄창/총기/파츠 확장을 포함한다. 몬스터 설정 재정비는 기획만 포함하며 게임 구현은 유지한다.
- 첫 ZIP은 연결 도구의 100MiB 제한에 걸렸다. 참조 없는 배우 v1 시안만 export에서 제외하고 원본과 현재 자산, ARM32/64 지원을 보존했다. 크기 검사와 회귀 검사1개를 전달 도구에 추가했고 전체7개 통과.
- 최종 버전0.5.20261005.232901/code20261007. APK 서명·정렬·리소스 CRC·추출 컴파일 모델/메인 씬 검사를 통과했다. 현행 텍스처9개 포함, Drive 메타데이터 및 재다운로드 SHA-256 일치를 확인했다. [다운로드·검증·한계](../../qa/reports/mobile_delivery_2026-10-05.md).
- 최신 전달 포인터와 설치/확인 안내를 갱신했다. Android 실기기 실행은 별도이며 게임 규칙/저장 변경과 커밋/푸시는 하지 않았다.
