# 2026-10-10

## 발사 순서 패널 정렬 교정

상단 배경 띠를 헤더 실측 영역에 맞추고, 과열 경고의 숨은 공간을 주 행동 버튼 중앙 정렬에서 분리했다. 탄환 판과 장전 확정/발사 버튼의 상하 기준선을 맞췄다. [원인·검증·화면](../../qa/reports/combat_alignment_2026-10-10.md).

## 후속 발열 표시 — 장전 예상치를 큰 숫자에 통합

사용자가 장전 단계의 카운터 표시를 의도했음을 설명하고 0/12 화면을 제공했다. 주 수치를 `현재 → 예상 최고 / 한계`로 변경해 탄환 추가·회수·재배치 때 즉시 판독하도록 했다. 계산/저장 규칙 변경 없음. 격리 UI410검사 통과, 3해상도 캡처 및 작은 화면/기본 화면 시각 검수. [후속 근거](../../qa/reports/heat_live_2026-10-10.md).

## 발열 0 표시 제보 조사

5종 무기 및 정상 저장 복사본을 격리 재생했다. 실제 열과 명중 후 UI 값은 일치했으며 저장된 조합은 최고 13 이후 강제 냉각으로 0이 되었다. 발사 이벤트의 HUD 연결 누락을 수정하고 강제 냉각 후 최고치→현재치 기록을 남겼다. 지속적인 0 고정은 미재현으로 구분한다. [재현·변경·검증](../../qa/reports/heat_live_2026-10-10.md). 사용자 저장과 계산 규칙 변경, APK, 커밋/푸시 없음.

## 공통 UI 사용자 채택 · 후속 디테일

사용자가 직전 UI에 긍정 평가를 주고 카드/패널/버튼 참조를 추가했다. 현행 디자인을 유지하면서 카드의 이음과 이름 띠, 장전 판 안착부, 버튼 어깨/받침/눌림의 세부를 보완했다. pressed에서 글자/기호가2px 내려가며 상하 여백 합계는 유지한다. [참조와 적용](../../art/style-reference/detail-ui-study.md) · [검증](../../qa/reports/console_detail_2026-10-10.md). 신규 미감 확인은 후속.

## 사용자 참조 기반 공통 도트 UI 구현

카드의 세 정보 면, 삽입 홈, 장전 판, 계기, 행동 키를 공용 SVG/tres 자원으로 제작해 전투에 통합했다. 가방/상점 탄환과 파츠, 메인/무기/맵의 공통 조작부까지 연결했다. 규칙·주 배치·사용자 그림을 보존했다. 격리 기능 검사와 실제 화면 검수, 중단한 구형 undo 테스트의 한계를 [보고서](../../qa/reports/console_ui_2026-10-10.md)에 남긴다. 사용자 미감/Galaxy 체감은 후속이며 APK/커밋/푸시 없음.

## Pinterest 추가 UI 참조

사용자 제공 보드의 공개 썸네일 3종을 직접 확인했다. 빈 슬롯/물건/선택의 대비와 장비·상세·행동의 구획을 가방/파츠 표현 후보로 기록했다. 로그인 안내와 작은 미리보기로 인한 검토 한계를 구분했다. [참조 기록](../../art/style-reference/pinterest-ui-study.md). 문서만 변경했다.

## CraftPix UI 참고 조사

사용자 제공 사이트에서 Cyberpunk, TDS Modern, Basic RPG의 실제 공개 미리보기를 열어 현재 전투 화면과 비교했다. 공통 단면/홈/깊이, 역할별 부품 형태, 읽는 면의 절제 등을 다음 제작 후보로 정리했다. [검토 기록](../../art/style-reference/craftpix-ui-study.md). 현행 정보 위계 유지, 철회 외피 복원 금지와 미구현/미확정 상태를 명시했다. 문서만 변경했으며 자산 다운로드·게임 변경·새 런타임 테스트는 없다.

## 전투 도트 UI 조작 단서

사용자가 기존 도트 UI 유지·조작/피드백 통합을 요청하고 Interface In Game 참고 사이트를 제공했다. The Final Station 배터리 화면의 자원/사용 관계를 검토하고, 탄창 삽입 모서리·재장전 냉각 미리보기·비활성 카드 이유·실제 탄 수·역할별 버튼 반응색·재장전 턴 분절을 구현했다. 주요 탄창/손패 배치는 .tscn으로 옮기고 실행 전 구성 예시를 추가했다.

새 조작 340검사/0실패와 실제3해상도 캡처. 피해 피드백489검사/0실패. 최종 연출 회귀와 시각 확인 근거는 [QA 보고서](../../qa/reports/combat_affordance_2026-10-10.md)에 남긴다. 모델/저장/규칙 변경 없음, 격리 저장 사용. Galaxy와 사람의 이해도는 후속, APK/커밋/푸시 없음.

반복 굵은 윗선/계단 모서리를 줄이고 카드 판형·탄창 홈·주 행동 눌림면·조용한 보조 버튼으로 분리했다. 청록 채도와 내부 선을 낮추고 손패는 탁한 회녹색으로 구분한다. 코드로 그리는 공통 프레임만 수정했으며 모델/배치/입력/배우/배경은 유지한다. 관련 기존 UI340검사/0실패, 세 비율 실제 렌더와 이전/수정 비교. [제작·검증](../../qa/reports/combat_visual_polish_2026-10-10.md). 미감·Galaxy 체감은 사용자 확인 전이다.
