# 적 일렬 배치와 배경 변경의 장기 비용 검토

후속 상태: 이 문서는 실행 승인 전의 비교 판단이다. 같은 날 사용자 승인 후 일렬 복원과 거리 표시 교정을 구현했다. [후속 결과·화면·남은 확인](../../qa/reports/enemy_grounding_2026-10-29.md).

## 사용자 피드백과 상태

사용자는10월28일 적 이동·겹침 개편을 플레이한 뒤, 몬스터가 이전처럼 일렬로 있어야 할 것 같으며 현재 배경과 앞뒤 배치가 어색하다고 보고했다. 배경 변경과 일렬 복원 중 장기적으로 효율적인 방향을 판단해 달라고 요청했다.

이는 사람의 실제 시각 평가다. 이전 기능 검사7,542건 통과와 구분하며, 전장 접지·공간 일관성 항목을 다시 연다. 이번 작업은 **검토와 방향 권고**이며 실행 코드·아트는 변경하지 않았다. 사용자 최종 선택이나 구현 완료로 기록하지 않는다.

## 관찰한 원인

- 배경 렌더러는 각 그림의 `floor_y`를 주인공 발 높이에 맞추고 그 아래2px에 통로 경계선을 그린다. 지역별 그림은 달라도 공통으로 하나의 바닥 기준을 사용한다.
- 새 적 배치는 `ground_y()-16+lane*16`으로 발 높이를 달리한다. 네 개체의 발 기준점이48논리px 범위로 벌어지고 주인공 기준으로는−24~+24px 차이가 난다. 배경의 통로·난간에는 이에 대응하는 앞뒤 바닥면이 없다.
- [정원](../../qa/reports/assets/enemy_readability_2026-10-28/region_2_imminent.png)과 [친위대](../../qa/reports/assets/enemy_readability_2026-10-28/region_4_imminent.png)의 기존 실제 캡처에서도 서로 다른 높이에 놓인 발과 바닥선 불일치를 확인했다. [이전 일렬 화면](../../qa/reports/assets/build_feedback_2026-10-28/volley_1008_result.png)은 공통 바닥에 발이 맞는다. 서로 다른 전투 상태의 자료이므로 동일 편성 A/B 검증으로 취급하지 않는다.
- 현재 핵심 선택은 탄환·순서·빌드와 시간을 쓰는 비용이다. 앞뒤 위치 선택이나 레인별 공격 규칙은 없다. 깊이를 추가해 얻는 기능적 가치는 현재 제한적이다.

## 두 방향 비교

| 항목 | 일렬·공통 바닥선 복원 | 깊이 배치에 맞춘 배경 변경 |
| --- | --- | --- |
| 기존 자산 | 현재 배경과 배우의 측면 표현을 활용 | 공통 바닥 레이어 보강부터 가능하지만 그림 속 통로·난간과 원근을 함께 확인해야 함 |
| 변경 범위 | 공통 접지 기준, 과도한 겹침, 정보·선택 대응 | 바닥 폭/원근·그림자·가림·발 접점, 필요시 크기 차이/배경 자산 수정 |
| 새 지역·적 추가 시 | 같은 발 기준에 맞춰 검수 | 앞뒤 위치별 접지·가림 조합도 계속 검수 |
| 현재 전투의 이득 | 측면 전투와 실제 접근 방향이 일치 | 시각적 공간감은 늘지만 현재 규칙상 별도 전술 선택은 없음 |
| 주요 위험 | 같은 거리에서 몸체가 지나치게 숨을 수 있음 | 배경만 넓혀도 배우/그림자/난간과 공간이 계속 어긋날 수 있음 |

배경 변경에15장을 무조건 새로 제작해야 하는 것은 아니다. 다만 현재5지역×3진행 단계의 바닥 정합성과 여러 화면 비율을 모두 검수해야 한다. 작업량·유지보수 범위에 근거한 판단이며, 두 방식의 모바일 성능 차이를 실측한 결과는 아니다.

## 디렉터 권고

**현재 배경을 유지하고 몬스터의 발을 같은 바닥선에 놓는 일렬 배치를 기본으로 복원한다.** 위치 밀림을 고친 가로 거리 계산과 HP/위협/상세 개선은 유지한다. 이전 코드 전체를 되돌리는 방식은 권하지 않는다.

접지 복원만으로 같은 거리의 네 적이나 큰 보스와 호위가 읽히는 것은 아니다. 과도한 가림은 같은 바닥선 안에서의 표시 간격·겹침 한도·선택 강조를 비교하고, 이웃의 처치/증원으로 전체가 이동하거나 실제 최근접 순서를 오해하게 만드는지 함께 확인해야 한다. 이 세부 배치 방식은 아직 검증·확정하지 않았다.

후속 검증은 같은 편성의 현재/일렬 화면,5지역×3단계 배경, 같은 거리 네 적, 대형 보스+호위, 밀기·추월·처치·증원과 작은 화면의 HP/터치를 포함한다. 이번 교정을 발열 비교보다 앞에 둔다. 앞으로 앞뒤 위치 자체를 플레이어가 선택하는 규칙을 도입한다면 그때 전장·배경을 함께 재설계하는 판단을 다시 한다.
