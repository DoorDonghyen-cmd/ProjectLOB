# 2026-10-28 플레이 피드백 접수·우선순위 재검토

## 근거와 상태

사용자는 **어제(2026-10-27) 최신 작업 빌드**로 플레이했다고 밝혔다. 추가 질문에 **후반 프레임 저하는 모바일에서 느꼈다**고 답했다. 모바일 기기 발열도 함께 보고했다. 이를 이전 작업 이전의 후기라고 취급하지 않는다. 실행한 바이너리의 해시·정확한 기기/세션 길이는 이번에 확인하지 않았다.

이번 작업은 피드백 보존, 현행 코드/이전 검증 대조, 개선안과 우선순위 정리다. 게임 코드·수치·저장·APK는 변경하지 않았고 신규 성능 계측이나 시각 재현 검사를 수행하지 않았다. 사용자 관찰, 원하는 개선, 대안 아이디어, 디렉터 검토안을 구분한다. 특히 탄환 불량/총기 고장과 발열 대체는 **검토 요청이며 채택된 규칙이 아니다**. 기존 순차 개편의 미완료 작업은 유지하되 아래 순서로 재정렬한다.

## 전달된 내용

1. 관문에서 재정비할 수 있어야 할 것 같다.
2. 탄환 발열 수치를 높이거나 총기의 기본 발열 관련 수치를 낮추는 안을 고려한다.
3. 뒤로 갈수록 프레임 드랍이 발생하고 모바일에서 기기 발열이 높아진다. 후반 프레임 저하도 모바일에서 관찰했다.
4. 몬스터 거리 표시는 없어도 될 것 같다.
5. 탄환 배율/피해를 높여야 하는 재미가 아직 잘 느껴지지 않는다.
6. 파츠 장착 효과가 발생하는 것은 알지만 시각적 체감이 약하다.
7. 발열 상승 조건을 연속 사격 시 더 많이 오르는 방식으로 바꿀 수 있다.
8. 발열 대신 탄환 불량을 고려한다. 탄마다 불량률을 두고 고장이 나면 사격 중단·재장전, 해당 탄은 현재 라운드에서 소실한다. 좋은 탄은 불량률이 낮다.
9. 위 아이디어를 총기 고장으로 옮겨, 연속 사격이나 고성능 탄 사용으로 고장 빈도가 높아지는 안도 고려한다.
10. 장비 선택 화면의 캐릭터가 지면에서 조금 떠 보이므로 위치를 낮춰야 한다.

‘총기 기본 발열 수치를 낮추기’는 과열을 더 쉽게 만드는 **열 한계 감소**를 우선 비교 대상으로 해석한다. 표현 자체를 확정된 수치/파라미터 요구로 바꾸지 않는다. ‘현재 라운드에서 소실’의 정확한 수명도 설계 시 명시해야 하며, 현재는 해당 교전 동안 사용 불가라는 비교안으로 다룬다.

## 발열과 고장 — 비교할 세 안

| 안 | 플레이어의 선택 | 확인할 문제 |
| --- | --- | --- |
| A. 현행 발열의 수치 조정 | 동일 규칙에서 탄 발열 증가 또는 무기 열 한계 감소 | 냉각/짧은 사격의 가치가 생기는지, 저위력 빌드가 더 답답해지거나 고열 코어가 오히려 과도하게 이득을 보는지 |
| B. 연속 사격에 따른 누적 부담 | 후속 공격일수록 부담 증가, 다음 탄의 임계 도달을 사전 표시, 냉각/재정비로 완화 | 짧게 끊기/냉각 삽입/위험을 감수한 마무리가 유효한지. 버튼 클릭 횟수가 아닌 실제 발사 상태로 계산해 입력 분할로 회피하지 못하게 한다. 단발/연쇄/다회 타격의 차이를 비교한다. |
| C. 탄환 불량 또는 총기 고장 | 안정적인 탄/장비 선택 또는 위험을 감수한 사격 | 확률 때문에 준비한 조합이 이유 없이 취소된다고 느끼는지, 저품질 탄만 가진 초반이 지나치게 불리한지. 고성능 탄의 사용을 피하도록 만드는 정도도 비교한다. |

**우선 비교 추천은 B**다. 강하게 오래 쏠수록 위험해지는 관계를 예측 가능하게 시험할 수 있다. 발열을 유지할지 총기 부담/고장으로 대체할지는 비교 후 판단한다. 열 게이지에 추가 고장 게이지와 탄별 불량 수치를 모두 붙이는 안을 기본값으로 삼지 않는다.

확률 고장을 시험한다면 위험과 결과 범위를 먼저 공개하고, 불량 탄1발의 처리와 나머지 미발사 탄의 처리, 재장전 비용을 분리해서 정한다. 사용자가 제안한 것은 해당 불량 탄의 소실이며 탄창 전체 파괴를 요구한 것이 아니다. 초기 비교안은 나머지 탄의 보존을 우선하고, 현재 전체 재장전 배출 규칙과의 차이를 명확히 설명한다. 같은 저장/예측을 반복해서 숨은 판정을 새로 뽑지 않아야 하며, 예측은 확률을 확정 결과로 표시해서는 안 된다.

‘고급탄의 낮은 불량률’과 ‘고출력탄의 큰 총기 부담’은 서로 다른 축이다. 품질을 높일 이유를 주면서 화력을 높이는 행위를 과도하게 벌하지 않도록 비교한다. 별도 품질/불량률을 실제 카드 데이터에 추가하는 것은 아직 결정하지 않았다.

## 재정렬한 순서

아래는 최신 후기 접수 시의 1차 정리다. 이후 사용자 요청으로 어제 구현·미완료 항목까지 합친 [통합 우선순위](../../direction/playtest-priorities.md)를 현행 작업 순서로 정했다. 장갑·정예/보스 대응, 전체 등반의 탄약 경제와 후순위 후보도 해당 문서에서 함께 추적한다.

1. **모바일 성능·기기 발열 원인 확인과 개선.** 장비 화면 접지는 독립적인 작은 수정으로 함께 처리 가능하다. 자동 PC 검사만으로 모바일 해결을 선언하지 않는다.
2. **관문 재정비와 출발 단계.** 기존 관문 씬 연출보다 플레이 기능을 먼저 연결한다.
3. **화력 강화의 결과와 파츠 발동 체감.** 전투 결과 차이와 연출을 함께 비교하고, 성능이 안정된 범위 내에서 적용한다.
4. **적 이동·위협 전달과 상시 거리 숫자 정리.** 원래 다음 작업을 오늘의 숫자 축소 의견에 맞춰 수정한다.
5. **연속 사격 부담/고장 시안 비교.** A/B/C의 효과와 비용을 같은 무기·적·획득 예산에서 비교한다. C를 채택된 설계로 앞당기지 않는다.

이미 적용한 획득/휴대 개편과 비상 보급을 되돌리지 않는다. 파츠 슬롯 확대·일회용 특수탄·관문 연출 씬 등 이전 미완료 후보는 위 작업 이후의 검토 항목으로 남긴다. 이번에는 기획과 우선순위만 갱신했으며 테스트 통과나 성능 개선 실적을 새로 주장하지 않는다.
