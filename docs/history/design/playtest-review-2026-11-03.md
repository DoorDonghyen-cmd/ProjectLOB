# 2026-11-03 핵심 탄 적용 후 플레이 피드백 검토

**후속 실행:** 사용자 지시로 [규칙](../../direction/combat-roles-growth.md)과 [검증/화면](../../qa/reports/playtest_rework_2026-11-03.md)을 본편에 연결했다. 아래는 접수 당시 검토이며 미구현/미수정 상태는 후속 실행 기록으로 갱신한다.

상태: 사용자 후기 접수와 현재 소스 대조 완료. 이번 작업에서는 게임 코드·수치·저장을 변경하지 않았다. 사용자 플레이 빌드·시드·기종·총기/코어 조합은 특정되지 않았다. 아래 코드 확인은 사용자가 겪은 화면 오류를 직접 재현한 결과가 아니다.

## 유지할 경험과 확인 경계

- **사용자 평가:** 현재 전투는 재미가 느껴지고 긴장감도 높다. 파츠와 코어를 재구성하면 더 발전할 가능성이 있다.
- **사용자 문제:** 히트 위치 불일치, 불편한 드래그 감도와 선택/발사 탄수 불일치, 전투를 계속 피할 수 있는 지도, 증폭·배율·연타 위주의 선택, 과도한 처치 후 전이.
- **사용자 제안:** 전이는 기본 추가 대상 1기부터 업그레이드, 소이탄의 약 2턴 지역 피해, 경직탄의 접근 감속, 복장별 덱 최소/최대와 정비 확장, 성장에 따른 열 부담 감소와 발사량 증가.
- **디렉터 판단:** 현재 접근 압박·선택 사격·핵심 탄의 큰 피해를 유지한다. 표시/입력 신뢰성 → 지도 밀도/성장 기회 → 전이·탄종·코어/파츠 역할 → 복장/발사량 성장 순으로 검증한다. 모든 탄을 의무적으로 쓰게 하거나 강한 덱의 반복 사격 승리를 금지하는 것이 목표는 아니다.
- **미확정:** 지역 피해의 범위·중첩·2턴 기준, 감속률/기간, 전이 성장 단계, 복장별 최소/최대, 발수/발열 성장 수치는 비교 후보이며 아직 적용되지 않았다.

## 질문에 대한 현재 구현 확인

### 최대 3발은 발열 때문인가

`magazine_trial.gd:39`에 총기별 별도 사격 상한이 있다. 발열은 이 상한과 별개로 사격을 더 일찍 중단시킬 수 있다.

| 총기 | 현행 한 번 사격의 상한/조건 |
|---|---|
| 리벳 | 최대 2장 |
| 래칫·스플린터 | 최대 3장 |
| 리액터 | 기본 3장, 강행 조건과 선택 범위가 허용하면 추가 1장 |
| 스파이크 | 처치 연속 조건으로 이어지며 생존 표적·열·잔탄·선택 범위에 의해 중단 |

따라서 열만 낮춰도 고정 발수 상한은 늘지 않는다. 성장 비교에서는 **허용 발수 증가**와 **그 발수를 감당하는 열 효율**을 구별한다. 총기 고유 조건과 적 행동 비용을 보존하면서, 파츠/정비 투자로 더 긴 사격을 선택할 수 있는지 평가한다. 전 총기에 무제한 연사나 동일한 열 감소를 일괄 적용하지 않는다. 고열을 이득으로 바꾸는 코어의 선택 가치도 함께 확인한다.

### 탄약은 무제한으로 모을 수 있는가

현재 새 등반에는 이미 `ammo_reserve.gd:25`의 복장별 휴대 상한이 있다. 정찰 28, 작업복 30, 운반 32, 방열 34, 인양 36, 회수 38, 원정 40발이며 정비 확장당 +2, 최종 상한은 40이다. 상한에 도달하면 새 탄 획득은 교체가 필요하다. 최소 덱은 `Campaign.MIN_DECK=8`로 공통이다.

다만 정비 가능 조건과 최대 안내는 `campaign.gd:472`에서 예전 손패 용량/구역 한도를 여전히 참조한다. 탄창 전투의 복장별 수납 성장으로 설명·조건을 재정리할 대상이다. 현재 상한이 사용자에게 체감되지 않는 이유가 표시인지, 도달 전 플레이인지, 다른 빌드인지까지 확인한 것은 아니다.

복장별 최소/최대 제안은 **작은 덱의 주력 탄 집중도와 큰 덱의 전투 지속력**을 비교하는 방향으로 검토한다. 최소는 덱 편집/제거 한도이며 전투 중 잔탄이 줄었다고 무료 탄을 채워 주는 의미가 아니다. 상한 확장은 탄 지급·탄창 크기·사격 발수 증가와 구분해 안내한다. 구체 수치는 지도 밀도와 실제 획득/소모를 확인한 뒤 정한다.

## 탄환·코어·파츠 재검토 방향

현재 집중 보상은 시작 후보가 연타/관통/방열이고, 그 지원 후보도 증폭/배율/냉각에 집중되어 있다(`focus_build.gd`). 증폭은 연타의 각 타격에 적용된다. `model.gd:1017`의 처치 후 남은 타격/초과 피해 전이는 별도의 추가 대상 수 상한 없이 남은 자원이 끝날 때까지 진행한다. 강한 한 표적 조합이 여러 적 처리도 해결할 수 있고, 획득 정책 역시 해당 조합을 자주 노출한다. **선호 편중은 약한 탄의 수치만으로 설명할 수 없으며, 보상 구성과 전이 범위를 함께 검토해야 한다.**

| 역할 | 우선 비교할 변화 | 평가할 선택 |
|---|---|---|
| 핵심 탄의 큰 피해 | 증폭·배율·연타의 주력 성격과 위치 파츠를 유지 | 보스/고체력 적에게 투자한 조합의 보상이 남는가 |
| 처치 후 전이 | 기본은 **주 대상 외 추가 1기**, 이후 코어/파츠 투자로 추가 대상 증가 | 한 표적 화력과 여러 적 처리의 성장 선택이 구분되는가. 잔여 타격이 같은 대상에 여러 번 닿아도 대상 수를 중복 계산하지 않는다. |
| 소이탄 | 현재는 표적에 붙는 화상. 착발 지점에 일정 구간의 불길을 남기는 후보를 별도 비교 | 현재 일렬 접근로에서 여러 적/후속 접근 적에게 누적 피해를 줄 수 있는가. 약 2턴은 우선 **적 행동 2회**로 정의해 재장전/냉각에도 일관되게 예고한다. 범위·중첩·갱신과 마지막 적/탄약 소진 처리를 함께 정한다. |

| 코어·파츠 | 발사 위치 배율, 전이 대상 성장, 지속 피해, 접근 제어, 열 효율을 서로 다른 투자 방향으로 배치 | 코어를 고르면 강화할 탄/행동이 달라지는가. 세 번째 발 강화 같은 이해 가능한 조건과 실제 대상 반응으로 성장을 보여 주는가 |
| 보상/상점 | 선택한 주력의 복사/강화는 유지하면서 화상·제어 계열의 시작/지원 경로도 검토 | 단순히 탄종 수가 늘지 않고 실제로 다른 덱을 완성할 기회가 생기는가 |

전이 1기 제안은 처치 후 잔여 타격/초과 피해를 우선 대상으로 한다. 모든 광역탄·열 충격파까지 같은 규칙으로 일괄 제한하거나 전이 횟수·반경·대상 수를 같은 개념으로 취급하지 않는다. 코어/파츠별 적용 범위는 실제 전투 비교에서 결정한다. 모든 빌드에 소이탄/제어탄을 필수로 넣게 만드는 것도 목표가 아니다.

## 다음 작업과 검증

1. 히트 기준점·드래그 경계·선택/발사 표시를 같은 조건에서 재현하고 수정한다. 계산/저장 결과와 표시를 대조하며 실제 모바일 입력 체감은 별도 기록한다.
2. 지도 생성의 모든 경로를 검사해 연속 회피를 제한한다. 시설/샛길/구역별 다양성과 기존 지도 저장을 보존하고 최신 덱의 보상·소모를 확인한다.
3. 추가 1기 전이와 서로 다른 역할의 대표 탄을 소수로 비교한다. 같은 획득 덱/편성에서 단일 위협·무리·재장전 압박의 결과와 성장 체감을 확인한 뒤 코어/파츠/획득 정책을 연결한다.
4. 복장별 최소/최대·정비 확장과 발수/열 효율 성장을 앞 단계의 경제에 맞춘다. 유한 탄약·강제 냉각·접촉 패배·예측·이전 저장을 포함해 전체 등반 검증을 진행한다.

이번에는 문서와 우선순위만 갱신했다. 신규 런타임 검사·화면 캡처·Android 재현·전체 등반 검사는 수행하지 않았다. 이전 검사 통과를 이 피드백의 수정/검증 완료로 사용하지 않는다. 복장 애니메이션 혼합, Android 배율/복귀·지속 성능은 기존 미해결 항목으로 유지하며 APK 제작은 사용자가 진행한다.
