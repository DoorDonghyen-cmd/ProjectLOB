# Phase 12 컨버전 킷 구현 워크스루

> 완료일: 2026-07-26
> 범위: 데이터 · 장착 제한 · 소멸 면제 · 보상 가중 · 무기고 판매 · 회귀 검증

## 결과

권총·기관단총·소총·지정사수·산탄총용 컨버전 킷 5종을 구현했다. 킷은 일반 파츠 슬롯 1칸을 사용하며, 총기의 원래 클래스와 같은 킷 또는 두 번째 킷은 장착할 수 없다. 기존 킷을 다른 클래스 킷으로 교체하는 것은 허용한다.

킷이 지정한 클래스의 탄환은 총기 고유 탄환과 동일하게 헛방 시 영구 소멸에서 보호된다. 승천 8등급 이상의 `no_caliber_safety`에서는 두 보호가 함께 해제된다. 킷 미장착 상태의 `UNIVERSAL` 값은 실제 클래스가 아니므로 범용탄을 잘못 보호하지 않는다.

## 획득과 가격

- 보상 드래프트에서 지정 클래스 탄환 가중치: 기본의 3배
- 획득 경로: 무기고 구매 전용
- 진열: 방문마다 자기 클래스 이외의 킷 1종
- 가격: `80 Cr × conversion_cost`

| 총기군 | 배수 | 가격 |
|---|---:|---:|
| 곡예형 권총 | 0.7 | 56 Cr |
| 도박형 | 0.8 | 64 Cr |
| 전술 리볼버·기관단총·샷건·제압형 | 1.0 | 80 Cr |
| 태세 사냥꾼 | 1.2 | 96 Cr |
| 중장형 소총·정밀 지정사수 | 1.5 | 120 Cr |

스탯 페널티는 적용하지 않았다.

## 주요 구현 지점

- `PartData`: 변환 대상 클래스와 킷 판별 계약
- `GunData` / `gun_stats.csv`: 총기별 `conversion_cost`
- `RunManager`: 장착·교체 제한, 지정 클래스 조회, 소멸 면제, 드래프트 가중치
- `RewardDraftPanel`: 가중 무복원 추첨
- `MaintenanceOverlay`: 적합 킷 1종 진열과 총기별 가격
- `suite_conversion_kit`: 리소스 5종, 가격, 장착 제한, 소멸 면제, 승천 8, 범용 경계 조건, 무기고 진열 회귀
