# 조합탄 전문축 가독성·피해 증폭탄 구현 완료

## 결과

조합탄의 첫 인상을 내부 운용 분류가 아니라 전투에서 실제로 바꾸는 값으로 통일했다.

- 넓은 카드: `[ACC 명중 보정] / [PEN 장갑 파훼] / [DMG 피해 증폭] / [CTRL 거리 제어]`
- 좁은 탄창: `[ACC] / [PEN] / [DMG] / [CTRL]`
- 기본탄: 전술 전문축과 분리해 `[기본탄] 고명중·고관통·고화력` 성향으로 표시
- 카드 효과: `다음 1발 ACC +3`처럼 범위·스탯·수치를 한 줄로 표시
- 내부 `공격/연계/제어` 분류: 일반 카드에서 숨기고 툴팁 마지막 줄로 이동

## 장약 증폭탄

기존 `chain` 리소스의 세이브 호환 ID와 경로는 유지하면서 표시명과 동작을 바꿨다.

| 항목 | 이전 | 현재 |
|---|---|---|
| 표시명 | 연쇄탄 | 장약 증폭탄 |
| 역할 | 공격·결산 | 연계·피해 증폭 |
| 발동 | 직전 유효 적중 | 이 탄의 유효 적중 |
| 효과 | 이 탄 피해 +3 | 다음 1발 DMG +2 |

피해 버프는 다음 격발 순간 소비되며 빗나감·도탄이어도 복구되지 않는다. 유효 적중한
탄에서만 새 버프가 생성되고, 리로드와 새 교전에서 소멸한다. 다음 탄의 명중·관통을
우회하지 않으며 관통한 주 피해에 더한 뒤 결정형 크리티컬 배율을 적용한다.

이로써 다음 1발 연계탄은 다음의 대칭 구조를 갖는다.

- 표식탄: ACC +3
- 천공탄: PEN +3
- 장약 증폭탄: DMG +2

## 확인 방법

메인 화면 개발자 테스트에서 `🎯 탄환 전문축 QA`를 선택하면 기본탄 3종과
ACC/PEN/DMG/CTRL 전술탄, 마무리탄을 한 전투에서 비교할 수 있다.

확인 포인트:

1. 기본탄과 전술탄의 첫 배지가 시각적으로 분리되는지 확인한다.
2. 넓은 보상 카드와 좁은 탄창 슬롯에서 같은 축이 전체/축약 표기로 이어지는지 확인한다.
3. 장약 증폭탄을 먼저 발사한 뒤 다음 탄의 전투 로그에 `DMG +2`가 적용되는지 확인한다.
4. 장약 증폭탄이 도탄하면 다음 탄에 피해 버프가 생기지 않는지 확인한다.

## 자동 검증

- 전체: **3,431 통과 / 0 실패 / 기존 경보 3**
- 9총기×13적, 기본/환기구 234대진: 실패 조합 0
- 포함 범위: CSV↔리소스, DMG 버프 발동·소비·도탄, 미리보기, 카드/가방/탄창/갤러리,
  개발자 QA 숏컷, 전투·런 전체 회귀

Godot의 Windows 루트 인증서 접근 경보로 프로세스 종료 코드는 1이지만, 테스트 러너의
게임 검증 결과는 PASS다. 이 경보 3건은 변경 전부터 존재한 환경 경보다.
