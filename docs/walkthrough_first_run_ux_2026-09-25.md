# 첫 등반 UX 후속 개선 워크스루

## 결과

거시 화면 개편 다음 단계로 상점과 빌드 작업실의 작업 연속성을 보강했다. 플레이어가 구매나 장착 행동 뒤 결과를 찾기 위해 화면을 다시 훑지 않아도 되고, 보관함에서 여러 파츠를 비교할 때 같은 탭에 머문다.

## 구현

- `DeckLoadout.current_tab`으로 현재 작업 탭을 저장한다.
- 파츠 장착·해제 뒤 전체 화면 작업실을 같은 탭으로 다시 연다.
- 작업실 상단 `BuildChangeFeedback`에 적용 결과를 한 줄로 표시한다.
- 상점 상단 `ShopFeedback`에 탄환·파츠 구매, 압축 코어 충전, 리롤 결과를 표시한다.
- 기존 캠페인 로그를 사용해 초기 상점에는 과거 메시지가 잘못 나타나지 않게 했다.

## 검증

- 전체 Godot 자동 테스트: 3,730 / 0 실패.
- 실제 OpenGL UI: 3,686 / 0 실패, 1,181개 버튼 입력.
- 보행자와 쇄도 35층 재생 완료.
- 회귀 계약: 구매 직후 결과 띠 존재, 보관함 장착 변경 뒤 보관함 탭 유지, 작업실 결과 띠 존재.

APK, 커밋, 푸시는 수행하지 않았다. 다음 사람 플레이에서는 신규 플레이어가 첫 상점에서 `구매 → 현재 빌드 확인 → 작업실 교체`를 설명 없이 이어가는지 확인한다.
