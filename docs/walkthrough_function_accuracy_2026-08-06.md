# #013·#014 기능 정확성 수정 워크스루

## 목표

- 기본탄 전투의 효율 등급이 실제 격발 수로 정산되게 한다.
- 상점당 파츠 1개 제한을 리롤로 우회할 수 없게 한다.

## #013 실제 격발 수 정산

- `CombatManager.battle_stats`에 `shots_fired`를 추가했다.
- 탄환이 탄창에서 실제로 발사되는 시점에 증가하므로 기본 보급탄·전술탄·연발을 모두 센다.
- 기존 `lead_bullets_fired`는 전투 중 추가 납탄 및 Tempo 해금 전용으로 유지했다.
- 효율·등급·크레딧 계산을 `CombatOverlayV2.combat_reward_for_stats()`로 분리해 UI와 테스트의 정본을 통일했다.
- 예시: 2처치/5발은 40%, C등급, 기본 10Cr다.

## #014 상점 방문 단위 구매 제한

- `_part_purchased_this_visit`가 상점 진입부터 이탈까지 구매 상태를 보존한다.
- 파츠 구매 후 리롤하면 새 파츠 후보는 정보용으로 표시되지만 `이번 상점 파츠 구매 완료` 상태로 잠긴다.
- 전술탄 구매는 계속 허용한다.
- 구매 콜백도 방문 플래그를 검사해 UI 외 경로의 우회를 막는다.

## 검증

- 신규 `suite_combat_rewards`로 기본탄 격발 수와 S~D 등급 경계를 검증했다.
- `suite_part_shop`에 구매 → 리롤 → 파츠 잠금 및 전술탄 유지 회귀를 추가했다.
- Godot 4.7 전체 자동 검증: **2,734 통과 / 0 실패 / 기존 경보 3**.
- **81개 스크립트 컴파일**, **4개 씬 로드** 성공.
