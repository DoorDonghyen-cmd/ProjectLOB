# 관리·정점 복합 편성 플레이테스트 구현 계획

> 상태: 사용자 승인 후 구현·자동 검증 완료 (수동 체감 비교 대기, 2026-08-15)
> 범위: 관리 계층·정점 일반전 편성의 구조적 압력 검증, 결정론적 회귀, 개발자 QA 진입점

## 1. 목표

- 상층 3~4체 편성이 탄환 순서를 설계할 최소 대응 시간을 보장하는지 실제 전진·차징 규칙으로 검증한다.
- 동일한 강제전진 역할이 중복되어 계산이 아닌 압력만 배가되는 편성을 제거한다.
- 35층을 다시 진행하지 않고 관리 계층과 정점 대표 편성을 즉시 플레이할 수 있게 한다.

## 2. 유지 조건

- 적 HP·DEF·EVA·SPD·시작 거리와 탄환·총기 수치는 변경하지 않는다.
- 관리 계층과 정점의 최대 4체 밀도를 유지한다.
- 정점은 신규 적을 도입하지 않고 기존 상위 자물쇠를 재조합한다.
- LIFO 적재와 거리 통제라는 핵심 전투 규칙을 우회하지 않는다.

## 3. 구현

- `EnemyRoster`에 관리·정점 대표 QA 편성을 정본화한다.
- 상층 모든 후보에서 차저를 최대 1체로 제한한다.
- 실제 `CombatManager` 전진·차징·긴급 격퇴 경로로 무대응 패배 턴을 측정해 4~8행동 압력 범위를 회귀 고정한다.
- 개발자 테스트 메뉴에 관리 계층·정점 편성 QA 버튼을 추가한다.
- QA 전투에는 중립적인 Workhorse와 현행 전술탄 묶음을 제공해 장전 순서만 비교할 수 있게 한다.

## 4. 완료 조건

- 관리·정점의 모든 일반전 후보가 차저 최대 1체를 만족한다.
- 모든 상층 후보가 개입 없이도 즉사하지 않으며, 무대응 시 지나치게 늘어지지 않는다.
- 두 QA 버튼이 실제 대표 4체 편성으로 전투 화면을 연다.
- 전체 Godot 헤드리스 테스트 실패 0을 유지한다.

## 5. 구현 결과

- 정점 초반·중반 후보에서 강제전진 차저가 2체 겹치던 두 편성을 차저 1체 조합으로 교체했다.
- 관리 계층과 정점의 모든 후보를 실제 `CombatManager` 전진·차징·긴급 격퇴 경로로 측정했다. 무대응 패배는 모두 4~8행동 범위에 들어왔다.
- 개발자 테스트 메뉴에 `관리 계층 편성 QA`, `정점 편성 QA`를 추가했다. 둘 다 Workhorse와 같은 전술탄 묶음으로 실제 종반 4체 후보를 연다.
- 적·탄환·총기 수치는 변경하지 않았다.
- 최종 검증: 스크립트 85개 컴파일, 씬 4개 로드, 3,342 통과 / 0 실패 / 기존 경보 3.
