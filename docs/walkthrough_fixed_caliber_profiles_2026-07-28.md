# 표준 규격 3종·전용 규격 2종 및 역할 전환 워크스루

> 날짜: 2026-07-28
> 세션 ID: `codex0728-fixed-caliber`
> 결과: 구현 및 자동 검증 완료

## 적용 결과

- 구경은 이제 런 중 바꾸는 빌드 축이 아니라 총기의 고정 탄도 성향이다.
- 플레이어가 처음부터 비교하는 규격은 경량탄·소총탄·산탄 3종으로 줄였다.
- 중량탄은 Tempo/Gambler, 저격탄은 Marksman 전용 규격으로 분리해 해당 총기를
  해금할 때 함께 학습한다. 내부 전투 데이터 5종은 유지한다.
- 준비실과 탄환 갤러리는 `표준 규격 · 경량탄 (9mm)` /
  `전용 규격 · 저격탄 (7.62mm)` 형식으로
  같은 분류 정본을 표시한다.
- 기반탄 카드도 경량탄·소총탄·산탄·중량탄·저격탄을 우선 표시하고 실제 구경은
  설명문의 기술 규격으로 남긴다.
- 공용 전술탄은 9mm 정밀, .45 화력, 5.56 관통, 7.62 고화력·저명중,
  12게이지 근접 화력·저관통 성향으로 달라진다.
- 기반탄에는 구경 프로필을 중복 적용하지 않는다.
- `.45ACP` 기반탄을 DMG 4로 조정해 9mm보다 낮은 명중을 높은 피해로 교환한다.
- 보상 드래프트는 자기 기반탄 1종과 공용 전술탄 14종만 보여준다.
- 교대탄·인터럽터·만능 약실은 공격/연계/제어 역할 전환을, 리듬 챔버는 동일 역할
  연속 박자를 읽는다.
- 컨버전 킷은 비활성 상태를 유지한다.
- 7.62 보안 게이트는 실제 DMR 고정 프로필만 열며, 5.56 Heavy는 열지 못한다.

- 신규 전용 검증:
  - 5개 고정 프로필 수치
  - 기반탄 비중복
  - 클래스별 드래프트 15종
  - 샷건 넉백 비중복
  - 역할 전환 파츠 3종

기존 경보는 `sentry_drone HP4`, `nano_stalker EVA9`, `nano_stalker HP4`이며 이번
변경으로 새로 생긴 실패나 경보는 없다.

## 다음 플레이테스트

같은 공용 전술탄이 총기에 따라 다른 해법이 되는지 먼저 확인한다.

1. Workhorse에서 표식탄·교란탄의 명중 안정성이 체감되는지
2. Gambler/Tempo에서 공용 공격탄의 피해 우위가 보이는지
3. Suppressor/Heavy에서 낮은 PEN 전술탄도 장갑 대응 선택지가 되는지
4. Marksman에서 높은 화력과 낮은 ACC의 교환이 읽히는지
5. Bruiser에서 장갑·원거리 약점과 근접 화력의 차이가 분명한지
6. 인터럽터/만능 약실은 역할 교대, 리듬 챔버는 역할 유지라는 서로 다른 빌드가 생기는지

여전히 빌드 다양성이 약하면 다음 변경 대상은 구경 수치가 아니라 **파츠 획득 빈도와
보상 선택 구조**다. 첫 구역 안에 일반 파츠가 빌드 방향을 정하고, 이후 보상이 그 방향을
강화하는 구조를 우선 검토한다.
