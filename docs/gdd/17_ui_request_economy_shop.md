## 1. 전투 결과 및 보상 드래프트 (Battle Result & Draft UI)

### ① 핵심 목표
전투의 결과(자원 효율성 평가)를 서늘하게 확인하고, 당장 다음 전투에 투입할 호환 탄약과 미래 투자를 위한 크레딧 중 전술적으로 선택할 수 있도록 설계합니다. 단일 오버레이로 클릭 피로를 예방합니다.

### ② 와이어프레임 (ASCII Layout)
```
+-------------------------------------------------------------+
|                                                             |
|                       [ 전 투 종 료 ]                       |
|                                                             |
|   +-----------------------------------------------------+   |
|   |                  기업 효율 감시 AI                  |   |
|   |                                                     |   |
|   |   탄약 소모율: 82%          배급 등급: A            |   |
|   |                                                     |   |
|   |  "자원 통제 수준 우수. 배급 한도가 임시 증액됨."     |   |
|   +-----------------------------------------------------+   |
|                                                             |
|   +-----------------------------------------------------+   |
|   |                  획득 보상 드래프트                 |   |
|   |  (다음 중 요원의 생존 자원을 '하나만' 배급하십시오)    |   |
|   |                                                     |   |
|   |  [탄환 A (경량탄)]  [탄환 B (소총탄)]  [크레딧 +35]   |   |
|   |  (무료 실탄 보급)    (무료 실탄 보급)    (효율 연동 재화) |   |
|   +-----------------------------------------------------+   |
|                                                             |
+-------------------------------------------------------------+
```

### ③ 정보 위계 및 이식 규칙
1. **평가 패널 (상단)**:
   - 효율 등급(S, A, B, C, D)을 가장 큰 폰트로 출력하여 직관적인 피드백을 줍니다.
   - 기업 감시 시스템의 메시지는 냉소적이고 차가운 텍스트 톤을 채택하여 사이버네틱 감시를 체감하게 만듭니다.
2. **드래프트 패널 (하단)**:
   - 3개의 카드형 버튼을 가로로 정렬합니다.
   - **호환 탄환 카드**: 구경과 패시브 효과 아이콘을 표기합니다.
   - **크레딧 카드**: 획득 액수를 선명하게 출력하며, 평가 등급에 따른 보너스가 가산된 값임을 시각적으로 표기합니다. (예: `+30 (+5 Bonus)`)
   - 선택 시 즉시 정산 오버레이가 닫히며 런 맵(Run Map) 화면으로 전환됩니다.

## 2. 무기고 종합 제어 단말 (Armory Management Terminal UI)

### ① 핵심 목표
플레이어가 무기고 노드 진입 시 장비 정비(스탯/파츠 조율), 가방 인벤토리 관리(소모품 사용, 폐기), 보급 상점(크레딧 구매 및 리롤)의 세 가지 핵심 작업을 상단 탭을 통해 유기적으로 전환하며 수행하게 합니다.

### ② 와이어프레임 (ASCII Layout)
```
+-------------------------------------------------------------+
|  [무기고 단말]                                 보유 크레딧: 75c|
|-------------------------------------------------------------|
|  [ 🛒 상점 (Shop) ]   [ 🛡️ 장비 (Equip) ]   [ 🎒 가방 (Bag) (2/8) ] |
|-------------------------------------------------------------|
|  [탭 1: 장비 선택 시]                                       |
|  +---------------------------+  +-------------------------+  |
|  | DMR-7 Spec Card           |  | 총기 개조 파츠 슬롯 (2)  |  |
|  | - DMG: 10 (+3) [🟩🟩🟩⬛]  |  | [1. 중량 보정기] [해제]  |  |
|  | - KB :  2 (+1) [🟩🟩⬛⬛]  |  | [2. 비어있음]           |  |
|  | - RT : 2.0s (-0.3s)       |  +-------------------------+  |
|  +---------------------------+  | 퀵 정비 (가방 내 파츠)  |  |
|                                 | [가스조절기] [즉시 장착] |  |
|                                 +-------------------------+  |
|-------------------------------------------------------------|
|  [탭 2: 가방 선택 시]                                       |
|  +---------------------------+  +-------------------------+  |
|  | 가방 인벤토리 그리드 (8)  |  | 선택 보급 물자 상세 정보 |  |
|  | [파츠] [탄 Box] [⬛] [⬛]  |  | - 경량 가스 조절기      |  |
|  | [⬛]   [⬛]     [⬛] [⬛]  |  | - 효과: 장전시간 -0.3s  |  |
|  |                           |  | [장착하기]  [물자 버리기]|  |
|  +---------------------------+  +-------------------------+  |
|-------------------------------------------------------------|
|  [탭 3: 상점 선택 시]                                       |
|  +-------------------------------------------------------+  |
|  | [보급품 1: 소총탄]          [보급품 2: 나노 총열]       |  |
|  |  가격: 20c [배급신청]      가격: 45c [배급신청]        |  |
|  |                                                       |  |
|  | [단말기 신호 재요청 (리롤)] (가격: 3c)                  |  |
|  +-------------------------------------------------------+  |
|-------------------------------------------------------------|
|                                                 [정비 완료] |
+-------------------------------------------------------------+
```

### ③ 정보 위계 및 이식 규칙
1. **탭 네비게이션**:
   - 상단에 선명한 물리적/시각적 탭 전환기(Shop, Equip, Bag)를 배치합니다.
   - **[디폴트 진입 규칙]**: 플레이어가 무기고 노드에 최초 진입하여 화면이 열릴 때, 기본 활성 탭은 **`🛒 상점 (Shop)`**이 되어야 합니다.
   - 가방 탭 버튼 우측에 현재 인벤토리 보관 수량을 실시간 표기합니다. (예: `(2/8)`)
2. **🛡️ 장비 (Equip) 탭**:
   - 총기의 스펙 카드와 상세 수치 게이지 바를 좌측에, 장착 슬롯 및 퀵 파츠 장착 인터페이스를 우측에 배치합니다.
   - 파츠 탈착 시 스탯 변화가 녹색 보조 라벨(예: `(+3)`) 및 색상 게이지 바 형태로 즉각 표시되어 정비 효율을 실시간 검증할 수 있어야 합니다.
3. **🎒 가방 (Bag) 탭**:
   - 8칸의 그리드 슬롯으로 가방 인벤토리를 시각화합니다.
   - 그리드 아이템을 클릭하면 우측 상세 정보창에 유형(파츠/탄 상자/소모품), 상세 효과 및 설명이 로드됩니다.
   - 아이템 유형에 대응하는 가변형 액션 버튼(`[장착하기]`, `[즉시 사용]`) 및 `[물자 버리기]` 폐기 옵션을 제공합니다.
4. **🛒 상점 (Shop) 탭**:
   - 구매 가능한 물자 카드를 가로 그리드로 노출합니다. 구매 시 크레딧이 차감되며 물자는 즉시 가방 인벤토리의 첫 번째 빈 슬롯으로 인송(생성)됩니다.
   - 단말 리롤을 상점 탭 하단에 배치하며, 갱신 횟수당 가격이 누진되는 규칙을 따릅니다.
5. **동적 탭 동기화 및 가드**:
   - 상점에서 물자를 살 때 가방 슬롯이 꽉 찬(8/8) 상태인 경우 구매가 실패하고 경고 메시지를 로그로 출력하는 예외 처리를 보장해야 합니다.
   - 상점이 아닌 다른 탭에서는 리롤 단말기 버튼을 감춤(`visibility: hidden`) 처리하여 오작동을 차단합니다.

## 🛠️ 개발자 테스트 숏컷 연동 명세

구현 완료 시 플레이어가 메인 메뉴의 **`🛠️ 개발자 테스트`** 오버레이를 통해 두 화면을 즉시 검증할 수 있도록 라우팅 버튼을 확보합니다.
- **[전투 결과 테스트 숏컷]**: 클릭 시 임의의 평가 등급(A등급 등) 및 무작위 드래프트 3택이 로드된 정산 오버레이를 팝업합니다.
- **[무기고 상점 테스트 숏컷]**: 클릭 시 특정 크레딧 보유 상태(예: 50c) 및 무작위 상품 2종 + 리롤이 연동된 상점 오버레이를 팝업합니다.
