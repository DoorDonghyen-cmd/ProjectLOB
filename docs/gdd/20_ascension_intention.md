## 1. 왜 승천인가 — 분량은 곱셈으로 만든다

- **챕터 추가 = 선형 비용.** 챕터 2개 = 보스·적 배리에이션·테마·난이도 곡선 몇 달치 → 얻는 건 +1시간. 게다가 완전 리셋 구조라 **후반 챕터는 소수만 본다.**
- **승천 = 곱셈.** 조건 조합만으로 기존 5챕터 전체에 곱해진다. **5챕터 × 10등급 = 50번의 다른 도전.**
- 제작비 대비 수명이 압도적이다.

---

## 2. 구조 (확정)

| 항목 | 결정 |
|---|---|
| **방식** | **누적(cumulative)** — 등급 N은 1~N의 조건이 **전부 동시에** 적용 |
| **단계** | **10~12단계** (슬더스의 20단계는 본작 스코프에 과함) |
| **적용 범위** | **전역** — 등급을 올리면 모든 총기에 적용 (총기별 승천 아님) |
| **해금** | 최종 계층(정점) 클리어 시 등급 1 해금, 이후 순차 |

### 누적 방식을 택한 이유
```
등급 1 : A
등급 2 : A + B
등급 3 : A + B + C  ...
```
- **"점점 조여든다"는 감각이 선명하다.**
- **"등급 = 난이도"라는 신뢰가 유지된다.** (개별 조건 방식은 등급 3이 등급 7보다 어려울 수 있어 신뢰가 깨진다.)

> ⚠️ **제약**: 각 등급이 추가하는 조건은 **작아야 한다.** 영원히 누적되므로 앞쪽에 큰 것을 넣으면 후반이 감당 불가능해진다.

## 3. ⚠️ 선행 조건 — 런 구조 재편 (확정)

**승천은 명확한 승리 조건을 요구한다.** 이것이 런 구조를 결정한다.

### 문제
현행 구현은 **한 구역 = 하나의 완결된 런**이다(구역 클리어 시 디브리핑·정산·다음 구역 해금). 이 구조에서는 *"승천 5등급 클리어"*가 **어느 챕터를 깬 것인지 모호**하다. 챕터별로 등급을 따로 매기면 5×10 = 50개 사다리가 되어 관리 불가능하다.

또한 각 구역이 `start_new_run()`으로 시작하므로 **챕터 5도 챕터 1과 동일한 기본 덱 8장으로 출발**한다. → **덱 빌드 아크가 한 챕터로 끝나** 덱빌더로서 빌드 완성의 쾌감이 부족하다.

### 결정
> **연속 런으로 재편한다. 한 런 = 1층부터 최종층까지 연속. 총 30~35층으로 압축.**

| | 현행 | 재편 후 |
|---|---|---|
| 한 런 | 구역 1개 (10~15층) | **전 계층 연속 (~35층)** |
| 총 층수 | 64층 (10/12/12/15/15) | **~35층** (6/7/7/7/8 등) |
| 예상 소요 | 20~40분 | **약 1시간** |
| 덱 빌드 아크 | 챕터 1개 | **5챕터 누적** |
| 승천 정의 | 모호 ❌ | **N등급 조건으로 전 계층 완주** ✅ |

- **런 중 유지**: 덱 · 파츠 · 가방 · 크레딧 (계층이 바뀌어도 끊기지 않음)
- **사망 시 소멸**: 위 전부. **1층부터 재시작** (HP 버퍼가 1회 완충)
- **사망 후에도 유지**: 메타(누적 크레딧 · 무기/구역 해금 · 업그레이드 레벨)

### 왜 압축이 필요한가
현행 64층을 그대로 연속화하면 **2~2.5시간**이 되어 장르 평균(45~60분)의 2배를 넘고, **GDD가 명시한 모바일 타겟**에 부적합하다. 완전 리셋 구조에서 2.5시간 런은 사망 시 손실이 과대해 *"한 판 더"*가 성립하지 않는다.

### 재편에 따르는 변경
- 계층당 층수 압축 (계층 정체성 5종은 유지)
- 구역 클리어 시 디브리핑이 아니라 **다음 계층으로 연결**
- 한 런에 **보스 5연전**
- 난이도 곡선을 35층 하나로 재설계
- **구역 관문 해금** — 바로 아래 관문 돌파 기록으로만 남기며, 해금과 동시에 같은 런에서 다음 계층으로 연결

## 4. 조건 풀 — 무엇을 조일 것인가

### ✅ 좋은 손잡이 — 자원·시간을 양적으로 조인다

| 조건 | 효과 | 근거 |
|---|---|---|
| 시작 아머 −1 | 목숨 하나 제거 | 직접적, 계단 없음 |
| **환급 감소** (§4.1) | 탄이 덜 돌아옴 | **"통하는 탄 고르기"가 더 절실 — 코어 강화** |
| 크레딧 수입 감소 | 구매력 감소 | 저축 판단이 빡빡해짐 |
| 파츠 획득 감소 | 빌드 완성 지연 | 현재 문제(초반에 슬롯이 다 참)의 반대편 |
| 탄환 획득 감소 | 호환탄 희소성 증가 | 자원 긴장 |
| 전투 시작 거리 −1 | 사격 기회 감소 | **코어 통화(거리)로 지불** |
| 적 SPD +1 | 전진 가속 | 시간 압박, 게이트 무관 |
| 적 HP 증가 / 적 수 증가 | 양적 부담 | 완만한 상승 |
| 무기고 노드 수 감소 | 정비 기회 감소 | 경제 저울추 |

> 공통점: **전부 양적**이라 완만하게 조여지고, 대부분 기존 파라미터라 **구현 비용이 거의 없다.**

### 4.1 환급 감소의 결정론적 구현 (확정)

**현행 규칙** (`combat_manager` → `run_manager.exile_bullet_from_deck`):
```
격발 → 유효타(피해 1 이상) → discard_pile  (덱에 남음)
     → 헛방(빗나감·도탄 0뎀) → exile        (덱에서 영구 삭제)
       └─ 단, 총기와 같은 클래스의 탄은 보존 ← 안전장치
```

주력 탄이 계속 소멸하면 쏠 것이 없어지므로 **같은 구경 탄은 보호**하는 안전장치가 있다.

#### 레버 ① — 전용탄 보존 해제 (질적 벽)
> 승천 N등급부터: **같은 구경 탄도 헛방이면 소멸한다.**

- ✅ **완전 결정론** — 확률 없음. 헛방이면 100% 소멸
- ✅ **구현 비용 0** — 기존 조건문 하나
- ✅ **총기 중립** — 모든 클래스 동일 적용
- ✅ **코어 강화** — 잘못 고른 한 발이 자원 손실로 직결. *"이 적에게 무엇이 통하는가"* 계산이 극도로 절실해짐
- ⚠️ **이진 스위치라 완만하지 않다** → **한 등급에 단독 배치**하여 "여기서부터 다른 게임"이 되는 **벽** 역할

#### 레버 ② — 시작 덱 감소 (양적 스케일링)
> 시작 덱 −1발씩 (`start_new_run`의 `basic_cnt / specA_cnt / specB_cnt`)

- 양적이라 완만하고, 총기 중립이며, 기존 파라미터라 구현 비용 없음
- **여러 등급에 걸쳐 조금씩** 누적

#### ❌ 채택하지 않은 구현
| 안 | 기각 사유 |
|---|---|
| 확률 환급 | **결정론 정체성 위반** |
| "DMG < X면 소멸" | 1뎀 유틸탄(넉백·슬로우)이 **항상 소멸** → 유틸 빌드 말살 |
| 리로드 시 소실 | dmr(3발)이 smg(6발)보다 2배 자주 리로드 → **총기 편향** |

### ❌ 피할 손잡이 — 적 DEF / EVA

**이진 관통 게이트라 절벽이 된다.** DEF 4→5인 순간 PEN 4 탄은 성능이 20% 떨어지는 게 아니라 **완전 무효(0)**가 되고, 다른 탄은 아무 영향이 없다.
→ 승천 등급이 균일하게 오르지 않고 **특정 빌드만 골라 죽인다.**

> **실제 사례**: `nano_stalker`의 EVA 9는 탄환 ACC 상한(8)을 넘겨, 전용 카운터(DMR 저격 시그니처·표적 지시기) 없이는 **명중이 원천 불가능**했다. 이진 게이트가 절벽을 만드는 구조를 그대로 보여준다.

→ 쓴다면 *"이 등급부터 빌드를 다시 짜라"*는 **의도된 벽**으로만, 아주 드물게.

### ❌ 피할 손잡이 — 총기 편향 조건

전역 적용이므로 **특정 클래스만 죽이는 조건은 금지**한다.

| 조건 | 편향 |
|---|---|
| 리로드 턴 +1 | 연발(사이클 3턴) 33% 페널티 vs 단발(사이클 8턴) 12% |
| 탄창 −1 | **dmr(3발) 33% 손실** vs smg(6발) 17% |

고등급에서 특정 클래스가 **사용 불가**가 되면 승천의 목적(*"모든 총기로 더 어려운 도전"*)이 무너진다. 조건은 **총기 중립적**이어야 한다.

## 5. 메타 진행과의 관계 (확정)

| 메타 유형 | 처리 | 이유 |
|---|---|---|
| **해금 메타** (무기 8종 · 구역) | **유지** | "선택지 확장"이라 공정성을 해치지 않음 |
| **파워 메타** (HP아머 · 가방 · 금고 · 할인) | **유지하되 승천 조건으로 상쇄** | 무효화하면 애써 모은 업그레이드가 무의미해짐 |

**상쇄 대응표**
| 파워 메타 | 상쇄하는 승천 조건 |
|---|---|
| HP 아머 +2 | 시작 아머 −1 (두 등급에 분산 배치) |
| 가방 확장 +3 | 탄환 획득 감소 / 시작 덱 −1 |
| 금고 이월 | 크레딧 수입 감소 |

> **밸런싱 기준: "최대 메타 보유" 상태.** 그래야 "등급 = 난이도" 신뢰가 유지된다. 메타가 덜 찬 상태로 승천에 오르면 그만큼 더 어려운 것은 감수한다(승천은 클리어 이후 콘텐츠이므로 자연스럽다).

### ⚠️ 무기 해금 조건과의 충돌 — 재설계 필요
승천 조건이 해금 조건을 **불가능하게** 만들 수 있다.

> **gambler**: *"런 전체에서 최소 접근 거리 > 1 유지"*
> ↔ 승천의 *시작거리 −N* + *적 SPD +N*이 누적되면 **사실상 달성 불가**

**결정**: 해금 판정은 승천에서도 **유지**하되, **충돌하는 조건 자체를 재설계**한다(거리 절대값 → 상대 기준 등). 진행이 막히지 않아야 한다.

## 6. ⚠️ 반드시 지킬 바닥선 — 공정성

> **최고 등급에서도 "완벽한 플레이"는 이길 수 있어야 한다.**

자원 시스템의 지배 원칙 그대로 — *효율 실패로 죽는 것은 공정, 완벽히 플레이했는데 자원이 부족해 죽는 것은 부당.*

승천은 이 선을 넘기 쉽다. 환급을 계속 조이면 어느 지점에서 **수학적으로 이길 수 없게 된다.**

**검증 방법**: 헤드리스 시뮬 하니스(`tests/sim_harness.gd`)로 환급률을 낮춰가며 *"한 런 탄 총량 < 클리어 필요량"*이 되는 지점을 계산 → **그 아래가 상한**.

## 7. 미해결 — 조건 배치는 밸런스 이후

**1~10등급에 무엇을 어떤 순서로 배치할지는 지금 정하지 않는다.**

각 조건이 얼마나 아픈지는 **기본 밸런스가 잡혀야** 알 수 있다. 예컨대 현재는 파츠가 초반에 슬롯을 다 채우므로 *"파츠 획득 감소"*가 페널티가 아니라 **정상화**일 수 있다.

| 항목 | 상태 |
|---|---|
| 런 구조 재편 (§3) | ✅ **완료** — 연속 런 35층 |
| 최종 단계 수 | ✅ **10단계 확정** (`Ascension.MAX_LEVEL`) |
| 등급별 조건 배치·순서 | ✅ **1차 배치 완료** — 아래 표. 플레이 데이터로 조정 예정 |
| gambler 해금 조건 재설계 | ✅ **완료** — 절대 거리 → **시작 거리 대비 1/3 비율**. 승천이 거리를 좁혀도 성립 |
| 승천 진행 표시 UI | ✅ 상승 브리핑에 등급 선택 + 누적 조건 목록 |
| 등급별 보상 | 해금/칭호/기록만. **파워 보상 금지**(런 리셋 원칙) |

### 1차 등급 배치 (`scripts/core/ascension.gd`)

| 등급 | 이름 | 추가되는 조건 |
|---|---|---|
| 1 | 가벼운 짐 | 시작 아머 −1 |
| 2 | 얇은 배급 | 크레딧 수입 ×0.8 |
| 3 | 빈 주머니 | 시작 덱 −1발 |
| 4 | 좁은 통로 | 교전 시작 거리 −1m |
| 5 | 빨라진 것들 | 적 SPD +1 |
| 6 | 마른 보급 | 드래프트 탄환 선택지 2 → 1장 |
| 7 | 무거운 짐 | 시작 아머 −1 (누적 −2) |
| 8 | **회수 불가** | **전용탄도 헛방이면 소멸** ← 질적 벽, 단독 배치 |
| 9 | 더 빈 주머니 | 시작 덱 −1발 (누적 −2) |
| 10 | 정점의 무게 | 크레딧 ×0.8 (누적 ×0.64) · 적 SPD +1 (누적 +2) |

> **공정성 바닥선 검증**(§6): 최고 등급 + 최대 메타에서도 시작 아머 ≥ 1, 완주 수입 368 Cr > 0.
> `suite_ascension.gd`가 이 부등식과 **등급별 단조성**(오를수록 반드시 어려워짐)을 고정한다.
>
> ⚠️ 배치 수치는 플레이 데이터로 바뀔 수 있다. 바꿀 때 지켜야 할 것은 수치가 아니라 **구조**다 —
> 누적일 것, 단조로울 것, 자원이 0이 되지 않을 것, DEF/EVA를 건드리지 않을 것.

## 8. 기각 기록

### 🚫 7챕터로 확장 — 기각
- **장르 천장 초과**: 슬더스 45분~1시간, 발라트로·하데스 30~40분.
- **완전 리셋 구조에서 장시간 런은 사망 손실이 과대** → *"한 판 더"*가 불가능 → 반복이 일어나지 않음 → 총기 8종·해금·빌드 다양성이라는 **배수가 전부 사망**.
- **제작 관점**: 대부분의 플레이어는 초반 챕터만 반복해서 본다. 후반 챕터는 **소수만 보는 콘텐츠에 몇 달**을 쓰는 것.

> 이 논리는 §3의 **층수 압축(64층 → ~35층)**을 정당화하는 근거이기도 하다. 챕터를 늘리기는커녕 현재 분량도 연속 런 기준으로는 과하다.

### 🚫 무한 모드 — 기각
1. **이진 게이트가 완만한 상승을 거부** — 적 DEF가 오르면 특정 탄이 약해지는 게 아니라 **0이 된다.** 난이도 곡선이 아니라 절벽의 연속.
2. **성장에 천장이 있음** — 파츠 3~5칸, 탄창 최대 6발(+약실 1). 무한히 강해질 수단이 없어 적만 세지는 구조 → *"얼마나 버텼나"* 점수 게임이 됨(다른 장르).
3. **호환탄 고갈** — 무한 모드에서는 호환 탄이 반드시 바닥나 고DEF 적 앞에서 **탈출구 없는 막힘이 구조적으로 보장**된다.
4. 이미 기각한 노선 — *"무한 콘텐츠 기각, 아담한 게임(30~50시간)"* 원칙.

> **무한 모드가 주려던 것(*"클리어 후에도 할 게 있어야 한다"*)은 승천이 전부 대체하며, 위 문제가 전혀 없다.**
