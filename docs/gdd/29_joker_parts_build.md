# 29. 파츠 빌드 — 런의 규칙 조합

파츠는 총기의 부속 수치 하나를 바꾸는 장비가 아니라, 한 런의 탄환 선택과 발사 순서를 바꾸는 핵심 빌드 축이다. 한 번에 최대 5개를 장착하며 효과는 모두 함께 적용된다.

## 장착 규칙

- 일반 모듈은 제한 없이 조합할 수 있다.
- 금색 코어 파츠는 최대 1개만 장착한다.
- 구매한 파츠는 조건이 맞으면 빈 슬롯에 자동 장착되고, 그렇지 않으면 보관함으로 이동한다.
- 전투 사이에는 무료로 장착하거나 해제할 수 있다.
- 장착 중인 파츠는 분해할 수 없다.
- 상점에서는 크레딧이 허용하는 만큼 여러 파츠를 살 수 있다.

| 파츠 | 효과 | 만드는 판단 |

| 증폭 시퀀서 | 증폭 피해 +1 | 증폭 뒤 두 발 강화 |
| 복열 노리쇠 | 연발 타격 +1 | 배리어와 쇄도 집중 |

## 코어 파츠 6종

코어는 전투 규칙을 크게 바꾸는 대신 실제 운용 비용을 가진다.

| 파츠 | 강점 | 대가 |
|---|---|---|
| 야전 압축기 | 교전마다 현장 압축 +1회 | 탄창 −2칸 |
| 과구경 총열 | 모든 직접 피해·관통 +2 | 탄창 −1칸 |
| 열폭주 노심 | 소이탄 화상 +2 | 재장전 +1턴 |
| 분기 전이기 | 전이 피해 +2, 대상 +1 | 모든 직접 피해 −1 |
| 충격 피스톤 | 밀치기·한도 +2m | 모든 직접 피해 −1 |
| 삼중 시퀀서 | 서로 다른 세 번째 탄 직접 피해 +5 | 회수탄 직접 피해 −1 |

## 정산 순서

직접 피해 보정은 탄환과 무기 기본값을 계산한 뒤 장갑을 차감하기 전에 더한다. 선두·후미·삼중 시퀀서는 실제 발사 순서를 사용한다. 배리어 파쇄기는 각 실제 타격마다 배리어를 최대 2칸 제거한다. 야전 압축기가 주는 무료 기회는 교전마다 추가되며, 상점에서 구매한 영구 충전량보다 먼저 소모된 것으로 정산한다.

예측은 실제 전투 모델의 복제 상태를 실행하므로 파츠 효과, 코어 패널티, 탄창 크기와 순서 조건이 실제 결과와 같아야 한다.

## 상점과 장비 UI

상점 상단에는 5개의 소형 장착 슬롯을 한 줄로 표시한다. 일반 파츠는 고유 색, 코어는 금색 이중 테두리와 `CORE` 표식으로 구분한다. 후보 카드는 큰 효과 수치와 `▲` 이점, `▼` 대가를 먼저 보여 주며 긴 설명은 상세 화면에서만 연다.

장비창은 현재 장착 5칸을 한 줄로 유지하고, 아래의 보유 파츠를 2열 카드로 보여 준다. 가로 스크롤 없이 장착·해제 버튼으로 교체한다.

## 저장 계약

전투 저장 v8과 캠페인 저장 v4는 `equipped_parts` 배열을 저장한다. 배열은 최대 5개, 중복 없음, 코어 최대 1개이며 캠페인에서는 보유 목록의 부분집합이어야 한다. 이전 단일 `part` 저장은 복원할 때 첫 장착 파츠로 변환한다.

구현 정본: `res://redesign/content.gd`, `model.gd`, `campaign.gd`, `campaign_ui.gd`, `part_card_view.gd`.
