## 22.4 결정형 크리티컬

> 인접 보조탄 덕분에 실패하던 게이트를 넘은 발은 피해 ×1.5(내림)다.

```
영구 디버프 + 잔여 탄창 버프 + 파츠를 포함한 기준 판정: 실패
위 상태 + 이번 인접 ACC/PEN 버프 판정: 통과
→ 결정형 크리티컬
```

피해 순서는 다음 하나로 고정한다.

```
탄 기본 DMG + 총기 패시브 + 탄 조건부 정액
→ 크리티컬 floor(×1.5)
→ 파츠·총기 시그니처 정액 보너스
```

이미 교란·파쇄·유도·정렬로 열린 게이트는 인접 버프의 공으로 다시 계산하지 않는다.
UI는 `preview_next_shot()`의 동일 반사실 계산을 사용해 격발 전에 금색
`✦ 크리티컬 ⟨게이트 개방⟩`을 표시한다.

## 22.5 소멸·컨버전 킷

- 현재 총기 구경의 기반탄은 실패해도 런 덱에서 보존한다.
- 컨버전 킷 대상 기반탄도 같은 보호를 받는다.
- 구경 무관 14종은 실패 시 전투 풀에서 소멸하고 런 덱에서도 영구 제거된다.
- 승천 8의 “회수 불가”는 기반탄·컨버전 보호까지 해제한다.
- UI는 실패 판정과 함께 영구 소실 위험을 사전에 표시한다.

> **2026-07-28 플레이테스트 보류:** 현재 컨버전 킷은 전투 리듬을 바꾸지 않고
> 특정 기반탄의 보존·획득 가중만 제공해, 크레딧과 파츠 슬롯을 지불할 이유가
> 충분히 드러나지 않았다. 런타임 계약과 리소스는 보존하되 무기고 진열을 중단한다.
> 재도입 여부는 1~2구역 빌드 다양성 검증 후 결정하며, 재도입한다면 구경 방향에
> 따른 탄창·재장전·명중·피해·관통 교환을 먼저 설계한다.

## 22.8 자동 검증 불변식

1. CSV와 `.tres` 집합은 정확히 19종이며 양방향 일치한다.
2. 계열은 기반5/보조6/특수6/제어2다.
3. 모든 탄 DMG ≥ 2, 기반탄 DMG 스프레드 ≤ 3이다.
4. 비기반탄은 전부 `UNIVERSAL`, 기반탄만 구체 구경을 갖는다.
5. 0이 아닌 `effect_type`은 중복하지 않는다.
6. 시작 패키지 5종과 무기고 범용 후보 14종은 모두 실제 로드 가능하다.
7. #009: 흡수체 셀은 피해 1 이상의 유효 적중만 센다.
8. #010: 태세 사냥꾼은 적의 실제 `stance_shift_interval`을 읽는다.

v5의 LIFO 360순열 결과는 `tests/baseline/lifo_depth_v5.json`에 역사 자료로 보존하며,
삭제된 v5 리소스로 현재 결과를 재생성하지 않는다.
