# 25. 무기 정체성과 단발 강점 — 채택 결정

2026-09-16 사용자가 기본 피해 +1 보행자와 탄환 효과 2배 단발 방향을 받아들였다. 기존 전체 개발·UI 위임에 따라 다섯 종을 구현했다. 단발은 앞서 추천한 피해·관통 포함 배율로 진행하며, 이를 별도 선택지에 대한 명시적 답변으로 기록하지 않는다. 현재 수치·정산 정본은 [24번 무기 설계](24_weapon_archetypes_redesign.md)다.

## 차별화 기준

무기는 한 런의 규칙과 빌드 방향을 정한다. 같은 탄환 패에서 장전 순서·처치 계획·탄환 보상의 가치가 달라져야 한다. 공통 탄환 7종, 피해·관통, 물리/화염/전기와 효과 하나를 유지하고 새로운 명중/회피 수치나 별도 게이지를 추가하지 않는다.

사용자 방향은 보행자 기본형, 쇄도 같은 적 3회 적중 보너스, 산개 여러 적에 무작위 발사, 압쇄 소이/전이 특화, 단발의 탄환 효과 2배다. 기본형과 특화 연쇄 세 종에는 전체 사격 후 적 행동 한 번을 공통 적용한다.

## 구현한 선택

| 무기 | 대표 규칙 | 비용과 실패 조건 |
|---|---|---|
| 보행자 | 기본 주 피해 +1, 범용 연쇄 | 화상·전이 같은 보조 효과를 강화하지 않는다 |
| 쇄도 | 같은 적 실제 주 타격 3회마다 고정 +4 | 재장전 2턴, 추가 피해 전에 처치하면 진도를 다음 적에 넘기지 못한다 |
| 산개 | 매 탄환 생존 적 균등 무작위, 탄창 5칸 | 가까운 적 제거를 확정할 수 없고 철갑이 장갑 적에게 간다는 보장도 없다 |
| 압쇄 | 화상 턴당 2, 전이 3 | 물리 위주 덱은 고유 이점을 활용하지 못하고 전이는 다른 생존 적이 필요하다 |
| 증강 | 단발, 기본 피해·관통·효과 강도 2배 | 탄환마다 생존 적이 접근하며 탄창 전체 실행에 여러 턴이 필요하다 |

보행자는 회수 5, 철갑 4, 연발 3×2로 기본 직접 화력을 명확하게 한다. 증강은 연발 타격 수·화상 기간·증폭 적용 탄환 수를 유지해 중복 4배를 피한다. 충격의 공유 탄창 상한도 4m로 맞춘다. 쇄도의 카운터는 적별로 재장전과 표적 변경을 거쳐 유지한다. 화상·보조 전이는 카운터에 포함하지 않는다.

산개는 실제 무작위 표적을 채택했다. 기존 결정론 지침을 근거로 사전 표적을 확정 공개하지 않는다. 가능한 표적 순서를 계산한 범위와 확률을 표시하고, 실제 표적 RNG는 확정 발사에서만 진행한다. 피해 정산은 명확하게 유지한다.

압쇄는 화상의 턴당 지속 피해와 전격 전이만 강화한다. 화염을 먼저 묻힌 뒤 다른 탄환으로 폭발시키는 규칙으로 바꾸지 않는다. 과거 산개 거리 확산·압쇄 관통/초과 관통·단발 처치 시 적 행동 생략 후보는 현재 규칙에서 제외한다.

## 검증 경계와 다음 판단

[사전 계획](../implementation_plan_weapon_rules_2026-09-16.md)의 와이어프레임을 작성한 뒤 코드와 UI를 편집했다. 저장을 보존하는 다섯 무기 개발자 비교 버튼으로 같은 대열의 실제 명령을 확인할 수 있다. 규칙·예측·저장·공개 UI의 기능 검증은 구현 결과 문서에 기록한다.

산개의 실제 승률·최종 재미를 한 고정 RNG 경로의 자동 완주로 대체하지 않는다. 기능 경로 탐색기는 미래 패와 RNG에 접근하므로 사람 관점의 플레이와 구분한다. 같은 패·같은 대열에서 증폭/연발, 적중 진도, 여러 표적 결과, 소이/전격, 단일 보스, 재장전과 접근 비용을 비교해 출발 수치를 조율한다.

[기존 발사 템포 분석](../qa/reports/fire_tempo_review_2026-09-16.md)은 이전 네 무기 규칙의 역사적 측정값이다. 새 다섯 무기의 균형을 증명하는 자료로 사용하지 않는다. APK는 사용자 요청 시 만들며 이번 작업에서 원격 푸시는 수행하지 않는다.
