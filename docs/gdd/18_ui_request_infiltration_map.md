## 1. 개요 및 비주얼 테마
본 UI는 플레이어가 런을 개시한 후 다음 층으로 나아가기 위해 **"봉쇄된 빌딩의 층별 단면도"**를 탐색하고 이동 경로(노드)를 선택하는 화면입니다.
*   **비주얼 컨셉**: 전술 군사 작전 모니터 스타일. 어두운 네이비/차콜 배경 위에 홀로그램 형태로 빌딩 단면도와 경로 분기가 입체적으로 투영됩니다.
*   **핵심 연출**:
    *   **층간 스크롤 (Floor Skips)**: 엘리베이터 샤프트 등으로 층을 건너뛸 때 맵 전체가 격렬히 하강 스크롤되며 상단 층 카운터가 흔들림과 함께 갱신됩니다.
    *   **정보 스캐너**: 미지 노드(`?`)에 마우스 호버(또는 터치) 시, 디제틱한 스캔 힌트 팝업창이 뜨며 내부 위험도를 노출합니다.

## 3. UI 구성 요소 및 데이터 매핑

### ① 헤더 영역 (HUD Header)
*   **층수 계측기**: 현재 도달한 빌딩 층수(`3F`, `8F` 등) 및 현재 난이도 구역을 표시합니다.
*   **크레딧 잔액**: 보유한 기업 크레딧(Cr)을 홀로그램 점멸과 함께 표시합니다.
*   **HP 버퍼 게이트**: 남은 하트/라이프 버퍼를 `[◆][◆][◇]` 형태로 연출합니다.

### ② 메인 층별 격자 맵 (Floor Grid Map)
*   **수직 층 구조**: 아래층(현재 위치)에서 위층(최상층 목표)으로 연결되는 노드 구조.
*   **3대 침투 통로 분기선**:
    *   **비상계단 (Stairs)**: 1층씩 안정적으로 상승. 패널티 없음.
    *   **환기구 (Air Duct)**: 경로가 길고 꺾이지만 전투 최소화. **진입 시 적과의 시작 거리 -2m 단축 패널티**가 적용된다는 주의 라벨 노출.
    *   **엘리베이터 샤프트 (Shaft)**: 2~3개 층을 단번에 스킵. **30% 확률로 버퍼 1칸 소실 또는 시작 거리 4m 초근접 난전 패널티** 주의 라벨 노출.
*   **노드 유형 배지**:
    *   `전투 노드`: 칼 모양 아이콘.
    *   `상점 노드`: 단말기/카트 아이콘.
    *   `대피소 노드`: 십자 보급품 아이콘.
    *   `미지 노드 (?)`: 보이지 않는 위험 표시.

### ③ 정보 스캐너 (Scanner Hint Popup)
*   **동작 규칙**: 미지 노드(`?`)에 마우스 오버 / 터치 유지 시 힌트 팝업 활성화.
*   **표시 정보**:
    *   `[생체 신호 다수 감지 - 위험 HIGH]`: 전투(엘리트) 노드 유력.
    *   `[전기적 노이즈 감지 - 상점 유력]`: 상점/정비 터미널 유력.
    *   `[렐릭 에너지 반응 감지 - 보급 상자]`: 렐릭/아이템 유력.
*   **개발 가드레일**: 스캐너 팝업 패널은 `mouse_filter = MOUSE_FILTER_IGNORE`를 설정하여 팝업이 활성화된 도중에도 맵의 다른 공간이나 뒤쪽 노드 클릭이 막히는 오작동을 차단합니다.

## 4. 인터랙션 및 애니메이션 가이드
1.  **층 이동 및 Skip 연출**:
    *   노드 클릭 시 화면이 수직으로 격렬히 스크롤 하강하며 새로운 층의 노드들로 카메라가 정렬됩니다.
    *   상단 층수 텍스트가 노이즈 점멸 효과(Glitch Effect)와 함께 `3F ➡️ 5F`로 갱신됩니다.
2.  **경로 선택 팝업**:
    *   노드를 선택하면 해당 경로의 리스크와 리턴을 대조해 보여주는 **"침투 경로 승인"** 팝업창이 떠서 다시 한번 최종 결정을 내리게 유도합니다.
