# 12. 전투 UI · UX — 설계 및 배치 보충안 (Combat UI/UX Addendum)

본 문서는 게임 *Last on Board* (L.O.B)의 전투 인터페이스에서 작동하는 정보 위계, 레이아웃 보존 규칙 및 조작 흐름에 대한 기획 설계 합의문입니다.

---

## 0. 지배 원칙 (Guiding Principles)

1. **계산은 화면이, 판단은 플레이어가**
   - 플레이어가 대미지 계산, 명중 여부, 도탄(Ricochet) 예외 등을 머릿속으로 암산하지 않도록 **사격 결과를 미리 시뮬레이션하여 정보 패널에 직관적으로 보여준다.**
   - 이진 게이트(O/X) 규칙으로 결과가 명확히 판정되므로 사격 전 "뚫림(GREEN)/막힘(RED)" 결과를 무료로 상시 표출한다.
2. **지금 필요한 것만 보여준다 (Minimal Cognition)**
   - 지나친 정보 과잉을 억제하기 위해 **상세 수치는 온디맨드(On-demand)로 숨기며**, 코어 흐름에 필요한 정보 위주로 한눈에 들어오게 압축한다.

---

## 1. 정보 위계 및 시각적 흐름 (Visual Hierarchy)

플레이어가 전투 턴을 해결할 때 눈이 이동하는 논리적 결정 흐름입니다:

```
[좌측: 내 정보 구역]                       [우측: 전술 상황 및 타겟팅]
1. 예고창 (내 탄창 스택 앞 2발)   ➡️   2. 캐릭터 (요원 위치)   ➡️   3. 공유 트랙 (적과의 거리/생사선)
                                                               ⬇️
                                                        4. 명중 분석 (최근접 적 대상)
                                                               ⬇️
                                                        5. 액션 바 (조작 활성 버튼군)
```

1. **거리 (생사선)**: 최근접 적과의 거리는 상단 중앙에 가장 거대하게 상시 표시되며, 임계점(3칸 이하) 도달 시 크기가 확장 및 맥동하며 붉게 점멸한다.
2. **세로 예고창**: 캐릭터 좌측에 위치하며, **"위 = 다음 발사, 아래 = 먼 미래 탄"**의 탑다운(Top-down) 방식을 일관되게 고수한다.
   - 전투 중에는 **앞 2칸만 선명**히 그리고, 나머지 칸들은 숫자로 묶어 덩어리로 표시함으로써 탄창이 10칸으로 늘어나더라도 항상 작고 정합된 크기를 유지한다.
3. **명중 분석**: 왼쪽 상단 정보 패널에 위치하며, 사격 시 첫 번째 관통 대상인 최근접 적에 대한 성공/실패 여부를 사전에 가시화한다.

---

## 2. 세부 UI/UX 스펙 및 레이아웃 정책

### ① 액션 바 버튼 레이아웃 고정 (Static Action Bar)
- 장전(`LOADING`) 모드 등으로 진입하여 특정 액션 버튼이 불필요해지더라도, **버튼을 숨기지 않고 회색 비활성화(`disabled = true`) 처리**한다.
- 사격 버튼(`_fire_btn`) 하나가 장약 삽탄 상황에서는 `"✅ 장전완료"`로 텍스트와 콜백만 대체되도록 결합하여, 가로 버튼 갯수와 위치를 100% 보존(근육 기억 유지 및 레이아웃 요동 원천 차단)한다.

### ② 자물쇠 UI 배지 상시 노출
- 현재 비주얼 리소스 수준에서 몬스터의 자물쇠 속성(방패, 회피, 돌격 등)을 외형만으로 구별할 수 없으므로, **자물쇠 종류를 표현하는 픽토그램 배지는 항상 무료로 적 머리 위에 표시**한다. (절대 스캔 아이템/렐릭 뒤에 숨기지 않는다.)
- 미래에 픽셀 그래픽 리소스가 정교화되면 몬스터 외형의 실루엣(방패 지참 등)과 UI 배지가 공용 픽토그램 언어를 공유하도록 설계한다.

### ③ 가방 확장 방식: 반투명 하프 슬라이더 (Half Transparent Slider)
- 전투 페이즈 도중 탄환 소모품이나 세부 수치를 점검하기 위해 가방을 열 때, 화면 전체를 덮지 않고 **좌측 40% 영역만 부분적으로 덮는 반투명 패널**을 탑재한다.
- 우측 60% 영역의 적 트랙 상황을 계속 주시할 수 있게 열어두어, 인벤토리 관리 도중에도 플레이어의 전술적 긴장감과 몰입도를 유지한다.

### ④ 스택 스펀지 몬스터 램프화
- 스택 스펀지 속성을 가진 적은 깡딜 HP 수치 대신 **하늘색 쉴드 램프(`◆ ◆ ◆`)** 배지를 머리에 띄우며, 사격 관통이 통과될 때마다 램프가 하나씩 꺼지게 시각화하여 계산 피로를 덜어준다.
