# 27. 상층 적 자물쇠와 관문 시험

상태: `prototype/core-redesign` 구현 정본  
기준: 공개 정보, 결정론, 순서 장전, 거리 압박

## 목적

35층 후반이 HP와 장갑 수치만 커지는 반복이 되지 않도록 적 실루엣 6종이 서로 다른 계산을 요구한다. 새 규칙은 공역, 정비, 관리 계층에서 하나씩 소개하며 정점은 이미 배운 규칙만 결합한다.

| 적 | 화면 실루엣 | 공개 규칙 | 주 해법 |
|---|---|---|---|
| 운반 사족체 | 낮고 긴 사족형 | 빠른 접근 | 충격, 짧은 고화력 순서 |
| 융합 장갑벽 | 넓은 벽 | 높은 장갑 | 철갑, 관통 파츠 |
| 전도 선체 | 가늘고 흔들리는 윤곽 | 낮은 HP와 중간 장갑 | 먼저 처치할 순서 계산 |
| 신경 교란 부유체 | 오각 부유체 | 3턴 충전 뒤 다른 생존 적 모두 2m 추가 접근 | 충전 전에 처치, 거리 확보 |
| 흡수 장갑 구체 | 원형 구체 | 직접 타격을 2회 흡수. 관문형은 3회 | 연발·압축 연발로 셀 제거, 화상·전이 우회 |
| 태세 교란 드론 | 삼각 드론 | 적 전진 뒤 장갑 4↔0 교대 | 열린 턴에 강한 탄 배치, 재장전 턴 계산 |

## 한 턴 정산 순서

1. 살아 있는 적의 화상 피해와 지속 수를 정산한다.
2. 부유체 충전을 1 올린다. 3에 도달하면 0으로 돌아가고 다른 생존 적을 2m 당긴다.
3. 살아 있는 적이 각자의 접근 수치만큼 전진한다.
4. 태세 드론의 장갑을 4와 0 사이에서 전환한다.
5. 어느 단계에서든 거리가 0m가 되면 패배한다.

이 순서는 발사 예고, 재장전 위험, 실제 정산, 연출에서 동일하다. 재장전이 2턴이면 위 순서를 두 번 수행하므로 충전과 태세도 두 번 진행한다.

## 배리어 계약

- 배리어는 직접 타격 한 번당 셀 하나를 소모하고 그 타격의 HP 피해를 0으로 만든다.
- 연발탄의 개별 타격은 각각 한 셀을 소모한다.
- 셀을 소모한 같은 타격에서 쇄도의 3타 추가 피해는 발생하지 않는다.
- 화상과 전이는 직접 타격 배리어를 우회한다.
- 화면은 `◆2/2`, 탄착은 `배리어 −1`, 발사 순서는 셀 소모 후 HP 피해를 각각 표시한다.

## 계층별 학습

| 계층 | 새 규칙 | 관문 주 시험 |
|---|---|---|
| 침전 거주구 | 기본 3종 | 장갑벽 단일 순서 |
| 공역 | 부유체 충전 | 충전 보스와 빠른 호위 |
| 정비 계층 | 배리어 | 3셀 흡수 보스와 장갑 호위 |
| 관리 계층 | 교대 장갑 | 태세 보스, 부유체, 선체 혼합 |
| 정점 | 신규 없음 | 3셀 배리어 + 충전 + 교대 장갑 종합 |

## UI 계약

- 거리 전장은 실루엣 위에 배리어 셀과 충전 수를 직접 표시한다.
- 오른쪽 적 요약은 `◆`, `충`, `장→` 축약과 접근 수치를 함께 표시한다.
- 적을 누르면 자동 조준을 바꾸지 않고 전체 행동 규칙을 연다.
- 지도에서 미래 전투를 누르면 적 이름, HP, 장갑, 거리, 접근, 고유 규칙을 모두 공개한다.
- 패배 정산은 접촉한 적 상태를 바탕으로 다음 장전 방향 한 가지를 제안한다.
