# Godot UI 제작 기준

기준일: 2026-09-21  
대상: `prototype/core-redesign`  
기준 뷰포트: 1280×800, 저해상도 검증 1008×630, 가로 화면

## 목적

아트가 교체되기 전에도 플레이어가 화면의 목적과 다음 행동을 짧게 파악하게 한다. 최종 아트 적용 뒤에도 화면 구조와 입력 계약을 유지할 수 있도록 고정 레이아웃, 동적 데이터, 시각 피드백의 책임을 분리한다.

## 장면과 코드의 책임

- 정식 화면과 큰 오버레이의 고정 구역, 컨테이너, 앵커, 대표 문구는 `.tscn`에 둔다.
- 상품, 탄환, 파츠, 적처럼 수가 달라지는 반복 항목만 스크립트에서 채운다.
- 가격, 현재 수량, 장착 상태, 잠금 상태와 로컬라이즈 문장은 노드 텍스트 또는 런타임 데이터로 유지한다.
- 주 화면의 위치를 런타임에서 직접 계산하지 않는다. `VBoxContainer`, `HBoxContainer`, `HFlowContainer`, `GridContainer`, `MarginContainer`가 배치한다.
- 공용 카드와 아이콘은 하나의 뷰를 상점, 장비, 보상, 상세 화면에서 재사용한다.

## 정보량 기준

화면은 아래 순서로 읽힌다.

1. 화면 제목
2. 지금 결정할 내용 한 문장
3. 비교할 수치 또는 카드
4. 카드에 붙은 즉시 행동
5. 필요할 때만 여는 상세 설명

- 같은 효과를 카드 본문과 카드 아래 문장에 반복하지 않는다.
- 파츠 기본 카드는 이름, 고유 도형, 핵심 이득, 강한 파츠의 대가만 표시한다.
- 역할 설명과 정확한 규칙 문장은 상세창과 툴팁으로 보낸다.
- 화면 안내 문장은 한 줄을 우선하며, 구매 결과는 행동 버튼에 포함한다.

## 상점·파츠 계약

```text
화면 제목 / 현재 결정
[새 진열] [맵으로 계속]
[현재 빌드: 무기·탄창·재장전·장착 5칸]

진열                                      보유 Cr
[탄환 상품] [파츠 상품] [파츠 상품]

[압축 코어 충전] [짧은 지속 규칙]

장착 작업대                 파츠 n/5 · 코어 n/1
[장착 슬롯 1..5]
보관함
[파츠 + 장착/해제 + 분해]
```

- 1280px 창은 상품 3열, 보관함 2열을 쓴다.
- 1120px 미만 창은 상품 2열, 보관함 1열을 쓴다.
- 구매, 상세, 장착, 해제, 분해는 카드와 같은 시각 묶음 안에 둔다.
- 현재 장착, 코어, 비활성, 구매 완료는 색과 외곽선 또는 짧은 상태 표기를 함께 쓴다.
- 주요 터치 버튼 높이는 최소 52px다.

## 입력과 피드백

- 화면이 열리면 키보드·패드 포커스가 이동 가능한 컨트롤만 남긴다.
- hover와 focus는 같은 강조 계열을 사용하고 pressed와 disabled는 별도 명암을 쓴다.
- 일반 선택은 짧은 색·외곽 변화, 구매와 장착은 카드 상태 갱신, 전투 핵심 사건은 별도 강한 연출을 쓴다.
- 반복 메뉴 이동에 흔들림, 긴 지연, 입력 잠금을 사용하지 않는다.

## 덱·장비와 전투 작업대 계약

- 덱·장비는 상점과 같은 파츠 카드, 5칸 장착 표시, 코어 1칸 제한을 사용한다.
- 전투는 전장 아래에 `탄 선택 → 순서 확인 → 발사` 단계와 `보유 탄환 ↔ 발사 순서`를 함께 둔다.
- 1008×630 가로 화면에서는 후보와 발사 순서를 나란히 유지한다. 900px 미만에서만 세로로 쌓는다.
- 전투 후보와 탄창 결과는 같은 화면에서 비교할 수 있어야 하며, 모바일 가로 기준에서 발사 순서를 첫 화면 아래로 강제로 밀지 않는다.
- 정식 구조는 `deck_loadout.tscn`, `combat_workbench.tscn`에 두고 스크립트는 현재 데이터와 행동만 연결한다.

## 검증 기준

- Godot 편집기에서 `.tscn`을 직접 열었을 때 주요 구역과 대표 문구가 보인다.
- 1280×800과 1008×630에서 가로 넘침이 없고 모든 행동에 세로 스크롤로 접근할 수 있다.
- 상품 구매, 상세 열기, 장착·해제, 분해, 리롤, 압축 코어 충전, 맵 복귀가 실제 입력으로 동작한다.
- 화면 폭에 따른 열 수와 52px 터치 높이를 자동 검사한다.
- 아트 교체 뒤 같은 경로와 해상도로 캡처해 구조·판독 순서·상태가 유지되는지 비교한다.
