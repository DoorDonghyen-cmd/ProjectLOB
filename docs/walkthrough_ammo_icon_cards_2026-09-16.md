# 탄환 카드 픽셀 아이콘 전환 결과

## 구현 결과

- 전투 후보 카드의 반복 문장을 `위력 → 관통 → 명중` 고정 순서의 픽셀 아이콘과 숫자로 교체했다.
- 기본 능력치는 `8`처럼 부호 없이, 탄환 효과는 `+4`, `−2m`, `×2`처럼 부호·기호를 붙여 서로 다른 정보임을 바로 구분하게 했다.
- 강화, 조준, 균열, 연속, 밀기, 둔화, 도약, 마무리, 회수 효과에도 전용 아이콘을 적용했다.
- 첫 학습 교전은 위력만, 장갑 학습부터 관통, 회피 학습부터 명중을 공개해 초반 정보량을 유지했다.
- 보상 카드도 전투 카드와 같은 아이콘 언어를 사용한다. 선택한 탄환의 문장 설명과 실제 피해 계산 근거는 기존 공용 정보 영역에 그대로 남겼다.
- 메인 메뉴의 `개발자 테스트 → 탄환 아이콘 카드 전체`에서 기본탄과 전술탄 10종을 한 화면에서 비교하고 실제 장전까지 시험할 수 있다. 원래 저장 데이터는 보존된다.

아이콘은 Godot에서 정수 좌표로 직접 그린다. 별도 임시 이미지 없이 현재 픽셀 UI의 색과 선 굵기를 따르며, 카드 버튼의 클릭·호버·키보드 입력은 기존 동작을 유지한다.

## 사람 플레이에서 확인할 점

자동 검증은 배치와 입력, 수치 정합을 보장하지만 아이콘을 처음 본 플레이어가 설명 없이 위력·관통·명중을 얼마나 빨리 구분하는지는 판단하지 못한다. 다음 플레이에서는 첫 1~2교전의 해석 속도, 후반 6장 비교 피로, 갤럭시 화면에서의 실제 크기를 확인한다.
