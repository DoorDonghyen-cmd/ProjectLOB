# 전투 UI 텍스트 밀도 정리

사용자는 현재 그래픽 방향을 긍정적으로 평가했고 텍스트 과밀을 지적했다. 기존 UI 변경 위임과 이번 요청에 따라 현재 Godot 그래픽·규칙을 유지하며 정보 계층을 정리한다.

## 배치

```text
LAST ON BOARD / 01·07                 정보  규칙  메뉴
총기 · 턴                              (시드/파츠 설명은 정보)
┌ 거리 전장 / 적 실루엣 / HP / 장갑·회피·접근 ─────────┐
└ 행동 중 짧은 결과만 표시 ──────────────────────────┘
┌ 보유 탄환 ─────────────────┐ ┌ 발사 순서 ──────────┐
│ 아이콘 + 이름/수량           │ │ 1 → 2 → 3 → 4       │
│ 한 줄 효과                  │ │ 연결 화살표         │
│ [선택 탄환 수치 한 곳 표시]  │ │ 첫 발 결과 요약     │
│ 다음 보충: 두 탄환           │ │ 취소 / 확정 또는 발사│
└────────────────────────────┘ └─────────────────────┘
```

- 카드마다 반복되던 피해/관통/명중을 포인터 또는 키보드 포커스가 놓인 탄환의 공용 정보줄로 옮긴다. 클릭 가능한 `정보` 창에도 모든 현재 탄환 수치·효과, 적 세부 수치, 덱/시드/파츠와 최근 결과를 제공한다.
- 빈 탄창의 중복 설명, 바닥 로그, 평상시 전장 설명, 조우 설명을 기본 화면에서 덜어낸다. 최초 장전 안내 한 줄과 첫 발 예측·행동 비용·재장전 위험은 유지한다.
- 보상 화면에서 기본/현재 스탯 중복과 전체 덱 나열을 정리한다. 제거 선택과 보상 기능은 유지한다.
- 기존 개발자 테스트의 장전/보상/최종 교전 바로가기를 유지한다. 작은 창에서는 기존 스크롤/스트레치 동작을 보존한다.

## 검증과 전달

기존 화면·연출·전체 UI 검증, 포커스로 탄환 수치 확인/정보 창 열기 및 닫기 확인, 실제 렌더 캡처 검토. 규칙 모델은 변경하지 않는다. 별도 Windows 폴더에 빌드하여 이전 실행 파일을 보존한다. 작업 기록과 로컬 커밋까지 완료한다.
