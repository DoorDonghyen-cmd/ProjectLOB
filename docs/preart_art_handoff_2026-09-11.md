# 아트 제작 인계 규격

> 개편판 최신 UI·적 규칙·화면별 에셋 목록은 [2026-09-20 UI·아트 인계](preart_ui_art_handoff_2026-09-20.md)를 우선한다. 아래 내용은 기존 제작본 13종 리소스 계약의 역사 기록이다.

## 제품 방향

핵심은 공개된 적 정보에 맞춰 탄환의 역순 장전을 설계하고 결과를 확인하는 전술 로그라이크다. 기계화가 계급을 결정하는 도시를 아래에서 위로 오른다. 무드는 비장함과 고독이며 필수 서사는 짧게 유지한다.

아트 작업은 기능 검토와 분리한다. 이 인계 문서와 검토용 빌드가 생겼다고 핵심 재미·모바일 사용성 검증까지 완료된 것은 아니다. 최신 판정은 `walkthrough_preart_completion_2026-09-11.md`를 따른다.

## 고정할 리소스 계약

| 대상 | 규격/연결 | 교체 후 확인 |
|---|---|---|
| 적 13종 | `resources/enemies/*.tres`의 `icon`, `visual_height`, `visual_ground_offset_y` | alpha 하단 자동 정규화, 기본 높이 64px/최대 표시 너비76px, 부유 높이는 명시적 설정 |
| 탄환 19종 | `resources/bullets/*.tres`의 `icon`, 기존 128×128 PNG 계약 | 우상단 사선 구도, 기존 전문축 배지와 식별, 작은 실린더/48px 카드 모두 판독 |
| 5계층 배경 | 960×540 기준, 화면 비율 확장 대응 | 적/명중 예고/패 카드 뒤의 명도 대비, 계층 팔레트 구분 |
| 모션·효과 | 전투 정산 완료 후 시각 재생 | 연발 잔탄 이월, 마지막 적 사망 후 보상, 입력 잠금 해제 |

적 원본 PNG는 UI가 수정하거나 저장하지 않는다. 투명 여백이 있는 원본도 `AtlasTexture` 표시 영역으로 정규화한다. HP/상태 배지/선택 영역은 아트의 숨쉬기 변형에서 분리되어 있다. 동거리 적은 같은 바닥선의 수평 슬롯으로 구분하며 논리 거리 수치는 바뀌지 않는다.

## 제작 항목

- 일반/변종 9종과 보스4종의 기계화율별 실루엣. 돌격=낮고 긴 형태, 방패=넓은 벽, 회피=얇은 윤곽, 술사=부유체, 흡수체=구체, 태세병=분리 드론.
- 계층 팔레트: 침전 갈색, 공역 주황, 정비 청록, 관리 청백, 정점 자홍.
- 최종 삽탄·격발·피격·재장전·보상 SFX 및 BGM 제작/연동.
- 최종 제목/로고. 현재 실행 이름 Last on Board는 가제다.

## 검수 화면

### 2026-09-21 다수전 추가 계약

- 한 화면의 전열은 최대 4기이며 서로 다른 네 레인과 충분한 터치 영역을 가져야 한다.
- 대기 증원은 오른쪽 위에 0.42배 실루엣으로 보인다. 적 종류는 24~32px에서도 외곽 형태만으로 구분되어야 한다.
- 적 아트 주변에는 HP 막대와 HP·거리·접근 수치가 붙으므로 얼굴과 무기 윤곽은 라벨과 겹치지 않는 중심부에 둔다.
- 증원 진입은 화면 오른쪽에서 짧게 이동하고 한 번 맥동한다. 등장 행동에는 적의 이동·공격 연출을 재생하지 않는다.
- 보스는 전열 앵커로 일반 적보다 크게 보이되, 함께 나오는 호위 3기와 터치 영역이 겹치지 않아야 한다.
- 최종 아트 교체 후 1008×630에서 전열 4기, 증원 4기, HP·거리·상태가 동시에 판독되는지 확인한다.

[다수전 QA 캡처](qa/reports/horde_reinforcement_ui_2026-09-21.md)를 최신 전투 배치 기준으로 사용한다.

2026-09-11 전술 작업대 후속: 장전 화면은 뷰포트 내부12px 여백에 적 정보·발사 순서·후보 탄·고정 하단 버튼을 함께 배치한다. 기본5발은42px 행으로 모두 보이며 긴 탄창은 스크롤한다. 전장 적은 인접 거리도 선택 영역 간격을 확보하고 개별 거리 라벨을 표시한다. [최신 기능·검증 보고](walkthrough_tactical_workbench_2026-09-11.md)를 함께 확인한다.

개발자 메뉴의 관리/정점 편성 QA, 탄환 카드 가독성 QA, 패 보충 연출 QA, 장전 안내 QA, 수집 기록 QA를 사용한다. 실제 렌더러 캡처는 `tools/run_preart_checks.ps1 -Mode visual`로 생성한다.

Windows 검토용 실행 파일은 `tools/export_windows_preart.ps1`로 다시 만든다. 기존 Android/Web/iOS 내보내기 설정은 임시 Windows preset 추가 후 원상 복원한다. APK 실기 검증 및 배포 서명은 별도이며 Windows 빌드 통과로 대체하지 않는다.
