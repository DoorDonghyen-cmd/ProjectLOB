# 플레이테스트 로그 가이드

> **도입일**: 2026-08-01
> **파일 형식**: JSON (`schema_version: 1`)

## 사용법

1. 평소처럼 새 런을 시작한다.
2. 각 전투 종료 시 현재 런의 JSON 파일이 자동 갱신된다.
3. 메인 화면의 `개발자 테스트` 메뉴에서
   `플레이테스트 로그`를 누르면 저장 폴더가 열린다.
4. 가장 최근의 `playtest_run_*.json` 파일을 공유한다.

Windows 기본 저장 위치:

```text
%APPDATA%\Godot\app_userdata\Last on Board\playtest_logs
```

## 기록 범위

- 런: 시작·종료 시각, 승패, 구역·층·노드, 승천, 침투 위험도
- 로드아웃: 총기, 기본탄, 전투 시점 장착 파츠, 전술탄 보유량
- 전투: 적 구성·시작/종료 상태, 발사·리로드·처치·최소 접근 거리
- 탄환: 탄 ID, 발사·명중·유효 적중 횟수, 주 대상 피해
- 탄종: 집중 진행 이벤트와 실제 폭발, 소총 관통, 산탄 확산
- 파츠: 효과 이벤트, 명시된 DMG·ACC·PEN 보너스, 원문 전투 로그

`focus.events`는 1/3·2/3 진행 표시까지 포함하고,
`focus.triggers`는 추가 피해가 실제로 발생한 폭발만 세므로 주의한다.

## 운영 원칙

- 로그는 로컬에만 저장되며 자동 업로드하지 않는다.
- 게임 세이브와 분리되므로 `전부 초기화`는 플레이테스트 로그를 삭제하지 않는다.
- 파일은 런 시작 즉시 생성되고 각 전투 종료마다 전체 보고서를 다시 저장한다.
- 강제 종료되어도 마지막으로 완료한 전투까지는 보존된다.
