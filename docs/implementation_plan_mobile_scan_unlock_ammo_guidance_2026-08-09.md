# 모바일 스캔·해금 표기·조합탄 전술 예고 구현 계획

> 상태: 구현 및 자동 검증 완료
> 범위: 버그 #018, 버그 #017, 조합탄 선택 다양성 1단계
> 비범위: 드래프트 가중치, 시작 패키지, 탄환 수치 변경

## 1. 목표

- 모바일에서도 미지 노드의 스캔 정보를 확인한 뒤 같은 노드 진입을 확정할 수 있게 한다.
- 제압형 해금 시 디브리핑에 `알 수 없음` 대신 정본 무기명을 표시한다.
- 연계탄 6종이 모두 `[연계]`로만 보이는 문제를 해결하고, 현재 적재 순서에서 실제로 명중·관통 게이트를 바꾸는 발수를 예고한다.
- 모든 예고는 현재 데이터와 결정론 규칙에서 계산하며 자동 장전·추천 순서는 제공하지 않는다.

## 2. UI 및 상호작용

### 2.1 미지 노드 모바일 스캔

데스크톱은 기존 호버 후 한 번 클릭을 유지한다. 터치 또는 호버 없이 접근한 입력은 첫 탭으로 스캔 패널을 열고, 같은 노드를 다시 탭하면 이동을 확정한다. 다른 노드를 탭하면 선택 대상만 바뀌고 아직 이동하지 않는다.

```text
┌──────────── 침투 지도 ────────────┐
│          [? 미지 노드]             │
│                ▲ 첫 탭             │
│  ┌─────────────────────────────┐  │
│  │ 생체 신호 다수 · 위험 HIGH   │  │
│  │ 같은 노드를 다시 탭해 진입    │  │
│  └─────────────────────────────┘  │
└──────────────────────────────────┘
```

상태 규칙:

1. 데스크톱 호버: 스캔 표시, 클릭: 즉시 이동.
2. 터치 첫 탭: 스캔 표시 및 해당 노드 준비 상태.
3. 준비된 같은 노드 두 번째 탭: 이동 확정.
4. 다른 노드 탭·맵 갱신·패널 이탈: 이전 준비 상태 해제.
5. 팝업은 계속 `MOUSE_FILTER_IGNORE`를 유지해 뒤쪽 입력을 막지 않는다.

### 2.2 제압형 해금 표기

레이아웃은 바꾸지 않는다. 디브리핑의 로컬 `match` 복사본을 제거하고 준비실 `WEAPON_PROFILES`에서 무기명을 조합하는 공용 조회 함수를 사용한다.

```text
🆕 인간용 화기 사용법을 익혔다
  ★ 제압형 (SUPPRESSOR) — 다음 상승부터 고를 수 있다.
```

알 수 없는 키는 크래시하지 않고 키 자체를 표시하는 안전 폴백을 둔다.

### 2.3 조합탄 효과 범위 배지

`BulletRoleUI`를 사용자 문구의 단일 정본으로 확장한다.

| `scope` | 표시 배지 | 의미 |
| :--- | :--- | :--- |
| `next_shot` | `[다음 1발]` | 바로 뒤의 한 발만 강화 |
| `target` | `[대상 지속]` | 명중한 적의 현 교전 스탯을 지속 약화 |
| `remaining_mag` | `[잔여 탄창]` | 뒤에 남은 모든 탄환 강화 |

드래프트 카드:

```text
┌──────── 표식탄 ────────┐
│ [연계]  [다음 1발]      │
│ DMG 1  ACC 7  PEN 1    │
│ 명중 +3                 │
└────────────────────────┘
```

가방·적재 카드:

```text
┌ 천공탄 ─────────────────┐
│ [연계] [다음 1발]  x2   │
│ DMG 1  ACC 7  PEN 2     │
└─────────────────────────┘
```

좁은 전투 실린더는 폭 증가를 막기 위해 `[1발]`, `[대상]`, `[잔탄]` 축약 배지를 사용하고 전체 문구는 툴팁에 제공한다. 드래프트·가방·장전 스택에는 전체 배지를 표시한다.

### 2.4 현재 적재 기여 예고

장전 화면의 탄창 목록 아래에 한 줄짜리 `연계 예고` 영역을 추가한다. 삽탄·제거·순서 변경 때마다 다시 계산한다.

```text
┌────────── LIFO 탄창 ──────────┐
│ 1  천공탄   [연계][다음 1발]   │
│ 2  공격탄   [공격]             │
│ 3  공격탄   [공격]             │
├───────────────────────────────┤
│ 연계 예고: 관통 전환 1발       │
└───────────────────────────────┘
```

표시 문구:

- `명중 전환 N발`
- `관통 전환 N발`
- `발동 불가 · 선행탄 게이트 실패`
- `현재 대열 게이트 전환 없음`
- 연계탄이 없으면 예고 영역을 숨긴다.

계산 계약:

1. 실제 LIFO 격발 순서와 현재 최근접 강제 타깃을 사용한다.
2. `next_shot`은 바로 뒤 1발, `remaining_mag`는 이후 전탄, `target`은 이후 전탄을 현재 타깃 기준으로 검사한다.
3. 효과 적용 전에는 실패하고 적용 후에는 성공하는 `ACC >= EVA` 또는 `PEN >= DEF`의 발수만 센다.
4. 효과탄 자체의 트리거가 현재 타깃에게 성립하지 않으면 발동 불가를 표시한다.
5. 처치 후 재타깃이나 조건부 파츠까지 자동 풀이하지 않는다. 실제 타깃이 바뀌면 현재 상태로 다시 계산한다.

## 3. 구현 구조

- `map_overlay.gd`
  - 현재 스캔 대상 버튼을 추적하고 미지 노드 선택을 2단계로 라우팅한다.
  - 호버·터치·맵 갱신에서 준비 상태를 명시적으로 초기화한다.
- `loadout_overlay.gd` / `debriefing_overlay.gd`
  - `weapon_display_name(key)`를 정본 조회 함수로 추가하고 디브리핑의 중복 `match`를 제거한다.
- `bullet_role_ui.gd`
  - 범위 정규화·전체/축약 배지·범위 도움말을 중앙 관리한다.
- 신규 순수 헬퍼 `ammo_guidance.gd`
  - 현재 총기, 적, LIFO 탄열을 받아 게이트 전환 발수와 표시 상태를 계산한다.
  - UI 노드를 몰라 단위 테스트가 가능해야 한다.
- `reward_draft_panel.gd`, `bag_inventory_drawer.gd`, `combat_overlay_v2.gd`, `cylinder_view.gd`
  - 동일 헬퍼의 배지 문구를 사용하고 장전 화면의 기여 예고를 갱신한다.

## 4. 개발자 테스트 진입점

`🛠️ 개발자 테스트`에 `스캔·연계 예고 UI` 버튼을 추가한다.

- 선택 가능한 미지 노드가 있는 지도 상태로 즉시 진입한다.
- 전투 장전 화면에는 `[다음 1발]`, `[대상 지속]`, `[잔여 탄창]` 3종과 게이트 전환/비전환 사례가 포함된 탄환·적 구성을 제공한다.
- 한 진입점에서 모바일 두 번 탭과 LIFO 적재 예고를 연속 확인할 수 있게 한다.

## 5. 검증

- #018: 첫 탭은 이동하지 않고 패널만 표시, 같은 노드 두 번째 탭은 정확히 한 번 이동, 다른 노드 탭은 대상만 교체.
- #017: `suppressor`가 `제압형 (SUPPRESSOR)`로 표시되고 전 프로필 키가 공용 조회에서 유효.
- 범위 UI: 6개 연계탄이 정확한 3개 범위 배지로 2종씩 분류.
- 기여 계산: 다음 1발·대상 지속·잔여 탄창별 0/N발, 선행탄 발동 실패를 결정론 테스트로 고정.
- UI 스모크: 드래프트·가방·적재·실린더 배지와 개발자 테스트 버튼 생성 확인.
- 전체 Godot 헤드리스 테스트, 스크립트 컴파일, 주요 씬 로드, 프로젝트 부팅 확인.

## 6. 완료 조건

- #017·#018을 `Verified`로 전환할 자동 회귀와 실제 UI 진입점이 존재한다.
- 조합탄 1단계가 완료되고 2단계 드래프트 다양성 이후 항목은 백로그에 남는다.
- 탄환·적·경제 수치는 변경하지 않는다.

## 7. 구현 결과 (2026-08-09)

- #018 모바일 미지 노드는 첫 탭 스캔·같은 노드 재탭 확정으로 전환했고, 데스크톱 호버·클릭 동작은 유지했다.
- #017 디브리핑 무기명은 준비실 프로필을 공용 조회하도록 단일화했다.
- 연계탄 6종에 `[다음 1발]`·`[대상 지속]`·`[잔여 탄창]` 배지를 적용하고 좁은 실린더에는 축약 배지를 적용했다.
- 현재 LIFO 탄열과 최근접 강제 타깃을 기준으로 `명중/관통 전환 N발`, 발동 실패, 전환 없음을 표시하는 순수 계산 헬퍼를 추가했다.
- 개발자 메뉴에 `스캔·연계 예고 UI` 통합 QA 진입점을 추가했다.
- 전체 Godot 헤드리스 검증: 2,799 통과 / 0 실패 / 기존 밸런스 경보 3, 스크립트 83개 컴파일·씬 4개 로드 성공.
- 드래프트 가중치·시작 패키지·탄환/적/경제 수치는 변경하지 않았으며 2단계 이후 다양성 개선은 백로그에 유지했다.
