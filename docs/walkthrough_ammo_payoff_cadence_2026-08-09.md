# 조합탄 결산 구조·2탄창 전투 호흡 구현 워크스루

> 완료일: 2026-08-09
> 계획서: `docs/implementation_plan_ammo_payoff_cadence_2026-08-09.md`
> 범위: 조합탄 선택 다양성 2단계 및 전투 호흡 회귀

## 완료 결과

연쇄탄과 교대탄이 이제 단순 공격탄이 아니라 연계 효과를 피해로 환산하는 `[결산]` 탄환으로 표시된다. 플레이어는 현재 LIFO 적재 순서에서 결산 성공 여부, 실패 조건, 예상 주 피해를 격발 전에 확인할 수 있다.

이번 단계는 새로운 피해 버프탄이나 적 체력 상향 없이 기존 결산 기능의 발견성과 조합 선택 구조를 개선했다. 탄환·총기·적 수치와 시작 패키지는 변경하지 않았다.

## 주요 구현

### 결산탄 공용 언어

- 연쇄탄·교대탄을 공용 `[결산]` 분류로 판별한다.
- 드래프트, 가방, 탄창, 적재 스택에서 동일한 배지와 조건 툴팁을 사용한다.
- 기존 `[공격]` 역할은 유지하고 `[결산]`을 보조 전술 태그로 추가했다.

### LIFO 결산 예고

- 현재 적재 순서를 실제 발사 순서로 순차 시뮬레이션한다.
- 직전 유효 적중과 직전 역할 교대 조건을 각각 판정한다.
- 결산 성공 시 예상 주 피해와 결산 추가 피해를 표시한다.
- 실패 시 `직전 유효 적중 필요`, `역할 교대 필요`, 명중·관통 부족을 구분한다.
- 집중, 파츠, 부가 대상 피해와 처치 연쇄는 계산 범위에서 제외해 수치를 `예상 주 피해`로 한정했다.

### 드래프트 다양성

- 덱에 연계탄이 있으나 결산탄이 없으면 다음 전투 보상 탄환 후보 중 1장을 연쇄탄/교대탄으로 보증한다.
- 이는 후보 노출 보증이며 획득 강제가 아니다. 다른 카드나 크레딧 선택은 계속 가능하다.
- 결산탄을 얻은 뒤에는 동일 탄 보유량에 따라 기본 추첨 가중치를 `3 → 2 → 1`로 낮춘다.
- 기존 컨버전 가중치는 곱하지 않고 독립 우선순위로 유지해 확률 폭증을 막았다.

### 전투 호흡 회귀

- Tempo에 연계·결산탄과 기본탄을 LIFO 순서로 적재한다.
- 돌격병·회피병·방패병 혼합 편성에서 첫 탄창이 앞의 고속 적 둘을 정리하는지 검증한다.
- 방패병은 생존하고 4m 전진하며, 전투가 종료되지 않은 채 재장전 뒤 `LOADING` 단계로 돌아오는 것을 고정했다.

## 개발자 QA

메인 화면 개발자 메뉴에서 `스캔·연계·결산 QA`를 선택하면 Tempo, 결산탄 포함 덱, 혼합 적 편성으로 바로 진입한다.

확인 순서:

1. 가방과 적재 스택에서 연쇄탄·교대탄의 `[결산]` 배지를 확인한다.
2. 표식탄 뒤 연쇄탄, 역할이 다른 탄 뒤 교대탄을 적재한다.
3. `연계·결산 예고`에서 성공 여부와 예상 주 피해를 확인한다.
4. 첫 탄창 격발 뒤 방패병이 남고 두 번째 적재 판단 단계로 돌아오는지 확인한다.

## 검증 결과

- 전체 Godot 헤드리스 회귀: **2,827 통과 / 0 실패**
- 기존 밸런스 경보: **3건 유지**
- 추가 고정 범위: 결산 분류·툴팁, 성공/실패 피해 예고, 첫 후보 보증, 보유량 가중치, 주요 UI 배지, Tempo 2탄창 생존 시나리오

## 후속 범위

- 시작 전술탄 패키지의 세 역할 분산은 3단계로 보류한다.
- 실제 플레이 로그에서 결산탄 선택률과 유효 기여를 확인한 뒤에만 탄환 수치를 검토한다.
- 일반 혼합 편성 2탄창, 엘리트 2~3탄창, 보스 장기전이라는 목표 호흡은 이후 플레이테스트에서 계속 관측한다.
