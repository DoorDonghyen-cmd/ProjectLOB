# 표준 규격 3종·전용 규격 2종 및 역할 전환 구현 계획

> 날짜: 2026-07-28
> 세션 ID: `codex0728-fixed-caliber`
> 배경: 첫 구역 플레이테스트에서 탄환과 구경의 차이가 약하고, 파츠가 주 덱빌딩 축이어야 한다는 피드백

## 목표

1. 구경을 런 중 갈아타는 선택이 아니라 총기 선택 시 고정되는 탄도 성향으로 만든다.
2. 다른 구경 기반탄이 드래프트를 희석하지 않게 한다.
3. 구경 교차에 의존하던 LIFO 효과를 공격·연계·제어 역할 전환으로 이관한다.
4. 파츠를 주 빌드 축, 탄환을 전투 시퀀스 축, 구경을 출발 성향으로 위계화한다.
5. 초반에는 표준 규격 3종만 학습시키고, 특수 총기 전용 규격 2종은 해금 시 공개한다.
6. 현실 구경명보다 역할명을 먼저 노출하고 실제 구경은 보조 기술 규격으로 남긴다.

## 규칙

| 플레이어 명칭 | 기술 규격 | 공용 전술탄 보정 |
|---|---|---|
| 경량탄 | 9mm | ACC +1 |
| 중량탄 | .45ACP | DMG +1 |
| 소총탄 | 5.56mm | PEN +1 |
| 저격탄 | 7.62mm | DMG/PEN +1, ACC −1 |
| 산탄 | 12게이지 | DMG +1, PEN/ACC −1 |

- 프로필은 `UNIVERSAL` 전술탄에만 적용한다. 기반탄에는 중복 적용하지 않는다.
- 표준 규격은 경량탄·소총탄·산탄의 3종이다.
- 중량탄은 Tempo/Gambler, 저격탄은 Marksman과 함께 공개되는 총기 전용 규격이다.
- 9mm·5.56mm·12게이지·.45ACP·7.62mm는 괄호 안 보조 기술 규격으로 유지한다.
- 내부 5개 클래스와 스탯은 유지하고, UI와 문서에서 학습 위계만 3+2로 분리한다.
- 보상 후보는 현재 총기의 기반탄 1종 + 공용 전술탄 14종이다.
- `.45ACP` 기반탄은 3→4 피해로 올려 9mm와 명중↔피해 교환을 만든다.
- 교차탄은 저장 호환을 위해 ID `crosscal`을 유지하되 ‘교대탄’으로 바꾸고 역할 전환 시 발동한다.
- 인터럽터·만능 약실은 역할 전환, 리듬 챔버는 동일 역할 유지에 반응한다.
- 컨버전 킷은 리소스·레거시 계약만 보존하고 현행 콘텐츠에서는 비활성화한다.

## 구현 범위

- `CaliberProfiles` 정본 추가 및 명중·피해·관통·넉백·UI 유효 스탯 계산에 연동
- 전투의 구경 기억 상태를 역할 기억 상태로 교체
- 보상 드래프트 후보 제한 및 카드 유효 스탯 표시
- 준비실 총기 설명, 탄환/파츠 리소스와 CSV, GDD 동기화
- 준비실과 탄환 갤러리의 규격 표시를 `표준 규격`/`전용 규격` 단일 정본으로 통일
- 7.62 보안 게이트를 표시명 휴리스틱에서 실제 DMR 클래스로 교체
- 고정 프로필·드래프트·역할 파츠·게이트 회귀 테스트 추가

## 검증 기준

- 표준 3종·전용 2종의 역할명/기술 규격 매핑과 5개 프로필의 정확한 정수 보정
- 기반탄 비중복
- 각 클래스 드래프트 15종 및 타 구경 기반탄 배제
- 샷건 넉백 이중 가산 없음
- 교대탄·인터럽터·만능 약실·리듬 챔버의 역할 순서 판정
- DMR만 7.62 게이트 개방
- 전체 Godot 헤드리스 회귀 실패 0
