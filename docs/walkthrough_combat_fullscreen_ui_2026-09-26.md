# 전투 전체 화면 UI 개편

## 결과

전투 화면을 `상태 바 → 전장 → 전술 콘솔`의 세 구역으로 다시 구성했다. 1008×630 모바일 가로 화면에서도 스크롤 없이 적 진형, 탄환 선택, 발사 순서와 행동 버튼을 동시에 볼 수 있다.

![6칸 탄창 모바일 전투](qa/reports/combat_fullscreen_ui_2026-09-26_assets/combat_phone_six_slot.png)

## 변경 내용

- 두 줄이던 전투 헤더를 위치, 무기, 턴·적·증원, 재화, 전투 메뉴가 들어간 한 줄 상태 바로 압축했다.
- 전장을 실제 높이에 맞춰 그리도록 바꾸고 모바일에서 플레이어·사선·적 진형의 비율을 조절했다.
- 하단을 탄환 선택과 발사 순서의 좌우 패널로 고정했다. 발사·재장전은 오른쪽 하단에 고정해 탄환 수와 관계없이 위치가 유지된다.
- 압축·교환 도구를 탄환 선택 헤더로 옮기고 카드·탄창·예비 탄환을 모바일 전용 밀도로 표시한다.
- 뷰포트 높이가 700px 이하이면 전투 전용 축약 모드를 사용하고, 크기 변경 시 즉시 다시 배치한다.
- 작은 화면 검증에 세로 스크롤바와 핵심 전투 영역의 뷰포트 이탈을 검사하는 단언을 추가했다.
