# 탄환 v6 수치 튜닝 및 해법 존재 검사

> 작성일: 2026-07-27
> 상태: **수치 후보 검증 완료 · 런타임 마이그레이션 보류**
> 후보 CSV: `tests/reference/bullet_stats_v6_tuned_candidate.csv`
> 전수 결과: `tests/baseline/ammo_v6_tuning_matrix.json`

## 1. 결론

v6의 층 분리와 범용 보조탄 구조는 실제 9총기 × 13적 데이터에서도 해법을 만든다.
다만 초안 피해 `2/3/4/4/5`와 현행 총기 시그니처를 그대로 결합하면 총기 사이클 격차가 너무 크다.

다음 수치를 마이그레이션 후보로 사용한다.

| 기반탄 | 초안 DMG | 후보 DMG | PEN | ACC | 판단 |
|---|---:|---:|---:|---:|---|
| 9mm | 2 | **3** | 1 | 8 | 권총 사이클 바닥 보강 |
| .45ACP | 3 | **3** | 1 | 7 | 유지 |
| 5.56mm | 4 | **3** | 2 | 6 | 소총 3종 공통 과화력 완화 |
| 7.62mm | 4 | **4** | 3 | 5 | 유지 |
| 12게이지 | 5 | **5** | 0 | 5 | 거리 게이트를 대가로 유일 최대 피해 유지 |

후보 피해는 `3/3/3/4/5`다. 단순히 피해가 오를수록 명중이 내려가는 곡선보다
**실제 총기 사이클과 거리 도달성**을 우선했다.

## 2. 총기 사이클 재산출

파츠·적 게이트를 제외하고 총기 시그니처까지 포함한 한 사이클 피해다.

| 총기 | 후보 적용 전 규칙 | 후보 보정 후 | 판정 |
|---|---:|---:|---|
| revolver | 2.50 | 2.50 | 밴드 |
| trickster | 2.50 | 2.50 | 밴드 |
| Tempo | 3.00 | 3.00 | 밴드 |
| gambler | **6.43** | **2.71** | 시그니처 보정 필요 |
| heavy | 3.00 | 3.00 | 밴드 |
| stance_hunter | 2.14 | 2.14 | 하한 |
| suppressor | **3.75** | **3.00** | 리로드 보정 필요 |
| dmr | 3.20 | 3.20 | 밴드 |
| shotgun | **4.17** | **4.17** | 거리 게이트 예외 |

기준 밴드: `2.14~3.33 DMG/턴`.

### 도박형 보정

```text
passive_dmg_bonus: +2 → 0
깊이 보너스: depth × 2 → floor(depth / 2)
5발 보너스: [8, 6, 4, 2, 0] → [2, 1, 1, 0, 0]
```

블라인드 예고창과 5개 파츠 슬롯이라는 장점은 유지하면서, 탄환 피해보다 총기 보너스가 더 큰 상태를 제거한다.

### 제압형 보정

```text
reload_turns: 3 → 4
5발 전탄 커밋 + 4턴 리로드 = 5턴 사이클
```

5발 계획 깊이는 보존하고 리로드 공백으로 과화력을 지불한다. 적용 시 `GunData.reload_turns` 편집 범위를
`1~3`에서 `1~4`로 확장해야 한다.

### 샷건 예외

12게이지를 4로 낮추면 종이 DPT는 3.33이 되지만 유일 최대 피해 정체성이 사라진다.
실제 샷건은 시작 거리에서 원거리 ACC−4를 받아 기반탄 직통이 **0/13**이므로 4.17이 그대로 실현되지 않는다.
따라서 DMG 5를 유지하고 거리 게이트를 명시적 비용으로 본다.

## 3. 적 게이트 정규화 전제

v6 계약의 DEF 상한 3을 시뮬레이션에 적용했다.

- CSV DEF 4~5: 흡수체·디렉터·오메가를 3으로 정규화
- 하드코딩 DEF 4: 교란 드론·2단 철갑 태세를 3으로 정규화
- 하드코딩 DEF 5: 오메가 철갑 태세를 3으로 정규화
- EVA 9 나노 스토커는 시그니처 적으로 유지

정적 CSV만 바꾸고 태세 하드코딩을 남기면 v6 게이트 사다리가 전투 중 다시 깨지므로 함께 마이그레이션해야 한다.

## 4. 9총기 × 13적 해법 검사

각 총기의 최대 탄창에 다음 탄을 배치한 모든 고유 발사 순서를 조사했다.

- 해당 총기의 기반탄: 중복 허용
- 보조탄 6종: 각 1발
- 기본 거리와 환기구 `−2m`를 별도 실행
- 단발은 매 격발 후 전진, 연발은 버스트 종료 후 1회 전진
- 처치하지 못해도 유효 진행 후 리로드를 생존하면 다음 사이클 해법으로 인정

결과:

| 검사 | 결과 |
|---|---:|
| 일반 적 9총기 × 8종 무해법 | **0건** |
| 시그니처 적 최소 안전 진행 실패 | **0건** |
| 지원탄만으로 막혀 제어탄이 필요한 조합 | **1건** |
| 9총기 전체를 지배하는 동일 지원 패키지 | **없음** |

유일한 제어탄 필수 조합은 **샷건 → 방패병**이다. 지원탄 화력만으로는 태세 전환 뒤 리로드 전에
거리가 닫히지만, 충격탄 또는 점착탄을 배치하면 환기구에서도 다음 사이클을 확보한다.
이는 제어탄이 단순 저화력 카드가 아니라 샷건의 생존 빌드 축으로 기능한다는 뜻이다.

> 이 검사는 1대1 게이트·거리 해법 검사다. 세라프와 L.O.B의 실제 호위 대열은 기존
> `suite_boss_gimmicks` 및 보스 대열 QA와 별도로 v6 마이그레이션 후 다시 검증해야 한다.

## 5. 첫 무기고 전 시작 덱

현행 수량 구조인 `기반탄 + 특수A 2발 + 특수B 1발`을 유지하고,
보조·제어탄 후보 8종의 A×2+B×1 조합 56개를 클래스별로 전수 탐색했다.

| 클래스 | 시작 패키지 후보 | 담당 |
|---|---|---|
| 권총 | 천공탄 ×2 + 파쇄탄 ×1 | 낮은 PEN 보완 |
| SMG | 천공탄 ×2 + 파쇄탄 ×1 | 낮은 PEN·Tempo 방패병 사이클 보완 |
| 소총 | 천공탄 ×2 + 표식탄 ×1 | 5.56의 DEF3·EVA7 양축 보완 |
| DMR | 천공탄 ×2 + 파쇄탄 ×1 | 기본 해법은 충분하되 초반 장갑 안정성 확보 |
| 샷건 | 천공탄 ×2 + 충격탄 ×1 | 장갑 개방 + 리로드 생존 거리 |

러셔·방패병·회피병을 기본 거리와 환기구 거리에서 검사한 결과 **27개 총기×적 조합 모두 해법 존재**다.

## 6. 마이그레이션 전 런타임 차단 항목

수치가 아니라 현재 코드가 문서 계약과 다른 결함 2건을 발견해 별도 등록했다.

1. **#009 흡수체 배리어** — 관통 실패 피해 0 명중에도 셀이 감소해 총 피해 0으로 처치 가능
2. **#010 태세 사냥꾼** — `shot_counter == 2` 하드코딩 때문에 2발 주기 오메가에는 파훼 미발동

두 결함을 먼저 수정하고 회귀를 고정해야 v6 매트릭스와 실제 런타임이 같은 계산을 사용한다.

- 클래스별 시작 패키지

- 제압형 리로드 4턴

- 실제 `bullet_stats.csv`와 `.tres` 교체
- 신규 효과 enum 9~11과 크리티컬 런타임
- 시작 덱·상점·프리로드 ID 마이그레이션
- #009·#010 런타임 수정

다음 작업은 #009·#010을 먼저 닫은 뒤, 본 후보를 사용해 v6 데이터·런타임을 한 번에 마이그레이션하는 것이다.
