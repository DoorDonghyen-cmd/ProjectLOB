# 갤럭시 전투 UI 테스트판 설치

파일: **LastOnBoard-city.apk** · 앱: **Last on Board Test** · 버전: **0.4.20260926**

1. APK를 USB, Quick Share 또는 클라우드로 갤럭시의 다운로드 폴더에 옮긴다.
2. **내 파일 → 다운로드**에서 APK를 눌러 설치한다.
3. 설치 권한을 요청하면 APK를 여는 앱의 `출처를 알 수 없는 앱 설치`를 허용한다.
4. 기존 **Last on Board Test**가 있으면 삭제하지 않고 업데이트 설치해 저장을 유지한다.
5. 앱을 실행하면 가로 화면으로 플레이한다.

이번 버전은 개편된 타이틀·출격 준비·총기 선택과 전체 화면 전투 UI를 포함한다. 모바일 가로 화면에서 상태 바, 전장, 탄환 선택, 발사 순서, 발사·재장전을 한 화면에 표시한다. 관문 영구 압축과 전투당 1회 현장 압축도 사용할 수 있다.

빠른 확인은 메인 메뉴의 **훈련 → 무기 선택 → 출격**에서 할 수 있다. 압축 확인은 **개발자 테스트 → 전투 중 임시 압축 UI**에서 같은 탄환 두 장을 서로 끌어 놓으면 된다.

기본 모드는 보행자·쇄도·산개·압쇄·증강과 맵·상점·이벤트·관문을 포함한 5계층 35층 등반이다. 패키지명과 로컬 테스트 인증서는 이전 APK와 같으며 인터넷·외부 저장소 권한을 사용하지 않는다.
