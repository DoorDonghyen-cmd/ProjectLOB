# 갤럭시 현장 압축 테스트판 설치

파일: **LastOnBoard-city.apk** · 앱: **Last on Board Test** · 버전: **0.4.20260920**

1. APK를 USB, Quick Share 또는 클라우드로 갤럭시의 다운로드 폴더에 옮긴다.
2. **내 파일 → 다운로드**에서 APK를 눌러 설치한다.
3. 설치 권한을 요청하면 APK를 여는 앱의 `출처를 알 수 없는 앱 설치`를 허용한다.
4. 기존 **Last on Board Test**가 있으면 삭제하지 않고 업데이트 설치해 저장을 유지한다.
5. 앱을 실행하면 가로 화면으로 플레이한다.

이번 버전은 관문 영구 압축과 전투당 1회 현장 압축을 포함한다. 전투 패에 같은 일반 전술탄 두 장이 남으면 두 카드에 청록 모서리와 연결 표시가 나타난다. 짧게 누르면 한 발을 장전하고, 한 장을 같은 탄환 위로 끌어 놓으면 임시 압축탄으로 합쳐져 자동 배치된다. 다른 탄환 위에 놓으면 아무 행동도 하지 않는다.

빠른 확인은 메인 메뉴의 **개발자 테스트 → 전투 중 임시 압축 UI**에서 할 수 있다. 증폭탄 또는 연발탄 두 장 중 한 장을 같은 이름의 다른 장 위로 끌어 놓는다. `끝 탄 회수`를 누르면 장전 확정 전에는 원본 두 발과 압축 충전, 패 교환이 복구된다.

기본 모드는 보행자·쇄도·산개·압쇄·증강과 맵·상점·이벤트·관문을 포함한 5계층 35층 등반이다. 패키지명과 로컬 테스트 인증서는 이전 APK와 같으며 인터넷·외부 저장소 권한을 사용하지 않는다.
