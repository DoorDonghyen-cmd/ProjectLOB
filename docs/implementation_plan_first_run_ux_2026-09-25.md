# 첫 등반 UX 후속 개선 계획

## 목적

거시 UI/UX 개편 뒤 첫 등반 흐름을 공개 정보만으로 점검하고, 화면 구조가 아니라 실제 작업 연속성을 막는 문제를 수정한다.

## 블랙박스 반복 신호

- 지도, 전투, 보상, 상점의 다음 행동은 새 화면 구조에서 구분된다.
- 보관함에서 파츠를 바꾸면 작업실이 다시 열리면서 `착용 중` 탭으로 돌아가 작업 맥락이 끊긴다.
- 상점 구매 직후 결과는 적용되지만 플레이어가 현재 빌드 띠를 다시 읽어야 변화를 확인할 수 있다.

## 구현

1. 빌드 작업실이 장착 변경 전의 활성 탭을 기억한다.
2. 장착·해제 뒤 작업실 상단에 한 줄 결과 피드백을 표시한다.
3. 상점 구매, 압축 코어 충전, 리롤 직후 상단에 결과 피드백을 표시한다.
4. 탭 유지와 피드백을 실제 UI 회귀에 추가한다.

## 완료 기준

- 보관함에서 장착·해제 후에도 보관함 탭이 유지된다.
- 상점 구매 직후 첫 화면에 구매 결과와 적용 위치가 표시된다.
- 기존 저장, 전투, 캠페인 진행이 바뀌지 않는다.
