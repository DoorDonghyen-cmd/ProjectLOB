# 렐릭 시스템 제거 워크스루

## 완료 결과

- 독립 데이터 클래스 없이 문자열로 분산돼 있던 렐릭 상태를 `RunManager`, `CombatManager`, 전투 오버레이에서 제거했다.
- 전술 장갑의 재장전 감소와 가스 밸브의 넉백 증가 효과를 제거했다.
- 로드아웃 화면의 전술 렐릭 카드, 토글 상태, 탄창/예고창 보정 미리보기를 제거했다.
- 렐릭 개수 기반 크레딧 정산과 디브리핑 표시를 제거했다.
- 가스 밸브 전용 숨김 경로 3곳을 일반 공개 가스 제어 우회로로 전환해 기존 맵 연결을 보존했다.
- 구형 전투 UI의 적 스탯은 별도 장비 조건 없이 표시하도록 현재 V2 UI 정책과 맞췄다.
- 현행 GDD, 로드맵, UI 목업, 프로젝트 전용 에이전트 지침을 탄환·파츠 중심으로 갱신했다.
- `point_blank.tres`는 총기 고유 `PartData`이므로 유지하고 로드아웃 설명만 바로잡았다.

## 검증

- 런타임 및 현행 문서 검색: 렐릭 키워드와 `active_relics`, `tactical_gloves`, `gas_valve`, `smart_sensor_goggles` 잔존 없음.
- `CombatManager.start_encounter()` 선언 1곳과 호출 2곳의 인자 정합 확인.
- 전술 로드아웃 HTML JavaScript 구문 검사 통과: `TACTICAL_LOADOUT_JS_OK`.
- 작업 대상 파일의 `git diff --check` 통과.
- 기존 작업 트리의 탄환/넉백/관통 UI 변경은 보존됨.

## 검증 제한

현재 환경에서 Godot 실행 파일을 찾지 못해 엔진 헤드리스 파싱 및 실제 씬 실행은 수행하지 못했다.
