# 일반 전투 편성 밀도

> 적용일: 2026-08-01
> 상태: 1차 플레이테스트

탄종 행동의 차이를 실제 전투에서 드러내기 위해 일반 전투의 적 수를 단계적으로 늘린다.
적 스탯 인플레이션 대신 편성 밀도로 난도를 올리며, 보스전과 첫 구역 초반은 기존 학습 곡선을 유지한다.

| 구역 | 초반(T0) | 중반(T1) | 후반(T2) |
|---|---:|---:|---:|
| 침전 거주구 | 1~2체 | 2~3체 | 3체 |
| 공역 | 3체 | 3~4체 | 4체 |
| 정비 계층 | 3체 | 4체 | 4체 |
| 관리 계층 | 3체 | 4체 | 4체 |
| 정점 | 3체 | 4체 | 4체 |

## 보호 조건

- 보스 편성은 1차 조정에서 변경하지 않는다.
- 일반전 최대치는 4체로 제한한다. 5체 편성은 UI와 전투 로그를 확인한 뒤 별도로 검토한다.
- 같은 거리에 선 적은 전투 트랙에서 대각 편성 슬롯으로 분산해 선택 영역과 상태 배지가 완전히 겹치지 않게 한다.

## 검증 목표

- 소총탄 관통과 산탄 확산의 발동 기회가 늘어나는지 확인한다.
- 경량탄의 단일 대상 집중과 다른 탄종의 다수전 가치가 구분되는지 확인한다.
- 전투별 발사 수, 재장전 횟수, 최근접 거리, 탄종 효과 발동 수를 플레이테스트 JSON으로 비교한다.
- 4체 편성이 장기전이나 강제 재장전 패배를 과도하게 만들지 확인한다.
