# 조합탄 전문축 가독성·피해 증폭탄 구현 계획

## 목표

- 전술탄의 핵심 효용을 `ACC 명중 보정 / PEN 장갑 파훼 / DMG 피해 증폭 / CTRL 거리 제어`로 즉시 구분한다.
- 기본탄은 전술탄과 같은 전문축 배지를 쓰지 않고 `[기본탄] 고명중·고관통·고화력` 성향으로 표시한다.
- 기존 연쇄탄을 `장약 증폭탄`으로 전환해, 유효 적중 시 다음 1발의 주 피해를 2 높인다.
- 표식탄(ACC +3)·천공탄(PEN +3)·장약 증폭탄(DMG +2)이 같은 규칙의 3축 연계탄으로 읽히게 한다.

## 수치·동작 계약

| 탄환 | 발동 | 범위 | 효과 | 실패 시 |
|---|---|---|---|---|
| 표식탄 | 유효 적중 | 다음 1발 | ACC +3 | 버프 없음 |
| 천공탄 | 유효 적중 | 다음 1발 | PEN +3 | 버프 없음 |
| 장약 증폭탄 | 유효 적중 | 다음 1발 | DMG +2 | 버프 없음 |

- 다음 1발 버프는 해당 탄을 격발하는 순간 소비한다. 빗나감·도탄이어도 되돌아오지 않는다.
- DMG 버프는 명중·관통 판정을 우회하지 않으며, 관통에 성공한 주 피해에 더한 뒤 결정론적 치명타 배율을 적용한다.
- 재장전·교전 초기화 시 보류 중인 버프는 모두 소멸한다.
- 기존 `COMBO` enum과 런타임 처리는 구버전 데이터 호환용으로 보존하되, 현행 탄환에는 배정하지 않는다.

## 카드 와이어프레임

넓은 카드:

```text
┌────────────────────────────┐
│ 장약 증폭탄                 │
│ [DMG 피해 증폭]             │
│ 다음 1발 DMG +2             │
│ DMG 2   PEN 1   ACC 5       │
└────────────────────────────┘
```

기본탄 카드:

```text
┌────────────────────────────┐
│ 경량 표준탄                 │
│ [기본탄] 고명중              │
│ DMG 3   PEN 1   ACC 7       │
└────────────────────────────┘
```

좁은 탄창 슬롯:

```text
┌──────────┐
│ 장약 증폭 │
│ [DMG]    │
│ 다음 +2  │
└──────────┘
```

## UI 규칙

- 넓은 카드에서는 영문 축 코드와 한국어 효용을 함께 표시한다.
- 좁은 슬롯에서는 `ACC / PEN / DMG / CTRL` 코드만 표시하고, 툴팁에 전체 효용과 정확한 효과 문장을 제공한다.
- 전술탄 카드 테두리는 전문축 색을 재사용해 글자를 읽지 않아도 축이 반복 인지되게 한다.
- `공격 / 연계 / 제어` 운용 분류는 일반 카드에서 숨기고 툴팁 마지막 줄에만 둔다.
- 기존 `탄환 전문축 QA` 숏컷을 갱신해 기본탄과 세 연계축을 한 화면에서 비교할 수 있게 한다.

## 검증 범위

- 신규 DMG 버프 발동·소비·도탄·재장전 소멸·치명타 적용 순서 단위 테스트
- 탄창 조합 예고에서 ACC/PEN/DMG 축과 예상 피해 표시 검증
- 기본탄/전술탄 배지, 전체/축약 문구, QA 숏컷 UI 스모크 검증
- 탄환 CSV↔리소스 정합, 9총기×13적 기본/환기구 매트릭스, 전체 회귀 테스트
