# Core redesign — 독립 전투 / 짧은 런

사용자는 별도 브랜치·작업 폴더에서의 재설계와 UI 변경을 승인했고, 더 나은 판단을 만드는 규칙 변경도 위임했다. 기준 버전은 main `f5da527`, 개발은 `prototype/core-redesign`에서만 한다.

## 유지할 핵심
마지막 장전 → 첫 발사, 가까운 적 자동 표적, 공개 명중/관통 임계값, 거리 0 패배. 빌린 구형 화기로 기계화 계급 도시를 오르는 인간. 실행 결과에는 난수를 사용하지 않는다.

## 첫 실험의 규칙
- 7개 교전으로 학습 → 조합 성장 → 복합 시험을 완주한다. 두 총기의 시작 덱은 같다.
- 단발: 4칸, 발당 피해 +1, 사격 1턴 / 재장전 1턴. 일제: 4칸, 전탄 사격 1턴 / 재장전 3턴.
- 기본탄은 재장전마다 3발 복구. 전술탄은 5장 공개 패와 다음 2장 예고, 미사용 패 유지, 사용탄 순환. 후보의 다양성과 탄창의 순서는 별개다.
- 장전 계획은 무료 취소 가능. 확정 뒤에는 발사 또는 유료 재장전으로만 바꾼다. 중간 삽탄·무료 추출·긴급 격퇴는 이번 실험에서 제거하여 비용을 읽기 쉽게 한다.
- 8탄종: 기본 / 철갑 / 정밀 / 관통 준비 / 조준 준비 / 장약 준비 / 밀기 / 둔화. 준비탄의 다음 1발 효과는 명중 여부와 무관하게 발사 시 발생하고 다음 사격에 소비된다. 제어 효과는 명중해야 적용된다.
- 밀기는 탄창당 최대 2m. 둔화는 다음 전진 한 번에만 적용. 행동 없이 무한히 거리를 늘릴 수 없다.
- 보상은 탄환 추가, 덱 유지/정제, 한 칸 파츠 교체. 자동으로 전부 획득하지 않는다. 선택 전에 다음 교전과 전체 덱을 공개한다.
- 이미 재장전이 최소 1턴인 단발 총기에는 효과 없는 회수 가속기를 제시하지 않는다. 일제 총기는 이 파츠로 3 → 2턴이 된다.
- 독립 저장 파일, 같은 시드 재도전, 새 시드 시작, 개발자 전투/보상/최종전 숏컷을 제공한다.

## UI 와이어프레임 (1280 × 800, 작은 창에서는 전체 스크롤)
```
LAST ON BOARD       03 / 07 | 총기 | 시드       규칙 / 메뉴
교전명 · 짧은 상황 문장                 다음 행동의 시간 비용
┌ 적 카드: HP / 장갑 / 회피 / 속도 / 거리 / 다음 행동 후 거리 ┐
├ 공개 패 (왼쪽 55%) ─────────┬ 실행 순서 (오른쪽 45%) ───────┤
│ 기본 공급 / 전술탄별 남은 수 │ 1. 마지막 넣은 탄 ← 먼저 발사 │
│ 피해 · 관통 · 명중 · 효과    │ 2... / 최근 장전 취소          │
│ 다음 2장 / 남은 덱 / 버림    │ 다음 한 발 결과 · 전진 비용    │
├ 마지막 행동 결과와 원인 ────┴ 확정 / 발사 / 재장전 ─────────┤
```
화면은 자동 정답을 제시하지 않는다. 다음 한 발은 실제 정산과 같은 함수를 복제 상태에 실행해 예측하며, 일제 사격 전체 결과를 미리 풀어주지는 않는다. 여러 적의 거리는 개별 카드로 비교한다.

최종 렌더 검토 후 확정/발사/재장전 버튼은 오른쪽 발사 순서 패널 내부에 배치했다. 1280×800에서 주요 행동을 스크롤 없이 실행하며, 긴 일제 결과 설명은 아래 스크롤 영역에서 읽는다.

## 구현 경계
기존 Godot 프로젝트와 검증된 `DamageCalculator`, `BulletData`를 재사용한다. 독립 규칙 모델 / 콘텐츠 / 런 저장 / 새 화면은 `redesign/` 아래 둔다. 기존 2천 줄 전투 매니저의 메타·구경·해금 결합을 새 실험에 가져오지 않는다. main 진입점 변경은 worktree에만 적용한다.

## 완료 기준
- 두 총기에서 실제 교전으로 7교전 완주 가능한 경로를 검증한다(강제 승리 fixture 제외).
- LIFO, 임계값, 준비탄, 제어 상한, 비용, 덱 보존, 보상, 저장/재개를 자동 검증한다.
- 실제 렌더링과 버튼 조작으로 시작/장전/확정/사격/보상/재시도를 검증한다.
- 독립 QA 후 수정, 새 실행 파일과 비교 설명을 제공한다.
- 자동 승리율을 사람의 재미로 표현하지 않는다. 사람의 선택감·피로·재도전 의사는 후속 검증이다.
