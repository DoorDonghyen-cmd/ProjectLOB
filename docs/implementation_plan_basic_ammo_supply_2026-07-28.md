# 기본탄 고정 보급 슬롯 구현 계획

> 날짜: 2026-07-28
> 상태: 구현 및 자동 검증 완료
> 정본: `docs/gdd/22_ammo_expansion.md` §22.5~22.6

## 목표

기본탄을 런 덱의 수량 카드에서 총기 고정 보급원으로 분리한다. 장기 고갈은 제거하되
한 재장전 사이클의 탄창·거리·LIFO 제약은 유지해, 파츠를 주 빌드 축으로 두고 전술탄을
게이트 해법으로 명확히 분리한다.

## 확정 계약

- 가방에 기본탄 고정 슬롯을 정확히 1칸 표시한다.
- 보급 상한은 `magazine_capacity + (has_chamber ? 1 : 0)`이다.
- 전투 시작과 리로드 완료 시 기본탄을 상한까지 맞춘다.
- 기본탄을 상한만큼 추가하지 않으며 초과 누적하지 않는다.
- 실제 탄창에서는 기본탄도 발당 1칸을 차지하고 LIFO 순서를 따른다.
- 기본탄은 런 덱·드래프트·상점 보상에서 제외한다.
- 전술탄의 유효타 순환과 실패 영구 소실은 유지한다.
- 승천도 기본 보급 계약을 깨지 않는다.

## 구현 범위

- `RunManager`
  - 선택 총기의 기본 보급탄 리소스를 별도 보관
  - 시작 덱에서 기본탄 수량 제거
  - 전술 백팩을 레벨당 시작 전술탄 +1로 재배분
  - 드래프트에서 기반탄 제외
- `CombatManager`
  - 기본 보급 잔량·상한과 변경 시그널 추가
  - 최초 적재·중간 납탄에서 보급 잔량 차감
  - 리로드 때 상한 복구 및 기본탄 버림/소멸 기록 정리
- 전투 UI
  - 기본탄을 가방 첫 칸의 `보급 현재/상한` 카드로 고정
  - 잔량 0에서도 슬롯 유지
  - 탄창 슬롯 강제 예약 없이 플레이어가 전술탄과 자유롭게 LIFO 구성
- 승천
  - 기본탄 보호를 깨던 구 8등급을 시작 거리 −1m 추가로 교체

## 검증 기준

- 기본탄이 시작 런 덱과 드래프트 후보에 없다.
- 전투 시작 보급량이 약실 포함 실제 장전 한도와 같다.
- 장전·중간 납탄으로 잔량이 정확히 감소한다.
- 성공·실패 여부와 무관하게 리로드 뒤 상한까지 복구된다.
- 남은 기본탄이 있어도 상한을 넘겨 누적되지 않는다.
- 기본탄이 탄창 한 칸을 강제로 예약하지 않는다.
- 기존 전술탄 순환·소실, 연발, 파츠, 연속 런 회귀가 유지된다.
