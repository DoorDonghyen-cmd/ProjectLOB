# 탄환 역할 단순화 및 조합 매트릭스 워크스루

> 완료일: 2026-07-27
> 대상: Phase 12 ⑥
> 결과: 구현 및 전체 회귀 검증 완료

## 결과

탄환 27종의 역할을 `attack/link/control` 3종으로 단순화했다. 화면에는 `[공격]`, `[연계]`, `[제어]`로 표시되며 분포는 **17 / 8 / 2**다.

핵심 원칙은 다음과 같다.

- 공격탄은 보통 적에게 단독으로 기능한다.
- 연계탄은 다음 공격탄의 명중·관통 범위를 회피·방어 전문 적까지 넓힌다.
- 제어탄은 낮은 피해 대신 넉백·슬로우로 거리와 시간을 산다.
- 연계탄이 명중 또는 관통 게이트를 넘지 못하면 버프가 발동하지 않는다.

## 수치 변경

| 탄환 | 변경 |
|---|---|
| 9mm 고압탄 | DMG 6 / ACC 2 → **DMG 5 / ACC 5** |
| .45ACP 과부하탄 | DMG 5 / ACC 3 → **DMG 4 / ACC 5** |
| 5.56mm 중격탄 | DMG 7 / PEN 0 → **DMG 5 / PEN 2** |
| 7.62mm 작렬탄 | DMG 9 / ACC 3 / PEN 0 → **DMG 7 / ACC 5 / PEN 2** |
| 12게이지 밀집탄 | DMG 7 / ACC 4 → **DMG 5 / ACC 5** |

CSV와 27개 탄환 리소스의 역할·스탯·설명을 함께 동기화했다. 구 역할값은 로딩 시 `standalone/payload → attack`, `setter → link`, `utility → control`로 안전하게 정규화한다.

## UI와 LIFO 안내

역할 배지와 도움말을 드래프트, 교체 목록, 장전 가방, LIFO 스택, 실린더, 탄환 갤러리에서 같은 정본으로 표시한다.

LIFO 안내는 “공격탄을 먼저 넣고 연계탄을 나중에 넣으면 연계탄이 먼저 발사됩니다”로 통일했다. 상단 두 발이 연계→공격이면 `⇢ 연계`를 표시하고, ACC/PEN 연계탄은 무엇을 여는지도 함께 보여준다.

## 실제 전투 매트릭스

신규 `tests/suite_ammo_matrix.gd`는 가공 수치가 아니라 실제 적 CSV와 실제 총기·탄환 리소스를 `CombatManager`에 넣어 검증한다.

| 시나리오 | 결과 |
|---|---|
| 권총 고압탄 ×2 → 러셔 | 처치 |
| 발광탄 → 고압탄 → 기본탄 → 회피병 | 처치 |
| 파쇄탄 → 중격탄 → 기본탄 → 방패병 | 처치 |
| 유효타 3발 → 스택 흡수체 | 배리어 규칙으로 처치, 4번째 탄 보존 |
| 제압형 파쇄 → 중격 → 중격 → 교차 기본 DMR → 방패병 | 태세 변경 EVA 7까지 반영해 1연발 처치 |
| 발광탄 → 고압탄 → 방패병 | 0피해, 막힌 연계는 버프 미발동 |
| DMR 기본탄 → EVA 9 나노 스토커 | 시그니처 포함 1발 처치 |
| Tempo 조율→과부하 3쌍 | 총 12피해, 리로드 포함 3.00 DMG/턴 |

매트릭스를 작성하면서 스택 흡수체가 HP 합산형이 아니라 3유효타 배리어라는 점과, 방패병이 세 번째 격발 뒤 EVA 7 태세로 바뀐다는 점도 실제 규칙대로 테스트에 반영했다.
