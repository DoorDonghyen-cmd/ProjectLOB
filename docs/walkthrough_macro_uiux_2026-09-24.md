# 거시 UI/UX 구조 개편 워크스루

## 결과

기존의 모든 화면이 같은 긴 대시보드처럼 보이던 구조를 화면 목적별로 분리했다. 전투 규칙과 캠페인 데이터는 유지하고, 플레이어가 지도·전투·보상·상점·빌드 작업실에서 내려야 하는 판단을 각각 다른 화면 위계로 표현했다.

## 변경 내용

- 도시 공통 상단부를 여섯 개 상태 카드에서 한 개의 압축 런 헤더로 바꿨다. 위치, 크레딧, 압축 코어, 무기, 덱, 난도를 두 줄 안에서 확인한다.
- 지도는 건물 단면을 중심에 두고 선택한 목적지 하나만 설명하는 `MapRouteSheet`를 추가했다. 목적지를 고르기 전에는 이동 확정 버튼이 나타나지 않는다.
- 전투는 위치·무기·턴·전열·증원·재화·보조 메뉴를 `CombatStatusBar` 한 모듈에 통합했다.
- 보상은 전투 보고와 탄환 두 장, 크레딧 한 칸을 동일한 3열 선택 프레임에 배치했다. 선택 행동은 노란 주 버튼으로 통일했다.
- 상점은 현재 빌드 요약, 상품, 구매 전후 비교, 압축 코어만 담당한다. 장착 작업대와 보관함의 중복 노출을 제거하고 `빌드 작업실` 진입을 추가했다.
- 덱·장비는 `AcceptDialog`에서 분리해 배경을 완전히 덮는 전체 화면 빌드 작업실로 전환했다. 착용 중, 보관함, 탄환 덱 탭을 유지하고 장착 파츠는 3열 작업 카드로 펼쳤다.
- 보급, 이벤트, 관문은 각각 청록, 주황, 노란 화면 헤더를 사용해 현재 장면의 성격을 구분한다.

## 남은 판단

자동 검증은 기능, 화면 경계, 입력 경로를 확인한다. 첫 플레이어가 화면 역할과 빌드 작업실의 위치를 설명 없이 이해하는지는 다음 사람 플레이에서 확인한다. APK, 커밋, 푸시는 수행하지 않았다.
