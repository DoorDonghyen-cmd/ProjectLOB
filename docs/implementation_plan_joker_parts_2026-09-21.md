# 빌드 핵심 파츠 시스템 개편 계획

상태: **구현·검증 완료**  
대상: `prototype/core-redesign`  
승인 근거: 사용자가 파츠를 발라트로의 조커 카드처럼 런의 방향을 형성하는 핵심 빌드 축으로 정의하고, 넓은 장착 범위와 강한 효과에 대응하는 패널티를 요청함

## 설계 원칙

1. 파츠는 단일 장비 교체가 아니라 여러 효과를 조합하는 런 빌드다.
2. 일반 모듈은 작고 명확한 순수 이점을 가질 수 있다.
3. 규칙을 바꾸는 코어 파츠는 강한 효과와 실제 운용을 바꾸는 패널티를 함께 가진다.
4. 패널티는 탄창 크기, 재장전, 직접 피해, 탄환 종류와 발사 순서에 연결한다.
5. 파츠 설명은 긴 문장보다 이점·대가 아이콘과 변화 수치를 먼저 보여 준다.

## 장착 구조

- 모든 무기는 파츠를 최대 **5개** 동시 장착한다.
- 일반 모듈은 제한 없이 조합할 수 있다.
- 금색 코어 파츠는 최대 **1개**만 장착한다.
- 구매 시 빈 슬롯과 코어 조건이 맞으면 자동 장착한다. 조건이 맞지 않으면 보관함으로 이동한다.
- 전투 사이에는 무료로 장착과 해제가 가능하다.
- 장착 중인 파츠는 분해할 수 없다.

## 파츠 풀

기존 일반 모듈 8종을 유지하고 일반 6종, 코어 6종을 추가해 총 20종으로 확장한다.

### 일반 모듈 14종

| 파츠 | 효과 |
|---|---|
| 가속 총열 | 관통 +2 |
| 회수 가속기 | 재장전 −1턴 |
| 확장 탄창 | 탄창·회수탄 +1 |
| 열축전 코일 | 화상 +1 |
| 전이 축전기 | 전이 피해 +1 |
| 충격 가이드 | 밀치기·한도 +1m |
| 증폭 시퀀서 | 증폭 피해 +1 |
| 복열 노리쇠 | 연발 타격 +1 |
| 점화 약실 | 화상 중인 적 직접 피해 +2 |
| 배리어 파쇄기 | 타격마다 배리어 1칸 추가 제거 |
| 처형 조준기 | HP 5 이하 적 직접 피해 +2 |
| 예비 급탄기 | 회수탄 보급 +2 |
| 선두 격발기 | 탄창 첫 발 직접 피해 +2 |
| 후미 점화기 | 탄창 마지막 발 직접 피해 +3, 재장전 +1턴 |

### 코어 파츠 6종

| 파츠 | 강점 | 패널티 |
|---|---|---|
| 야전 압축기 | 교전마다 현장 압축 +1회 | 탄창 −2칸 |
| 과구경 총열 | 피해 +2, 관통 +2 | 탄창 −1칸 |
| 열폭주 노심 | 화상 +2 | 재장전 +1턴 |
| 분기 전이기 | 전이 피해 +2, 대상 +1 | 직접 피해 −1 |
| 충격 피스톤 | 밀치기·한도 +2m | 직접 피해 −1 |
| 삼중 시퀀서 | 서로 다른 탄 3종째 직접 피해 +5 | 회수탄 피해 −1 |

## 전투 계산

- 장착 파츠 목록을 하나의 결정론적 상태로 저장한다.
- 직접 피해 보정은 기본 피해 뒤, 장갑 계산 전에 합산한다.
- 선두·후미·삼중 시퀀서는 실제 탄창 발사 순서를 기준으로 판정한다.
- 삼중 시퀀서는 직전 두 발과 현재 탄의 원본 탄종이 모두 다를 때 발동한다.
- 배리어 파쇄기는 피해 타격마다 배리어를 최대 2칸 제거한다.
- 야전 압축기는 상점 충전량과 별도로 교전 시작 시 1회를 더 제공한다.
- 모든 예측은 실제 전투와 같은 복제 모델을 사용하므로 파츠 결과도 동일해야 한다.

## 상점·보관함 UX

```text
┌ 현재 빌드 ───────────────────────────────────┐
│ [무기]  [01 파츠] [02 파츠] [03 빈칸] [04 빈칸] [CORE 빈칸] │
│ 탄창 4→2  ·  재장전 1턴  ·  현장 압축 +1                │
└──────────────────────────────────────────────┘

┌ 파츠 후보 ─────────┐  ┌ 코어 후보 ─────────┐
│ [아이콘] 야전 압축기 │  │ [아이콘] 과구경 총열 │
│ ▲ 압축 +1           │  │ ▲ 피해·관통 +2      │
│ ▼ 탄창 −2           │  │ ▼ 탄창 −1           │
│ 30Cr · 구매          │  │ 30Cr · 보관          │
└───────────────────┘  └───────────────────┘

보관함
[장착 1] [장착 2] [장착 3] [빈칸] [CORE]
[보유 파츠 카드 · 장착/해제] [보유 파츠 카드 · 장착/해제]
```

- 장착 파츠는 슬롯 번호와 금색 코어 테두리로 구분한다.
- 이점은 청록 `▲`, 패널티는 적색 `▼`로 표시한다.
- 상세 설명은 카드 터치 시에만 표시한다.
- 상점은 미확인 파츠 우선 정책을 유지하고, 보유 파츠는 후보에서 제외한다.
- 방문당 파츠 1개 제한을 제거해 크레딧이 허용하는 만큼 구매할 수 있다.

## 저장 호환

- 전투 저장 버전을 v8, 캠페인 저장 버전을 v4로 올린다.
- 기존 단일 `part` 값은 `equipped_parts` 배열의 첫 항목으로 자동 변환한다.
- 보유 목록, 상점 확인 이력과 기존 압축 코어 수량은 유지한다.
- 장착 목록은 최대 5개, 중복 없음, 코어 최대 1개, 보유 목록의 부분집합이어야 한다.

## 완료 조건

1. 서로 다른 파츠 5개가 한 전투에 동시에 적용된다.
2. 코어 파츠 두 개를 동시에 장착할 수 없다.
3. 야전 압축기가 교전마다 압축 1회를 주고 탄창 2칸을 실제로 줄인다.
4. 순서형 파츠가 첫 발·마지막 발·서로 다른 세 번째 탄을 정확히 판정한다.
5. 기존 단일 파츠 저장이 다중 장착 저장으로 손실 없이 변환된다.
6. 상점과 보관함에서 장착 5칸, 이점, 패널티와 코어 제한을 아이콘 중심으로 확인한다.
7. 실제 UI 캠페인과 전체 전투·저장 회귀를 통과한다.

## 완료 결과

- 일반 모듈 14종, 코어 6종과 5칸 동시 장착을 구현했다.
