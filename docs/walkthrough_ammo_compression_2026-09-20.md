# 탄환 압축과 시각 장전 제약 — 2026-09-20

후반에 덱을 얇게 정제해 같은 순서를 반복하던 흐름을 관문 압축 성장으로 교체했다. 같은 일반 전술탄 두 장을 같은 계열 압축탄 한 장으로 만들며, 탄창 확장과 24Cr을 포기해야 한다. 자유 제거는 보상·보급·무기고에서 빠졌고 새 제거·압축 경로는 덱 8장 바닥선을 지킨다.

압축탄은 새 이름을 외우게 하지 않고 철갑탄·충격탄·소이탄·증폭탄·연발탄·전격탄의 이름을 그대로 쓴다. 겹친 탄피와 밝은 코어가 압축 상태를 나타낸다. 철갑·소이는 카드 하나가 탄창 두 칸을 실제로 덮고, 연발·전격은 첫 발 결합부, 충격·증폭은 마지막 발 마개를 가진다. 탭하면 합법 위치로 자동 이동하므로 `압축/2칸/선두/후미` 배지를 전투 카드에 추가하지 않았다.

각 압축탄은 단순 상위 수치 대신 다른 순서를 만든다. 철갑은 높은 관통을 두 칸에 집약하고, 소이는 화상 6을 두 칸에 담는다. 연발 3타와 전체 전격 전이는 선두를 차지한다. 강한 밀기와 재장전을 한 번 넘기는 증폭은 후미를 차지한다. 증강의 배율은 피해·관통·효과 강도에 적용하고 타격 수·화상 기간은 유지했으며, 압쇄의 화상·전이 전문성도 그대로 연결했다.

현장 압축은 사용자 실기 피드백을 반영해 런 자원으로 바꿨다. 등반 시작 시 압축 코어 1개를 지급하고 최대 2개를 보유한다. 전투가 바뀌어도 자동 충전되지 않으며 무기고에서 방문당 한 번 18Cr에 1개를 산다. 같은 일반탄 두 발을 끌어 합치면 코어 1개만 소비하고 패 교환은 그대로 남는다. 확정 전 회수는 두 원본과 코어를 복구하고, 확정 뒤 발사하거나 재장전하면 두 원본이 버림패로 돌아가며 코어는 복구하지 않는다. 덱 자체는 변하지 않는다.

회수탄과 공개 전술 패를 합쳐 최대 여섯 장만 보이던 화면도 보완했다. 여섯 장은 손패 규칙으로 유지하되, 아래 예비 탄환 띠에 다음 두 장을 순서대로 표시하고 나머지 대기·사용 탄환은 계열 아이콘과 장수로 모두 보여 준다. 플레이어는 보유 탄환이 사라진 것으로 오해하지 않고 전체 구성을 확인할 수 있으며, 세 번째 이후의 순서는 계속 숨겨져 드로우 불확실성이 남는다.

모델 저장은 버전 6으로 올렸다. 장전 가능 여부와 확정은 카드 수 대신 실제 슬롯 사용량을 사용한다. 자동 정렬 뒤에도 마지막으로 탭한 탄환을 실행 취소할 수 있도록 입력 순서를 별도로 저장한다. 버전 2~5 저장은 일반탄 구성을 보존해 이관한다. 현장 압축 중 저장은 원본과 설계/탄창 위치를 함께 보존하며, 예측기는 임시탄도 실제 정산과 같은 규칙으로 계산한다.

관문에는 두 일반탄이 한 압축탄으로 합쳐지는 미리보기와 작은 탄창 모형을 넣었다. 전투 개발자 바로가기는 첫 발 연발탄, 두 칸 철갑탄, 마지막 발 충격탄을 한 4칸 탄창에 배치해 세 제약을 즉시 확인한다. [PC 화면](qa/reports/ammo_compression_2026-09-20_assets/compressed_ammo_loading.png)과 [휴대폰 크기 화면](qa/reports/ammo_compression_2026-09-20_assets/compressed_ammo_loading_phone.png)을 실제 Godot 렌더로 확인했다.

현장 압축 UI에는 문구 배지를 추가하지 않았다. `두 발 → 코어` 상태 장치와 충전등, 압축 가능한 개별 카드 쌍의 청록 모서리·연결 다이아, 임시탄의 청록 자기장으로 상태를 전달한다. [압축 가능](qa/reports/ammo_compression_2026-09-20_assets/field_compression_ready.png), [휴대폰 압축 가능 상태](qa/reports/ammo_compression_2026-09-20_assets/field_compression_ready_phone.png), [합성 완료](qa/reports/ammo_compression_2026-09-20_assets/field_compression_combined.png)를 실제 Godot 터치 입력과 렌더로 확인했다.

[QA 보고서](qa/reports/ammo_compression_2026-09-20.md)에 실행 근거를 정리했다. 현장 압축 추가 뒤 무기 규칙 3,190/0, 탄환 공식·예측·저장 30,247/0, 도시 캠페인 16,760/0·4완주, 현장 압축 밸런스 264/0, 도시 UI 2,667/0·864입력을 통과했다. 실제 터치로 짧은 장전, 다른 탄환 드롭 거부, 동일 카드 드래그 압축을 분리해 검증했다. 증강은 압축으로 한 턴을 줄일 수 있지만 첫/마지막 위치 제약 때문에 기존 증폭 조합을 잃을 수 있다. `증폭 → 연발 → 연발`은 3턴 34피해, 연발 현장 압축은 2턴 20피해였다.
