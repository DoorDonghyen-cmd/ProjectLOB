# 전투 전체 화면 UI 개편 계획

## 목표

1008×630 모바일 가로 화면에서 전투의 상태, 전장, 탄환 선택, 발사 순서, 주 행동을 스크롤 없이 한 화면에서 판단할 수 있게 한다. 전투 규칙과 밸런스는 유지하고 화면 구조와 정보 밀도만 개편한다.

## 화면 구조

1. 상단은 위치·무기·턴·적·증원·재화를 한 줄 상태 바로 합친다.
2. 중앙 전장은 남은 높이에 맞춰 축소되며 플레이어, 사선, 적 진형과 상태를 계속 표시한다.
3. 하단은 `탄환 선택`과 `발사 순서`를 좌우 전술 패널로 고정한다.
4. 발사·재장전은 발사 순서 패널 하단에 고정해 가장 중요한 행동의 위치가 바뀌지 않게 한다.
5. 압축·교환은 탄환 선택 헤더의 작은 도구로 묶어 전투 흐름을 가리지 않게 한다.

## 반응형 기준

- 높이 700px 이하에서는 외곽 여백, 전장, 탄환 카드, 탄창, 안내 문구와 행동 버튼을 전투 전용 밀도로 줄인다.
- 3단계 안내 띠는 작은 화면에서 숨기고 현재 행동 문구만 유지한다.
- 뷰포트 크기가 바뀌면 전투 화면을 다시 그려 데스크톱과 모바일 밀도를 즉시 전환한다.
- 6~8칸 탄창과 다수 적이 표시되어도 전투 핵심 영역은 뷰포트 안에 남아야 한다.

## 완료 기준

- 1008×630에서 세로 스크롤바가 나타나지 않는다.
- 상태 바, 전장, 전술 패널, 발사·재장전이 모두 한 화면 안에 있다.
- 무기별 전투 화면과 실제 캠페인 6칸 탄창 화면을 렌더링 검증한다.
- 전체 자동 회귀 테스트가 기존 결과를 유지한다.
