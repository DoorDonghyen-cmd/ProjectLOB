# 관리·정점 복합 편성 QA 워크스루

> 완료일: 2026-08-15
> 범위: 상층 편성 중복 압력 제거, 실제 전투 호흡 회귀, 수동 QA 진입점

## 결과

정점 일반전 후보 중 차저 두 체가 같은 주기에 강제전진을 중복시키던 두 조합을 발견했다. 이 중복은 새로운 계산 축을 만들지 않고 같은 벌칙만 반복하므로 다음과 같이 정리했다.

- 정점 초반: `상위 신경 통제체 + 신경 교란 부유체 + 태세 교란 드론` → `상위 신경 통제체 + 광학 굴절병 + 태세 교란 드론`
- 정점 중반: `광학 굴절병 + 신경 교란 부유체 + 흡수 장갑 구체 + 상위 신경 통제체` → `광학 굴절병 + 경보 순찰 드론 + 흡수 장갑 구체 + 상위 신경 통제체`

이제 관리·정점의 모든 일반전 후보는 강제전진 차저를 최대 한 체만 포함한다. 적 수치, 탄환 수치, 총기 수치와 최대 4체 밀도는 변경하지 않았다.

## 결정론적 압력 검증

`suite_enemy_roster.gd`가 각 상층 후보를 실제 `CombatManager`에 넣고 적 전진, 3행동 차징, 2m 강제전진, 일회성 긴급 격퇴를 그대로 실행한다. 플레이어가 아무 적도 제거하지 않는 기준으로 모든 후보가 4~8행동 사이에 패배해 다음 두 조건을 동시에 만족했다.

- 탄환 순서를 실행할 최소 계획 시간 확보
- 상층 편성이 개입 없이 장시간 정체되지 않음

## 수동 QA 진입점

개발자 테스트 메뉴에 `관리 계층 편성 QA`와 `정점 편성 QA`를 추가했다. 두 전투는 실제 종반 후보 4체, Workhorse, 동일한 11종 전술탄 묶음을 사용한다. 따라서 35층을 다시 진행하지 않고 계층별 표적 우선순위와 재장전 여유만 직접 비교할 수 있다.

세부 절차와 체감 기록표는 `docs/playtest_upper_roster_2026-08-15.md`에 있다.

- 씬 로드: 4개 성공

수동 체감 결과는 아직 입력하지 않았다. 실제 플레이 후 첫 위협 제거, 긴급 격퇴, 재장전, 계층 간 복합도만 기록하면 후속 편성 조정 여부를 판단할 수 있다.
