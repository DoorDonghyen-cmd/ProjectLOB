# LIFO 탄환 조합 핵심 재미 정밀 QA 개편 완료

## 결론

현재 자동 근거가 지지하는 결론은 **“순서 퍼즐은 작동하지만 실제 플레이에서 요구되는 빈도와 깊이가 아직 충분히 입증되지 않았다”**이다.

기계적 가능성은 분명하다. 동일한 탄환 묶음을 사용한 네 통제 시나리오에서 장전 순서에 따라 결과가 모두 달라졌고, 계획한 순서가 역순보다 4/4 우세했으며 혼합 장전도 기본탄 반복보다 4/4 우세했다. 그러나 실제 캠페인 표본은 1개 시드·9전투뿐이므로 게임 전체가 재미있다고 확정하지 않았다.

## 실제 QA 결과

- 판정: `PROMISING_BUT_THIN` — 가능성은 있으나 아직 얇음
- 통제 시나리오: 순서 영향 4/4, 계획 순서 우세 4/4, 혼합 장전 우세 4/4
- 구분된 해법 축: 명중, 관통, 피해, 위치/막발
- 실제 캠페인: 4프로필 중 3프로필이 전술탄 사용, 상황 근거가 있는 전술 장전 11회
- 표본: 1개 시드, 총 9전투, 승리 5회, 패배 또는 런 종료 4회
- 기능 버그: 신규 확정 버그 0건

## 바뀐 QA 동작

- 적의 공개 DEF/EVA/거리와 탄환 설명을 근거로 장전 순서를 세운다.
- 동일 탄환 묶음의 계획 순서·역순·기본탄을 실제 전투 로직으로 비교한다.
- 핵심 재미를 다섯 독립 게이트로 판정하고 총점을 만들지 않는다.
- 탄환별 장전 횟수를 전체 선택 집중도로 잘못 계산하던 집계를 제외했다.
- 표시명과 내부 ID가 달라 전술탄 미사용으로 오판하던 문제를 수정했다.
- 대시보드 첫 화면에서 결론, 통과/미통과 근거, 다음 조치, 사람 확인 항목을 바로 읽을 수 있다.

## 아직 자동화로 확정할 수 없는 것

- 장전 고민 자체가 즐거운지, 정답 발견 뒤 다시 시도하고 싶은지
- 발사·피격·관통 연출이 계획 성공의 쾌감을 충분히 전달하는지
- 장시간 플레이에서 장전 계산이 만족보다 피로를 더 크게 만드는지

이 세 항목은 실제 사람 플레이 확인이 필요하다. 또한 `CORE_FUN_CONFIRMED`로 올리려면 최소 3개 시드·12전투 이상의 반복 근거가 필요하다.
