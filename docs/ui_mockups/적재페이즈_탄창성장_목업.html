⚠ 10칸 — 가려질 칸이 많아 전투 시 기억 부담 큼 (성장의 트레이드)

탄창 10칸을 세로로 — "칸 크기 = 성장 피드백"

자동 축소칸 높이가 탄창 크기에 반비례. 4칸은 크게, 10칸은 촘촘히 → 항상 한눈에(스크롤 없음).
성장 피드백빽빽해지는 화면 자체가 "탄창이 컸다"는 뿌듯함 + 관리 부담(기억)을 시각적으로 전달.
구경 = 색작은 칸에서도 색 패턴으로 스택 구성이 읽힘(9mm 회색 / 5.56 초록 / 7.62 주황).
정보 계층화촘촘하면 스탯 숨기고 호버(탭)로 툴팁. 칸 위에 마우스 올려보면 D·A 표시.
전투 땐 무관10칸이어도 전투 페이즈는 앞 2칸만 표시 → 10칸 문제는 적재 페이즈 한정.
