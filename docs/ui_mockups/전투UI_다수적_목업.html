다수 적 — "트랙이 모든 것의 답"

거리 분포숫자 5개를 읽는 게 아니라 트랙 위 위치로 한눈에. "줄이 얼마나 붐비나"를 봄.
자물쇠각 적 위 배지 아이콘(돌·방·회·스·술)으로. 텍스트 나열 대신 스캔이 빠름.
강제 타겟최근접(맨 앞) 1명만 붉은 링 + "다음 타겟" 강조. 내 탄이 누구에게 가는지 자동.
명중 분석맨 앞 1명만 분석(5명 다 하면 정보 폭발). 헤더 좌측으로 올려 캐릭터 안 가림.
사격 결과적 위 플로팅 — 처치는 크게, 대미지는 작게. 관통 다중타는 순차로.
사격 로그플로팅이 놓치는 정밀 수치·관통 연쇄를 한 줄로 보조.
예고창캐릭터 옆 세로 — 위=다음 발사(적재와 방향 통일). 앞 2칸만 선명, 나머지는 "N칸 더" 흐린 덩어리(10칸이어도 항상 작음).
가방 서랍하단 서랍으로 슬라이드업 — 전황(거리·트랙·예고창)을 안 가림. 소모품은 즉발 사용, 탄환은 열람만(전투 중 커밋 유지). 🎒 가방 눌러서 확인.
