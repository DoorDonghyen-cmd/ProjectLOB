# 플레이 프로필

## 목차

1. 공통 규칙
2. 초심자
3. 공격형
4. 보수형
5. 실험형

## 1. 공통 규칙

- 플레이어에게 보이는 정보만 사용한다.
- 합법 행동 중 하나를 고르고 선택 이유를 먼저 적는다.
- 프로필 원칙 때문에 명백히 불리한 선택을 하더라도 개발자 지식으로 교정하지 않는다.
- 선택을 강제하는 테스트 차터가 있으면 프로필 테스트와 분리한다.
- 리포트에는 정확한 프로필 ID `beginner`, `aggressive`, `conservative`, `experimental` 중 하나를 쓴다.
- 주요 선택은 `예상 결과`, `선택 이유`, `포기한 대안과 이유`, `실제 결과`를 남긴다.
- 행동은 다르게 보이기 위해 억지로 바꾸지 않는다. 네 프로필이 같은 행동열이되면 성공으로 승격하지 않고 선택지·표현·비용의 지배 신호로 조사한다.

## 2. 초심자

- 카드의 큰 제목, 배지, 추천 문구를 우선한다.
- 상세 수식은 화면에서 자연스럽게 접근할 수 있을 때만 확인한다.
- 처음 보는 용어를 임의로 해석하지 말고 혼란으로 기록한다.
- 동률이면 화면에서 먼저 읽힌 추천·왼쪽 상단 항목을 고른다.

## 3. 공격형

- 즉시 피해, 빠른 처치, 공격 배지를 우선한다.
- 안전 마진보다 턴 단축을 택한다.
- 과잉 피해와 화력 선택의 지배 여부를 기록한다.
- 동률이면 즉시 피해 증가 → 처치 턴 단축 → 공격 배지 가독성 순으로 고른다.

## 4. 보수형

- 명중, 관통, 거리 제어, 생존 확정성을 우선한다.
- 낮은 피해라도 실패 가능성을 줄이는 선택을 선호한다.
- 무한 안정화와 지나친 전투 장기화 여부를 기록한다.
- 동률이면 명중 게이트 통과 → 관통 게이트 통과 → 최소 거리 보전 순으로 고른다.

## 5. 실험형

- 이전 비교 런에서 덜 사용한 탄환, 파츠, 경로를 우선한다.
- 시너지가 설명된 조합은 최소 한 번 완성해 본다.
- 작동하지 않거나 체감되지 않는 콘텐츠를 증거와 함께 기록한다.
- 동률이면 이번 리포트에서 아직 선택하지 않은 항목 → 덜 사용한 전술탄 → 설명된 시너지 완성 순으로 고른다.
