# ORVASK — 탄창·빼내기 비교 테스트 설치

1. Google Drive에서 ZIP을 다운로드하고 ‘내 파일’에서 압축을 풉니다.
2. `LastOnBoard-city.apk`를 눌러 설치합니다. 기존 `Last on Board Test`가 있으면 삭제하지 않고 업데이트합니다.
3. 앱을 가로로 열면 A안 전투 비교 화면으로 바로 들어갑니다. 본편 진행 저장은 읽거나 덮어쓰지 않고 비교 상태만 별도로 저장합니다.
4. 상단 **다음 총기 / 다음 전투**로 다섯 총기와 네 전투를 바꿉니다. **재시작**은 현재 비교 전투를 처음부터 시작합니다.
5. **탄 빼내기 → 카드 선택 → 빼내기 확정**으로 중간 탄도 최대2발까지 빼낼 수 있습니다. 확정 전에는 취소할 수 있습니다.

빼낸 탄은 이번 전투에서 소모되고 빈자리는 자동으로 채워지지 않습니다. 추가 적 행동이나 열 감소는 없으며 전체 탄창을 교체하면2발 한도가 다시 생깁니다. 선택 중 남는 탄의 다음 사격 결과를 확인해 주세요.

64비트 안드로이드(ARM64)용 테스트입니다. 설치 화면에서 필요한 경우 해당 파일 앱의 설치 허용 안내를 따르세요. 기존 앱을 지우면 로컬 저장이 지워질 수 있으므로 삭제를 요구하지 않습니다. 실제 기기의 성능·발열·터치 감각은 이번 플레이에서 확인할 사항입니다.

이번 파일은 전투 비교용이며 지도·상점·연속 등반으로 진행하는 본편 빌드와 구분됩니다.
