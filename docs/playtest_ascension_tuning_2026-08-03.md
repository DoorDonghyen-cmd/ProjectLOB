# 승천 2차 실제 플레이 튜닝 체크리스트

> 기준 빌드: 2026-08-03 승천 2차 배치
>
> 목적: 승천이 특정 적·총기를 갑자기 무력화하지 않고, 등급이 오를수록 보급·구매·거리 판단을
> 한 단계씩 더 요구하는지 확인한다.

## 준비

- [ ] 메인 화면 `개발자 테스트`에서 `모든 승천 해금`을 누른다.
- [ ] 상승 브리핑에서 0~10등급을 자유롭게 선택할 수 있는지 확인한다.
- [ ] 비교 런은 같은 총기와 같은 메타 업그레이드 상태로 진행한다.
- [ ] 각 런 종료 후 최신 `playtest_run_*.json` 파일명을 기록한다.

## 비교 우선순위

모든 등급을 한 번에 완주할 필요는 없다. 먼저 `0 → 3 → 5 → 8 → 10` 순서로 비교한다.

| 등급 | 확인할 변화 | 통과 기준 |
|---|---|---|
| 0 | 기준 런 | 기존 난도와 동일 |
| 3 | 전술탄 −1계열, 전투 Cr −10%, 거리 −1m | 변화가 보이지만 첫 구역이 막히지 않음 |
| 5 | 위 조건 + 아머 −1, 드래프트 탄환 1장 | 보상 선택과 피격 회피가 더 중요해짐 |
| 8 | 전투 Cr 누적 −19%, 전술탄 누적 −2, 거리 누적 −2m | 빌드 완성이 늦지만 선택은 계속 존재 |
| 10 | 아머 누적 −2, 거리 누적 −3m | 어렵지만 특정 적 조합이 즉사·무해법 벽이 되지 않음 |

## 런별 기록

각 등급에서 아래 항목을 `1~5`로 기록한다. `3`은 의식하면 느껴짐, `5`는 플레이 선택이
명확히 달라짐이다.

- 보급 압박: `__/5`
- 상점 구매 압박: `__/5`
- 시작 거리 압박: `__/5`
- 불공정하다고 느낀 정도: `__/5` — 낮을수록 좋음
- 첫 구역 종료 시 크레딧: `____ Cr`
- 첫 구역 종료 시 전술탄 수: `____발`
- 가장 위험했던 적 편성: `________________`
- 선택한 총기·핵심 파츠: `________________`
- JSON 파일명: `________________`

## 즉시 중단하고 알려줄 조건

- [ ] 시작하자마자 대응할 사격 기회 없이 접촉하는 일반 적이 있다.
- [ ] 드래프트에서 탄환과 크레딧 중 실질적인 선택이 사라진다.
- [ ] 5등급 이전부터 상점 파츠를 사실상 한 번도 살 수 없다.
- [ ] 8~10등급에서 특정 총기만 구조적으로 진행 불가능하다.
- [ ] 이전 등급보다 다음 등급이 오히려 쉽게 느껴진다.

## 1차 회신에 필요한 최소 정보

우선 `0등급`과 `5등급` 두 런만 비교해도 된다. 두 런의 첫 구역 종료 크레딧, 체감 점수,
가장 위험했던 적 편성, 최신 JSON 파일 2개를 전달하면 경제와 거리 중 어느 축부터 2차 조정할지
판단할 수 있다.
