# 격발 입력 잠금·총기별 연출 템포 워크스루

> 날짜: 2026-08-15
> 세션: `codex0815-fire-pacing`

## 1. 완료 결과

- 첫 탄의 격발·피격 연출이 진행되는 동안 발사, 빼내기, 재장전, 이젝트 입력을 받지 않는다.
- 버튼의 비활성화 표시와 핸들러 재진입 방어를 함께 적용해 빠른 더블탭과 동일 프레임 호출도 차단한다.
- 잠금 중 누른 입력은 예약되지 않으므로 다음 탄이 의도치 않게 자동 소비되지 않는다.
- 단발 총기는 총기 성격에 따라 0.32~0.52초의 최소 표시 시간을 사용한다.
- Tempo는 0.13초, Suppressor는 0.20초의 연발 간격을 사용해 전탄 커밋 총기 사이의 체감을 분리했다.
- 모든 시간은 UI 표시 전용이며 전투 수치와 턴 정산은 변경하지 않았다.

## 3. 자동 검증

```text
통과: 3,351
실패: 0
경보: 3 (기존 경보)
결과: PASS
```

검증된 핵심 계약:

- Tempo 0.13초 / Suppressor 0.20초 연발 간격
- DMR이 단발 기관단총보다 긴 최소 표시 시간 사용
- Shotgun 표시 시간이 0.55초 이하 반복 플레이 상한 유지
- 연출 중 전투 액션 버튼 일괄 잠금
- 연출 중 재입력 후 탄창 수와 전투 상태 불변
- 연출 종료 후 발사 버튼 재활성화

## 4. 수동 플레이테스트 체크포인트

1. Revolver를 빠르게 연타해도 한 발의 피격이 표시되기 전에 다음 발이 나가지 않는지 확인한다.
2. DMR·Shotgun이 묵직하되 기다림이 과도하지 않은지 비교한다.
3. Tempo는 빠른 6발 체인, Suppressor는 무거운 5발 체인으로 구분되는지 확인한다.
4. 연발 종료 직후 재장전 입력이 누락되지 않고, 연출 중 눌렀던 입력은 자동 실행되지 않는지 확인한다.
