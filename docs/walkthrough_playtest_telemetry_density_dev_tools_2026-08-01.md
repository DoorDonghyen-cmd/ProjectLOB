## 목표

- 9mm 집중 사격과 3회 주기 파츠의 실제 기여도를 런 단위 데이터로 분리한다.
- 탄종별 다수전 행동이 드러나도록 일반전 편성 밀도를 안전하게 높인다.
- 모든 총기를 빠르게 비교할 수 있는 개발자 테스트 기능을 제공한다.

## 구현 결과

### 런별 플레이테스트 JSON

- 런 시작 시 `user://playtest_logs`에 JSON 파일을 생성한다.
- 전투마다 구역·층·총기·장착 파츠·적 편성·탄 사용량·최소 거리·리로드·처치 정보를 누적한다.
- 경량 집중, 소총 관통, 산탄 확산과 파츠 효과를 별도 지표로 기록한다.
- 각 전투 종료 직후 파일을 갱신해 강제 종료 시에도 마지막 완료 전투까지 보존한다.
- 개발자 테스트 메뉴의 `플레이테스트 로그` 버튼으로 저장 폴더를 연다.

### 일반전 편성 밀도 1차 조정

- 침전 거주구 초반과 보스 편성은 기존 학습 곡선을 유지한다.
- 침전 거주구 후반은 최대 3체, 공역 이후 일반전은 3~4체로 확장한다.
- 일반전 상한은 4체로 제한한다.
- 같은 거리에 있는 4체는 대각 편성 슬롯으로 분산해 선택 영역과 상태 배지 중첩을 방지한다.

### 개발자 테스트 모든 무기 해금

- `모든 무기 해금` 버튼이 준비실의 실제 무기 프로필을 순회해 현재 9종을 해금한다.
- 다른 메타 진행도는 건드리지 않고 결과를 즉시 영구 저장한다.
- 중복 추가를 방지하고 완료 안내창에 전체·신규 해금 수를 표시한다.
- 기존 `전부 초기화` 기능으로 첫 실행 상태로 복원할 수 있다.
