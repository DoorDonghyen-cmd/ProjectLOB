# Godot 시각 전투 개선

사용자는 엔진 비교를 종료하고 Godot으로 계속 개발할 것을 승인했다. 진행 플랫폼은 Godot 네이티브 Windows이며 엔진 전환이나 별도 웹 빌드를 작업 계획에 넣지 않는다. UI/규칙 변경은 앞선 위임 범위에서 진행한다.

## 문제와 목표
현재 공개 정보와 전투 계산은 검증되어 있지만 전장·탄창·사격이 텍스트 위주여서 플레이어가 행동을 시각적으로 이해하기 어렵다. 최종 아트 전에 Godot의 도형·애니메이션을 사용해 전술적 원인과 결과를 보이게 한다.

## 구현 계약
- 새 `battle_view.gd`, `ammo_visual.gd`, `magazine_view.gd`는 Godot CanvasItem 도형으로 표현한다. 이미지 리소스나 최종 아트 제작 범위가 아니다.
- 전투 모델/피해/거리/시드/보상 규칙은 변경하지 않는다. 모델을 한 번 정산한 뒤 저장하고 복제 상태로 연출한다.
- 일제의 모든 발을 실제 결과 순서로 표시한다. 죽은 적은 그 발의 피격 시 사라지며, 다음 표적을 바로 읽을 수 있다.
- 명중/도탄/빗나감/처치와 준비 버프/밀기/둔화를 색뿐 아니라 형태·짧은 문구로 구분한다.
- 장전 시 탄창으로 이동, 마지막 넣은 탄이 첫 위치로 들어오는 연출. 확정은 별도, 사격 중 입력 잠금, 전투 종료 뒤 결과 화면 전환.
- 연출 스킵 제공. 연출 중 종료해도 모델 저장은 이미 완료되어 이어하기에서 이중 정산하지 않는다.
- 메인 메뉴 개발자 테스트에 시각 전투/최종전 연습 진입점을 유지·보강한다.

## 검증
기존 규칙48개 유지, 실제 화면 클릭/연출 전후 HP·거리·탄창 대조, 일제 순서·재표적·입력잠금·장전취소 검증. 두 총기 7교전 실제 UI 재생으로 저장/재개 포함 회귀. 대표 장전/발사/넉백/도탄/완주 캡처. 별도 Windows 실행 빌드 제공.
