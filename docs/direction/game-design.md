## 플레이 약속

매 교전은 주어진 패와 빌드로 화력을 키워 전열을 돌파하는 선택이다. 한 런은 무기·탄환·파츠를 모아 가산·배율·타격 수를 자신만의 방식으로 성장시키는 과정이다. 순서는 지원 효과를 전달하는 수단이며 정해진 탄종 짝을 외우는 것이 목표는 아니다. 적의 이동은 시간을 쓰는 결정의 비용이며, 빠른 손놀림을 요구하지 않는다.

[발열 중심 설계](heat-system.md)를 본편에 적용했다. 모든 탄의 열 변화량과 무기별 한계를 공개하며 한계 도달 탄까지 발사한 뒤 중단한다. 전투가 계속되면 기본 재장전+냉각1턴을 자동 처리한다. 일반 재장전은 무기별 일정량만 냉각하며 잔열을 다음 탄창에 남긴다. 강제 재장전은 열0, 증강의 사격 입력 사이에는 열 유지다. 화면은 현재 열과 사격 중 최고 열·미발사 잔탄·전체 경과 턴을 연결한다.

## 전투

- **마지막에 장전한 탄부터 발사한다.** 새 탄은 발사 레일 맨 앞에 들어가며 실제 실행은 왼쪽부터다. 철갑→연발→증폭을 장전하면 증폭→연발→철갑으로 발사한다. 예측과 확정 시 배열을 다시 뒤집지 않는다.
- 마지막 발사 고정 탄은 빈 레일에 먼저 장전하고, 첫 발사 고정 탄은 마지막에 장전한다. 제약을 어기는 삽입을 자동 재배치하지 않고 카드에 `먼저 장전` 또는 `선두 탄 회수`를 표시한다. 전장 압축탄도 같은 규칙이다.
- 확정 전 드래그/앞뒤 버튼은 보이는 발사 순서를 직접 편집한다. `맨 앞 회수`는 현재 첫 발사 탄을 빼며 선택 회수는 선택한 탄을 뺀다. 기존 저장의 이미 구성된 발사 순서는 보존하고 새 입력부터 새 장전 규칙을 적용한다.
- 확정 전에는 회수·교체를 쉽게 할 수 있어 실험을 장려한다. 확정과 사격의 경계 및 재장전 시간은 분명하게 표시한다.
- 연쇄형 사격 자체는1턴이다. 과열 시 강제 재장전 시간까지 같은 입력에 포함한다. 증강은 처치 시 계속하며 생존 표적 또는 발열 한계에서 멈춘다.
- 무작위 패는 적응을 만들고 산개의 무작위 표적은 분산 빌드의 성격을 만든다. 가능한 결과를 확정 결과처럼 그리지 않는다.
- 적은 고유 전열 위치를 유지한다. 새로운 적이 오면 기존 적의 수직 위치를 바꾸지 않는다.
- 적마다 HP 외에 필요한 전술 선택이 읽혀야 한다. 장갑·배리어·빠른 접근·전기 약점은 작은 긴 문장 대신 형태와 대표 수치로 구분한다.
- 화상은 시간을 쓰는 동안의 피해, 전이는 여러 적에게 전달되는 피해, 증폭은 다음 탄환과의 조합으로 구분한다.

현재는 플레이어 HP 없이 적이 0m에 닿으면 패배하며, 일반 무기는 가장 가까운 적을 자동 표적으로 삼는다. [탄환·적 대응 통합](ammo-combinations.md)으로 압력두꺼비·압력탄을 캠페인에도 적용했다. 압력탄은 생성 다음 턴부터 6m씩 접근하며 가장 가까우면 산개도 확정 요격한다. 본체 처치 후에도 남고 0m 도달 시 패배한다. 우회탄은 앞 적을 건너뛰지만 최근접 압력탄 요격이 우선한다. 나머지 [몬스터 목록](monster-roster.md)의 새 아트·이름은 후속이다.

## 패 선택과 순환

[개별 카드 순환](ammo-cycle.md)이 새 등반에 적용된다. 기본탄도 소유 카드이며 복장 가방(시작 작업복5장, 획득 최대10장)에 포함한다. 이전 별도 기본탄 공급/탄창+2 패 규칙은 해당 이전 저장에만 남는다. 재장전하면 미사용 패도 사용 더미로 보내고 새 패를 뽑는다. 남은 드로우 더미를 먼저 쓰고 비었을 때 사용 더미를 섞는다. 패 교환은 항상 정확히1장 대1장이며, 압축 후 줄어든 패나 이전 저장의 작은 패를 추가로 채워 주지 않는다.

## 탄환 발견과 조합

[탄창·파츠·총기 연결](build-synergy.md)의18종 전술 보급을 따른다. 기존 [탄환 발견·연계·과열](ammo-combinations.md)에 다음 패 예약·특수 행동 차단·화상 이동·탄종 결산 역할을 추가했다. 무기별 시작 덱은 3~4종으로 좁히고 보상/상점에서 새 역할을 발견한다. 기본 피해를 올리는 것 외에 장갑 개방, 화상 전환, 처치 연계, 후열 공격, 재장전 부담 조절이 순서의 이유가 된다. [탄환 등급](ammo-grades.md)에 따라17계열의 일반2장→고급1장 압축을 지원한다. 고급은 발열·점유·순서 비용을 동반하며 파츠의 런 전체 변형 역할도 유지한다.

## 무기와 파츠

[파츠 역할](parts-builds.md): 특정 탄을 모으고 발사 순서·일반/고급 투자를 달리할 이유를 만든다. 조합/순서/발열/패 순환/압축·탄창으로 나누되 필수 역할 슬롯은 없다. 가속 총열은 원래 관통탄만, 과구경 총열은2칸 공격탄만 강화한다. 교차 급탄기와 압축 안정기가 일반 유지/압축 준비의 다른 선택을 지원한다.

| 현재 무기 | 만드는 선택 | UI에서 먼저 보여 줄 것 |
| --- | --- | --- |
| 보행자 | 공격탄 화력과 보조탄의 순서 조합 | 연쇄·공격탄+2·열 한계12 |
| 쇄도 | 같은 적의 3번째 적중을 계산 | 누적 적중과 추가 피해 순간 |
| 산개 | 여러 표적에 효율이 남는 구성 | 무작위 표적, 가능한 피해 범위 |
| 압쇄 | 지속 피해·전이를 활용 | 화상과 전이의 강화 |
| 증강 | 강한 한 탄으로 처치선을 연결 | 두 배 효과와 처치 연쇄 종료 |

파츠는 부품 자체의 이름보다 실제로 플레이가 어떻게 바뀌는지가 먼저 읽혀야 한다. 장착 영역에서 슬롯과 활성 효과를 연결하고 상점에서는 구매 후 변화와 대가를 비교한다. 수치 원본은 콘텐츠 데이터 하나로 유지한다. 파츠 카드를 읽을 때 모든 세부 계산을 요구하지 않되 정확한 조건은 한 번의 상세 입력으로 제공한다.

현재 상점은 파츠의 역할과 보유 탄환의 연결 예시를 표시한다. 예비 급탄기는 교환+1회로 조합 탐색을 돕는다. 새 등반에서는 별도 기본탄 보급이 없다. 다른 파츠의 피해·코어 대가는 유지한다. 통제 비교의 평균 턴만으로 모든 빌드의 우열을 확정하지 않는다.

짧은 탄창은 냉각 약실로 재장전 냉각을 강화할 수 있고, 긴 탄창은 연쇄 방열기·예약 급탄기·연계탄의 공간을 확보한다. 확장만으로 열 한계가 늘어나지 않는다. 총기별 효과 강도와 사격/재장전 시간을 유지하며 상점·장비에서 탄창·손패·냉각량의 실제 변화를 보여 준다. 세부 규칙은 [빌드 연결](build-synergy.md)을 따른다.

## 등반 경로

새 등반은 [맵v2](route-map.md)의5지역45개 방문 장소를 사용한다. 지도 노드는 실제 건물의 한 층이 아니며, 사용자 결정에 따라1F·45층·LV번호 같은 층수 표기 대신 구역과 경로를 보여 준다. 매번 출발4곳과 분기·합류, 상점·정비·신호·정예의 배치가 시드에 따라 달라진다. 정예에서 파츠를 노릴지, 크레딧을 모아 상점으로 갈지, 정비에서 압축/제거/코어 충전 중 하나를 할지 선택한다. 기존 저장은 이전35방 맵을 유지한다. 구체적인 길이와 경제는 첫 구현값이다.

## 압축과 경제

[등급·압축 성장](ammo-grades.md): 상점 영구 압축18Cr/방문1회, 덱 최소8장. 관문/정비의 기존 성장 기회를 유지한다. 두 번째 지역부터 고급 발견 후보를 추가하며 새 진열은 일반12Cr/고급24Cr다. 전투 임시 압축과 영구 성장은 구분한다.

동일 탄 두 장을 한 장으로 압축하는 성장은 덱 순환·탄창 점유·발사 위치를 함께 바꾼다. 현장 압축은 보유 코어를 소비하고 상점 또는 새 맵의 정비 선택으로 충전한다. 코어 파츠의 예외는 일반 규칙과 구별해 표시한다. '매 전투 무료 1회'라는 오래된 설명을 사용하지 않는다.

상점의 주 결정은 현재 빌드를 바꿀 상품이다. 재화·상품·현재 장착 파츠·선택 상품 비교가 한 동선으로 이어진다. 충전·리롤·장비 관리는 보조 행동으로 둔다. 보상은 3개 선택의 차이를 비교하고 획득 뒤 덱 변화가 보이게 한다.

현재 구현: 새 런 30Cr, 파츠 30Cr, 진열 교체는 한 상점에서 3→5→7→9Cr(상한9). 첫 상점은 다른 역할의 일반 파츠 둘을 우선하고, 이후는 일반/코어를 우선 섞는다. 미등장·미소유 파츠 우선 규칙은 역할 분류보다 우선한다. 환기구 전투의 거리−2m에는 크레딧 보상+6Cr를 연결한다. 이 보너스는 크레딧 보상을 고를 때만 받으며, 비전투 환기구의 압박을 받은 계단 전투에는 붙지 않는다.

## 첫 지역의 도입

첫 전투는 소유 덱에서 조합 예시를 첫 패에 넣고 장갑 없는 두 적(HP8/12·거리18/22m)을 제공한다. 보행자의 증폭·파쇄·냉각에는 공격탄+2를 적용하지 않는다. 다른 편성의 접근 거리 조정은 [발열 설계](heat-system.md)를 따른다. 2층 전투에 장갑, 3층 전투에 전기 약점과 세 적을 소개한다. 첫 보상에는 철갑탄을 포함한다. 4층 상점에서 파츠를 고르고 이후 파츠 발동·증원을 경험한다. 분기를 건너뛰는 자유를 유지하며 안내를 필수 조작으로 강제하지 않는다. 전투 안내는 기존 선택 제목 옆의 한 줄이며 힌트 설정으로 숨긴다.

## 전체 흐름 재설계

주인공의 최신 선택 외형은 C 복장+B 방한모이며 별도 전투 샘플에서 35% 축소한 크기를 사용자가 확인했다. 복장/헬멧 획득과 교체는 [외형 후속 설계](appearance.md)로 관리한다. 독립 두 칸·영구 수집은 디렉터 설계이며 능력치 효과는 미정이다. 현재 무기·파츠 슬롯과 수집 UI에 이미 구현된 것으로 간주하지 않는다.

| 화면 | 플레이어의 결정 | 구성 기준 |
| --- | --- | --- |
| 메인 | 계속할지 새로 시작할지 | 도시의 분위기, 저장 요약, 주 행동 |
| 총기 선택 | 어떤 전투 방식을 택할지 | 무기 실루엣, 한 줄 역할, 선택 무기 설명과 출격 |
| 지도 | 어떤 위험·성장을 택할지 | 가까운 분기와 목적지, 비용, 이동 확정 |
| 전투 | 패를 어떤 순서로 실행할지 | 적 위협, 발사 레일, 손패, 사격 결과 |
| 보상 | 빌드에 무엇을 추가할지 | 선택 간 차이, 보유 수량, 확정 |
| 상점 | 어떤 빌드 변화를 살지 | 상품, 현재 빌드, 이득·대가, 가격 |
| 장비 | 어떤 파츠를 함께 쓸지 | 장착 5칸과 선택 부품 비교 |
| 결과 | 무엇이 성공/실패했는지 | 마지막 전투 근거, 이번 빌드, 다음 행동 |

## 검증할 가설

사용자는 강한 탄환 조합에 따른 리스크가 부족하다고 피드백했다. [탄환 출력과 대가](ammo-risk.md)의 비교 샘플에 고출력 증폭과 다음 재장전 +1턴을 구현했다. 후속 원거리 샘플에서 요격에 쓴 증폭도 후속 탄을 강화하고, 늘어난 재장전 시간에는 압력탄이 실제로 추가 접근한다. 이후 탄종·적 대응과 종합한 개발을 승인받아 고출력 보급과 냉각탄을 캠페인에 연결했다. 현재는 [발열 규칙](heat-system.md)이 기존 고출력 전용 추가 턴을 대체한다. 최종 수치와 장기 재미는 미확정이다.

순서 실험이 보수적인 기본탄 반복보다 매력적인가, 다수 적이 계산의 다양성을 만드는가, 파츠 선택이 런마다 달라지는가를 실제 플레이로 검증한다. 예측을 숨겨 난도를 만들거나 불필요한 수치를 추가하지 않는다. 새 맵45방의 길이와 초반 공개 속도는 사람의 피로도 확인 뒤 조정한다.

## 이번 구현과 후속 범위

전투·저장 기반을 활용해 비전투 UI, 조합 편집, 파츠 결과 전달과 첫 지역·경제를 구현했다. [4번까지의 변경과 검증](../qa/reports/progression_2026-10-03.md)을 따른다. 본편 전투는 승인된 주인공·주거구 배경을 재사용하며 적과 지역별 환경은 임시 아트다. 세계관·레퍼런스 정리와 새 도트풍 채택을 거쳐 C 복장+B 방한모 주인공과 주거구 배경을 [별도 실제 전투 샘플](../qa/reports/tower_art_sample_2026-10-03.md)에 적용했다. 전체 무기 전용 애니메이션, 지역별 배경 세트, 적의 완성 스프라이트, 복장/헬멧 수집·교체와 사운드는 후속 항목이다. 구현·자동 검사 완료와 사람의 이해도/전체 아트 완료를 구별한다.
