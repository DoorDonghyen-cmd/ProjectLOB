# 탄환 발견·연계·과열

2026-10-04. 사용자는 발열 비용, 적 대응의 의미, 탄종과 조합 확장을 종합한 개발을 승인했다. 아래 수치와 보급 배치는 디렉터의 첫 구현안이며 사람의 재미 검증을 마친 확정 밸런스가 아니다.

후속 사용자 테스트와 [선택 가치 감사](../qa/reports/ammo_choice_2026-10-04.md)를 반영해 [발열 규칙](heat-system.md)을 본편에 적용했다. 모든 탄에 열 변화량을 두며 과열 시 후속 발사 중단·강제 재장전, 냉각은 현재 열 감소로 변경했다. 보행자 보조탄 피해와 적의 공개 접근 시간도 함께 조정했다. 효과의 존재나 자동 승리율만으로 재미가 완성됐다고 판단하지 않는다.

## 한 탄창의 선택

- 전술 보급은 기존 여섯 역할 + 파쇄·기폭·추격·우회·냉각 + 고출력 증폭에 방출·과급을 더한 14종. 기본탄과 압축 변형은 이 수에 포함하지 않는다.
- 시작 덱은 무기별 3~4종, 10장. 새로운 역할은 전투 보상·보급·상점에서 발견한다. 기존 저장 덱은 바꾸지 않는다.
- 보상 두 칸은 현재 덱의 연계 후보와 미보유 탄환을 함께 제안한다. 복제 탄환도 압축을 위한 유효한 선택으로 남긴다. 첫 보상은 다음 장갑전을 위한 철갑을 보장한다.
- 1~2층은 기존 여섯 종, 3~4층부터 파쇄·기폭·추격, 5층부터 우회·냉각·고출력·방출·과급을 포함한다. 상점은 아직 진열하지 않은 탄환을 우선한다. 파츠 진열과 장착 규칙은 유지한다.

[열 기반 추가 탄과 파츠](heat-builds.md): 과급은 발사 전 고열 피해, 방출은 마지막 위치의 열 전환이다. 새 두 탄도 압축 변형은 없다.

## 신규 역할

| 탄환 | 선택을 바꾸는 효과 | 대가와 한계 |
|---|---|---|
| 파쇄 | 타격 후 장갑 감소. 태세 전환 뒤에도 유지 | 자체 피해가 낮음. 지금 발사는 감소 전 장갑 적용 |
| 기폭 | 남은 화상 총 피해를 즉시 지급, 화상 제거 | 먼저 불붙여야 함. 지속 피해를 두 번 받지 않음 |
| 추격 | 같은 탄창의 직전 탄이 적을 처치했으면 추가 피해 | 요격·시간 경과 화상 처치는 조건에서 제외. 비처치탄을 끼우면 끊김 |
| 우회 | 앞 적을 건너뛰어 두 번째 적 타격 | 앞 적의 접근은 계속됨. 산개는 앞 적을 제외한 무작위. 최근접 압력탄은 요격 우선 |
| 냉각 | 현재 열−3, 증강−6 | 기본 피해0·탄창 한 칸. 과열에 도달하기 전에 발사해야 함 |
| 고출력 증폭 | 다음 두 발에 큰 증폭 | 발열5. 무기 한계 도달 시 후속 중단·강제 재장전 |

화염은 지속 피해라는 정체성을 유지한다. 기폭은 별도 탄환이며 기존 화상량·무기의 턴당 화상 피해로 계산한다. 추가 속성이나 상태 게이지는 만들지 않는다. 신규 다섯 종과 고출력은 이번 단계에 압축 변형을 추가하지 않는다. 기존 여섯 종의 상점·전투 압축은 유지한다.

## 적과 UI

일반 전투 후반부터 장갑 전열, 배리어 전열, 장갑 뒤 원거리의 세 편성을 순환한다. 보조 적은 낮은 HP를 유지한다. 장갑은 관통/파쇄/화상/과열 화력, 배리어는 다중 타격/화상·전이, 원거리는 전열 돌파/우회/발사 후 요격으로 대응한다. 한 탄종 소지가 전투의 필수 열쇠가 되어서는 안 된다.

기존 비교 장면의 승인된 배경·주인공 크기와 원거리·과열 표시를 캠페인에도 연결한다. 탄환 카드는 서로 다른 픽셀 실루엣, 피해·관통, 한 줄 역할을 유지한다. 발사 순서 예측에는 장갑 감소·기폭·추격·냉각 결과, 확정 버튼 옆에는 이번 사격 후 재장전 비용과 위험을 보여 준다. 산개는 확정 결과처럼 표기하지 않는다.

## 검증 범위

실제 모델 기반 순서 비교, 조건 초기화, 파츠·무기 배율, 산개 분기 예측, 구 저장과 신규 상태 왕복, 보급 다양성, 모든 무기의 35층 경로 도달과 실제 UI 입력을 검증한다. 자동 도달 검증은 미래 패를 읽는 탐색이므로 사람의 난이도·재미 검증을 대신하지 않는다. 최종 몬스터 아트·사운드·타격 폴리싱은 별도 잔여 작업이다.
