# 화면 연결과 행동 소리

**2026-11-08 강화 사격 궤적·적중** — 일반 피해에는 기존 탄도와 타격 연출을 쓴다. 가산 증폭은 A 예광선·스파크, 단일 배율은 B 불씨·파편, ×3 이상이나 겹친 배율은 C 겹잔광·충격파를 쓴다. 새 효과는 적에게 실제 피해를 준 사격에 적용하며, 비행과 적중은 같은 단계와 파츠 색을 쓴다. [본편 화면과 검증](../qa/reports/shot_fx_live_2026-11-08/README.md)

**2026-11-08 전투 피격 반응** — 일반 피해는 짧은 몸 반동, 강한 피해나 유효한 증폭은 전장만 50~80ms 멈춘다. 한 번의 사격 명령에서 추가 정지는 최대 120ms이며 최종 처치에는 기존 피니시를 쓴다. 차단·감속이 적용된 순간에는 별도 경직 동작을 재생하고, 이동 감속이 남은 적의 발밑에는 낮은 보랏빛 표식을 그린다. 즉시 연출에서도 실제 감속 표식을 유지한다. [실제 화면과 검증](../qa/reports/enemy_hit_feedback_2026-11-08/README.md)

**2026-11-06 통합 검수1차:** [실제5구역/반복 검수](../qa/reports/presentation_integration_2026-11-06/README.md). 입력 잠금 동안 활성 사격의 검은 자식 글자가 비활성 배경에 남지 않도록 기존 비활성 잉크를 직접 적용했다. 배치/클릭 영역/시간/계산은 유지한다. 반복392/본편1,532/HUD11,558 실패0, 전체 기록/저장 일치. 사람 판독·반복 청감과 S26 지속 성능/발열은 미검증이다.

**2026-11-06 버튼/처리 반응1차:** [실제 입력·결과별 확인선과 구매 캡처](../qa/reports/interaction_fx_2026-11-06/README.md). 현재 테마에 맞춰 눌림/복귀와 잔액·물품·슬롯/강화 탄 반응을 구분한다. 성공한 명령 뒤에만 표시하고 취소/거절/페이지 이동에는 완료를 만들지 않는다. 원래 클릭/확정음을 유지하며 무료 정비 확정에도 기존 확인음을 연결했다. 배치/크기·포커스/저장을 유지하고 즉시 설정은 정적인 확인선만 남긴다. 다음은 전체 화면 통합 검수다.

**2026-11-06 타격·속성 외형1차:** [장갑·차폐/전이·불꽃](../qa/reports/surface_fx_2026-11-06/README.md)을 실제 영수증/지속 상태에 연결했다. 장갑 반사광/파편, 차폐 격자/균열, 전류와 적 사이 불씨·몸/바닥 화염을 구분한다. 기존 피해 숫자/파츠 배율색과 소리·행동 시간/계산은 유지했다. 세부 재질·사람/실기기 후속은 남으며 다음은 버튼/구매·장착 상호작용이다.

**2026-11-06 발사 외형1차:** [총기별 총구 섬광/탄도](../qa/reports/firing_fx_2026-11-06/README.md)를 실제 무기 등록과 파츠 적중색에 연결했다. 실제 결과당 한 번 발사하며 이동 거리 내에서 꼬리를 제한하고 출발점을 고정한다. 기존 사운드/시간/반동은 유지했다. 재질·차폐 타격/전이·불씨와 UI 상호작용의 후속 범위는 별도로 남는다.

피니시에는 대상 중심 최대25% 전장 줌을 함께 적용한다. 사용자 요청에 따라 보통 설정에서 전체2.5초 동안 줌인·슬로우·줌아웃 후 복귀하며 HUD는 고정, 여러 대상과 숫자는 함께 프레이밍한다. [현행 구현·검증](../qa/reports/finish_zoom_2026-10-18.md).

**2026-10-18 사용자 피드백 적용:** 발사 결과의 간결한 구성은 유지한다. 실제 타격 숫자를 일반/강화/큰 피해/처치로 구분하고, 전투를 끝내는 마지막 처치만 짧은 로컬 슬로우로 강조한다. 기본탄 위력2~3 빈도는 [밸런스 관찰](ammo-build-roles.md#플레이-관찰--2026-10-18)로 보류. [구현·실제 화면·검증](../qa/reports/finish_feedback_2026-10-18.md).

10월17일 후속: 코어 배율/다수 처치도 강한 발사음에 연결하고 다수 처치 충돌에 기존 저음 효과를 겹친다. 실제 피해 합계·처치 수·짧은 충돌 정지는 [화력 성장](damage-growth.md#사격의-결과를-보여-주는-방식)을 따른다. 새 음원 제작이나 최종 청감 확정은 아니다.

상태: 사용자의 다음 단계 진행 승인 범위에서 적용한 디렉터 구현안. 소리의 미감·장시간 피로도는 사람 플레이로 확인한다.

## 목적과 구현

청회색 도트 UI의 배치와 전투 계산을 유지하면서 행동의 시작·충돌·위험·완료를 귀로도 구별한다. 새 페이지는72% 밝기에서100%로0.16초 동안 돌아온다. 빠르게 설정은0.09초, 즉시는 전환을 생략한다. 덮개나 입력 대기 시간을 추가하지 않는다. 같은 전투의 장전·확정·예측 갱신은 전환으로 취급하지 않는다.

| 실제 행동 | 피드백 |
|---|---|
| 공통 버튼 | 작은 클릭 |
| 탄환 삽입 / 장전 확정 | 삽입음 / 잠금음 |
| 일반 / 증폭·기폭 발사 | 짧은 발사음 / 낮고 무거운 발사음 |
| 피해 / 장갑 감소 | 명중음 / 금속 파열음 |
| 과열 중단 | 짧은 두 음의 하강 경고 |
| 재장전 첫 턴 / 완료 | 개폐음 / 완료음 |
| 실제 열 감소 | 짧은 배출음 |
| 보상 화면 최초 진입 / 획득·구매 성공 | 세 음의 보상음 / 수령 잠금음 |

- 별도 녹음 없이 원본 합성 WAV12개 제작. 생성 도구·매니페스트·해시 보존. 음악·환경음·최종 무기별 소리 세트는 아직 없다.
- 효과음 설정은 끄기/25/50/75/100%, 기본50%. 기존 설정은50%로 보완하며 캠페인 저장과 분리한다. 끄기는 재생 중인 소리도 즉시 멈춘다.
- 즉시 연출에서는 전투 진행 소리를 생략하고 조작·획득 피드백은 유지한다. 건너뛰기는 현재 재생과 그 행동의 남은 소리를 생략한다. 다음 행동에서 복구한다.
- 실제 화면 이벤트에만 연결한다. 예측 계산, 거절된 구매, 반복 redraw에서 성공 소리가 나오지 않는다. 최대6개 재생 노드와 같은 소리60ms 간격 제한으로 누적을 제어한다.
