# 태그 기반 탄환·파츠 — 비교 시험판

2026-11-10. 사용자 "만일 너가 탄환과 파츠를 처음부터 설계한다면?"에 대한 태그 기반 설계를, 사용자 지시("태그 기반 탄환 파츠 설계를 별도로 진행해주고 두 가지 다 테스트 해봐야할 것 같아")에 따라 **현재 구성과 나란히 고를 수 있는 시험판**으로 만들었다. 기준 구조는 [성장·빌드 구조 v2](growth-structure.md), 현재 구성은 [탄환·파츠 재정비](ammo-parts-v2.md)다.

## 결정 상태

- **사용자 확정(11-10)**
  - 태그 기반 설계를 별도로 만들고, 현재 구성과 둘 다 시험한다.
  - 화염 파츠를 추가한다(화염 연소기·잔불 추격기의 수치는 디렉터 결정).
  - 11-11: "숫자를 키워야 잡는 체감은 좋은 것 같아". 피해 숫자를 키워 적을 잡는 성장(태그 파츠의 +N·×N)을 파츠의 중심 축으로 둔다. 탄 기능 강화(관통·밀치기 등)는 보조로 남긴다. 같은 날 "성장 체감도 느껴지고 숫자 플로팅이 연달아 탁탁 뜨는 느낌도 좋고" — 성장이 보이는 것과 연속 피해 숫자 표시는 지키고 키울 장점이다.
- **디렉터 결정**(되돌리기 쉬움, 사람 플레이 전)
  - 태그 목록, 파츠 15종의 효과와 수치, 바꿔 빼는 파츠 11종.
  - 등반 설정에서 고른다. 기본값은 현재 구성이다.
- **검증되지 않은 가설**
  - 태그가 있으면 새 탄을 추가할 때 파츠를 다시 만들 필요가 줄어든다.
  - 사람이 '이 탄은 화염·단타'를 보고 파츠를 고르는 쪽이 더 쉽다.
  - 아래 자동 등반 결과는 이것을 증명하지 않는다.

## 무엇이 다른가

| | 현재 구성 | 태그 시험판 |
| --- | --- | --- |
| 파츠가 보는 것 | 탄 이름(예: 소이탄 +2) | 탄의 태그(예: 화염 +2) |
| 새 탄을 넣으면 | 그 탄용 파츠가 따로 필요 | 태그만 붙이면 기존 파츠와 바로 연결 |
| 파츠 순서 | 대부분 무관 | 복제 기판만 순서를 본다 |
| 바뀌는 범위 | — | 탄 이름을 보는 가산 파츠 11종만 태그 파츠 15종으로 교체. 위치·규칙·구동·운용 파츠는 그대로 |

## 태그

탄마다 원소·역할 태그가 있고, 형태(단타/다회)는 실제 타격 수에서 정한다. 기본탄은 태그가 없다. 공격탄은 원소 + 형태(+ 역할) 최대 3개다.

| 계열 | 태그 | 카드 글자 |
| --- | --- | --- |
| 연타·철갑·우회·연계 | 물리 (+ 단타/다회) | 물 · 단/다 |
| 소이 | 화염 · 단타 | 화 · 단 |
| 기폭 | 화염 · 마무리 (+ 형태) | 화 · 마 |
| 불씨 | 화염 · 준비 | 화 · 준 |
| 전격 | 전기 · 광역 (+ 형태) | 전 · 광 |
| 추격 | 물리 · 마무리 (+ 형태) | 물 · 마 |
| 충격 | 물리 · 제어 (+ 형태) | 물 · 제 |
| 차단 | 제어 | 제 |
| 열방출·냉각 | 열(열방출은 + 형태) | 열 |
| 증폭·배율·잔열 증폭·파쇄·예약 | 준비(파쇄는 물리도) | 준 |

11-11: `타격` 태그를 뺐다. 읽는 파츠가 없고 '공격탄'이라는 뜻을 형태 태그가 이미 담는다. 카드에 3칸까지만 보이게 하기 위해서다.

## 파츠 15종

| 파츠 | 등급 | 종류 | 효과 |
| --- | --- | --- | --- |
| 화염 점화기 | 일반 | 가산 | 화염 탄 타격당 +2 |
| 전기 증폭 코일 | 일반 | 가산 | 전기 탄 타격당 +2 |
| 다회 가속기 | 일반 | 가산 | 다회 탄 타격당 +1 |
| 단타 조준경 | 일반 | 가산 | 단타 탄 +2 |
| 마무리 조준기 | 일반 | 가산 | 마무리 탄 타격당 +3 |
| 단타 배율기 | 고급 | 배율 | 단타 탄 ×1.5 |
| 고열 배율기 | 고급 | 배율 | 발사 전 열이 한계의 절반 이상이면 ×1.5 |
| 처형 회로 | 고급 | 배율 | 체력 절반 이하 적 ×2 |
| 경직 추격기 | 고급 | 배율 | 감속·차단된 적 ×2 |
| 화염 탄약고 | 고급 | 덱 구성 | 덱에 화염 탄 6장 이상이면 화염 ×1.5 |
| 혼합 탄띠 | 고급 | 탄창 구성 | 장전 탄창의 태그 4종 이상이면 타격당 +3 |
| 화염 연소기 | 일반 | 화상 | 화염 탄이 거는 화상 +1턴(최대 6턴) · 11-10 추가 |
| 잔불 추격기 | 고급 | 배율 | 화상 중인 적 ×2 · 11-10 추가 |
| 화염 기록기 | 고급 | 성장 | 화염 처치 3회마다 화염 +1(최대 +6), 분해하면 사라짐 |
| 복제 기판 | 희귀 | 복제 | 왼쪽에서 가장 가까운 태그 파츠 효과를 한 번 더(사이의 일반 파츠는 건너뜀) |

- 모든 효과는 특수 공격탄에만 붙는다. 기본탄과 지원탄에는 붙지 않는다.
- 화염 연소기는 화상 턴 수를, 나머지는 타격 피해를 바꾼다. 복제 기판은 화상 +1턴도 한 번 더 적용한다.
- 가산은 계산식의 '가산' 칸에, 배율·구성은 구동 배율 뒤에 곱한다. 전투 계산 줄과 파츠 발동 표시에 같은 이름으로 나온다.

**바꿔 빼는 파츠(태그 등반에서 제시 안 함)**: 가속 총열, 열축전 코일, 전이 축전기, 충격 가이드, 증폭 시퀀서, 점화 약실, 배리어 파쇄기, 처형 조준기, 교차 급탄기, 삼중 시퀀서, 예약 급탄기. 이미 가진 것은 그대로 쓸 수 있다.

## 화면에서 보이는 곳 (11-11)

사용자 플레이 피드백: "탄환 카드가 아직 기본탄 이런 형태로 되어 있어서 그런지 태그 효과를 잘 모르겠어".

- **전투 탄창 카드**: 카드 위쪽 빈 줄에 태그 글자(화·단 등)를 색으로 보여 준다. 장착한 태그 파츠가 읽는 태그는 **채운 칸**, 아닌 태그는 글자만. 태그 없는 기본탄에는 아무것도 없다(`tag_chips.gd`).
  - 처음에는 꺼진 칸을 테두리 상자로 그렸는데, 16px 글자가 칸을 거의 채워 켜진 칸과 구별되지 않았다. 글자만 남겼다.
- **탄 상세**(전투 'N번 상세', 보상, 상점, 탄약고, 탄약 가방, 정비소): 맨 위에 '태그 · 화염 · 단타', '적용 · 화염 점화기 +2 / 복제 기판(복제) +2', '조건부 · 처형 회로 ×2(체력 절반 이하)'를 쓴다. 기본탄은 '태그 없음', 지원탄은 '태그 파츠 효과는 받지 않고 덱 구성·탄창 태그 수에만 셈'(`readability.gd::description`, `tag_build.gd::round_summary`).
- **전투 빌드 창**: 카드 글자 범례와 지금 채워지는 태그.
- **남은 점**: 자동 장전 탄창의 대부분이 기본탄이라 태그 카드가 몇 장 안 된다. 기본탄에 태그를 줄지는 사람 플레이 뒤에 정한다(줄 경우 단타 조준경 등이 기본탄 화력을 크게 바꾼다).

### 효과가 보이게 (11-11, APK 플레이 뒤)

사용자: "느낌 괜찮아 과열 리스크도 크고, 단 태그 식별이 어렵고 효과가 있는지 잘모르겠어".

- 원인: 태그 배율이 총기 내장 구동 배율에 합쳐져 피해 숫자 아래 이름표에 '화력 ×1.5'로 나왔고, 태그 가산은 다른 가산과 섞여 숫자로만 보였다. 같은 이유로 리액터의 '고열 피해' 판정이 태그 배율에도 켜지는 문제가 있었다(구동 성장 조건이 잘못 채워질 수 있음).
- **계산**: 구동 배율과 태그 배율을 따로 기록한다(`math.tag_percent`, `math.tag_add`). 고열 판정과 '화력·열압·돌파' 표시는 구동 배율만 본다. 피해 결과는 그대로다.
- **맞힐 때**: 피해 숫자 바로 아래에 태그 이름표를 태그 색으로 띄운다(예: `단타+2×2.25`, 복제분 포함). 계산 줄에 태그 배율이 따로 `×` 로 나온다.
- **탄창 카드**: 조건 없이 적용되는 태그 파츠(태그 가산·배율·덱 구성·혼합·성장)가 키우는 탄은 카드 숫자를 올린 값으로, **초록색**으로 보여 준다(예: 철갑탄 3 → 11). 소이탄처럼 카드 숫자가 화상인 탄은 색만 바뀐다. 조건부(고열·처형·감속·화상 중)는 탄 상세에서 본다.
- 태그 색: 단타·다회가 거의 흰색이라 배경에서 태그로 보이지 않아 단타 분홍, 다회 하늘색으로 바꿨다.
- 고친 문제: 발사 연출 중 비워진 칸에 태그 글자가 남았다. 연출 중 칸 갱신에도 같은 표시 함수를 쓴다.
- 검사: `tests/tag_float_ui.gd`(실제 리벳 전투에서 태그 이름표·초록 숫자·빈 칸 글자 없음).

## 고르는 곳

- 장비 화면 → 등반 설정 → '탄환·파츠 구성 · 비교 시험'에서 현재 구성 / 태그 시험판을 고른다.
- 고르면 등반 설정 버튼에 '· 태그'가 붙는다.
- 새 등반에만 적용된다. 같은 시드로 다시 시작하면 그 등반의 구성을 따른다. 이전 저장은 바뀌지 않는다(`tag_build_version` 없음 = 현재 구성).
- 파츠 상세에 덱에서 그 태그를 가진 공격탄(예: '다회 태그 공격탄 · 연타탄 7'), 혼합 탄띠는 탄창 태그 수, 복제 기판은 복제 대상이 나온다.
- 전투 HUD의 빌드 창에 '태그 시험판 · 장전된 탄창 태그 N종'과 기록기 누적이 나온다.

## 자동 등반 비교 (11-10)

운반 복장, 성장 v2, 상점마다 구동 정비, 관문 1회 숙련. 자동 구매는 주력탄 태그에 맞는 태그 파츠와 태그 조건이 없는 파츠를 원한다. 자동 장착은 구성마다 손으로 정한 우선순위를 쓴다(복제 기판은 마지막 칸).

**최종(화염 파츠 2종 추가 뒤, 시드 17·23·41 합계)**

| 총기 | 현재 구성 | 태그 시험판 | 마지막 보스 평균 턴(현재 → 태그) | 태그 등반 최종 장착 예 |
| --- | --- | --- | --- | --- |
| 리벳(단발) | 1027턴 | **831턴**(−19%) | 27 → 25 | 제3 격발기, 선두 격발기, 단타 조준경, 단타 배율기, 복제 기판 |
| 래칫(점사) | 694턴 | 876턴(**+26%**) | 10 → 18 | 제3 격발기, 연타 공명기, 다회 가속기, 경직 추격기, 타격 기록기 |
| 리액터(중화기) | 1425턴 | **1119턴**(−21%) | 25 → 21 | 화염 점화기, 잔불 추격기, 화염 연소기, 처형 회로, 복제 기판 |

9회 모두 두 구성에서 완주했다.

**읽을 점**
- **리벳·리액터는 태그 쪽이 빠르다**: 리벳은 단타 가산·배율이 겹치고, 리액터는 화염 파츠 3종에 처형·복제가 붙는다.
- **래칫은 태그 쪽이 느리다** — 11-11 정정: 같은 덱·같은 적에서 파츠만 바꾸면 111 → 110턴으로 같다. 아래 원인 추정은 틀렸고, 차이는 상점 경로에서 왔다. 당시 추정: 현재 구성의 래칫은 충격 가이드·증폭 시퀀서를 쓰는데, 태그 시험판에서 이 둘이 빠진다. 대신할 다회·제어 태그 파츠가 다회 가속기(+1)와 경직 추격기뿐이다.
- 화염 탄약고·화염 기록기·혼합 탄띠는 거의 쓰이지 않았다. 사람 플레이에서 고르는지 봐야 한다.

**화염 파츠 통제 비교**: 리액터의 실제 4·5구역 보스·정예 4전투 상태에서 장착 파츠만 바꿨다(`tests/tag_fire_bench.gd`, 적 턴).

| 파츠 | 합계 | 마지막 보스 |
| --- | --- | --- |
| 등반에서 산 그대로(화염 상태 파츠 없음) | 109 | 33 |
| 화염 3종(가산·연소기·잔불 ×1.5) | 112 | 27 |
| 화염 3종(잔불 ×2, 채택) | 103 | 26 |
| 화염 3종 + 복제 | 96 | 28 |
| 현재 구성(열축전 코일·점화 약실·충격 가이드) | 104 | 24 |

잔불 추격기 ×1.5는 같은 고급인 처형 회로·경직 추격기(×2)보다 약하고 합계가 오히려 늘어서 ×2로 올렸다.

**시험 중 고친 것**
- **화염 상태 파츠 2종 추가**(사용자 "화염파츠 추가해 줘"): 첫 비교에서 리액터 마지막 보스가 20 → 45턴이었다. 현재 구성의 열축전 코일(화상 +1)·점화 약실(화상 중인 적 +2)이 태그 시험판에서 빠지고 대신할 파츠가 없었기 때문이다.
- **복제 기판**: 처음에는 '바로 왼쪽 칸'만 봤다. 파츠는 장착한 순서대로 뒤에 붙으므로, 리액터가 일반 파츠 오른쪽에 복제 기판을 달아 효과가 0이었다. 지금은 사이의 일반 파츠를 건너뛴다.
- **자동 구매·장착**: 처음에는 태그 파츠 전부를 원해서 래칫이 무관한 전기 파츠를 샀다. 장착 우선순위가 현재 구성 파츠만 알아서, 리액터가 화염 파츠를 얻고도 끼우지 않았다. 둘 다 사람이 고르는 방식에 가깝게 고쳤다.
- 시드 하나(17)로는 파츠 종류가 늘 때마다 상점 제시가 달라져 결과가 크게 흔들렸다(리액터 518 → 399턴, 화염 파츠 미장착인데도). 그래서 시드 3개와 통제 비교를 함께 본다.

## 두 방식이 실제로 만드는 차이 (11-11)

사용자: "지금의 태그 방식과 이전의 방식이 구체적으로 어떤 차이를 만드는지부터 비교해 줘". `tests/scheme_compare_probe.gd`가 시드 17 등반의 4·5구역 14전투를 해법기로 다시 풀고 모든 발사를 집계했다([원자료](../qa/reports/tag_build_2026-11-10/scheme_compare_20261111.json)).

**같은 덱·같은 적에서 파츠만 바꿈**(현재 구성 등반의 전투에 태그 등반의 대표 파츠를 끼움)

| 총기 | 현재 구성 파츠 | 태그 파츠 | 14전투 턴(현재 → 태그) | 발당 피해 |
| --- | --- | --- | --- | --- |
| 리벳 | 제3 격발기·선두 격발기·전이 축전기·후미 점화기·가속 총열 | 제3 격발기·선두 격발기·단타 조준경·단타 배율기·복제 기판 | 259 → **216**(−17%) | 5.6 → 6.3 |
| 래칫 | 충격 가이드·제3 격발기·복열 노리쇠·증폭 시퀀서·연타 공명기 | 제3 격발기·연타 공명기·다회 가속기·경직 추격기·복열 노리쇠 | 111 → 110(같음) | 11.1 → 11.1 |
| 리액터 | 열축전 코일·점화 약실·충격 가이드·압축 안정기·확장 방열판 | 화염 점화기·잔불 추격기·화염 연소기·처형 회로·압축 안정기 | 268 → 270(같음) | 4.1 → 4.4 |

**읽을 점**
1. **파츠의 힘은 리벳에서만 달라진다.** 단타 조준경(+2) → 단타 배율기(×1.5) → 복제 기판(배율 한 번 더 = ×2.25)이 한 줄로 겹친다. 발라트로식 곱셈 빌드가 태그에서 처음 생겼다. 래칫·리액터는 파츠를 바꿔도 같은 전투의 결과가 같다.
2. **등반 결과 차이(리벳 −19%, 래칫 +26%, 리액터 −21%)는 대부분 파츠 힘이 아니라 경로 차이다.** 상점·보상에 나오는 파츠가 달라지면 사는 것, 쌓이는 돈, 받는 탄이 갈라진다. 예: 태그 등반의 래칫은 4·5구역에서 기본탄을 20발 쐈고 현재 구성 등반은 0발이었다.
3. **파츠가 하는 일의 성격이 다르다.** 현재 구성의 바뀐 파츠 11종은 대부분 탄의 기능을 키운다(관통 +2, 화상 +1턴, 밀치기 +1m, 배리어 한 칸 더, 전이 피해, 연계). 태그 파츠는 대부분 피해 숫자(+N, ×N)를 키운다. 태그는 비교·이해가 쉽고, 대신 총마다 다른 전투 방식(밀치기 거리, 관통)을 키우는 선택이 줄어든다.
4. **보이는 정도가 다르다.** 태그 파츠는 발동할 때마다 계산 줄에 남는다. 현재 구성의 가속 총열(관통 +2)은 14전투 동안 발동 표시가 한 번도 없었다. 효과가 위력 계산에 섞여 보이지 않는다.
5. **판단 문제는 둘 다 같다.** 무판단 사격에서 두 방식 모두 일반 전투를 거의 다 이기고 보스에서 멈췄다([무판단 사격 측정](../qa/reports/naive_play_2026-11-11/README.md)). 태그 방식은 '판단 없이 깨지는 문제'를 풀지 않는다.
6. 두 방식 모두 총기 내장 구동이 가장 많이 발동한다(발사의 30~45%). 바뀌는 것은 나머지 4칸이다.
