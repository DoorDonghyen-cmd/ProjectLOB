# 발열 기반 빌드 확장과 폴리싱

2026-10-04 · 본편 구현. [발열 기본 규칙](heat-system.md), [검증과 화면](../qa/reports/heat_builds_2026-10-04.md).

## 결정 상태

- **사용자 확인:** 쇄도 테스트 후 현재 발열·재장전 메커니즘을 긍정 평가하고 폴리싱·탄종·과열 제어 파츠 확장을 승인했다.
- **디렉터 결정:** 아래 이름·수치는 첫 구현값이다. 최종 밸런스나 사람의 이해도·재미 검증을 마친 값으로 취급하지 않는다.
- **구현:** 파츠3종·탄환2종을 실제 모델, 상점·보상·장비, 카드·레일·발동 피드백, 저장·정확 예측에 연결했다. 전술 보급14종, 파츠23종(빈 슬롯 제외). 시작 덱과 초기 정보량은 유지한다.

## 파츠와 비용

| 파츠 | 종류 / 효과 | 선택과 한계 |
|---|---|---|
| 확장 방열판 | 일반 · 열 한계 +3 | 고발열 연쇄의 여유. 별도 페널티 없이 장착 한 칸을 사용. 저발열 조합에는 직접 화력 파츠가 더 유리할 수 있음 |
| 회수 순환펌프 | 일반 · 처치한 탄 열 −2 | 탄 하나당 한 번. 적을 못 잡으면 냉각 없음. 열을 낮춰 다음 고열 효과가 꺼질 수 있음 |
| 잔열 노심 | 코어 · 고열에서 타격당 피해 +2 | 열 한계 −2. 코어1개 제한. 높은 열을 유지할수록 화력과 강제 재장전 위험이 함께 커짐 |

고열 조건은 **발사 직전 열 ≥ 최종 열 한계의 절반(올림)**. 자신의 발열로 자신의 보너스를 켜지 않는다. 방열판을 함께 장착하면 한계뿐 아니라 고열 진입점도 올라간다. 상점·장비 교체 화면에서 두 수치의 변화를 예고한다. 조건 수치는 고열탄 카드에도 공개한다.

처치 냉각은 탄의 타격·기폭·전이 처치 확인 → 냉각 → 최종 열로 과열 판정 순이다. 여러 적을 잡아도 한 탄당 한 번만 발동한다. 시간 경과 화상과 압력탄 요격은 제외한다. 현재 열까지만 줄이며 냉각을 저축하지 않는다. 타격당 화력 파츠의 +2는 증강에서도 그대로다.

## 신규 탄환

| 탄환 | 기본 피해 / 관통 / 발열 | 대표 규칙과 비용 |
|---|---|---|
| 고열탄 | 2 / 1 / +4 | 발사 전 고열이면 직접 피해 +4. 차가운 상태에서는 낮은 효율, 적 장갑과 과열 위험을 함께 비교 |
| 열방출탄 | 1 / 1 / 0 | 마지막 위치 고정. 발사 전 열 최대4를 소모하고 열1마다 피해 +2. 앞에서 과열되면 발사 불가 |

증강은 과급 보너스+8, 방출의 열1당+4이며 열 소모 상한4·발열 비용은 두 배로 만들지 않는다. 보행자의 공격탄 피해 보너스는 두 탄에도 적용한다. 마지막 장전 탄부터 발사하므로 열방출탄은 빈 레일에 먼저 장전해야 한다. 이후 탄은 열방출탄 앞에 들어간다. 이미 탄이 있으면 열방출탄 카드에 `먼저 장전`을 표시하며 자동으로 끝에 끼워 넣지 않는다. 위치 고정은 발사 순서 기준이다.

새 두 탄은 압축 변형이 없다. 첫 지역5층 이후 전술 보급·연계/발견 보상·미진열 우선 상점에 연결한다. 초기 덱에 강제 추가하지 않고, 이미 보유한 덱을 교체하지 않는다. 파츠는 기존 미진열 우선 순환과 무기 적합성 규칙을 따른다. 첫 상점에서 열 제어 부품을 필수 지급하지 않는다.

## 화면과 응답성

- 카드 실루엣과 한 줄 조건, 레일의 고열 보너스/열 전환, 파츠 실제 발동, 게이지의 현재/한계·최고 열·고열 진입 표시를 연결한다.
- 처치 냉각은 적중 결과 뒤에 보인다. 일반 재장전과 추가 냉각은 각각의 진행 턴을 표시한다. 최종 열은 실제 모델과 일치시킨다.
- 산개5발 이상은 별도 작업 스레드에서 모든 분기를 정확히 계산한다. 기다리는 동안 순서 편집·회수는 가능하고, 피해 예측은 숨기며 확정/발사는 계산 뒤 활성화한다. 현재 열은 계속 공개한다.
- 수정된 패가 들어오면 이전 계산을 취소하고 최신 패를 계산한다. 늦게 끝난 예측으로 현재 패를 덮지 않는다. 정보창을 읽는 도중 닫지 않고, 전투를 벗어나면 계산을 취소한다.
- 산개는 처치에 따른 열과 중단, 파츠 발동을 범위/확률로 표시한다. 근사 표본이나 유리한 분기만으로 확정 결과를 만들지 않는다.

## 확인한 선택 차이

- 같은 보행자 패 `고출력→연발→철갑→냉각`: 기본 한계12에서는3발 뒤 강제 재장전, 방열판 한계15에서는4발·열9로 종료.
- 열10에서 철갑→냉각: 순환펌프가 처치로 열2를 회수하면 두 탄 발사·1턴. 처치가 안 되면 첫 탄에서 과열·총3턴.
- 잔열 노심과 같은 `고출력/과급/방출` 패: 장갑4·HP40 비교 적에게 고출력→과급→방출26피해, 과급→고출력→방출16피해. 순서 효과의 기능 사례이며 평균 플레이 피해나 난이도 평가는 아니다.
- 처치 냉각은 다음 고열탄의 고열 보너스를 끌 수 있다. 낮은 발열 손패에서는 방열판 없이도 사격이 유지돼 다른 화력 파츠의 장점이 남는다.

## 남은 판단

Galaxy 실기에서 예측 대기 시간·읽기·터치 체감은 확인 전이다. PC에서 입력은 분리했지만 복잡한8발의 계산 자체는 약1초 이상 걸린다. 여러 시드/난도의 장기 빌드 다양성, 열 제어 부품이 과도한 필수품이 되는지, 방출의 마무리 효율과 압쇄의 안정성은 사람 플레이로 재평가한다. 비상 배출기 등 추가 부품은 이번 묶음에 넣지 않았다. 별도 게이지나 신규 속성은 늘리지 않는다.

## 후속 비교와 결과 전달

[2,400 독립 전투와 화면 검증](../qa/reports/heat_polish_2026-10-04.md) 후 현재 수치를 유지했다. 냉각형의 안전성, 고열형의 순서 민감도, 방열판과 처치 냉각이 고열 조건에 주는 영향을 실제 안내에 반영했다. 보상/엔딩은 최고 열·탄/파츠 냉각·강제 재장전을 요약하고, 교전 기록에서 출처별 냉각과 과열 후 면제를 구분한다. 실패 안내는 실제 마지막 행동과 압력탄 피격을 구분한다. 소이 관련 파츠는 피해가 아닌 지속 턴의 변화를 안내한다.

디렉터 판단은 현 수치 유지이며 최종 밸런스 확정이 아니다. 비교는 2파츠/10장 덱의 독립 전투이고 숨겨진 RNG를 보지 않는 두 고정 정책이다. 최적 플레이·실제 선택률·최대5파츠/압축/고난도 검증과 구분한다.
