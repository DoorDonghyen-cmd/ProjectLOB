# 전체 등반 탄창 개편

## 결정 상태

- 사용자 확정(2026-11-01): 별도 다섯 전투 여정의 탄창 개편을 전체 등반에 우선 통합한다. APK는 사용자가 별도로 진행한다.
- 구현 범위: 새 등반의 자동 전체 탄창 장전, 총기별 분할 사격, 잔탄 보존 냉각, 탄창 교체, 탄 선택 후 최대 두 발 빼내기, 라인 + 도트 HUD와 실제 사격 피드백.
- 지도·장소·상점·보상·관문·성장·최종 구역은 본편 Campaign의 기존 경로와 계산을 사용한다.
- 이전 저장은 저장 당시 전투 규칙으로 이어진다. 새 등반만 `magazine_campaign_version=1`을 기록한다. 전투 도중 기존 저장을 강제 변환하지 않는다.

## 통합 판단

- 구역별 적 그림·전용 행동 연출을 유지한다. HUD용 전투 판독부만 공통 외형으로 연결한다.
- 관문/파츠로 늘어난 탄창을 고정 9칸으로 자르지 않는다. 같은 크기의 카드가 가로로 이어지며 끝 탄도 선택 가능해야 한다.
- 자동 장전에서는 손패 두 장을 골라 장전하는 전투 중 압축이 성립하지 않는다. 새 등반은 압축 충전과 해당 전용 파츠(`field_press`)와 수동 패 교환 파츠(`reserve`)를 판매/보상에서 제외한다. 공방의 영구 탄환 압축은 유지한다. 이전 저장의 상점 압축도 유지한다.
- 가방은 새 등반에서 총 휴대량의 의미로 설명한다. 손패 교환을 새 전투의 선택지로 안내하지 않는다.
- 첫 구역의 검증된 접근 압박을 유지한다. 다른 구역 수치는 실제 등반 검증 전 임의로 바꾸지 않는다.

## 검증과 미확정 사항

전투·저장 기능, 실제 화면 조작, 자동 탐색의 등반 가능성, 사람의 재미/난이도 판단을 별도로 기록한다. 자동 탐색의 성공을 초회 플레이의 적정 난이도로 간주하지 않는다. 결과는 QA 보고서와 작업 기록에 남긴다.

구현 완료: `PLAY.cmd`의 새 등반에 적용. 5총기125전투, 실제 본편 화면25전투/귀환, 이전 저장 보존과 별도 프로세스 복원을 확인했다. [검증·화면·미검증 경계](../qa/reports/campaign_magazine_2026-11-01.md).
