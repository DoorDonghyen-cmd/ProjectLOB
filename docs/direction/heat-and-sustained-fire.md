# 발열·연속 사격·고장 비교와 적용 방향

2026-10-29. [통합 우선순위](playtest-priorities.md)의 5번 비교 단계. 사용자는 발열 수치/조건 조정, 연속 사격 부담, 탄환 불량 또는 총기 고장을 대안으로 제안했고 순차 개편을 승인했다. 아래 수치와 선택은 **격리 비교 후의 디렉터 결정**이며 사용자가 특정 수치를 직접 확정한 것으로 기록하지 않는다.

**상태:** 사용자의 후속 실행 승인으로 B1을 본편 새 등반에 적용했다. `sustained_version=1`의 누적 공격 수를 저장하며, 표식 없는 기존 이어하기는 이전 발열을 유지한다. 확률 고장·전 탄환 발열 일괄 상향·열 한계 일괄 감소는 도입하지 않았다. [비교 근거](../qa/reports/heat_comparison_2026-10-29.md) · [본편 연결·검증·화면·한계](../qa/reports/sustained_heat_2026-10-29.md).

## 본편 B1 규칙

- 냉각 또는 재장전 이후 발사한 **공격 탄환 수**로 센다. 같은 탄의 다회 타격·연쇄 전달은 한 발이다. 여러 번 누르는 스파이크도 사격 버튼을 다시 눌렀다는 이유로 초기화하지 않는다.
- 첫 두 공격은 기존 발생 열을 유지한다. 세 번째·네 번째 공격에는 추가 열1, 다섯 번째 이후에는 추가 열2를 더한다. 파츠·증폭·압축·처치 냉각 등 기존 계산은 그 위에서 함께 작동한다.
- 증폭 등 지원탄은 연속 수를 늘리거나 끊지 않는다. 냉각탄·열방출탄 사용과 실제 턴 비용을 낸 재장전은 연속 수를 초기화한다. 짧게 나누어 쏘려면 적게 장전하고 실제 재장전 비용을 지불한다.
- 새로운 고장 게이지를 더하지 않는다. 기존 열 게이지와 발사 순서에서 다음 공격의 추가 열, 과열로 끊기는 위치, 강행탄과 강제 재장전 비용을 확인하도록 연결한다.
- 과열 시점의 예측 가능성을 우선한다. 열압 코어·리액터의 강행/냉각 선택, 마지막 처치 시 불필요한 재장전을 생략하는 현행 동작은 보존한다.

본편 연결과 냉각탄 미획득 초반 검증을 마쳤다. 운반 복장·5무기×2시드의 첫 구역45전투에서 보스 돌파 경로를 확인했지만, 숨은 패/RNG를 아는 탐색 결과이므로 사람 난이도나 전체 등반 균형을 증명하지 않는다. 6번 전체 성장·탄약 경제 감사에서 긴 탄창의 비용과 정비 선택을 추적했다. 스플린터의 부담 증가와 리액터의 열압 보상이 서로 달라 B1 수치는 유지하며, 미해결 경로와 사람 체감에 따라 후속 조정을 판단한다.

## 다른 안의 판단

- 공격탄마다 열1을 더하거나 열 한계를2 낮추면 연속 길이와 무관하게 짧은 조합도 영향을 받는다. 고열 코어에는 강화가 될 수 있어 단순 난도 상향으로 해석할 수 없다.
- 첫 두 발 열을 할인하고 후반을 더 무겁게 만드는 B2는 전체 과열을 줄였지만 고열 진입을 늦춰 열압 빌드 피해를 낮췄다. 현재 사용자가 원하는 열 관리의 존재감과 코어 역할을 함께 만족시키는 우선안으로 택하지 않았다.
- 확률 고장은 불량 탄만 소모하고 미발사 탄을 보존하는 유리한 조건에서도 피해 감소와 재장전 부담을 추가했다. 저품질/고품질 체계는 현재 콘텐츠에 없으므로2%·8%를 신뢰도 민감도 값으로만 비교했다. 기존 탄의 위력과 품질을 같은 축으로 확정하지 않는다.
- 이번 고장 실험은 **현행 발열에 중단을 추가한 최소 비교**다. 발열 완전 대체의 성능을 검증한 것으로 표현하지 않는다. 완전 대체는 열압 코어·잔열·방열·리액터와 냉각탄의 역할을 함께 바꾸는 별도 범위이며 현재는 진행하지 않는다.

## 구현·검증한 범위

1. 새 등반의 규칙 표식과 연속 수를 실제 모델·저장에 연결하고 기존 이어하기는 원래 열 계산을 유지한다. 상태 복원 시 누적 수의 범위·정수 여부·발사 수·단계와 소유 탄 보존을 검사한다. 처치 냉각·세 번째 탄 냉각은 온도만 내리며 연속 수는 유지한다.
2. 확정·산개 분기 예측, 예측 캐시와 분기 합치기, 실제 사격·냉각·재장전·비상 보급에 같은 누적 규칙을 사용한다. 저장/복원과 미리보기에서 연속 부담이 유지되는 것을 확인했다.
3. 발사 순서에 추가 열과 중단 지점을 표시한다. 세 화면 비율의 실제 렌더·터치를 확인했다. 기본 카드 열과 현재 발사의 추가 열을 구분한다.
4. 냉각탄을 아직 얻지 못한 새 등반, 다섯 무기·세 성장축, 리액터 기본탄 긴 탄창, 스파이크 별도 입력, 냉각·처치·세 번째 발 냉각·열방출·압축·다수 타격/증원·고갈을 점검한다. 이때6번 전체 성장·탄약 경제 검증과 연결한다.

사람의 위험 이해·사격 리듬·재미, 모바일 지속 성능과 기기 발열은 자동 계산과 별도로 남는다.


**2026-10-30 통합 감사:** [전체 성장·탄약 경제 결과](../qa/reports/economy_audit_2026-10-30.md)에서 운반5무기×2시드의 합법 정비 후 엔딩 경로를 확인했다. 정찰/압축 우선 리액터 최종전은 탐색 미해결이다. B1 수치는 유지하며 다음 독립 작업은7번 후반 성장 기회 배분 비교다. 기본 카드에는 기본 열을 유지하고 추가 열은 현재 발사 순서에서 따로 표시한다. 관문 축열/연쇄 수치는 연속 수와 함께 보이며, 기본탄 상세의 유한 탄약 설명도 현재 규칙에 맞췄다.
