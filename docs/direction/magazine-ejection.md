# 탄창의 선택 빼내기

**최신 조작 적용(2026-11-01):** 사용자 제안과 실행 승인에 따라 현재 픽셀 HUD의 탄창 여정/전투 비교를 **탄환 선택 → 같은 자리의 빼내기 버튼** 두 단계로 바꿨다. 한도·소모·시간 비용과 전투 계산은 유지한다. [실제 화면·검증](../qa/reports/direct_ejection_2026-11-01.md). 이전 모바일 배포본과 과거 비교 화면의 조작은 이 변경을 포함하지 않는다.

2026-10-31 · [총기별 탄창 비교](weapon-magazine.md)의 후속. 사용자가 중간 탄도 선택해 빼내는 방식과 제안한 첫 비교 규칙을 승인했다. A안 가로 탄창과5총기×4전투에 연결한다. 본편 새 등반의 활성화까지 승인·검증된 것으로 확대하지 않는다.

## 적용 규칙

- 장전된 탄창의 **어느 위치에서든 총2발까지** 빼낸다. 한 번에1~2발을 선택하거나, 사격 사이에1발씩 나눠 사용할 수 있다.2발은 탄창당 누적 한도이며 최종 균형 수치 확정은 아니다.
- 선택한 탄은 이번 전투 사용함으로 이동한다. 영구 보유 덱은 유지하고 다음 전투에 복구된다. 현재 전투의 예비나 손으로 돌아오지 않는다.
- 남은 탄의 상대 순서를 유지하며 뒤 탄이 앞으로 당겨진다. 빈자리에 새로운 탄을 공급하거나 남은 탄끼리 교환하지 않는다.
- 적 행동·턴·발열·연속 사격 누적·증폭·성장·넉백 여유·표적/덱 난수는 바뀌지 않는다. 발사나 재장전으로 계산하지 않는다.
- 첫/끝 고정 탄도 제거할 수 있다. 남아 있는 고정 탄의 위치 제약은 유지한다. 여러 칸을 쓰는 영구 압축탄도 한 장이면 빼내기1발로 센다. 임시 압축이 없는 기존 비교 범위를 유지한다.
- **비용을 지불해 새 탄창을 장전할 때만 한도가2발로 돌아온다.** 사격, 냉각, 저장 재개, 선택 취소는 회복 수단이 아니다. 교체 도중 패배하거나 새 탄창을 채우지 못하면 무료 회복하지 않는다.
- 마지막 장전탄을 빼도 자동 교체/공급하지 않는다. 예비 탄창 교체 또는 기존 비상 보급을 직접 선택한다. 비상 보급이 없는 상태의 완전 소진은 기존 소진 판정을 따른다.

전체 탄창 교체는 적 행동 시간을 지불하고 미사용 탄을 보존한다. 선택 빼내기는 탄약을 포기해 현재 발사 순서를 고친다. 빼내기 때문에 다음 탄이 실제 마지막 공격탄이 되면 기존 후미 효과 등은 바뀐 남은 탄창을 기준으로 계산한다.

## 조작과 예측

**모바일 전달(2026-10-31):** 사용자 요청으로 이 비교 화면에 바로 진입하는 ARM64 APK를 만들고 Google Drive 업로드·내려받기 해시 검증을 완료했다. [설치 파일·검증 기록](../qa/reports/magazine_ejection_mobile_2026-10-31.md). 본편 저장을 사용하지 않는 별도 비교이며 실제 기기의 성능·체감은 사용자 테스트가 남는다.

탄환을 먼저 누르면 탄창 위 버튼이 **1발 빼내기 / 2발 빼내기**로 바뀐다. 그 버튼을 누르면 즉시 제거하며 추가 모드 진입이나 확인창은 없다. 선택 전에는 버튼이 비활성이다. 선택한 탄은 올라온 붉은 외피와 `제외`로 표시하며, 남을 탄에 제거 후 발사 순서와 예상 피해/지원 효과를 표시하고 발열 게이지도 갱신한다. 스플린터는 기존처럼 범위·확률로 보여주고 숨은 표적 난수를 정답으로 노출하지 않는다.

같은 탄을 다시 누르면 그 탄을 선택 해제하고, 빈 곳·빈 탄창 홈·Escape는 전체 선택을 취소한다. 선택한 탄의 정보는 탄창 수 옆 **N번 상세**에서 읽는다. 두 발을 고르면 마지막에 고른 탄의 상세를 표시한다. 상세창을 닫아도 선택은 유지한다. 빼내기 한도를 다 쓴 뒤에도 탄을 눌러 상세를 볼 수 있으며 이때 사격을 막지 않는다.

선택은 취소할 수 있고 확정 전에는 전투 상태나 저장을 바꾸지 않는다. 잘못된 중복 선택/범위 초과/한도 초과는 전체 요청을 거부한다. 선택 중에는 사격·냉각·교체·총기/전투 변경을 막고 도움말을 열어도 탄약을 소모하지 않는다.

제거 뒤에는 남은 빼내기 횟수를 표시하고 저장하며 모든 선택을 비운다. 앞으로 당겨진 탄을 자동 선택하지 않고 빼내기 버튼을 다시 비활성화한다. 완전 소진으로 패배할 때는 실행 버튼에 `빼내면 패배`를 표시한다. 진행 중 선택은 저장하지 않는다. 사용 횟수와 잔탄·열·난수는 저장/재개해도 그대로다. 이전 총기 비교 저장에 횟수 필드가 없으면 아직 사용하지 않은2발로 취급한다. 기존 리벳 단일 비교와 본편에는 새 명령을 열지 않는다.

## 검증할 선택과 후속

보유 탄만 사용한 통제 순서 `증폭 → 기본 → 철갑 → 기본`에서는 중간 기본탄을 빼면 이번 두 발이 증폭/철갑이 된다. 같은 방패 적에 대한 강화된 공격의 직접 피해가4→10으로 바뀌었다. 앞 탄을 빼면 증폭을 포기한다. 자연스럽게 뽑힌 특정 저장이라고 주장하지 않는 순서 경계 사례다.

이전 제한 탐색 미해결인 스플린터 보스 순서17은 초기 앞1발/앞2발/중간1발을 뺀 뒤 각각 승리 경로를 재생했다. 이 사례는 앞에서만 빼도 해결되므로 중간 빼내기의 우월성 증거로 쓰지 않는다. 숨은 표적 결과가 고정된 QA이며 사람 승률/확정 전략도 아니다.

[검증 보고서](../qa/reports/magazine_ejection_2026-10-31.md). 다음에는 매 탄창마다 무조건2발을 빼는 행동이 지배적인지, 유한 탄약의 대가가 읽히는지, 새 규칙으로 얻는 지원탄·연속 전투/정예와 리액터의 긴 전투가 어떻게 바뀌는지 확인한다. 아래 사용자 평가는 구조 전반의 개선 근거로 삼으며, 빼내기의 개별 활용 상황·장기 균형·판독성 세부와 모바일 지속 FPS/발열의 검증은 이어간다.

## 사용자 후기와 다음 비교 범위

2026-10-31 모바일 전달 뒤 사용자는 전체적인 느낌을 긍정적으로 평가했고, “빼지 않고 쏴도 괜찮았고 근데 이 전투 하나로 탄 빼내기 상황이 유효한지는 아직 판단은 어려운 것 같아”라고 설명했다. 이는 플레이한 전투에서 빼내기 없는 사격도 괜찮았다는 관찰이다. 빼내기의 유효성·필수 여부·전체 균형이 확인되거나 모든 비교 전투/총기를 시험한 것으로 확대하지 않는다. 정확한 총기·탄 순서·사용 횟수와 지속 성능 수치는 보고되지 않았다.

후속 사용자 평가: “근데 내 판단으로 이 구조가 개편 이전 구조보다 더 긴장감 있고 선택과 덱 빌딩의 느낌이 확 사는 것 같아”. 이는 구조 전반에 대한 명확한 비교 체감이다. 앞선 빼내기 유효성 판단 유보와 양립하며, 단순한 첫인상 긍정으로 축소해 기록하지 않는다. 어떤 개별 변경이 얼마만큼 기여했는지나 모든 수치의 적절성까지 확인된 것은 아니다.

디렉터 후속 판단: 현재 탄창·부분 사격·접근 압박·선택 빼내기 구조를 이후 개발 기준으로 유지한다. 현행2발 후보와 소모 규칙을 유지하며 실제 보상으로 덱이 달라지는 초반3~5연속 전투를 다음 비교 범위로 삼는다. 조합 획득 전후의 선택과 성장 체감을 먼저 연결하고, 기존 획득·편성에서 아래 선택이 생기는지 확인한다. 빼내기를 쓰게 만들 목적으로 적을 일괄 강화하거나 탄 순서를 정답으로 고정하지 않는다.

- 빠른 처치: 그대로 사격해도 좋은 전투.
- 조합 획득 이후: 중간 탄 제거로 지원 효과의 적용 대상이나 사격 순서가 바뀌는 전투.
- 접근 압박: 필요한 탄을 앞당기는 이득과 냉각/전체 교체의 비용을 비교하는 전투.
- 여러 탄창을 쓰는 강적: 탄을 포기한 대가와 같은 전투의 후반 잔탄을 함께 보는 전투. 전투 사이 탄 복구 규칙은 유지한다.

같은 획득 상태를 재시작해 그대로 쏘기/빼내기를 비교할 수 있게 구성하고, 사용 이유·남긴 이유·공격/교체 횟수·소모 탄·접근 위험을 관찰한다. 모든 장면에서 빼내기를 써야 하거나 승리해야 한다는 목표는 두지 않는다. 이후 사용자 진행 승인에 따라 [탄창 여정](magazine-journey.md)으로 실제 보상·정비를 포함한 다섯 전투를 구현했다. 연속 성장 체감과 빼내기 선택 이유는 다음 사람 플레이에서 확인한다.
