# 5구역 — 중앙 통제구와 1~5구역 임시 밸런스

## 결정 상태

사용자는 2026-10-25 일반 친위대의 **B ‘봉쇄형’ 외형을 선택하고 본편 적용과 5구역까지의 임시 밸런스 작업을 요청했다.** 일반4종의 선택은 사용자 확정이다. 친위대장·탑의 지배자 추가 원화, 세부 행동과 아래 수치는 디렉터의 임시 구현값이다. 지배자의 생물학적 정체를 확정하는 설정은 추가하지 않았다.

현재 새 등반은 `roster_version=11`, `combat_revision=2`, 친위대 `central_version=2`다. 2026-10-27 순차 개편에서 중장병의 장갑을 높이고 지휘를2행동 주기로 바꿨다. 기존 저장은 저장된 전투규칙/편성을 유지한다. 아래는 현재 신규 등반 값이며 이전 친위대 버전1은 중장병 HP18~22/장갑1, 지휘3행동/차폐 최대치 회복이다. [개편 검증](../qa/reports/pressure_revision_2026-10-27.md).

## 적 구성

| 분류 | 이름 | HP | 장갑 | 기본 접근 | 시작 차폐 / 최대 |
|---|---|---:|---:|---:|---:|
| 일반 | 친위 돌격병 | 7~10 | 0 | 2m | 0 / 1 |
| 일반 | 친위 중장병 | 16~20 | 3 | 1m | 0 / 1 |
| 일반 | 친위 방패병 | 11~13 | 0 | 1m | 2 / 2 |
| 일반 | 친위 포격병 | 11~13 | 0 | 제자리 | 0 / 1 |
| 정예 | 친위대장 | 38 | 0 | 1m | 2 / 2 |
| 보스 | 탑의 지배자 | 80 | 0 | 1m | 3 / 3 |

- 일반전6~7기, 정예7기, 보스8기. 동시에 최대4기이며 나머지는 유한한 후속 편성이다.
- 일반전은 돌격+중장, 또는 돌격+방패+포격의 두 계열이다. 한 전투에 원거리 사수는 최대1기다.
- 정예·보스는 지휘+돌격+중장+차폐 전열을 사용한다. **최종전에는 포격병을 중장병으로 교체했다.** 지휘와 차폐에 원거리 요격 시계까지 겹쳐 유한 탄약을 과하게 요구하던 경우를 완화한다. 포격병은 일반전에서 만난다.
- 숫자의 원본은 `redesign/central_guard.gd`와 `campaign_content.gd`다. 실제 거리는 공통 접근 배율·난이도·압박 보정을 거친다. 무기에 따라 적 수치가 몰래 바뀌지 않는다.

## 지휘와 차폐

친위대장과 지배자는 **적 행동2회마다 ‘전진’과 ‘차폐 +1회’를 번갈아** 사용하며 첫 지시는 전진이다. 발사, 재장전, 강제 과열 냉각에서 발생하는 적 행동이 모두 시계를 진행한다. 주기를 줄이는 대신 차폐 보충량을 제한해 유한 탄약 부담을 조정했다.

1. 전진은 본체와 현재 살아 있는 이동형 친위대에게 각각2m 추가 접근을 준다. 제자리 포격병, 후속 대기 적, 압력탄은 제외한다. 접촉하면 패배한다.
2. 차폐 보충은 본체와 차폐가 부족한 가장 가까운 친위대1기에 각각1회를 더한다. 각자의 최대치를 넘지 않으며 HP를 회복하지 않는다.
3. 일반 친위대는 스스로 차폐를 재생하지 않는다. 일반 타격1회, 전기 주 타격2회, 파쇄 파츠의 추가1회로 제거한다. 마지막 차폐를 깨는 타격은 막히고 연타의 남은 타격부터 HP에 들어간다. 화상은 차폐를 우회한다. 전격탄의 별도 전이 피해는 기존처럼 직접 HP에 들어가며 주 타격의 차폐 제거와 구별한다.
4. 차단탄은 지휘 시계를 멈추지만 통상 접근까지 멈추지는 않는다. 화상 등으로 지휘관이 먼저 쓰러지면 그 행동의 명령은 취소된다.
5. HP 제한·강제 무적 국면·무한 증원은 없다. 성장한 빌드는 지휘 주기를 기다리지 않고 처치할 수 있다.

다음 지시와 남은 행동은 HP 위에 표시하며, 발동 때 본체 강조와 전진/차폐 표시를 재생한다. 일반/연쇄/열 파동의 차폐 피해도 ‘차폐’ 또는 ‘파손·본체 노출’로 읽힌다.

## 10월26일의 1~5구역 임시 수치 판단

이 절은 편성11 최초 적용 근거다. 10월27일 이후 2구역은 [최신 주조장 규칙](monster-roster.md#현행-2구역--편성8--2026-10-23), 5구역은 위 전투규칙2가 우선한다. 모든 구역의 직접 피해 장갑 계산은 [비례 감쇠](damage-growth.md)를 따른다.

| 구역 | 이번 판단 |
|---|---|
| 1 빈민가 | 편성11의 폐쇄 당직 HP44→32. 장갑5, 개방 주기, 압력탄, 호위는 유지. 짧은 경로의 낮은 성장 리액터가 첫 관문에서 공격탄을 소진하던 부담을 줄인다. 이전 저장은44 유지. |
| 2 축열 주조장 | 편성8의 고체력·낮은 장갑·축압 전진 유지. 새 게임부터 실제 성장 경로로 재검증. |
| 3 우수 정원 | 편성9의 빠른 접근·도약/숨고르기 유지. 새 게임부터 실제 성장 경로로 재검증. |
| 4 귀족 거주구 | 편성10의 차폐→노출→복구 유지. 새 게임부터 실제 성장 경로로 재검증. |
| 5 중앙 통제구 | 위 일반/정예/보스 수치와 지휘 적용. 최종전의 원거리 시계를 제거해 전진·차폐 공략에 집중. |

이 수치는 임시 기준이다. 모든 무작위 덱의 승리 보장이나 사람의 승률 확정이 아니다. 검사에는 실제 새 등반, 합법적인 보상·구매·관문 선택, 매 명령 저장 복원을 사용한다. 탐색은 미래 손패·RNG를 보므로 기능적 돌파 가능성과 탄약/거리 여유만 판단한다. [최종 실행 결과와 남은 체감 검증](../qa/reports/central_live_2026-10-26.md).

## 아트와 실행

- 일반4종은 승인 B 원본을 그대로 사용한다. A와 B 비교 뷰어 및 원본도 보존했다.
- 친위대장과 지배자는 B 중장/방패병·현행 주인공·중앙 상층 배경을 참조한 추가 원화다. 각각148px 높이로 표시한다. 보스의 초기165px 등록은 작은 화면의 HP 겹침을 피하려고 줄였다.
- 정지 원화에 기존 이동·피격·사망·발사와 지휘 강조를 연결했다. 상태별 신규 키포즈 시트나 수작업 걷기 프레임을 완성한 것은 아니다.
- [추가 원화의 전체 프롬프트·참조·해시·발 기준](../../새-게임-프로젝트/assets/art/central_leaders_20261026/provenance.json), `central_art.gd`의 내장 texture 참조로 실행·내보내기에서 같은 원본을 사용한다.
- `PLAY.cmd`의 새 등반에서 적용된다. 개발 메뉴의 중앙 일반전/친위대장/탑의 지배자는 실제 획득한 5구역 진입 덱으로 화면을 확인하며 사용자 저장을 쓰지 않는다. 후반 방 직접 이동은 그 사이의 추가 성장을 가정하지 않는다.

사용자의 일반 B 선택과 별개로, 추가 지도자 원화의 선호·지휘 이해도·장기 재미·Galaxy 실기기 확인은 아직 남아 있다.
