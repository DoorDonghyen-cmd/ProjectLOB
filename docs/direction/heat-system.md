# 발열을 중심으로 한 사격 설계

2026-10-04 · 본편 구현. [검증·화면·남은 한계](../qa/reports/heat_system_2026-10-04.md).

## 결정 상태

- **사용자 방향:** 탄환별 발열을 전투의 핵심 판단 요소로 둔다. 무기별 발열 스탯, 전투 상시 게이지와 과열 시 강제 재장전을 원하며 구현을 승인했다.
- **후속 플레이 확인:** 쇄도로 테스트한 뒤 현재 메커니즘을 긍정 평가했다. 구조를 유지한 폴리싱과 탄종·열 제어 파츠 확장은 [후속 제작안](heat-builds.md)으로 관리한다. 개별 수치의 최종 확정과 구별한다.
- **디렉터 결정:** 한계에 도달시킨 탄의 효과 해결 후 사격 중단, 전투가 계속되면 기본 재장전+냉각1턴. 아래 수치는 현재 콘텐츠에 적용한 첫 밸런스이며 사용자 확정 수치나 최종 재미 검증값은 아니다.
- **구현:** 실제 전투·예측·연출·무기 선택·카드·저장 v11에 적용했다. [선택 가치 개편](decision-value.md)에서 일반 재장전의 잔열을 추가했다. 이전 고출력 전용 `reload_heat` 규칙은 신규 발사에 사용하지 않는다. [이전 실험](ammo-risk.md)은 이력이다.

## 현재 규칙

1. 발사한 탄마다 표시된 열을 한 번 적용한다. 연발 타격 수·전격 전이·턴당 화상이 추가 발열을 만들지 않는다. 요격/배리어에 막혀도 발사한 탄의 비용은 같다. 장전·편집·미발사에는 열이 쌓이지 않는다.
2. 열이 한계 **이상**이면 해당 탄의 타격과 효과를 끝낸 뒤 후속 발사를 중단한다. 뒤의 냉각탄은 발사되지 않으므로 과열을 소급 취소할 수 없다.
3. 사격 시간1턴을 처리한 뒤 전투가 계속되면 강제 재장전을 한 번 처리한다. 비용은 `무기/파츠의 기본 재장전 + 냉각1턴`이다. 열1마다1턴이 아니다.
4. 강제 재장전 동안 적·화상·태세·투사체·증원이 실제로 진행한다. 중간에 승리/패배하면 실제 경과 턴만 센다. 사격으로 이미 전투가 끝났다면 재장전하지 않는다. 예비 적이나 투사체가 남아 있으면 승리가 아니다.
5. 일반 재장전은 아래 무기별 냉각량을 한 번 차감하며 최저0이다. 남은 열은 새 패/탄창으로 이어진다. 강제 재장전은 추가1턴의 대가로 열0이다. 전투 종료 시에도 열0. 과열 전 정상 재장전에는 추가 냉각 턴이 없다. 증강의 여러 사격 입력 사이에는 열이 유지된다. 무료 대기나 턴당 자동 냉각은 없다.
6. 미발사 잔탄과 미사용 손패를 모두 사용 더미로 보내고 새 패를 뽑는다. 소유 덱에서 삭제되지 않는다. 임시 압축탄은 원본 수량으로 돌아간다. 압축 증폭의 이월 등 기존 재장전 효과도 같다.
7. 냉각탄은 현재 열을3 낮추고 기본 직접 피해는0이다. 최저0이며 미래 냉각을 저축하지 않는다. 증강은 냉각 효과가6이지만 다른 탄의 발열 비용을 두 배로 만들지는 않는다. 증폭/파츠의 피해 효과는 냉각탄에도 적용될 수 있다.
8. 예전 저장에서 이미 쌓인 추가 재장전 턴은 별도 `legacy_reload_penalty`로 한 번 보존·소진한다. 이를 열로 변환하지 않는다. 기존 덱·파츠·진행은 보존하며 새 열은0에서 시작한다.

## 무기별 한계

| 무기 | 발열 한계 | 기본 탄창 / 재장전 | 일반 재장전 냉각 | 현재 선택 |
|---|---:|---|---:|---|
| 보행자 | 12 | 4칸 / 1턴 | −8 | 공격탄 보너스와 빠른 재장전으로 혼합 사격 |
| 쇄도 | 14 | 4칸 / 2턴 | −9 | 같은 적3회 적중 완성과 과열 시 긴 재장전 |
| 산개 | 16 | 5칸 / 2턴 | −12 | 분산 사격과 큰 열 용량 |
| 압쇄 | 13 | 4칸 / 1턴 | −6 | 화상·전이 연계와 재장전 중 지속 피해 |
| 증강 | 10 | 3칸 / 1턴 | −7 | 한 발의 큰 효과와 입력 사이 누적 열 |

한계에 도달하면 과열이다. 최종 열 한계는 무기 기본값에 확장 방열판+3·잔열 노심−2를 합산한다. [빌드 확장](heat-builds.md)의 처치 냉각은 과열 판정 직전에 적용한다. 기존 파츠의 탄창·재장전 변화는 그대로 적용한다.

## 같은 패에서의 순서 차이

보행자 열0/한계12, 적이 살아 있는 검증용 편성:

| 순서 | 누적 열 | 결과 |
|---|---|---|
| 고출력 → 연발 → 철갑 → 냉각 | 5 → 9 → **12** | 3발 뒤 중단. 냉각 미발사, 사격1+강제 재장전2턴 |
| 고출력 → 연발 → 냉각 → 철갑 | 5 → 9 → 6 → 9 | 4발 발사, 사격1턴. 열9 유지 |

두 번째 순서에서 냉각은 증폭의 두 번째 적용을 소비한다. 따라서 같은 화력에 무료 냉각을 얹는 선택이 아니다. 낮은 열을 섞는 사격, 자발적 재장전, 주요 위협을 먼저 제거하는 과열 사격도 남긴다.

## 보조탄·적 시한을 함께 조정

발열만 추가한 실제 편성 비교에서는 기본탄 반복 승리가 거의 그대로였다. 이번 구현에서는 보행자의 공격탄+2를 증폭·파쇄·냉각에는 적용하지 않았다. 무파츠 기본 직접 피해는 각각1·1·0이다. 기본탄의 기존+1은 유지한다.

첫 교전은 HP8/12·거리18/22m의 적 두 마리다. 나머지 본편 편성은 기존 작성 거리의65%를 올림해 접근 거리를 줄인 뒤 기존 난도/경로 압박을 적용한다. 최소6m이며 보스·예비 증원에도 적용한다. 적마다 공개된 거리로 판단하며 새로 등장한 적은 생성 턴에 이동하지 않는다. 이 조정은 영구 비율이 아니며 자동 승률 하락 자체를 재미로 취급하지 않는다.

## 화면과 조작

- 카드의 기존 도트 물건·피해·효과를 유지하고 열 변화량을 작은 아이콘/숫자로 표시한다. 냉각은 음수다.
- 발사 레일 아래에 열0일 때도 `현재/한계`를 표시한다. 채움은 현재 열, 윤곽/빗금은 이번 사격 중 최고 열이다. 자동 재장전 뒤0만 보이는 오해를 막는다.
- 과열을 일으키는 탄은 주황 테두리와 `!`, 뒤의 미발사 탄은 흐림·사선·문구로 구분한다. 냉각 위치 변경 시 예측도 갱신한다.
- 행동 영역에 `3발 후 과열 · 총3턴`과 강제 재장전 비용을 표시한다. 산개는 범위/가능성을 사용하고 확정 결과처럼 표시하지 않는다.
- 실제 연출은 탄별 가열 → 사격 중단 → 재장전 냉각을 순서대로 보여 준다. 연출 생략과 저장은 결과를 바꾸지 않는다.
- 무기 선택에는 탄창/재장전과 열 한계·냉각량이 함께 보인다. 재장전 버튼은 실제 종료 열, 확정 전에는 사격 후 재장전 시 남는 열을 보여 준다. 1008×630·1440×630·1280×900 실제 화면 검수를 수행했다. Galaxy 실기기 체감은 별도다.

## 남은 검증

열 경계·냉각 순서·마무리 면제·증강·산개·요격·증원·파츠 비용·압축 잔탄·저장/예측의 일치는 기능 검사로 확인한다. 현재 근거는 위 보고서에 모은다. 사람의 선택 이해도, 여러 난도의 장기 밸런스, 냉각이 필수가 되는지, 압쇄의 높은 무작위 승리율은 후속 플레이에서 확인한다. 열 전용 파츠 추가는 이 선택들이 안정된 뒤 판단한다.
