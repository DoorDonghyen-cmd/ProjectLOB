# Last on Board — 현재 방향과 결정 상태

2026-10-04 · 활성 프로젝트 `worktrees/core-redesign/새-게임-프로젝트` · Godot.

최신 플레이 비교: [PLAY_RANGED_SAMPLE.cmd](../../PLAY_RANGED_SAMPLE.cmd). 압력두꺼비 한 종의 공격 예고·압력탄 요격을 고출력/과열과 결합한 별도 전투 2개다. [구현·검증·화면](../qa/reports/ranged_2026-10-04.md). 본편 편성에는 아직 넣지 않았으며 새 적 외형은 단순한 시험용 도트 실루엣이다. 앞선 [출력 비교](../../PLAY_AMMO_RISK.cmd)도 유지한다. 사용자가 미룬 발사·과열 연출의 추가 폴리싱은 후속으로 둔다.

## 사용자에게 확인된 핵심

- 최신 종합 피드백: 사용자는 **현재까지의 전체 진행 방향이 마음에 든다**고 확인하고 작업 내용의 커밋을 요청했다. 현재 방향을 이어가되, 시험용 몬스터 외형·요격/과열 수치·장기 밸런스까지 최종 확정한 것으로 확대하지 않는다.

- 최신 연출 판단: 화면 반응 보강 후 사용자는 **대략적인 느낌을 이해했으며 재정비·폴리싱은 향후 진행**하기로 했다. 현재 상태는 방향 이해 확인이며 최종 연출 품질이나 과열 수치·재미의 확정은 아니다. 발사·잔열·냉각의 추가 미세 조정은 후속 폴리싱으로 둔다.

- 최신 전투 피드백: 몬스터·요격 방향으로 진행하는 데 동의했고, 탄환 사용의 리스크가 부족하다고 느낀다. 증폭 뒤 과열로 재장전 시 적에게 추가 시간을 주는 예시를 제시했다. [출력과 대가](ammo-risk.md)의 첫 비교 샘플 진행을 요청해 고출력 변형과 재장전 +1턴을 격리 전투에 구현했다. 수치는 실험값이며 캠페인 전체 밸런스로 확정하지 않는다.
- 최신 화면 확인: 샘플 주인공을 35% 축소한 현재 크기를 사용자가 긍정 확인했다. [몬스터 제작 초안](monster-roster.md)의 일반 8종·보스 후보 2종 중 압력두꺼비와 요격은 격리 샘플에 구현했다. 나머지 새 이름·아트·보스는 제작안이며 캠페인에는 미적용이다. 요격 수치와 재미는 사용자 최종 확정 상태가 아니다.
- 탄환을 조합하고 순서를 설계해 피해를 증폭하고 여러 적을 처치하는 재미.
- 무기는 캐릭터처럼 런의 플레이 방식을 바꾸고, 파츠는 조커처럼 여러 개를 조합해 개인 빌드를 만든다.
- 강력한 파츠·압축에는 의미 있는 대가가 존재하되 모든 파츠에 일률적으로 패널티를 붙이지 않는다.
- 탄환의 기본 정보는 단순하게, 선택과 상호작용은 깊게. 화염은 지속 피해, 전기는 전이 역할을 가진다.
- 랜덤 패와 선택의 변화가 반복 플레이를 만든다. 명중·회피 수치를 되살려 복잡도를 늘리지 않는다.
- 전투뿐 아니라 메인·무기 선택·맵·보상·상점·장비가 게임으로서 일관된 경험이어야 한다.
- 텍스트를 작게 줄여서 정보를 다 넣는 해법은 불충분하다. 모바일에서 위계와 판독성을 실제로 확인한다.
- 게임 전체와 UI/UX의 시각 표현은 도트 아트풍으로 통일한다. 사용자가 제시한 시각 참고작은 산나비(SANABI)와 ARCANE TRIGGER다. 캐릭터·몬스터·배경·탄환·파츠·메뉴를 같은 제작 기준으로 다룬다.
- 최신 아트 피드백: 사용자 제공 캐릭터 5장·배경 5장을 기준으로 재정립한다. 전반적으로 가장 가까운 느낌은 **산나비**, 배경은 **디스토피아적 분위기가 강하게 느껴지는 방향**이다. [원본/보드](../art/references/2026-10-03-user/README.md)와 [도트 제작 기준](pixel-style.md)을 따른다.
- 최신 캐릭터 선택: 초기 정비용 헬멧에서 추가 후보 비교를 거쳐 [C 복장+B 방한모](../art/concepts/2026-10-03-character-variants/character-c-expedition-cap-v2.png)를 선택했고, 이 캐릭터와 제작한 배경의 전투 샘플을 요청했다. [별도 실행 샘플](../qa/reports/tower_art_sample_2026-10-03.md)에 실제 적용했다. 복장·헬멧 획득/교체는 [후속 설계](appearance.md)를 유지하며 기본 캠페인 아트 교체/수집 구현은 아직이다.
- 기획·아트·레이아웃 재검토는 사용자에게 위임받았다. APK 제작은 별도 요청 시 수행한다.
- 앞선 화면 피드백: 탄환 카드 디자인은 유지하고 기존 인게임 캐릭터·적·배경은 임시 자산으로 둔다. 이후 세계관/레퍼런스 정리를 거쳐 새 도트풍과 헬멧 주인공을 채택했으므로 배우·환경 제작을 다시 진행할 수 있다.
- 2026-10-03 세계관 채택: 기상탑·탄환 기술자와 앞서 제안한 복구 엔딩의 큰 방향에 긍정 답변을 받았다. **위험한 탐험 + 사람 사는 온기 + 은근한 디스토피아적 어두움**, 폭주로 통제를 벗어난 생물, 상점별 생존자 이야기를 유지한다. 아이템·쪽지 등에서 세계의 깊이를 간접 발견하는 서사 방식을 원한다. 개별 원고·인물·마지막 조작까지 일괄 확정한 것은 아니다.

## 이번 디렉터 결정

핵심 문장: **손패로 한 번의 사격을 설계하고, 파츠로 나만의 연쇄를 만든다.**

- 기능과 계산을 재사용하며 화면 표현·동선·아트 언어를 재구성한다. 과거 구현 보존 자체를 목표로 삼지 않는다.
- 수직 산업도시·회수자·기계형 적은 구현을 위한 임시 해석이다. 최종 세계관으로 확정하지 않는다. 배우·환경 아트 재개 전에 세계관 핵심과 요소별 레퍼런스를 정리하고 통합 시안을 비교한다. 특정 계급론·개조 거부 결말·호러 금지는 필수 조건으로 계승하지 않는다.
- 아트는 사용자 확정에 따라 도트 아트로 재설계한다. 산업도시라는 세계관은 임시 해석이며 확정 사항과 구별한다. 앞서 적용한 세밀한 일러스트 배경·캐릭터와 평면 도형 적의 혼합은 교체 대상이다. 구체적인 픽셀 밀도·팔레트·글꼴은 실제 게임 크기의 통합 화면으로 검증한다.
- 전투는 바닥에 접지한 캐릭터와 적, 선명한 손패, 간결한 발사 순서로 구성한다. 적의 위협과 내 선택의 결과를 연결하고, 빈 장전 슬롯이 손패의 판독 공간을 잠식하지 않게 한다. 기존 전열의 안정성과 접근 거리 규칙은 유지한다.
- 플레이어에게 보이는 규칙은 단순한 이름과 결과로 설명하며 정확한 수치·조건은 누락하지 않고 상세로 제공한다.
- 세계관의 채택 방향은 **폭주한 기상탑을 오르는 탄환 기술자**다. [세계관 기준](worldbuilding.md)에 상점별 생존자, 풀려난 생물, 기상 기능 복구와 구역별 비상 제어권 개방의 엔딩 방향을 정리했다. [간접 서사](narrative-delivery.md)는 기능을 먼저 읽는 아이템 상세, 독립적으로 읽히는 쪽지, 서로 연결되는 흔적을 설계한다. 원고와 상세 인물/연출은 제작안이며 아직 게임·아트에 적용하지 않았다.
- 도트 재정립: 캐릭터의 성인 비율·큰 형태와 비대칭, 배경의 거대 수직 건축·차가운 깊이·생활의 작은 온기를 제작 방향으로 삼는다. 사용자 이미지 10개를 직접 검토했고 다음은 주인공·역할이 다른 적·배경·승인된 카드를 묶은 첫 통합 시안이다. 지금은 레퍼런스 검토/기준 정리 완료이며 새 게임 아트 적용 완료가 아니다.

## 구현 현황과 의도 구분

현행 모델은 왼쪽부터 발사하며 산개만 무작위 표적을 고른다. 다섯 무기, 파츠 5칸, 압축 코어 경제, 35층 캠페인은 지금 실행 가능한 기반이다. 이 숫자는 영구 헌법이 아니다. 이번 화면·아트 개편 동안 비교 기준으로 사용한다.

2026-10-03 첫 통합 도트 전투 화면을 적용했다. 회수자·여섯 적은 PixelLab 스프라이트, 전투 배경은 공업 지대 도트 배경, 바닥·탄환 실루엣·슬롯은 엔진의 픽셀 도형으로 구성한다. 카드의 중복 결과 문장을 제거하고 피해·관통·고유 효과를 분리했다. 배우·환경은 사용자 피드백에 따라 임시 자산이며 지도·지역별 환경·배우 애니메이션 등도 후속 범위다. 아직 게임 전체가 완료된 상태는 아니다. 화면 경계·기능 검사의 통과를 사람의 이해도나 최종 시각 품질의 증거로 사용하지 않는다.

새 기획의 상세는 [게임 설계](game-design.md), 시각·입력 기준은 [아트와 UX](art-and-ux.md), 검사 대상은 [현행 검증 경로](verification.md), 실행 범위는 [전체 경험 제작 계획](../implementation_plan_full_experience_2026-10-02.md)에서 관리한다. 계획된 항목을 이미 구현한 것으로 취급하지 않는다.

2026-10-03 비전투 UI 개편: 메인은 이어하기/새 등반 중심의 두 영역, 출격 준비는 다섯 무기와 실제 시작 보급을 한 화면에 구성했다. 상점은 위치가 고정된 비교 영역, 파츠 작업실은 장착 5칸·보관함·선택 상세를 함께 제공한다. 유효한 파츠 교체는 기존 파츠를 보관한 채 한 번에 적용한다. 세계관 핵심 정리 → 요소별 레퍼런스 → 통합 시안 비교 → 배우·환경 아트 재작업을 후속 대기로 등록했다. [구현·검증 보고서](../qa/reports/navigation_ui_2026-10-03.md).

2026-10-03 조작 흐름 후속 구현: 전투 기본 예측을 다음 발사 1회로 바꾸고 전체 탄창 예측을 분리했다. 손패 위치 유지, 탄창 선택/이동/회수/상세 분리, 확정 비용 표시, 파츠 교체의 얻음/잃음 비교, 상점 단일 구매 동선, 출격 고급 설정 접기를 적용했다. 카드 디자인·전투 계산·저장 형식을 유지한다. 3초·30% 확대·민트·세로 배치는 참고 의견이며 고정 의무가 아니다. [구현·검증 보고서](../qa/reports/interaction_flow_2026-10-03.md).

2026-10-03 파츠·조합 피드백 후속: 상단 장착 아이콘에 다음 발사의 발동 순서를 연결하고 실제 명중 때 파츠와 해당 탄을 함께 강조한다. 쇄도 적중 3칸, 교전별 주요 기록 최대 두 개와 상세 기록을 추가했다. 산개 예측의 순서 파츠·다중 장착 캐시 누락도 수정했다. 전투 수치는 유지하고 적용 기록을 선택적으로 저장한다. [구현·검증 보고서](../qa/reports/build_feedback_2026-10-03.md).

2026-10-03 4번까지의 후속: 실제 모델 720사례 비교 후 예비 급탄기에 탄창당 패 교환+1회를 추가했다. 첫 지역은 조합→장갑→전기/다수→파츠/증원을 단계적으로 소개한다. 첫 패는 소유 탄을 재배치해 무기·시작 보급에 맞는 조합을 제공한다. 새 런 30Cr, 역할이 다른 첫 상점 일반 파츠, 미등장 파츠 우선 진열, 점증 진열 비용, 환기구 전투의 크레딧 보상+6Cr를 적용했다. 지도에 실제 편성과 대가, 상점에 덱과의 연결·구매 잔액을 표시한다. [구현과 검증 한계](../qa/reports/progression_2026-10-03.md). 수치는 디렉터의 현재 구현 결정이며 사용자 확정 밸런스로 취급하지 않는다. 다음은 사람의 첫 지역/반복 플레이 피드백과 세계관·레퍼런스 정리다.

원거리 후속 구현: 준비 2턴, 본체 거리에서 발사, 생성 턴 이동 없음, 압력탄 6m/턴·HP 1을 실제 모델로 처리한다. 가장 가까운 압력탄은 산개도 확정 요격하며 증폭·전이를 유지한다. 발사된 탄은 본체가 죽어도 남고 0m 도달은 패배다. 사격·재장전 예측, 별도 위협 ID/저장 호환, 도달 표시와 상세 입력을 검증했다. 규칙 417/0·실제 UI 281/0 및 기존 회귀 통과. 다음 판단은 요격이 매번 같은 첫 탄을 요구하지 않는지 플레이로 확인한 뒤 공격 간격·편성 빈도와 몬스터 정식 아트를 정하는 것이다.
