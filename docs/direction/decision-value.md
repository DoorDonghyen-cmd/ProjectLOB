# 탄환 선택 가치 — 패와 행동 예산, 순환과 잔열

2026-10-04 · 디렉터 1차 구현. 사용자는 심층 검토 후 개발 진행을 승인하면서 슬레이 더 스파이어2의 덱 관리 유도를 먼저 조사하도록 요청했다. 아래 적용 방식과 수치는 사용자 확정 수치가 아니다.

## 참고작에서 확인한 것

슬더스2는 2026-03-05 얼리 액세스로 출시되었으며 개발사는 콘텐츠와 밸런스의 후속 변경을 예고한다. 특정 카드의 과거 시연 수치나 베타 수치를 현행 정답으로 옮기지 않는다. [개발사 출시 안내](https://www.megacrit.com/news/2026-03-05-early-access-launch/).

- 기본 턴에 5장을 뽑고 3에너지로 사용한다. 보유한 카드 수와 사용 예산이 분리되어 있다. Retain이 없는 손패는 턴 종료 시 버려지며, 손/드로우/버림/소멸 영역과 업그레이드·제거가 존재한다. 적 행동은 의도로 공개된다. 상세 규칙은 작성 중인 커뮤니티 위키에서 확인했으며 공식 출시 자료와 출처 수준을 구분한다. [전투·덱 규칙](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2%3ADeck).
- 개발사는 사일런트의 Sly를 버릴 때 무료로 자동 사용되는 효과로 소개했다. 카드를 버리는 행위도 특정 빌드의 이득이 될 수 있다는 설계 사례다. 소개 당시의 개별 카드 수치를 복사하지 않는다. [Mega Crit, May 2025](https://megacrit.com/news/2025-5-15-neowsletter-issue-10/).

**이 프로젝트에 대한 해석:** 좋은 덱은 강한 카드의 합계만이 아니라, 주어진 행동 예산 안에서 필요한 역할을 제때 꺼낼 수 있는 구성이다. 제거는 조합을 더 자주 찾게 할 수 있지만 카드 추가도 대응 폭을 넓힌다. 얇은 덱만 정답이라는 의미는 아니다. 기본 규칙의 제약을 덱/파츠 투자로 유리하게 바꾸는 성장 여지는 남겨야 한다. 이는 위 규칙을 바탕으로 한 디렉터 해석이며 개발사의 직접 발언이 아니다.

## 우리 게임에 적용한 범위

1. **선택할 패와 실제 탄창을 분리한다.** 패는 탄창+2장, 최소5장이다. 소유 덱이 더 작으면 그 수만큼만 뽑는다. 회수탄은 별도 보급으로 남는다. 확장 탄창도 패 전부를 넣는 자동 선택이 되지 않는다. 공간2칸 압축과 위치 제약은 그대로다.
2. **재장전은 새 패를 선택하는 시점이다.** 미발사 탄과 미사용 패를 사용 더미로 보낸 뒤 남은 드로우 더미부터 뽑는다. 드로우 더미가 비면 사용 더미를 섞는다. 어떤 탄도 덱에서 삭제되지 않는다. 패 교환은 정확히1장 대1장으로 유지한다.
3. **발열이 다음 탄창에 연결된다.** 일반 재장전은 [무기별 냉각량](heat-system.md)만 한 번 낮춘다. 강제 재장전은 기존의 기본 비용+1턴으로 완전히 냉각한다. 전투 종료 시에는 열0이다. 냉각탄·저발열탄·짧은 사격·일부러 뜨겁게 운용하는 파츠의 차이가 이어진다. 별도 에너지 수치는 추가하지 않았다.
4. **실행 전에 결과를 보여 준다.** 재장전 버튼은 지금 재장전한 뒤 남는 열을, 확정 전 비용 표시는 사격 후 재장전했을 때의 열을 보여 준다. 산개는 가능한 온도 범위다. 게이지와 실제 냉각 연출도 잔열을 유지한다.
5. **패가 늘어도 모두 조작할 수 있다.** 회수탄은 항상 표시하고 전술탄은 페이지당6장이다. 기본 보행자/압쇄의6장은 한 화면, 확장/산개의 추가 후보는 명시적인 이전/다음 버튼과 페이지 수로 접근한다. 장전 중 페이지와 카드 위치를 보존한다. 다른 페이지의 압축 쌍은 기존 압축 버튼으로도 합칠 수 있다.

마지막 장전 탄부터 발사하는 규칙, 직접 발사 순서 편집, 5무기·파츠23종·탄환 화력·적 HP/거리·보상 경제는 이번 변경에서 유지한다. 기존 압축/보상 건너뛰기가 덱을 관리하는 선택이므로 슬더스2를 이유로 폐기된 상점 제거 서비스를 되살리지 않는다. Retain/Exhaust/Sly를 모두 추가하는 것은 이번 범위가 아니다. 후속 파츠의 후보 개념으로만 남긴다.

## 검증과 남은 판단

[변경 전 감사](../qa/reports/decision_depth_2026-10-04.md)와 [변경 후 비교·기능·실제 화면](../qa/reports/decision_revision_2026-10-04.md)을 구분한다. 자동 정책의 완주율은 사람의 승률이 아니다. 패 선택 여지와 과열 중단의 실제 비용이 생겼다는 증거를, 모든 탄환의 역할과 재미가 완성됐다는 주장으로 확대하지 않는다.

보행자의 무작위 운용은 여전히 강하다. 다음 조정 대상은 조건부 탄의 기본 피해와 성공 보상, 장갑/다수/원거리 편성에서 서로 다른 두 가지 이상 대응의 성립 여부다. 적 HP를 일괄 늘리거나 모든 탄환을 약하게 만들지는 않는다. 남긴 카드가 계속 묶이는 문제는 순환으로 줄였지만, 원하는 조합을 보존하지 못하는 답답함은 사람 플레이로 확인해야 한다.

저장v11은 v8의 추가 턴 부채, v9/v10의 손패·이미 구성한 발사 순서를 보존한다. 불러오기만으로 추가 드로우나 셔플을 하지 않는다. 새 손패와 순환은 다음 실제 재장전에 적용한다.

## 후속 탄환 확장 검토

2026-10-05 사용자 피드백: 최신 APK 전달 후 이전보다 긴장감과 선택의 재미가 확실히 좋아졌으며, 탄종 다양화가 패 선택의 재미를 더 키울 것으로 기대했다. 현재 패·순환·잔열을 유지할 체감 근거다. 테스트 무기/층/시드는 알려지지 않았으므로 자동 비교에서 남은 특정 무기 문제나 장기 다양성까지 해결됐다고 기록하지 않는다.

후속으로 사용자가 확장을 승인하고 탄창 크기·파츠·총기 연동을 강조했다. 아래 후보 중4종을 [예약·차단·확산·연계](build-synergy.md)로 구현했다. 연결 파츠3종, 보상/상점/UI/저장v12도 적용했다. 아래 목록은 최초 검토 의도이며 현재 수치·제약은 구현 문서를 따른다.

- 다음 패 준비: 이번 탄창의 화력을 일부 포기하고 다음 패의 특정 조합을 확보한다. 보존/회수/예고 드로우 중 실제 조작과 비용이 적합한 방식을 고른다. 현행 즉시 장전 편집과 구분하고 새 패가 항상 정답 조합이 되는 무제한 순환을 피한다.
- 적 행동 대응: 원거리 준비나 특수 행동을 끊는 탄으로 즉시 처치 외의 대응을 만든다. 기존 충격탄의 거리 밀기와 구별하고 반복 제어로 적이 영구히 행동하지 못하는 상황을 확인한다.
- 기존 연계 분기: 화상 유지·기폭 외에 전파 같은 분기를 검토한다. 기존 소이/기폭/전격과 대체 관계를 확인하며 새 상태 게이지를 기본 전제로 추가하지 않는다.

신규 탄은 유리한 상황·아쉬운 상황·연결되는 기존 탄/파츠를 각각 설명할 수 있어야 한다. 보상/상점에서 현재 덱과의 관계를 이해하고 추가/건너뛰기를 고를 수 있게 한다. 탄종 수만 늘어 원하는 조합을 찾기 어려워지는 문제와 무작위 장전만으로 이득이 누적되는 문제를 함께 검증한다. 묶음의 크기와 후보 효과는 사용자 확정 요구가 아니다.
