# 관문 보상·재정비

최신 적용: 2026-10-30. 새 등반의2~4구역 관문에 코어 성장 확장 선택을 추가했다. 기존 개조 하나 대신 상한+2를 열며 즉시 성장하지 않는다. 재정비·명시적 출발은 유지한다. [확장 규칙](damage-growth.md) · [검증·화면·한계](../qa/reports/late_core_growth_2026-10-30.md) · [재정비 검증](../qa/reports/gate_reorganization_2026-10-28.md).

사용자는 보스 전리품과 특별한 관문 보상을 분리하는 제안을 승인했다. 성장 코어를 첫 관문까지 늦추는 안은 채택하지 않고 **첫 전투 후 코어 선택을 유지**한다. 아래 보상 수치·강화 상한·계산 순서는 디렉터 구현값이며 사람의 체감과 장기 균형은 후속 검증이다.

## 진행

1. 첫 전투: 기존 성장 코어 선택 → 첫 특수탄 선택. 코어의 누적 성장은 유지한다.
2. 보스 처치: 크레딧 자동 지급 → 고급탄을 포함한 탄환 3후보 중 1장 선택 또는 건너뛰기.
3. 첫 네 관문: 관문 개조 1개 선택·적용 또는 건너뛰기 확인 → **관문 재정비** → **다음 구역으로 출발**. 마지막 보스는 전리품 뒤 엔딩으로 연결한다.

## 재정비와 출발

- 개조 적용 또는 포기를 확정하면 보상은 소진되지만 구역은 바뀌지 않는다. 다음 구역의 이름·설명, 현재 개조·무기·복장·탄창·재장전·휴대량·손패·교환·장착 파츠를 확인한다.
- `보유 파츠 관리`에서 기존 빌드 작업실을 연다. 무료 장착·해제·교체와 기존 5슬롯/코어1개 조건을 유지한다. 교체한 파츠는 보관함에 남는다.
- `탄약 구성 확인`은 보유 탄약을 열람한다. 기존 생산권 외에 신규 탄약 지급·임의 교체·압축·개조·파츠 분해 서비스를 추가하지 않는다. 전투별 소진 탄은 다음 교전에서 기존 규칙대로 복구된다.
- `다음 구역으로 출발`만 다음 지도를 연다. 파츠 관리 창을 닫거나 저장 후 재개해도 재정비에 머문다. 구역 진입은 한 번만 가능하다.
- `gate_version=1`의 `phase=gate, resolved=false`는 개조 선택 중, `resolved=true`는 재정비 중이다. 기존 현대 관문 저장은 선택 단계로 이어지고 이미 넘어간 관문 보상은 다시 열리지 않는다. 버전 없는 옛 관문은 원래 보상·즉시 이동 흐름을 유지한다.
- 개조·파츠 교체·출발은 기존 원자적 자동 저장을 이용한다. 전리품·개조를 다시 받거나 출발을 중복 실행할 수 없다. 관문 연출과 등반 중 무기/복장 변경은 별도 후속이다.

보스 크레딧은 지역별 30/35/40/45/50Cr다. 탄환 선택을 포기해도 유지한다. 기존 발견 후보 2장에 현재 발견 규칙·보유 파츠를 고려한 압축 고급탄 1장을 더한다. 크레딧과 탄환 중 하나만 택하는 일반 보상과 구분한다.

## 관문 개조 현행 후보

| 개조 | 효과 | 제약·운용 차이 |
|---|---|---|
| 코어 성장 확장 | 성장 상한+2, 최대3회로8→10→12→14 | 새 등반2구역 보스 이후, 성장 코어 소유 시. 즉시 피해 증가 없음. 이후 장착/기존 조건 달성/승리로 성장. 다른 관문 개조 대신 선택. |
| 축열 변환기 | 일반 재장전에서 실제로 식힌 열을 다음 공격탄 첫 타격에 가산. I 최대 +6, II 최대 +10 | 강제 과열 냉각 제외. 중첩 없이 새 충전으로 교체. 지원탄은 소비하지 않는다. 첫 타격이 보호막에 막혀도 소비한다. |
| 전용 탄약 생산권 | 소유한 일반 특수탄을 견본으로 선택하고 기본탄 3장을 동일 성능의 특수탄 3장으로 교체 | 총 탄약 수 유지. 위력·개조 보존. 압축·임시탄 견본 제외. 바꿀 기본탄 3장을 직접 고른 뒤 확정. 필요 재료가 없으면 후보 제외. |
| 연쇄 격발기 | 같은 탄창에서 직접 처치를 낸 탄마다 이후 공격 배율 +0.25. I ×1.75, II ×2.00 상한 | 한 탄으로 여러 적을 잡아도 한 단계. 해당 탄 자신에는 새 단계 미적용. 재장전 시 초기화. 화상·기폭·전이·충격파·요격 처치 제외. 코어의 직접 잔타·초과 피해 처치는 포함. |

이번 등반 동안 유지하며 파츠 슬롯을 점유하지 않는다. 축열/연쇄는2단계, 성장 확장은3회까지 선택할 수 있고 생산권은 재료가 있으면 반복 선택 가능하다. 최대 강화나 재료 부족으로 후보가 줄 수 있으며 없는 선택지를 채우려고 다른 보상을 임의로 강제하지 않는다. 건너뛰기는 별도 확인 후 진행한다. 네 종류를 영구 후보군으로 고정한 결정은 아니다.

기존 관문의 탄창+1/가방+1/24Cr/압축 고정 선택은 새 등반에서 위 개조로 교체한다. 가방 확장과 압축의 공방 기회는 유지한다. 관문으로 얻던 추가 탄창 성장은 이번 개조에서 제공하지 않는다. 향후 무기·모듈과의 탄창 확장 기회는 별도 검토하며 무료 추가 효과로 숨겨 넣지 않는다.

## 계산·수명

- 기본 피해와 가산 → 증폭 배율 × 성장 코어 배율 × 관문 연쇄 배율 → 정수 버림 → 첫 타격에만 축열 가산 → 장갑/보호막. 연타 전체에 축열을 반복하거나 증강 무기로 두 배 복제하지 않는다.
- 돌파 코어는 축열을 포함한 첫 타격의 초과 피해를 기존 방식으로 전달한다. 잔타 코어의 남은 타격에는 축열이 재적용되지 않는다. 열압 충격파는 연쇄 적용 원 피해를 사용하지만 축열을 복제하지 않는다.
- 축열은 일반 재장전의 실제 냉각량과 상한 중 작은 값이다. 열 0에서 재장전하면 충전도 0으로 교체한다. 전투 종료/패배/다음 교전 시작 시 축열과 처치 연쇄를 초기화한다.
- 유한 탄약 비축·삽입 후 개별 회수 금지·무기별 발사/재장전 비용은 유지한다.

## 화면·저장

- 선택 카드 → 상세 조건 → 별도 적용 버튼. 네 후보가 있으면2열로 표시하고 작은 화면에서 세로 스크롤한다. 성장 확장은 장착 코어의 성장 완료 후 실제 효과를 함께 보여준다. 생산은 견본과 기본탄 3장 선택을 별도 단계로 보여주고 확정 전 보유량을 바꾸지 않는다.
- 보스 전리품 화면은 크레딧 수령, 코어 성장, 탄환 선택을 먼저 보여준다. 세부 열/발동 통계는 기록 버튼에 남긴다.
- 전투 열 패널의 축열/연쇄 상태, 발사 레일의 적용 표시, 적중 결과·계산 상세를 연결한다. 실제 적중마다 상태를 갱신하며 확률적 표적을 확정 피해로 바꾸지 않는다.
- 새 등반 `gate_version=1`, 전투 `gate_mods`와 런타임 상태를 저장한다. 버전 없는 기존 이어하기는 기존 관문 보상을 유지한다. 첫 전투 보상을 다시 주거나 이미 지급한 보스를 소급 정산하지 않는다.
- 개발 → 관문은 기존에 획득한 덱을 이용한 명시적 미리보기다. 저장하지 않고 관문 위치만 구성하며 자연 진행 증거로 간주하지 않는다.
