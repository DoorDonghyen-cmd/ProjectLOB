# 확보한 외부 자료의 개발 적용 순서

사용자 확정: 제안된 GitHub 자료에서 쓸 만한 것을 먼저 충분히 확보한 뒤, 이를 활용해 개발한다. 현재 게임 규칙·승인 도트풍이 결정 기준이며 외부 프레임워크의 샘플 기획을 새 기준으로 삼지 않는다.

## 확보 상태

[자료 보관소](../../reference_library/README.md)에12개 저장소의 고정 버전 소스·ZIP, 파일별 SHA-256, 별도 라이선스 사본과 읽을 진입점을 확보했다. [복원 가능한 버전 기록](../../reference_library/sources.lock.json), [도입 판단](../../reference_library/review.json). 대용량 원본은 로컬 `reference_library/cache/`에 있고 Git에는 버전·복원 도구·고지·검토가 남는다.

전체 저장소를 확보한 것과 바로 활성화 가능한 플러그인을 구별한다. 후보 소스는 본편 Godot 프로젝트 밖에 있다. 샘플 자산을 게임 배포물에 일괄 포함하지 않는다. 이전에 설치한 Godot/UI/아트 스킬과 LibreSprite는 유지한다.

## 첫 적용 — 공통 조작부 마감

**구현:** 기존 버튼 전용 공통 테마를 설정 드롭다운·선택 팝업·토글·스크롤바·도움말 배경까지 확장했다. 현재 LoB 도트 버튼 리소스·청회색 팔레트를 재사용한다. Pixel UI Fantasy의 전체 위젯 구성에서 착안했고 원본 테마/아트 코드는 복사하지 않았다. 설정값과 전투 규칙은 그대로다. 새 스타일은 디렉터 적용안이며 사용자 미감 확인은 후속이다.

**확인된 남은 범위:** 대화창 외곽/창 제목, 장비·탄환 비교 동작, 일부 개별 화면의 스타일 덮어쓰기를 같은 화면에서 추가 점검한다. 이번 조작부 확장을 전체 UI 완료라고 부르지 않는다.

## 후속 개발 순서

**UI 잔재 후속:** 설정/상세/확인 창의 네이티브 회색 외곽을 공용 도트 씬으로 대체했다. 모바일 스크롤을 막던 중간 입력 필터도 수정. 터치 제스처/압축 충돌/취소와 저장 보존497검사 통과. [검증](../qa/reports/modal_touch_2026-10-11.md). 아래 대화창 외곽 미완료 기록은 이 상태로 갱신한다.

**4차 구현:** Slay의 재생 노드 재사용, Open RPG의 입력 비차단 전환/Tween 정리를 참고해 본편 메뉴·전투·보상의 짧은 전환과 실제 행동 효과음을 연결했다. 원본 합성12종·효과음 설정·건너뛰기/즉시 지원. [258검사·실제 믹서 검증](../qa/reports/presentation_feedback_2026-10-11.md). 외부 애드온이나 샘플 음원 직접 복사 없음. 다음은 사람 청취에 따른 음색/음량 조정, 대표 적 동작의 다른 종 확장, 네이티브 대화창 외곽 등 UI 잔재 정리다.

**3차 대표 동작 경로 구현:** 처마등4키포즈를 ASE 타임라인/태그/시간/발 좌표로 보존하고 LibreSprite 출력→Godot SpriteFrames로 연결했다. 독립 AnimatedSprite2D 미리보기와 실제 시안 전투에서 검증. Importality의 메타데이터 분리 방식을 참고하고 원본 애드온 활성화는 보류한다. [465검사와 적용 범위](../qa/reports/monster_motion_2026-10-11.md). 다음은 이 경로로 동작을 확장하며 메뉴·전투·보상 연결 연출/소리 작업을 검토하는 단계다.

**1·2차 도구 구현:** 메인 → 개발 → 개발 작업대에서 공용 UI 상태 표본과 현행 Content 기반 탄환·파츠 조합 시험을 열 수 있다. Model/Forecast 독립 실행, LIFO/장착 불이익, 결과 고정 비교, 조건 변경 경고 적용. 3해상도134검사 통과. [실행·범위·화면](../qa/reports/developer_lab_2026-10-11.md). 전체 화면별 스타일 잔재 제거와 사람 체감은 계속 점검한다. 다음 적용 대상은 대표 적의 태그 애니메이션 제작 경로다.

| 우선 | 개발 결과물 | 확보 자료에서 볼 부분 | 완료 기준 |
|---|---|---|---|
| 1 | 전체 UI 부품/상태 점검 화면 | Pixel UI Fantasy의 테마, 공식 control_gallery·accessibility·multiple_resolutions | 기본/선택/비활성/키보드 포커스·긴 문구·작은 화면을 비교하고 기본 외형 잔재 제거 |
| 2 | 탄환·파츠 비교와 조합 시험 도구 | Card Skeleton 검색/속성/덱 구성, Slay The Robot 콘텐츠 묶음 | 현재 Content를 직접 읽음. 복제된 수치 원본 없음. 저장 격리, 실제 Model/Forecast를 통한 시험 |
| 3 | 대표 적의 태그 기반 애니메이션 시험 | Importality, 공식2D 동작 예제, Pixelorama 제작 소스 | 실제 프레임/태그/지속시간/발·총구 정렬 일치. 기존 원본과 출력 경로 보존 |
| 4 | 메뉴·전투·보상 연결 연출과 소리 | Open RPG의 전환·대화, Slay의 sound_manager/smooth_scroll_container, VFX Library | 행동 순서·건너뛰기·볼륨/감소된 연출을 함께 검증. 효과로 입력을 막지 않음 |

## 바로 설치하지 않는 근거

- Pixel UI Fantasy: Godot4.7에서 테마와 주요6위젯 로드 확인. 양피지 외형·라틴 글꼴은 현행 아트와 맞지 않아 기존 LoB 자산으로 구성 방식을 활용한다.
- Card Skeleton: MIT 원문 확보. 애드온만 복사하면 `res://icon.svg`, `res://CardImages/CardBack.jpg` 등 샘플 경로에 의존한다. 현행 데이터 전체를 외부 JSON으로 옮기는 대신 필요한 검색/비교 구조를 사용한다. 샘플 카드 이미지는 별도 출처이며 배포 대상으로 채택하지 않는다.
- Importality0.3.0: 별도 Godot4.7 프로젝트에서 파싱 오류 없이 로드했으나 종료 시 ObjectDB19개·리소스8개 정리 경고가 발생했다. 실제 다중 프레임 가져오기까지 검증된 것은 아니므로 본편 자동 활성화는 하지 않았다. 기존 LibreSprite 출력 경로는 사용 가능하다.
- Colorful Palette Swap: Godot3 형식이며 고정 버전에서 명시적 라이선스를 확인하지 못했다. 소스 참고용 보존, 프로덕션 복사/배포 제외.
- Smooth Pixel: 고정 전장에 즉시 도입할 필요는 낮다. 실제 카메라 이동이 도입될 때 비교한다.
- Pixelorama: 편집기 소스 확보. 설치 실행파일을 새로 내려받거나 기존 편집기를 교체하지 않았다.

외부 출처·라이선스의 확인 범위는 `review.json`이 기준이다. 목록 저장소의 라이선스가 그 목록에 연결된 모든 게임·이미지·글의 사용 허가를 뜻하지 않는다.
