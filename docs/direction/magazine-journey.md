# 탄창 여정 — 첫 관문까지 다섯 전투

**본편 통합 완료(2026-11-01):** 사용자 후속 요청으로 [새 등반 전체](campaign-magazine.md)에 현행 탄창 전투/HUD를 연결했다. 본 문서의 다섯 전투 여정은 비교 경로로 유지한다. 아래의 본편 미활성/통합 대기는 이 후속 결정으로 대체하며 사람 체감·실기기 검증까지 완료했다는 뜻은 아니다. [기능·화면·저장 근거](../qa/reports/campaign_magazine_2026-11-01.md).

**인게임 피드백 연결(2026-11-01):** 기존 사격/강화·명중·과열·냉각·교체·승리 효과음과 실제 열 이벤트를 새 HUD에 연결했다. 과열의 중간 표현 시점을 복구해 추가 적 행동이 생략되지 않게 하고, 잔탄 보존 냉각은 교체 동작과 구분한다. 음량/연출 설정은 공통 환경설정에 보존한다. [검증·화면·범위](../qa/reports/journey_feedback_2026-11-01.md). 사용자가 APK를 별도로 진행하므로 여기서는 인게임을 계속한다. 아래 모바일 준비 기록은 이번 변경 이전 묶음이며 최신 APK 완료 기록이 아니다.

**모바일 전달 준비(2026-11-01):** 기존 빌드 도구의 `magazine-journey` 모드를 연결하고 최신 HUD·여정 리소스를 따로 묶어 검증했다. 컴파일된 리소스에서5총기·5전투/정비2곳·보상/성장·별도 프로세스 저장 재개와 다른 모드 저장 보존을 확인했다. [범위·근거](../qa/reports/mobile_journey_ready_2026-11-01.md). APK는 아직 제작하지 않았으며 실기기 지속 성능·터치·발열은 미측정이다.

**최신 점검(2026-11-01):** 라인 + 도트 적용에 사용자가 긍정 평가한 뒤 연속 플레이를 점검했다. 행동 뒤 사라지던 적 행동 안내와 누락된 전장 HP 예측 연결을 복구했다. 실제 획득 덱에서 빼내기로 사격 한 번을 줄이는 사례와 그대로 쏴도 승리하는 대안을 확인했다. 기존5총기·25전투 재생과 실제 HUD5전투 흐름·저장 재개 통과. [재현·판단·검증 경계](../qa/reports/journey_review_2026-11-01.md). 전투 수치·여정·기본 진입은 유지하며 연속 재미와 모바일 실기기 결과는 아직 없다.

**최신 UI(2026-11-01):** [전투 사이 선택 화면](../qa/reports/journey_flow_ui_2026-11-01.md)을 기존 여정에 적용했다. 코어/탄/정비 후보를 고르면 실제 명령의 복사본으로 적용 전후를 보여준다. 경로 화면은5전투·정비2곳의 위치와 다음 목적지를 확인하는 용도이며 기존 고정 경로를 바꾸지 않는다. 선택만으로 저장/소유가 바뀌지 않고 확정 후에만 반영한다. 기존 아래 규칙과 본편 통합 조건을 유지한다.

## 판단과 적용 범위

2026-10-31 사용자 진행 승인에 따라, 이전보다 긴장감·선택·덱 빌딩이 좋아졌다는 평가를 받은 탄창 구조를 **보상으로 덱이 바뀌는 다섯 연속 전투**에 연결했다. [사용자 후기와 후속 범위](magazine-ejection.md#사용자-후기와-다음-비교-범위)가 결정 근거다. 기존 두 발 빼내기 한도, 현재 전투에서의 소모, 탄창 교체 비용과 총기별 발사 규칙을 유지한다.

현재는 별도 저장을 쓰는 플레이 가능한 첫 관문 여정이다. 본편 새 등반의 기본 규칙을 변경하지 않는다. 모바일 전달본의 독립 전투 비교와 이 연속 여정을 구분한다.

## 실제 획득 흐름

| 순서 | 전투·정비 | 이어지는 변화 |
| --- | --- | --- |
| 1전 | 순찰 구역 | 성장 코어 하나를 고른 뒤 특수탄을 별도로 선택 |
| 2전 | 흩어진 약탈단 | 가진 탄에 맞춰 생성되는 조합 후보 중 하나 선택 |
| 3전 | 교대 방패 진지 | 보상 선택 후 무료 정비에서 기본탄 한 발을 특수탄으로 교체 가능 |
| 4전 | 모여든 약탈단 | 보상 선택, 두 번째 무료 정비로 관문 준비 |
| 5전 | 관문 보스 | 보상 선택 후 여정 종료, 다섯 전투의 행동·소모·빼내기 기록 표시 |

기존 캠페인의 연결된 경로 `101 → 201 → 302 → 401 → 501 → 602 → 702 → 802`, 순서731042, 지도3을 사용한다. 비전투302는 기존 건너뛰기 명령으로 통과하고 기록한다. 상점·전체 지도 선택을 이 비교 화면에 추가하지 않는다. 경로는 비교용으로 고정하지만 탄을 보상 전에 지급하거나 탄창의 조합 순서를 고정하지 않는다.

출발 덱은 실제 기본 작업복의20발이다. 전투·보상·정비·코어 성장은 기존 Campaign/Model 명령을 그대로 거친다. 다섯 총기를 새 출발 시 선택할 수 있다. 코어 선택, 첫 특수탄 선택은 각각 별도 확정한다. 이후 탄 보상과 무료 개조는 현재 덱을 유지하고 건너뛸 수 있다. 획득 탄은 다음 전투부터 보유 덱과 함께 섞이고, 사용·빼낸 탄은 다음 전투에 복구된다. 성장한 코어의 수치는 유지된다.

방패 진지와 관문 보스는 이미 비교한 접근 후보를 동일한 실제 노드에 적용한다. 새 강제 빼내기 조건이나 적의 추가 체력 강화는 넣지 않는다.

## 조작과 저장

- `OPEN_COMBAT_UI_STUDY.cmd`: 새 연속 여정. 기존 독립 비교는 `OPEN_MAGAZINE_COMPARISON.cmd`로 보존한다.
- `덱`: 현재 보유 탄과 남은 탄을 확인. `파츠`: 실제 코어 배율·성장 조건 확인. 승리 후 성장한 값의 전후 차이를 표시한다.
- `재도전`: 확인 후 현재 전투에 들어왔을 때의 덱·장비·성장·탄 순서·난수·빼내기 한도를 복원한다. 이전 전투의 보상은 보존한다. 승리 보상을 다시 받을 목적으로 이미 끝난 전투로 돌아갈 수 없다.
- `새 출발`: 총기를 선택하고 명시적으로 출발해야 현재 여정을 새로 시작한다. 취소하면 그대로 유지한다.
- 전투 행동·빼내기·보상·정비·구간 이동마다 별도 자동 저장. 첫 코어를 고른 뒤 첫 특수탄을 아직 고르지 않은 상태도 그대로 재개한다.
- 패배는 같은 조건으로 재도전하거나 새 출발 가능. 첫 관문 이후 지역으로 자동 진입하지 않는다.

주요 배치는 A안 전투 씬을 상속한 `combat_magazine_journey.tscn`에 저장한다. 보상은 기존 도트 탄환/코어 리소스, 먹색 배경, 상아색 제목과 황동 선택 테두리를 재사용한다. 설명이 긴 탄은 카드 안에서 스크롤한다.

## 검증과 다음 판단

[기능·실제 화면 보고서](../qa/reports/magazine_journey_2026-10-31.md)를 기준으로 구현 결과와 체감 가설을 구분한다. 같은 전투의 재도전과 종료 기록으로 그대로 사격/빼내기를 비교할 수 있다. 자연 순서에서 빼내기가 다음 피해를 줄이는 사례도 있으므로, 빼내기를 매번 쓰게 만드는 방향으로 수치를 바꾸지 않는다.

다음 사람 플레이에서는 **보상 이후 덱이 달라졌다고 느껴지는지**, **어떤 상황에서 탄을 포기할 가치가 있었는지**, **관문까지 긴장감이 이어지는지**를 먼저 확인한다. 모든 코어 조합·다른 순서·정예/후반·모바일 지속 FPS와 발열, 본편 연결은 후속 범위다.

## 본편 연결 판단 조건

2026-10-31 사용자 승인으로 [개편·검증 절차](development-workflow.md)를 이 여정에 적용했다. 아래 조건과 해석은 디렉터의 작업 기준이며, 사람 테스트 결과나 본편 전환 완료 선언이 아니다. 기존 탄창 구조에 대한 긍정 후기와2026-11-01 라인 + 도트 UI 적용에 대한 긍정 평가를 유지한다. 개별 빼내기의 사람 선택 이유와 연속 재미는 미확정이다.

| 질문/통합 조건 | 유지할 근거와 수정할 신호 | 현재 상태·근거 |
| --- | --- | --- |
| 보상이 다음 판단을 바꾸는가 | 획득 탄/코어 때문에 사격·냉각·교체·보상 선택이 달라지고 이유를 설명할 수 있음. 수치만 오르고 같은 행동이 반복되면 보상 역할/조우 구성을 재검토 | 실제 획득·성장 연결 구현, [기능 검사](../qa/reports/magazine_journey_2026-10-31.md). 연속 성장의 사람 체감 대기 |
| 빼내기와 그대로 쏘기가 모두 선택인가 | 위험 회피·순서·연계의 이득과 탄 소실의 대가가 읽힘. 항상 한도까지 빼거나 특정 탄을 무조건 버리는 패턴이면 원인 확인 | 독립 비교에서 그대로 쏴도 괜찮다는 사용자 후기. 제작자 검토에서 실제 획득 탄창의 한 발 포기/사격 횟수 감소와 양쪽 승리 확인. 사람의 선택 이유는 [기록지](../qa/protocols/magazine-journey-playtest.md)로 확인 대기 |
| 전투가 다른 판단을 요구하는가 | 짧은 무리전·사수/방패 대응·성장 확인·관문 압박의 초점이 구분됨. 위협 전에 모두 해결되거나 정답 행동 반복이면 해당 조우를 수정 | 개편의 긴장감에 긍정 후기, 관문까지 연속 체감은 미검증. 일렬 배치·거리 숫자 제거 유지 |
| 전투 밖의 상태가 이어지는가 | 보상/정비/건너뛰기/재도전/재개에 보유·성장·난수·빼내기 한도가 정합하며 중복 보상이 없음 | 여정 기능 검사와 [최신 공통 HUD 흐름 검사](../qa/reports/combat_feedkit_2026-10-31.md) 존재. 관련 코드 변경 시 해당 증거 갱신 |
| 다른 조건에서도 선택이 남는가 | 다른 순서·총기 고유 규칙·정예/후반 표본에서 지배 전략과 불합리한 패배를 구분. 재장전/냉각 비용·접촉 여유·탄 소모를 함께 봄 | 고정 경로 구현과 독립 총기 비교는 존재. 새 규칙의 정예/후반·장기 경제는 미검증 |
| 적용할 제품 경로가 준비됐는가 | 새 등반/기존 이어하기 정책, 기본 진입과 되돌릴 경로, 실제 포함 리소스, 실기기 지속 플레이/저장 복귀가 적용 범위에 맞게 확인됨 | 본편 기본 진입 유지. `magazine-journey` 전달 모드 지원과 컴파일 리소스의 여정/저장 재개 확인. 최종 APK 제작·설치와 [실기기 지속 측정](../qa/protocols/mobile-sustained.md)은 남음 |

다음은 표시 복구를 포함한 최신 화면에서 위 세 가지 사람 질문을 같은 연속 여정으로 확인하는 것이다. UI 방향의 긍정 평가를 연속 재미·실기기 검증으로 확대하지 않는다. 후기를 받으면 유지/수정/보류와 이유를 여기에 갱신하고, 드러난 문제에만 후속 구현을 붙인다. 모바일 APK 요청 시 준비된 `magazine-journey` 모드로 빌드하고 최종 APK의 실제 포함 씬·서명·용량을 다시 검증한다.

본편 적용 작업에서는 위 미해결 항목 중 출시 범위에 영향을 주는 것을 해소하거나 범위를 명시적으로 제한하고, 새 등반과 기존 이어하기의 동작을 구현·검증한다. 이 문서 추가만으로 기본 모드·규칙·저장 형식이 바뀌지는 않는다. 모든 전투에서 빼내기를 강제하거나 기능을 새로 만들며 비교 단계를 계속 늘리지 않는다.
