계열 이름 자체는 대부분 효과와 잘 맞는다. 문제는 **변형 표기**와 **겹치는 낱말**이다.

## 문제와 제안

### 1. 같은 계열의 변형이 모두 같은 이름

- 기본탄은 위력 1~5 × 개조(없음·화력·방열) × 압축 여부로 15종인데 전부 '기본탄'이다. 철갑탄과 압축 철갑탄(피해 2 → 5)도 탄창 카드·보상 카드에서는 둘 다 '철갑탄'이다.
- '압축' 접두는 상점에만 붙고 탄창 카드·보상 카드에는 없다. 위력·개조는 상세(‘기초 위력 3/5 · 화력 개조 +1’)에서만 보인다.
- 앞서 사용자 피드백 "탄환 카드가 아직 기본탄 이런 형태"와도 이어진다.
- **제안**: 이름은 계열 이름 그대로 두고, 모든 화면에 같은 **표식**을 붙인다.
  - 압축: 이름 뒤 `+` (예: `연타탄+`). 탄창 카드는 좁아서(가로 60px 남짓) 접두보다 짧은 표식이 낫다.
  - 위력 1~5: 카드 숫자가 이미 보여 주므로 이름에는 넣지 않는다. 상세에만.
  - 개조: 상세에만(지금처럼).

### 2. '연계'가 여러 곳에서 다른 뜻으로 쓰인다

- 탄 이름 **연계탄**(앞서 쏜 다른 탄종 수만큼 +2).
- 보상 카드 설명 **'연계 · 연타탄'** = 주력을 돕는 지원탄이라는 뜻(`focus_build.gd::offer_label`).
- 전투 HUD **'연계 3번째 기본탄 ×3'** = 이번 탄창에서 생긴 파츠 효과 줄(`magazine_build.gd::combo_line`).
- 그 밖에 파츠 발동 표시 '증폭 연계 N발'(`part_feedback.gd`), 계산식 '탄종 연계 N'(`readability.gd`).
- **제안**: 탄 이름은 그대로 두고 나머지 둘을 바꾼다. 보상 설명 → '보조 · 연타탄', HUD 줄 → '탄창 효과 · 3번째 기본탄 ×3'.

### 3. '섞으면 강해진다'가 세 곳에 있다

- 연계탄(탄), 다종 급탄기(파츠, 11-11 '교차 급탄기'에서 이름 변경), 교차 사격(규칙).
- 겹치는 것 자체는 '섞기 빌드'를 받쳐 주지만, 연계탄은 이제 기본 규칙(교차 사격)과 거의 같은 말을 한다.
- **제안**: 연계탄의 효과를 교차 사격을 키우는 쪽으로 바꾼다(예: '쏘면 교차 단계 +2'). 이름은 유지.

### 4. 예약탄

- '다음 패로 예약'은 손패 전투 전용이고, 탄창 등반 후보에 나오지 않는다(예약 급탄기도 제시 중단).
- **제안**: 탄창 전투용으로 바꾸거나(예: '탄창 뒤쪽 탄 1발을 다음 탄창 맨 앞에') 정리한다. 바꾸면 이름도 효과에 맞춰 다시 정한다.

### 5. 같은 이름, 다른 탄

- 옛 소이탄 변형(`thermal`)도 '소이탄'이다. 지금 등반 후보에는 없어 문제가 되지 않지만, 다시 쓰면 이름을 나눠야 한다.

## 적용 (2026-11-12, 사용자 "전부 진행해 줘")

결정 상태: 사용자 지시에 따른 디렉터 결정. 사람 확인 전.

1. **압축 표식**: 압축 탄 이름 끝에 `+`(예: `연타탄+`, `철갑탄+`). 모든 화면에 같은 이름(`content.gd::_marked`), 상점의 '압축 ' 접두는 뺐다. 표시만 바꾸므로 모든 저장에 적용된다.
2. **'연계' 낱말**: 탄 이름에만 남겼다. 보상 설명 '연계 · 연타탄' → '보조 · 연타탄', 전투 HUD '연계 …' → '탄창 효과 …', 파츠 표시 '증폭 연계 N발' → '증폭 이어짐 N발', 계산식 '탄종 연계 N' → '연계탄 N'. 모든 저장.
3. **연계탄**(새 등반, `ammo_revision.gd`): 자기 +2(앞선 다른 탄종마다)를 없애고, 쏘면 교차 사격 단계를 +2 올린다(최대 +3). 예: 연타 → 연계 → 철갑이면 철갑탄이 교차 +3.
4. **예약탄**(새 등반): 바로 뒤의 탄 1발을 탄창에서 빼 두었다가 다음 탄창 맨 앞에 먼저 넣는다(최대 3발). 등반 후보에 다시 나온다(발견 v5). 빼 둔 탄은 남은 탄으로 센다.

이전 저장의 연계탄·예약탄은 예전 규칙 그대로다. 검사: `tests/ammo_revision_rules.gd`.
