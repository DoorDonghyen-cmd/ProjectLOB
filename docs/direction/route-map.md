# 등반 경로와 비전투 장소

**현행:** 새 등반은 `map_version=3`, `place_version=1`. 상점·공방·탄약고·조우와 샛길의 최신 규칙은 아래 「비전투 장소 개편」을 따른다. 기존 v1/v2 등반은 원래 경로·거래를 유지한다. 아래 10월9일 내용은 v2 기반 구현 기록이다.

2026-10-09 · 사용자 승인 방향의 첫 구현. 구체적인 길이·위험·보상 수치는 디렉터 조정값이며 사람의 장기 플레이로 확정하지 않았다.

## 의도와 구현

사용자는 기존 맵의 짧은 길이, 두 출발점, 매번 같은 시설과 분기를 지적했다. 출발 후보 4개, 중간 분기와 합류, 시드에 따라 달라지는 시설·연결, 성장 목적에 따른 경로 선택으로 개편한다. 슬레이 더 스파이어의 시작점이 항상 4개라는 주장은 하지 않는다. [변경 전 조사](../history/design/map-structure-review-2026-10-09.md).

- 구역별 내부 진행 깊이는 8/9/9/9/10으로 총45단계다. v2는 각 단계 한 방씩 방문하며, v3는 샛길로 건너뛴 만큼 실제 방문 수가 줄어든다. 화면의 다른 후보까지 모두 방문하는 구조가 아니다.
- 출발 후보4개, 중간 진행 단계3~4개 후보, 마지막 관문1개. 연결선만 따라 다음 장소로 이동하며 보스 뒤에는 다음 지역의 출발점을 고른다.
- 시드로 방 종류·시설 위치·연결선을 생성한다. 막힌 방·고립된 방·교차하는 복도는 만들지 않는다. 같은 시드와 맵 버전은 같은 경로다.
- 첫 지역의 초기 전투는 조합→장갑→복합 표적의 기존 학습 편성을 유지한다. 방을 우회하면 해당 전투를 강제하지 않는다. 보스는 지역 끝에 고정된다.
- 상점은 내부 진행 순서상4~5번째 시설 구간에 위치하며, 같은 시점의 정비·보급과 경쟁한다. 관문 앞에는 전투를 강요하는 대신 정비·보급·기록 경로가 있다. 모든 출발점에서 모든 시설에 갈 수 있는 것은 아니다.

## 경로의 선택 가치

| 목적지 | 얻는 것 | 포기하거나 감수하는 것 |
|---|---|---|
| 일반 전투 | 탄환 후보 또는 크레딧 | 적 접근과 발열 운용 |
| 위험 전투 `+` | 크레딧 선택 시 추가6Cr | 시작 거리−2m |
| 정예 | 미보유·무기 호환 파츠 최대2종 중1개, 또는22+지역Cr | 선두 HP×1.35 올림, 모든 적 시작 거리−1m(최소6m) |
| 상점 | 탄환12Cr·파츠30Cr·압축 코어18Cr | 크레딧 지출, 다른 시설 경로 |
| 정비 | 압축 / 탄환1장 제거 / 코어+1 중 하나 무료 | 다른 정비를 동시에 받을 수 없음 |
| 보급·신호·우회 | 기존 탄환·기록·자원 선택 | 전투의 파츠/크레딧 기회 |

정예는 기존 적 편성을 강화한 기능 변형이다. 새로운 세계관 몬스터의 외형·종·애니메이션 제작이 완료됐다는 뜻이 아니다. 파츠 슬롯5개·코어1개, 탄환 최소8/최대14장, 압축 코어 최대2개, 관문 탄창 확장 최대2칸을 유지한다. 장착 조건이 맞는 정예 보상만 자동 장착하고 나머지는 보관한다. 보상 후보는 이미 소유한 파츠를 제외한다.

일반 전투의 크레딧 기본값은 새 맵에서12→10, 하한8을 유지했다. 전투 소모·난이도·지역 보정과 위험 경로+6은 유지한다. 정예에서는 파츠와 돈 중 하나만 얻는다. 길이가 늘어도 덱·장착 한도를 늘려 모든 보상을 무조건 가져가게 하지 않는다.

## 화면과 조작

### 사용자 채택 — 구역 내부 배경 3단계

한 구역의 세로 진행도를 초반·중반·상층으로 나누어 전투 배경을 바꾼다. 방문 개수·전투 횟수·선택한 분기 대신 현재 노드의 내부 `floor`와 해당 맵 버전의 구역 길이를 사용한다. 단계는 `floor((clamp(depth,1,length)-1)*3/length)`이며0~2다. 12단계라면1~4/5~8/9~12, 현행 첫 구역8단계는1~3/4~6/7~8로 나뉜다. 이는 물리적인 층수나 화면에 노출할 새 숫자가 아니다.

동일 높이의 모든 분기는 같은 배경을 사용한다. 상점·이벤트를 거쳐도 단계가 일치하며, 기존 저장은 저장된 구역·진행 위치·맵 버전에서 다시 계산한다. 별도 저장 필드나 RNG를 추가하지 않는다. 발사·재장전 중에는 해당 노드의 배경을 유지한다.

첫 적용은 주거 통로의 생활 공간(기존 승인 배경) → 폐쇄 주거지 → 승강 설비다. 배경마다 실제 발판의 높이를 등록해 캐릭터·적의 발 위치와 거리 계산을 유지한다. 현재 전투 화면에 적용하며 지도·상점 내부 그림은 별도의 기존 화면을 유지한다.

`ascent_background.gd`의 공통 규칙은5구역 모두 사용한다. **전용3종 아트가 완성된 곳은 현재 첫 구역뿐**이다. 다른 구역은3단계 그림을 같은 목록에 등록하면 자동으로 연결되며, 등록 전에는 기존 전투 배경을 유지한다. 다른 구역의 그림까지 완료됐다는 뜻은 아니다. [실제 화면·검증](../qa/reports/ascent_background_2026-10-11.md).

**사용자 확정 — 물리적 층수와 경로를 분리한다.** 거대한 탑을 전달하기 위해1F·2F 같은 층수 표기를 사용하지 않는다. 지도 눈금·수평 층 구분선·선택 장소 번호·시설의F표기, HUD의전체 방문 수 분모와LV번호, 준비/이어하기/결말의35층·45층 표현을 제거했다. 현재 위치는 구역명, 앞으로 갈 곳은 시설 아이콘과 연결선으로 전달한다. 정산의 `N곳 통과`는 실제 방문 장소 수다. 내부 `floor`는 저장과 순서 계산용이며 탑의 실제 한 층으로 해석하지 않는다. 탑의 총 층수도 이 값으로 정하지 않는다.

사용자는 노드 선택 때 자동으로 노출되는 정보가 과하고 가독성이 떨어진다고 지적했다. 지도는 전체 폭으로 펼치고, 하단 고정 영역에는 선택 장소명과 `자세히`·`이동`만 둔다. 일반 장소는 추가 설명을 자동 표시하지 않는다. 정예 보상, 무료 정비, 시작 거리 감소 등 선택 전에 알아야 하는 예외 조건만 한 줄로 표시한다. 적 편성·장갑·학습 설명·가격·이후 시설은 `자세히`를 눌렀을 때 게임 안의 별도 화면으로 열고 닫으면 같은 지도 선택으로 돌아온다. 이 배치는 사용자 문제 제기를 반영한 디렉터 구현이며 사람의 체감 검증은 후속이다.

아이콘만 있는 노드와 상단 공통 범례 → 연결 경로 확인 → 하단 이동 확정. 첫 후보를 기본 선택하며 다른 후보도 한 번 눌러 비교한다. 미래 방은 장소명에 `미리보기`를 붙이고 이동 버튼을 숨긴다. 강조된 후속 경로는 가능한 선택지이며 모두 방문한다는 뜻이 아니다.

지도는 헤더와 하단 선택 영역을 제외한 가용 높이를 채운다. 긴 지역에서는 지도만 세로로 스크롤하고 하단 선택 영역은 안전 여백 위에 유지한다. 정비는 작업 종류를 고른 다음 전체 화면에서 압축 결과·장전 제약이나 제거할 탄을 확인한다. 선택 화면을 닫아도 기회를 소모하지 않으며 확정 후에만1회 사용한다.

## 사용자 채택 — 탑 탐사도 본편 통합

중앙의 지도 면과 가장자리 탑 배경을 구분한다. 시설 미니어처 대신 전투 탄환·기계 경비 표장·관문·거래 저울·렌치·상자·전파·우회 표식8종을 본편과 개발 지도에서 공통 사용한다. 개발 → `탑 탐사도`에서 저장을 보존하며 확인할 수 있다. [본편 화면·검증](../qa/reports/map_chart_adoption_2026-10-09.md).

현재 선택 가능한 장소는 밝게, 이후 후보는 낮은 대비로 표시한다. 현재에서 다음 후보로 가는 경로와 방문 경로는 실선, 미래 경로는 점선으로 구분한다. 노드 뒤 상시 박스는 없으며 선택 금색 모서리/키보드 포커스 모서리/현재 점/방문 체크/위험 `+`만 둔다. 터치 영역은 유지한다. 노드 높이78/간격90은 이번 구현값이며 영구 규칙은 아니다.

선택한 기호는 잠깐 밝아졌다 원래 색으로 돌아온다. 이동 확정은 다음 화면 위쪽의 가는 선으로 짧게 알리며 입력이나 저장을 기다리게 하지 않는다. 즉시 연출 설정에서는 두 반응을 생략한다. 5구역은 청회색·갈색·녹색·청색·보랏빛 지도 바탕/주변 배경 색조로 구분한다. 배경 원본은 공통 승강 통로이며 지역별 전용 환경 아트는 후속이다.

## 저장과 검증 경계

v2 도입 당시 새 캠페인은 `map_version=2`였다. 현행 새 캠페인은 아래 v3 규칙을 따른다. 필드가 없는 기존 저장은1로 읽고35개 장소의 이전 경로·시설·보상을 유지한다. 같은 경로 재도전도 원래 맵 버전을 유지한다. 새 등반을 선택해야 새 맵을 경험할 수 있다. 전투 저장 버전12는 유지한다.

지도 표시, 진입 허용, 저장의 방문 이력 검증은 모두 노드의 `next` 연결을 사용한다. 출발 후 시설을 다시 뽑거나 저장에 임의의 연결을 받아들이지 않는다. 생성 알고리즘 변경 시 기존 버전의 재현성을 보존해야 한다.

자동 검사는 연결·다양성·저장·조작·전투 도달 가능성을 확인한다. 실제 런 소요 시간, 정비와 정예의 장기 선택 편향, 체감 길이, 고난도 및 Galaxy 터치 체감은 후속 플레이 검증이다.


## 비전투 장소 개편 — 2026-10-18

**사용자 승인·본편 구현:** 상점/공방/탄약고의 역할 분리, 조우에서 뜻밖의 전투, 결과 일부 비공개, 독립 우회 방을 샛길 연결로 전환. 정확한 가격·확률·후보 수와 사건3종은 디렉터 구현값이며 사람의 선택 편향 검증은 남아 있다. 이전 「선택 전에 모든 이득·대가 공개」 제안은 최신 사용자 지시에 따라 채택하지 않았다.

| 장소 | 고유 역할 | 현행 기능 |
| --- | --- | --- |
| 상점 | 재화로 빌드 확보 | 탄환1종·파츠 최대2종 진열, 압축 충전18Cr/방문1회, 새 진열3→5→7→9Cr. 영구 압축·개조 메뉴 제거 |
| 정비 공방(범례: 공방) | 가진 구성 개선 | 무료 작업1회: 동일 성능 일반탄2장 압축 / 한 장 화력+1 또는 방열−1 개조 / 한 장 제거 / 가방+1. 메뉴 열람·취소는 소모 없음 |
| 탄약고 | 보충과 발견 | 무료1장. 압축 가능한 일반 보유 탄과 같은 프로필1후보 + 기존 지역 발견2후보(중복 제외 최대3). 기본탄 교체/추가/통과 유지 |
| 조우 | 단서로 현장에 관여 | 짧은 상황 → 행동 선택 → 결과 공개. 도움·기록·탄환·크레딧·돌발 전투. 떠나기 선택 가능하나 전투 결과가 드러난 뒤 전투를 무시하고 통과할 수는 없음 |
| 샛길 | 위험과 성장 기회 교환 | 일부 일반 전투 한 곳을 건너뛰는 연결. 구역당 최대1개. 건너뛴 방의 보상·처치·코어 성장 없음 |

공방은 기존 최소 덱8장·구역별 가방 성장 상한을 유지한다. 탄환 개조는 실제 한 장만 바꾸며 압축탄의 현행 개조 조건도 유지한다. 파츠 장착/해제는 무료 비전투 빌드 관리로 남으며 공방 작업을 소비하지 않는다. 전투용 압축 충전은 상점에서만 구매한다. 코어 성장, 열, 적 수치, 장전/LIFO/피니시 규칙은 변경하지 않았다.

탄약고 보충은 압축 가능한 일반 탄(기본탄 포함)만 대상으로 한다. 한 장만 보유한 프로필을 먼저, 그 안에서 특수탄을 우선하고 남은 후보에서는 시드로 고른다. 위력·개조까지 같은 프로필이며 압축탄·희귀탄 복제는 하지 않는다. 나머지 발견 후보는 기존 지역별 발견 규칙을 사용한다. 진입 때 후보를 저장하므로 파츠 교체·재접속으로 다시 뽑히지 않는다.

### 조우의 정보와 결과

- 선택 전: 상황 단서, 행동, 즉시 지불할 크레딧만 표시. 정확한 전투 확률·보상 수량은 공개하지 않는다.
- 선택 후: 실제 결과와 비용 지불을 저장. 같은 시드/장소/선택의 결과는 재접속으로 재추첨되지 않는다. 기록은 상호작용에 동반되므로 전리품과 반드시 경쟁하지 않는다.
- 전투가 드러나면 짧은 결과 → `전투 준비` → 정상 장전 화면. 적 선제 이동/추가 발열 없이 열0·새 손패·정상 거리로 시작한다. 기존 외부 압박은 일반 전투와 같은 규칙이다.
- 승리 시 현장 크레딧을 한 번 자동 지급한 뒤 일반 전투 보상을 별도로 선택한다. 패배 시 현장 보상은 지급하지 않는다. 전투 중 적/열/발사 정보는 기존대로 공개한다.

| 사건 | 선택과 내부 결과(기획·QA용, 게임에 확률 표시 안 함) |
| --- | --- |
| 문 너머의 발소리 | 문 열기: 50% 정상 전투(승리 현장+18Cr), 50% 주민 도움+16Cr. 두드리기: 주민+6Cr. 기록 동반 |
| 봉인된 유실물 | 8Cr로 봉인 해제: 40% 전투(승리+22Cr), 60% 탄환2후보 중1장과+10Cr. 쪽지 읽기는 무료 기록 |
| 멈춘 보급 수레 | 직접 끌기: 50% 전투(승리+18Cr), 50% 탄환 선택. 모터 사용6Cr: 소음 없이 탄환 선택 |

결과를 숨긴 만큼 항상 위험 선택이 유리하거나 나쁜 결과만 나오는지는 후속 플레이에서 확인한다. 이번에 전투 편성을 새로 난이도 조정하지 않았고, 해당 지역/깊이의 일반 전투 편성을 재사용한다. 3사건은 전 구역 공통이며 구역별 추가 사건/전용 삽화는 미제작이다.

### 지도·화면·저장

- 지도 범례: 전투/정예/관문/상점/공방/탄약고/조우/샛길. 기존 아이콘·선택 후 자세히 흐름을 유지한다. 조우 상세는 결과를 누설하지 않는다.
- 상점 이름: 승강장 잡화점 / 주조장 고물상 / 정원 교역소 / 회랑 물자상 / 관측대 상점. 기존 인물·대화·세계관은 유지한다.
- 상점 실내, 작업대와 복장 레이어, 탄약고 실내를 재사용했다. 조우도 기존 실내를 배경으로 사용하며 사건 전용 아트가 완성됐다는 뜻은 아니다.
- 공방은2열 작업 선택, 개조는 전후 카드/화력·열·칸수 비교. 탄약고/조우 보상은 고정 폭 카드로 표시한다. 모자란 카드 수를 화면 전체 폭으로 늘리지 않는다.
- v3는 v2 생성 결과에서 우회 방을 조우로 대체하고, 이미 존재하는 `일반 전투 → 다음 방` 경로 하나를 건너뛰는 연결을 추가한다. 출발 이후 첫2전투와 관문/정예/시설 자체를 건너뛰지 않는다. 노드 사이의 점선에 `전투 생략`을 표시하고 `전투 건너뛰기` 버튼을 사용한다. 선택 시 목적지와 그 전투의 보상/코어 성장을 포기한다는 대가를 함께 표시한다.
- 진입·방문 이력 검증은 `next`를 사용한다. 실제 방문 수는 `visited.size()`이며 배경 진행은 목적지의 내부 깊이로 계산한다. 새 연결을 타도 관문은 반드시 거친다.
- 새 등반: map3/place1. 기존 map1/2: place0으로 복원, 원래 그래프·유료 상점 압축/개조·무료 정비 충전·기존 사건 유지. 같은 경로 재도전도 원래 버전을 사용한다.

[기능·화면·검증 한계](../qa/reports/place_revision_2026-10-18.md). 장기 경제/경로별 코어 성장과 Galaxy 체감은 후속 사용자 테스트 대상이다.


### 장소 UI 배치 — 2026-10-18 후속

사용자가 바뀐 구성에 따른 레이아웃·간격 조정을 요청했다. 구현 결정: 실내/소개 → 장소별 선택 → 하단 오른쪽 계속/통과. 공방은2×2, 탄약고는 고정 폭 후보, 조우는 단서와 비용을 보고 선택한 뒤 결과를 소개 영역에 표시한다. 상점의 진열 변경은 제목 옆, 구매는 선택 상세 아래, 압축 충전/파츠 관리는 하단 왼쪽으로 분리한다. 기존v1/2 저장의 거래 역할은 보존한다. 3해상도/큰 글씨/실제 흐름 검증 완료, 사람 체감/Galaxy는 후속. ### 장소 공간 정리 후속

사용자 재피드백으로 샛길은 지도 가장자리의 긴 우회선 대신 노드 사이 열 간격을 지나며 ‘샛길’을 직접 표시한다. 상점은 입장 시 인사/이야기 전문을 실내 옆에 제공한다. 비전투 탄환 카드는 폭230px/높이164px(확보·보상196px)를 사용하고 부모 폭에 따라 늘리지 않는다. 이는 현재 판독성 기준이며 영구 아트 규격이 아니다. 선택 창은 내용 폭을 제한하고 확보 창은 실제 교체 후보 수에 맞춰 높이를 정한다. [검증·화면](../qa/reports/place_clarity_2026-10-18.md).


### 장소 공통 정렬·샛길 설명 후속

소개·선택·계속을 같은 제한 폭 안에 정렬한다. 계속은 화면 끝이 아닌 선택지 바로 아래, 행동 버튼은 내용에 맞는 단일행/비확장 폭으로 배치한다. 조우의 맥락과 비용은 유지하며 짧은 행동명으로 정리했다. 지도 연결의 직접 표기는 ‘샛길’에서 ‘전투 생략’으로 보강하고 선택 제목에 ‘샛길 → 목적지’를 표시한다. 생성 규칙·전투 보상·코어 성장 규칙은 유지한다. [검증·화면](../qa/reports/place_alignment_2026-10-18.md).
