# 전투 역할·지도 밀도·운용 성장

**현재 새 도전 보정(2026-11-06):** [전투 밸런스1차](combat-balance-pass.md)의 `balance_version=1`을 추가했다. 지속 피해 성장3회당 +1·코일 불길 +1·노심 불길3행동,3구역 이후 이동 적의 일반/정예 시작 거리82%/90%를 적용한다. 초반/보스/정지 사수 거리와 직접 피해 성장·적 체력은 유지했다. 아래v1~v3 규칙은 독립 표식으로 보존하며, 새 보정은 새 도전만 사용한다. [실제 획득/전투·예측·본편 화면·저장](../qa/reports/combat_balance_2026-11-06/README.md).

2026-11-03. [플레이 후기](../history/design/playtest-review-2026-11-03.md)와 사용자의 실행 지시에 따라 본편에 적용했다. 전투의 재미·긴장감이 좋아졌다는 사용자 평가는 유지 기준이다. 아래 수치와 구현 선택은 디렉터의 첫 적용값이며 새 빌드에 대한 사람의 체감 확인은 남는다.

## 적용과 호환

- 새 등반은 지도 `map_version=4`. 탄창 본편 새 등반은 `combat_roles_version=3`를 캠페인/전투 상태에 함께 기록한다. 앞선 역할 개편의 v1/v2 저장도 그대로 지원하며 이어하기에서 버전을 올리지 않는다.
- 이전 지도 v1~v3와 기존 진행 중인 덱·코어·발사·휴대 규칙은 유지한다. 같은 시드 재도전은 기존 지도 버전을 따르며, 이번 규칙을 보려면 **새 등반**을 시작한다. 입력/히트 표시 수정은 공통 화면에 적용한다.
- APK·외부 게시·커밋은 수행하지 않았다. 실행은 기존 `PLAY.cmd`다.

v3 코어·파츠/획득의 세부 결정과 유지 조건은 [파츠 역할](parts-builds.md), 검사·실제 화면·미확인 범위는 [검증 기록](../qa/reports/build_roles_2026-11-03.md)을 따른다. 성장형 코어의 큰 직접 피해와 v2 소이 성장률은 유지한다.

## 입력과 피격 표시

- 앞 카드에서 오른쪽으로 드래그해 연속 범위를 지정한다. 카드 간 빈틈은 가까운 카드로 판정하고 놓은 지점도 반영한다. 화면 배율을 되돌린 UI 좌표로 시작 감도를 계산한다.
- 최초의 작은 세로 흔들림을 허용하고, 활성 선택 중 위아래 20 UI px의 여유를 둔다. 다른 조작 영역까지 확장하지 않는다. 영역 밖 해제·Esc·포커스 이탈·다중 터치는 취소하며 탭 빼내기는 유지한다.
- 카드 상승/순번과 사격 버튼은 같은 **선택한 최대 카드 수**를 표시한다. 예측상 조기 처치·열 중단·조건부 발사라면 버튼에 `최대`를 붙인다. 실제 미발사 탄은 보존되고 발사된 카드만 소모된다. 한 장의 연타 수와 카드 수를 혼용하지 않는다.
- 피해 숫자는 HP 카드 열 대신 실제 피격 대상의 충돌 시점 위치를 따른다. 죽은 적·밀치기 후에도 그 피격점을 유지한다. HP 카드의 기존 높이 쌓기/낮은 화면 가로 배치는 변경하지 않는다.

## 지도 v4

- 관문을 제외하고 일반 경로는 최소 4전투, 샛길 포함 경로는 최소 3전투다. 일반·정예를 합산하며 선택적으로 피할 수 있는 돌발 전투는 보장 횟수에서 제외한다.
- 모든 경로에서 비전투 장소는 최대 2곳 연속이다. 이전 v3 그래프에서 이 기준을 어기는 경로의 선택형 조우 일부만 일반전으로 바꾼다.
- 노드 ID·모든 연결·샛길·상점/공방/탄약고·관문 직전 휴식은 보존한다. 모든 길을 같은 편성으로 만들거나 샛길을 없애지 않는다.
- v4 생성 결과는 최대 32개 키까지 보관하고 호출자에게 깊은 복사본을 돌려준다. 반복 조회/저장 검증에서 밀도 보정을 다시 계산하지 않으며 호출자의 이름/노드 편집이 원본을 바꾸지 않는다.

## 처치 후 전이와 다른 탄환 역할

| 요소 | 새 등반 규칙 |
|---|---|
| 연쇄·돌파 코어 | 주 표적을 제외한 **추가 1기**까지 잔여 타격/초과 피해 전달. 같은 추가 적에게 여러 타격이 들어가도 대상 수는 한 번 센다. 주 표적의 직접 피해·위치 배율·코어 화력 성장은 유지한다. |
| 전이 성장 | 관문 전이 회로 확장 1회당 추가 대상 +1, 최대 2회. v3에서는 함께 장착 가능한 전이 축전기 모듈도 처치 전이 대상 +1(v1/v2의 전격 분배 연결은 옛 저장에 보존). 모두 투자하면 추가 4기까지. 일반 광역탄·열압 충격파는 이 제한과 구별한다. |
| 소이탄 | 기존 표적 화상에 더해 착발 거리 앞뒤 2m에 불길을 **적 행동 2회** 남긴다. 직접 처치해도 그 지점에 남는다. 매 적 행동의 이동 직전에 범위 안 적에게 피해, 장갑/차폐 무시. 재장전·냉각도 시간을 진행한다. |
| 불길 중첩 | 동시에 최대 3곳, 같은 중심은 기간/피해를 큰 값으로 갱신한다. 겹친 지역 피해와 표적 화상은 행동당 큰 피해 한 번만 적용한다. 네 번째 지점은 가장 먼저 생성한 지점을 교체한다. 전투마다 초기화하며 압력탄에는 생성하지 않는다. |
| 소이 파츠 | v3 열폭주 노심은 화상/불길 피해 +2·앞뒤3m·4적 행동, 재장전 +1행동. 코일은 불길 피해 +2. 기존 표적 화상·기폭·불씨 이동의 연계도 유지한다. |
| 차단탄의 경직 | 이동 적의 통상 접근량을 2적 행동 동안 절반으로 낮춘다(올림, 이동하는 경우 최소 1). 압축형은 3행동. v3 충격 피스톤은 기간 +1행동, 충격 가이드는 경직 중 직접 타격당 +2. 같은 적에게 경직은 전투당 1회. 기존 특수 행동 차단도 별도 조건대로 유지한다. 압력탄·독려/끌기 자체를 정지시키지 않는다. |

불길의 기본 피해는 현행 화상 피해를 사용한다. 증폭·배율·위치 파츠의 직접 피해 배율을 불길에 중복 적용하지 않는다. 경직은 일반 이동을 늦추는 선택이며 모든 적을 멈추는 기능이 아니다. 실제 전투의 불길 영역/남은 행동, 피격 문구, 적 행동 예고, 탄 상세를 계산과 연결한다.

첫 주력 보상에 소이/전격을 추가했다. 이 두 시작 묶음은 주력 2장+차단탄 1장이며 기본탄 3장을 교체한다. 연타/철갑/열방출의 기존 묶음도 유지한다. 이후 지원 후보에는 차단·소이·기폭 등을 주력 계열에 맞춰 포함하고, 주력 복사/강화 경로는 유지한다. 모든 덱에 제어탄을 의무적으로 넣게 만드는 것이 목표는 아니다.

경제 후속 `economy_version=1`은 [관문 유료 정비·첫 연결 파츠](outfit-bag.md)를 별도 연결한다. 무료 관문 개조는 아래 규칙을 유지한다.

## 관문 운용 성장

| 개조 | 효과 | 유지하는 제약 |
|---|---|---|
| 급탄 기구 확장 | 사격 선택 상한 +1발, 최대 2회 | 탄창 크기·열 한계·적 행동 비용·과열 중단·리액터 강행 조건 유지. 이미 처치 조건으로 탄창 끝까지 발사 가능한 스파이크에는 무효 선택을 제시하지 않는다. |
| 저발열 약실 | 모든 탄의 양수 기본 발열 −1, 최소 1, 최대 2회 | 연속 사격 추가 열·배율탄이 뒤 공격에 주는 추가 열·파츠 열은 유지. 냉각/열방출의 원래 효과는 유지. |
| 전이 회로 확장 | 연쇄/돌파 처치 전이 대상 +1, 최대 2회 | 화력 배율·일반 광역탄·열압 충격파 변화 없음. |

새 등반 관문은 위 선택과 기존 연쇄 격발기·전용 탄약 생산·후반 코어 성장 확장을 사용한다. 열을 줄이지 않는 기본 탄창 교체와 중첩되던 관문 축열 변환기는 새 목록에서 제외하되 기존 저장의 효과는 유지한다. 한 관문에 한 개조를 고른다. 작은 화면은 새 보상 화면과 같이 원래 글자 크기와 세로 스크롤로 읽고, 이탈 시 원래 화면 배율로 복원한다.

## 복장별 덱 범위와 정비

| 복장 | 최소 덱 | 초기 휴대 상한 | 정비 완료 상한 |
|---|---:|---:|---:|
| 정찰용 작업복 | 8 | 22 | 28 |
| 기본 작업복 | 10 | 26 | 32 |
| 운반용 외투 | 12 | 32 | 38 |
| 배관공 방열복 | 10 | 28 | 34 |
| 승강로 인양 장구 | 14 | 34 | 40 |
| 봉쇄구역 회수 장구 | 12 | 30 | 36 |
| 밀폐형 원정복 | 14 | 36 | 42 |

- 공방 정비의 수납 확장은 +2발씩 최대 3회. 첫 구역에서 누적 1회, 두 번째에서 2회, 세 번째 이후 3회까지 허용한다. 이전 손패 용량 때문에 특정 복장이 확장 불가능해지는 조건은 제거한다.
- 최소는 덱 제거/압축/판매의 편집 한도다. 전투 중 사용해 잔탄이 줄어드는 것을 막거나 무료 탄을 지급하는 조건이 아니다.
- 상한에서 획득하려면 기존 탄을 교체한다. 정비 확장은 탄약 지급·탄창 용량·한 사격 발수 증가와 별개다. 시작 덱은 총기에 따라 14/20장으로 유지한다.
- 작은 덱은 주력 집중, 큰 덱은 전투 지속력이라는 비교가 목표다. 복장 전체 등반 균형은 아직 확정하지 않았다.

## 후반 소이 성장 보정 — 2026-11-03

- 질문: 후반 소이 구성이 화상을 기다리는 긴 과열 반복에 치우치지 않고, 획득한 성장으로 탄약·행동을 절약하는가?
- v2에서 **장착한 열압 구동핵의 성장 2회마다 화상 피해 +1/적 행동**. 일반 화상 2 → 성장2의 3 → 성장8의 6이며, 스파이크의 원래 기본값4도 보존한 뒤 성장분을 더한다. 고열 직접 피해 후 승리라는 성장 조건과 기존 성장 상한/관문 확장은 유지한다.
- 지역 불길과 기폭도 같은 성장한 화상 피해를 사용한다. 코일의 지역 피해 +2는 그 뒤에 더한다. 화상/불길은 겹쳐도 큰 값 한 번이고 증폭·발사 위치·고열 직접 피해 배율을 추가로 곱하지 않는다. 다른 코어를 장착하면 저장된 열압 성장만으로 화상을 강화하지 않는다.
- 발사·과열 강제 냉각·교체 비용, 소이탄 기본 발열/직접 피해/기간, 적 체력/접근/지도, 획득 후보와 장착 제한은 변경하지 않았다. v1과 이전 저장의 화상 값은 보존한다.
- 카드 상세가 고정 `spec.text`를 읽던 연결을 현행 탄환 설명으로 교체했다. 전투 카드/상세의 화상·불길 값과 발열이 실제 계산을 따른다. 코어 상세에도 성장 조건을 표시한다.
- [통제 비교·3시드 획득 등반·화면·저장 검증](../qa/reports/late_balance_2026-11-03.md). 같은 노드 경로/최종 덱/파츠/관문 투자에서 행동 턴과 긴급 보급이 줄었다. 숨은 RNG를 보는 자동 탐색의 가능성 증거이며 사람 승률·재미 확정은 아니다. 다음은 전이·소이/제어·직접 화력 빌드의 코어/파츠 선택과 실제 플레이의 호흡이다.

## 검증과 다음 판단

[기능·실제 화면·전체 등반·회귀·한계](../qa/reports/playtest_rework_2026-11-03.md)를 기준으로 관리한다. 자동 탐색은 숨은 난수를 보므로 합법 완료 가능성의 근거이며 사람의 승률이나 조작감 판정이 아니다.

다음 사람 플레이에서는 드래그 끝점/발사 표시의 신뢰성, 경로별 전투·정비 리듬, 전이 확장을 고를 이유, 소이+경직의 사용 이유, 후반 냉각/비상 보급의 부담을 확인한다. 리액터의 긴 전투·실기기 터치/발열·다른 복장/여러 시드의 전체 경제는 계속 확인할 대상이다. 신규 규칙 전체를 사용자가 재미 검증 완료한 것으로 기록하지 않는다.
