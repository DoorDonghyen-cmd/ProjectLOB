# 적 이동과 위협 표시

**현행 교정 — 2026-10-29:** 사용자 승인으로 **배경 유지·공통 바닥선의 일렬 배치 복원**을 적용했다. 독립 가로 거리 계산·위협/상세는 유지하고 주 화면의 보스 이동량 숫자도 제거했다. 같은 거리의 과도한 가림은 겹친 적 수, 표적/포커스 우선 그리기와 분리된 HP 상세로 보완한다. [원인·장기 비용 판단](../history/design/enemy-grounding-review-2026-10-29.md) · [구현·검증·실제 화면](../qa/reports/enemy_grounding_2026-10-29.md). 기능과 대표 화면은 확인했으며 사람의 식별·위험 이해도와 모바일 실기기 확인은 남는다.

2026-10-28 적용 후 10월29일 교정. [통합 우선순위](playtest-priorities.md)의 4번 작업이다. 일렬 복원·거리 숫자 축소·안정적인 이동·몸체 일부 겹침은 사용자 피드백이며, 아래 세부 표시 방식은 그 범위에서 적용한 디렉터안이다.

- 몸체의 가로 기준점은 해당 적의 실제 거리와 화면 폭으로 정한다. 이웃의 크기·거리·처치·증원 때문에 밀어내지 않는다. 32m 밖은 먼 영역만 압축해, 밀려난 적도 같은 지점에 고정되지 않게 한다.
- 모든 적의 발을 주인공과 같은 바닥선에 놓는다. 개체별 전열 값은 기본 그리기 순서에만 쓰며 자동 표적, 포커스한 적 순으로 앞에 보여 준다. 새 다중 레인 전투 규칙은 없다.
- 몸체 겹침은 허용하되 HP·상태·행동 경고와 상세 버튼은 분리한다. 몸체 선택 사각형의 가로 겹침이 작은 쪽 폭의70% 이상인 연결 그룹에는 `적 N기 겹침`을 표시한다. 이 기준은 표시용 디렉터값이며 전투 판정이 아니다. 동일 거리·동일 외형은 여전히 한 몸체처럼 보일 수 있어 사람 테스트에서 식별성을 확인한다.
- 분리된 HP와 몸체는 연결선으로 대응한다. HP에 포커스하거나 가리키면 연결선과 해당 몸체를 강조한다. 식별 문자 A–D는 다시 도입하지 않는다. 몸체를 직접 누르면 화면 앞쪽 적을, 분리된 HP를 누르면 그 적을 연다.
- 발밑의 상시 거리 숫자와 보스 예고/접근 연출의 이동량 숫자는 주 화면에서 제거한다. 정확한 거리·기본 속도·특수 이동량은 터치 상세·도움말에 남기며, 실제 다음 접근량을 별도로 구분한다. 탄환 카드의 밀기 효과처럼 선택 결과를 비교하는 수치는 유지한다.
- HP 아래의 `다음 접촉!`, `다음 발사`, `다음 돌진`, `다음 전진 지시` 등은 **플레이어가 개입하지 않았을 때 다음 적 행동 1회**의 조건부 안내다. 실제 전투 모델의 분리된 복사 상태에서 한 번 계산하며 화상 선처치, 차단, 호위 당기기, 지휘, 축압, 도약, 회복, 기존 압력탄을 반영한다. 단순 거리÷속도를 보편적인 남은 턴으로 표시하지 않는다.
- 재장전·비상 보급·과열은 여러 적 행동을 진행할 수 있다. 해당 버튼과 기존 사격 예측의 위험 안내를 함께 사용한다. 연출 중에는 이전 상태의 `다음` 경고를 숨기고, 실제 결과 동기화 후 갱신한다.
- HP·경고·표적 강조·압력탄·피해 숫자는 몸체보다 위에 표시한다. 근접한 압력탄에는 `다음 적 행동 도달!`을 강조하며, 본체 사망 후에도 실제 탄이 남으면 표시한다.

전투 수치·표적 계산·저장 버전·적 편성은 변경하지 않았다. 전체 등반 기록은 경고 계산에 복사하지 않으며 계산을 매 프레임 반복하지 않는다. [10월28일 최초 적용·성능·한계](../qa/reports/enemy_readability_2026-10-28.md)와 [10월29일 접지·거리 표시 교정](../qa/reports/enemy_grounding_2026-10-29.md)을 구분한다.
