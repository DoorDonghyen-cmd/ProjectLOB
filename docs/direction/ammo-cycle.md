# 탄환의 개별 카드화와 덱 순환

2026-10-09. 사용자 승인: 기본탄도 덱에서 뽑는 개별 카드로 만든다. 철갑탄 등 일반 탄환은 해당 런의 덱에 유지하고, 사용하면 버린 더미로 보내 다시 순환한다. 영구 소모나 전투당 소진 탄종을 이번 변경에 추가하지 않는다.

## 적용 규칙

- 새 등반: 시작 덱 총10장 중 기본탄3장 + 무기/시작 보급별 전술탄7장. 기존 시작 덱 앞7장에 기본탄3장을 편성한 **디렉터 첫 테스트값**이다. 무기 수치·기본탄 피해/발열은 유지한다.
- 기본탄도 복장 가방의 후보 수에 포함한다. 작업복5/운반6/정찰4로 시작하고 획득 성장 최대10. 탄창 크기와는 독립적이다.
- 전투 시작에 덱을 섞어 가방만큼 뽑는다. 카드1장으로1발 장전한다. 탄창을 덜 채운 채 확정·사격할 수 있다. LIFO 유지.
- 발사한 탄은 버린 더미로 이동. 재장전 때 남은 패·미발사 탄도 버리고, 남은 뽑을 더미부터 새 패를 채운다. 뽑을 더미가 비어야 버린 더미를 섞는다. 매 턴 탄을 생성하지 않는다.
- 기본탄도 패 교환·예약탄의 다음 패 예약·덱 제거 대상이다. 예약/교환은 소유 카드를 이동하며 복제하지 않는다. 기본탄은 이번에 새 압축 계열을 추가하지 않는다.
- 편집 중에도 `패 재장전 N턴`으로 사격 없이 새 패를 뽑는다. 적 행동과 냉각은 일반 재장전과 동일. 임시 압축은 원본2장으로 돌아가지만 소비한 압축 기회는 환급하지 않는다.
- 확장 탄창: 탄창+1칸. 예비 급탄기: 교환+1회. 새 규칙에서 별도 기본탄 보급은 없다. 기본탄 기본 피해2/열1, 보행자 기본탄 보너스+1은 유지한다.
- 훈련도 실제 카드 사용: 처음 증폭2장+기본3장. 이후 기존 단계별 탄환 획득을 유지한다.

## UI와 저장

기본탄을 고정 수량 카드 대신 실제 소지 수만큼 개별 카드로 표시한다. 새 모드는6장씩 페이지를 나누며 가방10장일 때6+4장. 기본탄이 패에 없으면 표시하지 않는다. 시작 덱 미리보기, 교환, 상세, 기본탄의 낮은 발열 설명과 파츠 설명을 연결한다.

새 모델 저장에 `ammo_cycle: 1`. 마커 없는 진행 중 저장은 기존 별도 공급·장전 규칙을 유지하며 새 등반부터 전환한다. 저장 검증은 기본탄까지 손패/뽑을 더미/버린 더미/탄창의 소유 총량을 확인한다. 새 모드에서 별도 보급이나 기본탄 복제를 허용하지 않는다. 기존 저장을 자동 변환하거나 사용자 저장 파일을 덮어쓰지 않는다.

## 검증과 후속

[기능·시각 검증](../qa/reports/ammo_cycle_2026-10-09.md). 모든 총기의 초반 전투 도달성 표본은 자동 탐색으로 확인했지만 승률·사람 이해도 증거는 아니다. 기본탄3장 비율, 큰 탄창에서의 패 부족, 보행자 우위, 덱 축소/가방10장의 반복성은 사용자 플레이 후 조정한다. 복장 획득 경로(히든 노드/업적)는 아직 미확정이다.

## 후속 적용 — 탄환 가방 열람

사용자 요청으로 전투 `탄환 가방` 버튼을 추가했다. 전체 보유·손패·장전·뽑을 탄·버린 탄을 분리하며 카드와 수량으로 표시한다. 장전 예정 탄은 손패 수에서 제외, 임시 압축의 원본/실물 수 차이 안내, 뽑을 더미는 종류별 표시로 추첨 순서를 숨긴다. 열람은 턴/패/RNG를 변경하지 않는다. 탭·설명·닫기를 고정하고 뒤로 가기와 포커스 복귀를 지원한다. [검증](../qa/reports/ammo_bag_2026-10-09.md).
