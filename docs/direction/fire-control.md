# 본편 사격 범위와 열 관리

**후속 적용(2026-11-03):** [후기 개편](combat-roles-growth.md)의 드래그 경계/해제 좌표와 카드·버튼의 선택 최대 수 표시를 적용했다. 새 등반은 관문 발수 상한/기본 열 효율 투자도 사용한다. 아래 사격/열의 기본 역할과 이전 저장은 유지한다.

2026-11-03. 사용자가 후반/파츠/탄약 검증과 본편 통합을 지시했다. [격리 비교](fire-heat-comparison.md)를 본편 **새 등반**에 연결한다. 채택 수치와 냉각 보완은 디렉터 판단이며, 사람의 재미 검증 완료를 뜻하지 않는다.

## 적용 규칙

- 첫 탄부터 연속으로 끌어 이번 사격의 최대 발수를 정하고 사격 버튼으로 확정한다. 짧게 누르기는 기존 빼내기다. 메뉴 −/+도 같은 발수를 조절한다. 탄창 밖에 놓기·Esc·포커스 이탈·다중 터치는 드래그를 취소한다. 선택만으로 탄·턴·RNG를 쓰지 않는다.
- 총기별 발수 한계, 리액터 강행과 스파이크 처치 연속, 사격 뒤 적1행동, 과열 강제 냉각은 유지한다. 선택한 발수까지 도달하기 전에 조건에 따라 사격이 멈출 수 있다. 새 전투는 기본 발수로 시작한다.
- **탄창 교체:** 기존 비용(기본2행동, 실제 파츠 보정 유지), 미사용 탄을 예비로 보내고 새 탄창을 채운다. 열과 연속 공격 누적을 유지한다. 냉각 약실의 교체 냉각+4는 적용한다.
- **전용 냉각:** 적1행동, 잔탄 보존, 열0, 연속 공격 누적 초기화. 기존 비교의 무기별 부분 냉각보다 강화했다. 재장전에서 냉각을 제거한 뒤 별도 냉각을 반복하는 부담을 낮추고 의도적인 냉각의 이득을 분명히 한다. 열압 빌드는 고열 보너스를 잃는 대가가 있다.
- 냉각탄/열방출탄·파츠 자체 효과, 적 편성·HP·지도·보상·출발 덱은 이번에 바꾸지 않는다. 고열 위력80%·확률 명중 저하는 채택하지 않는다.

## 근거와 호환

교체1행동안은 검토 후 제외했다. 기존 획득 상태125개에서 사격/빈 탄창 교체 반복 통과가99→107로 늘었다. 사용자 피드백인 생각 없이 사격하는 문제를 강화하기 때문이다. 교체2행동+전용 냉각 강화로5총기의 전체 등반 경로와 스플린터의 다른 시드를 확인했다. 스플린터 특정2구역 정예에서 기존 획득 경로로는 넓은 탐색도 해법을 찾지 못했으며, 경로/획득 선택에 따른 편차를 남은 균형 문제로 유지한다. [과정·실제 화면·검증](../qa/reports/fire_control_2026-11-03.md).

캠페인/전투에 `fire_control_version=1`을 함께 기록하고, 공통 규칙 필드는 기존 `fire_heat_trial` 형식을 재사용한다. 본편에서는 range/none/피해 감소 꺼짐만 허용하고 선택 발수만 저장한다. 누락된 이전 저장은 자동 전환하지 않는다. 비교판은 기존 조건을 유지한다. 장비·총기 상세·파츠 교체 수치도 해당 모드의 실제 규칙을 표시한다.

## 덱 빌딩에 대한 현재 판단

사용자의 "그냥 별 생각없이 사격을 해도 진행이 돼"는 [독립 전투 재생에서도 확인](../history/design/deckbuilding-review-2026-11-03.md)됐다. 이번 입력·열 관리 연결은 선택 수단을 제공한 것이며 이 문제를 해결한 것으로 보지 않는다. 다음 우선순위는 **획득한 조합에 따라 대응이 달라지는 전투 편성, 핵심 탄의 집중 확보, 자동 성장과 능동 선택의 보상 배분**이다. 단순 HP 상향이나 조작 사용률을 목표로 삼지 않는다.
