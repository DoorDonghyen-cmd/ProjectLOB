# 아트와 UX — 도트 아트와 탄환 조합

2026-10-03 · 전체 도트풍과 참고작은 사용자 확정. 세계관과 사용자 제공 레퍼런스 검토를 마쳤으며 다음은 배우·환경의 통합 시안이다. 현재 게임 자산은 임시 상태이며 아래 제작 방식은 실제 화면 검증으로 조정한다.

## 확정 방향과 참고작

최신 전투 샘플: 추가 후보 비교 후 C의 긴 외투+B의 방한모 조합을 선택했다. 제작한 주거구 배경·기존 탄환 카드와 [실제 Godot 샘플](../qa/reports/tower_art_sample_2026-10-03.md)을 만들었다. 4개 비율·실제 확정/발사 검수 완료. 적은 기존 임시 자산이고 정식 캠페인 교체/배우 애니메이션은 후속이다. 아래 초기 헬멧 채택은 이전 결정 이력으로 읽는다.

2026-10-03 최신 사용자 결정: **탄환 카드 디자인을 유지하고, 새 도트풍과 정비용 헬멧 주인공을 채택한다.** 기존 게임 안의 캐릭터·적·배경은 임시 자산이며 [새 시작 외형](../art/concepts/2026-10-03-pixel-reference/character-reference-v2-helmet.png)으로 교체할 제작 기준이 마련됐다. 추후 복장·헬멧 획득/교체를 위해 [분리 제작과 후속 흐름](appearance.md)을 따른다. 컨셉 채택을 실제 게임 적용 완료로 취급하지 않는다.

배우·환경 아트의 재개 선행 작업: (1) 플레이어의 정체·목적·적대 관계 등 세계관 핵심 정리, (2) 캐릭터 비율/복장·적 형태·공간/색감별 레퍼런스 수집과 비교, (3) 캐릭터·적·배경을 함께 배치한 소수의 통합 시안 비교. 산업도시·기계형 적은 디렉터의 임시 해석이며 사용자 확정 세계관으로 취급하지 않는다.

현재 [세계관 기준](worldbuilding.md) v0.3의 큰 방향을 사용자가 채택했다. 정서는 **위험한 탐험 + 사람 사는 온기 + 은근한 디스토피아적 어두움**이다. 풀려난 생물과 상점별 생존자의 생활 흔적을 아트에 연결한다. 주전자 옆의 배급 중단 통지, 판매대 뒤의 임시 잠자리처럼 온기와 결핍을 한 공간에서 보여 주는 안을 제안한다. 개별 인물·공간·엔딩 연출은 제작안이다. 사용자 제공 캐릭터/배경 10장으로 [레퍼런스 보드](../art/references/2026-10-03-user/reference-board.html)를 구성하고 [도트 제작 방향](pixel-style.md)을 재정립했다. 새 배우·배경의 통합 시안은 아직 제작하지 않았고 기존 게임 자산은 여전히 임시 적용이다.

간접 서사는 아이템·쪽지·환경 흔적으로 전달한다. 탄환/파츠 카드에는 기능 정보가 먼저 보이고 상세의 `물건의 흔적`을 선택해 읽는 안을 사용한다. 기록은 획득 때 전투를 막지 않고 보관함에서 다시 읽게 한다. 인물 대사는 거래 진입을 막지 않는다. [노출 위치와 원고 기준](narrative-delivery.md)은 설계 상태이며 현재 UI에 이미 적용된 동작으로 취급하지 않는다.

메인·무기 선택·지도·전투·보상·상점·장비·결과까지 일관된 도트 아트풍을 사용한다. 캐릭터만 도트로 교체하거나 기존 고해상도 일러스트에 픽셀 필터를 씌운 상태를 완성으로 취급하지 않는다.

- [산나비](https://store.steampowered.com/app/1562700/SANABI/): 산업도시 분위기, 전경 발판과 원경의 명암 분리, 캐릭터의 접지와 실루엣을 참고한다.
- [ARCANE TRIGGER](https://store.steampowered.com/app/2981070/Arcane_Trigger/): 전장과 조합 도구가 함께 보이는 화면, 식별 가능한 큰 아이콘, 도트 프레임·숫자의 일관성을 참고한다.
- 두 참고작의 화면 검토에서 선택한 원칙이며 전체 레이아웃·세계관·전투 규칙의 복제를 뜻하지 않는다. 우리 게임의 순서 계산·무기·파츠·압축과 모바일 터치 흐름에 맞춘다.
- 앞선 세밀한 일러스트와 평면 기호 적의 혼합은 현재 목표가 아니다. 기존 자산은 보존하되 최종 적용 자산과 구별한다.

## 사용자 레퍼런스 이후의 우선 기준

사용자는 가장 가까운 전반적 느낌으로 **산나비**를 지정했고 **배경의 강한 디스토피아적 분위기**를 요청했다. 최신 배우·환경 제작 기준은 [10개 이미지 검토와 도트 방향](pixel-style.md)이다. 캐릭터는 성인 비율·큰 색면·무기/장비의 비대칭, 배경은 거대 건축·차가운 명암층·수직 공간의 압박을 중심으로 설계한다. 생활의 온기는 작은 조명과 사람의 흔적에 둔다.

배경03·04는 분위기/구도, 배경02·05는 도트 면 처리/깊이의 주 참고로 구분한다. 세로 레퍼런스를 가로 전투에 맞는 원경·중경·전투면·전경으로 새로 구성한다. 현재 탄환 카드는 승인된 정보 위계를 유지하며 통합 시안에서 배우·환경과 함께 검토한다. 아래 기존 렌더 수치와 팔레트는 현재 구현 상태이며 새로운 레퍼런스보다 우선하는 영구 규격이 아니다.

## 시각 언어

캐릭터·적·바닥·배경·아이콘·버튼에 공통 픽셀 밀도와 명암 단계를 적용한다. UI는 도트 금속 프레임, 명확한 모서리와 눌림 상태, 제한된 강조색으로 구성한다. 원경의 세부와 대비는 전투 대상보다 약하게 유지한다. 스캔라인·격자·발광 테두리를 모든 영역에 반복하지 않는다.

- 바탕 `#101820`, 패널 `#1a2833`, 밝은 글자 `#f2eee3`, 보조 글자 `#acbbc1`.
- 행동·선택 `#edc47a`, 위험 `#ee8777`, 전기 `#78c9ed`, 화염 `#ef9967`.
- 상태는 색 외에 형태·문구·위치로 구별한다. 전기와 압축, 선택과 피해 예측이 같은 의미처럼 보이지 않게 한다.
- 제목·수치·버튼은 판독 가능한 픽셀 글꼴을 우선 검토한다. 한글 설명은 충분한 글자 크기·자간·대비를 먼저 확보한다. 필요할 때 선명한 한글 본문 글꼴을 함께 비교하며, 낮은 해상도로 모든 텍스트를 일괄 축소하지 않는다. 현행 Noto Sans KR은 전환 중 유지 자산이며 최종 글꼴 확정은 아니다.
- 버튼은 '전/규/설/메'로 줄이지 않는다. 작은 보조 기능은 메뉴로 합치거나 이해되는 짧은 이름을 쓴다.

## 공간과 픽셀 기준

- 실제 전투 바닥을 원경 이미지와 분리해 구성한다. 배경의 화면 채우기 크롭에 따라 배우의 발이 바닥에서 떨어져 보이지 않아야 한다.
- 발 위치를 배치 기준으로 삼고 접지 그림자·캐릭터 크기·시점·광원을 맞춘다. 부유형 적은 지면 그림자와 부유 동작으로 의도를 전달한다.
- 접근 거리는 가로 위치와 연결한다. 다수 적의 얕은 깊이 배치는 식별을 위한 표현이며 새로운 다중 레인 규칙이 아니다. 증원·이동 때 기존 적의 전열을 재정렬하지 않는다.
- 캐릭터와 적은 동일한 픽셀 밀도·외곽선·명암으로 제작한다. 탄환과 파츠도 같은 계열의 픽셀 물건으로 읽혀야 한다.
- 월드의 기준 해상도와 UI의 읽기 크기를 구분해 검토한다. 텍스처 보간·정수 배율·좌표 정렬은 실제 출력에서 흐림과 픽셀 두께 변동이 없도록 설정한다. 특정 해상도를 영구 규칙으로 확정하지 않는다. [Godot 다중 해상도 기준](https://docs.godotengine.org/en/stable/tutorials/rendering/multiple_resolutions.html)

## 전투 와이어프레임

```text
층/무기/현재 턴                                      전투 정보 · 메뉴
┌──────────────────────────────────────────────────────────────┐
│                        전장                                  │
│ 회수자  ← 접근 거리 / 고정 전열 / 적의 HP·장갑·핵심 상태       │
│             선택한 탄창의 피해 변화와 처치 표시                 │
└──────────────────────────────────────────────────────────────┘
발사 순서  [1 탄] → [2 탄] → [3 탄] → [4 탄]    [확정 / 발사]
예상 결과                                       [회수/재장전]
손패      [회수탄] [전술탄] [전술탄] [전술탄] [전술탄] [전술탄]
예비 탄환 / 압축과 교환 도구        선택 상세는 별도 창
```

이 와이어프레임은 동선 기준이며 현재 패널 높이를 고정하지 않는다. 전장·발사 순서·손패가 전체 폭을 공유한다. 빈 장전 레일의 높이를 줄이고 손패 6장의 그림·수치와 전장의 바닥에 공간을 배분한다. 낮은 높이에서는 정보의 노출 단계를 바꾸며 모든 글자를 함께 줄이지 않는다. 비정상적으로 좁은 창은 필요한 곳의 스크롤을 허용한다.

## 정보 공개

적: 큰 HP와 장갑, 접근 시간/거리, 전술적으로 중요한 상태. 이동량·정확한 조건은 상세로 이어진다.

탄환: 큰 물건 실루엣과 이름 → 직접 피해·관통 → 고유 효과 한 줄. 피해를 명중처럼 보이는 조준점으로 표현하지 않는다. 고유 효과는 `매 턴 1 · 3턴`, `다음 2발 +2`처럼 짧은 문구와 수치를 결합한다. 이는 표기 예시이며 수치 원본을 바꾸는 지시가 아니다. `2×2`와 `×2` 같은 타격 횟수의 중복을 없앤다. 장전 결과는 선택한 탄·적의 변화·레일에 연결하고 모든 카드에 작은 결과 문장을 반복하지 않는다.

파츠: 실루엣과 이름, 핵심 이득, 대가. 장착 전후 비교는 선택한 한 부품에 집중한다.

각 화면의 주 행동은 한 곳이다. 툴팁만 있어야 이해되는 기능은 터치 상세도 제공한다. 선택·잠금·부족·위험·사용 완료 상태를 구분한다.

현재 조작 기준: 전장의 기본 예측은 다음 발사 1회이며 여러 턴에 걸친 전체 탄창 결과는 범위를 명시해 전환한다. 장전한 탄은 손패의 같은 자리에 사용 상태로 남긴다. 슬롯 탭은 선택, 이동·회수는 명시적 행동이며 확정 전 순서 이동은 드래그도 지원한다. 계산 상세로 전체 화면의 높이를 늘리지 않는다. 장전 확정의 변경 비용은 버튼 곁에 노출한다. 파츠 교체는 얻는 규칙과 잃는 규칙, 새 대가와 해제되는 대가를 함께 비교한다. ## 제작 방식

### 현재 비전투 UI

- 메인: 왼쪽은 게임 이름과 실제 탄환 카드 조합, 오른쪽은 이어하기/새 등반과 훈련. 미확정 캐릭터 원화를 화면의 주인공으로 고정하지 않는다. 기록·규칙·설정은 보조 영역으로 분리한다.
- 출격 준비: 다섯 무기 전체 카드가 선택 영역이다. 선택한 무기의 고유 규칙·탄창·재장전과 실제 무기별 시작 보급을 보여 준다. 시작 탄환은 전체 영역을 눌러 효과를 확인한다. 난도 입력과 시드는 등반 설정에 접으며 현재 난도와 출격 버튼은 기본 화면에 남긴다.
- 상점: 세 상품과 고정 비교 영역을 나란히 배치한다. 상품은 선택과 가격/재고 표시, 비교 영역은 구매를 담당한다. 선택해도 높이와 스크롤이 갑자기 바뀌지 않는다. 파츠 카드에 이득·대가를 보여 주고 비교 영역에서 장착/보관 위치와 구매 결과를 확인한다.
- 파츠: 장착 5칸·보관함·선택 상세를 함께 보여 준다. 보관함만 내부 스크롤하며 끝의 파츠도 선택 가능하다. 슬롯이나 코어 제한에 걸리면 유효한 교체 후보를 고르고, 탄창·재장전 변화 확인 후 한 번에 교체한다. 전투 중에는 열람만 가능하며 분해에는 게임 안의 확인 절차가 있다.
- 파츠 실루엣은 엔진 픽셀 도형으로 구별하며 승인된 탄환 카드와 각진 프레임을 공유한다. 탄환 카드 디자인과 배우·환경 자산은 이번 범위에서 변경하지 않았다.

[실제 화면과 검사](../qa/reports/navigation_ui_2026-10-03.md). 화면·입력 검사를 사람의 이해도 확정으로 해석하지 않는다.

먼저 첫 지역의 통합 전투 화면을 제작한다. 적 4마리, 손패 6장, 발사 순서, HUD를 함께 검토해 공통 팔레트·픽셀 밀도·시점·그림 크기를 정하고 나머지 화면으로 확장한다. 에셋 단독 미리보기로 화풍의 통일을 판정하지 않는다.

생성 도구는 컨셉과 스프라이트 후보 제작에 활용한다. 생성 결과는 픽셀 밀도·팔레트·투명 경계·발 기준점·프레임 일관성을 검수한다. 활자·수치·슬롯·버튼의 동작은 엔진에서 구성한다. 코드로 그리는 공통 아이콘도 최종 출력의 도트 규칙을 따른다. 적은 장갑판·충전 코어·다리·흡수 셀처럼 역할을 전달하는 형태를 가진다. 원본을 지우지 않고 교체 자산은 새 이름으로 저장한다.

[자산 목록](art-assets.md)에 파일·용도·도구·프롬프트·적용 상태를 남긴다. 원화 완성과 스프라이트/애니메이션 적용을 구분한다.

## 통과 기준

### 2026-10-03 첫 통합 화면의 구현

- 새 자산은 `assets/art/pixel_20261003/`에 저장했다. 원본 80×80 회수자, 64×64 적, 512×192 배경을 다시 그리거나 리샘플링하지 않고 투명 여백만 잘랐다. 팔레트는 자산별 18~63색, 스프라이트 알파는 0/255다. 실제 발의 아래쪽 픽셀에서 기준점을 계산하고 `.tres`로 보존했다.
- 월드 텍스처는 nearest, 배우는 원본의 2배로 그린다. 바닥은 배경 크롭과 무관한 별도 픽셀 금속판이다. 부유형은 바닥 그림자와 18px 높이 차로 구별한다. 화면 전체의 한글은 읽기 크기를 유지하며 Noto Sans KR을 계속 사용한다.
- 같은 거리에 모인 네 적을 구분하기 위해 고정 전열별 가로 간격 96px와 얕은 깊이 12px를 둔다. 거리 감소는 각 적을 왼쪽으로 이동시키며 정확한 거리는 명찰로 표시한다. 이는 배치 오프셋이며 실제 표적·거리 계산이나 다중 레인 규칙을 추가하지 않는다. 사망·증원으로 생존 적을 재정렬하지 않는다.
- 명찰은 적의 가로 위치에 따라 배치하고 이웃끼리 겹치지 않도록 밀어낸다. HP/예상 HP·거리/접근·장갑/상태를 구분한다. 산개의 HP는 범위로 표시한다. 터치 상세를 유지한다.
- 손패는 큰 탄종 실루엣·피해·유효 관통·효과 한 줄이다. 모든 카드의 결과 문장을 없애고 예측을 발사 순서와 전장에 모았다. 연발의 배수 중복을 없앴다. 압축의 두 칸/첫 발/끝 발 표시는 유지한다.
- 현재 전투 전체는 첫 공업 지대 배경을 공유한다. 지역별 도트 환경, 지도와 배우 최종 아트, 전용 보행/대기 프레임은 아직 후속 제작이다. 메인·무기 선택·상점·파츠의 후속 UI 개편은 위의 현재 비전투 UI 항목에 반영했다. 전체 아트 완료 상태는 아니다.
- 실제 렌더 1280×800, 1008×630, 1440×630에서 기본/장전/발사와 네 적 밀집을 검토했다. 자세한 증거와 한계는 [작업 기록](../history/daily/2026-10-03.md)에 남긴다.

- 실제 렌더에서 적·탄환·주 행동의 시선 순서가 구분된다.
- 캐릭터·적이 같은 바닥과 공간에 속해 보이며 증원·이동·피격 전후에도 발 위치와 그림자가 어긋나지 않는다.
- 모든 화면에서 픽셀 밀도·외곽선·프레임·아이콘의 제작 규칙이 일관된다. 화면 전체의 픽셀 필터를 검수의 대체물로 사용하지 않는다.
- 1280×800, 1008×630과 갤럭시형 긴 가로 비율에서 핵심 조작과 정보가 겹치지 않는다.
- 위험·파츠 패널티·압축 비용을 작은 기호만 보고 추측할 필요가 없다.
- 손패 6개, 탄창 최대, 장갑/화상/배리어/증원, 산개 확률을 확인한다.
- 기능 자동 검사, 시각 검토, 실제 사람의 이해도는 각각 기록한다.
