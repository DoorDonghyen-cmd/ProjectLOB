## 실행과 결정 상태

`OPEN_MAGAZINE_COMPARISON.cmd`에서 5총기 × 첫 교전·장갑 진지·첫 관문을 플레이한다. 시드731042의 현행 덱 빌딩 버전2로 실제 획득한 진입 상태15개를 사용한다. 조건 변경은 같은 전투 처음부터, 총기/전투 변경은 각 진입 상태부터 시작한다. 출처와 해시는 `redesign/samples/fire_heat/openings.json`에 있다.

본편 `PLAY.cmd`의 새 등반/기존 저장에는 실험을 켜지 않는다. 비교 저장은 격리된 실행 폴더의 `fire_heat_comparison_v1.json`이며 본편이나 이전 비교 저장을 덮지 않는다. [기능·실제 화면·선택 비교](../qa/reports/fire_heat_comparison_2026-11-02.md).

## 비교할 세 가지

| 항목 | 조건 | 이번 기본값과 이유 |
| --- | --- | --- |
| 사격 | 기존 고정 묶음 / 앞줄 연속 범위 | 범위 선택. 즉사 전투에서 과열 직전 멈출 선택을 제공하고, 기존 빼내기와 공존 가능한지 확인 |
| 탄창 교체 | 기존 냉각 / 열 유지 / 열 −2 | 열 유지. 교체는 탄약 갱신, 냉각은 열 관리라는 구분을 먼저 확인 |
| 고열 성능 | 기존 유지 / 위력80% | 기존 유지. 교체 변경과 분리해서 평가하고 열압 빌드의 보상을 무조건 약화하지 않음 |

**입력:** 첫 탄을 누른 채 오른쪽으로 끌어 앞에서부터 몇 발 쓸지 정하고, 놓은 뒤 사격 버튼으로 확정한다. 짧게 누르기는 기존 선택→빼내기다. 탄창 밖에 놓기·Esc·포커스 이탈·두 번째 손가락은 드래그를 취소한다. 가장자리를 누르고 있으면 탄창이 스크롤된다. 메뉴의 −/+도 같은 범위를 조절한다. 선택만으로 턴·탄·RNG를 소비하지 않는다.

**발수와 비용:** 리벳 최대2, 래칫/스플린터 최대3, 리액터 기본3에 실제 과열 강행 조건일 때만4번째, 스파이크는 실제 처치 연속 조건 안에서 선택한 발수까지다. 범위는 최대치이며 과열·처치 조건·탄 소진으로 더 일찍 멈출 수 있다. 짧게 쏴도 전투가 계속되면 적1행동, 과열 냉각 비용은 추가된다. 발수를 줄여 무료로 시간을 나누지는 않는다.

**열 관리:** 열 유지/−2 교체는 연속 공격 누적을 끊지 않는다. 냉각은 적1행동·잔탄 보존·기존 총기별 냉각량·연속 누적 초기화를 유지한다. 냉각 약실의 교체 냉각+4는 두 실험에서도 더한다. 냉각탄/열방출·강제 냉각·종료 상태 정리는 기존 규칙을 따른다.

**80% 후보:** 발사 직전 열이 한계의75%(올림) 이상이면 기존 배율을 적용한 장갑 차감 전 위력을0.8배(버림, 양수는 최소1)로 계산한다. 그 위력에서 파생되는 충격파에도 반영하며 화상 틱은 바꾸지 않는다. 실제 HP 피해가 언제나 정확히20% 줄어드는 규칙은 아니다. 장갑과 정수 반올림으로 저위력탄의 손실률이 커질 수 있다. 명중률·확률 고장은 추가하지 않았다.

## 다음 판단과 본편 연결 조건

사격 범위와 열 유지안을 우선 플레이하고, 메뉴의 기준 조건 복귀와 열−2를 같은 전투에서 비교한다. **더 쏘기/여기서 멈추기, 냉각/탄창 교체를 고른 이유가 서로 달라지는지**, 드래그가 빼내기와 혼동되는지, 긴장감보다 조작 피로가 커지는지를 확인한다. 무조건 짧게 쏘거나 냉각만 반복하는 구조는 목표가 아니다.

5총기15진입 상태의 경로 존재와 기능 검증은 완료했다. 제한 탐색은 최적 플레이·사람 승률의 증거가 아니다. 사람 피드백 후 조건을 좁히고 다른 획득 순서/후반·탄약 경제·열압/냉각 파츠와 Android 실제 터치를 확인해 본편 적용을 판단한다. 누르고 있기 연발·파츠별 전탄 사격은 이번 비교에 함께 넣지 않는다. 지도 전투 밀도와 전체 등반 균형은 이 결정 뒤 이어간다.
