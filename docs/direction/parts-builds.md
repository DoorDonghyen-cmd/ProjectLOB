# 파츠 역할과 탄환 빌드

**현재 새 도전 보정(2026-11-06):** `balance_version=1`은 [전투 밸런스1차](combat-balance-pass.md)를 사용한다. 열압의 지속 피해 성장과 노심의 성장 계승은3회당 +1, 코일의 지역 불길은 +1, 노심의 지역 불길은3적 행동이다. 직접 코어 배율·성장과 노심의 고유 +2/기간·범위/교체 기록은 유지한다. 아래2회당 계승·4행동/+2 불길 규칙은 표식 없는 기존 저장의 규칙이다. [실제 획득·5총기·470전투/표시·저장 검증](../qa/reports/combat_balance_2026-11-06/README.md). 디렉터1차값이며 최종 균형·사람 체감 확인은 남는다.

**현행 — 성장 후 코어 교체 보완(2026-11-04):** 사용자 다음 작업 실행 승인에 따라 실제 보유 코어/모듈의 유지·교체를 비교했다. 새 등반 `specialist_core_version=1`에서 열폭주 노심은 기존 화상 +2에 **열압 구동핵의 누적 성장 2회당 +1**을 더한다. 열압 직접 배율/충격파를 이어받지 않고, 노심 장착 중에는 열압이 추가 성장하지 않는다. 재장전 +1행동과 코어1개 제한은 유지한다. 성장 기록은 계속 보존되어 원래 코어로 돌아갈 수 있다. 이전 저장에 표식이 없으면 기존 고정 +2를 그대로 사용한다. 이 규칙은 디렉터 보정값이며 사람 재미/최종 균형 확정은 아니다. [비교·실제 획득·표시·검증](../qa/reports/core_choice_2026-11-04.md).

- 질문: 성장한 코어를 계속 쓰기와 소이 전용 코어로 전환하기가 각각 유효한 선택인가?
- 근거: 실제 보유 관문에서 분기한 동일19전투 경로는 열압 유지314행동·비상0회, 기존 노심434행동·비상2회였다. 성장 기록의 화상 효과까지 잃는 문제가 확인됐다.
- 적용: 노심의 화상 성장만 계승하며 직접 화력/재장전의 차이는 남긴다. 같은 경로의 보정 노심은295행동·비상0회, 열압 대비8전투 빠름/2동일/9느림이었다. 이후 획득도 실제 선택으로 달라질 수 있으므로 순수 단일 효과 비교는 별도의 같은 상태20분기 검사를 따른다.
- 표시: 빌드 작업실은 현재 성장 배율·화상 피해 변화·관련 보유 탄 수·성장 기록 보존을 보여 준다. 상세의 첫/마지막 발·복열/증폭 등 이전 규칙 문구를 현재 `part_spec` 기준으로 정리했다. 카드 성장 상한도 관문 투자에 맞춘다.
- 유지/보류: 기존 성장3코어와 위치/제어 모듈의 수치는 유지했다. 소이 없는 연타 덱의 노심, 제어 탄이 적은 소이 덱의 피스톤을 강제 정답으로 만들지 않는다. 피스톤/분기 전이기의 전용 덱 장기 획득 비교와 다른4복장 경제는 후속이다.

**경제 후속(2026-11-03):** 새 등반 `economy_version=1`에서 현재 탄과 맞는 첫 추천 모듈을 등반당1회18Cr에 살 수 있다. 그 외 파츠 가격30Cr와 이전 저장은 유지한다. 관문의 수납/보유 탄 복제1회 선택도 [복장·탄약 경제](outfit-bag.md)에 연결했다. 아래 v3 적용 당시의 ‘가격 유지/다음 경제 검토’는 이 후속으로 갱신한다.

**현행 — 탄환 역할과 획득 선택 v3(2026-11-03):** 사용자가 승인한 다음 우선순위2를 새 등반 `combat_roles_version=3`에 적용했다. 기존 v1/v2 이어하기는 계산·획득을 유지한다. 아래 수치는 디렉터 구현값이며 사람 재미/최종 균형 확정과 구분한다. [실제 획득·비교·화면 검증](../qa/reports/build_roles_2026-11-03.md).

| 역할 | 현행 v3 효과와 비용 |
|---|---|
| 직접 화력 | 선두 ×2·제3 실제 탄 ×3·증폭된 마지막 단타 ×3과 성장형 3코어를 유지한다. 모든 파츠를 위치 배율로 통일하지 않는다. |
| 소이 전용 코어 `inferno` | 화상/불길 행동당 피해 +2, 착발 앞뒤 3m·4적 행동. 기존 표적 화상 기간 +2/불씨 이동 +2 유지. 재장전은 총기의 기본 최소 비용을 적용한 뒤 +1행동으로 실제 대가를 보장한다. 코일은 불길 피해 +2, 점화 약실은 화상 대상 직접 후속을 담당한다. |
| 제어 코어 `momentum` | 차단탄 접근 감속 +1행동: 일반3/압축4. 같은 적에게 전투당1회. 특수 행동 차단 기간은 별개. 밀기/한도 +2m, 직접 피해 −1 유지. |
| 후속 모듈 `rammer` | 감속이 남은 적의 직접 타격당 피해 +2. 차단 지원탄 자체·화상·기폭·전격 전이에 추가 피해 없음. 연쇄 코어의 잔여 타격은 새 표적을 재판정하며 돌파의 초과 피해는 원래 공격의 초과분을 전달한다. 기존 밀기/한도 +1m 유지. |
| 전이 모듈 `capacitor` | 전격 전이 피해 +1에 연쇄/돌파 처치 전이 대상 +1을 추가. 기존 코어 `arc_splitter`에 붙었던 동시 장착 불가능한 설명/확장 연결을 이 모듈로 옮겼다. 전격 분배 코어는 전격 전이 +2/대상+1, 직접 −1의 고유 역할이다. |

장착5칸/코어1개, 가격·등급·카드 수·UI 배치·적 편성은 그대로다. 소이 전용 코어와 성장형 열압 코어는 대체 관계이며 성장8의 열압을 무조건 교체할 이유로 제안하지 않는다.

상점과 정예 보상의 첫 파츠는 보유 주력 탄 계열을 보고 추천한다. 첫 구역 기본 진열의 대표는 소이→코일, 전격→축전기, 연타/철갑→제3 격발기, 열방출→연쇄 방열기다. 보유 차단탄은 충격 가이드, 장착 연쇄/돌파 코어는 축전기를 연관 후보로 추가한다. 두 번째는 가능한 다른 역할을 제안하며 미소유/미등장 우선·등급 추첨을 유지한다. 미등장 후보가 남으면 재진열에서 이미 본 대표 파츠를 강제 반복하지 않는다.

상점의 기존 탄환 한 칸은 주력 복사/강화/적게 보유한 연관 지원탄을 시드·노드·진열 횟수로 순환한다. 지원탄은 계열 수를 세므로 일반/고급을 별도 결핍으로 오인하지 않는다. 보유 탄 상태와 동일 입력이면 결과가 같다.

관문 전이 확장은 장착 연쇄/돌파 코어에, 성장 확장은 성장형3코어에만 제시한다. 기존 저장의 선택/투자 효과를 지우지 않는다. 실제 발동에는 불길·경직·후속 피해·처치 전이 확장 표시를 연결한다. 회수 탄·원래 발사 입력과 저장 형식은 유지한다.

획득 검사에서 첫 상점 30Cr로 12Cr 탄을 먼저 사면 30Cr 파츠를 놓칠 수 있었다. 자동 검사 정책의 선택 결과이므로 이번에 무료 보급/가격 인하로 덮지 않는다. 다음 우선순위3에서 복장 최소/최대·전투 밀도·상점 구매 여력을 함께 확인한다.

**앞선 역할 v1/v2 적용(2026-11-03):** [처치 전이/소이 역할·관문 운용 성장](combat-roles-growth.md)을 새 등반에 연결했다. 연쇄/돌파의 직접 화력은 유지하고 전이 대상은 기본 추가1기부터 투자한다. 기존 전격 분배·열폭주 노심·코일을 전이/불길 역할에도 연결한다. 새 위치 파츠는 유지하며 모든 파츠를 위치 조건으로 통일하지 않는다.

**현행 추가 — 위치 파츠와 주력 탄(2026-11-03):** `focus_build_version=1` 새 등반에서 선두 격발기 첫 발 ×2, 신규 모듈 제3 격발기 세 번째 실제 탄 ×3, 후미 점화기 실제 증폭된 마지막 단타 ×3을 적용했다. 지원탄도 순서에 포함하며 빼내기는 제외, 냉각/부분 사격은 유지, 교체는 초기화. 성장/증폭/연타·냉각·관통 파츠는 각 역할을 유지한다. [전체 조건·계산 순서·획득](focus-build.md) · [검증](../qa/reports/focus_build_2026-11-03.md). 아래 기존 규칙은 해당 이전 저장에 남는다. 전 파츠 일괄 교체나 사람 재미 확정은 아니다.

**현행 — 발동 체감1차(2026-10-28):** 실제 발동 결과를 사용해 연쇄/복열·돌파/후미·열압의 궤적과 적중 형태를 구별하고, 대표 발동·실제 사격 합계·발동 파츠를 사격 후에도 표시한다. 지원탄/차폐 실패를 피해 증가로 표시하지 않으며 파츠별 추가 HP를 역산하지 않는다. 기존 효과·수치는 유지했고162조건 전후 결과가 같다. [화면·기능·성능 한계](../qa/reports/build_feedback_2026-10-28.md). 사람의 체감은 후속이다.

**현행 — 조합 의존도 개편(2026-10-27):** 사용자가 승인한 플레이 피드백 순차 개편의 두 번째 단계. 새 캠페인 `combat_revision=1`에서 시퀀서 증폭 추가 +3, 복열 연타 +2/연타 열 +1, 후미는 강화된 마지막 단타 직접 피해 ×2(뒤의 지원탄 허용, 재장전 +1턴 유지). 기존 저장은 종전 효과. 코어 성장 일부를 모듈·탄환 조합으로 옮기는 디렉터 1차 수치이며 성장식은 [화력 성장](damage-growth.md), 조건·실험·한계는 [검증 보고서](../qa/reports/build_revision_2026-10-27.md)를 따른다. 아래 옛 개별 수치는 기존 규칙 설명으로 남긴다. 장착5칸/코어1개는 이 단계에서 유지.

**현행 확장(2026-10-16):** [화력 성장](damage-growth.md)에 따라 성장 코어3종을 추가해 수집31종이다. 파츠는 이번 사격의 보정뿐 아니라 런 동안의 화력 성장 방향도 결정한다. 기존5칸/코어1개 제한을 유지한다. 아래28종 개편 기록은 이전 단계다.

**후속 적용:** [파츠 등급](part-grades.md)에 따라 일반8/고급13/희귀7로 분류했다. 아래 ‘등급을 추가하지 않는다’는 문장은 이전 역할 개편 당시 범위다. 코어 장착 제한과 효과는 유지하며 획득과 카드 표식에만 등급을 연결한다. 도트 그림은 사용자 긍정 평가를 받은28종 리터치를 사용한다.

## 역할 기준

총기는 기본 전투 방식, 탄환은 이번 사격의 행동, 압축은 특정 탄에 투자하는 성장이다. 파츠는 특정 조합을 반복해서 활용할 이유를 만든다. 파츠를 얻은 뒤 어떤 탄을 모으고 어떤 순서로 쓰며 무엇을 압축할지가 달라져야 한다.

작은 수치 보강 파츠도 유지한다. 다만 모든 탄을 장갑 대응탄으로 만들거나 고급탄의 발열·공간·위치 대가를 전부 지우지 않는다. 강한 효과의 비용은 해당 운용과 연결한다. 모든 파츠에 일률적인 패널티를 추가하지 않는다.

장착5칸·코어 최대1개는 유지한다. 다음 역할은 필수 장착 칸이나 세트 보너스가 아니다. 상점에서 다른 역할을 제안할 때도 미등장·미소유 우선 규칙을 보존한다.

| 역할 | 파츠 | 플레이에서 만드는 선택 |
| --- | --- | --- |
| 조합 보상 | 가속 총열, 열축전 코일, 열폭주 노심, 점화 약실, 전이 축전기, 분기 전이기, 충격 가이드, 충격 피스톤, 증폭 시퀀서, 복열 노리쇠, 배리어 파쇄기, 처형 조준기 | 관통·화상·전이·타격·처치 준비를 연결 |
| 순서 보상 | 선두 격발기, 후미 점화기, 삼중 시퀀서, 교차 급탄기 | 첫/끝 발, 다른 탄종의 연결 |
| 발열 운용 | 확장 방열판, 회수 순환펌프, 잔열 노심, 연쇄 방열기 | 열 용량·처치·잔열·세 번째 발을 구분 |
| 패 순환 | 회수 가속기, 예비 급탄기, 예약 급탄기, 냉각 약실 | 재장전·교환·다음 패·짧은 탄창 순환 |
| 압축·탄창 | 확장 탄창, 야전 압축기, 과구경 총열, 압축 안정기 | 공간 확보·현장 압축·중량탄·선행 준비 |

각 파츠는 여러 탄종과 연결할 수 있고 두 가지 역할을 걸칠 수 있다. 표는 진열/설명용 주 역할이며 게임 계산은 콘텐츠와 실제 모델이 결정한다.

| 교차 급탄기(ordinary_chain), 신규 | 직전 발이 다른 일반 전술탄이면 이번 일반 공격탄 타격당 피해+2 | 일반탄을 남겨 서로 다른 종류를 연결. 기본탄·고급탄·기본 피해0 탄은 보너스 대상 아님 |
| 압축 안정기(compression_sink), 신규 | 일반 전술탄 직후의 영구/임시 압축탄 발생 열−2(최소0), 열 한계−1 | 압축탄 앞에 준비탄을 쓸 이유. 현재 잔열을 직접 냉각하지 않으며 점유/위치 제약 유지 |

일반은 grade0 전술탄이다. 기본탄은 별도 보급이며 고출력 증폭탄은 고급이므로 두 신규 파츠의 일반 선행 조건을 만족하지 않는다. 첫 발 고정 압축탄 앞에 일반탄을 끼워 넣을 수 없다. 열이 발생하지 않는 냉각/열방출 탄에 안정기로 추가 냉각을 만들지 않는다.

연계의 ‘직전’은 같은 탄창에서 실제 발사한 탄이다. 여러 번 방아쇠를 당기는 증강도 동일하며 저장/불러오기 후 이어진다. 재장전 후 새 탄창에는 이 조건이 이어지지 않는다. LIFO 장전·발사 규칙을 유지한다.

기존26종 전체를 다시 수치 변경한 것은 아니다. 역할이 이미 분명한 처치 냉각·화상 후속·예약·전이·순서 파츠는 유지했다. 새2종을 더해 수집28종이다. 일반탄 중심, 압축탄 중심, 상태 연계 모두 만들 수 있도록 빈 역할을 보완했다.

## UI와 접근

파츠 공용 카드에 발동 조건과 이득/대가를 연결하고 신규2종에 기존 도트 기계 기호 방식의 아이콘을 추가했다. 상점의 역할/현재 덱 연결 설명, 장비 비교, 실제 발동, 확정 예측과 산개 확률을 연결했다. 일반/압축 계열을 함께 세는 보유 탄 안내도 보완했다.

작은 화면에서 긴 연결 문구 때문에 장비 영역이 밀려나지 않도록 비교 문구를 줄였다. 전체 조건은 규칙 상세에 남긴다. 새 재화·등급·세트 카운터·전투 패널은 추가하지 않는다.

[PLAY.cmd](../../PLAY.cmd) → 개발 → 파츠 빌드 · 일반 연쇄/압축 준비/화상 추격. 실제 진행 저장을 쓰지 않는 연습이며 일반 패 크기·장전·발열·발사 규칙을 사용한다. 압축 준비는 잔열5로 시작해 순서에 따라 과열 결과가 갈린다. 본편에서는 상점/정예의 기존 파츠 보급 경로로 새 파츠를 얻는다.

기존 파츠 ID·장착/보유 목록·저장 형식은 유지한다. 가속 총열과 과구경 총열의 효과는 이어하기에도 새 규칙으로 적용된다. 보유 파츠를 삭제하거나 자동 교체하지 않는다.
