**7종 목록 본편 후속(2026-11-06):** 데드볼트·리와인더를 추가했다. 기존5칸 기준 카드 폭/92높이·그림 여백, 중앙 배우0.85와 고정 시작250×54를 유지하고 한 줄 가로 탐색을 저작했다. 터치 드래그/PC 휠·키보드 포커스, 실제49조합 시작/저장과 작은 창·글씨3배율을 검수했다. [화면/검증·범위](../qa/reports/weapon_live_2026-11-06/README.md). 아래5종 기록은 이전 단계의 검증이다.

**장비 팝업 재질 본편 반영(2026-11-06):** 사용자 다음 작업 지시로 장비 선택에서 여는 상세·시작 탄환·등반/시스템 설정·기존 진행 교체 확인창을 철제/먹색·아이보리·황동으로 연결했다. 기존 공용 씬을 상속한 `equipment/dialog.tscn`만 사용하며 배치/입력/폰트 크기와 계산/저장을 유지한다. [14상태/280관측·팝업75/장비479검사와 한계](../qa/reports/equipment_dialog_2026-11-06/README.md). 장비 팝업의 이전 청록 미적용 지적은 이번 후속으로 해소했다. 다른 페이지의 공용 팝업과 Android/사람 확인은 별도다.

**하단 무기 카드 그림 축소(2026-11-06):** 사용자의 과밀 피드백으로5카드의 그림 영역만 줄여 여백을 늘렸다. 카드/이름·입력·왼쪽 미리보기·중앙 배우는 유지한다. [전후·18상태 기하 차이0/479검사](../qa/reports/equipment_rail_scale_2026-11-06/README.md). 이 여백을 다른 화면이나 무기 원화의 일괄 크기 규칙으로 확대하지 않는다.

**핵심 정보 정리 본편 반영(2026-11-06):** 사용자 승인으로 고유 효과를 총기명 바로 아래에, 발사 방식/탄창/발열/교체·냉각을 저작된 수치 그룹에 묶었다. 복장 목록은 `탄약 최대 N발`로 상한을 명시하고 최소 유지/정비 확장 값은 툴팁과 기존 시작 탄환 상세에서 확인한다. 큰 구도·중앙 배우·버튼 위치/크기·스크롤과 규칙은 유지했다. [전후18화면/486기하 차이0·실제35조합 포함2,852검사](../qa/reports/equipment_information_2026-11-06/README.md). 아래 ‘후속 제안/미배치’는 이 반영 전 상태다. 장비 선택 팝업에 남은 청록 디더 재질은 위 팝업 후속으로 정리했다.

**돌아가기/정보 노출 검토 당시:** 사용자 지시로 돌아가기를 좌측 하단의 기존 설정 위치로, 설정은 우측 상단 보조 메뉴로 이동했다. 하단의 선택 요약/시작 위치와 중간 영역·캐릭터/목록·폰트 크기를 유지했다. [본편/310검사와 정보 위계 검토](../qa/reports/equipment_navigation_2026-11-06/README.md). 당시 정보 위계 제안은 위 최신 후속으로 반영했다. 시드·난도·선호 보급의 기능도 이번에 바꾸지 않았다.

**좌측 총기 정보 패널 후속:** 사용자 승인으로 이름·그림·성능·상세 버튼을 불투명도68%의 검정/얇은 철제 윤곽으로 묶었다. 정보열을 오른쪽12 이동해 내부 여백을 주고 폭/버튼 크기·최소 높이/중앙 착장·시작/총기 목록 배치는 유지한다. 정식 씬의 입력 무시 Panel과 `equipment/weapon_info_panel.tres`를 사용한다. [실제 화면/기존310검사 실패0](../qa/reports/equipment_panel_2026-11-06/README.md).

## 사용자 확정과 유지 범위

- 분위기와 디자인을 우선하고, 검토한 철제·황동 외형을 본편으로 진행한다.
- 총기·복장·장착 선택에 따라 실시간으로 달라지는 캐릭터 구성은 유지한다.
- 중앙 캐릭터는 더 작게 조정한다. 초기 시안의 ‘캐릭터 크기 유지’보다 이 후속 지시가 우선한다.
- 모바일에서 시작을 누르기 위해 전체 페이지를 내려야 했던 문제를 해결한다. 복장 목록의 정상 스크롤과 주요 행동의 화면 밖 배치를 구별한다.
- 기존 장비실/조명, 좌측 총기 정보·중앙 캐릭터·우측 복장·아래 총기 선택의 큰 구도, 버튼/카드/폰트 크기, 선택·전투·저장 규칙은 유지한다.

## 현행 구현

- 정식 화면 `redesign/equipment_screen.tscn`: 상단/하단 행동 줄과 중간 `SelectionScroll/SelectionLayout`을 별도로 저작했다. 장면·복장·총기 목록만 필요한 경우 스크롤된다. 시작 버튼은 스크롤 밖에 고정된다.
- 짧은 화면은 상속 씬 `redesign/equipment/screen_short.tscn`의 상하 여백12/간격8을 사용한다. 선택 기준은 기존 안전 영역 높이660 미만이다. 화면 전체에617 이상 높이를 강제하지 않으며, 불필요한 고유 효과 최소 높이44/개발 안내를 제거했다. 글씨나 전체 UI를 축소하지 않는다.
- S26 비율2340×1080/정수2배에서는 논리1170×540에5총기 목록과 시작 버튼이 함께 보인다. 더 짧은 가용 높이에서는 가운데만 스크롤된다. PC1280×800의 시작 버튼 위치/250×54 크기는 종전과 같다.
- `equipment_actor.gd`의 실제 배우 미리보기에0.85 표시 계수를 적용하고 발을 바닥에 맞춘다. 모바일은 장면 가용 높이도 줄어 이전 화면 대비 전체 축소폭이 더 크다. 전투 배우/총기 아트에는 이 계수를 적용하지 않는다.
- 정식 `equipment/theme.tres`의 철제 받침/아이보리 글자/황동 선택·시작, `skin.gd`의 선택 색, `edge.gd`의 작은 빛받음을 사용한다. 장식은 입력/컨테이너 크기에 참여하지 않는다. 대표 착장 PNG는 에디터 표시용이며 플레이 중에는 기존 실제 배우가 바뀐다.

## 판단 근거와 검증

기존 정비소/상점의 절제된 재질과 Hunt 공식2019 캐릭터 선택 예시/2025 Hunter Details 제안의 ‘조명 속 캐릭터 중심, 주변 UI 절제’를 참고했다. 서부극 장식·빽빽한 슬롯·메뉴 구조나 팔레트 전체는 가져오지 않았다. [출처/이미지/판단](../art/references/2026-11-06-equipment/README.md).

[초기 외형 시안](../qa/reports/equipment_visual_2026-11-06/README.md)의41검사는 위치/크기 보존과 착장 연동 범위였고, 모바일 출발 노출을 검증하지 않았다. [후속 진단](../qa/reports/equipment_mobile_2026-11-06/README.md)에서 최소617 대비 논리540 문제와 단순 하단 고정의 목록 가림을 확인했다. 최종 구현은 최소 높이·여백 정리와 저작된 중간 스크롤/고정 행동 줄로 둘을 함께 해결한다.

본편 네이티브1,513검사 실패0:6창 크기·지원3글씨 설정/5총기, 실제 터치/키보드,35조합 시작·기존 캠페인/모델/RNG 정합성·전체 저장 내용 복원, 상세/설정·교체 확인·취소·훈련·창 변경을 확인했다. 기존 HUD11,558검사 실패0. 에디터에서 씬 계층/테마/대표 캐릭터 표시도 확인했다. [검사와 알려진 한계](../qa/reports/equipment_live_2026-11-06/README.md#검증).

유지 근거는 S26 비율에서 시작 버튼과 총기 목록이 함께 보이고, 더 짧아도 주요 행동을 스크롤하지 않는 것이다. 사람의 캐릭터 크기·미감, Android 실제 안전 영역/터치 및 지속 발열은 후속 확인이며 PC 모의 검사로 통과 처리하지 않는다. APK는 생성하지 않았다. 이전 시안의 확인 대기는 이번 실행 지시로 해소됐고, 아래 과거 보고서의 미적용 표기는 당시 상태다.
