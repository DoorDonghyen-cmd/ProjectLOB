# 성장·빌드 구조 v2 — 처음부터 다시 짠다면

2026-11-10. '이 게임의 성장·빌드 구조를 처음부터 만든다면' 설계를 사용자가 승인했다("이대로 진행해 줘"). 이 문서가 성장·빌드 구조의 목표 그림이다. [보상·경제 개편](reward-economy.md)과 [빌드 엔진](build-engine.md)은 이 그림의 부분 설계로 읽는다.

## 결정 상태

- **사용자 확정(11-10)**
  - 아래 원칙과 다섯 층 구조, 단계적 진행(먼저 '특수탄 우선 장전'과 '코어 → 숙련·희귀 파츠'를 시험판으로 만들고 자동 등반으로 비교).
  - 파츠는 발라트로의 조커다.
  - 초반에 빌드를 반강제하지 않는다.
- **디렉터 결정**: 시험판의 구체 규칙과 수치(아래). 사람 플레이 확인 전이다.
- **지키는 기존 확정**: 파츠 등급은 희소도(10-09), 탄 영구 강화는 2발→1발 한 가지(11-06).

## 원칙

1. **계산식 하나**: `(탄 기본 + 가산) × 배율 → 장갑`. 모든 성장은 이 식의 어느 칸을 키우는지 분명해야 한다. 전투에서 계산 줄로 보인다.
2. **초반은 탐색, 후반은 완성**: 처음부터 정체성을 고르지 않는다. 모은 것에서 빌드가 생긴다.
3. **자동 성장은 없다**: 모든 성장에 고르는 순간이 있다.
4. **장소마다 다른 종류의 결정**: 같은 보상을 반복하지 않는다.

## 다섯 개의 층

| 층 | 역할 | 발라트로 | 늘고 주는 방식 |
| --- | --- | --- | --- |
| 총기 | 쏘는 방식(발수, 탄창 칸, 열 한계, 고유 규칙) | 시작 덱 | 시작할 때 고정, 관문의 총기 개조 |
| 탄 (카드) | 무엇을 쏘나 | 플레잉 카드 | 추가·제거·강화(2→1) |
| 탄종 숙련 | 한 계열 전체 강화 | 행성 카드 | 정예·관문 보상 |
| 파츠 (조커) | 들어온 탄을 곱하는 엔진, 5칸 | 조커 | 획득·판매·★강화 |
| 정비 도구 | 1회용 전투 조작 | 타로·소모품 | 상점 구매, 2칸 |

크레딧(이자 있음)이 층 사이의 연료다. 코어는 따로 두지 않는다.
- 방향 → 탄종 숙련
- 성장 → 성장형 파츠·★강화
- 겹침 제한 → 희소도와 대가

## 단계

1. **시험판 1 (11-10, 이 문서)**: 특수탄 우선 장전, 첫 전투 코어 선택 제거, 코어 1개 제한 해제, 관문의 탄종 숙련. 새 등반 기본 적용. 자동 등반 비교.
2. **보상·경제**: 탄 제거, 파츠 ★강화, 이자, 장소별 보상([보상·경제 개편](reward-economy.md)).
3. **정비 도구, 후반 규칙 희귀 파츠, 관문을 큰 분기로**.
4. **성장 코어의 자동 성장 정리**(성장형 파츠·★로), 4~5구역 적 조정.
5. **메타 해금**: 전술 데이터로 파츠·탄·총기를 보상 풀에 추가.

## 시험판 1 (`growth_structure.gd`, `growth_structure_version=1`)

- **특수탄 우선 장전**
  - 전투 시작 때 섞은 탄 중 특수탄이 항상 기본탄보다 먼저 장전된다. 재장전으로 돌아가는 쏘지 않은 특수탄도 기본탄 앞에 선다.
  - 기본탄은 그대로 덱에 남는다(휴대량, 교체, 관문 생산이 계속 작동). 남는 칸만 채우는 역할이다.
  - 처음 설계의 '덱은 특수탄만, 기본탄 무한'을 기존 규칙을 깨지 않고 가깝게 구현한 형태다. 휴대량이 기본탄을 세는 문제는 2단계(탄 제거)에서 다룬다.
- **첫 전투 코어 선택 제거**: 첫 승리 후 바로 주력 탄 묶음(주력 2 + 지원 1)으로 간다. 주력 탄은 영구 잠금이 아니다(덱에서 매번 다시 판단).
- **코어 1개 제한 해제**: 코어 표시 파츠도 다른 파츠와 함께 5칸에 낄 수 있다. 성장 코어 3종이 승리마다 성장하는 규칙은 아직 그대로다(4단계에서 정리).
- **탄종 숙련**: 관문 선택지에 '탄종 숙련'을 추가했다. 지금 주력 계열의 모든 공격탄이 단계마다 타격당 +1, **단타 탄은 +2**(최대 4단계). 계산식의 가산 칸에 들어가고 계산 줄에 보인다.
- **총기 내장 구동(11-10 추가)**: 첫 전투 코어를 없애자 리벳·리액터 등반이 실패했다(아래). 그래서 총기마다 예전 첫 코어의 역할을 내장했다. 장착 칸을 쓰지 않고, 그 총기의 성장 코어는 파츠로 제시하지 않는다(`content.gd::GUN_ENGINES`, `active_parts`). 총기는 시작할 때 고르므로 등반 중 강제가 아니다.

| 총기 | 내장 구동 |
| --- | --- |
| 리벳, 스파이크, 데드볼트 | 돌파: 단타 ×2, 처치 초과 피해 전달 |
| 래칫, 스플린터 | 연쇄: 타격당 +1, 남은 타격 다음 적으로 |
| 리액터, 리와인더 | 열압: 고열 ×1.5 |

내장 구동은 지금 성장 코어처럼 승리마다 성장한다. 자동 성장 정리는 4단계에서 한다.
