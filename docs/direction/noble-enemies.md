# 4구역 — 귀족 거주구

## 결정 상태

사용자는 4구역을 기계화 귀족들의 도시로 정하고, 적의 핵심 스타일을 공격 기회를 여는 전투로 제안했다. 2026-10-25 진행 요청에 따라 아래 내용을 본편에 구현했다. 개별 이름·수치·편성·원화는 디렉터의 1차 구현값이며 사용자 체감 확정은 아니다.

새 등반은 편성10을 사용한다. 기존 저장 편성1~9는 원래 전투를 유지한다. 1~3구역의 현행 편성과 5구역의 기존 편성은 바꾸지 않는다.

## 적 구성

| 분류 | 이름 | 역할 | HP | 차폐 |
|---|---|---|---|---|
| 일반 | 차폐 귀족 | 기계 신체와 개인 방호 장치를 지닌 귀족. 차폐를 열어 집중 공격 | 10~12 | 2회 |
| 일반 | 겹문 시종 | 인간을 닮은 순수 기계. 접힌 문판이 열리면 몸체 노출 | 10~12 | 2회 |
| 일반 | 가문 시종 | 차폐 없는 약한 전열. 처치·돌파·연쇄의 출발점 | 5~9 | 없음 |
| 일반 | 사설 경호기 | 시종 뒤에서 요격 가능한 압력탄 발사 | 9~11 | 없음 |
| 정예 | 수석 시종 | 차폐 복구 직전에 추가 전진 예고 | 36 | 3회 |
| 보스 | 백동 후작 | 부채형 방호 장치를 가진 기계화 귀족 | 64 | 4회 |

- 일반전6~7기, 정예6기, 보스7기. 최대4기 노출, 나머지는 유한한 후속 편성.
- 한 전투 전체에 압력탄 사수는1기만 존재한다. 후속에도 중복 배치하지 않는다.
- 차폐와 장갑·회피·지휘 게이지를 겹치지 않는다. 차폐형은 장갑0, 기본 접근1m. 경호기는 제자리에 선다.
- 차폐 없는 전열과 방호 대상을 섞어 빌드의 다수 처치 보상을 유지한다.

## 차폐 → 노출 → 복구

1. 일반 타격은 차폐1회, 전기 주 타격은2회를 제거한다. 파쇄 파츠는1회를 추가한다.
2. 마지막 차폐를 깨는 타격까지 직접 피해를 막는다. 같은 연타탄의 남은 타격부터 HP 피해가 들어간다.
3. 차폐가 깨진 순간 일반 적3행동, 정예·보스5행동의 노출 시간이 생긴다. 발사에 따른 적 행동도 포함되므로 행동 종료 후에는 보통2/4가 남는다.
4. 재장전과 강제 과열 재장전도 이 시간을 소비한다. 차단 효과는 열린 상태의 복구 시계를 늦춘다.
5. 시간이 끝나면 차폐가 전량 복구된다. 수석 시종은 기본 이동에2m, 백동 후작은3m를 추가한다. HP는 회복하지 않는다.
6. 마지막1행동에 재차폐와 총 전진 거리(정예3m/보스4m)를 미리 표시한다.

특정 탄을 갖지 못하면 막히는 구조는 아니다. 기본탄으로 차폐를 소모시키고 연타·전기·파쇄 파츠로 효율을 높이거나, 소이탄의 화상으로 차폐를 우회할 수 있다. 기존 전기 전이의 보조 피해 규칙은 보존한다. 열린 동안의 HP 피해에 별도 상한이나 강제 페이즈를 넣지 않아 강한 빌드는 한 번의 노출에 처치할 수 있다.

## 원화와 표시

- 기존 귀족 거주구3단계 배경과 승인 C 주인공의 색면·윤곽을 기준으로 원화를 제작했다.
- 차폐 귀족·겹문 시종·수석 시종·백동 후작은 닫힘/노출/재차폐3키포즈. 가문 시종·경호기는 정지 원화와 기존 절차적 이동·피격·발사 동작.
- 백동·상아색 기계부와 바랜 자주색/청록색 천으로 상층 신분 차이를 드러낸다. 시종은 전부 순수한 기계다.
- 남은 차폐는 상태 아이콘과 몸체 앞의 분절 표시, 노출 시간은 적 위의 짧은 행동 예고로 표시한다. 원화 속 물리 문판 수와 차폐 횟수는 동일한 개념이 아니다.
- 피해0을 단순 '막힘'으로 끝내지 않고 '차폐 −N회' 또는 '파손 / 본체 노출'로 보여준다.
- 기존 총기 파지·발사/재장전·피니시 카메라·배경 변화 규칙은 유지한다.

## 테스트와 다음 판단

[실제 화면·검증 보고서](../qa/reports/noble_live_2026-10-25.md). 개발 메뉴의 귀족 거주구 일반전/수석 시종/백동 후작으로 바로 확인할 수 있다. 미리보기는 실제 3구역 관문까지 획득한 리벳 덱을 사용하며 저장하지 않는다. 후반 방 직접 진입은 화면 확인용이며 그 사이의 추가 성장을 가정하지 않는다.

다섯 무기의 실제 획득 덱으로 동일 시드의3구역→4구역→5구역 입구 진행을 확인했다. 모든 경로·빌드의 난이도를 확정한 것은 아니다. 특히 리액터의 보스전 장기화, 차폐 개방 후 공격 기회 이해, 새 원화의 배경 조화는 사람의 플레이 피드백으로 이어서 판단한다.
