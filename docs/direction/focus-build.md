# 핵심 탄과 발사 위치 파츠

**후속 적용(2026-11-03):** [탄환 역할·운용 성장](combat-roles-growth.md)을 새 등반에 연결했다. 소이/전격 시작 묶음과 제어 지원을 추가하고 기본 처치 전이를 추가1기로 제한해 별도 확장 선택을 둔다. 아래 직접 피해/위치 파츠·주력 복사/강화는 유지한다. 사용자에게 현재 전투의 재미·긴장감 긍정 후기를 받았지만, 이번 후속 빌드의 체감은 별도 확인 대상이다.

2026-11-03. 사용자 확정: 발라트로처럼 핵심 탄을 중심으로 피해가 크게 증폭되는 덱 빌딩을 먼저 개편하고, 파츠도 세 번째 발 강화처럼 재검토한다. 아래 수치·지급 방식은 디렉터의 첫 구현값이며 사람 재미 검증 전이다.

## 이번 적용

- 새 등반에 `focus_build_version=1`. 이전 저장은 변경하지 않는다. 기존 사격 범위·빼내기·열·적·지도 규칙을 사용한다.
- 첫 전투의 코어 선택 다음에 연타 / 철갑 / 열방출 중 주력 탄을 고른다. 주력 2장과 지원 1장으로 위력이 낮은 기본탄 3장을 교체한다. 총 탄약 수는 유지한다. 선택 전에 실제 구성과 교체를 표시한다.
- 이후 일반 탄 보상은 보유 주력의 동일 프로필 보충 / 연계 지원 / 강화 탄 또는 새 발견을 제시한다. 첫 구역 깊이 4 이후에는 가능한 주력의 화력 개조본, 이후 압축본을 제시한다. 새 1장을 확보하는 선택이며 기존 모든 탄을 자동 강화하지 않는다. 원래 발열·점유 칸·위치 제약을 그대로 표시하고 적용한다. 주력은 보유 공격 특수탄의 가장 많은 계열로 판단하고 동률은 장착 코어 연계로 판단한다. 별도 영구 직업 잠금은 없다. 공방·보급과 상점의 탄 진열도 집중 획득을 지원한다.
- 선두 격발기: 첫 실제 발사 탄의 직접 피해 ×2. 제3 격발기(신규 모듈): 세 번째 실제 발사 탄의 직접 피해 ×3. 후미 점화기: 실제 증폭을 받은 마지막 단타의 직접 피해 ×3, 재장전 +1행동 유지. 지원탄도 발사 순서에 포함하며 그 자리에 지원탄을 쏘면 위치 강화는 소비된다. 연타의 여러 타격은 한 발이다. 빼낸 탄은 세지 않고 냉각은 순서를 유지하며 교체 시 초기화한다.
- 합산 피해 → 증폭 배율 → 위치 파츠 → 코어/관문/강행 배율 → 장갑 순서. 위치 강화는 직접 타격과 기존 잔타/초과 피해 전달에만 적용한다. 화상·기폭·전이 재발동이나 무한 재귀는 없다.
- 증폭/연타/열/관통 파츠는 기존 조합 재료로 유지한다. 모든 파츠를 위치 조건으로 바꾸지 않는다. 냉각·탄창·관통은 큰 피해를 성립시키는 보조 선택이다. 성장 코어 일괄 약화·적 HP 상향은 하지 않는다.

## 검증 질문

같은 투자량에서 주력 탄을 모으고 지원·위치 파츠를 맞춘 덱의 피해와 처치선이 달라지는가? 첫 획득 후 다음 전투에 조합 재료가 보이는가? 사격을 그대로 이어가도 잘 만든 덱이 강한 것은 허용한다. 반복 사격 승률을 낮추는 것이 목표가 아니다.

실제 Model/Forecast로 위치 조건(지원·연타·빼내기·부분 사격·냉각·교체), 배율 중첩, 산개 분포, 획득 전후, 저장 복원과 이전 규칙을 검증한다. 본편 획득 경로와 5총기의 등반을 확인한다. 결과·사람 확인·모바일 미검증을 분리해 기록한다.

본편 새 등반 적용 및 규칙/예측·3크기 실제 UI·저장/이전 규칙 회귀 완료. 5총기 125전투 획득 경로와 현재 코드 재생 통과. [결과·화면·남은 탄약/사람 확인](../qa/reports/focus_build_2026-11-03.md). 기능 조건을 유지하며 다음은 성장 체감과 획득 선택 이유의 플레이 확인이다. 제3 격발기는 하나의 모듈이며 성장 코어와 함께 장착할 수 있다. 초기 첫 미발견 파츠 진열에서 제시하고 이후 기존 파츠 획득 풀에 들어간다.
