# 과열 대가 — 전투에 결정 만들기 1단계

2026-11-11. 사용자 플레이 피드백 "아무탄이나 막 발사해도 클리어 되는 문제"에 대한 [무판단 사격 측정](../qa/reports/naive_play_2026-11-11/README.md) 뒤, 사용자가 '전투 결정 먼저, 과열 대가 하나만 먼저' 제안을 승인했다("진행해 줘").

## 결정 상태

- **사용자 확정(11-11)**: 전투 결정 문제를 파츠 방식보다 먼저 고친다. 1단계는 과열 대가 하나만 바꾼다.
- **디렉터 결정**(되돌리기 쉬움, 사람 플레이 전): 강제 냉각 +2행동, 리액터만 +1행동. 새 등반만.
- **사람 확인(11-11, APK 플레이)**: "과열 경고를 보고 확실히 발수를 제한하게 돼". 경고를 보고 발수를 바꾸는 결정이 생겼다(위 가설 확인). 이전 플레이 소감 "과열 리스크도 크고".

## 규칙

| | 이전 | 지금(새 등반) |
| --- | --- | --- |
| 미리 냉각 | 적 1행동 | 적 1행동(그대로) |
| 과열 강제 냉각 | 적 (재장전 + 1)행동, 보통 3 | 적 (재장전 + 1 **+ 2**)행동, 보통 5. 리액터는 **+ 1** |

- 과열해도 남은 탄은 보존된다(그대로).
- 사격 버튼의 '적 N행동 · 과열'과 사격 예측이 늘어난 행동 수를 그대로 센다(`tests/overheat_cost_rules.gd`).
- 전투 도움말: '과열되면 강제 냉각 · 적 N행동(미리 냉각하면 1행동)'.
- 구현: `redesign/overheat_cost.gd`(플래그 `overheat_version`), `model.gd::_trial_cool`, `campaign.gd`(새 등반에 플래그).

## 크기를 정한 근거 (시드 17·23, 성장 v2, 현재 구성)

무판단 = 매 턴 최대 발수·빈 탄창 재장전만. 해법기 = 최선의 수 탐색.

| 대가 | 무판단 | 해법기 |
| --- | --- | --- |
| +0 | 2구역 보스~4구역에서 멈춤, 래칫은 완주(시드 23) | 6/6 완주 |
| +1 | 래칫·리액터 1~2구역, 리벳 3구역 보스 | 6/6 완주 |
| **+2** | 3총기 모두 1~2구역에서 패배 | 5/6 — 리액터 시드 23의 5구역 정예가 넓힌 탐색으로도 풀리지 않음 |
| +4(시드 17만) | 1~2구역 | 3/3 완주, 전투 턴 +37~71%, 보스 최소 여유 1m |

- 채택: 기본 +2, 리액터 +1. 이 조합은 위 실험 안에 그대로 있다: 해법기 6/6 완주, 무판단 6/6 패배(1~2구역, 리벳 시드 17만 2구역 7층).
- 해법기의 선택 냉각: 리벳 8·13 → 16·19회, 리액터 발수 조절 0·5 → 10·11회(시드 17·23). 결정이 생기기 시작했다.
- 해법기 전체 턴(두 시드): 리벳 +20~23%, 래칫 +39~43%, 리액터 +11~13%.
- 래칫은 대가를 올려도 해법기가 냉각을 거의 쓰지 않는다(+2에서 0~1회). 래칫의 결정은 2단계(질문하는 적)에서 봐야 한다.
- 확인 안 한 총기: 확산·증폭·데드볼트·리와인더는 자동 등반 대상이 아니라 +2를 재지 않았다.
