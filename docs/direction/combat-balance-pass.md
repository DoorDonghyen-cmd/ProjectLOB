# 전투 밸런스 1차 보정 — 2026-11-06

## 결정 상태와 질문

사용자는 리액터·소이 조합의 과성능과 총기·탄환·파츠 전체 밸런스, 성장 후 부족한 접근 압박을 지적하고 진행을 승인했다. 이번 수치는 실제 모델 비교를 바탕으로 한 **디렉터 1차 적용값**이며 사람의 재미·최종 균형 확정은 아니다. 탄환 등급·강화 통합과 정예/보스 신규 패턴·전장 기믹은 별도 후속 범위다.

질문은 ‘큰 피해를 만드는 성장의 재미를 유지하면서 사격량·냉각·재장전 선택이 후반 생존에 영향을 주는가’다. 기존 실제 획득 경로에서 단순 사격/빈 탄창 재장전도 대부분의 전투를 통과했고, 소이의 지속 피해 성장·지역 불길과 이전 HP 보정의 거리 여유를 함께 확인했다.

## 현재 적용

현행 수치 원본은 `redesign/run_balance.gd`, `combat_roles.gd`이며 본편의 새 자동 탄창 도전(`map_version >= 4`)이 `balance_version=1`을 기록한다.

## 비교와 판단

[원본 결과·방법·범위](../qa/reports/combat_balance_2026-11-06/README.md). 현재 규칙의 보상·상점·정비를 실제로 거친 획득 정책을 재사용했다.5총기는 시드17/운반용 복장으로 전후 비교하고, 리액터/스플린터는 시드731042·정찰 복장 전후, 리벳은 해당 조건의 새 규칙 추가 검증, 리액터는 열압 유지 대안을 확인했다.16개 완주 경로·총470전투의 탐색/실행·저장 재개가 통과했다.

리액터 소이의 시드17 경로에서 단순 사격/재장전 운용의 국소 통과는28/30→23/30, 경과 적 행동 합계409→517이었다. 실제 선택 경로는 완주했고 비상 보급0회를 유지했다. 다른 총기도 모두 완주 가능 경로가 있었다. 무조건 사격을 줄이거나 모든 전투를 어렵게 만드는 목표는 아니다.

정찰 복장·다른 시드의 리액터는 비상 보급0→2회로 탄 소모 부담이 늘었다. 이 부담과 전투 길이는 사람 플레이에서 우선 확인한다. 위 탐색은 미래 드로/난수를 볼 수 있고 국소 단순 운용 비교도 매 전투의 실제 획득 시작 상태에서 별도로 수행하므로 사람의 승률이나 단순 운용 전체 완주율을 뜻하지 않는다.

- **유지 근거:** 다섯 총기의 유효한 성장/완주 경로, 큰 직접 피해, 소이의 장갑 대응/지속 피해 역할과 합법적인 냉각/교체 대안이 남는다.
- **수정 근거:** 소이의 재적용/탄 소모만 늘어 전투가 늘어지거나, 작은 가방에 비상 보급이 상시 강제되거나, 직접 화력만 정답이 되면 추가 보정한다.
- **다음 결정:** 이번1차값을 새 도전에 적용하고 사람의 선택·호흡을 확인한다. 후속 우선순위는 탄환 강화 통합/등급 카드, 이어서 고유 적 패턴과 전장 기믹이다. 전체 파츠의 모든 조합이나 난도/복장 전 조합을 최종 균형 완료로 표시하지 않는다.

## 예측·표시·저장

실제 Model과 Forecast가 같은 버전별 화상/불길 함수를 사용한다. 무작위 예측 캐시도 `balance_version`을 구분한다. 파츠 상세·탄환 상세·발동 표기의 기간/보너스/성장 주기를 현재 상태로 계산한다. 새 도전의 실제 획득 전투를 본편 HUD에 불러 공개 입력과 정확한 저장 재개를 검증했다.

표식 없는 기존 이어하기는 이전 지속 피해와 거리 규칙을 유지한다. 신/구 상태를 임의 혼합하거나 유효 범위 밖의 표식을 저장에서 받아들이지 않는다. 이번 보정을 확인할 때는 새 도전을 시작한다. Android 실기기/실제 플레이 체감은 별도 확인 대상이다.
