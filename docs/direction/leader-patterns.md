# 정예·보스 패턴 후속

## 현행 추가 — 연속 압력탄과 증원 호출

사용자가 보스 스킬의 다양성과 연속 압력탄/추가 몬스터 등장을 요청했다. 다음은 **디렉터 1차 적용값**이며 사용자 최종 체감/난도 확정과 구분한다. 이번 본편 범위는 폐쇄 당직의2연발, 수로의 어미의 증원 호출이다. 아래2구역 돌진/반격 창도 유지한다. 나머지 고유 행동은 유지하며 모든 보스의 개편 완료로 기록하지 않는다.

새 전체 탄창 도전에 `boss_skills_version=1`을 기록한다. 이전 표식 없는 저장과 앞 단계의 `enemy_pattern_version=1`만 있는 저장은 기존 단발/자동 증원을 유지한다. 수치/필드 원본은 `redesign/boss_skills.gd`, `ranged.gd`와 실제 Model이다.

[본편 검증과 실제 화면](../qa/reports/boss_skills_2026-11-06/README.md): 새 규칙228/본편UI213/저장185상태/최종 첫 보스 재생50, 실제6완주179전투·동일12상태72국소 비교. 실제2연발/호출과 합법 대응이 있어1차값을 유지한다. 실제 요격→차단 순서로 새 연속 발사 상태의 차단 누락을 수정·검증했다. 구형 압력탄 스위트의 폐기된 열 필드 참조 중단, 초기 UI 가정 수정과 사람/Android 한계를 보고서에 구분한다.

증원1차는 총물량을 더하지 않고 기존2기의 등장 시점을 보스 행동으로 바꾸는 비교다. 생성된 탄을 각각 추적하는 예측·독립 식별/요격·다중 표시/안내·시계 중간 저장/재개까지 연결한다. 제거한 HP 아래 ‘다음’ 문구를 되살리거나 사격 입력/큰 레이아웃을 바꾸지 않는다.

질문은 ‘연속 요격과 증원 예고가 다른 대응을 요구하는가’다. 같은 실제 획득 상태에서 이전/새 규칙의 최대 사격·공개 열 기반1발/냉각·미래 정보 탐색을 구분해 비교한다. 실제 압력탄 발사/동시 수·요격·호출/투입·적 행동/잔탄/비상 보급을 관측한다. 패턴 전에 쓰러뜨리는 큰 화력 조합은 허용한다. 특정 탄을 반드시 가져야 하거나 작은 가방에서 보급이 늘거나 예고 없이 접촉하면 수정한다. Android 실기기·사람 이해도/긴장감과 후반 전체 균형은 자동 통과와 구분한다.

## 앞 단계 — 2구역 반격 구간

사용자의 ‘정예·보스가 체력만 많은 적처럼 느껴진다’는 후기 후속이다. 탄환 강화 통합 이후 우선순위4를 순차 진행한다. 이번은 **본편의 디렉터 1차 적용값**으로, 2구역 금형 파수꾼·주조 감독만 다룬다. 다른 구역·전장 차단벽은 후속이다. 사용자 최종 체감 확정과 자동 기능 검증을 구분한다. [기능296/본편UI111/HUD11,558검사·실제 획득6완주179전투·동일11상태88국소 비교](../qa/reports/leader_patterns_2026-11-06/README.md).

현재 두 적에게 축압→본체 돌진→한 행동 정지가 이미 있다. 그러나 정지 중에도 장갑3이 유지되어 반격 시점을 선택할 화력 이득이 없다. ‘사격을 미루기만 하면 유리한가’가 아니라, 가까워지는 대가를 감수하고 반격 창을 활용할 이유가 생기는지 확인한다. 빠르게 완성한 큰 피해 조합이 패턴 전에 처치하는 것은 허용한다.

## 새 도전 규칙

수치 원본은 `redesign/leader_patterns.gd`와 `foundry_workers.gd`다. 새 전체 탄창 도전에만 `enemy_pattern_version=1`을 저장한다. 해당 두 적만 `foundry_version=3`을 받으며 과거 저장은 이전 행동을 유지한다.

- 체력·기본 장갑·축압2행동·1행동 회복·호위 편성/거리·보상은 유지한다.
- 파수꾼 돌진은 기본1+추가5m, 감독은 기본1+추가6m다. 이전 추가3/4m보다 본체 압박을 높인다. 호위는 함께 당기지 않는다.
- 돌진 직후부터 다음 적 행동 전까지 장갑0으로 열린다. 회복 행동은 이동0이며 끝나면 남은 장갑으로 닫힌다. 사격/냉각은 각각 실제 적 행동을, 재장전은 총기/파츠별 여러 행동을 진행한다. 창을 넘길 수 있다.
- 파쇄는 저장된 장갑을 영구히 깎아 재폐쇄 시 복구되지 않는다. 차단/감속·화상 선처치·접촉 즉사와 기존 코어/파츠는 실제 Model 계산을 따른다.
- 기존 상단 상태 문구와 상세에 반격 창을 연결한다. HP 아래의 제거한 ‘다음’ 문구나 별도 조작·레이아웃을 추가하지 않는다.

## 비교와 유지 조건

실제 획득한 동일 시작 덱/파츠/난수에서 이전/새 패턴을 비교한다. 단순 최대 사격, 공개 열 상태를 이용한 짧은 사격/냉각, 미래 난수를 아는 제한 탐색을 구분한다. 돌진/회복 발생·노출 중 실제 타격·장갑 차이·적 행동·접촉/잔탄·비상 보급을 관측한다. 국소 승리와 자연 획득 전체 경로를 구분한다.

새 규칙에 합법적 대응/반격 이득이 있고 강한 기존 빌드의 이점이 남으면 유지한다. 예고 없이 접촉하거나 저화력 총기의 탄만 소모시키거나 반격 창이 실제 선택에서 드러나지 않으면 수정한다. 전투를 오래 끌어야만 패턴을 보게 만드는 강제 무적/피해 상한은 넣지 않는다. 기능/획득 경로/본편 화면 결과와 사람·Android 미검증 범위를 QA 보고서에 연결한다.

현재 표본에서 최대 사격 반복은9/11→5/11, 반격 구간을 활용하는 공개 운용은9/11→9/11, 미래 정보를 아는 탐색은11/11→11/11의 국소 통과였다. 실제 획득6경로도 완주했다. 반격 시점을 고를 실제 이득과 기존 조합의 대응이 있어 이번 값을 유지하되, 이 수치를 사람 승률·최종 균형으로 해석하지 않는다. 정찰의 후반 탄 소모/긴 전투·사람의 반격 창 이해도와 다른 구역/어센션은 다음 관찰 대상이다.
