# 도트 제작 방향 — 산나비에 가까운 인물과 디스토피아적 공간

**생물 화풍 기준 추가:** 사용자가 처마등 시안을 전반적으로 긍정 평가했다. 큰 등판/낮은 몸과 조용한 색면 표현을 후속 생물 제작의 실물 참조로 추가한다. 새 숨접이·빗주머니2종은 [개발 전투 비교](../qa/reports/residential_creatures_2026-10-09.md) 단계이며 아직 사용자 채택 전이다.

**현행 제작 진입점:** 새 아트와 화풍 수정은 [승인 이미지·공통 제작 지시·검수 기준](pixel-production.md)을 먼저 사용한다. 아래 결정 상태에서 최신 사용자 채택을 확인한다. 뒤의 초기 통합 시안/완료와 후속 항목은 제작 당시 이력이며 현재 주인공·동작·탐사도의 채택 상태를 되돌리지 않는다.

2026-10-03 · 사용자 제공 10개 레퍼런스의 직접 시각 검토. [원본과 검토 보드](../art/references/2026-10-03-user/README.md).

## 결정 상태

- **사용자 확정 — 몬스터 개성:** 생물은 원래 동물을 바로 분류하기 어려운 몸을 지향한다. 기계형에는 인간 같은 실루엣·기계 기관·태엽의 개성을 사용하되 정체는 전부 순수한 기계다. 인간 개조체나 인체가 들어간 존재로 설정하지 않는다. [최신 몬스터 방향](monster-roster.md)의 자동인형 후보를 비교하며, 승인된 큰 색면·낮은 잔묘사와 작은 화면의 역할 판독을 유지한다. 개별 종 시안은 미확정이다.

- **사용자 확정 — 주인공 동작 이미지:** 조준·반동·탄창 꺼내기/끼우기4키포즈에 대해 사용자가 “딱 원한 그림”이라고 확인했다. [현재 아틀라스·실제 화면](../qa/reports/actor_motion_2026-10-05.md)의 큰 색면과 낮은 잔묘사, 모자/복장·성인 비율을 이후 자세에도 유지한다. 동작 속도와 연결감은 별도 플레이 검증 대상이다.

- **사용자 확정 — 주인공 표현 v2:** 사용자가 “딱 내가 원하던 느낌”으로 확인하고 이 표현으로 진행하기로 했다. 배경과 어울리는 큰 색면·적은 내부 경계·절제된 외곽선을 현재 배우 아트의 기준으로 삼는다. 선택한 모자/복장/자세/표시 크기를 유지한다. [확정 주인공 비교](../qa/reports/hero_mass_v2_2026-10-05.md). 정확한 논리 해상도/팔레트 수의 영구 규격을 확정한 것은 아니다.

- **적 표현 v2 구현:** 위 기준으로7종을 다시 제작해 본편에 적용했다. 명암/묘사를 크게 묶되 역할별 외형과 개구리의 준비 예고를 유지한다. [네 적 편성·전후 비교·검증](../qa/reports/enemy_mass_v2_2026-10-05.md). 다른 종별 재설계나 정식 애니메이션 완료가 아니며 새 적 이미지에 대한 사용자 확인은 후속이다.

- **2026-10-05 표현 통합 1차 적용:** 사용자가 배경까지 고려해 주인공 표현을 더 뭉개자는 방향으로 제작을 승인했다. 선택한 디자인·크기를 유지하며 주인공 내부 선/반사광을 큰 청회색 면으로 묶었다. 같은 기준으로 압력두꺼비 2상태와 기존 적 6종을 제작해 본편/샘플에 적용했다. 준비 상태는 실제 모델에 연결하고 지면·명찰·증원·요격을 검수했다. [원본 비교·검증·제작 파일](../qa/reports/actor_cohesion_2026-10-05.md). 엄격한 고정 팔레트/픽셀 격자 완료나 새 시각 결과의 사용자 확정으로 확대하지 않는다.

- **최신 크기 확인:** 사용자가 샘플 주인공을 30~40% 줄이길 요청해 현재 샘플의 가로·세로를 35% 줄였고, 2026-10-04 이 크기가 좋다고 확인했다. 발 위치를 유지하고 총구 좌표에도 0.65 배율을 적용했다. [현재 화면](../qa/reports/tower_art_scale_2026-10-04_assets/tower_battle_1280x900.png). 이는 현재 통합 샘플의 조정값이며 모든 캐릭터의 고정 제작 해상도 규칙은 아니다. 다음 적 비교는 [몬스터 컨셉](monster-roster.md)을 기준으로 한다.

- **통합 이력:** C 복장+B 방한모와 주거구 배경을 별도 실제 전투 샘플에 먼저 적용한 뒤 본편으로 연결했다. 현재 주인공/적 표현은 위 2026-10-05 수정안이 우선한다. 원래 [통합 샘플 기록](../qa/reports/tower_art_sample_2026-10-03.md)은 당시 상태다.

- **사용자 확정:** 전반적으로 가장 가까운 느낌은 산나비. 배경은 디스토피아적인 분위기가 강하게 느껴져야 한다. 기존 탄환 카드 디자인과 기상탑 세계관은 유지한다.
- **시안 피드백/채택:** 사용자는 제작한 캐릭터·배경의 도트풍을 긍정적으로 확인했고 [짧은 챙의 정비용 헬멧 캐릭터 v2](../art/concepts/2026-10-03-pixel-reference/character-reference-v2-helmet.png)를 시작 외형으로 채택했다. 추후 복장/헬멧 획득·교체 요청은 [별도 후속 설계](appearance.md)로 유지한다.
- **이미지에서 관찰한 공통점:** 머리보다 몸과 팔다리가 충분히 드러나는 인물, 큰 무기/장비와 비대칭 실루엣, 제한된 색 덩어리, 사람이 작게 느껴지는 수직 건축, 여러 겹의 깊이.
- **디렉터 제작 방향:** 성인 체형의 탄환 기술자, 무기·공구가 읽히는 비대칭, 절제된 내부 묘사. 도시/탑의 압박감은 거대한 구조물·닫힌 통로·감시와 공급 설비로 전달한다. 인물과 생활 소품 주변에 국소적인 온기를 남긴다.
- **제작 상태:** 본편은 주거구 배경과 위 주인공/7종 적 자산을 사용한다. 아래 초기 시안 기록과 구별한다. 캐릭터의 레이어 분리·프레임 애니메이션·새 지역/보스는 후속이다. 비율/명암/색의 제안은 실제 크기의 검수 기준이며 모든 에셋의 영구 규격이 아니다.

주인공의 첫 비교안은 약 5~6등신 범위의 성인 체형에서 시작한다. 이는 제작 가설이며 영구 비율 규칙이 아니다. 웅크린 사격 자세의 화면 높이와 실제 신체 비율을 혼동하지 않는다. 짧은 작업 외투·비대칭 탄약팩·도구 벨트·두 발의 지지를 큰 형태로 설계하고, 얼굴의 세밀한 묘사보다 머리 방향과 총의 방향을 우선한다.

배경의 불안과 압박은 건축으로 드러낸다. 화면 밖까지 이어지는 기둥, 닿기 어려운 가교, 닫힌 생활 통로, 케이블의 늘어짐과 작게 남은 점검등을 배치한다. 어두운 면 안에서도 금속·콘크리트·식생과 앞뒤 거리를 구별할 수 있어야 한다.

청록·회녹·남청·탁한 보라를 지역별 주색 후보로 둔다. 따뜻한 창문과 난로는 작은 생활 영역에 집중한다. 전투 배경의 빛은 총구·피격·전기/화염 효과와 구별한다. 밝은 하늘이나 안개 틈도 쓸 수 있으나 적/수치 바로 뒤의 대비를 낮춘다. 세계의 차가운 규모와 작은 생활의 온기가 한 화면에서 함께 읽히는 것이 목표다.

## 가로 전투 화면으로 옮기는 방법

제공된 배경은 모두 세로에 가까운 이미지다. 가로 전투에는 아래 구성을 새로 그린다. 세로 이미지를 단순히 늘리거나 잘라 넣은 결과를 통합 시안으로 삼지 않는다.

1. **원경:** 높은 탑/거대 설비의 일부와 안개를 옅은 명암으로 놓는다. 화면 밖으로 이어지는 형태로 규모를 만든다.
2. **중경:** 가교·배관·옛 주거 통로를 배치한다. 전투 대상 뒤는 큰 면으로 정리하고 일부 구간에서만 디테일을 보여 준다.
3. **전투면:** 주인공과 적이 서는 연속된 실제 발판을 둔다. 발과 접지 그림자의 기준점을 공유하고 좌우 접근 거리를 유지한다.
4. **가까운 전경:** 화면 가장자리의 기둥/케이블 등으로 공간을 감싸되 적·명찰·손패를 가리지 않는다.

산나비에 가까운 도시의 크기는 원경에서 표현한다. 우리 게임의 인물은 탄환 선택과 적 상태를 읽어야 하므로 세로 레퍼런스 속 아주 작은 사람과 같은 화면 점유율을 강제하지 않는다. 기존 전열의 얕은 깊이는 식별용이며 다중 레인 규칙을 새로 추가하지 않는다.

## 현행 임시 화면과의 차이

[최근 QA 전투 캡처](../qa/reports/progression_2026-10-03_assets/first_fight_1008.png)를 비교 자료로 확인했다. 이번에 새 빌드를 렌더한 것은 아니다.

- 주인공과 적의 장비 반사광·작은 내부 묘사가 조밀하다. 새 방향에서는 몸·팔다리·총을 먼저 읽는 큰 형태와 색면을 우선한다.
- 공장 설비가 같은 높이의 수평 띠처럼 보인다. 새로운 배경은 거대한 수직 구조의 일부, 안개 속 먼 공간, 실제 통로를 분리해 깊이를 늘린다.
- 현재의 금속 짐승 실루엣을 모든 생물의 기준으로 삼지 않는다. 기상탑에서 풀려난 생물도 캐릭터와 같은 명암/외곽 처리로 제작한다.
- 사용자가 좋아한 탄환 카드의 큰 탄종 실루엣과 정보 위계를 유지한다. 캐릭터/배경을 다시 정립하는 동안 전투 UI 전체를 동시에 갈아엎지 않는다.

## 첫 통합 시안의 제작 범위

한 장면은 승강장 밖의 폐쇄된 주거 통로로 잡는다. 화면 옆에는 잠긴 큰 셔터와 작은 생활 조명, 뒤에는 상층으로 사라지는 거대한 구조물을 둔다. 주인공과 빠른 생물·장갑 생물·전기 약점 생물 세 종을 같은 발판에 놓고 승인된 탄환 카드와 비교한다. 적 외형은 이번에 별도 레퍼런스가 제공되지 않았으므로 기존 전술 역할과 채택 세계관을 바탕으로 새로 설계할 부분이다.

먼저 인물·적·바닥·배경을 묶은 시안에서 공통 픽셀 밀도와 인물 크기를 비교한다. 이어 Godot의 현재 전투 비율에 넣고, 네 적 동시 등장·같은 거리·증원·명찰·발사 효과·손패 6장 상태를 확인한다. 기존 런타임의 2배 스프라이트 그리기와 발 앵커는 구현 출발점이며 새 스타일을 판단하는 고정 규칙은 아니다. 현재 자료는 JPEG/확대본을 포함하므로 원작의 논리 해상도나 정확한 팔레트 수를 역산해 확정하지 않는다.

실제 제작 자산은 PNG와 일관된 스프라이트 배율로 통합한다. 1008×630, 1280×800, 1440×630에서 흐림·픽셀 두께 변화·명찰 가림·발 위치를 확인한다. 판독성과 스타일이 맞는 통합 장면이 나오면 대기/조준/재장전/피격 동작과 다른 지역을 확장한다.
