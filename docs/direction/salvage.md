# 탄환 회수 — 적에게서 탄을 얻는다

2026-11-11. 사용자: "탄환을 적과의 전투에서 파밍하는 방식은 어떤것 같아" → 디렉터 의견(덱에 바로 넣지 말고 보상 후보로) → "설계문서 및 시험판 진행해 줘".

## 결정 상태

- **사용자 확정(11-11)**: 설계 문서와 시험판을 만든다.
- **디렉터 결정**(시험판, 되돌리기 쉬움): 아래 규칙 전부. 사람 플레이 전.
- **검증되지 않은 가설**: 사람이 원하는 탄을 얻으려고 적을 잡는 순서를 바꾼다.

## 왜

- 한 탄만 쓰는 문제(11-11 피드백)를 보상 구성(섞인 탄 보상)과 다른 쪽, 즉 **전투 안의 결정**으로도 푼다.
- 무판단 사격 측정에서 일반 전투에 결정이 없었다. 누구를 마지막에 잡을지가 결정이 된다.
- 고철을 회수한다는 세계관과 맞다. 처치 숫자 옆에 무엇을 얻는지가 뜬다.

## 규칙 (새 등반, `redesign/salvage.gd`)

1. 적 종류마다 **그 적에게 답이 되는 탄**을 떨어뜨린다.

   | 적 | 특징 | 회수 탄 |
   | --- | --- | --- |
   | 융합 장갑벽 | 높은 장갑 | 철갑탄 |
   | 전도 선체 | 전기 약점 | 전격탄 |
   | 운반 사족체 | 빠른 접근 | **없음** — 거의 모든 전투의 졸개이고 늦게 증원으로 나와, 첫 측정에서 회수 카드의 59%를 차지했다 |
   | 흡수 장갑 구체 | 배리어 | 연타탄 |
   | 신경 교란 부유체 | 충전 | 차단탄 |
   | 압력두꺼비 | — | 소이탄 |
   | 태세 교란 드론 | 교대 장갑 | 우회탄 |

   표의 이름은 종류 이름이다. 구역마다 실제 적 이름은 다르다(예: 노역 인형·재받이는 운반 사족체 종류). 카드에는 실제 적 이름이 붙는다.

2. 이기면 적이 모두 쓰러지므로, **마지막으로 쓰러뜨린 적**(회수 탄이 있는 종류 중)이 회수 카드를 정한다. 원하는 탄이 있으면 그 적을 마지막에 잡는다. 직접 사격·후속 타격·화상으로 쓰러뜨린 것을 모두 센다.
3. **덱에 바로 넣지 않는다.** 일반 전투 보상 3장 중 '다른 공격탄' 칸을 회수 카드가 대신한다(주력과 같은 계열이어도 주력·강화 칸은 그대로). 카드에 '회수 · 적 이름'이 붙고, 고르는 것은 플레이어다.
4. **정예**는 강화된 회수 탄(예: 소이탄 → 압축 소이탄)을 파츠 2택 옆에 한 장 더 내놓는다. 기본 선택은 파츠다.
5. 보스는 회수 탄을 주지 않는다(보스 전리품이 따로 있다). 첫 보상(주력 탄 묶음)도 그대로다.
6. 전투 중 처치 숫자 아래 '처치 · 회수 철갑탄'처럼 그 적의 회수 탄이 뜬다. 전투 도움말에 한 줄.

## 조심할 점

- **덱이 불어나지 않게**: 회수 카드는 보상 카드 하나를 대신할 뿐이다.
- **마지막 처치가 한쪽으로 쏠렸다**: 첫 자동 등반(12회, 회수 137번)에서 운반 사족체가 81번(59%)이었다 → 충격탄만 쌓여 섞는 선택이 오히려 느려졌다(래칫 +13~39%). 운반 사족체를 회수 대상에서 뺐다. 분포는 [검증](../qa/reports/salvage_2026-11-11/README.md).
- 처형·화상 같은 처치 조건으로 더 좋은 탄을 주는 것은 다음 후보다. 숫자가 복잡해지는지 본 뒤 정한다.
