# 탄환 v6 런타임 마이그레이션 워크스루

> 날짜: 2026-07-27
> 결과: Phase 13-3 구현 및 자동 검증 완료

## 적용 결과

라이브 탄환을 v5 27종에서 v6 19종으로 교체했다. 기반탄만 구체 구경을 가지며,
보조·특수·제어 14종은 모든 총기가 사용할 수 있는 범용 계열이다. CSV에는
`caliber/family/trigger/scope/condition`을 분리해 수치와 발동 계약이 한 행에서 읽힌다.

기반 피해는 사전 전수검사 결과인 **3/3/3/4/5**를 적용했다. 시작 패키지는 클래스별
56조합 탐색에서 선택한 `기반 + A×2 + B×1` 구성이며, 샷건은 방패병 대응을 위해
충격탄을 받는다.

## 전투 변화

- 표식·천공의 인접 버프로만 게이트가 열린 발은 `floor(피해×1.5)` 크리티컬.
- 교란·파쇄는 명중 시 적 EVA/DEF를 영구 −2.
- 유도·정렬은 유효 적중 시 잔여 탄창 ACC/PEN +1.
- 연쇄탄은 직전 명중이 아니라 직전 **유효 적중**을 요구.
- 마무리탄은 배율 대신 마지막 발 정액 +4.
- 교차탄은 첫 탄 자동 발동과 범용탄 연속 발동을 차단.
- 관통 저격탄은 주 대상이 유효 적중일 때만 후열을 타격.

크리티컬 판정은 영구 디버프와 잔여 탄창 버프를 기준 상태에 포함한다. 이미 열린
게이트를 인접 버프가 열었다고 중복 보상하지 않는다. 피해 순서는
`탄·총기·탄 조건 → 크리티컬 → 파츠 정액`이다.

## 추가로 막은 지배 전략

v6 충격탄은 구경 무관이라 Suppressor에 5발을 넣으면 한 턴에 10칸 넉백이 가능했다.
연발 한 버스트의 총 넉백을 2칸으로 제한해 거리 잠금만 제거했다. 단발 총과 샷건의
충격탄 1발 가치는 변하지 않는다.

## UI

- 양 게이트가 보조탄 덕에 열리면 적 배지가 금색으로 바뀐다.
- 사격 정보에 `✦ 크리티컬 ⟨게이트 개방⟩ ×1.5`를 표시한다.
- 범용탄이 실패할 경우 `런 덱에서 영구 소실`을 격발 전에 경고한다.
- 실린더와 갤러리는 신규 EVA 감소·잔여 탄창 버프 및 탄환 계열을 표시한다.

## 데이터·현지화 점검

- `bullet_stats.csv`와 `resources/bullets/*.tres`: 19↔19 양방향 일치.
- 프로덕션 스크립트의 v5 탄환 ID: 0건.
- 별도 번역 카탈로그/PO 파일은 현재 프로젝트에 없으며, 한국어 표기명과 설명은
  CSV·리소스 양쪽에서 전수 비교한다.

## 검증

- v6 실전 매트릭스: ACC/PEN 크리티컬, EVA/DEF 영구 감소, 잔여 탄창 버프,
  연쇄·마무리·선제·교차·제어탄 동작 확인.
- #009·#010 통합 회귀 확인.
- 연발 넉백 총 2칸 상한 확인.
- 전체 자동 테스트: 최종 실행 결과는 작업 종료 기록에 함께 보존한다.
