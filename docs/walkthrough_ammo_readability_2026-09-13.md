# 탄환 정보와 단계 학습 개선

사용자가 승인한 [계획](implementation_plan_ammo_readability_2026-09-13.md)의 1~3단계를 Godot에 구현했다. 탄환 기본 수치를 카드에서 비교하고 선택한 발의 실제 피해 근거를 연결한다. 첫 플레이에서는 규칙을 순차 도입한다. 회피의 별도 태세 대안은 사람 피드백 이후 검토한다.

## 실행과 확인

- Windows 검토용 런처: `builds/readability-windows/Play-Readability.cmd`. 별도 `qa-profile`에 저장한다. 이전 비교판 `builds/chain-windows`를 유지한다.
- Godot 프로젝트: `새-게임-프로젝트/project.godot`, 메인 씬 `redesign/main.tscn`.
- 시작 메뉴의 **차근차근 배우기**를 켜면 학습 런, 끄면 일반 런이다. 학습 완주 후에는 다음 새 게임에서 일반 런이 기본 선택된다. 저장 재개/같은 시드 재시도는 해당 런의 모드를 보존한다.
- 개발자 테스트에 첫 강화·장갑/관통·명중/회피 연습을 추가했다. 실제 저장을 덮어쓰지 않는다.
- **APK 제작·갱신·서명·패키징은 하지 않았다. 이후에도 명시 요청이 있을 때만 수행한다.**

## 카드와 계산 영역

카드를 `이름 ×보유 수 / 위력·관통·명중 / 짧은 효과` 순서로 통일했다. 수치는 현재 총기/파츠를 반영하며, 연속탄은 타격당 위력과 2타를 `2×2`처럼 표시한다. 강화탄·조준탄·마무리탄으로 명칭을 정리했다.

장전한 발의 표적 문자, 최종 피해, HP 변화와 위력/강화/장갑/스침 등의 근거를 보유 탄환 아래 공용 영역에 표시한다. 탄환 설명과 계산을 같은 공간에 사용해 발사 버튼을 화면 안에 유지한다. 탄창은 각 발의 결과를 보여 주며 변경된 슬롯을 짧게 강조한다.

카드를 한 번 누르면 추가된다. 확정 전 칸 터치는 회수이며, **계산 보기**를 켜면 회수 없이 원하는 칸의 계산을 선택한다. 확정 후에도 칸 터치로 검사할 수 있다. 마우스는 칸 위에 올려 확인할 수 있다. 계산은 실제 모델 결과에 기록된 `math`를 포맷하며 UI가 별도의 피해 공식을 재구현하지 않는다.

## 단계별 도입

| 교전 | 적과 학습 내용 | 처음 제공하는 탄 |
| --- | --- | --- |
| 1 | 장갑/회피 없는 적, HP·거리·순서와 강화 | 기본 회수탄 + 강화탄 2장 |
| 2 | 장갑·관통·균열 | 균열탄, 파쇄탄 |
| 3 | 장갑 대응 반복과 2회 타격 | 연속탄 |
| 4 | 장갑 없는 회피 적, 명중 보조 | 조준탄 |
| 5 | 두 표적과 밀기·보조 피해 | 충격탄, 도약탄 |
| 6 | 혼합 상황 | 점착탄, 마무리탄 |
| 7 | 배운 연계 종합 | 추가 강제 지급 없음 |

아직 소개하지 않은 방어 축은 초반 적에게 실제로 적용하지 않는다. 해당 카드 수치도 생략하며 전체 수치는 선택형 정보창에서 볼 수 있다. 새 탄은 교전 진입 때 덱에 지급하고 첫 손패에 보장한다. 보상 후보는 배운 탄환 범위 안에서 구성한다. 미래 지급분을 위한 덱 공간도 예약한다. 학습용 작은 덱의 최소 제거 한도는 2장, 일반 런은 기존 6장이다.

일반 런의 시작 덱, 시드별 편성/보상, 피해 공식은 유지했다. 독립 비교에서 일반 10경로의 명령·적 편성·턴·발수가 이전 결과와 같았다. 초기 두 장의 단순한 학습 패는 의도적이며, 일반 런의 무작위 구성을 대체하지 않는다.

## 검증 근거와 한계

- [독립 전투 정산](qa/reports/readability_combat_2026-09-13.md): 5,177 통과 / 0 실패. 정산 근거, 도약/2타/상한, 지급/복원 검사. 보고된 조사 오기 세 곳도 후속 정정했다.
- [독립 캠페인](qa/reports/readability_campaign_2026-09-13.md): 24/24 완주 경로, 실제 명령 2,416개·거절 0, 23,046 assertions 통과. 168회 저장 왕복, `course` 없는 v2 저장 10회 복원. 보상 유지·제거 정책도 검증했다.
- UI 전체 재생: 학습/일반 × 두 총기, 4/4 완주, 442개 버튼 행동, 1,457 검사 통과. 디스크 재개와 전체 행동 기록 대조 포함. `readability_ui_source_2026-09-13.json`에 재생 입력을 보존한다.
- PC 합성 터치: 106 검사 통과. 처음 두 교전, 슬롯 회수/계산, 자동 저장 재개, 회피 연습 숏컷, 5칸 다수전과 두 화면 비율을 확인했다. 처음 발견한 하단 버튼 밀림은 공용 영역 배치 수정 후 재검증했다.
- 최종 전체 회귀·Windows 산출물·독립 화면 검토는 [통합 QA 보고](qa/reports/readability_summary_2026-09-13.md)에 기록한다.

자동 해법의 존재와 검사 통과는 사람의 이해도나 재미 점수가 아니다. 다음 사람 테스트에서는 관통/명중의 대응 대상, 강화 전후 피해, 파쇄 순서 선택 이유를 실제 화면만으로 이해할 수 있는지 확인한다. 장갑/회피가 여전히 반복 계산으로 느껴질 때 후속 회피 태세 실험을 검토한다. 이번 변경은 실제 갤럭시에서 실행하지 않았다.

재현: `tools/run_readability_checks.ps1 -Mode visual|rules|ui_campaign`, 독립 캠페인은 원본 보고 명령 참조. 전체 기존 회귀는 `tools/run_redesign_checks.ps1 -Mode regression`, Windows 내보내기는 `tools/export_windows_readability.ps1`.
