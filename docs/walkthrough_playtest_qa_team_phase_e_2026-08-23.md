# 전용 플레이 QA 팀 Phase E 워크스루

> 완료일: 2026-08-23
> 세션 ID: `codex0823-qa-team-metrics`
> 범위: 네 플레이 프로필, 블랙박스 경험 보고서, 재미 지표와 통합 비교

## 결과

초심자·공격형·보수형·실험형의 선택 원칙을 경험 테스터 reference에 고정했다.
게임 코드는 프로필의 선택을 하드코딩하지 않고, 외부 테스터가 `player_view`를 보고
남긴 예상·이유·포기한 대안·실제 결과만 검증·집계한다.

## 구현

- `QAExperienceReport`: 네 프로필 ID, 시작 조건, 선택 증거와 관찰 계약
- `oracle_state` 재귀 차단과 주요 선택의 예상·이유 누락 검출
- `QAExperienceMetrics`: 선택 집중도, 리로드·무효 행동 비중, 최소 거리, 과잉 피해,
  전술탄 미사용, 파츠·경로 중복률 개별 집계
- `QAProfileComparator`: 동일 시작 조건 검증, 동일 행동열 거절, 쌍별 선택 중복,
  지배 선택의 대안별 격차, 반복 프로필 수에 따른 신뢰도 통합
- `qa_profile_compare_runner.gd`: 네 JSON 원본을 읽어 통합 비교 JSON을 생성하는 헤드리스 실행기

## 판정 경계

- 종합 재미 점수를 만들지 않는다.
- 한´50 프로필의 신호는 `hypothesis`, 세 프로필 이상 반복은 `strong_signal`이다.
- 촉감·애니메이션 속도·장시간 피로는 `human_confirmation`을 유지한다.
- 많이 선택된 항목은 선택 횟수만 보지 않고 밀려난 대안과 격차를 함께 남긴다.

## 검증

- 네 프로필 원본과 시작 조건·선택 증거 유효성 통과
- `oracle_state` 오염과 gameplay seed 불일치 거절
- 프로필명만 다른 동일 행동열 거절
- 3프로필 반복 관찰의 `strong_signal`, 촉감의 `human_confirmation` 유지
- 전체 회귀: **3,541 통과 / 0 실패 / 기존 경보 3**
