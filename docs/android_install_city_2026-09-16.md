# 갤럭시 최신 도시 개편판 설치

파일: **LastOnBoard-city.apk** · 앱: **Last on Board Test** · 버전: **0.3.20260916**

1. APK를 USB 또는 Quick Share로 갤럭시의 다운로드 폴더에 옮긴다.
2. **내 파일 → 다운로드**에서 APK를 눌러 설치한다.
3. 설치 권한을 요청하면 APK를 여는 앱의 ‘출처를 알 수 없는 앱 설치’를 허용한다.
4. **Last on Board Test**를 실행해 가로로 플레이한다.

기존 테스트 앱과 같은 패키지와 테스트 서명으로 업데이트한다. 정상 업데이트는 앱 내부 저장을 유지하며 PC 저장과는 별개다. 최신 규칙을 비교하려면 메뉴에서 무기를 골라 새 등반을 시작한다.

- 보행자: 전탄 연쇄, 기본 주 피해+1.
- 쇄도: 전탄 연쇄, 같은 적 주 타격3회마다 추가 피해4.
- 산개: 전탄 연쇄, 매 탄환 생존 표적 무작위, 기본5칸.
- 압쇄: 전탄 연쇄, 화상 턴당2/전이3.
- 증강: 단발, 기본 피해·관통·효과 강도2배. 매 발 생존 적이 접근한다.

기본 모드는 맵·상점·이벤트·성장·관문을 포함한 5계층35층 등반이다. 메뉴의 ‘탄환 기초 훈련’을 켜면 별도의7교전 훈련이다. 개발자 테스트의 무기별 같은 대열 조합 비교는 일반 도시 저장을 변경하지 않는다.

APK 패키지·서명·정렬은 PC에서 검사하며 실제 기기 실행·성능·발열·터치감은 모바일 플레이테스트에서 확인한다.
