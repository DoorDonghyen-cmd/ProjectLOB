# 전체 도시 런 개편 — 아트 작업 이전 통합 개발

사용자 승인 범위: 기존 제작본의 맵·상점까지 포함한 전체 게임 개발. 규칙과 UI의 재설계는 위임받았다. 가로 화면, Godot, 순서 기반 탄환 조합, 화염의 지속 피해를 유지한다. APK와 원격 푸시는 별도 요청 시 진행한다.

## 범위 대조

| 기존 제작본 | 개편판 통합 방식 |
|---|---|
| 5계층, 6/7/7/7/8층 | 동일한 35층 연속 런. 계층명·고도·노드 이름은 기존 MapGenerator 정본 사용 |
| 분기 맵, 계단/환기구 | 연결된 목적지만 선택. 환기구 비용 −2m는 다음 전투까지 유지, 중첩하지 않음 |
| 탄환/크레딧 드래프트 | 전투마다 탄환 2개 또는 효율 평가 크레딧 중 하나. 유지 선택 제공 |
| 무기고, 리롤, 장비 가방 | 탄환 1개 + 파츠 2개. 방문당 파츠 1개, 리롤 후에도 구매 제한 유지. 보유 파츠 교체·분해 |
| 보급, 정비, 우회 | 특수탄 보급 또는 덱 정제. 우회에서는 전투를 줄이되 환기구 압박 유지 |
| 미지 노드, 단말 이벤트, 로어 | 생성 시 확정한 결과와 스캔 힌트. 정확한 비용을 공개하는 선택 이벤트, 20개 기록 수집 |
| 보스와 계층 전환 | 각 계층 관문, 중간 승강기에서 탄창 확장/크레딧 중 선택. 최종 코어와 완주 정산 |
| 영구 데이터, 승천 | 기록실, 누적 전술 데이터, 시작 탄환 선택 해금과 난도 0~10. 통합 저장으로 중복 정산 방지 |
| 개발자 테스트 | 맵·상점·이벤트·보급·계층 전환·기록실 바로가기. 실제 진행 저장 보존 |

기존 27탄종·명중/회피·구경 제약은 새 간결한 전투 규칙으로 대체한다. 기존 7교전 학습 모드는 별도로 유지한다. 기존 제작본과 실험판의 저장 파일은 보존한다.

영구 HP·가방 레벨·총기 8종 해금 대신 현재 두 총기와 네 시작 덱 성향으로 정리한다. 구역 잠금으로 첫 완주를 끊지 않고 35층을 연속으로 제공한다. 5관문 전투는 간결한 HP·장갑·속도·호위 편성으로 구성하며, 최종 아트의 보스 스프라이트는 후속 단계다.

## UI 와이어프레임 (1280×800 및 작은 가로 뷰포트)

### 맵
```text
┌ LAST ON BOARD / 침전 거주구 / 03·35 ─ Cr 28 ─ [덱] [기록] [메뉴] ┐
│        6F             ◆ 승강기 관문                            │
│        5F       ○ 전투 ───── ○ 우회                             │
│        4F             ▣ 고물상                                 │
│        3F       ▢ 보급 ───── ○ 배관 미로                         │
│        2F       ● 현재 ───── ? 비공개 구획                       │
│        1F       ✓ 방문 ───── ○ 미선택                           │
├ [보급 / 계단·무료]            [배관 미로 / 환기·다음 전투−2m]   ┤
│ 노드를 선택하면 즉시 이동. 밝은 연결선으로 갈 수 있는 방 표시    │
└───────────────────────────────────────────────────────────────┘
```
맵 도형을 Godot에서 그리며, 목적지 카드는 실제 버튼으로 만든다. 상단은 요약, 상세 정보는 선택 가능한 별도 창. 회전은 가로 유지.

### 상점
```text
┌ 고물상 / Cr 38 ─ 현재 장착: 가속 총열                         ┐
│ [탄환 아이콘·두 수치]   [열축전 코일]   [회수 가속기]          │
│ [12Cr 구매]             [30Cr 구매]    [30Cr 구매]            │
│ [진열 갱신 · 3Cr]       파츠는 이번 방문에 1개                │
├ 보유 파츠: [장착/교체] [장착/교체]   [분해·+10Cr]             ┤
└ [맵으로 계속]                                                ┘
```
확장 탄창은 관문 성장 보상으로 제한. 구입은 유효성 검증 후 원자적으로 처리. 구매한 품목은 저장·재시작·리롤로 복제되지 않는다.

### 이벤트 / 보급 / 승강기
```text
┌ 방 이름 ─ 한 문장의 상황 설명                               ┐
│ [확정 이득 / 정확한 비용] [다른 선택 / 정확한 비용] [통과]     │
│ 선택 완료 시 결과 한 줄 → [맵으로 계속]                      │
└──────────────────────────────────────────────────────────────┘
```
이벤트는 숨은 확률 판정 없이 예고된 교환. 정제는 선택한 탄환 1장 제거, 최소 6장 유지.

## 구현 구조

- 기존 Combat Model은 결정론적 전투와 학습의 책임 유지.
- Campaign은 35층 경로, 지갑, 보유 파츠, 노드 처리와 프로필 정산 책임. 하나의 통합 저장 안에 전투 상태와 프로필 포함.
- CampaignContent는 생성된 노드·상점·이벤트·관문 전투의 정본. 생성 RNG는 저장된 시드와 노드 ID로 분리.
- MapView는 건물 단면과 연결선, CampaignUI는 비전투 화면을 담당.
- 공격 결과를 Campaign에 전달할 때는 실제 적 HP와 phase로 검증. 보상 화면 재진입·로드로 이중 지급하지 않음.

## 검증과 납품

모든 노드·통로·예산·보상·중복 입력·저장/복원·기록·승천의 규칙 테스트. 여러 시드/두 총기의 실제 명령 기반 전체 런 완주 및 UI 재생. 개발자 바로가기를 통한 화면 캡처·작은 가로 화면 검증·저장 보존. 기존 탄환 규칙과 학습 회귀. Windows 플레이 파일 갱신 및 로컬 커밋, 작업 로그·워크스루 기록.

## 전체 런 이후 경제 조정

크레딧 선호 자동 플레이에서 완주 잔액393~410Cr을 확인하여 전투 배급 기준을24Cr에서12Cr으로 낮췄다. 현재 배급은 `max(8, 12 + 계층 - 초과 사격 - 초과 시간 - 난도)`다. 전투 보상을 대신 쓰는 정제와 상점 유료 정제12Cr(방문당 한 번)를 제공한다. UI는 기존 보상 하단에 정제 버튼, 상점 갱신 아래에 유료 정제 버튼을 배치하고, 선택 창에서는 탄종·장수·1장 제거만 표시한다. 구매·정제의 지갑 변경은 검증 후 동시에 반영한다.

## 6칸 탄창 가독성 마감

실제 6칸 탄창 캡처에서 표적/피해/남은 HP를 한 줄에 넣으면 옆 칸을 침범했다. 좁은 칸에서는 `탄환 아이콘 / 짧은 이름 / A −2 / HP14 / ×2`처럼 피해와 결과를 두 줄로 분리한다. 증폭·화상·전이는 짧은 수치 표기로 바꾸고, 전체 설명은 기존 칸 선택 계산창을 유지한다. 실제 재생 상태를 사용하는 레이아웃 전용 QA와 폰 가로 캡처로 확인한다.
