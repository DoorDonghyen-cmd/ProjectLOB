# 격발 입력 잠금·총기별 연출 템포 구현 계획

> 날짜: 2026-08-15
> 세션: `codex0815-fire-pacing`
> 상태: 완료

## 1. 목표

단발 총기의 발사 버튼을 빠르게 연타했을 때 첫 탄의 피격 결과가 보이기 전에 여러 턴이 선계산되어 연발처럼 느껴지는 문제를 해소한다. 실제 전투 턴과 대미지는 바꾸지 않고, 플레이어가 한 번의 격발 결과를 확인한 뒤 다음 행동을 선택하게 한다.

## 2. 설계 원칙

- 전투 정산은 기존처럼 동기식·결정론적으로 유지한다.
- 격발 연출 큐가 재생되는 동안 발사·빼내기·재장전·이젝트를 잠근다.
- 버튼 비활성화와 액션 핸들러 재진입 검사를 함께 적용한다.
- 잠금 중 입력은 버퍼에 저장하지 않으며 자동 재실행하지 않는다.
- 총기별 시간은 표시 전용이며 턴 수, 적 전진, 피해량, 리로드 비용을 바꾸지 않는다.

## 3. 표시 템포

### 단발 최소 입력 잠금

| 총기 | 시간 |
|---|---:|
| Gambler | 0.32초 |
| Revolver / Trickster | 0.34초 |
| Stance Hunter | 0.42초 |
| Heavy | 0.44초 |
| DMR | 0.48초 |
| Shotgun | 0.52초 |

### 연발

| 총기 | 발 사이 간격 | 마지막 탄 이후 판독 여운 |
|---|---:|---:|
| Tempo | 0.13초 | 0.18초 |
| Suppressor | 0.20초 | 0.18초 |

## 4. 구현 범위

1. `CombatOverlayV2`에 총기 ID 기반 표시 템포 정본을 추가한다.
2. 연출 중 액션 버튼을 일괄 비활성화하고 네 액션 핸들러에 재진입 방어를 추가한다.
3. 탄환 도착 뒤 적 이동 갱신을 시작하고 최소 표시 시간이 지난 뒤 입력을 다시 연다.
4. UI 스모크 테스트에 총기별 값, 버튼 잠금, 탄창·상태 불변, 잠금 해제 계약을 추가한다.
5. 발사 방식 GDD와 전투 UI/UX 정본을 동기화한다.

## 5. 검증 기준

- 연출 중 반복 호출이 탄창을 추가 소비하지 않는다.
- 연출 중 반복 호출이 재장전 또는 다음 턴 상태를 선계산하지 않는다.
- 연출 종료 후 정상적으로 다음 발사가 가능하다.
- Tempo와 Suppressor가 서로 다른 내부 연발 간격을 사용한다.
- 전체 자동 테스트가 실패 없이 통과한다.
