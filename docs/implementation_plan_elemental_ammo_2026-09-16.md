# 탄환 규칙 단순화 및 3속성 개편 계획

상태: 구현·자동 검증·Windows 검토 빌드 완료. 사람 플레이 체감 확인만 남음. `prototype/core-redesign`의 아이콘 카드판을 기준으로 구현했다.

## 목표

탄환의 공통 판단 축을 `피해·관통` 두 숫자로 줄이고, 속성은 피해가 작동하는 방식을 알려 주는 세 분류로 한정한다. 전투의 깊이는 수치 종류가 아니라 발사 순서, 적과의 거리, 단일전·다수전 선택에서 만든다.

## 전투 규칙

### 공통 계산

```text
남은 장갑 = max(0, 장갑 - 관통)
타격 피해 = max(1, 피해 + 총기 보정 + 증폭 - 남은 장갑)
```

- 명중·회피·조준·스침·균열·파쇄·둔화를 제거한다.
- 적의 공개 정보는 `HP·장갑·거리·접근`만 사용한다.
- 속성 저항·약점·확률 판정은 도입하지 않는다.
- 모든 탄환은 속성 하나와 특수 효과 최대 하나만 가진다.

### 세 속성

| 속성 | 역할 | 고정 의미 |
| --- | --- | --- |
| 물리 | 즉시 해결·장갑·거리 | 높은 피해/관통 또는 넉백. 별도 지속 상태 없음 |
| 화염 | 시간에 따른 피해 | 적의 전진 직전에 화상 1피해, 화상 수치 1 감소. 화상으로 죽으면 전진하지 않음 |
| 전기 | 다수 적 대응 | 주 표적 적중 뒤 가장 가까운 다른 생존 적에게 고정 피해 전이 |

화상 수치는 남은 총피해와 남은 발동 횟수를 동시에 뜻한다. `화상 3`은 최대 3번, 각 1피해다. 소이탄을 더 맞히면 수치를 더하며 상한은 6이다.

### 탄환 7종

| 내부 ID | 표시명 | 속성 | 피해/관통 | 효과 |
| --- | --- | --- | ---: | --- |
| `basic` | 회수탄 | 물리 | 4/0 | 재장전 시 공급 상한까지 복구 |
| `pierce` | 철갑탄 | 물리 | 3/3 | 없음 |
| `push` | 충격탄 | 물리 | 2/0 | 2m 넉백, 탄창당 총 2m |
| `bore` | 소이탄 | 화염 | 2/1 | 생존 표적에게 화상 +3 |
| `charge` | 증폭탄 | 물리 | 1/0 | 다음 2발의 타격당 피해 +2 |
| `precise` | 연발탄 | 물리 | 2/0 | 같은 적을 2회 타격 |
| `arc` | 전격탄 | 전기 | 3/1 | 가장 가까운 다른 적에게 고정 2피해 |

`mark`, `slow`, `finish`는 신규 덱·보상에서 제거한다. 이전 v2 저장은 v3로 읽을 때 `mark→charge`, `slow→push`, `finish→pierce`로 변환하여 덱 장수를 보존한다.

### 파츠

- `lens`는 **가속 총열**로 바꾸고 모든 탄환 관통 +1.
- `coil`은 **열축전 코일**로 바꾸고 소이탄 화상 +1.
- 회수 가속기와 확장 탄창은 유지한다.

## 학습 순서

1. 피해와 증폭
2. 장갑과 관통
3. 화상과 전진 직전 피해
4. 연발과 증폭 조합
5. 넉백과 거리 확보
6. 전기와 다수 적
7. 전체 조합

각 단계에서 아직 배우지 않은 탄환은 보상에 등장하지 않는다. 장갑은 2단계부터 공개한다. 화상·전이는 등장하는 즉시 전장과 계산 설명에서 같은 용어로 표시한다.

## UI 요청 제작안

### 탄환 카드

```text
┌──────────────────────┐
│ ◇ 소이탄 ×2       🔥 │  이름 / 수량 / 속성 배지
│ [충격 2] [방패↗ 1]  │  피해 / 관통 두 칸 고정
│ 🔥 화상 +3           │  특수 효과 한 줄
└──────────────────────┘
```

- 카드의 공통 숫자는 피해와 관통 두 개만 표시한다.
- 우상단 속성 배지는 물리 회백색, 화염 주황, 전기 청록으로 통일한다.
- 효과 행은 `화상 +3`, `전이 2`, `밀기 2m`, `다음 2발 +2`, `2회 타격`처럼 결과만 쓴다.
- 철갑탄처럼 별도 효과가 없으면 효과 행에 `물리 · 장갑 대응`을 표시한다.
- 선택 카드 아래 공용 설명은 `피해 → HP   관통 → 장갑` 한 줄과 선택 탄환 설명만 유지한다.

### 적과 전장

```text
A · 융합 장갑벽  HP 12
장갑 3   접근 1m   🔥화상 2
거리 8m
```

- 회피·균열·둔화 표시는 모두 제거한다.
- 화상 상태는 불꽃 아이콘과 남은 수치로 적 옆과 상세창에 표시한다.
- 화상 발동 시 전진 애니메이션보다 먼저 주황 펄스와 `화상 −1` 피해 숫자를 재생한다.
- 전격탄 전이는 청록 선과 `전이 −2`로 표시한다.

### 규칙·보상·개발자 테스트

- 규칙 창을 새 계산식과 세 속성 설명으로 전면 교체한다.
- 보상 카드도 동일한 두 수치와 속성 배지를 사용한다.
- 메인 메뉴 `개발자 테스트`에 `3속성 탄환 전체`와 `화상 전진 정산` 숏컷을 제공한다. 두 숏컷 모두 실제 장전·발사와 저장 보존을 지원한다.

## 검증 기준

1. 전투·보상 카드 어디에도 명중·회피 수치가 남지 않는다.
2. 모든 탄환은 피해·관통·속성 하나·효과 최대 하나로 검사된다.
3. 화상은 각 적 전진 직전에 1피해를 주고 사망한 적의 이동을 막는다.
4. 전기는 살아 있는 가장 가까운 다른 적 하나에게만 고정 2피해를 준다.
5. 증폭과 연발은 타격당 계산을 유지하고 예측과 실제 결과가 일치한다.
6. v2 저장은 v3로 원자적으로 변환되며 무효 저장은 현재 상태를 바꾸지 않는다.
7. 1280×800과 1920×864에서 카드·화상·전이 표시가 겹치지 않는다.
8. 두 총기, 학습/일반 런, 보상·교환·재장전·저장 복원이 자동 검증을 통과한다.
9. Windows 검토 빌드와 기동 검사를 갱신한다. APK는 명시 요청 전까지 작업하지 않는다.
