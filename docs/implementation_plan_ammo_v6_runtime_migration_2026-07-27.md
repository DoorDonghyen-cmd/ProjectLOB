# 탄환 v6 런타임 마이그레이션 구현 계획

> 날짜: 2026-07-27
> 범위: Phase 13-3 — 승인된 19종 후보를 라이브 전투·UI·경제에 적용

## 목표

- v5 27종을 기반5/보조6/특수6/제어2의 v6 19종으로 교체한다.
- 구경과 카드 계열을 분리해 범용탄이 권총으로 폴백되는 데이터 오류를 막는다.
- 결정형 크리티컬, 영구 EVA/DEF 디버프, 탄창 잔여 버프, 교차구경 기억을 구현한다.
- 실패 시 영구 소실과 크리티컬 여부를 커밋 전에 UI에 표시한다.
- #009 흡수체 유효 적중과 #010 태세 사냥꾼 주기 계약을 먼저 수리한다.

## 구현 단계

1. **전투 계약 수리**
   - 배리어 셀은 피해 1 이상에서만 차감.
   - 태세 사냥꾼은 `shot_counter + 1 >= stance_shift_interval`을 사용.

2. **데이터 계약**
   - CSV 13열 → 17열.
   - `class`를 `caliber`와 `family`로 분리.
   - `trigger/scope/condition`으로 발동 문법을 명시.
   - `BulletEffect` 9~11 추가.

3. **리소스 마이그레이션**
   - v5 `.tres` 27종 삭제.
   - v6 19종을 CSV와 완전 일치하도록 생성.
   - 시작 패키지와 무기고 후보를 새 ID로 교체.

4. **전투 구현**
   - 다음 1발 ACC/PEN +3.
   - 적 EVA/DEF 영구 −2.
   - 잔여 탄창 ACC/PEN +1.
   - 결정형 크리티컬 `floor(×1.5)`.
   - 범용탄이 구경 기억을 덮지 않는 교차탄.
   - 관통 저격탄은 주 대상 유효 적중 때만 후열 타격.

5. **밸런스 안전장치**
   - Gambler 패시브 +2 삭제, 깊이 `floor(depth/2)`.
   - Suppressor 리로드 4턴.
   - 구경 무관 충격탄 도입에 따라 연발 버스트 총 넉백 2칸 상한.

6. **UI·검증**
   - 금색 크리티컬 배지와 `⟨게이트 개방⟩` 태그.
   - 실패 시 범용탄 런 덱 영구 소실 경고.
   - 19종 집합·계열·시작 패키지·삭제 ID·실전 효과 회귀.
   - v5 LIFO JSON은 역사 자료로만 보존.

## 완료 조건

- 전체 Godot 자동 테스트 실패 0.
- CSV와 `.tres` 각각 정확히 19종.
- 일반 적 해법과 시작 패키지 사전검증 기준 유지.
- 프로덕션 코드에 삭제된 v5 ID가 남지 않음.
