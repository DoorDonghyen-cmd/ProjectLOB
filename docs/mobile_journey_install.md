# ORVASK — 첫 관문 연속 여정 테스트

1. 받은 ZIP을 ‘내 파일’에서 압축 해제하고 `LastOnBoard-city.apk`를 설치합니다. 기존 `Last on Board Test`가 있으면 삭제하지 않고 업데이트합니다.
2. 앱을 가로로 열면 최신 전투 UI의 첫 관문 여정으로 들어갑니다. 여정 기록이 있으면 마지막 자동 저장부터 이어집니다. 본편과 독립 전투 비교의 저장은 따로 유지됩니다.
3. 사격·냉각·탄창 교체로 전투를 진행합니다. 탄을 누르고 **1발/2발 빼내기**를 누르면 선택한 탄이 빠집니다. 같은 탄이나 빈 곳을 누르면 선택을 취소할 수 있습니다.
4. 승리 후 코어와 특수탄을 고르고 두 차례 정비를 거쳐 총 다섯 전투를 진행합니다. 보상을 고르기만 해서는 바뀌지 않으며 아래 확정 버튼을 눌러야 적용됩니다.
5. **메뉴 → 재도전**은 현재 전투에 들어왔을 때의 덱·탄 순서로 돌아갑니다. **메뉴 → 새 출발**은 총기를 골라 처음부터 시작합니다. 첫 관문을 돌파하면 이번 여정이 끝납니다.

사용하거나 빼낸 탄은 현재 전투에서 소모되고 다음 전투에 복구됩니다. 획득한 탄과 성장 코어는 다음 전투까지 이어집니다. 행동·보상·정비마다 자동 저장합니다.

보상을 얻은 뒤 선택이 달라지는지, 탄을 빼거나 그대로 쏜 이유, 반복되거나 긴장됐던 구간을 자유롭게 알려 주세요. 화면이 끊기거나 기기가 뜨거워지면 기종과 대략의 플레이 시간·당시 화면을 함께 알려 주시면 도움이 됩니다.

이 모드는 첫 관문까지의 연속 플레이용입니다. 전체 본편 등반·상점 경제를 검증한 빌드는 아니며, 실제 기기의 지속 성능·발열·터치는 별도 확인이 필요합니다. 지원 기기 종류는 아래 패키지 표기를 따릅니다.
