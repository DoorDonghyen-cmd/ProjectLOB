# 저체력 다수전·증원·전투 UI 개편 계획

상태: **완료**  
대상: `prototype/core-redesign`의 5계층 35층 도시 등반  
승인 근거: 2026-09-21 사용자가 전열을 처치하면 후속 적이 등장하는 방향과 UI/UX를 포함한 최적화 구현을 요청함

## 목표

적 한두 마리의 체력을 오래 깎는 전투를, 여러 저체력 적을 올바른 순서로 끊어 내고 공개된 증원까지 계산하는 전투로 바꾼다. 탄환 순서, 과잉 피해, 화상과 전이, 무기별 표적 규칙이 한 교전 안에서 반복해서 의미를 갖도록 한다.

## 확정 규칙

- 화면에 동시에 배치되는 전열은 최대 4기다.
- 교전 총 규모는 진행도에 따라 2~8기이며, 첫 교전은 2기부터 시작한다.
- 행동 정산 후 살아 있는 전열이 2기 이하이면 대기열에서 최대 4기까지 보충한다.
- 증원 구성과 순서는 교전 시작부터 공개한다.
- 새로 배치된 적은 그 행동에서 이동하거나 능력을 발동하지 않는다.
- 전열을 모두 처치해도 대기열이 남아 있으면 전투는 끝나지 않는다.
- 보스는 첫 전열의 중심으로 등장하고 저체력 호위가 뒤를 잇는다.
- 증강은 한 발씩 쏘되 처치에 성공한 동안 같은 행동에서 다음 탄을 이어 쏜다. 처음 살아남은 적에서 연쇄가 끝난다.

## UI/UX 작업

- 전장을 화면 너비 전체로 확장하고 적 목록 패널의 중복 정보를 제거한다.
- HP 막대, 현재 HP, 거리, 접근량과 핵심 상태를 적 실루엣 가까이에 직접 배치한다.
- 전장 오른쪽 위에 증원 실루엣과 수량을 항상 보여 주고 터치하면 상세 편성을 연다.
- 예상 결과는 `처치 · 전열 · 증원 · 최근접` 한 줄로 요약한다.
- 상단 상태는 무기/탄창, 턴, 전열, 증원, 크레딧, 압축 코어만 유지한다.
- 탄환 후보 높이와 단계 안내를 줄여 휴대폰 화면 첫 장에 계산·확정·발사·재장전이 들어오게 한다.
- 지도 노드 상세에도 전열/증원/총 규모와 전열 카드, 증원 순서를 분리해 보여 준다.

## 완료 조건과 결과

1. 전열 최대 4기와 최대 8기 규모가 저장·복원·예상 계산에 모두 반영됨.
2. 전열 2기 이하에서 증원이 들어오며, 그 행동에는 이동하지 않음.
3. 다섯 무기가 새 교전 구조에서 완주 가능함.
4. 1008×630 휴대폰 비율에서 전열 4기, 증원, 탄창, 주요 행동이 판독 가능함.
5. 기존 저장은 v7로 변환되고 현대 회귀 묶음이 통과함.

결과: 기계 검증 3,730/0, 다수전 규칙 142/0, UI 20/0, 적 규칙 27/0, 무기 규칙 3,192/0, 압축 밸런스 264/0을 통과했다. 대표 시드 731042에서 다섯 무기 모두 안전/혼합 35층 경로를 완주했다.
