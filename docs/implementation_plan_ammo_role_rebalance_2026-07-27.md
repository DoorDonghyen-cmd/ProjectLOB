# 탄환 역할 단순화 및 조합 밸런스 재조정 구현 계획

> 작성일: 2026-07-27
> 사용자 승인: 2026-07-27
> 대상: Phase 12 탄환 확장 잔여 작업

## 1. 목표

- `독립/셋업/페이로드/유틸` 4역할을 `공격/연계/제어` 3역할로 단순화한다.
- 공격탄은 일반 적에게 단독으로 작동하고, 연계탄은 고회피·중장갑 적까지 대응 범위를 넓힌다.
- LIFO, 결정론적 명중·관통 게이트, 다음 1발 버프, 연발 전탄 커밋 규칙은 유지한다.
- 문서의 페이로드 폐기 방향과 실제 CSV·리소스·UI의 불일치를 해소한다.

## 2. 데이터 변경

| 기존 역할 | 신규 역할 |
|---|---|
| `standalone` | `attack` |
| `payload` | `attack` |
| `setter` | `link` |
| `utility` | `control` |

1차 수치 조정:

| 탄환 | 기존 | 변경 |

| 9mm 고압탄 | DMG 6 / ACC 2 | DMG 5 / ACC 5 |
| .45ACP 과부하탄 | DMG 5 / ACC 3 | DMG 4 / ACC 5 |
| 5.56mm 중격탄 | DMG 7 / PEN 0 | DMG 5 / PEN 2 |
| 7.62mm 작렬탄 | DMG 9 / ACC 3 / PEN 0 | DMG 7 / ACC 5 / PEN 2 |
| 12게이지 밀집탄 | DMG 7 / ACC 4 | DMG 5 / ACC 5 |

## 3. UI 변경

- 모든 역할 배지를 `[공격]`, `[연계]`, `[제어]`로 통일한다.
- 기존 `standalone/setter/payload/utility` 값은 신규 역할로 안전하게 정규화한다.
- 연계탄은 `⬇ 명중 열기` 또는 `⬇ 관통 열기`를 유지한다.
- 공격탄의 조건부 효과는 역할이 아니라 툴팁 설명으로 유지한다.
- 실린더, 가방, 드래프트, 교체 목록, 갤러리에서 같은 정본을 사용한다.

## 4. 검증

- CSV와 27개 `.tres`의 역할·수치 완전 일치.
- 역할 분포: 공격 17 / 연계 8 / 제어 2.
- 일반 적 단독 공격, 고회피 명중 연계, 중장갑 파쇄·관통 연계를 몬스터 실데이터로 검증.
- Tempo와 Suppressor 연발 화력, 오버킬 이월, 버프 소비 규칙 회귀.
- 전체 Godot 테스트 및 씬 로드 0 실패.
