# 첫 구역 이후 35층 연속 상승 복구 워크스루

> 세션: `codex0728-continuous-ascent`
> 완료일: 2026-07-28

## 결과

첫 구역 보스를 처치하면 공역이 즉시 해금되고, 계층 전환 연출의 `계속 오른다 ▲`를 통해 같은 런으로 이어진다. 계층 경계에서는 `start_new_run()`을 다시 호출하지 않으므로 덱·파츠·가방·크레딧이 유지된다.

## 주요 변경

- `RunManager.run_itinerary()`와 `total_run_length()`를 고정 5계층·35층 계약으로 교정
- `get_next_section()`을 추가해 잠금 상태와 런 진행 목적지를 분리
- `_advance_floor_or_finish()`에서 다음 계층 즉시 해금 후 연속 진입
- 지도 조기 종료 상한 마커 제거
- 상승 브리핑을 항상 `35층 · 보스 5체 · 정점까지`로 표시
- 디브리핑을 사망·정점 종료로 단순화
- GDD 01·08·20 및 자동 회귀 정합

## 자동 검증

- Godot 4.7: **2,300 통과 / 0 실패 / 기존 경보 3**
- 첫 관문→공역 진입, 공역 해금, 덱·가방·크레딧 유지, 디브리핑 미표시를 메인 씬으로 검증
- 70개 스크립트 컴파일 및 4개 씬 로드 성공

## 다음 수동 확인

공역까지 이어서 플레이하며 첫 구역에서 얻은 탄환이 다음 계층에서 실제 빌드 정체성으로 발전하는지 확인한다. 이후에도 빌드 감각이 약하면 첫 드래프트 빌드 시드와 후속 친화 가중을 적용한다.
