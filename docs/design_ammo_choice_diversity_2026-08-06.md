# 조합탄 선택 편향 진단 및 개선 순서

> 상태: 1·2·3단계 구현 완료 / 이후 실전 텔레메트리 재확인

## 결론

조합탄 중 일부만 반복 사용하는 것은 플레이어의 선택 실수보다 **시작 교육과 보상 구조가 관통 축을 정답처럼 학습시키는 문제**에 가깝다. 즉시 약한 탄의 수치를 올리기보다 다음 순서가 안전하다.

1. 효과 범위와 현재 전투 기여를 UI로 설명한다.
2. 드래프트가 서로 다른 운용법을 비교하도록 후보 구성을 바꾼다.
3. 시작 패키지의 중복 탄을 세 가지 역할로 분산한다.
4. 그래도 선택률이 낮은 탄만 결정론 시뮬레이션 후 수치를 조정한다.

## 확인된 구조적 원인

### 1. 시작 패키지 편향

메타 백팩 0 기준 다섯 클래스의 시작 전술탄은 총 15발이다.

| 탄환 | 수량 | 비중 |
| :--- | ---: | ---: |
| 천공탄 | 10 | 66.7% |
| 파쇄탄 | 3 | 20.0% |
| 표식탄 | 1 | 6.7% |
| 충격탄 | 1 | 6.7% |

- 천공+파쇄가 **13/15발(86.7%)**, 연계 역할 전체가 **14/15발(93.3%)**이다.
- 현재 패키지는 첫 무기고 전 모든 해법을 보장하지만, 그 안전성을 위해 관통 조합을 반복 학습시킨다.

### 2. 보상은 무작위지만 비교는 무작위가 아니다

- 전투 보상은 공용 전술탄 14종에서 중복 없이 2장을 뽑고 크레딧 카드와 함께 제시한다.
- 비활성 컨버전 가중치가 없을 때 특정 탄 한 장의 전투당 노출 확률은 `2/14 = 14.3%`다.
- 보유 수량이나 효과 범위를 고려하지 않으므로 익숙한 탄을 더 집고, 필요한 보완 탄은 오래 보지 못할 수 있다.

### 3. 서로 다른 6종이 UI에서는 모두 `[연계]`다

실제 기능은 세 종류다.

| 운용 | ACC 축 | PEN 축 | 적합한 상황 |
| :--- | :--- | :--- | :--- |
| 다음 1발 +3 | 표식 | 천공 | 즉시 게이트 개방·결정형 크리티컬 |
| 대상 영구 −2 | 교란 | 파쇄 | 보스·장기 교전 |
| 잔여 탄창 +1 | 유도 | 정렬 | 긴 탄창·연발 |

역할 배지만 보면 이 차이가 전투 전에 드러나지 않는다. 특히 이진 게이트에서 `+1`은 정확히 한 칸 부족할 때만 가치가 생겨, 기여 예고가 없으면 약해 보인다.

### 4. 총기별로 한 축이 실제 정답이 된다

- Workhorse 경량탄은 ACC 8이고 공용 전술탄에는 ACC +1 프로필이 있어 대부분의 적에게 명중한다.
- 반면 기본 PEN 1은 방패병·흡수체·보스 방어를 넘지 못한다.
- 따라서 Workhorse 런에서 천공·파쇄가 반복 선택되는 것은 현재 데이터상 합리적인 최적해다.

## 권장 구현 순서

### 1단계 — 연계 범위 배지와 기여 예고 ✅ 완료 (2026-08-09)

- `[다음 1발]`, `[대상 지속]`, `[잔여 탄창]` 배지를 드래프트·가방·적재 카드에 추가한다.
- 적재 화면에는 `명중 전환 2발`, `관통 전환 3발`, `현재 대열 효과 없음`처럼 실제 게이트 변화 수를 표시한다.
- 수치를 바꾸지 않고도 왜 이 탄을 써야 하는지 읽을 수 있어 가장 먼저 적용할 가치가 높다.

### 2단계 — 드래프트 후보 다양성 ✅ 완료 (2026-08-09)

- 두 탄환 카드가 같은 효과 범위만 나오지 않도록 서로 다른 범위를 우선 제시한다.
- 보유 중인 동일 탄 수량이 많을수록 추첨 가중치를 낮추되 완전히 금지하지 않는다.
- 권장 가중치 후보: `max(1, 3 - 보유 수량)`. 의도적 집중 빌드는 남기면서 새 조합 노출을 늘린다.
- 연계탄 보유·결산탄 미보유 시 연쇄탄/교대탄 중 1장을 첫 후보로 보증해 결산 구조를 실제로 접할 수 있게 했다.
- 상세 구현과 검증 결과: `docs/implementation_plan_ammo_payoff_cadence_2026-08-09.md`

### 3단계 — 시작 패키지·전문축 재검증 ✅ 완료 (2026-08-15)

- 운용 분류와 별도로 화력/관통/명중/제어 전문축을 도입하고 카드 첫 배지에 노출했다.
- 시작 패키지를 기반탄의 전문축과 상호 보완하도록 재배치했다. 소총은 흡수체 대응을 위해
  `천공+연쇄`, 산탄은 구경 PEN −1을 고려해 `파쇄+충격`을 유지한다.
- 9총기×13적, 기본/환기구 거리 234개 대진에서 첫 탄창 유효 대응 해법 0건 실패를 확인했다.
- 상세 구현과 검증 결과: `docs/implementation_plan_ammo_stat_specialization_2026-08-15.md`

### 4단계 — 마지막으로 수치 조정

- 1~3단계 이후 텔레메트리에서 특정 탄 선택률·유효 기여가 계속 낮을 때만 조정한다.
- 우선 검토 대상은 `잔여 탄창 +1` 계열이다. +2 상향은 긴 탄창 전체를 뒤집을 수 있으므로 연발·보스·환기구 조건을 함께 시뮬레이션한다.

## 중단 조건

- 특정 탄을 강제로 쓰게 하려고 적 DEF/EVA를 올리지 않는다. 이진 게이트라 난이도가 계단식으로 폭증한다.
- 동일 탄 보유를 하드 제한하지 않는다. 의도적인 집중 빌드까지 제거할 수 있다.
- 신규 탄을 추가하지 않는다. 현재 14종의 쓰임과 설명을 먼저 완결한다.
