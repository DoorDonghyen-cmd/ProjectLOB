# 개발자 테스트 전체 데이터 초기화 구현 계획

## 목표

반복 플레이테스트 중 누적된 현재 런과 영구 진행 데이터를 한 번에 지우고, 게임을 처음 실행한 상태에서 다시 검증할 수 있게 한다.

## 구현 범위

1. `RunManager`에 영구 메타와 현재 런을 각각 기본값으로 복원하는 단일 진입점을 둔다.
2. 기존 `user://meta_save.cfg`를 삭제하고, 삭제할 수 없는 환경에서는 기본값 세이브로 덮어쓴다.
3. 메인 화면의 개발자 테스트 패널에 위험 색상의 `전부 초기화` 버튼과 확인 대화상자를 추가한다.
4. 초기화 직후 열린 런·갤러리·준비 화면을 닫고 메인 화면과 메타 상점 표시를 갱신한다.
5. 저장/로드 회귀와 UI 스모크 테스트에서 초기화 범위 및 확인 절차를 고정한다.

## 초기 상태 계약

- 영구: 100 Cr, 기본 무기 `workhorse`, 첫 계층 `section_a`, 승천 0, 침투 위험도 1
- 런: 1층·첫 계층, 크레딧 0, 아머 1, 덱·가방·파츠·맵·통계 비움
- 세이브: 기존 파일 삭제. 삭제 실패 시 위 기본값으로 저장

## 안전장치

- 개발자 테스트 메뉴에서만 노출한다.
- 확인 대화상자에서 되돌릴 수 없는 범위를 명시한다.
- 취소 시 어떤 데이터도 변경하지 않는다.
