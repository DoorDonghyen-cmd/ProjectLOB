# 아트 이전 완성형 체험판 개발 계획

## 요청과 목표

사용자는 외출 중에도 개발을 계속 진행하도록 위임했으며, APK 제작과 원격 푸시는 별도 요청 전까지 제외한다. 이번 작업은 현재의 핵심인 **탄환을 왼쪽부터 순서대로 조합해 피해를 증폭하는 결정론 전투**를 유지하면서, 가로 화면의 일곱 교전이 하나의 완결된 플레이로 느껴지게 만드는 데 목적이 있다.

완료 기준은 다음과 같다.

- 탄환을 고를 때 수치와 발사 순서가 실제 결과로 어떻게 이어지는지 전투 화면에서 읽힌다.
- 보상 화면에서 방금 만든 조합의 성과, 다음 적의 핵심 위협, 각 후보의 구체적 쓰임을 짧은 문장으로 비교할 수 있다.
- 두 총기와 여러 시드·보상 성향에서 완주 가능성과 탄환/파츠 선택 편향을 확인한다.
- 기본탄 반복 같은 단조로운 전략이 캠페인을 지배하지 않는다.
- 1280×800 및 Galaxy 계열 가로 화면에서 필수 정보와 버튼이 겹치지 않는다.
- 자동 회귀, 실제 UI 입력, 시각 캡처, Windows 내보내기와 기동 검사를 통과한다.

## UI 제작 계획

### 보상 화면 정보 계층

1. 상단에 방금 끝난 교전의 짧은 성과를 한 줄로 표시한다.
   - 예: `교전 기록 · 직접 피해 18 · 증폭 2회 · 화상 6`
2. 다음 교전 패널은 적별 전체 문장 아래에 위협 요약을 먼저 표시한다.
   - 예: `위협 · 장갑 3 · 고속 접근 · 3개체`
3. 각 보상 카드에는 기존 효과 설명 아래에 다음 교전 또는 현재 덱에 미치는 구체적 영향을 한 줄로 표시한다.
   - 예: `다음 교전 · 장갑 3 대응`
   - 예: `현재 덱 · 소이탄 2장 화상 +1`
4. 추천 정답을 지정하지 않는다. 공개된 사실과 수치 영향만 제공해 플레이어가 선택하게 한다.
5. 덱 제거·유지 선택은 카드 후보와 분리하되 같은 화면에서 한 번에 비교할 수 있게 유지한다.

### 완주 화면

- 기존 턴·발사·재장전 수에 더해 런 전체 조합 성과를 한 줄로 표시한다.
- 최종 덱은 중복 이름 나열 대신 탄환별 장수로 압축한다.
- 기존 재도전과 새 시드 진입은 유지한다.

### 개발자 진입점

- 메인 메뉴의 `개발자 테스트`에 `보상·빌드 판단` 바로가기를 추가한다.
- 저장을 건드리지 않는 디버그 세션으로 방금 전투 요약, 다음 위협, 보상 후보 설명을 함께 검증할 수 있어야 한다.

## 구현 범위

- 전투 기록에서 직접 피해, 증폭 적용 횟수, 화상 피해, 전이 피해, 밀어낸 거리를 계산하는 순수 요약 모듈
- 다음 편성의 장갑·접근 속도·개체 수를 압축하는 위협 요약
- 탄환·파츠 후보를 현재 덱/총기/다음 편성에 대입한 짧은 영향 문장
- 중복 탄환을 `이름 ×장수`로 표시하는 덱 요약
- 보상·완주 화면과 개발자 바로가기 연결
- 순수 계산 계약, UI 입력, 화면 시각 회귀 테스트

## 밸런스 검증

- 일반/코스, 보행자/쇄도 총기를 여러 시드로 실행한다.
- 보상 성향을 탄환 우선, 파츠 우선, 유지/정제 성향으로 나누어 완주율과 선택 분포를 기록한다.
- 기본탄만 반복하는 기준 전략은 중반 이전 또는 중반에서 실패해야 한다.
- 특정 탄환이나 파츠가 모든 조건에서 자동 선택이 되면 수치보다 편성·보상 노출·역할 중복을 먼저 조정한다.
- 휴리스틱 자동 플레이 결과는 사람의 재미를 증명하는 근거로 사용하지 않는다.

## 제외 범위

- 신규 아트 에셋과 최종 애니메이션 제작
- 메타 진행, 상점, 맵, 스토리 시스템 확대
- APK 생성·서명·패키징
- 원격 저장소 푸시

## 산출물

- 갱신된 Godot 소스와 테스트
- 밸런스 매트릭스 및 QA 결과 문서
- 대표 화면 캡처
- 최신 Windows 플레이 빌드와 실행 파일 해시
- 작업 추적기·일일 로그·히스토리 갱신

## 구현 결과

- 전투 기록을 실제 히스토리에서 집계하는 `run_insight.gd`를 추가했다.
- 보상 화면을 `교전 성과 → 다음 위협 → 적 A/B/C → 후보별 영향` 순서로 재구성했다.
- 완주 화면에 런 전체 조합 성과와 탄환별 장수로 압축한 최종 덱을 표시했다.
- 저장을 건드리지 않는 `보상·빌드 판단` 개발자 바로가기를 추가했다.
- 세 시드, 두 총기, 여섯 보상 성향, 학습 모드, 기본탄 전용 정책을 실행하는 밸런스 매트릭스와 실패 경로 다중 빔 폭 재검증을 추가했다.
- 전투 수치는 변경하지 않았다. 보상을 받는 정상 빌드에는 해법이 있었고, 기본탄 전용은 6/6 패배했으며, 전 보상 건너뛰기 쇄도 한 사례만 6교전에서 막혔다.
