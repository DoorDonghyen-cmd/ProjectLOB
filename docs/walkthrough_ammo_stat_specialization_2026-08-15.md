# 조합탄 전투 전문축 분리 구현 결과

> 완료일: 2026-08-15
> 자동 검증: 3,424 통과 / 0 실패 / 기존 경보 3

## 결과

공용 전술탄을 카드에서 즉시 구분할 수 있도록 **화력 / 관통 / 명중 / 제어** 전문축을
도입했다. 기존 공격/연계/제어는 효과 발동과 보상 구성을 위한 운용 분류로 남기고,
플레이어가 실제 탄 순서를 짤 때 읽는 기준만 전문축으로 분리했다.

## 주요 변경

- 19종 탄환 CSV와 리소스에 `specialty`를 추가하고 전문축별 수치 경계를 적용했다.
- 드래프트·가방·실린더·적재 스택·갤러리의 첫 배지를 전문축 색상으로 통일했다.
- 툴팁은 전문축 설명을 먼저, 기존 운용 분류와 발동 범위를 그다음에 표시한다.
- 교대탄·인터럽터·만능 약실은 전문축 전환을, 리듬 챔버는 동일 전문축 반복을 판정한다.
- 플레이테스트 로그와 전투 텔레메트리에 전문축 스냅샷을 기록한다.
- 개발자 메뉴에 `🎯 탄환 전문축 QA` 버튼을 추가했다.

## 시작 패키지

| 규격 | 기본 보급 | 전술 A×2 | 전술 B×1 | 핵심 대응 |
|---|---|---|---|---|
| 권총 | 9mm | 천공 | 연쇄 | 명중 기반 + 관통/화력 |
| SMG | .45 ACP | 표식 | 천공 | 화력 기반 + 명중/관통 |
| 소총 | 5.56mm | 천공 | 연쇄 | 고장갑 유효타 + 화력 결산 |
| DMR | 7.62mm | 천공 | 연쇄 | 관통 강화 + 화력 결산 |
| 산탄 | 12게이지 | 파쇄 | 충격 | DEF 선해체 + 거리 제어 |

소총의 표식 시작안은 흡수체 배리어에 유효타가 없었고, 산탄의 천공 시작안은 구경
`PEN -1` 때문에 DEF 4를 넘지 못했다. 전수 검사 결과에 따라 위 조합으로 확정했다.

## 검증

- CSV ↔ 19개 `.tres` 전문축·수치 일치
- 전문축 분포: 화력 5 / 관통 7 / 명중 4 / 제어 3
- 9총기 × 13적 × 기본/환기구 거리 234대진에서 첫 탄창 유효 대응 해법 존재
- Tempo·Suppressor 연발, 결정형 크리티컬, 탄환 소멸, 후열 관통·산탄 확산 회귀 유지
- UI 스모크에서 전문축 배지와 개발자 QA 버튼 확인

## 수동 플레이 체크

1. 타이틀의 개발자 테스트에서 `탄환 전문축 QA`를 실행한다.
2. 카드 첫 배지가 화력/관통/명중/제어로 구분되는지 확인한다.
3. 명중→관통→화력 순서에서 교대탄·인터럽터가 전문축 전환으로 발동하는지 확인한다.
4. 같은 전문축을 연속 배치했을 때 리듬 챔버가 반대 선택지로 느껴지는지 확인한다.
5. 실제 런에서 특정 전문축만 다시 반복 선택되는지는 다음 플레이 로그로 재평가한다.
