# Phase 12 ④ 구현 계획 — 기관단총 연발 전환과 탄환 역할 UI

> 날짜: 2026-07-24
> 세션: `codex0724-smg-role`
> 설계 정본: `docs/gdd/21_fire_mode.md`, `docs/gdd/22_ammo_expansion.md`

## 목표

- 전술 기관단총(Tempo)을 `full_auto`로 전환하고 도박형(Gambler)은 `single`로 유지한다.
- 탄환 v5의 `setter`·`payload`·`standalone`·`utility` 역할을 실제 플레이 화면에서 읽을 수 있게 한다.
- 셋업→페이로드 연계가 전술 기관단총의 DMG −1 패시브 이후에도 실제로 발동하도록 수치 계약을 정합한다.

## 범위

### 1. 발사 계약

- Tempo: 리로드 3, 예고창 6, 파츠 슬롯 3, `full_auto`
- 더블탭 런타임·UI·QA 숏컷 제거
- Gambler 단발 회귀 고정
- Tempo 전용 연발 체인 QA 숏컷 추가

### 2. 밸런스 안전장치

- 조율탄 DMG 1→2, 과부하탄 DMG 6→5
  - Tempo 적용 후 한 쌍은 1+4=5피해
  - 3쌍/4턴 = 3.75 DMG/턴으로 기존 계획값 보존
- 리듬 챔버 기본 내장 해제
  - 구 공식은 6발에서 +20 DMG를 자동 생성
  - 선택 장착 시 2·4·6번째 동일 클래스 격발에 +1, 총 +3으로 제한
- 기본 파츠 제거와 함께 슬롯 4→3으로 조정해 자유 슬롯 3칸 유지

### 3. 역할 데이터와 UI

- `BulletData`에 `is_basic`, `role` 추가
- 27개 `.tres`를 CSV 역할값과 동기화
- `BulletRoleUI`에서 역할명·색·도움말·연계 판정을 중앙 관리
- 적용 화면:
  - 보상 드래프트와 교체 목록
  - 적재 가방과 전투 가방
  - 장전 스택과 실린더
  - 탄환 갤러리
- 보이는 상단 2발이 셋업→페이로드면 `⇢ 연계` 표시
- 3번째 깊이부터 역할도 은폐
