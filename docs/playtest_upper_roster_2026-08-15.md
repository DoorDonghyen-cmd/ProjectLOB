# 관리·정점 복합 편성 수동 플레이테스트

> 자동 구조 검증 완료 / 실제 체감 결과 입력 대기
> 공통 조건: Workhorse, 승천 0, 동일 전술탄 묶음, 대표 종반 4체 편성

## 진입 방법

1. 타이틀 화면에서 `개발자 테스트`를 연다.
2. `관리 계층 편성 QA`를 플레이한다.
3. 다시 개발자 테스트를 열고 `정점 편성 QA`를 플레이한다.
4. 승패보다 아래 네 지점을 비교한다.

## 비교 항목

| 항목 | 관리 계층 | 정점 | 판정 기준 |
| :--- | :--- | :--- | :--- |
| 첫 위협 제거 시점 | 미입력 | 미입력 | 첫 탄창 안에 우선 위협 하나를 제거할 수 있어야 함 |
| 긴급 격퇴 발동 | 미입력 | 미입력 | 탄 순서를 잘 짰을 때 필수가 아니어야 함 |
| 첫 재장전 가능 여부 | 미입력 | 미입력 | 재장전 선택이 즉사와 동의어가 아니어야 함 |
| 탄 순서 재설계 필요성 | 미입력 | 미입력 | 관리보다 정점에서 우선순위 판단이 한 단계 더 복합적이어야 함 |

## 대표 편성

- 관리 계층: 태세 교란 드론 → 광학 추적체 03 → 경보 순찰 드론 → 상위 신경 통제체
- 정점: 흡수 장갑 구체 → 광학 추적체 03 → 태세 교란 드론 → 상위 신경 통제체

자동 검증에서는 상층의 모든 후보가 아무 적도 처리하지 않을 때 4~8행동 사이에 패배했다. 따라서 실제 플레이에서 3행동 이내에 사실상 해법이 사라지거나, 9행동 이상 위협 없이 늘어진다면 탄환 순서·표적 우선순위와 무관한 체감 문제가 있는 것으로 본다.

## 조정 우선순위

체감 문제가 확인되면 `편성 내 순서 → 후보 조합 → 계층별 출현 구간` 순서로 조정한다. 적 스탯과 탄환·총기 수치는 기능 구현 동결이 끝날 때까지 건드리지 않는다.
