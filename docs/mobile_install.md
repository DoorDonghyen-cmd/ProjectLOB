# Last on Board — Galaxy 테스트 설치

1. Google Drive에서 ZIP을 다운로드하고 ‘내 파일’에서 압축을 풉니다.
2. `LastOnBoard-city.apk`를 눌러 설치합니다. 필요하면 설치 화면에서 해당 앱의 ‘이 출처 허용’을 켭니다.
3. 기존 `Last on Board Test`가 있다면 삭제하지 않고 업데이트 설치합니다. 같은 패키지와 테스트 인증서를 사용합니다.
4. 앱을 열고 가로 화면으로 플레이합니다. 기존 진행은 ‘이어하기’로 유지할 수 있습니다.

설치가 차단되면 Galaxy의 보안 정책/자동 차단 설정과 화면의 안내를 확인하세요. 기존 앱을 먼저 지우면 로컬 저장도 지워질 수 있습니다.

Android 7.0 이상용 테스트 빌드입니다. 지원 아키텍처는 아래의 `This package` 또는 `build_manifest.json`의 `architectures`에 표시됩니다. `arm64-v8a`는 64비트 안드로이드용이며, 32비트 기기에는 `armeabi-v7a`가 포함된 빌드가 필요합니다. 게임은 인터넷 권한을 요청하지 않습니다. 실제 Galaxy 성능·터치 감각은 기기에서 확인해 주세요.

ZIP의 `RELEASE_NOTES.md`에서 해당 빌드의 변경 내용을 확인할 수 있습니다.
