# 디렉터 리빌딩 실행 계획

사용자 위임: 2026-10-02 기획·아트 전면 재검토와 개편. 현행 기준은 `docs/direction/current.md`.

1. 실제 로드되는 스킬과 개편판 스킬 12개, AGENTS, 작업 흐름을 정리하고 원문을 보관한다.
2. 사용자 핵심과 디렉터 결정을 구분한 게임·아트·전체 화면 기준을 작성한다.
3. 산업 도시 배경을 제작해 프로젝트 자산으로 보존하고 타이틀·전투에 적용한다.
4. 공통 글꼴·주 행동색·카드 표현을 통일하고 전투를 전장/발사 레일/손패로 다시 배치한다.
5. 실제 렌더와 합법 입력으로 무기·압축·긴 탄창·캠페인 흐름을 검증한다. 문서 구조와 스킬 참조도 확인한다.

게임 수치와 저장 형식은 비교 가능한 기반으로 유지한다. 구현되지 않은 전체 지역 아트·적 애니메이션·화면별 후속 개편은 현황에 명시한다. 이전 변경을 삭제하거나 임의로 커밋·푸시하지 않는다.

실행 결과: 위 1~5 범위를 수행했다. 실제 변경·검증·제작이 남은 범위는 [결과 보고서](qa/reports/director_rebuild_2026-10-02.md)에 기록했다. 기획·아트 기준과 첫 실행 적용을 마쳤으며 전체 최종 아트 제작이 완료된 것은 아니다.
