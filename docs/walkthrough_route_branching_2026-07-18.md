# 통로 분기 구조 개편 — 완료 워크스루

> 날짜: 2026-07-18

## 완료 내용

* 통로를 비상계단과 환기구 2종으로 축소하고 층 스킵·확률 패널티 로직을 제거했다.
* 맵 노드를 클릭하면 연결 통로가 자동 확정되도록 2단계 선택 UI를 1단계로 단순화했다.
* 현재 노드의 실제 연결 대상만 선택할 수 있으며, 통로 종류와 비용을 노드 카드·연결선에 미리 표시한다.
* 환기구 이용 시 다음 전투 시작 거리 `-2m` 상태를 저장하고, 비전투 노드를 지나도 유지한 뒤 전투 생성 시 한 번 소비한다.
* 환기 압박은 중첩하지 않는다.
* 런 시작 시 무기고 통로를 가변 배치하고, 무기고가 2개 이상이면 계단과 환기구가 최소 하나씩 나오도록 보장한다.
* 통로 자체의 TDC 보상을 제거하고 보스·히든·우회·보급 목적지 클리어에 귀속해 메타 자원 획득 단절을 막았다.
* GDD v0.18, 로드맵, 침투 맵 UI 명세, HTML 목업, CD/BD 지침을 동기화했다.

## 검증 결과

* 런타임 경로 값: `stairs`, `air_duct`만 존재.
* 제거 대상 문자열과 구형 통로 선택 UI 참조: 현행 런타임·GDD·목업에서 잔존 없음.
* HTML 목업 JavaScript: Node.js 구문 검사 통과.
* 정적 호출 정합: 목적지 직접 선택, 실제 연결선 제한, 환기 상태 전투 1회 소비 확인.
* Godot 실행 파일이 환경에 없어 엔진 헤드리스 파싱과 실제 씬 실행은 미수행.

## 수동 스모크 테스트

1. 새 런에서 무기고 진입 통로가 런마다 바뀌며 계단/환기구가 함께 존재하는지 확인한다.
2. 현재 노드와 연결되지 않은 같은 층 노드가 클릭되지 않는지 확인한다.
3. 환기구 → 무기고 → 계단 → 전투 순서에서 전투 시작 거리만 `-2m` 줄어드는지 확인한다.
4. 환기구를 연속 이용해도 `-4m`로 누적되지 않는지 확인한다.
5. 전투 종료 후 환기 압박 헤더가 사라지는지 확인한다.
