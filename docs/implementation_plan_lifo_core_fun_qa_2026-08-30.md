# LIFO 탄환 조합 핵심 재미 정밀 QA 개편 계획

## 목표

QA 결과를 단순한 자동 테스트 통과율이 아니라 다음 질문에 답하도록 개편한다.

- 같은 탄환 묶음도 장전 순서에 따라 전투 결과가 달라지는가?
- 적의 방어력·회피·거리와 남은 체력에 따라 필요한 조합이 달라지는가?
- 기본탄 반복보다 혼합 장전이 실제로 더 나은 선택이 되는가?
- 이 판단이 실제 캠페인 플레이에서도 충분한 빈도로 요구되는가?
- 기계적으로 성립하는 퍼즐이 사람에게도 재미·성공감·재도전 욕구를 주는가?

## 판정 원칙

- 총점이나 평균 재미 점수를 만들지 않는다. 서로 다른 근거를 하나의 숫자로 가리지 않는다.
- 기능 오류와 재미 부족을 분리한다. 버그가 없어도 재미는 부족할 수 있다.
- 동일한 탄환 묶음의 계획 순서·역순·기본탄을 실제 `CombatManager`로 비교한다.
- 자동화가 판정할 수 없는 타격감·피로도·재도전 욕구는 사람 확인 항목으로 남긴다.
- 3개 이상의 시드와 12전투 이상에서 반복되지 않으면 핵심 재미를 확정하지 않는다.

## 구현 범위

1. 명중·관통·피해 결산·막발 조건의 네 상황에서 동일 탄환 묶음 순서 대조
2. 공개된 적 DEF/EVA/거리만 읽는 상황 대응형 자동 장전 정책
3. 순서 영향, 상황별 해법, 혼합 장전 가치, 실제 선택 압력, 표본 범위의 독립 게이트
4. `확인됨`, `가능성 있으나 얇음`, `입증되지 않음`, `구조 문제`의 사람 언어 판정
5. 핵심 재미 결론·근거·다음 검증을 대시보드 최상단에 표시
6. 탄환 ID/표시명 혼용과 전투 수 집계 오류 제거

## 완료 조건

- 네 순서 대조 시나리오가 모두 순서 차이와 계획 우위를 재현한다.
- 실제 QA 실행이 판정과 근거를 `core_fun_assessment.json`으로 보존한다.
- 단일 시드 결과는 재미 확정으로 승격되지 않는다.
- 대시보드가 기술 로그보다 먼저 핵심 결론과 미확인 항목을 보여준다.
- 전체 자동 회귀가 실패 없이 통과한다.
