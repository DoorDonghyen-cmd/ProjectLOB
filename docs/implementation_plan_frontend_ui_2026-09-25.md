# 타이틀·출격 준비 프런트엔드 UI 개편 계획

## 목적

메인 화면부터 총기 선택까지 한 화면에 섞여 있던 설정 폼을 게임의 첫 흐름으로 재구성한다. 플레이어는 타이틀에서 `이어하기`, `새 등반`, `기초 훈련` 중 하나를 고르고, 새 등반에서는 총기를 먼저 선택한 뒤 시작 보급과 난도를 확인하고 한 번만 출격을 확정한다.

## 구조

1. 타이틀 홈과 출격 준비실을 별도 화면 상태로 분리한다.
2. 타이틀은 게임 정체성, 진행 중 등반, 주 행동, 보조 메뉴 순으로 배치한다.
3. 총기 선택은 5종 비교 레일, 선택 총기 쇼케이스, 시작 보급, 세부 조건, 최종 출격 순으로 배치한다.
4. 총기 카드는 선택만 수행하고 실제 시작은 화면 하단의 단일 버튼이 수행한다.
5. 훈련은 별도 타이틀 행동으로 진입하되 같은 준비실과 총기 선택 경험을 공유한다.
6. 1280×800에서는 총기 5종을 한 줄에, 1008×630 또는 큰 글씨에서는 3열로 재배치한다.
7. 최종 아트 전에도 게임 화면처럼 읽히도록 절차적 도시 실루엣과 총기별 색·벡터 실루엣을 사용한다.

## 완료 기준

- 타이틀에 난도·시드·총기 설정 폼이 노출되지 않는다.
- 진행 중 저장이 있으면 현재 층·총기·계층·파츠·크레딧을 한 카드에서 이어갈 수 있다.
- 총기 선택 뒤 선택 상태, 핵심 규칙, 탄창, 재장전, 추천 조합을 한 시야에서 확인한다.
- 새 등반과 훈련이 같은 준비 흐름을 사용하며 실제 선택 총기로 시작한다.
- 기존 전투, 도시 캠페인, 저장 교체 확인과 개발 도구가 회귀하지 않는다.
