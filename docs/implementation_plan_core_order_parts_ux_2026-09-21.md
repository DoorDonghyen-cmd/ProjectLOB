# 탄 순서 회복·파츠 빌드·상점 UX 재개편 계획

상태: **구현·자동 검증 완료**  
대상: `prototype/core-redesign`  
승인 근거: 2026-09-21 사용자 플레이테스트에서 전열 위치 재배치, 기본탄 과성능, 탄 조합과 순서 의미 상실, 파츠 반복과 상점/보관 UX 문제를 확인하고 종합 개선을 요청함

## 확인된 원인

1. 전장 레인은 적의 고유 위치가 아니라 현재 생존 배열 순서로 계산되어, 사망과 증원 때 생존 적까지 위아래로 이동한다.
2. 회수탄 피해 4와 보행자 피해 +1이 HP 4 적을 한 발에 처치해 전술탄보다 효율적이다.
3. 전장 본문은 HP와 거리만 크게 보이고 장갑, 배리어, 충전과 탄환 상성이 작거나 숨겨져 있다.
4. 상점 파츠 풀은 가속 총열·열축전 코일과 일부 무기의 회수 가속기뿐이다. 확장 탄창은 판매에서 제외되어 실제 선택 폭이 2~3종이다.
5. 진열 이력을 보존하지 않아 사지 않은 파츠는 다음 상점과 갱신에서 반복될 수 있다.
6. 파츠는 효과가 작은 단일 수치 변경이고 상점·보관함은 현재 장착품과 후보를 직접 비교하기 어렵다.

## 전투 수정

- 적마다 `lane`을 저장하고 생존 여부와 관계없이 교전 동안 유지한다.
- 증원은 비어 있는 레인에만 들어오며 기존 적의 세로 위치를 바꾸지 않는다.
- 회수탄 피해를 4에서 2로 낮춘다. 보행자는 회수탄 +1, 전술탄 +2로 분리해 무장갑 저체력 적도 기본탄 두 발이 필요하고 조합탄의 우위는 더 커진다.
- 전술탄은 상황별 우위를 강화한다: 철갑은 장갑, 소이는 배리어와 장기 접근, 전격은 다수전과 전도 선체, 충격은 고속 접근, 증폭→연발은 처치선 조절을 담당한다.
- 전도 선체는 전기 주 타격 추가 피해를 받으며 이를 공개 약점으로 표시한다.
- 전장에 장갑 방패 숫자, 배리어 칸, 전기 약점, 충전 시계, 화상, 접근 위험을 HP와 같은 위계로 표시한다.

## 파츠 빌드 수정

도시 상점 파츠를 8종으로 확장한다.

| 파츠 | 핵심 효과 | 빌드 역할 |
|---|---|---|
| 가속 총열 | 관통 +2 | 장갑 대응 |
| 회수 가속기 | 재장전 −1턴 | 긴 재장전 무기 순환 |
| 확장 탄창 | 탄창·회수탄 +1 | 긴 연쇄 |
| 열축전 코일 | 화상 +1 | 소이 지속 피해 |
| 전이 축전기 | 전이 피해 +1 | 전격 다수전 |
| 충격 가이드 | 밀치기·탄창 밀치기 한도 +1m | 거리 제어 |
| 증폭 시퀀서 | 증폭 피해 +1 | 증폭 후속 조합 |
| 복열 노리쇠 | 연발 타격 +1 | 적중·집중 조합 |

- 무기에 효과가 없는 파츠만 후보에서 제외한다.
- 런 동안 보지 못한 파츠를 우선 진열하고, 전체 후보를 본 뒤에만 반복한다.
- 진열 이력 `shop_seen_parts`를 저장하고 갱신에도 유지한다.
- 구매 파츠는 즉시 장착하지만 보관함에서 전투 사이 언제든 무료 교체할 수 있다.

## 상점·보관함 와이어프레임

```text
┌ 현재 빌드 ──────────────────────────────┐
│ [무기] [장착 파츠 아이콘·핵심 수치] [덱 성향] │
└────────────────────────────────────────┘

전술 탄환                 파츠 모듈
┌ 탄환 카드 ┐            ┌ 파츠 A ┐ ┌ 파츠 B ┐
│ 현재 보유 │            │ 현재→교체 핵심 변화 │
│ 12Cr     │            │ 30Cr · 즉시 장착   │
└─────────┘            └────────┘ └────────┘

[압축 코어]   [새 진열 3Cr · 미확인 우선]   [맵으로]

장비 보관함
현재: [큰 장착 카드]
보유: [작은 카드+장착] [작은 카드+장착] [분해]
```

## 완료 조건

1. 적 처치·이동·증원 전후 생존 적의 레인이 변하지 않는다.
2. 무장갑 HP 4 적은 일반 연사 무기의 회수탄 한 발에 죽지 않는다.
3. 전장만 보고 장갑, 배리어, 전기 약점, 충전, 접근 위험을 구분할 수 있다.
4. 전술탄의 순서가 실제 처치 수 또는 생존 거리 차이를 만든다.
5. 상점 파츠 8종이 무기 적합성에 맞게 순환하고 미확인 후보가 반복 후보보다 먼저 나온다.
6. 상점과 덱·장비 화면에서 현재 장착과 교체 후보를 아이콘 중심으로 비교·교체할 수 있다.
7. 1008×630 실제 UI와 전체 현대 회귀를 통과한다.

## 구현 결과

- 적에게 고정 레인을 부여하고 증원은 빈 레인만 사용하도록 바꿨다. 처치·이동·증원 후에도 생존 적의 세로 위치가 유지된다.
- 회수탄 피해를 2로 낮추고 보행자는 회수탄 +1, 전술탄 +2로 분리했다. 전도 선체에는 공개 전기 약점 `⚡ +2`를 부여했다.
- 전장에 장갑·배리어·전기 약점·화상·충전·접근 위험을 실루엣과 같은 영역에 표시했다.
- 파츠를 8종으로 확장하고 미확인 파츠 우선 진열, 런별 진열 이력 저장, 구매 즉시 장착, 보관함 무료 교체를 구현했다.
- 상점과 장비 보관함을 아이콘 카드 중심으로 다시 구성했다. 현재 무기·장착 파츠·덱 성향과 후보의 핵심 효과를 한 화면에서 비교할 수 있다.
- 파츠 교체 후 넉백 예산 상한이 저장 상태와 달라져 복원이 간헐적으로 실패하던 문제도 함께 수정했다.
