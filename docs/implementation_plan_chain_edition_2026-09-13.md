# 연계 개편판 구현 계약

사용자 승인: 순서 조합/랜덤성 검토 방향으로 규칙과 탄환 명칭 전면 개편 허용. 원본 main과 `afbf070`/기존 APK는 비교 기준으로 보존한다. 대상은 core-redesign 7교전, Godot/Android를 유지한다. 기존 기획 스킬의 LIFO/이진 관통 게이트 고정은 이 버전에 한해 사용자 승인으로 대체한다.

## 목표와 구현

- 발사 순서 직접 입력: 클릭한 순서대로 1→4, 슬롯 터치 회수. 확정 전 무료, 확정 후 유료 재장전. 단발/일제의 시간 차와 0m 패배는 유지.
- 적의 균열(0~3)은 장갑을 낮춘다. 균열탄이 2 추가, 파쇄탄이 전부 소비해 균열당 +2피해. 나머지 탄은 균열 유지. 적 상태는 재장전에도 유지되며 다른 적에게 옮겨가지 않는다.
- 연속탄은 같은 적 2타, 축전은 다음 2발 타격당 +2, 유도는 다음 2발 명중 +4. 강화 두 종류는 함께 유지되고 같은 종류는 횟수 갱신. 재장전하면 강화 종료. 마지막 2타 중 잔여 피해가 다른 적에게 넘어가지는 않는다.
- 도약탄은 다른 최근접 생존 적에게 고정1피해, 주 표적이 균열 상태면3피해. 보조 피해에 강화/장갑 계산을 중복 적용하지 않는다. 수확탄은 발사 직전 반피 이하에 +4피해.
- 피해는 타격마다 `max(1, 기본+총기+축전+특수 − max(0, 장갑−균열−관통) − max(0, 회피−명중))`. 피해 표시는 남은 HP까지로 제한한다. 명중 부족은 스침이며 확률 실패가 아니다. 제어 효과는 실제 피해가 있는 타격 후 생존 적에게 적용한다.
- 충격탄 탄창당 넉백2m 한도, 점착 다음 전진 1회−2. 처치/밀기/전진 후 최근접 표적 갱신.
- 시작 덱10장(9종, 균열2), 공개 패5장, 미사용 패 유지. 재장전마다 기본4발·교환1회 복구. 덱 최소6/최대14. 교환 탄은 대체 탄을 받은 뒤 버림 더미로 가므로 그 자리에서 다시 뽑지 않는다. 계획에 사용 중인 수량은 교환하지 못한다.
- 교전마다 3개의 검토된 편성 중 하나와 거리0~1 변주. 시드·층으로 결정하고 손패 RNG와 분리. 보상은 시드별 탄환3종 또는 파츠 최대3종; 현재 파츠는 제외. 다음 교전 편성을 보상 화면에서 공개.
- 파츠1개: 명중 보정/리로드 감소/균열 코일/확장 탄창. 확장 탄창은 용량·기본 공급5발이며 화면·예고도 5발 처리.
- 저장 v2, `user://chain_run_v2.json`. 이전 v1 저장 파일을 다른 규칙으로 읽지 않는다. Android 패키지는 동일하게 유지해 업데이트 설치 가능, 버전코드 증가. 기존 APK 파일 보존.

## 표시와 검증

카드는 짧은 이름과 한 줄 역할, 선택한 탄의 상세 정보만 아래 표시한다. 탄창은 실제 순서/주 표적/피해/연계, 도약은 별도 표적까지 표시한다. 적의 균열은 몸 옆 상태표시, 실제 남은 장갑은 적 요약으로 드러낸다. 준비 효과 잔여 발수는 장비 줄에 표시한다.

규칙·독립 산식·예고/실행·교환 보존·저장/복원·확장5칸 검사를 실행한다. 독립 탐색의 실제 명령 경로를 UI 버튼으로 재생하고 중간 저장 재개와 양 총기 완주를 확인한다. 화면/터치는 PC 실제 렌더와 합성 터치이며 Galaxy의 성능/촉감은 후속 사람 확인 대상이다.

랜덤성 검사는 패/적/보상별 변화를 분리한다. 기본탄 정책과 전술 탐색을 대조하되 검색 승률을 사람 승률이나 재미 점수로 부르지 않는다. 광범위 기존 회귀는 원본 시스템 보존 확인에만 사용하며 v1 prototype 전용 검사는 `afbf070` 기준 기록으로 남긴다. 현재 개편판의 실행 도구는 `tools/run_chain_checks.ps1`이다.
