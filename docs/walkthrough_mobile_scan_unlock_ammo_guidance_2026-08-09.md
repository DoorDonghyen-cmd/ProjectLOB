# 모바일 스캔·해금 표기·조합탄 전술 예고 구현 워크스루

> 완료일: 2026-08-09
> 계획서: `docs/implementation_plan_mobile_scan_unlock_ammo_guidance_2026-08-09.md`
> 범위: 버그 #017·#018 및 조합탄 선택 다양성 1단계

## 완료 결과

- 모바일 미지 노드는 첫 탭에서 스캔 정보를 열고 같은 노드를 다시 탭해야 진입한다.
- 데스크톱은 기존 호버 스캔과 한 번 클릭 진입을 유지한다.
- 제압형 해금 시 디브리핑에 `제압형 (SUPPRESSOR)`가 표시된다.
- 연계탄의 효과 범위를 카드에서 읽을 수 있고, 현재 LIFO 적재가 명중·관통 게이트를 실제로 바꾸는 발수를 확인할 수 있다.

## 주요 구현

### 모바일 미지 노드 입력

- `InputEventScreenTouch`를 미지 노드 전용 입력 경로로 분리했다.
- 첫 탭은 스캔 대상만 준비하고, 같은 버튼의 두 번째 탭만 이동을 확정한다.
- 다른 노드 선택, 지도 갱신, 실제 이동 시 준비 상태를 초기화한다.
- 터치에서 합성된 마우스 이벤트가 첫 탭 직후 이동을 중복 확정하지 않게 차단했다.

### 해금 무기명 단일화

- 준비실의 `WEAPON_PROFILES`를 사용하는 `weapon_display_name()`을 공용 조회점으로 추가했다.
- 디브리핑에 있던 별도 무기명 `match`를 제거했다.
- 미등록 미래 키는 키 자체로 폴백하고 빈 키만 `알 수 없음`으로 처리한다.

### 연계 범위와 현재 기여 예고

- 연계탄 6종을 `[다음 1발]`, `[대상 지속]`, `[잔여 탄창]`으로 구분한다.
- 좁은 실린더에는 `[1발]`, `[대상]`, `[잔탄]` 축약 배지를 사용한다.
- 현재 총기·최근접 적·LIFO 탄열을 순차 계산해 `명중 전환 N발`, `관통 전환 N발`, 선행탄 게이트 실패 또는 현재 전환 없음 상태를 표시한다.
- 처치 후 재타깃, 조건부 파츠, 전체 전투 풀이까지 자동 추천하지 않고 현재 보이는 대열만 설명한다.

## 개발자 QA

메인 화면 개발자 메뉴의 `스캔·연계·결산 QA`에서 다음을 연속 확인할 수 있다.

1. 미지 노드 첫 탭 스캔과 같은 노드 재탭 진입
2. 연계탄 3종 범위 배지
3. 현재 적재의 명중·관통 전환 예고
4. 후속 결산탄 성공·실패 및 예상 주 피해
