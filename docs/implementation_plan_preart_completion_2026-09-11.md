# 아트 제작 전 기능 완성 계획

작성: 2026-09-11
상태: 진행 중 — 사용자의 아트 이전 전체 개발 위임에 따른 실행 계획

## 목표와 범위

달라지는 탄환 재료를 적의 공개 정보에 맞춰 LIFO로 배열하고, 계획이 실제 결과로 이어지는 전술 덱빌딩 로그라이크를 완성한다. 기존 임시 아트로 처음 시작·장비 선택·35층 상승·보상·성장·사망·완주·재도전까지 검증한다.

이번 위임은 기능 개발·버그 수정·비전 내 설계 판단·검증·문서 정리를 포함한다. 신규 원화·스프라이트·배경·음악 제작과 최종 브랜딩은 아트 단계로 남긴다. 보류 기능은 필요성이 입증될 때만 재검토하며 콘텐츠 수를 임의로 늘리지 않는다.

## 유지할 핵심 계약

- 마지막 장전 탄부터 발사하며 장전 후 순서를 무작위로 바꾸지 않는다.
- 명중·관통·피해·적 행동과 거리 비용을 공개하고 결정론적으로 정산한다.
- 기본탄 정량 보급, 패 밖 전술탄 선택 금지, 미사용 패 유지, 리로드 보충을 검증한다.
- 랜덤 패 B안의 기본 적용은 자동 비교 근거와 사람의 피로·성공감 확인을 분리해 결정한다. 자동 지표만으로 사람의 재미를 통과 처리하지 않는다.
- 기존 사용자 저장 파일은 QA에 사용하지 않는다.

## UI 구현 계약

대규모 시각 개편 대신 기존 화면의 기능을 완성한다. #019에서는 전투 트랙 공통 Y에 실제 스프라이트 하단을 맞추고 동거리 적을 X 간격으로 구분한다. HP·상태 배지는 개별 선택 영역과 함께 이동하며 논리 거리는 바꾸지 않는다. 관리/정점 4체 QA 진입점으로 확인한다.

```text
전투 트랙
  [적 정보]       [적 정보]       [적 정보]
    [적]           [적]           [적]
------------------------------------------------ 공통 바닥선
                  같은 논리 거리도 개별 선택 가능
```

구체적인 추가 UI 기능은 해당 문제를 확인한 뒤 이 계획 또는 별도 요청서에 동작·배치·QA 진입점을 기록하고 구현한다.

### 게임 안내와 수집 기록 (2026-09-11 감사 후 추가)

기존에는 파편 수집 수만 표시되고 파편을 읽는 화면과 본문 20개가 없다. 타이틀의 복원율 아래에 `장전 안내`와 `수집 기록` 버튼을 나란히 배치한다. 동일한 스크롤 대화상자에서 장전→예고→격발→보급 규칙과 수집한 파편을 각각 읽는다. 미수집 본문은 숨기고 번호만 표시한다. 작은 화면은 대화상자 크기를 뷰포트 안으로 제한하며 닫기 버튼을 제공한다. 개발자 테스트에도 두 화면 진입점을 연결한다. 로어 본문은 전투 이해에 필수로 사용하지 않는다.

```text
보유 크레딧
기록 복원율 n / 20
[장전 안내] [수집 기록]
...
[상승 개시]

대화상자: 제목 / 스크롤 본문 / 닫기
```

## 판정 원칙

자동 실행 실패, 기능 결함, 밸런스 가설, 사람의 체감 미확인은 별도로 기록한다. 신규 회귀 실패를 통과로 숨기거나 기존 기대값을 이유 없이 바꾸지 않는다. 실제 실행할 수 없는 플랫폼 패키지는 검증 완료로 표기하지 않는다.
