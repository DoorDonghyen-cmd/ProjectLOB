# 무기고·파츠 작업대 UI 워크스루

## 결과

무기고의 현재 빌드, 상품, 압축 코어, 파츠 장착을 하나의 장면 기반 작업대로 재구성했다. 게임 규칙과 상점 경제는 유지하면서 중복 설명을 줄이고 비교와 행동을 같은 구역에 배치했다.

## 플레이 흐름

1. 무기고에 들어오면 현재 장착 수, 무기, 탄창, 재장전, 덱 구성을 먼저 확인한다.
2. 진열의 세 상품을 비교한다. 파츠 카드에는 고유 도형, 핵심 이득, 강한 파츠의 대가가 먼저 보인다.
3. 카드를 누르면 전체 규칙을 상세창에서 확인한다.
4. 구매 버튼에서 가격과 결과를 확인한다. 빈 슬롯과 코어 제한에 따라 즉시 장착 또는 보관함 이동을 미리 알려 준다.
5. 같은 화면 아래의 장착 작업대에서 5칸 구성과 보관함을 비교하고 장착·해제·분해한다.
6. 압축 코어를 충전하거나 새 진열을 요청한 뒤 맵으로 돌아간다.

## 구조 변경

- `redesign/shop_workbench.tscn`을 추가해 고정 구역과 대표 문구를 편집기에서 바로 확인할 수 있게 했다.
- `campaign_ui.gd`는 장면을 이동·재구축하지 않고 현재 상품과 빌드 데이터만 채운다.
- 기존 상품 효과 반복 문장을 `보유 수`, `즉시 장착`, `보관함으로 이동` 상태로 축약했다.
- 1280px 창은 상품 3열·보관함 2열, 1120px 미만 창은 상품 2열·보관함 1열로 전환한다.
- `city_buy_*`, `city_part_info_*`, `city_equip_*`, `city_dismantle_*` 등 기존 입력 계약을 유지했다.

## 개발 절차 도입

`awesome-gamedev-agent-skills`에서 Godot UI, 게임 UI/UX, 게임 필, Godot 애니메이션 스킬만 선별 설치했다. `godot-ui-integration`의 장면 우선·런타임 바인딩·실행 캡처 절차를 적용했다. Impeccable의 일반 웹 UI 도구는 설치하지 않고 점검 개념을 `docs/gdd/30_godot_ui_production_standard.md`의 Godot 기준으로 다시 작성했다.

## 검증

- Godot 4.7 편집기 로드와 파싱 통과
- 실제 OpenGL UI 3,430조건/0실패, 1,103입력
- 보행자·쇄도 35층 UI 재생 통과
- 무기 규칙 3,245조건/0실패
- 1280×800 및 1008×630 대표 캡처 4장 육안 검토

검증 원본은 `docs/qa/reports/shop_workbench_ui_2026-09-21.md`에 기록했다. APK와 Windows 패키지는 갱신하지 않았다.
