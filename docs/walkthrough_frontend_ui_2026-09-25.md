# 타이틀·출격 준비 프런트엔드 UI 개편 워크스루

## 결과

메인 화면이 설정 항목과 총기 카드가 길게 이어지던 형태에서 게임의 타이틀 홈으로 바뀌었다. 새 등반을 누르면 별도 출격 준비실로 이동하고, 총기 비교 → 선택 총기 확인 → 시작 보급·난도 → 출격 확정 순서로 진행한다.

## 타이틀 홈

- 절차적 도시 실루엣 배경과 게임 제목·핵심 문장으로 첫 화면의 정체성을 만든다.
- 진행 중인 등반은 층, 총기, 계층, 파츠 수, 크레딧을 보여 주는 `등반 계속` 카드로 표시한다.
- `새 등반 준비`와 `기초 훈련`을 주 행동으로 분리했다.
- 기록실, 안내, 규칙, 설정은 보조 행동으로 내리고 개발 도구는 작은 별도 버튼으로 축소했다.

## 출격 준비실

- 총기 5종을 실루엣·고유색·한 줄 규칙으로 비교한다.
- 카드를 누르면 바로 시작하지 않고 선택 총기 쇼케이스가 갱신된다.
- 쇼케이스는 총기의 역할, 고유 규칙, 추천 조합, 발사 방식, 탄창, 재장전을 한 곳에 모은다.
- 해금된 시작 보급을 카드로 고르고 난도와 시드를 보조 영역에서 조정한다.
- 화면 마지막에는 선택한 총기 색을 따르는 하나의 출격 버튼만 둔다.
- 훈련도 같은 준비실을 사용하며 고정 훈련 보급과 7교전 조건을 명시한다.

## 반응형·입력

- 1280×800에서는 총기 카드 5종을 한 줄로 비교한다.
- 1008×630 또는 큰 글씨에서는 3열로 접어 가로 넘침을 막는다.
- 타이틀의 기본 포커스는 이어하기 또는 새 등반, 준비실의 기본 포커스는 출격 버튼이다.
- 기존 안드로이드 뒤로 가기는 준비실에서 타이틀로 돌아간다.

## 검증

- 전체 자동 테스트 3,730 / 0 실패.
- 프런트 전용 실제 렌더·입력 33 / 0 실패.
- 총기 UI 290 / 0 실패.
- 저장 교체·설정·뒤로 가기 UX 32 / 0 실패.
- 실제 도시 UI 3,698 / 0 실패, 1,186개 입력, 보행자·쇄도 각 35층 완주.
