# 연계 개편판

발사 순서를 직접 설계하고, 적에게 남긴 균열을 여러 탄환에 활용하거나 파쇄로 소비하는 전투로 개편했다. 시드별 손패·적·보상이 달라지며 패 교환으로 대응할 수 있다. Godot의 기존 그래픽 방향을 유지하고 Android/Windows 테스트 파일을 제공한다. 이는 사람 플레이 피드백을 받을 수 있는 구현판이며, 재미·장기 균형의 최종 승인은 아니다.

## 플레이 변화

- **클릭한 순서대로 발사.** 왼쪽이 첫 발이다. 확정 전 아무 슬롯이나 눌러 그 탄을 회수한다. 확정 후에는 재장전 비용을 지불한다.
- **균열을 유지하거나 소비.** 균열탄→연속탄, 균열탄→도약탄, 균열탄→파쇄탄처럼 상황별 연결이 생긴다. 축전→연속탄은 두 타격을 모두 강화하고, 수확탄은 반피 이후에 강해진다.
- **10종 탄환과 적응.** 기본탄 외 9종 전술탄, 시작 덱10장/손패5장, 장전마다 패 교환1회. 장갑·명중 부족은 피해를 낮추되 최소1을 남겨 재료 부족이 무행동으로 이어지지 않게 했다.
- **시드별 교전·보상.** 각 층의 세 편성과 거리 변주, 무작위 보상 후보. 다음 적 정보는 보상 선택 전에 공개한다. 현재 장착 중인 같은 파츠는 다시 제안하지 않는다.
- **4→5칸 확장.** 확장 탄창 파츠로 긴 연계를 선택한다. 한 파츠 슬롯을 다른 강화와 경쟁하며 사용한다.
- **연계 표시.** 각 탄 아래 실제 예상 표적/피해/강화 표시, 도약의 보조 표적 명시, 적의 균열과 남은 장갑, 강화 잔여 발수, 스침 안내, 52px 기본 버튼.

정확한 규칙과 범위는 [구현 계약](implementation_plan_chain_edition_2026-09-13.md)에 기록했다. 기존 기획의 역순 장전과 이진 관통 게이트는 사용자의 전면 개편 승인에 따라 이 버전에서 바뀌었다.

최종 캠페인 864발 중 기본탄은 41.67%, 축전 강화131발·파쇄63발·강화 도약36발·수확68발을 관찰했다. 충격탄은 최종 정책에서0회였고 유도탄도 적었다. 탐색은 유도/충격을 교환 우선으로 처리하므로 이를 무용함으로 단정하지 않는다. 사람 테스트에서 제어탄 선택 이유와 다른 파츠 선택을 후속 확인한다.

초기 전체 회귀에서는 구 캠페인 검사기가 삭제된 고정 `Content.REWARDS`를 읽는 컴파일 오류1건이 있었다. 공개 `reward_options()` 조회로 고친 뒤 전체 회귀를 다시 실행해 3,730 통과/0실패/기존 경보3을 확인했다. 개편판 게임 로직의 동작 오류와 구분한다.

## 테스트 파일

- Galaxy: [LastOnBoard-chain.apk](../builds/chain-android/LastOnBoard-chain.apk), **81,387,538바이트**.
- APK SHA256: `FF2BC0DFA7991FEC82D098C48F948B6A846440D218E3A88D7D22B8F346772F41`.
- Windows: [Play-Chain.cmd](../builds/chain-windows/Play-Chain.cmd), EXE **126,677,104바이트**, SHA256 `8185DEDF6706397C6FB680D35AFCCBC7307462297580B6CDE23B29323DE75EA3`.
- Android 패키지 `com.lastonboard.prototype`, `0.2.20260913`/코드20260913, ARM64+ARMv7, 최소API24/대상API36. 테스트 서명·zipalign(4바이트/16KiB)·ZIP CRC 확인, 테스트 파일 제외. Windows 패키지 headless 기동 확인.
- [갤럭시 설치 안내](android_install_chain_2026-09-13.md). 기존 테스트 앱에 업데이트하며 새 규칙은 `chain_run_v2.json` 별도 저장을 사용한다. v1 진행을 v2로 잘못 읽지 않는다.
- 이전 APK의 SHA256을 다시 검사해 원본 보존을 확인했다. 기존 Windows 비교판/main도 보존한다.

생성 시 `afbf070` 위 작업본을 포함했으며 APK 검증 JSON에 제품파일별 해시를 기록했다. 빌드 실행 때 콘솔에 root certificate store 읽기 경고가 있었으나 네트워크가 필요 없는 로컬 빌드·검증은 성공했다. Android 실기 실행·발열·조작감은 이번 개편판에서 아직 미검증이다.

재실행: `tools/run_chain_checks.ps1 -Mode rules|visual|ui_campaign`. 독립 캠페인 실행기는 보고서의 환경변수를 따른다. 빌드는 `tools/export_chain_android.ps1`, `tools/export_windows_chain.ps1`. 기존 v1 UI/규칙 검사와 수치는 비교 커밋 `afbf070` 기준이며 현재 개편판 통과 근거로 혼용하지 않는다.
