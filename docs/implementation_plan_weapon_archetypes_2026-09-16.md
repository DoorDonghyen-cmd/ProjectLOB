# 무기를 런의 플레이 방식으로 만드는 4종 개편

## 목적과 승인 범위

사용자 확정: “우리 게임의 무기는 슬더스의 캐릭터 같은 역할”, 초기 로스터는 4~5개가 적당하다. 기존 전체 개발 위임과 규칙·명칭·UI 변경 허용 안에서 첫 4개를 구현한다. 공통 탄환 7종의 피해/관통/속성/효과는 유지한다. Godot 가로 화면을 유지하며 APK 생성과 원격 푸시는 하지 않는다.

무기는 런 시작에 고르고 끝까지 유지한다. 초반부터 모든 무기를 선택할 수 있게 해 비교 플레이를 지원한다. 5번째는 독립된 의사결정을 제공하는 경우 추가한다. 이번 단계에서 전용 탄환 풀이나 복잡한 고유 자원까지 늘리지 않는다.

## 4개 고유 규칙

| ID / 이름 | 고유 규칙 | 비용 | 좋은 판단 |
|---|---|---|---|
| single / 보행자 | 한 발씩 1턴, 타격당 피해 +1 | 일제 사격 불가 | 화상 먼저, 밀치기로 다음 표적 변경 |
| burst / 쇄도 | 탄창 전체를 1턴에 실행 | 재장전 3턴 | 증폭→연발을 몰아치고 재장전 공백 계산 |
| scatter / 산개 | 한 발씩 1턴, 표적과 거리 차 3m 이내인 다른 적 모두에 확산 | 재장전 2턴, 확산은 낮은 피해로 장갑에 약함 | 군집/속도 차, 증폭→연발의 다중 타격 |
| heavy / 압쇄 | 모든 관통 +2, 관통이 장갑을 넘으면 타격당 피해 +1 | 기본 탄창 3칸, 재장전 2턴 | 철갑/가속 총열의 초과 관통, 짧은 증폭 순서 |

산개의 확산은 `max(1, floor((기본 피해+총기 보정+증폭)/2) - max(0, 다른 적 장갑-관통)) × 타격 수`, 실제 HP 한도. 거리 판정은 밀치기 전 발사 표적의 위치다. 주 표적이 사망해도 해당 발의 확산은 발생한다. 화상/밀치기/증폭 부여를 다른 적에게 복제하지 않는다. 전격탄은 확산 이후 가장 가까운 다른 생존 적에게 기존 고정 2피해 전이를 별도로 적용한다.

압쇄 주 피해는 기존 식에 `min(1,max(0,관통-장갑))`를 타격당 추가한다. 초기 최대 +2를 실제 기본탄 한 탄창+재장전 주기로 비교한 결과, 회수 가속기 장착 후 무장갑에서도 보행자의 기본탄 화력을 넘겨 최대 +1로 조정했다. 최종 용량/실제 재장전까지 포함해 보행자의 무장갑 템포와 압쇄의 장갑 대응을 회귀 검증한다. 탄환 아이콘은 고정 피해/실제 관통을 유지하고, 상대 장갑에 따라 변하는 추가 피해는 예측과 계산 상세에 표시한다.

기본 탄창: 보행자/쇄도/산개 4→5→6, 압쇄 3→4→5. 관문 성장 +2칸은 장착 파츠와 독립적이다. 회수 가속기는 기본 재장전이 2턴 이상인 무기에 제공한다.

기본 보급은 기존 두 무기의 덱을 보존하고, 산개는 연발/전격을, 압쇄는 철갑을 더 포함한 10장으로 시작한다. 해금된 보급 사이드그레이드는 네 무기 모두 선택 가능하다. 기본 보급이라는 이름과 실제 시작 덱을 UI에서 확인할 수 있게 한다.

## UI 제작 계획 — 소스 편집 전 작성

기준 캔버스 1280×800, Galaxy 가로 비율에서는 동일 논리 캔버스를 축소한다.

```text
┌─────────────────────────────────────────────────────────────┐
│ LAST ON BOARD                  빌린 총의 순서를 정하는 인간 │
│ 기본 보급[선택]    난도[0] [기록실]                          │
│ [ ] 탄환 기초 훈련 7교전     도시 등반 5계층 / 35층          │
├──────────────────────────────┬──────────────────────────────┤
│ [단발 실루엣] 보행자 / 조절  │ [다연 실루엣] 쇄도 / 일제   │
│ 한 발씩 / 피해 +1            │ 전탄 1턴                    │
│ 4칸 · 재장전 1턴             │ 4칸 · 재장전 3턴            │
│ 화상·충격 [이 총으로 시작]   │ 증폭·연발 [이 총으로 시작]  │
├──────────────────────────────┼──────────────────────────────┤
│ [확산 실루엣] 산개 / 군집    │ [중장 실루엣] 압쇄 / 관통   │
│ 거리 차 3m 이내 적에 확산    │ 관통 +2 · 남는 관통→피해    │
│ 4칸 · 재장전 2턴             │ 3칸 · 재장전 2턴            │
│ 연발·전격 [이 총으로 시작]   │ 철갑·증폭 [이 총으로 시작]  │
├──────────────────────────────┴──────────────────────────────┤
│ 시드[      ] [이어 하기] [규칙] [개발자 테스트]             │
│ 보급 선택/시드/새 등반의 저장 교체 안내                     │
└─────────────────────────────────────────────────────────────┘
```

카드는 2열로 정렬해 시작 버튼을 첫 화면에서 접근 가능하게 한다. 긴 탄환 설명은 시작 화면에 나열하지 않는다. 총기 아이콘은 임시 벡터 실루엣이다. 고유 규칙의 자세한 식과 시작 보급은 카드의 정보 버튼에서 확인한다.

전투에서는 장착 무기 옆 한 줄에 고유 규칙을 표시한다. 기존 탄창에 확산 대상/피해와 초과 관통 추가 피해를 표시하고, 계산 상세는 모든 보조 타격의 근거와 HP를 설명한다. 6칸에서도 셀 아래 짧은 줄은 범위 안에 맞춰야 한다. 적 정보 팝업은 주 피해와 보조 피해를 모두 집계한다. 확산 연출은 총구→보조 표적 선, 전이 연출은 주 표적→보조 표적 선으로 구분한다.

개발자 테스트에는 네 무기의 조합을 같은 편성에서 즉시 비교하는 4개 버튼과 무기 선택 화면 숏컷을 제공한다. 실제 저장은 보존한다.

## 구현 순서와 검증

1. 무기 데이터, 시작 덱, 공통 함수로 용량/관통/파츠 적합성 정의.
2. 실제 타격 정산에 확산과 초과 관통 구현. 예측은 동일 명령을 복사 실행.
3. 메뉴/고유 규칙/상점 파츠/관문 용량/탄환 공급/계산/연출 UI 연결.
4. 실제 명령과 저장 복원으로 결정론, 장갑/거리 경계, 확산 후 표적 변경, 전이 중복, 넉백 상한 검증.
5. 35층 새 무기 완주와 기존 두 무기 회귀, 실제 버튼/가로 폰 레이아웃 확인.
6. 기록·QA 결과·로컬 커밋, Windows 최신 플레이 파일 갱신.

자동 완주는 기능상 플레이 가능한 경로의 근거다. 사람의 체감 재미나 네 무기의 최종 균형이 입증되었다고 표현하지 않는다.
