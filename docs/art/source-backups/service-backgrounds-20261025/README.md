# 실내 배경 원본 보존

사용자의 2026-10-25 배경 묘사 밀도 완화 요청에 앞서 기존 상점/보급/작업대 배경을 그대로 복사했다.

- 원래 파일: `새-게임-프로젝트/assets/art/service_layers_20261011/{place}_background.png`
- 이 폴더의 PNG와 원래 파일은 해시가 같다. `manifest.json` 참조.
- 새 사용본: `새-게임-프로젝트/assets/art/service_background_grouped_20261025/{place}.png`
- 원래 경로도 보존한다. 새 배경을 이 폴더에 덮어쓰지 않는다.
