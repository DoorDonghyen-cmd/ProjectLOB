# 주인공 추가 후보 3종

최신 요청 조합: [C의 복장 + B의 방한모 v2](character-c-expedition-cap-v2.png). 사용자가 C의 긴 외투에 B의 모자를 원해, 모자 본체를 짙은 청회색으로 바꾸고 붉은 어깨 덮개와 연결되는 적갈색 띠를 넣었다. 기존 A/B/C는 보존한다. 내장 image_gen으로 두 원본을 입력해 편집했고 [프롬프트·출처·해시](provenance-c-expedition-cap-v2.json)를 기록했다. 컨셉 조합 시안이며 게임에는 미적용이다.

2026-10-03 · 사용자 요청으로 기존 헬멧 주인공을 바탕으로 제작한 외형 비교 시안. 새 플레이 직업이나 별도 전투 규칙을 추가한 것이 아니다. 기존 시작 외형의 채택 상태는 유지하고 새 후보는 사용자 검토 전으로 둔다.

| 후보 | 이미지 | 주요 차이 |
| --- | --- | --- |
| A · 작업모 정비사 | [PNG](character-a-workcap.png) | 낮은 챙의 작업모, 짧은 황토색 재킷, 옆구리 공구 가방. 가볍고 생활감 있는 실루엣 |
| B · 방한모 탐험가 | [PNG](character-b-expedition.png) | 귀를 덮는 방한모, 밝은 칼라, 회녹색 방한복과 배낭. 기상탑 탐험의 준비된 인상 |
| C · 장외투 회수자 | [PNG](character-c-longcoat.png) | 각진 헬멧, 긴 청회색 외투, 비대칭 붉은 어깨 덮개. 강한 머리/어깨 실루엣 |

[기존 시작 외형](../2026-10-03-pixel-reference/character-reference-v2-helmet.png)과 동일한 방향·비슷한 자세/크기로 만들었다. 모자·외투 길이·어깨·짐의 형태를 비교할 수 있다. 판단: C는 붉은 비대칭 어깨와 긴 옷자락이 눈에 남고, A는 기술자의 생활감이 분명하다. 이는 디렉터의 시안 평가이며 실제 게임 크기 판독성 검증 결과가 아니다.

내장 image_gen.imagegen 편집 사용. [전체 프롬프트와 원본·해시·크기](provenance.json). 원본을 삭제하지 않고 프로젝트에 복사했다. 세 이미지 직접 시각 검토와 사본 해시/알파 형식을 확인했다. 게임 적용/엄격한 픽셀 격자/분리 레이어/애니메이션은 후속이며, 작은 무기·손과 투명 경계는 생산용 스프라이트 단계에서 정리한다. 게임 코드·저장·현재 기본 외형 결정은 바꾸지 않았다.
