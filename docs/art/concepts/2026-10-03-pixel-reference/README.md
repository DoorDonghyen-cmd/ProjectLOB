# 캐릭터·배경 레퍼런스 시안

2026-10-03 · 사용자는 이 시안의 도트풍과 헬멧 주인공 v2를 시작 외형으로 채택했다. 실제 게임 적용과 추후 복장·헬멧 획득/교체는 [후속 작업](../../../direction/appearance.md)이다.

- [채택된 시작 외형 v2](character-reference-v2-helmet.png): 챙이 짧은 청록 정비용 헬멧, 황토색 띠와 작은 점검등. 내장 image_gen 편집을 사용했으며 [수정 프롬프트·출처·해시](provenance-helmet-v2.json)를 기록했다. provenance의 검토 전 표시는 생성 당시 기록이고 이후 사용자 채택 상태는 이 문서를 따른다.

- [캐릭터](character-reference-v1.png): 청록 작업 외투, 탄약 가방, 공구와 황동 탄환으로 직업을 나타내는 성인 기술자. 가방 끈을 잡고 총을 아래로 내린 대기 자세.
- [배경](background-reference-v1.png): 기상탑의 폐쇄된 주거 통로. 거대한 차가운 수직 공간과 왼쪽의 작은 수리점 불빛, 연속된 가로 발판.

사용자 레퍼런스 중 캐릭터01/02의 큰 색면과 성인 실루엣, 배경02/05의 건축·명암층을 수정 입력으로 사용했다. 초기 생성안의 잔묘사를 줄였고 캐릭터의 손과 총이 겹치는 자세를 단순화했다. 첫 캐릭터·배경과 후속 헬멧 수정안을 별도 파일로 보관하며 생성 원본은 삭제하지 않았다.

도구는 내장 image_gen.imagegen. [전체 생성·수정 프롬프트와 파일 출처](provenance.json)를 보존했다. 복사 해시와 이미지 크기를 확인했고 후처리/리샘플링은 하지 않았다. 생성 이미지의 명암에 미세한 색 변화가 남아 있으므로 엄격한 단일 픽셀 격자·제한 팔레트 스프라이트로 검증한 결과가 아니다. 캐릭터의 투명 가장자리 정리, 게임 크기의 무기/손 판독성, 배경 레이어 분리와 공통 픽셀 밀도는 실제 적용 단계에서 검수한다.

게임 코드·현재 탄환 카드·플레이 자산은 변경하지 않았다.
