# Pinterest Pixel Art UI 보드 검토

2026-10-10. 사용자 제공 [LaBine Pat의 Pixel Art UI 보드](https://kr.pinterest.com/dethmuffin/pixel-art-ui/)를 브라우저로 확인했다. 보드는 핀 8개로 표시됐다. 로그인 안내가 화면을 가리지만 페이지에 공개 로드된 썸네일은 확인 가능했다. 아래 세 이미지를 별도로 열어 관찰했으며 추천 핀을 보드 수록작으로 혼동하지 않는다.

## 관찰 근거

- [장비/소지품/능력치의 네 구획 예시](https://i.pinimg.com/236x/83/84/32/838432f50679e505965501efc3ff5872.jpg): 같은 프레임 안에서 아이콘 격자와 상태 수치를 공간으로 분리한다. 두 화면 중 아래 화면에는 소지품 위 작은 메뉴가 보인다. 정지 이미지이므로 실제 호출 방식은 확인하지 않았다.
- [어두운 슬롯과 선택 행동 예시](https://i.pinimg.com/236x/c2/47/5f/c2475ffbe4d94e6e581d434007a5b229.jpg): 빈 장비 칸에는 낮은 대비의 종류 실루엣, 아이템에는 선명한 색을 사용한다. 선택 아이템은 밝은 윤곽, Equip 행동은 노란 면으로 강조한다.
- [캐릭터 중심 장비 배치 예시](https://i.pinimg.com/236x/15/d6/4e/15d64e977aa4f08369acec9940b3c293.jpg): 캐릭터 주변 장비 칸, 위쪽 자원 게이지, 오른쪽 수치를 분리한다. 큰 외곽 패널 안에서 모든 수치에 별도 박스를 두지 않는다.

원 제작자·게임명·라이선스는 이번 공개 썸네일에서 확인하지 못했다. 미리보기는 폭236px로, 정확한 픽셀 단위·폰트 품질·누름 애니메이션·모바일 가독성의 근거로 삼지 않는다. 보드 전체나 고해상도 원본을 모두 검토했다고 간주하지 않는다.

## LoB 적용 후보 — 디렉터 해석, 미구현

- **탄환 가방/파츠:** 물건 그림을 중심으로 선택하게 하고, 선택 대상의 상세와 행동을 가까이 묶는다. 현재 자산의 이름과 효과 설명을 모두 없애는 제안은 아니다. 종류 구분과 필요한 설명은 유지한다.
- **빈 칸/보유/선택의 대비:** 빈 칸은 약한 홈과 기호, 보유 물건은 읽히는 실루엣, 선택은 선명한 가장자리로 구분한다. 잠김·부족·비활성이 같은 어두운 칸으로 오해되지 않도록 별도 상태 단서를 둔다.
- **선택 강조의 범위:** 전체 패널을 밝히기보다 선택한 물건과 실행 가능한 행동에 강조를 모은다. 참고작의 노란색을 그대로 도입하지 않고 LoB의 민트 선택/주 행동 의미를 유지한다.
- **화면 역할 구분:** 이 자료는 주로 장비/인벤토리 구성에 유용하다. 조밀한 스탯 격자를 전투 HUD에 옮기지 않는다. 전투에서는 현재 발열·냉각·실행 결과의 위계가 우선이다.

CraftPix의 부품 형태/깊이 검토를 보완하는 참조다. 새 스타일 확정이나 사용자 승인으로 기록하지 않는다. 외부 자산 편입, 코드 수정, 런타임 테스트는 수행하지 않았다.
