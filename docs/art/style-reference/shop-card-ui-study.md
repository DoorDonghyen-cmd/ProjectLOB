# 사용자 제공 상점 카드 UI 참조

2026-10-10. [사용자 제공 이미지](user-shop-card-reference.png)를 직접 확인했다. 출처 게임명·제작자·사용 조건은 미확인이다. 참고용으로 보존하며 게임 배포 자산으로 편입하지 않는다. 사용자는 카드 섹션과 버튼 디자인의 중요성을 강조했으며 이미지의 모든 색상·배치를 채택하라고 지시하지 않았다.

## 이미지에서 관찰한 점

- 상단 상점 풍경 아래 탭, 하나의 큰 상품 면, 그 안의 카테고리와 카드 격자로 이어진다. 영역 간 겹친 가장자리와 공통 갈색 외곽이 화면을 묶는다.
- 상품 카드는 위쪽 레벨 띠, 물건 그림, 기호와 수치, 하단 가격/구매 상태로 같은 순서를 반복한다. 설명 문장이 없어도 물건 비교 위치가 일정하다.
- 가격은 카드 바깥의 별도 목록이 아니라 카드 하단에 붙어 있는 버튼 모양의 면이다. BOUGHT/LOCK 표시가 상품 상태를 구분한다. 실제 클릭 영역과 구매 확정 동작은 정지 이미지로 확인할 수 없다.
- 상단 탭과 가격 면은 좁은 밝은 가장자리와 어두운 아래 단면을 공유한다. 카드 내부 밝은 면, 갈색 띠, 주황 행동/상태 면이 반복된다. 활성·잠금에 주황이 함께 보여 색만으로 상태를 판별하는 방식은 그대로 채택하지 않는다.

## LoB 적용 제안 — 미구현, 디렉터 해석

1. 카드 자체뿐 아니라 **카드를 담는 섹션·카드·행동 버튼을 한 묶음**으로 설계한다. 바탕 대비와 가장자리 깊이를 함께 정하고, 각 영역에 임의의 박스를 추가하지 않는다.
2. 탄환/파츠 카드는 정해진 위치에서 이름·물건·핵심 수치·효과를 비교할 수 있게 한다. 카드 하단은 전투에서는 효과, 상점에서는 비용과 구매 상태라는 화면별 역할을 갖는다. 모든 카드에 구매 버튼 형태를 복제하지 않는다.
3. 상점에서는 물건과 가격/행동의 관계를 가깝게 보여 준다. 모바일 실수 구매를 막는 선택/비교/확정 흐름은 별도로 검증하며, 참고 이미지에서 직접 구매 방식을 추정하지 않는다.
4. 버튼은 공통 윗면·아랫면·눌림 깊이를 사용하고 탭/주 행동/보조 행동은 강조 크기를 달리한다. 카드와 버튼의 도트 두께가 제각각인 결과를 피한다.
5. 밝은 상품 면이 배경과 구분되는 원리는 참고하되, 베이지/주황 팔레트와 3열의 촘촘한 격자를 LoB에 그대로 이식하지 않는다. 현재 청회색 전장, 승인 탄환 도트, 한글 크기와 모바일 터치 영역에 맞춰 실제 통합 화면에서 평가한다.

이 참조는 기존 CraftPix의 부품 조형과 Pinterest의 선택 대비 기준을 보완한다. 이번에는 참조 이미지 보존과 문서만 변경했다.
