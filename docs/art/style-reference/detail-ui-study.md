# 카드·버튼 디테일 참조

2026-10-10. 사용자는 직전 공통 도트 UI가 이전보다 월등히 좋아졌다고 평가하고, 아래 세 이미지를 세부 완성도의 참조로 제공했다. **직전 공통 UI 방향은 사용자 채택**, 이번 추가 디테일은 디렉터 구현 후 확인 대상으로 구분한다.

- [카드](user-detail-card.png): 비대칭 모서리 이음, 외곽의 두께, 어두운 이름 띠, 아래로 모인 게이지가 카드 한 장의 실루엣을 만든다. 배경 무늬와 수많은 스탯을 우리 탄환 카드에 복사하는 지시는 아니다.
- [패널 모음](user-detail-panels.png): 제목판과 조작 면이 연결되며, 슬라이더·선택 틀·버튼이 동일한 각진 모서리 표현을 반복한다. 장식이 많고 밝은 판타지 팔레트여서 세부 형태의 참고로 한정한다.
- [버튼](user-detail-buttons.png): 넓은 윗면과 아래 단면, 단계별 모서리, 국소 하이라이트가 있다. 좌우 그림의 두께가 다르지만 실제 누름 애니메이션인지 정지 시안의 변형인지는 확인되지 않았다. LoB에서는 이 두께 차이를 실제 pressed 상태에 연결한다.

원 제작자·게임명·사용 조건은 미확인. 사용자가 첨부한 참고 이미지는 문서에 보존하며 게임의 배포 자산으로 사용하지 않는다. 실제 UI는 기존 자체 제작 그리드 SVG를 보완했다.

## 적용

카드는 우측 위 이음과 좌측 아래 받침, 이름 띠의 짧은 단차를 추가했다. 장전 판은 양 끝의 작은 안착부로 카드와 구분한다. 버튼은 계단형 어깨와 4px 아래 받침을 갖고, pressed에서 윗면이 낮아지며 글자가 2px 내려간다. 버튼의 상하 내용 여백 합계와 클릭 영역은 유지한다. 작은 반사광은 모서리에만 두며 프레임 전체에 점·얼룩을 흩뿌리지 않는다.

주요 배치·효과 텍스트·색 의미·그림은 직전 채택안을 유지했다. 현재/예측 발열 및 선택 표시를 가릴 만한 무늬는 추가하지 않았다. [구현·검증](../../qa/reports/console_detail_2026-10-10.md).
