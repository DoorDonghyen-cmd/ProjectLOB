## 현재 화면과의 차이 — 디렉터 판단

비교 대상은 [현재 전투 캡처](../../qa/reports/combat_visual_polish_2026-10-10_assets/insertion_1280.png)다. 현재 UI는 정보 위계와 상태 표시를 정리했지만, 큰 단색 사각형과 얇은 선이 지배적이다. 도트 글꼴과 탄환 그림을 제외하면 부품 자체의 특징이 약하다. 장식을 줄이는 작업만으로 사용자가 원하는 도트 게임의 완성된 인상을 만들기는 어렵다는 판단이다. 이는 제작 방식이나 AI 사용 여부를 판별하는 객관 지표가 아니라 시각적 일관성에 대한 평가다.

참고 이미지에서는 재질의 두께, 단면, 받침과 눌림 깊이가 제한된 색면으로 읽힌다. 모든 면에 질감을 넣기보다 가장자리와 연결부에 묘사를 배분하고 읽는 면을 비운다는 접근을 가져온다. 네온 배선, 두꺼운 다중 테두리, 군용 장식, 종이 찢김 자체를 모방하지 않는다.

## 다음 제작에서 검증할 제안

1. **공통 부품 언어:** 탑의 오래된 조작 장치에 어울리는 청회색 외곽·빛 받는 단면·어두운 내부 홈을 카드/탄창/버튼/계기에 일관되게 쓴다. 현행의 절제된 색과 넓은 읽는 면을 유지한다. 이전에 철회한 금속/가죽 정비함 외피나 얼룩을 복원하는 제안이 아니다.
2. **역할별 형태:** 탄환 카드는 얇은 판, 탄창은 삽입 홈, 발사·재장전은 눌리는 키, 발열은 계기라는 차이를 실제 그림으로 보강한다. 같은 사각형에 색만 달리한 결과인지 통합 화면에서 확인한다.
3. **의도적인 도트 덩어리:** 가는 벡터 선에 도트 글꼴만 얹지 않고 모서리·단면·그림자의 크기를 승인 탄환 및 전장과 비교한다. 가장자리만 선명하게, 내부에는 불필요한 잡음을 넣지 않는다. 픽셀 해상도를 영구 규칙으로 고정하지 않는다.
4. **상태도 한 세트로:** 기본/선택/눌림/비활성에서 형태와 깊이 변화가 읽히도록 제작한다. 참고 시트의 색상 변형을 실제 인터랙션 증거로 간주하지 않는다. 민트 선택·주 행동, 청회색 냉각, 주황 위험의 현행 의미를 지킨다.
5. **통합 비교:** 부품별 예쁜 시안만 평가하지 않고 현재 전투 화면에 카드·탄창·행동 키·계기를 함께 놓고 비교한다. 작은 화면에서도 숫자·한글·선택 모서리·발열 예측이 장식보다 먼저 읽혀야 한다. 기존 레이아웃과 입력 영역은 이번 검토의 변경 대상이 아니다.

이번 검토는 공개 이미지 열람과 문서 정리만 수행했다. 외부 자산은 다운로드·구매·프로젝트 편입하지 않았으며 게임 코드 변경과 새 런타임 검증은 없다. 이후 실제 자산 편입 시 해당 제품의 사용 조건을 별도로 확인한다.
