# 아트·사운드 이전 UI/UX 완성 계획

상태: 구현 및 검증 완료  
대상: `prototype/core-redesign`의 5계층 35층 도시 등반  
목표: 최종 일러스트·애니메이션·음향 리소스를 교체하기 전에도 처음부터 완주까지 막힘 없이 이해하고 조작할 수 있는 기능 완성본

## 1. 플레이어가 화면마다 답해야 하는 질문

| 화면 | 가장 먼저 보일 질문 | 주 행동 |
|---|---|---|
| 타이틀 | 어떤 무기로 어떤 모드를 시작할까? | 무기 선택 후 등반 시작 |
| 지도 | 다음 한 칸의 보상과 비용은 무엇인가? | 두 경로 중 하나 선택 |
| 전투 | 어떤 탄환을 어떤 순서로 넣으면 접촉 전에 끝나는가? | 선택 → 순서 확인 → 장전 확정 → 발사 |
| 보상 | 현재 덱에 필요한 탄환인가, 크레딧이 더 필요한가? | 탄환/크레딧/건너뛰기 |
| 무기고 | 이 구매가 현재 무기와 덱을 어떻게 바꾸는가? | 탄환·파츠·압축 코어 구매 |
| 보급·이벤트 | 얻는 것과 지불하는 것은 무엇인가? | 공개된 교환 중 하나 선택 |
| 관문 | 다음 계층에서 유지할 영구 성장은 무엇인가? | 탄창/압축/크레딧 |
| 정산 | 왜 이기거나 졌고 다음에는 무엇을 바꿀까? | 재도전/기록/새 등반 |

## 2. 공통 화면 골격

```text
┌ 계층 / 진행 ─────────── 덱·장비  기록실  설정  메뉴 ┐
│ LV   Cr   압축 코어   무기·탄창   덱 장수   난도     │
├─────────────────────────────────────────────────────┤
│ 화면 제목                                             │
│ 한 문장의 현재 결정                                   │
│                                                     │
│ 실제 조작 영역                                       │
│                                                     │
├─────────────────────────────────────────────────────┤
│ 상황에 맞는 짧은 도움말 / 주 행동                    │
└─────────────────────────────────────────────────────┘
```

- 정보는 색만으로 구분하지 않고 아이콘·명칭·수치를 함께 쓴다.
- 모든 주요 버튼은 모바일 기준 최소 52px 높이를 유지한다.
- 같은 성격의 화면은 제목, 질문, 후보 카드, 주 행동 순서를 공유한다.
- 긴 설명은 기본 화면에서 빼고 `정보`, `규칙`, 카드 상세에 둔다.
- 좁은 가로 화면은 전체 세로 스크롤로 접근 가능해야 하며 버튼이 잘리면 안 된다.

## 3. 전투 작업대

```text
┌ 거리 전장 / 가까운 적 위협 강조 / 적 터치 상세 ┐
├ 보유 탄환 ─────────────┬ 발사 순서 0/4칸 ─────┤
│ 카드  카드  카드       │ ①  ②  ③  ④          │
│ 카드  카드  카드       │ 예상 처치·안전 거리   │
│ 다음2 / 대기 / 사용    │ [장전 확정]            │
└────────────────────────┴ [발사] [재장전] ──────┘
```

- `탄환 선택 → 순서 확인 → 장전 확정`의 현재 단계를 항상 표시한다.
- 빈 탄창, 확정된 탄창, 발사 가능한 상태마다 다음 행동을 한 문장으로 안내한다.
- 압축 가능 여부와 코어 잔량은 글을 늘리지 않고 기존 결합 표시와 2칸 코어 픽토그램으로 전달한다.
- 손패 5장 제한은 유지하고 다음 2장·대기 더미·사용 더미 전체 구성을 계속 노출한다.
- 계산 결과에는 처치 대상, 남은 HP, 안전 거리 또는 접촉 위험을 우선 노출한다.

## 4. 첫 실행과 안전장치

- 타이틀에서 `도시 등반`과 `7교전 기초 훈련`의 차이를 짧게 보여 준다.
- `처음 안내`는 3단계 시각 카드로 제공하고 언제든 다시 열 수 있다.
- 진행 중인 도시 저장이 있을 때 새 도시 등반을 누르면 무기·층·진행 교체 사실을 확인받는다.
- 메뉴로 돌아가기는 자동 저장된 진행을 유지한다.
- 실제 저장 파일을 지우는 기능은 이번 화면에 두지 않는다.

## 5. 설정·접근성

- 글자 크기: 90% / 100% / 110%.
- 전투 연출: 기본 / 빠르게 / 즉시.
- 상황 도움말: 켜기 / 끄기.
- 설정은 `user://redesign_preferences_v1.json`에 즉시 저장한다.
- 최종 사운드가 연결되기 전이므로 음량 항목은 실제 기능이 생길 때 추가한다.

## 6. 선택 화면 정보 규칙

- 탄환 보상에는 현재 덱 보유 수와 핵심 효과를 함께 표시한다.
- 구매 버튼에는 가격과 결과(`덱에 추가`, `구매·장착`, `1회 충전`)를 함께 표시한다.
- 이벤트는 보상과 비용을 같은 버튼 안에서 한 번에 읽게 한다.
- 관문 성장은 현재값→변경값으로 표시한다.
- 정산은 진행 층, 전투 수, 턴, 발사, 재장전과 함께 가장 많이 사용한 효과를 보여 준다.

## 7. 구현·검증 완료 조건

1. 타이틀, 안내, 설정, 지도, 전투, 보상, 상점, 보급, 이벤트, 관문, 덱·장비, 기록실, 승리, 패배에 개발자 바로가기가 있다.
2. 새 등반 덮어쓰기 확인, 설정 저장/복원, 도움말 on/off가 자동 검사된다.
3. 1280×800과 1008×630에서 모든 주요 행동이 터치로 실행되고 겹침·잘림이 없다.
4. 실제 UI 입력으로 35층 완주와 저장/복원이 통과한다.
5. 기능 회귀, 규칙/가독성/압축 밸런스 검사가 모두 통과한다.
6. 최종 화면 원본과 아트 교체 대상·상태표를 인계 문서에 남긴다.
