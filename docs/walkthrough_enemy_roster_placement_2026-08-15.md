# 몬스터 13종 계층 배치·표기명 정합 워크스루

> 완료일: 2026-08-15
> 범위: 일반·변종 9종의 계층별 편성, 관문 보스 4종을 포함한 캠페인 도달성, 적 표시명 정합

## 결과

35층 캠페인의 일반전 편성을 `EnemyRoster` 한 곳에서 관리하도록 분리했다. 기존에는 `combat_scene.gd`의 조건문에 편성이 흩어져 있었고 관리 계층과 정점 계층이 같은 분기를 공유했지만, 이제 다섯 계층이 각각 독립된 초·중·종반 후보 편성을 가진다.

| 계층 | 처음 도입되는 일반·변종 | 운용 원칙 |
| :--- | :--- | :--- |
| 침전 거주구 | 폭동 돌격병, 진압 방패병, 광학 굴절병 | 거리·관통·명중 기본 학습 |
| 공역 | 경보 순찰 드론, 신경 교란 부유체 | 후열 우선순위와 충전 대응 |
| 정비 계층 | 흡수 장갑 구체 | 유효타 누적 대응 |
| 관리 계층 | 태세 교란 드론, 광학 추적체 03, 상위 신경 통제체 | 교란·고명중·충전의 복합 대응 |
| 정점 | 없음 | 이미 학습한 상위 적을 고밀도로 재조합 |

일반전은 최대 4체를 유지하며, `SPD >= 3`인 고속 적이 한 편성에 둘 이상 겹치지 않도록 회귀로 고정했다. 관문 편성은 기존 `CampaignContent`를 유지해 A/B/C/E 보스 4종과 D 정예 관문의 흐름을 바꾸지 않았다.

## 표시명 정리

CSV와 `.tres`의 표시명을 동일하게 맞추고, 변종과 보스를 현행 기계화 계층 세계관에 맞는 명칭으로 정리했다. 대표 변경은 `광학 굴절병`, `신경 교란 부유체`, `흡수 장갑 구체`, `태세 교란 드론`, `광학 추적체 03`, `상위 신경 통제체`, `세라프 방어 프로토콜`, `적합성 개조체 Ω`다.

표시명만 변경했으며 적 ID, 체력·방어·회피·속도, 아키타입과 특수 기믹은 그대로 유지했다. 게임 제목과 `L.O.B 코어`의 최종 명칭 재검토도 이번 범위에서 제외했다.

## 구현 파일

- `새-게임-프로젝트/scripts/core/enemy_roster.gd`: 계층별 편성·증원·최초 등장 정본
- `새-게임-프로젝트/scripts/ui/combat_scene.gd`: 일반전 생성 경로를 정본에 연결
- `새-게임-프로젝트/data/enemy_stats.csv`, `resources/enemies/*.tres`: 표시명 동기화
- `새-게임-프로젝트/tests/suite_enemy_roster.gd`: 계층 배치와 13종 도달성 회귀
- `docs/gdd/04_enemy_design.md`: 실제 5계층 배치표와 정본 위치 반영
