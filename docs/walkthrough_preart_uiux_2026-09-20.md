# 아트·사운드 이전 기능 및 UI/UX 완성 워크스루

## 결과

`prototype/core-redesign`을 처음 실행해 무기를 고르는 순간부터 35층 정점 완주 또는 패배 후 재도전까지 하나의 플레이 흐름으로 마감했다. 최종 그림과 음원을 제외하면 게임 규칙, 콘텐츠 연결, 저장, 설정, 모바일 입력과 화면 정보 구조가 구현되어 있다.

## 플레이 흐름

1. 타이틀에서 도시 등반과 7교전 훈련을 구분하고, 시작 보급·난도·다섯 무기를 선택한다.
2. 처음 안내에서 `탄환 선택 → 순서 설계 → 결과 확인`을 배우며 언제든 다시 열 수 있다.
3. 지도에서 목적지와 계단/환기구 비용을 보고 이동한다.
4. 전투에서 전술 패5장과 예비 탄환을 보며 탄환을 왼쪽부터 배치하고, 계산 뒤 전탄 또는 단발로 발사한다.
5. 보상·무기고·보급·이벤트·관문에서 덱, 크레딧, 압축 코어와 탄창을 성장시킨다.
6. 승리와 패배 정산에서 원인, 사용 기록, 최종 덱과 다음 설계를 확인하고 재도전한다.

## 이번 완성 패스

- 모든 런 화면에 고도·크레딧·압축 코어·무기/탄창·덱·난도 상태바와 덱·기록·설정·메뉴 동선을 통일했다.
- 첫 실행 안내, 설정 저장, 글자90/100/110%, 연출 기본/빠르게/즉시, 상황 도움말 토글을 추가했다.
- 진행 중인 도시를 새 등반으로 교체할 때 확인 창을 표시하고, 메뉴로 나가도 저장을 보존한다. Android 뒤로 가기는 연출 건너뛰기, 창 닫기, 메뉴 복귀 순으로 처리한다.
- 화면을 다시 그릴 때 이전 세로 스크롤 위치가 남아 제목이 잘리던 문제를 수정했다.
- 지도·보상·상점·보급·이벤트·관문에 `지금 무엇을 고르는가`를 한 문장으로 표시하고 가격과 결과를 같은 선택 카드에서 읽게 했다.
- 덱 상세는 탄환 카드 묶음, 기록실은 20칸 수집 그리드로 바꿔 긴 텍스트 목록을 제거했다.
- 패배 화면에 접촉 원인과 덱 상태에 맞춘 다음 장전 조언을 추가했다.

## 전투와 콘텐츠 잠금

- 전투 상단에 3단계 진행 표시를 두고 빈 탄창·계획 완료·발사 가능 상태마다 다음 행동을 안내한다.
- 부유체는 3턴 충전 후 다른 적을 2m 당기고, 흡수 구체는 직접 타격 횟수로 배리어가 벗겨지며, 태세 드론은 매 턴 장갑4와0을 오간다.
- 계층1부터 충전, 계층2부터 배리어, 계층3부터 태세를 차례로 소개하고, 정점 관문은 세 규칙을 결합한다.
- 실루엣, 상태 기호, 적 상세와 발사 예측이 같은 정산 모델을 사용한다.

## 개발자 검수 동선

타이틀의 `개발자 테스트`에서 안내·설정, 다섯 무기, 압축 장전, 현장 압축, 상층 적3종, 지도·상점·보급·이벤트·관문·보상·덱·기록·승리·패배를 저장 손상 없이 바로 연다. 아트 교체 후 같은 동선으로 전 화면을 비교할 수 있다.

## 검증

- Godot 전체 파싱, UX30, 적 규칙27, 무기 규칙3,192, 가독성30,247, 현장 압축264 항목을 실패 없이 통과했다.
- 다섯 무기와 난도0~10에서 35층 도시 28회, 총 59,310개 검사와 2,328,270개 탐색 상태가 실패 없이 완료됐다.
- 실제 OpenGL UI는 35층 완주, 526회 입력, 1,639개 경계·상태 검사를 통과했다.
- 대표 원본 16장은 `docs/qa/reports/preart_uiux_2026-09-20_assets/`에 보관했다.
