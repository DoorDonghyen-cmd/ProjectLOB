# 탄종·파츠 빌드 일괄 플레이테스트 체크리스트

> 작성일: 2026-08-03
>
> 목적: 여러 차례 나눠 확인하던 탄종·파츠·상점·연속 런 항목을 한 번의 테스트 묶음으로 검증한다.
>
> 원칙: 수치 암기보다 **다음 장전과 표적 선택이 실제로 달라졌는지**를 우선 기록한다.

## 0. 테스트 준비

- [ ] 개발자 테스트에서 `전부 초기화`를 한 번 실행한다.
- [ ] `모든 무기 해금`을 실행한다.
- [ ] 각 런이 끝난 뒤 메인 화면의 `플레이테스트 로그`에서 가장 최근 JSON 파일명을 기록한다.
- [ ] 아래 런 사이에는 비교 조건을 맞추기 위해 새 런을 시작하되, 플레이테스트 로그 파일은 삭제하지 않는다.

기록 척도:

- `1`: 전혀 느껴지지 않음
- `3`: 의식하면 구분됨
- `5`: 장전·표적 선택이 명확히 달라짐

## P0. 필수 비교 — 같은 총기, 다른 파츠 분기

### 런 A — Workhorse + 연속 운용

- [ ] Workhorse로 시작한다.
- [ ] 4층 첫 상점이 `전술탄 1 + 파츠 2`로 표시되는지 확인한다.
- [ ] 파츠 카드가 `A · 연속 운용`과 `B · 운용 전환`으로 구분되는지 확인한다.
- [ ] 리듬 챔버를 구매한다. 가격은 30Cr이고, 인터럽터는 `반대 분기 폐쇄`가 되어야 한다.
- [ ] 가방에서 리듬 챔버를 장착한다.
- [ ] 같은 역할 탄을 연속 배치하는 장전을 최소 3전투 시도한다.
- [ ] 침전 거주구 보스 처치 후 메인 화면으로 돌아가지 않고 공역으로 이어지는지 확인한다.
- [ ] 공역 4층 상점까지 진행해 `후속 시너지` 카드에 실제 보유 파츠명이 표시되는지 확인한다.

기록:

- 연속 역할 장전을 의식한 정도 `__/5`
- 리듬 챔버가 탄환 선택을 바꾼 정도 `__/5`
- 첫 상점에서 선택 차이를 이해한 정도 `__/5`
- 구역 A 종료 시 장착 파츠: `________________`
- 구역 B 4층에서 제시된 두 파츠: `________________ / ________________`
- JSON 파일명: `________________`

### 런 B — Workhorse + 운용 전환

- [ ] 동일하게 Workhorse로 시작한다.
- [ ] 첫 상점에서 인터럽터를 구매하고 리듬 챔버가 폐쇄되는지 확인한다.
- [ ] 공격·연계·제어 역할을 번갈아 배치하는 장전을 최소 3전투 시도한다.
- [ ] 공역 4층 상점까지 진행해 후속 시너지/총기 친화 분기를 확인한다.

기록:

- 역할 교대 장전을 의식한 정도 `__/5`
- 인터럽터가 탄환 선택을 바꾼 정도 `__/5`
- 런 A와 다른 빌드라고 느낀 정도 `__/5`
- 구역 A 종료 시 장착 파츠: `________________`
- 구역 B 4층에서 제시된 두 파츠: `________________ / ________________`
- JSON 파일명: `________________`

## P1. 탄종별 짧은 확인

각 항목은 첫 구역 또는 해당 현상을 충분히 본 시점까지만 진행해도 된다.

### 런 C — Tempo / 강화 경량탄

- [ ] 같은 적에게 유효 적중 1/3·2/3 표시가 이해된다.
- [ ] 세 번째 유효 적중의 추가 피해가 눈에 띈다.
- [ ] 표적을 바꿀 때 적별 집중 스택이 구분된다.
- [ ] 연발 사격이 너무 강해 별도 전술탄 장전이 무의미해지지 않는다.
- [ ] 리로드 공백이 실제 위험으로 느껴진다.

기록: 집중 재미 `__/5` · 과화력 체감 `__/5` · JSON `________________`

### 런 D — Heavy / 강화 소총탄

- [ ] 주 대상 뒤의 적에게 스침 피해가 들어가는 것이 보인다.
- [ ] 첫 후열의 강화 스침과 그 이후 후열의 피해 차이가 과도하지 않다.
- [ ] 적이 3~4체일 때 소총탄이 모든 다른 공격탄을 항상 대체하지 않는다.
- [ ] 적 대열 순서와 DEF를 먼저 확인하게 된다.

기록: 관통 체감 `__/5` · 과화력 체감 `__/5` · JSON `________________`

### 런 E — Bruiser / 산탄

- [ ] 4m 이상에서도 주 대상에게 최소 피해가 들어가 무의미한 격발이 사라졌다.
- [ ] 원거리에서는 확산과 총기 자체 넉백이 발생하지 않는다.
- [ ] 3m 이내에서는 주변 적 확산과 넉백 차이가 분명하다.
- [ ] 적이 접근할 때까지 기다릴지 원거리 약화 사격을 할지 선택이 생긴다.
- [ ] 샷건 친화 상점에서 `확산 격발`이 후보가 될 수 있다. 무리한 리롤로 억지 확인할 필요는 없다.

기록: 거리별 차이 `__/5` · 원거리 답답함 `__/5` · JSON `________________`

## P1. 공통 UI·경제 확인

- [ ] 상점 카드 세 장이 모바일 화면에서 겹치거나 잘리지 않는다.
- [ ] 파츠 설명과 선택 이유, 가격, 구매 버튼을 스크롤 없이 판독할 수 있다.
- [ ] `선택 (30 Cr) · 1개 한정` 문구가 구매 전에 보인다.
- [ ] 리롤 시 비용이 3Cr, 6Cr 순으로 증가한다.
- [ ] 리롤 뒤에도 연속 운용/운용 전환 또는 후속 시너지/총기 친화의 두 축이 유지된다.
- [ ] 이미 장착·가방·Hold에 있는 파츠가 다시 제시되지 않는다.
- [ ] 기본탄 보급 현재/상한과 가방 8칸이 혼동되지 않는다.
- [ ] 리로드 후 기본탄이 총기 보급 상한까지만 복구된다.

## P2. 시간 여유가 있을 때

- [ ] 계층 전환 시 덱·파츠·가방·크레딧이 유지된다.
- [ ] 공역 이후 일반전 3~4체가 많지만 감당 가능하다.
- [ ] 보스 5연전과 35층 연속 런의 길이가 지나치게 늘어지지 않는다.
- [ ] 제압형 연발 총기의 예고창 5칸이 모바일에서 읽힌다.
- [ ] 승천 1 이상에서 난이도 상승이 불공정한 DEF/EVA 벽이 아니라 거리·자원 압박으로 느껴진다.

## 전달할 결과

테스트 후 아래만 전달하면 된다.

1. 런 A~E의 점수와 한 줄 소감
2. 가장 재미있었던 파츠 조합 1개
3. 가장 의미 없었던 파츠 또는 탄환 1개
4. 불편하거나 이해되지 않은 UI
5. 각 런의 최신 `playtest_run_*.json` 파일

JSON `schema_version: 2`에는 전투 기록뿐 아니라 상점 최초 진열, 리롤, 구매 분기,
구매 전후 크레딧과 당시 장착 파츠가 함께 기록된다.
