## 목표

후반 덱이 자유 정제로 얇아져 같은 장전 순서를 반복하는 문제를 줄이고, 중복 탄환을 새로운 장전 판단으로 바꾼다. 압축탄은 수치만 높은 상위 탄환이 아니라 탄창 공간이나 발사 위치를 대가로 효과를 집중하는 변형이다.

## 확정 규칙

- 계층 관문에서 `탄창 확장 / 탄환 압축 / 24Cr` 중 하나를 선택한다.
- 탄환 압축은 같은 일반 전술탄 2장을 같은 계열의 압축탄 1장으로 영구 변환한다.
- 회수탄과 이미 압축된 탄환은 압축할 수 없다.
- 압축 및 탄환 제거 뒤 덱은 최소 8장을 유지한다.
- 전투 보상·보급·무기고의 자유 정제는 제거한다. 희귀 신호의 탄환 분해는 최소 8장 규칙을 적용해 경제 선택으로만 남긴다.
- 압축탄의 전투 카드 제목은 원형 이름을 유지한다. 별도 이름이나 `압축/중량/선두/후미` 문구를 상시 노출하지 않는다.
- 정확한 규칙 문장은 길게 누르기/마우스 툴팁과 전투 정보에서만 제공한다.

## 압축탄 규격

| 원형 | 압축 효과 | 장전 대가 |
|---|---|---|
| 철갑탄 | 피해 5, 관통 6 | 2칸 점유 |
| 충격탄 | 피해 5, 넉백 강도 3 | 마지막 발 고정 |
| 소이탄 | 피해 3, 화상 6 | 2칸 점유 |
| 증폭탄 | 다음 2발 피해 +4 | 마지막 발 고정, 다음 탄창으로 이월 |
| 연발탄 | 피해 3으로 3회 타격 | 첫 발 고정 |
| 전격탄 | 피해 4, 다른 모든 생존 적에게 전이 2 | 첫 발 고정 |

증강 총기는 기존 계약대로 피해·관통·효과 강도를 2배로 하되 타격 횟수와 화상 기간은 늘리지 않는다. 압쇄는 압축 소이의 화상 틱과 압축 전격의 전이 강도에 기존 전문 보정을 적용한다.

## 장전 와이어프레임

```text
발사 방향  ─────────────────────────────────────▶

┌──────────┬──────────┬──────────┬──────────┐
│  ◈  ◈    │          │    ⚡    │          │
│   철갑탄───────────  │   전격탄 │    ·     │
│  피해/관통 아이콘    │  피해/전이 아이콘      │
└──────────┴──────────┴──────────┴──────────┘
   두 칸을 실제로 덮음                 ▲ 마지막 고정 위치
```

- 압축 상태: 동일 탄환 실루엣 두 개가 겹치고 중심 코어가 점등된다. 속성 색은 그대로 유지한다.
- 2칸 점유: 하나의 카드 외곽선이 인접한 두 슬롯을 가로질러 이어진다. 선택 시 두 슬롯이 동시에 점등된다.
- 첫 발 고정: 카드 앞면의 뾰족한 결합부와 첫 슬롯의 맞물리는 홈으로 표현한다. 선택하면 첫 슬롯으로 자동 배치된다.
- 마지막 발 고정: 카드 후면의 마개와 탄창 끝단의 맞물리는 홈으로 표현한다. 이후 일반탄을 추가하면 압축탄이 자동으로 마지막으로 이동한다.
- 배치 불가: 남은 유효 슬롯을 어둡게 하고 카드가 들어갈 위치만 점등한다. 확인 뒤 오류 문구를 띄우지 않는다.
- 모바일 탭 조작은 자동 배치하며, 탄창 슬롯을 눌러 회수하는 기존 조작을 유지한다.

## 구현 구조

1. `content.gd`
   - 압축탄 6종 데이터와 원형↔압축 매핑을 추가한다.
   - `slot_cost`, `anchor`, `compressed`, 다중 전이 및 타격 수를 데이터로 공개한다.
   - 탄창 사용량과 합법 배열을 계산하는 공용 함수를 둔다.
2. `model.gd` / `forecast.gd`
   - 배열 길이 대신 슬롯 사용량으로 장전 한도를 판정한다.
   - 첫 발·마지막 발 규칙을 자동 정렬하고 확정 시 재검증한다.
   - 압축탄의 다중 타격·전체 전이·증폭 이월을 실제 정산과 예측이 동일한 경로로 처리한다.
   - 저장 버전을 올리고 이전 저장은 일반탄 상태 그대로 이관한다.
3. `campaign.gd` / `campaign_ui.gd`
   - 관문 압축 선택과 변환을 추가한다.
   - 압축 가능한 중복 탄환만 시각 카드로 제시한다.
   - 자유 정제 진입점을 제거하고 최소 덱을 8장으로 통일한다.
4. `ammo_visual.gd` / `ammo_card_view.gd` / `magazine_view.gd`
   - 압축 이중 실루엣, 결합부, 두 칸 연결 카드, 자동 배치 미리보기를 그린다.
   - 카드 본문에는 효과 아이콘과 숫자만 남긴다.
5. 개발자 테스트
   - 메인 메뉴 개발자 팝업에 `압축탄 장전 UI`와 `관문 압축 선택` 바로가기를 추가한다.

## 검증 기준

- 6종 변환이 정확히 같은 일반탄 2장을 소비하고 압축탄 1장을 만든다.
- 압축 뒤 덱 8장 미만, 회수탄 압축, 재압축을 거부한다.
- 2칸·첫 발·마지막 발 제약이 탭 순서와 무관하게 합법적인 탄창을 만든다.
- 예측과 실제 발사 결과가 다섯 무기 모두에서 일치한다.
- 이전 저장을 읽고 새 저장을 왕복하며 덱·패·탄창 소유권이 보존된다.
- 1008×630 모바일 기준 카드·탄창·관문 화면이 가로로 넘치지 않는다.
- 기존 35층 완주, 무기 5종, 산개 확률 예측 회귀가 유지된다.

## 후속 확장 — 런 자원형 현장 압축

- 장전 단계에서 패에 남아 있는 같은 일반 전술탄 2장을 선택해 압축탄 1발로 만든다.
- 런 시작 시 코어 1개, 최대 2개다. 무기고에서 방문당 한 번 18Cr로 1개를 충전하며 전투 시작 시 자동 복구하지 않는다.
- 코어 1개를 소비하며, 회수탄·압축탄·이미 장전에 사용한 탄환은 대상에서 제외한다.
- 추가 턴과 패 교환 기회는 들지 않는다. 코어와 압축탄의 물리 장전 제약이 비용이다.
- 임시 압축탄은 한 번 발사하면 원본 2장이 버림패로 돌아간다.
- 확정 전 장전 취소 또는 압축 취소 시 원본 두 장을 패로 되돌리고 코어 1개를 복구한다.
- 확정 뒤 재장전으로 발사하지 않은 임시 압축탄을 버리면 원본 두 장이 버림패로 돌아가며 코어는 복구하지 않는다.
- 전투 종료와 캠페인 저장에서도 영구 덱은 변하지 않는다. 저장 상태는 임시 탄환의 원형과 위치를 명시한다.
- UI는 패 영역의 작은 압축기 상태와 충전등 2개를 사용한다. 남은 전술탄은 개별 카드로 펼치고 압축 가능한 동일 카드 쌍에만 청록 연결 표시를 켠다. 짧은 탭은 한 발 장전, 같은 카드로의 드래그 앤 드롭은 합성과 자동 배치를 실행한다.
- 공개 패 5장 밖의 탄환은 `다음 2장`, `대기 구성`, `사용 구성`으로 모두 표시한다. 다음 2장만 순서를 공개하고 나머지는 아이콘과 수량만 보여 준다.
- 정확한 문장은 상세 보기와 최초 안내에만 두며 전투 카드에는 새 상태 단어를 추가하지 않는다.
- 증강에서 현장 압축이 고정 행동이 되는지 다른 네 무기와 같은 조건으로 우선 비교한다.
