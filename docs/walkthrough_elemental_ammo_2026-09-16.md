# 피해·관통 및 물리·화염·전기 개편 결과

## 최종 규칙

탄환의 공통 수치를 `피해·관통` 두 개로 줄였다. 적의 공개 수치도 `HP·장갑·거리·접근`으로 정리했으며 명중·회피·조준·스침·균열·파쇄·둔화를 제거했다. 속성 저항과 확률 판정은 없다.

```text
남은 장갑 = max(0, 장갑 - 관통)
타격 피해 = max(1, 피해 + 총기 보정 + 증폭 - 남은 장갑)
```

- **물리:** 즉시 피해, 높은 관통, 넉백과 같은 장갑·거리 대응
- **화염:** 화상 수치만큼 적 전진 직전에 1피해씩 적용. 화상으로 죽으면 이동하지 않음
- **전기:** 주 표적 공격 뒤 가장 가까운 다른 생존 적에게 고정 2피해 전이

탄환은 회수·철갑·충격·소이·증폭·연발·전격 7종이다. 각 탄환은 속성 하나와 특수 효과 최대 하나만 가진다. 증폭은 다음 2발의 타격당 피해 +2, 연발은 같은 적 2회 타격, 충격은 탄창당 총 2m 넉백이다.

## 화면과 학습

- 전투·보상 카드는 상단에 `속성 아이콘 + 물리/화염/전기`, 가운데에 피해·관통, 하단에 효과 한 줄만 표시한다.
- 소이탄은 주황 불꽃과 `화상 +3`, 전격탄은 청록 번개와 `전이 2`로 통일했다.
- 적 옆과 상세창에 화상 수치를 표시하고, 전진보다 먼저 `화상 −1` 주황 펄스를 재생한다.
- 규칙창과 실제 피해 설명도 두 수치와 세 속성만 사용한다.
- 학습은 피해/증폭 → 장갑/관통 → 화상 → 연발 → 넉백 → 전기 → 복합 순서다.
- 개발자 테스트의 `3속성 탄환 전체`와 `화상 전진 정산`에서 실제 장전·발사와 저장 보존을 즉시 확인할 수 있다.

## 저장 호환

저장 버전을 v3로 올렸다. 기존 v2 저장은 불러올 때 `조준탄→증폭탄`, `점착탄→충격탄`, `마무리탄→철갑탄`으로 변환한다. 덱·손패·드로우·버림·탄창·계획을 모두 같은 규칙으로 바꾸고, 적의 회피·둔화·균열 상태는 제거한 뒤 화상 0으로 시작한다. 변환 뒤에도 소유 장수와 저장 원자성을 검사한다.
