# 탄종 3계열 행동·기술 규격·파츠 시너지 구현 계획

> **작성일**: 2026-07-30
> **상태**: Phase A~F 구현·자동 검증 완료 / 수동 플레이테스트 대기
> **설계 정본**: [gdd/23_ammo_family_behaviors.md](./gdd/23_ammo_family_behaviors.md)

## 1. 범위

- 경량탄: 적별 3회 유효 적중 집중
- 소총탄: 5.56mm 1명 / 7.62mm 3명 후열 관통
- 산탄: 3m 이내 거리 군집 확산
- 기존 파츠 23종과 전술탄 중복 해소
- 탄종별 전투 예고·피격 피드백
- 9총기×13적 결정론 검증과 1~2구역 수동 테스트

컨버전 킷 재활성화, 새로운 산탄 강화 규격, 신규 파츠 추가는 이번 범위가 아니다.

## 2. 구현 순서

### Phase A — 실패하는 계약 테스트 ✅

1. `suite_ammo_family_behavior.gd`를 추가한다.
2. 집중의 유효 적중·실패·타겟 전환·사망·리로드 초기화를 고정한다.
3. 5.56/7.62의 대상 수, 피해 감쇄, 중간 DEF 차단을 고정한다.
4. 산탄의 3m·거리 차 1m·PEN 게이트·대상 상한을 고정한다.
5. 보조 피해가 흡수체 셀, 파쇄, 집중, 후속 효과를 중복 발동하지 않는지 고정한다.

### Phase B — 데이터와 규칙 계층 ✅

- `scripts/data/enums.gd`
  - 기존 직렬화 값을 건드리지 않는 별도 `AmmoFamily`·`AmmoGrade` 추가
- `scripts/core/caliber_profiles.gd`
  - 5개 `WeaponClass`를 3개 계열과 표준/강화 규격으로 매핑
  - 집중 보너스, 관통 깊이·감쇄, 확산 반경·상한을 단일 정본으로 제공
- 필요하면 `scripts/core/ammo_family_rules.gd`를 추가해 대상 선정과 감쇄 계산을
  `CombatManager`에서 분리한다.

### Phase C — 전투 정산 ✅

- `scripts/core/combat_manager.gd`
  - 적별 집중 상태와 재장전 초기화
  - 주 피해 전에 보조 대상 거리순 스냅샷 생성
  - 주 적중 1회와 보조 피해 N회를 분리한 비재귀 정산 함수
  - Heavy 과관통, `PIERCE`, 확산 격발, 관성 격발을 새 계약으로 교체
  - 복수 처치 통계·신호·승리 판정 누락 방지

정산 순서는 아래로 고정한다.

```
주 대상 ACC/PEN 판정
→ 탄 조건·크리티컬·주 대상 파츠
→ 경량 집중 보너스
→ 주 대상 피해 1회
→ 소총 후열 또는 산탄 확산 보조 피해
→ 주 대상 후속 효과·넉백·상태·처치
→ 한 격발 단위 보조 처치 정리
```

### Phase D — 중복 파츠·전술탄 마이그레이션 ✅

- `pierce`: 고정 2명 타격에서 관통 깊이 +1로 변경
- Heavy: 추가 대상 생성에서 첫 후열 감쇄 완화로 변경
- `spread_shot`: 기본 확산 생성에서 대상·반경·넉백 확장으로 변경
- `inertia_fire`: 무제한 누적에서 3회 주기 +2로 변경
- 파츠 `.tres`, 탄환 `.tres`, `bullet_stats.csv`, UI 설명을 함께 갱신

### Phase E — 수치 사전검증 ✅

1. 9mm 집중 +1, .45 ACP 집중 +2를 1차 후보로 검사한다.
2. .45 ACP DMG 4→3과 Tempo 리로드 3→4 후보를 함께 비교한다.
3. 단일 대상 DPT 2.14~3.33과 계획 탄창 상단 3.50~3.75를 기준으로 본다.
4. 다중 대상은 단일 DPT가 아니라 ‘추가 피해 상한’과 대열 출현 빈도로 검사한다.
5. 흡수체·태세병·보스 호위 대열에 우회 해법과 지배 해법이 모두 없는지 확인한다.

### Phase F — UI·연출 ✅

- 적 트랙에 집중 0~3 표식
- 사격 예고에 집중 발동, 관통 대상, 확산 대상을 표시
- 경량 집중 폭발 / 소총 직선 트레이서 / 산탄 펠릿 콘을 서로 다른 색·형태로 재생
- 전투 로그는 수치보다 `집중 2/3`, `후열 2명`, `군집 1명`을 먼저 표시

## 3. 회귀 검증

- 전체 데이터 검증과 CSV↔리소스 양방향 일치
- `suite_fire_mode`: Tempo/Suppressor 전량 커밋, 적 전진 1회, 넉백 총 2m
- `suite_parts`: 23종 발동 및 개편 3종 계약
- `suite_ammo_integrity`: 19종 탄환 수와 공용 전술탄 14종 유지
- `suite_combat_simulation`: 9총기×13적, 기본/환기구 거리
- `suite_ui_smoke`: 집중·관통·확산 예고와 실제 대상 일치
- 메인 씬 헤드리스 부팅

검증 결과: **2,476 통과 / 0 실패 / 기존 경보 3**.
`suite_ammo_family_behavior.gd`가 집중·직선 관통·군집 확산·관성 격발·Tempo
3.20 DPT를 고정하고, `suite_ui_smoke.gd`가 적별 집중 라벨과 탄종 이벤트의 격발 큐
결합을 확인한다.

## 4. 수동 플레이테스트 체크포인트

첫 구역 종료 시 아래 질문에 각각 ‘예’가 나와야 한다.

1. 경량탄은 같은 적을 세 번 맞히고 싶게 만드는가?
2. 소총탄은 적 대열 순서와 DEF를 먼저 보게 만드는가?
3. 산탄은 적 군집과 3m 진입 시점을 먼저 보게 만드는가?
4. 파츠를 바꿨을 때 탄종 기본 행동보다 더 큰 빌드 차이가 생기는가?
5. 탄종 효과가 전술탄 LIFO 순서를 무시하고 기본탄만 연사하는 지배 전략을 만들지 않는가?

## 5. 중단 조건

- Tempo 기본탄 사이클이 계획 탄창 없이 3.33 DMG/턴을 초과
- 7.62mm가 3명 이상 대열에서 다른 공격탄을 항상 대체
- 산탄 확산이 중장갑의 PEN 게이트를 사실상 무시
- 집중 폭발이 흡수체 배리어를 한 발에 두 칸 이상 차감
- 보조 피해가 파츠 효과를 대상 수만큼 복제

하나라도 발생하면 수치만 깎기 전에 발동 범위와 효과 복제 규칙부터 재검토한다.
