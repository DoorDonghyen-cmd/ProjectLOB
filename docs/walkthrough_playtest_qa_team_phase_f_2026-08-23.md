## 구현 결과

세 역할을 같은 결론에 유도하지 않고 각각의 최소 입력으로 실행한 뒤, 원본 보고가 모두 끝난 뒤에만
QA 리드가 통합하는 실행 계약을 코드와 실제 전방 검증으로 고정했다.

- `qa_role_packet.gd`: 기능 QA·경험 QA·전투 시뮬레이터별 입력 패킷 생성. 사전 결론과 조기 공유를 거절하고 경험 QA의 소스·오라클 접근을 차단한다.
- `qa_team_report.gd`: PASS/FAIL/INFRA/SIGNAL/BLOCKED와 심각도, FAIL 재현 증거, 역할별 판정 권한을 검증한다.
- `qa_team_integrator.gd`: 같은 session·commit·scenario·seed의 독립 원본 3개만 통합하고 확정 버그·경험 신호·인프라·근거 부족·상충을 분리한다.
- `qa_team_orchestrator.gd`: 역할 패킷 저장과 세 원본 완료 후 통합 JSON 생성을 담당한다.
- `suite_qa_team_orchestration.gd`: 정상 sample A, seeded 결함 sample B, 조기 정보 누출, 오탐·미탐, 역할 권한을 회귀 고정한다.

## 최근 인간 로그 재분석

최근 플레이 로그의 완료된 3전을 다시 계산했다.

- 3승, 16발, 15명중, 14유효 적중
- 명중식 불일치 0/16, 관통 게이트 불일치 0/15
- 주 피해 44 = 실제 HP 소모 40 + 과잉 피해 4
- 최소 거리 8m, 리로드 1회/1턴

이는 조합탄이 실제 수식 결과를 바꿨다는 점은 지지한다. 반면 사용자가 말한 배지 가독성,
발사 간격 체감, 조합탄 효과 구분의 명확성은 정지 JSON으로 판정할 수 없으므로 인간 결론을 유지했다.
생산 로그의 과잉 피해 직접 필드 부재와 sim harness의 리로드 미모델링은 제품 버그가 아닌 계측 개선 후보로 분리했다.
