# 현재 장전 순서와 랜덤성 검토

대상: `prototype/core-redesign`, `ba7957a`, Galaxy 테스트 APK와 같은 7교전 규칙. 제품 코드·밸런스·APK 변경 없음. 구버전 35층 게임과 혼동하지 않는다.

## 판단

순서가 결과를 만드는 기능은 존재한다. 다만 현재 콘텐츠가 반복해서 새로운 조합을 발견하게 만드는지는 충분히 입증되지 않았고, 구조상 변화의 폭이 좁다. 역순 입력은 가능한 발사 순서를 줄이지 않지만 생각한 조합을 입력하는 부담을 더할 수 있다. 따라서 UI 개선만으로 해결된다고 보거나 LIFO 폐지만으로 재미가 생긴다고 보지 않는다.

사용자는 Galaxy 플레이 후 전반적으로 괜찮다고 평가했으나, 탄환 정보가 직관적이지 않고 순서 조합의 느낌이 약하다고 보고했다. 이는 실제 사용자 피드백이며, 인간의 장기 재미·피로도나 기기 성능을 정량 검증한 결과는 아니다.

## 확인한 현재 규칙

- 공개 패의 탄환은 뽑힌 순서와 무관하게 선택 가능하다. 확정 전 장전/마지막 탄 취소는 시간 비용이 없다. 원하는 발사 순서의 역순으로 넣으면 모든 배열을 만들 수 있다. 확정 이후 변경은 재장전을 요구한다.
- 시작 덱은 서로 다른 전술탄 6종이고 공개 패는 5발이다. 처음 손패는 어느 1종이 빠졌는지에 따른 6가지 구성이다. 카드의 화면 나열 순서를 별도 선택지로 세지 않는다.
- 회수탄은 매 장전 3발 공급된다. 적 구성·거리·보상 후보는 층마다 고정되어 있다. 전투마다 덱을 다시 섞고 패·버프·탄창을 초기화한다. 보상 선택으로 이후 덱과 파츠는 달라질 수 있다.
- 피해/관통/명중 준비탄은 바로 다음 1발에만 영향을 주며 매 발 기존 버프를 소비한다. 여러 준비탄을 넣는다고 마지막 탄에 모든 버프가 누적되지는 않는다. 다만 앞의 준비탄이 뒤 준비탄을 강화하는 3발 연계도 실제로 가능하다.
- 적 장갑/회피는 조건 미달 시 피해 0/빗나감이다. 적절한 탄환으로 문턱을 넘기는 판단과 넉백으로 다음 표적을 바꾸는 판단이 주요 상호작용이다.

## 실제 모델 탐색

`tests/redesign_order_probe.gd`가 `Model.load_round → confirm → fire`를 호출했다. 시드 0~255의 초기 패 구성을 조사하고, 총기 2종 × 교전 1/2/3/4/7 × 시작 패 6종의 60개 조건에서 각 조건의 합법 4발 발사 순서 500개를 모두 실행했다. 총 30,000회이며 동일 순서가 다른 조건에서 반복될 수 있다.

후반 교전도 시작 덱/파츠 없음으로 고정한 분석용 조건이다. 실제 보상 경로를 밟은 캠페인, 재장전 이후 전술, 인간의 선택 확률을 나타내지 않는다. 각 조건에서 탄환 묶음 30종의 순열을 비교했다. 피해 민감도는 같은 묶음에서 순서에 따라 적별 최종 HP가 달라졌는지만 판정한다. 종합 종료 상태에는 거리·턴·실제 발사 수가 포함되므로 더 많은 차이를 잡지만, 죽은 적의 거리 같은 비본질적 차이도 포함할 수 있다. 수치를 재미 점수로 사용하지 않는다.

| 총기 / 교전 | HP가 달라진 묶음 / 180개(6패 합계) | 4발 이내 처치 배열 수 범위 / 패당 500개 |
| --- | ---: | ---: |
| 단발 / 1 | 0 / 180 | 500~500 |
| 단발 / 2 | 94 / 180 | 14~127 |
| 단발 / 3 | 83 / 180 | 114~274 |
| 단발 / 4 | 122 / 180 | 0~0 |
| 단발 / 7 | 82 / 180 | 0~0 |
| 일제 / 1 | 7 / 180 | 482~500 |
| 일제 / 2 | 94 / 180 | 0~36 |
| 일제 / 3 | 106 / 180 | 24~113 |
| 일제 / 4 | 92 / 180 | 0~0 |
| 일제 / 7 | 85 / 180 | 0~0 |

0회 처치는 첫 탄창에 전원을 처치하지 못했다는 뜻이다. 전투가 불가능하다는 뜻이 아니다. HP 차이 0도 순서가 완전히 무의미하다는 뜻은 아니다. 처치까지 사용한 탄 수/턴 수가 다를 수 있다.

구체적인 발사 순서 예시:

- 2교전, 단발총, HP 10 장갑 적: **장약 준비탄 → 천공 준비탄 → 회수탄**은 처치. **천공 준비탄 → 장약 준비탄 → 회수탄**은 HP 6 잔존. 장전 클릭 순서는 각각 반대다.
- 같은 조건에서 **천공 준비탄 → 회수탄**은 6피해, 반대 순서는 2피해다.
- 1교전은 무작위 전술탄 없이 회수탄만으로 단발 2발 또는 일제 3발에 처치된다. 입문 전투로는 이해되지만 순서 조합을 체감시켜 주는 근거로 삼을 수 없다.
- 256개 시드에서 초기 패 구성은 예상대로 6종이었다. 시작 패가 거의 전체 덱이므로 장갑 대응 쌍(천공/철갑)이나 회피 대응 쌍(조준/정밀)이 둘 다 없는 경우는 없다. 그렇다고 단독 대응탄 하나로 어떤 전투든 해결된다는 뜻은 아니다.

원본: `qa/reports/order_randomness_2026-09-13.json`. 로컬 환경의 인증서 저장소 읽기 경고가 있었으나 이 검사는 네트워크를 사용하지 않으며 Godot 실행은 종료 코드 0, 완료 표식과 60개 결과를 출력했다.

독립 전투 검토자 `preart_combat_audit`도 제품 파일을 변경하지 않고 코드/실제 Model로 별도 확인했다. 초기 64개 시드에서 손패 구성 6종을 확인했으며, 일제 총기 3교전의 조준→철갑/철갑→조준은 6/1피해, 6교전의 천공→조준→철갑/조준→천공→철갑은 7/1피해를 보고했다. 순서 조합이 존재하고 작은 덱·고정 교전/보상·제한된 효과 연결이 변동성의 제약이라는 독립 해석이 일치했다. 이 역시 인간 재미 판정은 아니다.

재실행: 별도 QA `APPDATA`/`LOCALAPPDATA`를 지정하고 `ORDER_PROBE_OUTPUT`에 출력 JSON의 절대 경로를 지정한 후 Godot에 `--headless --path <프로젝트> --script res://tests/redesign_order_probe.gd`를 전달한다.

## 해석과 논의 제안

현재 약점은 순서의 효과가 전혀 없다는 것이 아니라, 같은 적과 비슷한 재료를 반복하며 몇 가지 익숙한 연결을 재사용하기 쉽다는 점이다. 일반탄 자체의 수치, 다음 탄 수치 보정, 1회 제어에 효과가 집중되어 있다. 기존 3발 연계와 다수 적 표적 전환은 살릴 만한 기반이다. 지배 전략의 존재/빈도나 반복 피로는 이번 탐색으로 확정하지 않는다.

권장 순서는 다음과 같다. 아직 구현 결정은 하지 않는다.

1. **상호작용을 먼저 비교한다.** 탄환마다 전용 정답 상대만 늘리기보다 하나의 준비 효과를 여러 후속 탄이 서로 다르게 활용하도록 설계한다. 새 규칙 예시로 적에게 남는 균열을 강타로 소비해 큰 피해를 줄지, 후속 여러 발의 관통을 돕도록 유지할지 선택하게 할 수 있다. 지속 시간·소비 조건은 발사 전 표시하고, 회수탄도 약하지만 유효한 사용처를 둔다. 기존 효과와 혼동하지 않도록 별도 소규모 실험이 필요하다.
2. **제시되는 상황에 변화를 준다.** 보상 후보와 적 조합/거리의 제한된 변주를 우선 검토한다. 공격 결과는 예측 가능하게 유지한다. 단순히 손패를 줄이면 장갑/회피의 0피해 문턱 때문에 선택 대신 운에 막힐 수 있으므로, 손패 변화 실험에는 공개된 제한 교환 또는 다른 우회 수단을 함께 검토한다.
3. **발사 순서 전략과 역순 입력을 별도로 비교한다.** 동일한 콘텐츠로 현재 역순 장전과 '발사 순서를 직접 배치하고 역순 장전은 연출로 처리'하는 입력을 비교한다. 후자는 기존 LIFO 조작 정체성을 바꾸는 제안이다. 사용자와 논의 가능한 대안이며 기존 스킬 지침 때문에 배제하지 않는다. 사고의 긴장과 성취를 줄이는지, 단순 입력 실수를 줄이는지 구분한다.

비교에서는 같은 탄 묶음에 상황별로 다른 좋은 순서가 생기는지, 다른 패에서 다른 해법을 찾는지, 선택 이유를 플레이어가 설명할 수 있는지, 실패가 조작 착오/해법 부족/재료 부족 중 무엇인지 기록한다. 한꺼번에 규칙·패·입력을 전부 바꾸지 않는다. 4칸은 우선 이 차이를 비교하는 고정 조건으로 두고, 5~6칸 확장은 별도 후속 판단으로 남긴다.
