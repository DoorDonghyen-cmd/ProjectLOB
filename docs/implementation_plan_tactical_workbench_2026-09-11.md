# 전술 장전 작업대와 판단 피드백 개선

사용자가 UI 레이아웃 변경을 포함한 게임 개선을 명시적으로 위임했다. 이 문서는 그 범위의 실행 설계이며 별도 UI 승인 대기 없이 구현한다. 기준 커밋은 3a116ad. 아트 제작 이전 범위와 결정론적 LIFO를 유지한다.

## 문제와 목표

기존 700×390 가방은 적을 가리고, 탄창 슬롯이 긴 총기는 고정 높이 밖으로 버튼을 밀 수 있다. 장전 전술에는 적의 거리·장갑·회피와 발사 순서를 동시에 비교할 수 있는 화면이 필요하다. 장전 완료와 발사, 무료 장전 취소와 전투 중 빼내기의 비용을 구분한다.

## 화면 계약

```text
┌ 순서 설계 · 장전 중 턴 진행 없음 ────────────── 전장 보기 ┐
│ [첫 표적: 이름 HP/장갑/회피/거리] [적2] [적3] [적4]    │
│ 마지막에 넣은 탄부터 발사 · 카드의 게이트는 현재 첫 표적 기준 │
├ 탄환 / 버림 / 소멸 / 소모품 ──────────────────────────┤
│ 발사 순서 ↑           │ 사용 가능한 탄환                 │
│ 1 다음 발사           │ 역할·효과·현재 적 명중/관통       │
│ 2                     │ 보급탄 잔량 / 전술탄 수량         │
│ 3 ... (스크롤)        │ 후보 스크롤                      │
│                      │                                 │
├ 최근 장전 취소 · 비용 없음 ──── N발 장전 확정 (발사 별도) ┤
└───────────────────────────────────────────────────────┘
```

- 가로 화면 내부 여백12px, 뷰포트에 맞는 너비/높이, 탄창과 후보는 독립 스크롤. 버튼은 하단 고정, 최소44px.
- 적 카드 순서는 실제 가까운 적 우선이며 같은 거리 순서를 보존한다. HP/DEF/EVA/거리/SPD는 공개 런타임 상태만 사용한다. 카드 열람으로 타겟을 바꾸지 않는다.
- 장전 진입/리로드 완료 시 자동으로 작업대 열기. B 패 공개 연출 종료 후 열며 입력 잠금과 중복 실행을 보존한다.
- 기존 개별 삽탄/맨 위 취소/LIFO 확정/전술탄 보유량 검증 경로를 사용한다. 자동 조합, 순서 셔플, 패 밖 선택, 확률 정산은 추가하지 않는다.
- 발사 버튼은 장전 중 'N발 장전 확정', 전투 중 단발/연발을 명시한다. 비용과 실패 이유는 현재 규칙/예고가 확정하는 범위만 표시한다.
- 개발자 메뉴에 작업대 QA 바로가기 추가. 960×540,1280×720 및 긴 탄창/4체/B안 실제 렌더와 입력·리로드 회귀 확인.

## 검증 및 완료 범위

레이아웃 경계·가림·장전 순서·잔량·무료취소·확정 후1발격발·리로드의 실제 UI 경로를 검증한다. 전체 회귀, 독립 전투 조사, 화면 원본·Windows 빌드·기록을 제공한다. 실제 사람의 재미 점수와 Android 실기 통과를 자동 결과로 대신하지 않는다.
