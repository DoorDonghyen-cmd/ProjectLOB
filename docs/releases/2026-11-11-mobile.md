# ORVASK 전체 본편 모바일 테스트 · 2026-11-11

이번 빌드는 `res://redesign/main.tscn`에서 시작하는 전체 본편입니다. 새 규칙은 모두 **새 등반**에만 적용됩니다. 기존 이어하기는 이전 규칙 그대로이므로, 확인하려면 '새 도전'으로 시작하세요.

## 이번에 볼 것

- **과열 대가**: 과열로 강제 냉각되면 적이 보통 5번 움직입니다(이전 3번, 리액터는 4번). 미리 냉각하면 1번입니다. 사격 버튼의 '적 N행동 · 과열'을 보고 몇 발 쏠지, 언제 식힐지를 골라 보세요. 생각 없이 다 쏘면 1~2구역에서 질 수 있습니다.
- **태그 시험판**: 장비 화면 → 등반 설정 → '탄환·파츠 구성 · 비교 시험'에서 현재 구성 / 태그 시험판을 고릅니다.
  - 전투 탄창 카드 위쪽에 태그 글자(화·단 등)가 보입니다. 채운 칸은 장착한 파츠가 그 태그를 키우는 중이라는 뜻입니다.
  - 탄을 눌러 상세를 열면 태그와 지금 적용되는 파츠·수치가 나옵니다.
  - (두 번째 빌드) 태그 파츠로 오른 탄은 카드 숫자가 초록색 올린 값으로 보입니다. 맞힐 때 피해 숫자 아래에 태그 이름표(예: `단타+2×2.25`)가 태그 색으로 뜹니다. 단타는 분홍, 다회는 하늘색입니다.
  - 화염 파츠(화염 연소기·잔불 추격기)가 들어 있습니다.
- **일반 전투 보상 · 탄 1장 빼기**(세 번째 빌드): 전투 승리 후 보상 카드 맨 앞의 '탄 1장 빼기'를 고르면 덱에서 탄 1장을 뺄 수 있습니다(기본탄부터, 최소 장수까지).
- **섞인 탄 보상**(네 번째 빌드): 전투·탄약고 보상이 주력 1장 / 다른 공격탄 1장 / 지원탄 1장으로 나옵니다.
- **교차 사격**: 탄창 안에서 직전 공격탄과 다른 계열을 이어 쏘면 타격당 +1, 연달아 바꾸면 최대 +3(피해 숫자 아래 `교차+N`).
- **탄환 회수**: 마지막으로 쓰러뜨린 적이 그 적의 약점 탄(장갑벽 → 철갑탄 등)을 보상 카드 한 장('회수 · 적 이름')으로 내놓습니다. 처치 숫자 아래 '회수 …'가 뜹니다.
- **파츠 종류 표시**: 총열·조준기·약실·탄창·회로.
- **파츠 수정**: 야전 압축기 제외, 냉각 약실·가속 총열·처형 조준기 등 숫자 조정, 교차 급탄기 → 다종 급탄기.
- **탄환 이름·효과**: 압축 탄은 이름 끝 `+`(예: 연타탄+). 연계탄은 쏘면 교차 사격 단계 +2, 예약탄은 뒤 탄 1발을 다음 탄창 맨 앞으로 보냅니다.
- **성장 구조 v2**: 총기 내장 구동, 탄종 숙련(관문), 상점 구동 정비, 특수탄 우선 장전.

## 설치

갤럭시용 ARM64 테스트 APK입니다(32비트 기기에서는 실행되지 않습니다). 기존 `Last on Board Test`와 같은 앱 식별자·테스트 서명이라 압축을 풀고 APK를 설치하면 업데이트됩니다. 기존 앱 삭제는 필요 없습니다.

APK 서명·정렬·포장·본편 컴파일 자료 검사를 거쳤습니다. 실제 기기의 프레임·발열·터치와 과열 수치의 체감은 이번 플레이에서 확인해야 합니다.
