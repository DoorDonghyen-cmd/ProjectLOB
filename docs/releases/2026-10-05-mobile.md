# 모바일 플레이 테스트 — 2026-10-05

현재 작업 트리의 플레이 버전을 Android APK로 제공한다. ZIP을 풀고 `LastOnBoard-city.apk`를 설치한다. 기존 앱은 삭제하지 않고 업데이트한다.

## 이전 모바일 빌드 이후 변경

- 탄창·총기·파츠의 연계를 확장한 전투 모델 v12. 예약·차단·확산·연계 탄환과 냉각 약실·연쇄 방열기·예약 급탄기를 포함한다.
- 승인한 주인공의 부드럽고 덩어리감 있는 도트 표현과 기존 적 7종의 색감·도트 밀도 조정.
- 주인공의 조준·반동·재장전 동작과 적의 접근·피격·처치 반응. 재장전 및 강제 냉각의 실제 처리에 동작을 연결했다.
- 적과 투사체의 화면 위치를 실제 거리에 맞춰 정렬한다. 표시 거리가 먼 적이 더 가까이 보이던 문제와 발 위치의 흔들림을 수정했다.

## 테스트 시 확인할 부분

- Galaxy 가로 화면에서 탄약 선택, 마지막에 넣은 탄환부터 발사되는 순서, 예상 결과와 발사 조작.
- 거리가 서로 다른 적과 투사체의 위치 및 터치 표적 선택.
- 일반 발사, 1·2턴 재장전, 과열에 따른 강제 냉각의 동작과 표시.
- 총기·탄창 크기·파츠 조합에 따른 선택의 재미와 발열 부담.

## 포함 범위와 검증 범위

- 기존 캠페인과 상점·파츠·무기 선택 흐름을 포함한다.
- 최근 재정리한 몬스터 세계관과 새 명칭은 기획 단계이며 이번 APK의 새 몬스터 구현으로 포함되지 않는다.
- APK 서명·정렬·패키지 정보·리소스 및 압축 무결성을 검사하고, APK에서 추출한 실제 리소스를 PC Godot에서 격리 저장으로 실행 검사한다. Android 기기에서의 설치·실행 검증은 별도다.
- 빌드 버전과 체크섬은 동봉한 `build_manifest.json`, `validation.json`, `SHA256SUMS.txt`에 기록한다.
