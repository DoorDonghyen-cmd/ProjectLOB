# ORVASK 모바일 테스트 — 2026-10-17

최근 작업 내용을 포함한 Galaxy용 테스트 버전입니다. 기존 앱을 삭제하지 말고 업데이트 설치하세요.

## 이번 플레이 확인

새 등반을 시작하면 새 탄환 구성을 사용합니다. 기존 등반은 보유 탄환과 기존 발견 규칙을 유지합니다.

- 기본탄·철갑탄·연타탄의 기초 위력1~5와 발열 차이. 높은 위력이 항상 좋은 선택은 아니며 코어·파츠·열 한계에 맞춰 고릅니다.
- 상점의 탄환 개조: 방문당1회,12Cr로 보유한 한 장만 화력 또는 방열 개조. 다른 사본은 그대로 유지됩니다.
- 같은 탄종·위력·개조 두 장끼리 압축. 현장 압축이 끝나면 정확한 원본 두 장으로 복원됩니다.
- 교차 급탄기는 마지막 공격탄을 앞선 다른 탄종마다 강화합니다. 연계탄 신규 획득은 중단했습니다.
- 연쇄·열압·돌파 성장 코어, 다수 적 처치와 발열 피드백, 최근 복장·무기·타이틀·실내 장소와 UI 변경이 포함됩니다.

첫 구역 깊이5부터 위력4/5 탄도 보상·상점 후보에 등장합니다. 탄환 카드의 피해/발열 숫자와 상점의 전후 비교를 확인해 주세요.

PC에서 실제 전투 계산, 저장 복원, UI3해상도, 첫 구역15개 총기·코어 경로를 검증했습니다. Android 실기 성능과 터치 체감은 이번 휴대폰 플레이에서 확인해야 합니다.
